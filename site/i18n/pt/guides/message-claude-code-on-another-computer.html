Instale o Antenna nos dois computadores, pareie-os uma vez como ∞ · Meu computador e conecte a sessão do Claude Code de lá ao Antenna com um nome próprio. A partir daí, você escreve para essa sessão do seu Mac como para um contato num chat, ou deixa o seu Claude Code local escrever para ela. Se você iniciar a sessão pelo Antenna, ela é acordada quando fica parada, e uma mensagem urgente pode interrompê-la no meio do turno. Duas sessões no mesmo computador? Nesse caso, ligue-as no mapa de agentes: dois agentes conversando.

Quando você precisa disso

  • O Claude Code roda num servidor ou num desktop para tarefas longas, e você quer passar a próxima tarefa a partir do notebook.
  • Uma sessão planeja e outra executa, cada uma na sua máquina.
  • Você usa várias máquinas e quer um chat por sessão em vez de um terminal por máquina.

1. Pareie os dois computadores

Instale o Antenna nos dois: o app num Mac ou num desktop Linux, o nó de servidor num servidor Linux (o guia Claude Code numa VPS mostra como). Em um deles, crie um convite no nível ∞, abra-o no outro e digite em um lado o código de seis dígitos que o outro mostra. O pareamento é igual ao de uma pessoa, e só você pode fazê-lo: ele exige a sua senha de dono em cada lado.

2. Dê um nome à sessão

No outro computador, na pasta do projeto:

antenna connect claude-code --agent api-dev --links mac --hello mac

Aqui, mac é o nome que o servidor deu ao seu Mac no pareamento. Isso cria o agente api-dev, adiciona o Antenna ao Claude Code só para esta pasta (depois do seu sim) e manda um oi para o seu Mac, para que um chat chamado api-dev apareça lá na hora. Uma sessão em outra pasta ganha um nome e um chat próprios. O Codex funciona do mesmo jeito, com antenna connect codex.

3. Mantenha a sessão acordada

O Claude Code só lê o Antenna enquanto está trabalhando em alguma coisa. Para que ele pegue uma mensagem quando está parado num prompt vazio, inicie-o pelo Antenna:

antenna session start api-dev --dir ~/projects/api

(Para isso, o servidor precisa do tmux.) O Antenna então digita uma linha curta no prompt vazio quando chega uma mensagem, e a sessão lê a mensagem como dado e segue com o trabalho. Num desktop, o modo Código do Antenna faz o mesmo numa aba de terminal dentro da janela. Experimental.

4. Escreva para ela

Abra o chat api-dev no seu Mac e escreva, como escreveria para uma pessoa. Ou peça ao seu Claude Code local: “Peça ao api-dev para rodar os testes da migration e me contar o resultado.” Quando não dá para esperar, ative Urgente: interromper agora (o botão de raio ao lado de Enviar) antes de enviar (pelo terminal, antenna send --urgent): numa sessão que o Antenna roda, no modo Código ou com antenna session start, o Antenna interrompe uma vez o turno em andamento, como você faria apertando Esc, e a sessão lê a sua mensagem. Ele nunca aperta Esc por cima de uma pergunta ou de um pedido de permissão aberto no terminal. Experimental.

O que trafega e o que não trafega

A mensagem é criptografada em um computador e descriptografada no outro. Nenhum terminal é compartilhado, e nenhuma porta precisa ser aberta ou redirecionada: a outra sessão só recebe mensagens, e o próprio Antenna dela decide o que ela pode fazer com elas. O token do agente fica no computador em que foi criado.

Perguntas

Isso é controle remoto do terminal?

Não. Você não vê nem digita no outro terminal. Você manda mensagens e tarefas à sessão, e ela responde no chat. Para o terminal completo, use SSH como antes.

Consigo ver o que a sessão está fazendo?

O chat mostra as respostas dela, e o mapa de agentes mostra quem falou com quem. Em Meus dispositivos, você também vê os agentes dos seus outros computadores e pode parar um deles junto com tudo o que ele iniciou.

O servidor precisa de um endereço público?

Não. Os dois computadores se conectam para fora; quando não conseguem se alcançar diretamente, um relay repassa o tráfego criptografado.

O que acontece depois que o servidor reinicia?

As chaves ficam bloqueadas depois de um reinício. Faça login uma vez e rode antenna unlock; depois disso, a sessão pode ser iniciada de novo.
