No próprio notebook não dá: fechar a tampa coloca o notebook em suspensão, um computador suspenso não roda nada, e o Claude Code fica parado junto com ele. A saída é rodar o Claude Code num computador que fica ligado, como um servidor Linux ou um Mac mini configurado para não entrar em suspensão, iniciá-lo lá pelo Antenna e mandar tarefas pelo chat do Antenna no seu notebook. Feche o notebook: o Claude Code continua trabalhando no outro computador, e as respostas dele esperam pelo notebook e chegam quando ele volta a ficar online.

Por que ele para

O Claude Code roda no computador em que você o inicia. Quando esse computador entra em suspensão, todos os programas dele param, inclusive o Claude Code, até ele acordar. Fechar o terminal ou a janela de SSH em que ele roda também o encerra. Dá para manter um notebook acordado com a tampa fechada, mas aí ele precisa ficar na tomada e ligado, e virou um servidor. Por isso o trabalho vai para um computador que está sempre ligado, e o notebook só conversa com ele.

O que você precisa

  • Um computador que fica ligado: um servidor Linux x86_64 (uma VPS ou um em casa), ou um Mac ou desktop Linux configurado para não entrar em suspensão.
  • O Claude Code instalado e com login feito nele.
  • O Antenna nos dois computadores: o app no seu notebook (macOS ou Linux) e o nó ou o app no outro.

Num servidor

  1. Instale o nó do Antenna e deixe-o rodando depois que você sair: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
    O instalador configura o Antenna como serviço de usuário do systemd e cria o seu nó com uma senha. Ele não ativa o lingering, só lembra você: sem a segunda linha, o serviço para quando você sai da sessão.
  2. Pareie o servidor com o seu notebook uma vez. No notebook: Novo contato → Convidar, marque Este é o meu próprio computador (∞), clique em Criar link e copie o link. No servidor: antenna join '<link>' --trust 5 --label mac, digite o código que o notebook mostra e depois clique em O contato confirmou — os códigos conferem no notebook.
  3. Inicie o Claude Code pelo Antenna na pasta do projeto (o servidor precisa de tmux): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Responda às primeiras perguntas do Claude Code, como se ele confia na pasta, e depois saia com Ctrl-b d. Agora há um chat chamado api-dev no seu notebook.
  4. Deixe o notebook responder aos pedidos de aprovação do servidor: antenna devices confirm mac.

Agora saia do SSH. O serviço continua rodando, e o Claude Code continua rodando no servidor tmux do próprio Antenna; o seu tmux não é tocado. Em Claude Code numa VPS você encontra cada passo com mais detalhes.

Num Mac ou desktop sempre ligado

  1. Configure o computador para não entrar em suspensão sozinho, nos ajustes do sistema. O Antenna não mantém o computador acordado.
  2. Pareie-o com o seu notebook como acima, com Este é o meu próprio computador (∞) marcado.
  3. Nele, abra Agentes → Apps de IA e clique em Iniciar no modo Código ao lado do Claude Code. Escolha Novo agente… e dê um nome a ele, escolha a Pasta de trabalho, digite a sua senha e clique em Iniciar. A janela passa para o modo Código, e o Claude Code roda numa aba dentro dela.
  4. Peça uma vez ao Claude Code, na aba dele, que dê um oi ao seu notebook pelo Antenna. O chat dele então aparece no notebook.
  5. Deixe o notebook responder aos pedidos de aprovação dele: Meus dispositivos → o cartão do notebook → Aprovações → Aceitar aprovações assinadas com …, com a sua senha.

Deixe a janela do Antenna aberta: fechá-la para os agentes que rodam nela, e a janela pergunta antes.

Deixe-o trabalhando

Escreva a tarefa no chat do agente no seu notebook: “Rode os testes da migração, corrija o que falhar e responda aqui com o que mudou.” Quando o Claude Code está parado no prompt, o Antenna digita uma linha fixa para ele ler a sua mensagem; se ele estiver no meio de um turno, recebe a mensagem quando o turno termina. O Antenna nunca digita o seu texto no terminal. Experimental. Depois, feche o notebook.

Antes de uma tarefa longa, veja o que poderia pará-la enquanto ninguém está olhando:

  • O próprio aviso de permissão do Claude Code (“Do you want to proceed?”) espera no terminal dele até alguém responder, e o Antenna nunca responde. Libere nas configurações do Claude Code as ferramentas de que a tarefa precisa.
  • Os pedidos de aprovação do Antenna esperam 10 minutos. Depois disso nada roda, e o Claude Code fica sabendo que ninguém aprovou. Uma tarefa que você manda do seu próprio computador em ∞ roda os comandos e as edições dela sem perguntar; mudanças na configuração do próprio Claude Code, como CLAUDE.md ou .claude/, continuam pedindo aprovação.

Quando o notebook acorda

Enquanto o notebook dorme, as respostas do Claude Code esperam na fila do outro computador, e o Antenna continua tentando entregá-las. Assim que o notebook volta a ficar online, elas chegam no chat, com uma notificação se a janela do Antenna não estiver em primeiro plano. Uma mensagem que você escreveu offline mostra um relógio e sai sozinha. Os pedidos que ainda esperam a sua aprovação aparecem no cartão do outro computador em Meus dispositivos (experimental).

Depois que o outro computador reinicia

As chaves ficam travadas depois de um reinício, então as conexões dele ficam em silêncio até você digitar a senha. Num servidor, faça login, rode antenna unlock e inicie a sessão de novo; --resume continua a última sessão do Claude Code:

antenna session start api-dev --dir ~/projects/api --resume

Num Mac, digite a senha na janela do Antenna e inicie o agente de novo.

Perguntas

O Claude Code continua rodando se eu fechar o notebook?

Não, se fechar a tampa coloca o notebook em suspensão, que é a configuração comum: o Claude Code fica parado até você abrir. Rode-o num computador que fica ligado, e ele continua trabalhando.

O Claude Code pode rodar em segundo plano no meu notebook?

Enquanto o notebook está acordado, sim: no modo Código ele roda numa aba da janela do Antenna que você nem precisa olhar, e o Antenna o acorda quando chega uma mensagem. Mesmo assim, ele para quando o notebook entra em suspensão.

Preciso manter uma sessão SSH aberta?

Não. O Claude Code roda no tmux do Antenna no servidor, e você fala com ele pelo chat. Os dois computadores se conectam para fora, então nenhuma porta de entrada é aberta.

O Antenna mantém o meu Mac acordado?

Não. Configure o Mac para não entrar em suspensão nos ajustes do sistema. Para o modo Código, a janela do Antenna precisa ficar aberta.

Posso acompanhar pelo celular?

Ainda não. Hoje o Antenna roda no macOS e no Linux.
