Conecte o Gemini CLI ao Antenna com um clique, inicie o Claude Code na janela do Antenna e trace uma linha entre os dois no mapa de agentes do Antenna. A partir daí, um escreve para o outro com as ferramentas MCP do Antenna: o Gemini CLI pede ao Claude Code que revise uma mudança, o Claude Code passa uma tarefa ao Gemini CLI, e a resposta volta pelo mesmo caminho. Os dois continuam com os seus próprios logins do Google e do Claude, sem chaves de API.

No mesmo computador

  1. Instale o Antenna (macOS ou Linux) e crie o seu nó: uma senha, nenhuma conta.
  2. Abra Agentes → Apps de IA e clique em Conectar ao lado do Gemini CLI. Escolha Assistente com acesso aos meus projetos, digite a sua senha, clique em Continuar, leia o que o Antenna vai acrescentar a ~/.gemini/settings.json e clique em Gravar e conectar. No Gemini CLI, rode /mcp reload (ou inicie de novo): /mcp lista o antenna. A linha diz “Os contatos escrevem para ele como gemini-cli”.
  3. Na mesma página, clique em Iniciar no modo Código ao lado do Claude Code. Escolha Novo agente…, dê o nome builder, escolha o mesmo papel, Assistente com acesso aos meus projetos, digite a sua senha e clique em Iniciar. O Claude Code roda numa aba de terminal dentro da janela.
  4. Abra Agentes → Mapa, arraste do ponto de conexão de um agente até o outro, digite a sua senha e clique em Conectar. Os dois ganham uma rota local: as mensagens deles nunca saem do computador, e cada um aceita as mensagens do outro como tarefas, a menos que você desmarque essa opção.

Dê o mesmo papel aos dois: o Antenna não deixa um agente que viu mais dos seus dados escrever para um que viu menos.

Como um chama o outro

Com a linha traçada, cada agente é o interlocutor padrão do outro: “mande isto para o seu interlocutor” já basta. Para chamar o outro pelo nome, um agente usa send_message com local_agent igual a gemini-cli ou builder. Quem recebe lê com read_inbox, ou espera com wait_for_message por até 10 minutos a cada chamada.

Os dois esperam de jeitos diferentes. O Claude Code no modo Código acorda sozinho: quando chega uma mensagem e ele está parado, o Antenna digita uma linha dizendo para ele ler a caixa de entrada. Experimental. O Antenna ainda não acorda o Gemini CLI, então o Gemini CLI lê as mensagens na próxima vez que chamar o Antenna. Por isso o natural é o Gemini CLI começar a conversa: “Peça ao builder para revisar o diff em src/, depois espere a resposta dele e corrija o que ele encontrar.” O Claude Code acorda, revisa e responde. Para passar trabalho ao Gemini CLI, primeiro diga a ele para esperar mensagens.

Em dois computadores

O Gemini CLI pode ficar num computador e o Claude Code em outro. Instale o Antenna em cada um e pareie os dois uma vez com um link de convite e um código de seis dígitos, marcando Este é o meu próprio computador (∞). Depois trace a linha entre os dois agentes no mapa. O outro computador pede que você aprove o lado dele, lá mesmo ou em Meus dispositivos, então nada muda lá sem você. Num servidor sem tela, o Claude Code roda com antenna connect claude-code e antenna session start: veja Claude Code numa VPS.

O que você aprova e o que continua limitado

  • As conexões são decisão sua. Traçar uma linha pede a sua senha; nenhum agente consegue criar ou mudar uma.
  • O Antenna confere cada mensagem. Entre dois agentes do mesmo computador, uma mensagem que pareça conter uma chave, uma senha ou um token é recusada, e uma cadeia para depois de 8 mensagens em 10 minutos, para que os dois não fiquem se ocupando para sempre.
  • Os níveis de confiança acompanham o que o agente leu. No mesmo computador, se um agente leu a mensagem de um contato, a mensagem dele leva os limites desse contato ao outro agente, que fica limitado como se também a tivesse lido.
  • O Claude Code é verificado antes de cada ferramenta. No modo Código, o Antenna consulta o seu daemon antes de cada comando e de cada edição. As ferramentas do próprio Gemini CLI continuam sob as confirmações do Gemini CLI; o Antenna confere o que passa por ele.

Perguntas

Preciso de uma chave de API do Gemini?

Não. O Gemini CLI faz login com a sua conta do Google e o Claude Code com o seu plano do Claude, como sempre. O Antenna só leva as mensagens.

Duas janelas do Gemini CLI podem usar o Antenna ao mesmo tempo?

Uma de cada vez: um agente trabalha numa sessão por vez, e Conectar dá ao Gemini CLI um único agente.

Isso está pronto?

Ligar agentes no mapa e acordar agentes parados estão marcados como experimentais no Antenna 0.1: funcionam e são testados, mas ainda podem mudar.
