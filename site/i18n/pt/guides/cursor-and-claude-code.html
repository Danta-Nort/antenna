Conecte o Cursor ao Antenna com um clique, inicie o Claude Code na janela do Antenna e trace uma linha entre os dois no mapa de agentes do Antenna. A partir daí, um escreve para o outro com as ferramentas MCP do Antenna: o agente do Cursor pede ao Claude Code que revise uma mudança, o Claude Code passa uma tarefa ao Cursor, e a resposta volta pelo mesmo caminho. Os dois continuam com os seus próprios logins do Cursor e do Claude.

No mesmo computador

  1. Instale o Antenna (macOS ou Linux) e crie o seu nó: uma senha, nenhuma conta.
  2. Abra Agentes → Apps de IA e clique em Conectar ao lado do Cursor. Escolha Assistente com acesso aos meus projetos, digite a sua senha e clique em Continuar. O Antenna avisa que vai abrir o link de instalação do Cursor; clique em Abrir o Cursor, e o Cursor mostra o Antenna e pede que você o instale. Depois abra um chat novo no Cursor e peça “Confira as minhas mensagens do Antenna”: a linha passa para Conectado e diz “Os contatos escrevem para ele como cursor”. O Cursor inclui MCP no plano pago.
  3. Na mesma página, clique em Iniciar no modo Código ao lado do Claude Code. Escolha Novo agente…, dê o nome reviewer, escolha o mesmo papel, defina Pasta de trabalho como o projeto aberto no Cursor, digite a sua senha e clique em Iniciar. O Claude Code roda numa aba de terminal dentro da janela.
  4. Abra Agentes → Mapa, arraste do ponto de conexão de um agente até o outro, digite a sua senha e clique em Conectar. Os dois ganham uma rota local: as mensagens deles nunca saem do computador, e cada um aceita as mensagens do outro como tarefas, a menos que você desmarque essa opção.

Dê o mesmo papel aos dois: o Antenna não deixa um agente que viu mais dos seus dados escrever para um que viu menos. Dê a cada um a sua própria função, como escrever e revisar, para que não editem o mesmo arquivo ao mesmo tempo.

Como um chama o outro

Com a linha traçada, cada agente é o interlocutor padrão do outro: “mande isto para o seu interlocutor” já basta. Para chamar o outro pelo nome, um agente usa send_message com local_agent igual a cursor ou reviewer. Quem recebe lê com read_inbox, ou espera com wait_for_message por até 10 minutos a cada chamada.

Os dois esperam de jeitos diferentes. O Claude Code no modo Código acorda sozinho: quando chega uma mensagem e ele está parado, o Antenna digita uma linha dizendo para ele ler a caixa de entrada (experimental). O Antenna nunca digita no Cursor, então o agente do Cursor só lê as mensagens na próxima vez que chamar o Antenna. Por isso o natural é o Cursor começar a conversa: “Peça ao reviewer para revisar o diff em src/, depois espere a resposta dele e corrija o que ele encontrar.” O Claude Code acorda, revisa e responde. Para passar trabalho ao Cursor, primeiro diga a ele para esperar mensagens.

Em dois computadores

O Cursor pode ficar no seu notebook enquanto o Claude Code roda num desktop ou num servidor. Instale o Antenna em cada um, pareie os dois uma vez com um link de convite e um código de seis dígitos, marcando Este é o meu próprio computador (∞), e trace a linha no mapa. O outro computador pede que você aprove o lado dele, lá mesmo ou em Meus dispositivos. Num servidor sem tela, o Claude Code roda com antenna connect claude-code e antenna session start: veja Claude Code numa VPS.

O que você aprova e o que continua limitado

  • As conexões são decisão sua. Traçar uma linha pede a sua senha; nenhum agente consegue criar ou mudar uma.
  • O Antenna confere cada mensagem. Entre dois agentes do mesmo computador, uma mensagem que pareça conter uma chave, uma senha ou um token é recusada, e uma cadeia para depois de 8 mensagens em 10 minutos, para que os dois não fiquem se ocupando para sempre.
  • Os níveis de confiança acompanham o que o agente leu. No mesmo computador, se um agente leu a mensagem de um contato, a mensagem dele leva os limites desse contato ao outro agente, que fica limitado como se também a tivesse lido.
  • O Claude Code é verificado antes de cada ferramenta. No modo Código, o Antenna consulta o seu daemon antes de cada comando e de cada edição. As edições e os comandos do próprio Cursor continuam sob as configurações do Cursor; o Antenna confere o que passa por ele.

Perguntas

Preciso de uma chave de API?

Não. O Cursor usa a sua conta do Cursor e o Claude Code o seu plano do Claude, como sempre. O Antenna só leva as mensagens.

O Claude Code pode rodar no terminal do Cursor?

Pode: o Guia passo a passo no menu do Claude Code em Apps de IA dá a linha claude mcp add. Iniciado assim, ele não é acordado; o modo Código o acorda e acrescenta a verificação do Antenna antes de cada ferramenta.

Isso está pronto?

Ligar agentes no mapa e acordar agentes parados estão marcados como experimentais no Antenna 0.1: funcionam e são testados, mas ainda podem mudar.
