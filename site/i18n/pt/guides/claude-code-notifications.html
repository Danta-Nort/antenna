Passe a tarefa ao Claude Code num chat do Antenna, a partir do seu notebook, e ele manda o resultado de volta para esse chat quando terminar: as instruções do Antenna dizem a um agente conectado que envie os resultados ao contato que deu a tarefa. O notebook então mostra uma notificação, “Nova mensagem em server · api-dev”, enquanto a janela do Antenna não está em primeiro plano. Pedidos de aprovação também geram notificação, então uma execução que para no meio do caminho não fica esperando sem você perceber. O Antenna não acompanha sozinho os turnos do Claude Code: o relatório é uma mensagem do próprio Claude Code.

O que gera notificação

  • Uma mensagem do Claude Code para você. A notificação mostra o nome do chat, nunca o texto, no máximo uma vez a cada 10 segundos por chat.
  • Um pedido de aprovação. Um passo que precisa do seu aval aparece como “Antenna: aprovação necessária em server”, com o agente, o que ele quer fazer e o tempo que resta (“Expira em 9 min”), mas nunca com o texto do pedido. Uma segunda notificação chega uns dois minutos antes de o pedido se fechar; ele se fecha depois de 10 minutos. Pedidos de outro computador chegam a você por Meus dispositivos (experimental).
  • Uma pergunta. Experimental. A pergunta de um agente gera notificação no computador onde ele roda: “Uma pergunta do seu agente”. Num servidor, rode lá antenna agent escalate api-dev --to mac, e as perguntas dele passam a chegar no chat do agente, no seu notebook.

As notificações funcionam no macOS e nos desktops Linux que mostram notificações. O Antenna precisa estar aberto no notebook; com a janela dele em primeiro plano, os contadores de não lidas da lista de chats fazem esse papel.

Como configurar

  1. Instale o Antenna nos dois computadores e pareie-os uma vez com Este é o meu próprio computador (∞) marcado. Claude Code numa VPS mostra o lado do servidor passo a passo.
  2. Inicie o Claude Code pelo Antenna. Num servidor: 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
    Num segundo desktop: Agentes → Apps de IA → Iniciar no modo Código.
  3. Não há nada para configurar no notebook. Desde o início, um chat com um agente notifica as mensagens dirigidas a você pessoalmente e os pedidos de aprovação.

Peça o relatório

Escreva a tarefa no chat api-dev e diga o que você quer de volta: “Rode os testes da migração e corrija o que falhar. Quando terminar, responda aqui com o que mudou.” Se o Claude Code estiver parado no prompt, o Antenna digita uma linha para que ele leia a sua mensagem (experimental); ele trabalha, depois responde no mesmo chat, e o notebook mostra a notificação.

Para o trabalho que você começa no terminal dele (antenna session attach api-dev), termine o prompt com “me mande um resumo pelo Antenna quando terminar”. Para virar hábito, acrescente uma linha ao CLAUDE.md do projeto: “Quando terminar uma tarefa, mande um resumo curto para mac com o send_message do Antenna.”

O relatório chega quando o Claude Code decide que terminou, como acontece com qualquer instrução que ele segue. Se ele parar no próprio aviso de permissão no terminal (“Do you want to proceed?”), o Antenna não vê isso, e nenhuma notificação chega: libere nas configurações do Claude Code as ferramentas que você usa no dia a dia.

Escolha quais chats notificam

Abra ⋮ na linha de um chat, ou clique nela com o botão direito, e depois Notificações:

  • Todas as mensagens: cada mensagem nova deste chat (o padrão para uma pessoa).
  • Só quando precisar de mim: mensagens dirigidas a você pessoalmente e pedidos de aprovação (o padrão para um agente).
  • Desligado: os pedidos de aprovação continuam notificando.

Quando o Claude Code se reporta a outro dos seus agentes em vez de a você, essas mensagens ficam em silêncio, a menos que você ligue Notificar mensagens entre agentes no mesmo menu. Num terminal: antenna chats notify server --agent api-dev all.

No computador em que você está

Com o Claude Code no modo Código no seu próprio notebook, o Antenna notifica os pedidos de aprovação e as perguntas dele enquanto a janela está em segundo plano, mas não o fim de um turno: um agente não consegue mandar mensagem para você no próprio computador dele. Para isso, os hooks do próprio Claude Code podem rodar um comando seu quando ele para.

Perguntas

A notificação mostra o que o Claude Code escreveu?

Não. Ela diz só “Nova mensagem em” e o nome do chat, porque uma notificação pode aparecer com a tela bloqueada. Abra o chat para ler o relatório.

E se o notebook estiver em repouso?

A mensagem espera no servidor, e o Antenna a entrega, com a notificação, quando o notebook volta a ficar online.

Posso receber a notificação no celular?

Ainda não. Hoje o Antenna roda no macOS e no Linux.
