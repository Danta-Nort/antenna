Inicie o Claude Code pelo Antenna, no modo Código da janela ou com antenna session num servidor, e o daemon do Antenna confere cada ferramenta que ele usa e cada mensagem que ele envia. Quando um passo precisa de você, ele vira um pedido de aprovação que aparece, com uma notificação, em cada computador que você pareou como seu, em Meus dispositivos. Aprove ali com a senha daquele computador ou com Touch ID: o computador onde o Claude Code roda confere a sua resposta, executa o passo e o Claude Code segue em frente.

O que chega até você

  • Passos depois de ler a mensagem de um contato. Depois que o Claude Code leu uma mensagem de um colega, o nível de confiança desse colega define o que ele pode fazer: no nível 4, cada comando espera por você; nos níveis 2 e 3, cada edição espera, e os comandos são recusados.
  • Mudanças na própria configuração. Depois de ler a mensagem de qualquer contato, mesmo do seu próprio notebook, edições em CLAUDE.md, .claude/, perfis do shell, chaves e arquivos de build como package.json esperam por você.
  • Mensagens que levariam os seus dados para fora. Depois que ele leu arquivos do seu projeto, cada mensagem para um contato abaixo de ∞ espera, assim como qualquer mensagem para um contato desses que pareça conter uma chave, uma senha ou um token. Depois que ele leu uma conversa, uma mensagem para outra conversa também espera.
  • Perguntas. Experimental. As perguntas de um agente aparecem no computador onde ele roda, em Perguntas dos seus agentes. Para recebê-las no notebook, rode antenna agent escalate api-dev --to mac naquele computador: a partir daí, cada pergunta chega no chat do agente, e você responde no chat.

O próprio aviso de permissão do Claude Code (“Do you want to proceed?”) fica no terminal dele: o Antenna nunca digita nele. Libere nas configurações do Claude Code as ferramentas que você usa no dia a dia, ou responda com antenna session attach.

Como configurar

  1. Instale o Antenna nos dois computadores e pareie-os uma vez com Este é o meu próprio computador (∞) marcado, como em Claude Code numa VPS.
  2. Inicie o Claude Code pelo Antenna. Num desktop: Agentes → Apps de IA → Iniciar no modo Código. Num servidor: 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
  3. No computador onde o Claude Code roda, aceite as respostas do computador de onde você vai aprovar: Meus dispositivos → o cartão desse computador → Aprovações → Aceitar aprovações assinadas com …, com a sua senha. Num servidor: antenna devices confirm mac.

Responda de qualquer computador

O pedido aparece no cartão do computador que pergunta, em Meus dispositivos (experimental), com uma notificação como “Antenna: aprovação necessária em Mac mini”. O cartão diz qual agente pede, o quê e por quê, e cita o texto dele, exceto um texto com um segredo, que nunca sai do computador que perguntou. Clique em Aprovar com Touch ID num Mac (experimental), em Aprovar com senha com a senha do computador em que você está, ou em Recusar.

O computador que perguntou confere a assinatura com as chaves que você aceitou nele, com o seu próprio desafio de uso único e com exatamente este pedido, e então executa o pedido ele mesmo, uma única vez. No próprio computador, o pedido fica em Pedidos de aprovação, ou num terminal com antenna approvals e antenna approve <id>.

O Claude Code espera até 50 segundos, e um passo aprovado nesse prazo roda na hora. Depois disso, ele segue com outro trabalho; quando você aprova, o Antenna digita “Approved — continue.” no prompt dele e ele roda o passo de novo.

Se ninguém responder

Um pedido se fecha depois de 10 minutos: nada roda, nada é enviado, e o Claude Code fica sabendo que ninguém aprovou. Uma notificação avisa você pouco antes. Depois de Recusar, que não pede senha, o Claude Code fica sabendo que você disse não.

Um agente que aprova por você

Experimental. Pode aprovar por… em Agentes deixa um agente de sua confiança responder aos pedidos dos seus outros agentes sobre mensagens e arquivos, e a resposta dele só vale quando tudo o que o pedido envolve está em ∞. Comandos e edições sempre chegam a você.

Perguntas

Funciona com o Codex?

Em parte. O que o Codex envia pelo Antenna é conferido do mesmo jeito, e esses pedidos chegam a todos os seus computadores; os comandos do próprio Codex continuam com as aprovações do Codex, no terminal dele.

Qualquer computador pode aprovar?

Não. Só um computador que você pareou como seu e cujas chaves você aceitou, com a senha, no computador que pergunta. Se perder um, use Revogar este computador em cada um dos outros.

Posso aprovar pelo celular?

Ainda não. Hoje o Antenna roda no macOS e no Linux.
