Instale o Antenna no seu notebook e no computador onde o Claude Code roda, pareie os dois uma vez como computadores seus e inicie o Claude Code lá pelo Antenna. Um chat com essa sessão aparece no seu notebook: escreva uma tarefa nele, o Antenna acorda o Claude Code quando ele está parado, e a resposta volta para o chat. As mensagens passam por uma conexão peer-to-peer com criptografia de ponta a ponta entre os seus dois computadores, o Antenna não precisa de conta, e os passos que precisam da sua aprovação chegam ao notebook, onde você responde com a sua senha.

O Remote Control do próprio Claude Code, e o Antenna

O Claude Code tem um recurso Remote Control próprio, embutido; a documentação da Anthropic descreve como ele funciona. Este guia trata de outra configuração: o Claude Code roda num computador seu que fica ligado, um servidor ou um desktop, e você o comanda pelo Antenna no seu notebook. Ela serve para você se quiser:

  • Várias sessões em vários computadores numa só lista. Cada sessão é um chat próprio, e Meus dispositivos mostra o estado de cada computador, os agentes dele e os pedidos que esperam lá.
  • A sua própria conexão. As mensagens são criptografadas num computador e descriptografadas no outro. Os seus computadores se conectam diretamente quando a rede permite; senão, por um relay que só repassa tráfego criptografado. Sem conta e sem porta de entrada.
  • Permissões conferidas pelo daemon do Antenna no computador onde o Claude Code roda, com aprovações respondidas do computador seu em que você estiver.
  • Outros agentes do mesmo jeito: o Codex funciona como o Claude Code.

Como configurar

  1. Instale o Antenna nos dois computadores: o app no seu notebook (macOS ou Linux) e, no outro computador, o app ou, num servidor Linux, o nó: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
  2. Pareie os dois uma vez. No notebook: Novo contato → Convidar, marque Este é o meu próprio computador (∞), clique em Criar link e copie o link. Num servidor: antenna join '<link>' --trust 5 --label mac; num desktop: Novo contato → Entrar, com a mesma opção marcada. Digite em um lado o código que o outro mostra e clique em O contato confirmou — os códigos conferem no notebook.
  3. Inicie o Claude Code pelo Antenna no outro computador. Num servidor, na pasta do projeto (é preciso ter tmux): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Responda às primeiras perguntas do Claude Code e saia com Ctrl-b d: ele continua rodando, e um chat chamado api-dev aparece no seu notebook. Num desktop: Agentes → Apps de IA → Iniciar no modo Código, e o Claude Code roda numa aba da janela do Antenna lá; peça uma vez que ele dê um oi ao seu notebook pelo Antenna, e o chat dele aparece no notebook.
  4. Deixe o notebook responder aos pedidos de aprovação daquele computador. Num servidor: antenna devices confirm mac. Num desktop: Meus dispositivos → o cartão do notebook → Aprovações → Aceitar aprovações assinadas com …, com a sua senha.

Comande do seu notebook

  • Mande uma tarefa. Escreva no chat da sessão como escreveria para uma pessoa. Quando o Claude Code está parado no prompt, o Antenna digita uma linha fixa para ele ler a sua mensagem; ele nunca digita o seu texto no terminal e nunca responde a uma pergunta que o Claude Code faça lá. Experimental.
  • Interrompa. Ative Urgente: interromper agora antes de enviar: o Antenna aperta Esc uma vez para encerrar o turno em andamento, nunca por cima de uma pergunta ou de um aviso de permissão aberto lá, e o Claude Code lê a sua mensagem. Experimental.
  • Aprove os passos dele. Um passo que precisa de você aparece no cartão do outro computador em Meus dispositivos, com uma notificação. Clique em Aprovar com senha, em Aprovar com Touch ID num Mac, ou em Recusar. Experimental.
  • Pare. Parar o agente e os processos dele…, ao lado do agente nesse cartão, encerra o Claude Code e tudo o que ele iniciou lá. Experimental.

O próprio aviso de permissão do Claude Code (“Do you want to proceed?”) fica no terminal dele, no outro computador, e o Antenna nunca o responde. Libere nas configurações do Claude Code as ferramentas que você usa no dia a dia, ou responda com antenna session attach.

Codex e outros agentes

O Codex funciona do mesmo jeito: antenna connect codex e --cli codex num servidor, ou Iniciar no modo Código ao lado do Codex num desktop (veja Controle remoto do Codex CLI). O Gemini CLI se conecta em Agentes → Apps de IA e envia e lê mensagens pelo Antenna, mas o Antenna ainda não o acorda: ele lê uma mensagem nova na próxima vez que chamar o Antenna.

Perguntas

Eu vejo o terminal do Claude Code no notebook?

Não. Você passa tarefas e lê as respostas num chat; o terminal fica no outro computador. Para olhar, rode antenna session attach lá, por SSH se quiser.

O outro computador precisa de IP público ou de portas abertas?

Não. Os dois computadores se conectam para fora, diretamente quando a rede permite e, senão, por um relay. O relay só repassa tráfego criptografado.

Quem mais pode mandar tarefas para ele?

Só os contatos pareados com aquele computador cujas mensagens o agente pode ler (com --links mac, só o seu notebook) e os agentes que você liga a ele no mapa de agentes. Quem decide o que a mensagem de um contato pode levá-lo a fazer é o daemon do Antenna lá, não o Claude Code, pelo nível de confiança desse contato.

Precisa de chave de API?

Não. O Claude Code mantém o seu próprio login no computador onde roda, e o Antenna só transporta mensagens, arquivos e aprovações.

Posso controlar pelo celular?

Ainda não. Hoje o Antenna roda no macOS e no Linux.
