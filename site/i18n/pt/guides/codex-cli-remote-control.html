Instale o Antenna nos dois computadores e pareie-os uma vez como seus. No computador onde o Codex roda, dê um nome à sessão do Codex com antenna connect codex e inicie-a com antenna session start … --cli codex. Um chat com esse nome aparece no seu notebook: escreva uma tarefa ali, e o Antenna acorda o Codex quando ele estiver parado. O Codex lê a sua mensagem, trabalha no outro computador e responde no chat. Nenhuma sessão SSH fica aberta e não há porta de entrada para abrir.

O que você precisa

  • O Codex CLI instalado e com login feito no computador que faz o trabalho: um servidor Linux x86_64 ou um desktop Mac ou Linux. O Codex continua usando a sua própria assinatura; o Antenna não precisa de chave de API.
  • tmux nesse computador. Num servidor, rode também sudo loginctl enable-linger $USER uma vez, para que o Antenna e a sessão continuem rodando depois que você sair.
  • O Antenna nos dois computadores: o app num desktop, o nó num servidor (curl -fsSL https://antenna.contact/install.sh | sh).

1. Pareie os dois computadores

No notebook: New contact → Invite, marque This is my own computer (∞) (este é o meu próprio computador), crie o link e abra-o no outro computador (num servidor, antenna join '<link>' --trust 5 --label mac). Digite em um lado o código que o outro mostra. Agora os dois lados tratam um ao outro como computadores seus. A versão passo a passo com capturas de tela está em Claude Code numa VPS; para o Codex é igual.

2. Dê um nome à sessão do Codex

No computador onde o Codex roda, na pasta do projeto:

cd ~/projects/api
antenna connect codex --agent api-codex --links mac --hello mac

Isso cria o agente api-codex com o seu próprio arquivo de token, liga-o ao seu notebook (mac é o nome que este computador deu ao seu notebook no pareamento) e manda um oi, para que um chat chamado api-codex apareça no notebook na hora. As suas configurações do Codex não mudam: o Antenna é adicionado só para as sessões deste agente.

3. Inicie o Codex pelo Antenna

antenna session start api-codex --dir ~/projects/api --cli codex
antenna session attach api-codex

O Codex inicia no servidor tmux do próprio Antenna; o seu tmux não é tocado. Conecte-se uma vez para responder às primeiras perguntas do Codex. Na primeira vez, o Codex pede que você confie nos hooks do Antenna (“Hooks need review”): escolha “Trust all and continue”. Depois saia com Ctrl-b d, e o Codex continua rodando. --resume retoma a última sessão do agente depois de um reinício.

4. Escreva para ele do seu notebook

Abra o chat api-codex e escreva: “Rode os testes, corrija o que falhar e me diga o que você mudou.” Quando o Codex está parado no prompt, o Antenna digita uma linha fixa mandando ele ler a caixa de entrada. Ele nunca digita o seu texto no terminal e nunca digita por cima de uma pergunta que o Codex esteja fazendo. O Codex lê a mensagem pelo Antenna, trabalha e responde no chat. Experimental.

Precisa que ele pare o que está fazendo? Ative Urgent: interrupt now (urgente: interromper agora) antes de enviar. O Antenna aperta Esc uma vez para encerrar o turno em andamento e depois acorda o Codex para a sua mensagem. Para parar o agente e tudo o que ele iniciou, abra o cartão do outro computador em My devices no notebook e clique em Stop agent and its processes… ao lado de api-codex.

Num desktop: Code mode

Se o Codex roda num desktop Mac ou Linux com o app do Antenna, você pode pular os passos do terminal. No Code mode, clique em + no painel de agentes, escolha o Codex e a pasta de trabalho, e o Codex roda numa aba dentro da janela, acordado do mesmo jeito. O chat dele pode ser acessado dos seus outros computadores como o de qualquer outro agente.

Perguntas

Isso me mostra o terminal do Codex no notebook?

Não. Você passa tarefas ao Codex e lê as respostas num chat; o terminal fica no outro computador. Para acompanhar, rode antenna session attach lá, por SSH se quiser.

Quais versões do Codex funcionam?

O Codex 0.160 e posteriores informam o que fazem por meio de hooks, e é assim que o Antenna sabe quando o Codex está parado. Com um Codex mais antigo, ou sem confiar nos hooks, o Antenna espera até o Codex mostrar a linha de entrada vazia depois de um turno, e nunca digita enquanto um turno está em andamento.

O Codex também pode conversar com o Claude Code?

Sim. Ligue os dois agentes no mapa de agentes, e as mensagens de cada um vão para o outro sem precisar indicar o nome: veja Claude Code e Codex conversando entre si.

Posso controlar pelo celular?

Ainda não. Hoje o Antenna roda no macOS e no Linux.
