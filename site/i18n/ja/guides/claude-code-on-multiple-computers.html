Claude Code は作業のある場所、つまりノート PC、デスクトップ、サーバーで動かし、それぞれに Antenna をインストールします。コンピューター同士を一度だけ自分のもの（∞）としてペアリングすれば、どのコンピューターからでも、すべてのセッションを 1 つのチャット一覧で確認し、名前を指定してどれにでもメッセージを送り、承認リクエストに答え、暴走したセッションを止められます。そのマシンでターミナルを開く必要はありません。Codex も同じように使えます。

できること

  • セッションごとに 1 つのチャット。どのコンピューターで動いていても同じです。サーバーのセッションもデスクトップのセッションも、連絡先と同じ一覧に並びます。
  • My devices（自分のデバイス）：コンピューターごとのカードに、OS と Antenna のバージョン、そのマシン自身のチェックによる健全性、エージェントとそれぞれの接続状態、そこであなたを待っているリクエストが表示されます。
  • 今いる場所から承認。サーバー上のエージェントからのリクエストを、Mac で Touch ID や Mac のパスワードを使って承認できます。サーバーは署名を確認し、リクエストを自分で実行します。
  • 停止ボタン。ほかのコンピューター上のエージェントごとにあり、エージェントとそれがそこで起動したすべてのプロセスを止めます。
  • エージェントマップ。あるコンピューターのセッションを別のコンピューターのセッションとつなぎ、互いにメッセージを送り合えるようにします。

セットアップ

  1. 各コンピューターに Antenna をインストールします。Mac や Linux のデスクトップにはアプリを、Linux サーバーにはノードを入れます（curl -fsSL https://antenna.contact/install.sh | sh）。
  2. コンピューター同士を自分のものとしてペアリングします。This is my own computer (∞) にチェックを入れて招待を作り、もう一方のコンピューターで開いて、片方に表示されたコードをもう片方に入力します。互いに見たり接続したりしたいすべてのコンピューターの組み合わせでペアリングしてください。どちらの側も、相手を ∞ にしておく必要があります。
  3. 各 Claude Code セッションに名前を付けます。デスクトップでは、エージェントパネルの + から Code モードで起動します。サーバーでは、プロジェクトフォルダーで antenna connect claude-code --agent api-dev --links mac --hello mac を実行し、antenna session start api-dev --dir ~/projects/api で動かし続けます。すべての手順は VPS で Claude Code を動かすにあります。
  4. メインのコンピューターがリクエストに答えられるようにします。サーバーでは antenna devices confirm mac を一度実行します。デスクトップでは、My devices → そのカード → Approvals で、メインのコンピューターの鍵を受け入れます。

コンピューター間で作業を受け渡す

人に話しかけるように、セッションにメッセージを送ります：「api-dev、サーバーでマイグレーションを実行して、何が変わったか教えて」。チャットにドロップしたファイルはそのコンピューターに保存され、エージェントには保存場所が伝えられます。自分のコンピューター同士なら普通のファイルは確認なしに保存されますが、プログラムやインストーラーはあなたの確認を待ちます。デスクトップのセッションからサーバーのセッションに作業を渡せるようにするには、エージェントマップで 2 つをつなぎます。サーバー側のセッションはメッセージが届くと起こされ、緊急のメッセージなら実行中のターンを中断させることもできます。実験的機能です。

よくある質問

Antenna は Claude Code の設定や履歴をコンピューター間で同期しますか？

いいえ。Claude Code は設定、履歴、サインインを各コンピューターに保持し、コードはこれまでどおり git で移動します。Antenna がセッション間で運ぶのは、メッセージ、ファイル、承認です。

サーバーにグローバル IP やポート開放は必要ですか？

いいえ。どのコンピューターも外向きに接続します。ネットワークが許せば直接、そうでなければリレーを経由し、リレーは暗号化された通信を転送するだけです。

ここからほかのコンピューターの設定を変えられますか？

いいえ。コンピューター間でやり取りされるのは、承認、停止、そしてエージェントマップからの接続リクエスト（相手のコンピューターであなたの承認を求められます）だけです。信頼レベル、招待、アップデート、設定はそのコンピューター自身で変更するので、ノート PC を盗まれてもサーバーのルールを書き換えられることはありません。

Windows やスマートフォンで使えますか？

まだ使えません。現在、Antenna は macOS と Linux で動きます。
