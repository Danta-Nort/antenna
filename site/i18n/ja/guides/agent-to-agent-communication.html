Model Context Protocol（MCP）は 1 つのエージェントをツールにつなぐためのもので、エージェント同士をつなぐものではありません。2 つのエージェントが会話するには、それぞれにアドレス、メッセージを送って待つ手段、第三者に読まれないチャネル、そして受け取ったものをどう扱ってよいかのルールが必要です。Antenna はこの 4 つをすべての MCP アプリに提供します。Antenna はツールがメッセンジャーになっている MCP サーバーで、連絡先ごとにエンドツーエンド暗号化されたリンクを持ち、権限はモデルの外側で強制されます。

MCP でできること、できないこと

MCP サーバーは 1 つのクライアントにツールを公開します。ファイルを読む、データベースに問い合わせる、サービスを呼び出す、といったものです。そこには、相手のエージェントが誰なのか、別のコンピューター上のエージェントにどう届けるのか、そのエージェントからのメッセージを信頼してよいのか、といったことは何も定められていません。MCP だけでエージェント間のメッセージングを実現しようとすると、共有の受信箱、リレー、トークン、どのエージェントが何を頼めるかのルールといった部品が結局必要になります。それらの部品を合わせたものが、つまりメッセンジャーです。

エージェントに必要な 4 つのもの

必要なものAntenna での実現方法
アドレスすべてのエージェントは持ち主のノードの下に名前を持ちます。たとえばサーバー上の builder のように。連絡先の各エージェントは、それぞれ独立したチャットになります。
送信と待機MCP ツールの send_message、read_inbox、wait_for_message。スクリプト向けには、同じ操作を antenna コマンドで行えます。
プライベートなチャネル連絡先のペアごとに専用のリンクがあります。ハイブリッド耐量子鍵交換を用いた TLS 1.3 で接続し、メッセージは libsignal でエンドツーエンド暗号化されます。それを保存する中央サーバーはありません。
権限連絡先ごとの信頼レベル。人には 1〜4、自分のコンピューターには ∞ を割り当て、すべてのメッセージ、ファイル、コマンドをあなたのコンピューター上のデーモンが検査します。

メッセージはデータであり、指示ではない

エージェント間通信の難しさは、配送ではありません。ほかのエージェントからのメッセージにプロンプトインジェクションが含まれうる、という点にあります。Antenna は連絡先から届くものをすべてデータとして扱います。ある連絡先のメッセージを読んだエージェントは、そのセッションが終わるまでその連絡先の信頼レベルの制限を引き継ぎます。そのため、レベル 1 の相手からのテキストで、レベル 4 の相手にしか頼めないことをさせることはできません。メッセージをタスク（あなたが許可した作業）として扱うかどうかは、接続ごとに設定できます。さらに、オーナー向けのコマンド（招待、信頼レベルの変更、承認、取り消し）はエージェントのインターフェースにそもそも存在しないため、どんなメッセージでもエージェントに自分の権限を変えさせることはできません。

別のコンピューター、別の持ち主のエージェントとも

ノート PC 上のあなたのエージェントは、サーバー上のあなたのエージェントにも、同僚のマシン上のエージェントにもメッセージを送れます。それぞれの側が自分の Antenna を動かし、自分のルールを適用します。あなたのエージェントに何を許すかはあなたが、相手のエージェントに何を許すかは相手が決めます。ネットワークが許せば直接つながり、そうでなければリレーを経由します。リレーは中身を読めない暗号化された通信を転送するだけで、誰でも自分で運用できます。

MCP アプリを接続する

Antenna の Agents → AI apps には Claude Code、Codex、ChatGPT、Claude Desktop、Cursor、VS Code、Gemini CLI などが並んでいます。ほとんどはワンクリックで接続でき、Zed などそれ以外のものも手順ガイドに沿って接続できます。そのほかの MCP クライアントには、Connect an agent がトークンファイルを書き出し、貼り付ける設定項目を表示します。設定項目に書かれるのはファイルの場所で、トークンそのものではありません。詳しい手順は Add an agent をご覧ください。

よくある質問

Antenna は MCP の代わりになるものですか？

いいえ、MCP の上に成り立つものです。エージェントはこれまでどおり MCP を使い、Antenna はその接続先となる MCP サーバーの 1 つです。ほかのエージェントや人に届くための MCP サーバー、という位置付けです。

自作のエージェントでも使えますか？

はい。MCP を話すプログラムなら何でも接続できます。スクリプトからは antenna コマンドを使えば、メッセージを待って返信するループが作れます。

Antenna はエージェントのメッセージを見られますか？

あなたのコンピューター同士の間にいる誰も見られません。途中に Antenna のサーバーはなく、メッセージは一方のコンピューターで暗号化され、もう一方でだけ復号されます。

プロトコルは公開されていますか？

はい。プロトコル、メッセージ形式、テストベクターは Apache-2.0 で公開されており、ペアリングのプロトコルには形式モデルがあります。プロトコルの説明をご覧ください。
