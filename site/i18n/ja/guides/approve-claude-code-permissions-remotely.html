Claude Code を Antenna 経由で起動すると（ウィンドウの Code モード、またはサーバーなら antenna session）、Antenna のデーモンが、Claude Code の使うすべてのツールと送るすべてのメッセージを確認します。あなたの判断が必要な手順は承認リクエストになり、自分のコンピューターとしてペアリングしたすべてのマシンの My devices（自分のデバイス）に、通知付きで表示されます。そこで、そのコンピューターのパスワードか Touch ID で承認すると、Claude Code が動いているコンピューターがあなたの返答を検証して手順を実行し、Claude Code は作業を続けます。

あなたに届くもの

  • 連絡先のメッセージを読んだ後の操作。Claude Code がチームメイトのメッセージを読むと、その相手の信頼レベルで何をしてよいかが決まります。レベル 4 ではコマンドが 1 つずつあなたの承認待ちになり、レベル 2 と 3 では編集が 1 つずつ承認待ちになり、コマンドは拒否されます。
  • 自分自身の設定の変更。どの連絡先のメッセージでも、たとえ自分のノート PC からのものでも、読んだ後は、CLAUDE.md、.claude/、シェルのプロファイル、鍵、package.json のようなビルドファイルへの編集があなたの承認待ちになります。
  • あなたのデータを外へ持ち出しかねないメッセージ。プロジェクトのファイルを読んだ後は、∞ より下の連絡先へのメッセージがすべて承認待ちになり、そうした連絡先に宛てた、鍵やパスワード、トークンを含んでいそうなメッセージも同じです。ある会話を読んだ後は、別の会話へのメッセージも承認待ちになります。
  • 質問。実験的機能です。エージェントの質問は、それが動いているコンピューターの Questions from your agents（エージェントからの質問）に表示されます。ノート PC で受け取りたい場合は、そのコンピューターで antenna agent escalate api-dev --to mac を実行します。以後、質問はそのエージェントのチャットに届き、チャットで答えます。

Claude Code 自身の権限確認（「Do you want to proceed?」）は、そのターミナルに残ります。Antenna がそこに何かを入力することはありません。いつも使うツールは Claude Code の設定で許可しておくか、antenna session attach で入って答えてください。

セットアップ

  1. 両方のコンピューターに Antenna をインストールし、This is my own computer (∞) にチェックを入れて一度だけペアリングします。手順は VPS で Claude Code を動かすと同じです。
  2. Antenna 経由で Claude Code を起動します。デスクトップでは Agents → AI apps → Start in Code mode、サーバーでは次のとおりです。 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
  3. Claude Code が動くコンピューターで、承認に使うコンピューターからの返答を受け入れます。My devices → そのコンピューターのカード → Approvals → Accept approvals signed with … を開き、パスワードを入力します。サーバーでは antenna devices confirm mac です。

どのコンピューターからでも答える

リクエストは、My devices にある依頼元のコンピューターのカードに表示され（実験的機能）、「Antenna: approval needed on Mac mini」のような通知が届きます。カードには、どのエージェントが、何のために、なぜ求めているかが書かれ、その文面も引用されます。ただし秘密情報を含む文面は、依頼元のコンピューターから出ることはありません。Mac では Approve with Touch ID（実験的機能）、いま使っているコンピューターのパスワードで Approve with password、または Deny を押します。

依頼元のコンピューターは、そこで受け入れた鍵、自分が出した使い捨てのチャレンジ、そしてこのリクエストそのものと照らして署名を検証し、リクエストを自分で一度だけ実行します。依頼元のコンピューター上では、リクエストは Approval requests（承認リクエスト）にあり、ターミナルでは antenna approvals と antenna approve <id> で扱えます。

Claude Code は最大 50 秒待ち、それまでに承認された手順はすぐに実行されます。それを過ぎると、ほかの作業に移ります。あとで承認すると、Antenna がプロンプトに「Approved — continue.」と入力し、Claude Code がその手順をもう一度実行します。

誰も答えなかったら

リクエストは 10 分で閉じられます。何も実行されず、何も送られず、Claude Code には誰も承認しなかったことが伝わります。閉じる少し前に通知でお知らせします。Deny にはパスワードが要らず、押すと Claude Code にはあなたが断ったことが伝わります。

代わりに承認するエージェント

実験的機能です。Can approve for…（代わりに承認できる相手）を Agents で設定すると、信頼するエージェントが、ほかのエージェントのメッセージやファイルに関するリクエストに答えられます。その答えが有効なのは、リクエストに関わるものがすべて ∞ のときだけです。コマンドと編集は必ずあなたに届きます。

よくある質問

Codex でも使えますか？

一部は使えます。Codex が Antenna を通して送るものは同じように確認され、そのリクエストはすべてのコンピューターに届きます。Codex 自身のコマンドは、これまでどおりターミナルでの Codex の承認に任されます。

どのコンピューターでも承認できますか？

いいえ。自分のコンピューターとしてペアリングし、依頼元のコンピューターでその鍵を受け入れたコンピューターだけが、パスワードを使って承認できます。紛失したコンピューターは、ほかの各コンピューターで Revoke this computer（このコンピューターを取り消す）を押してください。

スマートフォンから承認できますか？

まだできません。現在、Antenna は macOS と Linux で動作します。
