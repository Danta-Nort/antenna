あなたとチームメイトがそれぞれ Antenna をインストールし、招待リンクと、通話で読み合わせるコードで一度だけペアリングします。あなたの Claude Code には名前が付き、チームメイトのエージェントはその名前で書き込みます。チームメイトの信頼レベルはあなたが選び、モデルではなく、あなたのコンピューター上の Antenna のデーモンがそれをエージェントに守らせます。何を読み、編集し、実行してよいか、どの返信があなたの確認を待つか、です。チームメイトの側でも同じです。

セットアップ

  1. 両方のコンピューターに Antenna をインストール（macOS または Linux）します。それぞれパスワードが 1 つだけで、アカウントは要りません。
  2. どちらか一方が 新しい連絡先 → 招待 を押し、相手のレベルを選んでリンクを送ります。もう一方はそのリンクを開くか、新しい連絡先 → 参加 を使います。6 桁の数字か 6 匹の動物のコードが表示されるので、通話で読み上げ、相手がそれを入力します。お互いに相手のレベルを選びます。
  3. エージェント → AI アプリ → Code モードで起動 から Claude Code を起動します。新しいエージェント… を選び、backend-claude のようにチームメイトが使う名前を付けて、連絡先にチームメイトを含めます。チームメイトも同じようにして自分のエージェントを接続します。

チームメイトのレベルを選ぶ

チームメイトのエージェントには、チームメイトと同じレベルが適用されます。あなたのエージェントは、相手のメッセージを一度読むと、そのセッションが終わるまでそのレベルの制限を受け、Code モードの Claude Code が使うすべてのツールを Antenna がその制限に照らして確認します。

レベル相手のメッセージを読んだ後のあなたのエージェントファイル
1 · オブザーバー文章で答えるだけなし
2 · 知人読み取りと編集はすべてあなたの承認待ち。コマンドは実行不可隔離フォルダー inbox/ に受信
3 · 同僚読み取りは可能。編集はあなたの承認待ち。コマンドは実行不可読み取り専用の shared/
4 · パートナーチームメイト用のフォルダー内で読み取りと編集が可能。それ以外の編集とすべてのコマンドはあなたの承認待ち読み書きできる shared/

レベル 1 と 2 では、通信はリレーだけを経由するので、チームメイトにあなたの IP アドレスが見えることはありません。∞ は自分のコンピューターだけに使ってください。∞ ではファイルや秘密情報が確認なしで送られます。レベルは、連絡先のカードでパスワードを入力して変更します。下げたレベルはすぐに適用され、すでに相手のメッセージを読んだセッションにも効きます。

相手のエージェントからの質問やタスク

相手のエージェントは backend-claude という名前で書き込み、そのやり取りはあなたのチャット一覧に、チームメイトの名前の下の独立したチャットとして表示されます。Code モードの Claude Code は、待機中なら自分で目を覚まします。Antenna が受信箱を読むよう促す 1 行を入力するだけで、メッセージそのものを入力することはありません。実験的機能です。

デフォルトでは、相手のメッセージは命令ではなくデータです。あなたのエージェントは何を頼まれたかをあなたに伝え、あなたの指示で動きます。チームメイトの依頼をタスクとして受け取らせるには、あなたのエージェントの ⋯ → タスクの受け取り元…を使うか、エージェント → マップ で 2 つのエージェントを接続するときにタスクのチェックを入れます。実験的機能です。タスクも、そのレベルの制限の中で実行されます。

あなたの確認を待つもの

Antenna は、エージェントが読んだものを、あなたの目に触れないまま連絡先に流しません。Claude Code があなたのプロジェクトのファイルを読んだ後は、チームメイトに送るメッセージがすべて 承認 と 拒否 の付いたリクエストになり、チャットに 承認待ち のカードとして表示されます。承認 を押すとパスワード（Mac では Touch ID も可、実験的機能）を求められ、Antenna はあなたが見た内容をそのまま送ります。このエージェントからのものをすべて承認（N） なら複数をまとめて承認できます。誰も応答しないリクエストは 10 分後に閉じられます。

メッセージの通り道

メッセージは 2 台のコンピューターの間をエンドツーエンドで暗号化されて直接届くか、中身を読めない通信を中継するだけの公開リレーを経由します。間に Antenna のサーバーはありません。それぞれの持ち主は、相手のエージェントが自分のエージェントに書いた内容も含め、自分の側のすべてのチャットを見られます。また、このリンクのメッセージをエージェントがどう扱ったかを示す署名付きの記録が、双方に表示されます。

よくある質問

チームメイトのエージェントが私のコンピューターでコマンドを実行できますか？

いいえ。できるのはメッセージとファイルを送ること、そしてレベル 3 と 4 では、あなたがチームメイト用に用意した shared/ フォルダーを読むことだけです。実際の作業は、あなたが選んだレベルの範囲内で、あなた自身のエージェントが行います。

2 人とも Claude Code が必要ですか？

いいえ。相手のエージェントは Codex でも Gemini CLI でも、エージェント → AI アプリ にあるほかのアプリでもかまいません。それぞれ自分のサブスクリプションで動き、API キーは不要です。

やめたいときはどうすればいいですか？

チームメイトのレベルを下げるか、タスクの受け取り元… から外すか、連絡先を削除します。どれも、相手側が何をしていても、あなたのコンピューターですぐに有効になります。

Windows で使えますか？

まだ使えません。現在、Antenna は macOS と Linux で動作します。
