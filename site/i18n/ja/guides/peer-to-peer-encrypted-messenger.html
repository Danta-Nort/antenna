Antenna は macOS と Linux 向けの無料・オープンソースの P2P メッセンジャーです。メッセージとファイルは QUIC でデバイスからデバイスへ直接届き、libsignal の耐量子プロトコルでエンドツーエンド暗号化されます。接続そのものにもハイブリッドの耐量子鍵交換を使います。メッセージを保存したり中継したりする中央サーバーはありません。2 台のデバイスが直接つながれないときは、復号できない通信をリレーが転送します。

実際の P2P

「P2P」と聞くと単純そうですが、ほとんどのコンピューターは、外からの接続をブロックする家庭用ルーターやファイアウォールの内側にあります。Antenna が使う iroh は、そうした壁を越える直接の経路を見つけ（ホールパンチング）、見つからなければリレーにフォールバックする QUIC ライブラリです。接続はたいていリレー経由で始まり、直接の経路が見つかるとそちらに切り替わります。いずれの場合もリレーに見えるのは暗号化されたパケットだけで、デフォルトのリレーの代わりに自分のリレーを運用することも誰でもできます。

同じネットワーク上なら、十分に信頼している連絡先とは、インターネットがまったくなくてもローカルネットワーク経由でつながれます。

「耐量子」とは、今日の通信を記録しておき、後で量子コンピューターで復号しようとする相手に対しても、鍵交換が安全であり続けるという意味です。Antenna は暗号を自作しません。どちらの層も監査済みまたは形式検証済みのライブラリによるもので、ペアリングのプロトコルには ProVerif で検証した形式モデルがあります。

P2P の設計で変わること

  • 盗まれるアカウントがありません。ユーザー、その連絡先、そのメッセージの一覧を持つサーバーが存在しません。
  • 電話番号は不要です。相手の追加は、1 回限りのリンクと、声で照合するコードで行います。電話番号不要のメッセンジャーをご覧ください。
  • IP アドレスはあなたの条件で。直接接続では相手にあなたのアドレスが見えます。信頼レベル 1 と 2 の連絡先とは常にリレーを経由するので、そうした相手には見えません。
  • 両方のデバイスが同時にオンラインである必要があります。それまでメッセージは送信側のキューで待ち、自動的に送られます。サーバーを動かしたままにしておけば、エージェントにはいつでも届きます。

オープンソースで、検証できる

アプリケーションは AGPL-3.0、プロトコルとその形式、テストベクターは Apache-2.0 なので、ほかの人が互換クライアントを作れます。リリースは署名されており、ソース、仕様、すべての設計判断は GitHub にあります。メッセージは署名されてハッシュでつながり、双方がコピーを照合するので、メッセージが変更されたり巻き戻されたりすれば、それがどこで起きたかがわかります。

よくある質問

P2P のメッセンジャーは遅くないですか？

たいていは遅くありません。直接の経路ならデータセンターへの往復がなく、リレー経由でも経由地が 1 つ増えるだけです。

自分のリレーを運用できますか？

はい。リレーはオープンソースで、暗号化された通信を転送するだけです。ノードの接続先を、デフォルトのリレーから自分のリレーに変えてください。

グループで使えますか？

まだ使えません。Antenna 0.1 にあるのは 1 対 1 の会話で、人と人、人とエージェント、エージェントとエージェントの間で使えます。

対応プラットフォームは？

Apple Silicon の macOS（署名・公証済み）と、x86_64 の Linux（デスクトップアプリとサーバー用ノード）です。
