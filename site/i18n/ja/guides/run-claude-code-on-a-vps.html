Linux の VPS に Claude Code と Antenna のノードをインストールし、サーバーとノート PC を一度だけペアリングして、プロジェクトフォルダーで Antenna 経由で Claude Code を起動します。すると Claude Code はログアウト後も専用の tmux セッションで動き続け、宛てたメッセージが届くと起きて、ノート PC のチャットで答えます。受信用のポートを開ける必要も、SSH セッションを維持する必要もありません。Codex も同じように使えます。

必要なもの

  • x86_64 の Linux サーバー。Claude Code（または Codex）がインストール済みでサインイン済みであること、そして tmux。
  • ノート PC に Antenna。macOS または Linux。

1. サーバーに Antenna のノードをインストールする

curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER

インストーラーは署名付きマニフェストから最新のリリースを読み取ってアーカイブを検証し、antennad と antenna を systemd のユーザーサービスとして ~/.local/bin にインストールし（root は不要）、パスワード付きでノードを作成します。2 行目は、ログアウト後もサービスを動かし続けるためのものです。Ubuntu や Fedora なら、代わりに .deb や .rpm をインストールすることもできます。

2. ノート PC とペアリングする

ノート PC で 新しい連絡先 → 招待 を開き、名前を付け、これは自分のコンピューターです（∞） にチェックを入れて リンクを作成 を押し、リンクをコピーします。サーバーで：

antenna join '<link>' --trust 5 --label mac

シングルクォートは外さないでください。リンクには # が含まれています。ノート PC に表示されたコードをサーバーのターミナルに入力し、ノート PC で 相手が確認しました — コードは一致 を押します。レベル 5 は双方で ∞ にあたるので、サーバーはあなた自身のコンピューターとして扱われます。

3. Antenna 経由で Claude Code を起動する

cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev

connect の行はセッションに専用のエージェントとトークンを与え、あいさつを送るので、ノート PC に api-dev という名前のチャットが現れます。start の行は Antenna 専用の tmux サーバーで Claude Code を起動します（あなたの tmux には触れません）。一度アタッチして、フォルダーを信頼するかどうかといった Claude Code の最初の質問に答え、Ctrl-b d でデタッチすれば、Claude Code は動き続けます。Codex の場合は antenna connect codex と --cli codex を使います。

4. 話しかける

ノート PC の api-dev のチャットに書きます：「マイグレーションのテストを実行して、失敗したものを直して」。Claude Code がプロンプトで待機していると、Antenna が短い 1 行を入力してあなたのメッセージを読ませます。連絡先のテキストを入力することも、代わりに質問に答えることもありません。自分のデバイス のサーバーのカードにはその健全性とエージェントが表示され、サーバーからのリクエストをノート PC で承認できます。

再起動後

サーバーが再起動すると、ノードの鍵はロックされます。サービスは動いていますが、あなたがログインして antenna unlock を実行するまで、リンクは沈黙したままです。こうしておけば、サーバーのディスクのコピーを手に入れても誰もあなたの鍵を得られません。ロックされているかどうかは antenna status でわかります。

よくある質問

SSH と tmux だけではだめなのですか？

ターミナルの前に座っている間はそれで十分です。Antenna はそれに加えて、ノート PC からいつでも書き込めるチャットを用意し、書き込んだらセッションを起こし、ほかのエージェントからも仕事を渡せるようにします。権限は Antenna 自身が検査します。

サーバーにグローバル IP やポート開放は必要ですか？

いいえ。どちらの側も外向きに接続します。ネットワークが許せば直接、そうでなければリレーを経由し、リレーは暗号化された通信を転送するだけです。

1 台のサーバーで複数のセッションを動かせますか？

はい。プロジェクトフォルダーごとに 1 つのエージェントで、それぞれがノート PC 上に自分の名前と自分のチャットを持ちます。

ARM 向けのビルドはありますか？

まだありません。サーバー用のノードは x86_64 の Linux 向けにビルドされています。
