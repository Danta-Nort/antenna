両方のコンピューターに Antenna をインストールし、一度だけ自分のものとしてペアリングします。Codex を動かすコンピューターで、antenna connect codex で Codex セッションに名前を付け、antenna session start … --cli codex で起動します。するとノート PC にその名前のチャットが現れます。そこにタスクを書けば、Codex が待機中のときに Antenna が起こします。Codex はメッセージを読み、もう一方のコンピューターで作業して、チャットで答えます。SSH セッションを開いたままにする必要も、受信用のポートを開ける必要もありません。

必要なもの

  • 作業をするコンピューターに、インストール済みでサインイン済みの Codex CLI。x86_64 の Linux サーバー、または Mac か Linux のデスクトップです。Codex はこれまでどおりあなた自身のサブスクリプションで動き、Antenna に API キーは要りません。
  • そのコンピューターに tmux。サーバーでは、ログアウトした後も Antenna とセッションが動き続けるように、sudo loginctl enable-linger $USER も一度実行しておきます。
  • 両方のコンピューターに Antenna。デスクトップにはアプリを、サーバーにはノードを入れます（curl -fsSL https://antenna.contact/install.sh | sh）。

1. 2 台のコンピューターをペアリングする

ノート PC で 新しい連絡先 → 招待 を開き、これは自分のコンピューターです（∞） にチェックを入れてリンクを作り、もう一方のコンピューターで開きます（サーバーでは antenna join '<link>' --trust 5 --label mac）。片方に表示されたコードをもう片方に入力します。これで両者は互いを自分のコンピューターとして扱います。スクリーンショット付きの詳しい手順は VPS で Claude Code を動かすにあり、Codex でも同じです。

2. Codex セッションに名前を付ける

Codex を動かすコンピューターの、プロジェクトフォルダーで：

cd ~/projects/api
antenna connect codex --agent api-codex --links mac --hello mac

これでエージェント api-codex が専用のトークンファイル付きで作られ、ノート PC にリンクされ（mac はペアリング時にこのコンピューターがノート PC に付けた名前です）、あいさつが送られるので、ノート PC にはすぐに api-codex という名前のチャットが現れます。あなた自身の Codex の設定は変更されません。Antenna が追加されるのは、このエージェントのセッションだけです。

3. Antenna 経由で Codex を起動する

antenna session start api-codex --dir ~/projects/api --cli codex
antenna session attach api-codex

Codex は Antenna 専用の tmux サーバーで起動し、あなたの tmux には触れません。一度アタッチして、Codex の最初の質問に答えてください。初回、Codex は Antenna のフックを信頼するかどうかを尋ねてきます（「Hooks need review」）。「Trust all and continue」を選んでください。その後 Ctrl-b d でデタッチすれば、Codex は動き続けます。再起動後は --resume でエージェントの前回のセッションを続けられます。

4. ノート PC からメッセージを送る

api-codex のチャットを開いて書きます：「テストを実行して、失敗したものを直して、何を変えたか教えて」。Codex がプロンプトで待機していると、Antenna が受信箱を読むよう伝える組み込みの 1 行を入力します。あなたのテキストをターミナルに入力することはなく、Codex が質問している最中に入力することもありません。Codex は Antenna を通じてメッセージを読み、作業して、チャットで返信します。実験的機能です。

今やっていることを止めさせたいときは、送信前に 緊急: 今すぐ中断をオンにします。Antenna が Esc を一度押して実行中のターンを終わらせ、それからあなたのメッセージのために Codex を起こします。エージェントとそれが起動したすべてのものを止めるには、ノート PC の 自分のデバイス でもう一方のコンピューターのカードを開き、エージェントとそのプロセスを停止…（api-codex の横にあります）を押します。

デスクトップなら Code モードで

Codex を Antenna アプリの入った Mac や Linux のデスクトップで動かすなら、ターミナルでの手順は省けます。Code モードでエージェントパネルの + を押し、Codex と作業フォルダーを選ぶと、Codex はウィンドウ内のタブで動き、同じように起こされます。そのチャットには、ほかのエージェントと同じく、あなたのほかのコンピューターからもアクセスできます。

よくある質問

ノート PC で Codex のターミナルが見られますか？

いいえ。Codex へのタスクの依頼と回答の確認はチャットで行い、ターミナルはもう一方のコンピューターに残ります。様子を見たいときは、そちらで（必要なら SSH 経由で）antenna session attach を実行してください。

どのバージョンの Codex で使えますか？

Codex 0.160 以降はフックを通じて自分の動作を報告するので、Antenna は Codex が待機中かどうかを知ることができます。それより古い Codex や、フックを信頼していない場合は、Antenna はターンの後に Codex が空の入力行を表示するまで待ち、ターンの実行中に入力することはありません。

Codex を Claude Code と会話させることもできますか？

はい。エージェントマップで 2 つのエージェントをつなぐと、宛先を指定しなくても互いのメッセージが相手に届きます。Claude Code と Codex を会話させる方法をご覧ください。

スマートフォンから操作できますか？

まだできません。現在、Antenna は macOS と Linux で動きます。
