メッセンジャーをセルフホストするのは、自分のメッセージを他人のサーバーに置かないためです。Antenna はサーバーをまったく使わずにそれを実現します。一人ひとりが自分のコンピューターで Antenna を動かし、メッセージはそのコンピューター同士の間をエンドツーエンド暗号化されて行き来し、履歴はそこだけに、暗号化されたデータベースとして保存されます。さらに管理したい場合は、常時稼働の Linux ノードを追加したり、自分のリレーを運用したりできます。どちらもオープンソースです。

セルフホストのサーバーとは、ふつう何を意味するか

従来のセルフホスト型メッセンジャーは、自分でインストールし、アップデートし、バックアップを取り、オンラインに保つサーバーで、利用する全員のアカウントとメッセージをすべて抱えています。信頼の対象を企業から自分に移せる一方で、手間とリスクも一緒に移ってきます。サーバーが侵害されれば、全員の履歴も侵害されます。

Antenna のやり方

  • ホストするアカウントがありません。あなたの ID は、パスワードで保護された自分のコンピューター上の鍵です。相手の追加は、1 回限りの招待リンクと、声で照合するコードで行います。
  • 途中にメッセージの保管場所がありません。履歴はあなたのコンピューターと相手のコンピューターの、SQLCipher で暗号化されたデータベースにあります。
  • オンラインに保つべきサーバーがありません。2 台のコンピューターはネットワークが許せば直接つながり、そうでなければ暗号化された通信を転送するだけで何も保存しないリレーを経由します。

常時稼働のノードを追加する

ノート PC はスリープしますが、サーバーはしません。AI エージェントにいつでも届くようにしたいなら、Linux サーバー（x86_64）に Antenna のノードをインストールします。リリースを展開して ./install.sh を実行すると root なしで systemd のユーザーサービスがセットアップされます。.deb や .rpm パッケージでインストールすることもできます。あとは連絡先と同じように、∞ · My computer で自分のコンピューターとペアリングします。詳しい手順は Add a server をご覧ください。

再起動後、ノードの鍵はあなたがログインして antenna unlock を実行するまでロックされたままです。盗まれたディスクイメージから誰かがあなたの鍵を得ることはできません。

自分のリレーを運用する

リレーは唯一の共有部分で、見えるのは暗号化されたパケットと、どのエンドポイントがそこを経由して通信しているかだけです。それを自分のマシンにしたいなら、オープンソースの iroh-relay を動かし、antennad --relay <your relay URL> でノードを起動してください。信頼レベル 1 と 2 の連絡先とは常にリレー経由でつながるので、そうした相手にあなたの IP アドレスが知られることはありません。

よくある質問

家族でも使えますか？

コンピューターなら使えます。Antenna 0.1 は macOS（Apple Silicon）と Linux で動きます。スマートフォンアプリはまだありません。

リレーはオフラインの連絡先宛てのメッセージを保存しますか？

いいえ。オフラインの連絡先宛てのメッセージはあなた自身のコンピューターで待機し、相手が戻ると自動的に送られます。

自分でホストしなければならないものはありますか？

ありません。Antenna はデフォルトのリレーで、あなたのサーバーなしで動きます。ノードとリレーは、必要になったときのためのものです。

サーバーでのアップデートはどうなりますか？

install.sh でインストールしたノードは antenna update でアップデートでき、最初にリリースの署名が確認されます。パッケージでインストールした場合は、パッケージマネージャーでアップデートします。
