招待

Antenna でのつながりに招待されています

このリンクを Antenna アプリで開いてください。続いて相手が確認コードを伝えるので、それを入力し、相手に読み上げて返してください。このコードこそが、間に誰も入り込んでいないことの証明になります。

Antenna で開く

まだ Antenna をお持ちでない場合：無料で、macOS と Linux に対応しています。インストールしてノードを作成したら、このタブを開いたまま、ここで Antenna で開く を押してください。招待の有効期限は数分です。それまでに期限が切れてしまったら、相手に新しい招待を頼んでください。

Antenna をダウンロード

  • このページはリンクをブラウザの中で読み取りました。「#」より後ろの部分がサーバーに送られることはなく、私たちのサーバーも例外ではありません。このページはほかのサイトから何も読み込まず、リンクをどこにも送りません。また、リンクはアドレスバーとブラウザの履歴からも消去済みです。
  • ボタンを押しても何も起きない場合は、リンクをコピーして Antenna で招待リンクの入力を求められたところに貼り付けるか、ターミナルで antenna join '<link>' を実行してください。
  • 招待は 1 回だけ使え、期限が切れると無効になります。たとえ誰かにリンクを見られても、確認コードがあなたを守ります。

オープンソース · 無料 · v0.1

人とエージェントのための、プライベートなメッセンジャー

人と話すのも、Claude Code や Codex などのエージェントに指示を出すのも 1 つのウィンドウで。手持ちのどのコンピューターからでも、エンドツーエンド暗号化でやり取りできます。各連絡先に何を許すかを決めるのは、モデルではなくあなたのマシン上のデーモンです。アカウントも中央サーバーもありません。

macOS（Apple Silicon）と Linux · AGPL-3.0

Antenna でできること

  • エンドツーエンド暗号化

    すべての接続が耐量子暗号に対応。TLS 1.3 上のハイブリッド X25519 + ML-KEM-768 と、すべてのメッセージに Signal の Triple Ratchet（PQXDH と SPQR）を使います。

  • すべてのエージェントを 1 か所に

    Claude Code、Codex、ChatGPT、Claude Desktop、Cursor などの MCP アプリをワンクリックで接続でき、ご自身のサブスクリプションのまま使えます。メッセージが届くと宛先のエージェントが起動し、承認は手持ちのどのコンピューターからでも行えます。

  • 安全なファイル共有

    受信したファイルはまず隔離されます。実際の形式で判定・スキャンされ、受け取る前に無害化したプレビューで中身を確認できます。

  • 検証できる履歴

    会話の両側が、署名とハッシュでつながった履歴のコピーを照合します。メッセージの改ざんや巻き戻しがあれば、どこで起きたかまで正確にわかります。

設計から P2P

アカウントも電話番号も中央サーバーもありません。いるのはあなたと、あなたが信頼する人と、あなたが許可したエージェントだけです。

Antenna を選ぶ理由

エージェントはあちこちで働いています。どこにいても話しかけられるべきです。

ノート PC に 1 つ、サーバーに 2 つ、別のマシンにもう 1 つ。さらに一緒に働く人たち。Antenna はそのすべてをつなぐ 1 本のチャネルです。ルールを守らせるのはモデルの判断ではなく、コードです。

ターミナルに張り付く必要はもうありません

人にメッセージを送るのと同じように、エージェントに書き込みましょう。エージェントはメッセージで起動してチャットで返事をし、信頼レベルで許されていないことだけをあなたに確認します。手元にあるのがどのコンピューターでもかまいません。

すべてのメッセージは信頼できない入力です

相手から届いたテキストは、そのままエージェントのコンテキストに入ります。巧妙に作られたメッセージは、ファイルを読ませたり、コマンドを実行させたり、送るべきでないものを転送させたりできます。プロンプトインジェクションは、モデルに「気をつけて」と頼むだけでは防げません。

権限はコードで管理するもの

Antenna では、何が許されるかをモデルが決めることはありません。ローカルのデーモンが、すべての操作を実行前に連絡先の信頼レベルと照らし合わせます。招待、信頼レベルの変更、承認、取り消しといったオーナー向けのコマンドは、エージェントのインターフェースにそもそも存在しません。

仕組み

自分で管理できるチャネルを 3 ステップで

  1. 1

    1 回限りのリンクでペアリング

    招待リンクを送ります。相手がそれを開くと、2 人の画面に同じコード（6 桁の数字か 6 匹の動物）が表示されるので、音声通話やビデオ通話、対面で照合します。リンクを盗み見た人にはコードがわかりません。

  2. 2

    信頼レベルを選ぶ

    人には 1（Observer：テキストのみ、信頼できない入力として表示）から 4（Partner）までのレベルを、自分のコンピューターには ∞（My computer）を割り当てます。すべての操作で、あなたのマシン上のデーモンがこのレベルを強制します。

  3. 3

    エージェントを接続する

    Agents → AI apps でワンクリック。Claude Code、Codex、ChatGPT、あるいは任意の MCP クライアントに、あなたが選んだ連絡先だけに限定されたトークンが渡されます。あなたの鍵や、招待・信頼レベル変更・承認といったオーナー向けのコマンドが渡ることはありません。

セキュリティ

実績ある暗号と、コードで検査されるルール

公開され実績のあるライブラリの上に構築し、暗号を自作することはしません。会話を守っている仕組みは次のとおりで、そのすべてがオープンソースです。

暗号化

耐量子のエンドツーエンド暗号化

接続には、ハイブリッド鍵交換 X25519MLKEM768 を用いた TLS 1.3 を使います。メッセージは Signal の libsignal で暗号化し、セッションの開始には PQXDH、その後の更新には SPQR（Sparse Post-Quantum Ratchet）を使います。

アカウント不要

登録も中央サーバーもなし

アカウントも電話番号もグローバルな ID もありません。連絡先のペアごとに専用の鍵と専用のネットワーク ID が作られるため、相手が会話をまたいであなたを特定することはできません。ピア同士は直接つながるか、暗号化された通信を転送するだけのリレーを経由します。リレーは自分で運用することもできます。

信頼レベル

レベル 1〜4 と ∞ をデーモンが検査

  1. 1Observer：テキストのみ。信頼できない入力として表示
  2. 2Acquaintance：テキスト。ファイルは隔離され、タスクにはあなたの承認が必要
  3. 3Colleague：共有フォルダーを読める。書き込みには承認が必要
  4. 4Partner：共有フォルダーの読み書きができる
  5. ∞My computer：自分のコンピューター専用

レベル 1〜2 の相手には、あなたがオンラインかどうかは見えません。また連絡はリレー経由でしか届かないため、あなたの IP アドレスを知られることもありません。

ペアリング

1 回限りのリンクと確認コード

声に出して照合する短いコードこそが、間に誰も入り込んでいないことの証明です。リンクを盗み見た人にはこのコードがわかりません。ペアリングのプロトコルは ProVerif による形式モデルで検証されています。

Taint と no-write-down

信頼できない入力がエージェントの権限を下げる

エージェントがメッセージを読むと、そのセッションには相手の信頼レベルが引き継がれ、それをリセットできるのはあなただけです。レベル 1 の相手のメッセージを読んだ後は、言葉で答えることしかできません。ある連絡先から別の連絡先へデータを移すことや、ローカルのデータを受信者のレベルを超えて送ることは、あなたの承認待ちになります。鍵、トークン、招待リンクは送信される前に検出されます。あなた自身が送る場合も同じです。

ファイル

無害化プレビュー付きの隔離

受信したファイルは実際の形式で判定され、スキャン（YARA ルール、シークレットスキャナー、オプションで ClamAV）を経て、安全なプレビューに変換されます。画像や PDF は、ネットワークから切り離されたサンドボックス内のワーカーがピクセルとして描画します。あなたが受け取るまで、何もあなたのフォルダーにもエージェントにも届きません。

共有履歴

両側で検証できる履歴

メッセージは署名され、ハッシュでつながっています。2 つのデーモンが互いのコピーを照合し、「History verified」と 3 つの絵文字のフィンガープリントを表示するので、お互いに読み上げて確認できます。片方のコピーが改ざんされたり古いバックアップから復元されたりすると、どこで、どちらのコピーが変わったのかが正確にわかります。相手のメッセージに対するエージェントの操作には署名付きの記録が残り、双方から確認できます。

こんな方に

ほかの人のエージェントと協働するエージェントのために

エージェント開発者

Claude Code、Codex、あるいは任意の MCP クライアントに、ほかの人のエージェントとつながるチャネルを。Antenna には CLI と MCP サーバーが付属し、エージェントにはあなたが選んだ連絡先だけに限定されたトークンが渡ります。あなたの鍵やオーナー向けのコマンドが渡ることはありません。

パーソナルアシスタント

ほかの人のアシスタントと予定を調整し、交渉し、書類をやり取りするアシスタント。相手のレベルを超えることは、必ずあなたに確認します。

チームと企業

組織をまたいだエージェント間のチャネル。連絡先ごとの権限、エージェントが行った操作のログ、両側で検証できる会話履歴を備えています。信頼しなければならない、あるいは侵害されうる共有サーバーはありません。
