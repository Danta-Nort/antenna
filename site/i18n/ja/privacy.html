プライバシーポリシー

要点だけ言うと、このサイトはあなたに関する情報を一切収集しません。フォーム、トラッカー、アクセス解析、Cookie はなく、ほかのサイトから何も読み込みません。Antenna アプリから受け取るのは新規インストール数のカウントだけで、IP アドレスや内容は受け取りません。

このサイトについて

  • アクセス解析、トラッキングピクセル、広告、Cookie は一切使っていません。
  • 外部のスクリプト、フォント、画像は使っていません。すべて antenna.contact から配信しています。
  • 招待リンク：アドレスの「#」より後ろの部分はブラウザの中にとどまり、このサイトに送られることはありません。
  • ダウンロードボタンを押すと GitHub 上のファイルに移動します。そこでは GitHub のプライバシーに関する声明が適用されます。

このサイトは Cloudflare Workers 上で動いています。ほかの Web サーバーと同じく、ページを届けるために Cloudflare があなたの IP アドレスを扱いますが、私たちはリクエストのログを保存していません。

Antenna アプリについて

Antenna にはアカウントがなく、メッセージを中継する私たちのサーバーもありません。メッセージやファイルは会話する人どうしのデバイス間でエンドツーエンド暗号化されて届きます。直接届くか、暗号化された通信を転送するだけのリレーを経由します。新規インストール数のカウントを除き、アプリは利用状況のデータもクラッシュレポートも送信しません。私たちのサーバーに送るリクエストは、次に説明するアップデートの確認だけです。

アプリは 1 日に 1 回、署名済みの新しいリリースがあるかどうかを updates.stillbyte.dev に問い合わせます。このリクエストには、あなた自身、連絡先、メッセージに関する情報は一切含まれません。ただし、ほかの Web リクエストと同じく、コンピューターの IP アドレスは接続先に伝わります。バージョン 0.1.1 からは、Antenna をインストールして最初の確認にだけ「初回の確認」を示す印が 1 つ付きます。それ以外には何も付かず、新規インストール数を数えるためだけに使います。アップデートサーバーは 1 日あたりの確認回数と、そのうち新規インストールの初回確認が何回あったかを数えるだけで、IP アドレスは保存しません。確認をオフにするには、~/.config/antenna/update-url に off と書き込んでください。

クローズドベータの申し込みについて

一般公開の前、このサイトにはクローズドベータの申し込みフォームがありました。そこから送られたメールアドレスは、Antenna が利用可能になったことをお知らせするためだけに使い、その後削除します。今すぐ削除してほしい場合は、ご連絡ください。
