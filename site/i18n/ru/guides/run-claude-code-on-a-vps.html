Установите Claude Code и узел Antenna на свой VPS с Linux, один раз свяжите сервер с ноутбуком и запустите Claude Code через Antenna в папке проекта. Дальше он работает в своей сессии tmux и после того, как вы вышли из системы, просыпается, когда ему приходит сообщение, и отвечает в чате на ноутбуке. Не нужно открывать входящий порт или поддерживать SSH-сессию, а с Codex всё работает так же.

Что понадобится

  • Сервер с Linux на x86_64, на котором установлен Claude Code (или Codex) с выполненным входом, и tmux.
  • Antenna на ноутбуке: macOS или Linux.

1. Установите узел Antenna на сервер

curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER

Установщик берёт самый новый выпуск из подписанного манифеста, проверяет архив, ставит antennad и antenna в ~/.local/bin как пользовательскую службу systemd (root не нужен) и создаёт ваш узел с паролем. Вторая строка нужна, чтобы служба продолжала работать после того, как вы выйдете из системы. В Ubuntu или Fedora вместо этого можно поставить пакет .deb или .rpm.

2. Свяжите сервер с ноутбуком

На ноутбуке: Новая связь → Пригласить, дайте связи имя, отметьте Это мой собственный компьютер (∞), нажмите Создать ссылку и скопируйте её. На сервере выполните:

antenna join '<link>' --trust 5 --label mac

Не убирайте одинарные кавычки: в ссылке есть #. Введите в терминале сервера код, который показывает ноутбук, а потом нажмите на ноутбуке Контакт подтвердил — коды совпадают. Уровень 5 — это ∞ на обеих сторонах, так что сервер считается вашим собственным компьютером.

3. Запустите Claude Code через Antenna

cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev

Строка с connect даёт сессии собственного агента и токен и здоровается, чтобы на ноутбуке появился чат api-dev. Строка со start запускает Claude Code на собственном tmux-сервере Antenna (ваш tmux остаётся нетронутым). Подключитесь один раз, чтобы ответить на первые вопросы Claude Code, например доверяет ли он этой папке, а потом отключитесь сочетанием Ctrl-b d: он продолжит работать. Для Codex используйте antenna connect codex и --cli codex.

4. Пишите ему

Напишите в чат api-dev на ноутбуке: «Прогони тесты миграций и исправь то, что падает». Когда Claude Code простаивает у строки ввода, Antenna набирает одну короткую строку, чтобы он прочитал ваше сообщение; текст контакта она никогда не набирает и никогда не отвечает за Claude Code на его вопросы. Карточка сервера в разделе Мои устройства показывает его состояние и агентов, а одобрять его запросы можно прямо с ноутбука.

После перезагрузки

После перезапуска сервера ключи узла закрыты: служба работает, но его связи молчат, пока вы не войдёте на сервер и не выполните antenna unlock. Так копия диска сервера никому не даст ваших ключей. Закрыты ли ключи, покажет antenna status.

Вопросы

Почему не обойтись SSH и tmux?

Это работает, пока вы сидите у терминала. Antenna добавляет чат, в который можно написать с ноутбука в любой момент, будит сессию, когда вы пишете, и позволяет другим агентам давать ей работу, причём права она проверяет сама.

Серверу нужен белый IP или открытые порты?

Нет. Обе стороны сами подключаются наружу: напрямую, если сеть позволяет, а если нет — через relay. Relay пересылает только зашифрованный трафик.

Можно запустить несколько сессий на одном сервере?

Да: по агенту на каждую папку проекта, у каждого своё имя и свой чат на ноутбуке.

Есть сборка для ARM?

Пока нет. Серверный узел собирается для Linux на x86_64.
