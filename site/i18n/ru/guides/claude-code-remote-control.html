Установите Antenna на ноутбук и на компьютер, где работает Claude Code, один раз свяжите их как свои собственные компьютеры и запустите Claude Code там через Antenna. На ноутбуке появится чат с этой сессией: напишите в него задачу, Antenna разбудит Claude Code, когда тот простаивает, и его ответ вернётся в чат. Сообщения идут по прямой связи между вашими двумя компьютерами со сквозным шифрованием, аккаунт для Antenna не нужен, а шаги, которым нужно ваше одобрение, приходят на ноутбук, и вы отвечаете паролем.

Remote Control в самом Claude Code и Antenna

В Claude Code есть собственная встроенная функция Remote Control; она описана в документации Anthropic. Эта инструкция — о другой схеме: Claude Code работает на вашем компьютере, который всегда включён, сервере или настольном, а вы управляете им из Antenna на ноутбуке. Она подойдёт вам, если вы хотите:

  • Несколько сессий на нескольких компьютерах в одном списке. У каждой сессии свой чат, а раздел Мои устройства показывает состояние каждого компьютера, его агентов и запросы, которые там ждут.
  • Собственную связь. Сообщения шифруются на одном компьютере и расшифровываются на другом. Ваши компьютеры соединяются напрямую, если сеть позволяет, а если нет — через relay, который пересылает только зашифрованный трафик. Без аккаунта и без входящего порта.
  • Права, которые проверяет daemon Antenna на компьютере, где работает Claude Code, а одобрять можно с любого вашего компьютера, за которым вы сейчас.
  • Других агентов так же: Codex работает так же, как Claude Code.

Настройка

  1. Установите Antenna на оба компьютера: приложение на ноутбук (macOS или Linux), а на другой компьютер — приложение или, если это сервер с Linux, узел: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
  2. Один раз свяжите их. На ноутбуке: Новая связь → Пригласить, отметьте Это мой собственный компьютер (∞), нажмите Создать ссылку и скопируйте её. На сервере: antenna join '<link>' --trust 5 --label mac; на настольном компьютере: Новая связь → Присоединиться, с той же отметкой. Введите на одной стороне код, который показывает другая, и нажмите на ноутбуке Контакт подтвердил — коды совпадают.
  3. Запустите Claude Code через Antenna на другом компьютере. На сервере — в папке проекта (нужен tmux): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Ответьте на первые вопросы Claude Code и отключитесь сочетанием Ctrl-b d: он продолжит работать, а на ноутбуке появится чат api-dev. На настольном компьютере: Агенты → ИИ-приложения → Запустить в режиме «Код», и Claude Code заработает там во вкладке окна Antenna; один раз попросите его поздороваться с вашим ноутбуком через Antenna, и его чат появится на ноутбуке.
  4. Разрешите ноутбуку отвечать на запросы на одобрение с того компьютера. На сервере: antenna devices confirm mac. На настольном компьютере: Мои устройства → карточка ноутбука → Одобрения → Разрешить одобрения, подписанные: …, с вашим паролем.

Управляйте им с ноутбука

  • Давайте задачи. Пишите в чат сессии так же, как человеку. Когда Claude Code простаивает у строки ввода, Antenna набирает одну встроенную строку, чтобы он прочитал ваше сообщение; ваш текст она в терминал никогда не набирает и никогда не отвечает на вопрос, который Claude Code задаёт там. Экспериментально.
  • Прерывайте. Перед отправкой включите Срочно: прервать сейчас: Antenna один раз нажмёт Esc, чтобы завершить текущий ход, — но никогда поверх открытого там вопроса или запроса разрешения, — и Claude Code прочитает ваше сообщение. Экспериментально.
  • Одобряйте его шаги. Шаг, для которого нужны вы, появляется в карточке другого компьютера в разделе Мои устройства вместе с уведомлением. Нажмите Одобрить паролем, Одобрить по Touch ID на Mac или Отклонить. Экспериментально.
  • Останавливайте. Остановить агента и его процессы… рядом с агентом в этой карточке завершает Claude Code и всё, что он там запустил. Экспериментально.

Собственный запрос разрешения Claude Code («Do you want to proceed?») остаётся в его терминале на другом компьютере, и Antenna на него никогда не отвечает. Инструменты, которыми вы пользуетесь постоянно, разрешите в настройках Claude Code или отвечайте на этот запрос через antenna session attach.

Codex и другие агенты

С Codex всё так же: antenna connect codex и --cli codex на сервере или Запустить в режиме «Код» рядом с Codex на настольном компьютере (см. Удалённое управление Codex CLI). Gemini CLI подключается в разделе Агенты → ИИ-приложения и отправляет и читает сообщения через Antenna, но будить его Antenna пока не умеет: новое сообщение он прочитает, когда в следующий раз обратится к Antenna.

Вопросы

Видно ли терминал Claude Code на ноутбуке?

Нет. Задачи вы даёте и ответы читаете в чате; терминал остаётся на другом компьютере. Чтобы заглянуть в него, выполните там antenna session attach, при желании — по SSH.

Нужен ли другому компьютеру белый IP или открытые порты?

Нет. Оба компьютера сами подключаются наружу: напрямую, если сеть позволяет, а если нет — через relay. Relay пересылает только зашифрованный трафик.

Кто ещё может давать ему задачи?

Только контакты, связанные с тем компьютером, чьи сообщения агенту разрешено читать (с --links mac — только ваш ноутбук), и агенты, которых вы соедините с ним на карте агентов. Что сообщение контакта может заставить его сделать, решает daemon Antenna на том компьютере, а не Claude Code, — по уровню доверия этого контакта.

Нужен ли API-ключ?

Нет. Claude Code сохраняет ваш собственный вход на компьютере, где работает, а Antenna только передаёт сообщения, файлы и одобрения.

Можно ли управлять им с телефона?

Пока нет. Сейчас Antenna работает на macOS и Linux.
