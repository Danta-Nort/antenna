Вы и ваш коллега ставите Antenna и один раз связываетесь ссылкой-приглашением и кодом, который сверяете голосом. Ваш Claude Code получает имя, и агент коллеги пишет ему по этому имени. Вы выбираете для коллеги уровень доверия, и удерживает вашего агента в его рамках daemon Antenna на вашем компьютере, а не модель: что агенту можно читать, править и запускать и какие ответы ждут вас. Коллега делает то же самое у себя.

Настройка

  1. Установите Antenna на оба компьютера (macOS или Linux): у каждого свой пароль, никаких аккаунтов.
  2. Один из вас нажимает Новая связь → Пригласить, выбирает уровень для другого и отправляет ссылку; другой открывает её или пользуется Новая связь → Присоединиться. Появится код из шести цифр или шести животных: прочитайте его вслух во время звонка, а собеседник введёт его. Каждый выбирает уровень для другого.
  3. Запустите свой Claude Code через Агенты → ИИ-приложения → Запустить в режиме «Код», выбрав Новый агент… и имя, которым будет пользоваться коллега, например backend-claude, и добавив коллегу в его контакты. Коллега подключает своего агента так же.

Выберите уровень для коллеги

Агенты коллеги получают его уровень. Как только ваш агент прочитал его сообщение, он сохраняет ограничения этого уровня до конца своей сессии, и Antenna сверяет с ними каждый инструмент, которым Claude Code пользуется в режиме «Код».

УровеньВаш агент после чтения его сообщенияФайлы
1 · НаблюдательОтвечает только словамиНет
2 · ЗнакомыйКаждое чтение и каждая правка ждут вашего одобрения; команд нетПринимаются в карантин inbox/
3 · КоллегаЧитает; правки ждут вашего одобрения; команд нетshared/ только для чтения
4 · ПартнёрЧитает и правит в папке коллеги; другие правки и каждая команда ждут вашего одобренияshared/ для чтения и записи

На уровнях 1 и 2 коллега никогда не видит ваш IP-адрес: связь идёт только через relay. Уровень ∞ оставьте для своих компьютеров: на нём файлы и секреты отправляются без вопросов. Уровень меняется в карточке контакта, с вашим паролем; более низкий уровень действует сразу, даже для сессии, которая уже прочитала его сообщения.

Вопрос или задача от его агента

Его агент пишет backend-claude по имени, и переписка появляется в вашем списке отдельным чатом под именем коллеги. Claude Code в режиме «Код» просыпается сам, когда простаивает: Antenna набирает за него одну строку с просьбой прочитать входящие, но никогда не само сообщение. Экспериментально.

По умолчанию его сообщение — это данные, а не приказ: ваш агент рассказывает вам, о чём просили, и действует по вашему слову. Чтобы агент принимал просьбы коллеги как задачи, выберите у своего агента ⋯ → Принимает задачи от… или поставьте галочку задач, когда соединяете двух агентов в Агенты → Карта. Экспериментально. Задачи всё равно выполняются в рамках уровня.

Что ждёт вас

Antenna не даёт тому, что прочитал ваш агент, незаметно уйти к контакту: как только Claude Code прочитал файлы вашего проекта, каждое его сообщение коллеге становится запросом с кнопками Одобрить и Отклонить, который показывается в чате карточкой Ждёт вашего одобрения. Одобрить просит пароль (или Touch ID на Mac, экспериментально), и Antenna отправляет ровно то, что вы видели; Одобрить все от этого агента (N) одобряет несколько сразу. Запрос, на который никто не ответил, закрывается через 10 минут.

Куда идут сообщения

Напрямую между двумя компьютерами со сквозным шифрованием или через публичный relay, который пересылает трафик, но не может его прочитать; никакого сервера Antenna посередине нет. Каждый владелец видит у себя все чаты, включая то, что агент другого написал его агенту, а подписанные квитанции о том, что агенты сделали с сообщениями этой связи, видны вам обоим.

Вопросы

Может ли агент коллеги запускать команды на моём компьютере?

Нет. Он может только присылать сообщения и файлы, а на уровнях 3 и 4 — читать папку shared/, которую вы держите для коллеги. Работу делает ваш собственный агент, в рамках выбранного вами уровня.

Нужен ли Claude Code нам обоим?

Нет. Агентом коллеги может быть Codex, Gemini CLI или другое приложение из Агенты → ИИ-приложения, каждое по своей подписке, без API-ключей.

Как это остановить?

Понизьте уровень коллеги, уберите его из Принимает задачи от… или удалите контакт. Всё это действует на вашем компьютере сразу, что бы ни происходило на его стороне.

Работает ли это в Windows?

Пока нет. Сейчас Antenna работает на macOS и Linux.
