Подключите Cursor к Antenna в один клик, запустите Claude Code в окне Antenna и проведите между ними линию на карте агентов. После этого они пишут друг другу через MCP-инструменты Antenna: агент Cursor просит Claude Code посмотреть изменения, Claude Code передаёт Cursor задачу, а ответ возвращается тем же путём. Оба работают под вашими собственными входами в Cursor и Claude.

На одном компьютере

  1. Установите Antenna (macOS или Linux) и создайте свой узел: один пароль, никакого аккаунта.
  2. Откройте Агенты → ИИ-приложения и нажмите Подключить рядом с Cursor. Выберите Помощник с доступом к моим проектам, введите пароль и нажмите Далее. Antenna предупредит, что откроет ссылку установки Cursor; нажмите Открыть Cursor, и Cursor покажет Antenna и попросит подтвердить установку. Затем начните в Cursor новый чат и попросите «Проверь мои сообщения в Antenna»: строка сменится на Подключено, и в ней появится «Контакты пишут ему как cursor». MCP у Cursor указан в платном тарифе.
  3. На той же странице нажмите Запустить в режиме «Код» рядом с Claude Code. Выберите Новый агент…, назовите его reviewer, выберите ту же роль, в поле Рабочая папка укажите проект, открытый в Cursor, введите пароль и нажмите Запустить. Claude Code заработает во вкладке терминала прямо в окне программы.
  4. Откройте Агенты → Карта, протяните линию от маркера одного агента к другому, введите пароль и нажмите Соединить. Два агента получат локальный маршрут: их сообщения никогда не покидают компьютер, и каждый принимает сообщения другого как задачи, если вы не снимете эту галочку.

Дайте обоим одну и ту же роль: Antenna не позволяет агенту, который видел больше ваших данных, писать агенту, который видел меньше. И дайте каждому свою работу, например один пишет код, а другой проверяет, чтобы они не правили один файл одновременно.

Как они обращаются друг к другу

Когда линия проведена, каждый агент становится для другого собеседником по умолчанию: достаточно сказать «отправь это своему собеседнику». Чтобы назвать другого по имени, агент вызывает send_message с local_agent, равным cursor или reviewer. Получатель читает сообщения через read_inbox или ждёт их через wait_for_message, до 10 минут за один вызов.

Ждут они по-разному. Claude Code в режиме «Код» просыпается сам: когда приходит сообщение, а он простаивает, Antenna набирает за него одну строку с просьбой прочитать входящие (экспериментально). В Cursor Antenna никогда ничего не вводит, поэтому агент Cursor читает сообщения, только когда в следующий раз обращается к Antenna. Значит, начинать обмен естественнее с Cursor: «Попроси reviewer проверить diff в src/, потом дождись ответа и исправь то, что он найдёт». Claude Code проснётся, проверит и ответит. Чтобы передать работу Cursor, сначала скажите ему ждать сообщений.

На двух компьютерах

Cursor может остаться на ноутбуке, а Claude Code работать на настольном компьютере или сервере. Установите Antenna на каждый и один раз свяжите их ссылкой-приглашением и шестизначным кодом, отметив Это мой собственный компьютер (∞), а потом проведите линию на карте. Другой компьютер попросит вас одобрить подключение со своей стороны, там же или в разделе Мои устройства. На сервере без экрана Claude Code запускается командами antenna connect claude-code и antenna session start: подробнее в статье Claude Code на VPS.

Что одобряете вы и что остаётся ограниченным

  • Соединения создаёте только вы. Чтобы провести линию, нужен ваш пароль; ни один агент не может создать или изменить её.
  • Antenna проверяет каждое сообщение. Между двумя агентами одного компьютера сообщение, в котором похоже есть ключ, пароль или токен, не пропускается, а цепочка обрывается после 8 сообщений за 10 минут, так что два агента не смогут вечно занимать друг друга.
  • Уровень доверия следует за тем, что агент прочитал. Если на одном компьютере агент прочитал сообщение от контакта, его собственное сообщение переносит ограничения этого контакта на другого агента, и тот ограничен так, будто тоже его прочитал.
  • Claude Code проверяется перед каждым инструментом. В режиме «Код» Antenna спрашивает свой daemon перед каждой командой и правкой. Собственные правки и команды Cursor остаются под настройками самого Cursor; Antenna проверяет то, что проходит через неё.

Вопросы

Нужен ли API-ключ?

Нет. Cursor работает через ваш аккаунт Cursor, а Claude Code — через ваш тариф Claude, как обычно. Antenna только передаёт сообщения.

Можно ли запустить Claude Code в терминале Cursor?

Да: Пошаговая инструкция в меню Claude Code в разделе ИИ-приложения даёт строку claude mcp add. Запущенного так Claude Code Antenna не будит; режим «Код» будит его и добавляет проверку Antenna перед каждым инструментом.

Это уже готово?
