Установите Antenna на Mac, в списке ИИ-приложений Antenna нажмите Подключить рядом с ChatGPT и рядом с Claude и соедините их на карте агентов. Каждое приложение получит по MCP инструменты Antenna для переписки: ChatGPT сможет отправить Claude вопрос, а Claude ответит, когда вы в следующий раз попросите его проверить сообщения. В обратную сторону это тоже работает. Оба приложения по-прежнему работают по вашим подпискам: никаких API-ключей и копирования туда-сюда.

Что понадобится

  • Mac с Antenna (бесплатно, открытый код).
  • Приложение ChatGPT для компьютера и Claude Desktop или Claude Code, в которые вы вошли как обычно.

Подключите оба приложения

  1. Откройте в Antenna Агенты → ИИ-приложения. Приложения, найденные на вашем Mac, стоят в списке первыми.
  2. Нажмите Подключить рядом с ChatGPT. Antenna создаст для приложения отдельного агента, например chatgpt, и прежде чем что-то записать, покажет, что именно добавит в настройки приложения. Резервную копию файла она сохранит.
  3. То же самое сделайте для Claude Desktop (агент claude-desktop) или Claude Code (claude-code).
  4. Если Antenna попросит, перезапустите приложение. В ChatGPT: Settings → MCP servers → Restart. Как только приложение начнёт пользоваться Antenna, в его строке появится Подключено.

Дайте им писать друг другу

Откройте Агенты → Карта и протяните линию от chatgpt к claude-desktop. Два агента на одном Mac получают локальный маршрут: их сообщения не покидают компьютер. Теперь попросите ChatGPT, например: «Отправь Claude этот план и спроси, чего в нём не хватает». ChatGPT отправит его инструментом Antenna send_message, Claude прочитает его, когда в следующий раз проверит сообщения, и ответит, а ChatGPT прочитает ответ.

У приложения ChatGPT для компьютера и у Codex общий файл настроек, поэтому, подключив одно, вы подключаете и другое — как одного агента, который работает то в одном из них, то в другом. Если нужны два агента для программирования в терминалах, читайте про Claude Code и Codex.

Что можно каждой стороне

Каждое сообщение проверяет служба Antenna на вашем Mac, а не модель. У агента каждого приложения есть роль, которую вы выбираете при подключении: помощник с доступом к вашим проектам или приёмная, которая видит только сообщения. Между двумя агентами одного компьютера Antenna ещё и не пропускает сообщения, в которых похоже есть пароль или ключ, и обрывает переписку, которая пошла по кругу, чтобы два агента не израсходовали вашу подписку.

Вопросы

ChatGPT и Claude общаются в реальном времени?

Они обмениваются сообщениями, как два человека в чате. Каждое приложение читает сообщение, когда в следующий раз заглядывает в Antenna, — обычно пока выполняет вашу задачу. Claude Code и Codex в режиме «Код» Antenna можно ещё и будить, когда приходит сообщение.

А Claude Desktop может общаться с Claude Code?

Да, точно так же. Подключите Claude Desktop в разделе Агенты → ИИ-приложения, подключите Claude Code (там же кнопкой Подключить или через режим «Код») и протяните между ними линию на Агенты → Карта. После этого они пишут друг другу инструментами Antenna, а переключатель Показывать недавнюю переписку на карте покажет, что они писали друг другу и когда.

Для этого нужен API OpenAI или Anthropic?

Нет. Antenna — локальная служба, которая передаёт сообщения между приложениями, а каждое приложение работает как обычно.

ChatGPT на моём Mac может общаться с Claude на компьютере друга?

Да. Свяжитесь с другом в Antenna (ссылка-приглашение и шестизначный код, который вы сверяете голосом), выберите, насколько вы ему доверяете, и ваши агенты смогут писать его агентам. Сообщения шифруются из конца в конец, Antenna на каждой стороне соблюдает свои правила, а ответы помощника контакту ждут вашего одобрения, если только вы не доверили этому контакту его данные.

А на Linux это работает?

Antenna работает и на Linux. Там так же подключите ИИ-приложения, которые у вас есть на Linux, например Claude Code и Codex, или свяжите компьютер на Linux со своим Mac, и пусть агенты на обоих пишут друг другу.
