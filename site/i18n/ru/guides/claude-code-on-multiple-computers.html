Пусть Claude Code работает там, где идёт работа: на ноутбуке, настольном компьютере и сервере, — а на каждый из них поставьте Antenna. Один раз свяжите компьютеры как свои собственные (∞). После этого с любого из них вы видите все сессии в одном списке чатов, пишете любой из них по имени, отвечаете на их запросы одобрения и останавливаете сессию, которая пошла вразнос, не открывая терминал на том компьютере. С Codex всё работает так же.

Что вы получаете

  • Свой чат для каждой сессии, на каком бы компьютере она ни работала. Сессия на сервере и сессия на настольном компьютере стоят в одном списке с вашими контактами.
  • Мои устройства: карточка для каждого вашего компьютера — система и версия Antenna, состояние по его собственным проверкам, его агенты и подключён ли каждый из них, а ещё запросы, которые ждут вас на этом компьютере.
  • Одобрения оттуда, где вы сейчас. Запрос агента на сервере можно одобрить на Mac через Touch ID или пароль Mac. Сервер проверит подпись и сам выполнит запрос.
  • Кнопка остановки для каждого агента на другом компьютере: она останавливает агента и все процессы, которые он там запустил.
  • Карта агентов: на ней можно соединить сессию на одном компьютере с сессией на другом, чтобы они писали друг другу.

Как настроить

  1. Установите Antenna на каждый компьютер: приложение — на Mac или компьютер с Linux, узел — на сервер с Linux (curl -fsSL https://antenna.contact/install.sh | sh).
  2. Свяжите компьютеры друг с другом как свои. Создайте приглашение с отмеченным пунктом Это мой собственный компьютер (∞), откройте его на другом компьютере и введите код, который показывает одна сторона, на другой. Свяжите каждый компьютер со всеми, которые хотите с него видеть или к которым хотите с него подключаться: у каждого другой должен быть на уровне ∞.
  3. Дайте каждой сессии Claude Code имя. На настольном компьютере запустите её в режиме «Код» кнопкой + на панели агентов. На сервере в папке проекта выполните antenna connect claude-code --agent api-dev --links mac --hello mac и держите сессию запущенной командой antenna session start api-dev --dir ~/projects/api; все шаги — в инструкции «Claude Code на VPS».
  4. Разрешите главному компьютеру отвечать на запросы. На сервере один раз выполните antenna devices confirm mac; на настольном компьютере примите ключ главного компьютера в разделе Мои устройства → его карточка → Одобрения.

Как передавать работу между компьютерами

Пишите сессии так же, как человеку: «api-dev, прогони миграции на сервере и расскажи, что изменилось». Файлы, которые вы бросаете в её чат, сохраняются на том компьютере, и агенту сообщают, где они лежат. Между вашими собственными компьютерами обычные файлы сохраняются без вопросов, а программы и установщики всё равно ждут вашего решения. Чтобы сессия на настольном компьютере могла передавать работу сессии на сервере, соедините их на карте агентов. Сессия на сервере просыпается, когда приходит сообщение, а срочное сообщение может прервать её текущий ход. Экспериментально.

Вопросы

Antenna синхронизирует настройки или историю Claude Code между компьютерами?

Нет. Claude Code хранит настройки, историю и вход на каждом компьютере отдельно, а код переносится как и раньше — через git. Antenna передаёт между сессиями сообщения, файлы и одобрения.

Нужен ли серверу белый IP или открытые порты?

Нет. Каждый компьютер сам подключается наружу: напрямую, если сеть позволяет, а если нет — через relay, который пересылает только зашифрованный трафик.

Можно отсюда поменять настройку на другом компьютере?

Нет. Между вашими компьютерами передаются только одобрения, остановки и запросы на подключение с карты агентов, которые тот компьютер попросит вас одобрить. Доверие, приглашения, обновления и настройки меняются на самом компьютере, поэтому украденный ноутбук не сможет переписать правила сервера.

А на Windows или телефоне это работает?

Пока нет. Сейчас Antenna работает на macOS и Linux.
