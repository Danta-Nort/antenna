Запустите Claude Code через Antenna — в режиме «Код» в окне или командой antenna session на сервере, — и daemon Antenna будет проверять каждый инструмент, которым он пользуется, и каждое сообщение, которое он отправляет. Когда для шага нужны вы, шаг превращается в запрос на одобрение: он появляется вместе с уведомлением в разделе Мои устройства на каждом компьютере, который вы связали как свой собственный. Одобрите его там паролем этого компьютера или Touch ID: компьютер, где работает Claude Code, проверит ваш ответ и выполнит шаг, а Claude Code продолжит работу.

Что приходит к вам

  • Шаги после чтения сообщения контакта. Как только Claude Code прочитал сообщение коллеги, уровень доверия коллеги определяет, что агенту можно: на уровне 4 каждая команда ждёт вас; на уровнях 2 и 3 вас ждёт каждая правка, а команды отклоняются.
  • Изменения его собственной настройки. После чтения сообщения любого контакта, даже с вашего собственного ноутбука, правки CLAUDE.md, .claude/, профилей оболочки, ключей и файлов сборки вроде package.json ждут вас.
  • Сообщения, которые унесли бы ваши данные. Как только он прочитал файлы вашего проекта, каждое его сообщение контакту ниже ∞ ждёт вас, как и любое сообщение такому контакту, в котором, похоже, есть ключ, пароль или токен. Если он прочитал одну переписку, сообщение в другую тоже ждёт.
  • Вопросы. Экспериментально. Вопросы агента показываются на компьютере, где он работает, в разделе Вопросы от ваших агентов. Чтобы они приходили на ноутбук, выполните на том компьютере antenna agent escalate api-dev --to mac: тогда каждый вопрос придёт в чат агента, и вы ответите прямо в чате.

Собственный запрос разрешения Claude Code («Do you want to proceed?») остаётся в его терминале: Antenna никогда ничего в него не вводит. Инструменты, которыми вы пользуетесь постоянно, разрешите в настройках Claude Code или отвечайте на этот запрос через antenna session attach.

Настройка

  1. Установите Antenna на оба компьютера и один раз свяжите их с отметкой Это мой собственный компьютер (∞), как в инструкции Claude Code на VPS.
  2. Запустите Claude Code через Antenna. На настольном компьютере: Агенты → ИИ-приложения → Запустить в режиме «Код». На сервере: 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
  3. На компьютере, где работает Claude Code, разрешите ответы с того компьютера, с которого будете одобрять: Мои устройства → карточка того компьютера → Одобрения → Разрешить одобрения, подписанные: …, с вашим паролем. На сервере: antenna devices confirm mac.

Отвечайте с любого компьютера

Запрос появляется в карточке спрашивающего компьютера в разделе Мои устройства (экспериментально) вместе с уведомлением вроде «Antenna: нужно одобрение на Mac mini». В карточке видно, какой агент спрашивает, о чём и почему, и приведён его текст — кроме текста с секретом: такой текст никогда не покидает компьютер, который спросил. Нажмите Одобрить по Touch ID на Mac (экспериментально), Одобрить паролем — с паролем компьютера, за которым вы сейчас, или Отклонить.

Спросивший компьютер сверяет подпись с ключами, которые вы на нём разрешили, со своим одноразовым challenge и именно с этим запросом, а потом выполняет запрос сам, один раз. На самом этом компьютере запрос виден в разделе Запросы на одобрение, а в терминале — через antenna approvals и antenna approve <id>.

Claude Code ждёт до 50 секунд, и шаг, одобренный за это время, выполняется сразу. Если позже, он берётся за другую работу, а когда вы одобрите, Antenna введёт в его строку ввода «Approved — continue.», и он выполнит шаг заново.

Если никто не ответил

Запрос закрывается через 10 минут: ничего не выполняется и не отправляется, а Claude Code узнаёт, что одобрения не было. Незадолго до этого вас предупредит уведомление. После Отклонить, для чего пароль не нужен, Claude Code узнаёт, что вы ответили «нет».

Агент, который одобряет за вас

Экспериментально. Кнопка Может одобрять за вас… в разделе Агенты позволяет агенту, которому вы доверяете, отвечать на запросы других ваших агентов о сообщениях и файлах, и его ответ засчитывается, только если всё, чего касается запрос, находится на уровне ∞. Команды и правки всегда приходят к вам.

Вопросы

Работает ли это с Codex?

Частично. То, что Codex отправляет через Antenna, проверяется так же, и эти запросы приходят на все ваши компьютеры, а собственные команды Codex по-прежнему одобряются в его терминале его же средствами.

Может ли одобрить любой компьютер?

Нет. Только компьютер, который вы связали как свой собственный и чьи ключи разрешили на спрашивающем компьютере, и только с паролем. Если компьютер потерян, нажмите Отозвать этот компьютер на каждом из остальных.

Можно ли одобрять с телефона?

Пока нет. Сейчас Antenna работает на macOS и Linux.
