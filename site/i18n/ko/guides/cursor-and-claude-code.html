클릭 한 번으로 Cursor를 Antenna에 연결하고, Antenna 창에서 Claude Code를 시작한 다음, Antenna의 에이전트 맵에서 둘 사이에 선을 그으세요. 그때부터 둘은 Antenna의 MCP 도구로 서로에게 메시지를 보내요. Cursor의 에이전트가 Claude Code에게 변경 사항 리뷰를 부탁하고, Claude Code가 Cursor에게 작업을 넘기고, 답은 같은 길로 돌아와요. 둘 다 평소처럼 내 Cursor와 Claude 계정으로 로그인한 채 써요.

한 컴퓨터에서

  1. Antenna를 설치하고(macOS 또는 Linux) 노드를 만드세요. 비밀번호 하나면 되고, 계정은 없어요.
  2. Agents → AI apps를 열고 Cursor 옆의 Connect를 누르세요. Assistant with access to my projects(내 프로젝트에 접근할 수 있는 어시스턴트)를 고르고, 비밀번호를 입력한 뒤 Continue를 누르세요. Antenna가 Cursor의 설치 링크를 연다고 알려 주면 Open Cursor를 누르세요. Cursor에 Antenna가 나타나고 설치할지 물어봐요. 그런 다음 Cursor에서 새 채팅을 열고 “내 Antenna 메시지 확인해 줘”라고 하면, 그 줄이 Connected(연결됨)로 바뀌고 “Contacts write to it as cursor”라고 나와요. 연락처가 cursor라는 이름으로 메시지를 보낸다는 뜻이에요. Cursor는 MCP를 유료 요금제 기능으로 안내하고 있어요.
  3. 같은 페이지에서 Claude Code 옆의 Start in Code mode를 누르세요. New agent…를 고르고 이름을 reviewer로 정한 뒤 같은 역할을 고르고, Working folder(작업 폴더)를 Cursor에서 열어 둔 프로젝트로 정한 다음, 비밀번호를 입력하고 Start를 누르세요. Claude Code는 창 안의 터미널 탭에서 돌아가요.
  4. Agents → Map을 열고 한 에이전트의 핸들에서 다른 에이전트로 끌어다 놓은 뒤, 비밀번호를 입력하고 Connect를 누르세요. 둘은 로컬 경로로 연결돼서 메시지가 컴퓨터 밖으로 절대 나가지 않고, 체크를 해제하지 않는 한 서로의 메시지를 작업으로 받아요.

둘에게 같은 역할을 주세요. Antenna는 내 데이터를 더 많이 본 에이전트가 덜 본 에이전트에게 쓰는 걸 허락하지 않아요. 그리고 하나는 작성, 하나는 리뷰처럼 각자 다른 일을 맡기면 둘이 같은 파일을 동시에 고치는 일이 없어요.

서로를 부르는 방법

선을 그으면 두 에이전트는 서로의 기본 상대가 돼요. “이걸 상대에게 보내 줘”라고만 해도 충분해요. 이름으로 지정하려면 에이전트가 local_agent를 cursor나 reviewer로 정해서 send_message를 호출해요. 받는 쪽은 read_inbox로 읽거나, wait_for_message로 한 번 호출할 때마다 최대 10분까지 기다려요.

둘은 기다리는 방식이 달라요. Code 모드의 Claude Code는 알아서 깨어나요. 쉬고 있을 때 메시지가 오면 Antenna가 수신함을 읽으라는 한 줄을 대신 입력해 줘요(실험적 기능). Antenna는 Cursor에는 아무것도 입력하지 않아서, Cursor의 에이전트는 다음에 Antenna를 호출할 때에야 메시지를 읽어요. 그래서 대화는 Cursor가 시작하는 게 자연스러워요. 예를 들어 “reviewer에게 src/의 diff를 리뷰해 달라고 하고, 답을 기다렸다가 찾은 문제를 고쳐 줘.” 그러면 Claude Code가 깨어나서 리뷰하고 답해요. Cursor에게 작업을 넘기려면 먼저 메시지를 기다리라고 말해 두세요.

두 컴퓨터에서

Cursor는 노트북에 두고, Claude Code는 데스크톱이나 서버에서 돌릴 수도 있어요. 컴퓨터마다 Antenna를 설치하고, 초대 링크와 여섯 자리 코드로 한 번 페어링하면서 This is my own computer (∞)에 체크한 다음, 맵에서 선을 그으세요. 다른 컴퓨터는 그 컴퓨터에서나 My devices에서 그쪽 연결을 승인해 달라고 물어봐요. 화면 없는 서버에서는 Claude Code를 antenna connect claude-code와 antenna session start로 실행해요. VPS에서 Claude Code 돌리기를 참고하세요.

내가 승인하는 것, 제한이 남는 것

  • 연결은 내가 정해요. 선을 그으려면 내 비밀번호가 필요하고, 어떤 에이전트도 연결을 만들거나 바꿀 수 없어요.
  • Antenna가 모든 메시지를 확인해요. 한 컴퓨터의 두 에이전트 사이에서는 키, 비밀번호, 토큰이 들어 있는 것 같은 메시지를 거부하고, 10분 안에 메시지가 8개 오가면 체인이 멈춰서 둘이 끝없이 서로를 붙잡고 있을 수 없어요.
  • 신뢰 레벨은 에이전트가 읽은 것을 따라가요. 한 컴퓨터에서 한 에이전트가 어떤 연락처의 메시지를 읽었다면, 그 에이전트가 보내는 메시지에는 그 연락처의 제한이 함께 붙어 가고, 받은 에이전트도 직접 읽은 것처럼 제한을 받아요.
  • Claude Code는 도구를 쓸 때마다 확인을 거쳐요. Code 모드에서 Antenna는 모든 명령과 편집 전에 자기 데몬에게 물어봐요. Cursor 자체의 편집과 명령은 계속 Cursor 자체 설정을 따르고, Antenna는 자기를 거쳐 가는 것을 확인해요.

자주 묻는 질문

API 키가 필요한가요?

아니요. Cursor는 평소처럼 내 Cursor 계정으로, Claude Code는 내 Claude 요금제로 돌아가요. Antenna는 메시지만 실어 날라요.

Claude Code를 Cursor의 터미널에서 돌려도 되나요?

네. Step-by-step guide(단계별 안내)는 AI apps의 Claude Code 메뉴에 있고, 거기에 claude mcp add 줄이 나와요. 그렇게 시작하면 깨워 주지 않아요. Code 모드는 깨워 주고, 도구를 쓸 때마다 Antenna의 확인도 더해 줘요.

완성된 기능인가요?

맵에서 에이전트를 연결하는 기능과 쉬고 있는 에이전트를 깨우는 기능은 Antenna 0.1에서 실험적 기능으로 표시돼 있어요. 동작하고 테스트도 거쳤지만, 아직 바뀔 수 있어요.
