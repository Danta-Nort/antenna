Antenna에서 팀은 하나의 git 프로젝트에서 일하는 리드 에이전트와 워커들이에요. 예산을 한 번 정해 두면(예: “Claude Code 코더 최대 2명”), 리드가 일을 작업으로 나누고, 예산 안에서 워커를 띄우고, 결과마다 검토해서 돌려보내거나 받아들여요. 워커는 각자의 샌드박스에서, 각자의 프로젝트 사본으로 병렬로 코딩하고, 팀의 작업은 내가 승인해야만 내 브랜치에 들어가요. 실험적 기능이에요.

한 폴더에 에이전트 여럿을 두면 생기는 문제

Claude Code 세션 두세 개를 나란히 띄우는 건 쉬워요. 서로 발을 밟지 않게 하는 게 어렵죠. 같은 파일을 고치고, 같은 폴더에서 명령을 실행하고, 각자 다른 세션이 읽을 수 있는 건 전부 읽을 수 있어요. 누군가는 작업을 나눠 주고, 돌아온 결과를 확인하고, 병합해야 하는데, 보통 그게 터미널 사이를 오가는 나예요.

팀은 이렇게 일해요

  1. 팀을 만들어요. Teams → New team에서 프로젝트 폴더, 리드(내 에이전트 중 하나, 로컬 모델, 또는 나), 워커 예산, 그리고 규칙을 정해요. 워커가 명령을 실행해도 되는지, 작업에 어떤 Check commands(검사 명령, 예: cargo test, npm test)를 지정할 수 있는지, 그 검사가 어떤 패키지 레지스트리에 접근할 수 있는지요.
  2. 리드에게 목표를 알려 줘요. 리드의 터미널에서: “로그인 기능을 코더 두 명이 할 작은 작업들로 나눠 줘.”
  3. 리드가 계획하고 인원을 꾸려요. 작업을 작성하고, 예산 안에서 web.coder-1 같은 워커를 띄우고, 작업을 맡겨요.
  4. 워커들이 병렬로 코딩해요. 각자 팀 브랜치 기준의 새 프로젝트 사본을 받고, 자기 작업만 읽고, 일하고, 제출해요. 막히면 리드에게 질문하고요.
  5. Antenna가 모든 결과를 검사해요. 작업에 지정된 검사 명령을 별도의 샌드박스에서 실행해요. 이 샌드박스에는 토큰이 없고, 지정한 레지스트리 외에는 네트워크도 없어요. 검사에 실패하면 리드가 판단하기 전에, 정해진 횟수까지 자동으로 워커에게 되돌아가요.
  6. 리드가 검토해요. 받아들이거나, 코멘트를 달아 돌려보내요. 받아들인 작업은 팀 브랜치 antenna/web에 쌓여요.
  7. 내가 적용해요. Review and apply(검토 후 적용)에서 내 브랜치에 무엇이 병합될지 보여 주고, 비밀번호를 입력하면 fast-forward로 병합돼요. 비밀번호 없이는 아무것도 움직이지 않아요.

화면에서 보이는 것

팀 보드에는 모든 작업이 상태별로 나와요. Open, Working부터 In review, Blocked, Accepted, Applied까지요. 워커마다 실시간 출력, 결과가 바꾸는 내용, 검사 출력, 사용한 토큰도 함께 보여요. 리드가 할 수 있는 건 나도 다 할 수 있어요. 워커의 질문에 답하고, 수정을 요청하고, 작업을 취소하거나 워커를 멈출 수 있어요. 리드가 Antenna의 Code 모드에서 돌고 있으면, 워커가 제출하거나 질문할 때마다 리드가 깨어나서 내가 자리를 비워도 팀은 계속 움직여요.

프로젝트를 지키는 장치

  • 워커는 내 폴더를 절대 보지 못해요. 다른 파일도, 다른 워커의 사본도 볼 수 없고, 연결할 수 있는 곳은 모델 제공자뿐이에요.
  • 리드는 자기 예산을 늘릴 수 없어요. 나 대신 무언가를 승인하거나 워커의 토큰을 볼 수도 없어요. 모든 호출은 모델이 아니라 Antenna가 결정해요.
  • 신뢰할 수 없는 입력은 갇혀 있어요. 레벨 2 연락처의 메시지를 읽은 뒤 작성된 작업은 명령도, 검사도 실행하지 않아요. 그래서 그 메시지에 몰래 끼워 넣은 지시가 내 컴퓨터에 닿을 수 없어요.
  • 원하면 로컬 전용으로. 팀이 내 컴퓨터에서 도는 모델만 쓰도록 제한해서, 클라우드 모델을 전혀 쓰지 않게 할 수도 있어요.

자주 묻는 질문

어떤 에이전트가 워커가 될 수 있나요?

내 로그인으로 쓰는 Claude Code, Claude Code의 stream-json을 쓰는 다른 프로그램, 또는 분류, 요약, 문서 작업처럼 가벼운 역할이라면 로컬 모델도 돼요.

리드를 Codex나 다른 앱으로 할 수 있나요?

Antenna에 연결된 내 에이전트라면 무엇이든 리드가 될 수 있어요. 앱을 다음에 시작할 때 MCP로 팀 도구를 받아요. 보드에서 내가 직접 팀을 이끌 수도 있어요.

비용은 어떻게 제한하나요?

예산이 종류별 워커 수의 상한을 정하고, 규칙이 한 턴과 한 번의 검사에 걸리는 시간, 작업 하나가 쓸 수 있는 토큰의 상한을 정해요.

Mac에서도 되나요?

네, macOS와 Linux에서 돼요. 워커는 팀이 있는 컴퓨터에서 돌아요. 다른 컴퓨터의 워커는 나중에 지원할 예정이에요.
