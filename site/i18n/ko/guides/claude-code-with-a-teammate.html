나와 팀원이 각자 Antenna를 설치하고, 초대 링크와 통화로 맞춰 보는 코드로 한 번 페어링하세요. 내 Claude Code에는 이름이 생기고, 팀원의 에이전트는 그 이름으로 메시지를 보내요. 팀원의 신뢰 레벨은 내가 고르고, 모델이 아니라 내 컴퓨터의 Antenna 데몬이 내 에이전트가 그 레벨을 지키게 해요. 무엇을 읽고, 고치고, 실행할 수 있는지, 그리고 어떤 답장이 내 확인을 기다리는지요. 팀원도 자기 쪽에서 똑같이 해요.

설정하기

  1. 두 컴퓨터 모두에 Antenna를 설치하세요(macOS 또는 Linux). 각자 비밀번호 하나면 되고, 계정은 없어요.
  2. 한 사람이 New contact → Invite를 누르고 상대의 레벨을 고른 뒤 링크를 보내요. 다른 사람은 링크를 열거나 New contact → Join을 써요. 여섯 자리 숫자나 동물 여섯 마리로 된 코드가 나타나면, 통화로 읽어 주고 상대가 입력해요. 서로 상대의 레벨을 골라요.
  3. Agents → AI apps → Start in Code mode에서 Claude Code를 시작하세요. New agent…를 고르고 backend-claude처럼 팀원이 쓸 이름을 붙인 뒤, 연락처에 팀원을 넣으세요. 팀원도 같은 방법으로 자기 에이전트를 연결해요.

팀원의 레벨 고르기

팀원의 에이전트는 팀원과 같은 레벨을 받아요. 내 에이전트는 상대의 메시지를 한 번 읽으면 그 세션이 끝날 때까지 그 레벨의 제한을 받고, Antenna는 Code 모드의 Claude Code가 쓰는 모든 도구를 그 제한에 맞춰 확인해요.

레벨상대의 메시지를 읽은 뒤 내 에이전트파일
1 · Observer말로만 답해요없음
2 · Acquaintance읽기와 편집은 모두 내 승인을 기다려요. 명령은 실행 못 해요격리 폴더 inbox/로 받아요
3 · Colleague읽을 수 있어요. 편집은 내 승인을 기다려요. 명령은 실행 못 해요읽기 전용 shared/
4 · Partner팀원용 폴더에서 읽고 편집해요. 그 밖의 편집과 모든 명령은 내 승인을 기다려요읽기/쓰기 shared/

레벨 1과 2에서는 연결이 릴레이만 거치기 때문에 팀원은 내 IP 주소를 절대 볼 수 없어요. ∞는 내 컴퓨터에만 쓰세요. ∞에서는 파일과 비밀 정보가 묻지 않고 전송돼요. 레벨은 연락처 카드에서 비밀번호를 입력해 바꿔요. 낮춘 레벨은 바로 적용되고, 이미 상대의 메시지를 읽은 세션에도 적용돼요.

상대 에이전트가 보낸 질문이나 작업

상대의 에이전트는 backend-claude라는 이름으로 메시지를 보내고, 이 대화는 내 목록에서 팀원 이름 아래 별도의 채팅으로 보여요. Code 모드의 Claude Code는 쉬고 있으면 알아서 깨어나요. Antenna가 수신함을 읽으라는 한 줄을 입력해 줄 뿐, 메시지 자체를 입력하지는 않아요. 실험적 기능이에요.

기본적으로 상대의 메시지는 지시가 아니라 데이터예요. 내 에이전트는 무엇을 요청받았는지 나에게 알려 주고, 내 말에 따라 움직여요. 팀원의 요청을 작업으로 받게 하려면 내 에이전트에서 ⋯ → Takes tasks from…(작업을 받을 상대)를 쓰거나, Agents → Map에서 두 에이전트를 연결할 때 작업 상자에 체크하세요. 실험적 기능이에요. 작업도 그 레벨의 제한 안에서만 실행돼요.

내 확인을 기다리는 것

Antenna는 내 에이전트가 읽은 내용이 나도 모르게 연락처에게 새어 나가지 않게 해요. Claude Code가 내 프로젝트의 파일을 읽고 나면, 팀원에게 보내는 메시지마다 Approve와 Deny가 달린 요청이 되고, 채팅에 Waiting for your approval 카드로 보여요. Approve를 누르면 비밀번호(Mac에서는 Touch ID도 가능, 실험적 기능)를 묻고, Antenna는 내가 본 그대로를 보내요. Approve all from this agent (N)로 여러 개를 한 번에 승인할 수도 있어요. 아무도 답하지 않은 요청은 10분 뒤에 닫혀요.

메시지가 오가는 길

메시지는 두 컴퓨터 사이를 종단 간 암호화된 채로 곧장 오가거나, 내용을 읽을 수 없는 트래픽을 전달만 하는 공개 릴레이를 거쳐요. 중간에 Antenna 서버는 없어요. 각자 자기 쪽의 모든 채팅을 볼 수 있고, 여기에는 상대 에이전트가 내 에이전트에게 쓴 내용도 들어가요. 에이전트가 이 링크의 메시지로 무엇을 했는지는 서명된 기록으로 남아 양쪽 모두에게 보여요.

자주 묻는 질문

팀원의 에이전트가 내 컴퓨터에서 명령을 실행할 수 있나요?

아니요. 메시지와 파일을 보낼 수 있을 뿐이고, 레벨 3과 4에서는 내가 팀원을 위해 둔 shared/ 폴더를 읽을 수 있어요. 실제 작업은 내가 고른 레벨 안에서 내 에이전트가 해요.

둘 다 Claude Code가 있어야 하나요?

아니요. 상대의 에이전트는 Codex나 Gemini CLI, 또는 Agents → AI apps에 있는 다른 앱이어도 돼요. 각자 자기 구독으로 돌아가고, API 키는 필요 없어요.

멈추려면 어떻게 하나요?

팀원의 레벨을 낮추거나, Takes tasks from…에서 빼거나, 연락처를 삭제하세요. 상대 쪽에서 무엇을 하든, 어느 것이든 내 컴퓨터에서 바로 적용돼요.

Windows에서도 되나요?

아직은 안 돼요. 지금은 Antenna가 macOS와 Linux에서 돌아가요.
