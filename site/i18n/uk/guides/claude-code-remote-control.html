Встановіть Antenna на ноутбук і на комп’ютер, де працює Claude Code, один раз з’єднайте їх як власні комп’ютери й запустіть там Claude Code через Antenna. На ноутбуці з’явиться чат із цією сесією: напишіть у нього завдання, Antenna розбудить Claude Code, коли той простоює, і його відповідь повернеться в чат. Повідомлення йдуть прямим з’єднанням між вашими двома комп’ютерами з наскрізним шифруванням, акаунт для Antenna не потрібен, а кроки, яким потрібне ваше схвалення, приходять на ноутбук, і ви відповідаєте паролем.

Remote Control у самому Claude Code і Antenna

У Claude Code є власна вбудована функція Remote Control; її описано в документації Anthropic. Цей посібник — про іншу схему: Claude Code працює на вашому комп’ютері, який завжди ввімкнений, сервері чи десктопі, а ви керуєте ним з Antenna на ноутбуці. Вона підійде вам, якщо ви хочете:

  • Кілька сесій на кількох комп’ютерах в одному списку. У кожної сесії свій чат, а розділ Мої пристрої показує стан кожного комп’ютера, його агентів і запити, що там чекають.
  • Власне з’єднання. Повідомлення шифруються на одному комп’ютері й розшифровуються на іншому. Ваші комп’ютери з’єднуються напряму, якщо дозволяє мережа, а інакше — через ретранслятор, який пересилає лише зашифрований трафік. Без акаунта й без вхідного порту.
  • Дозволи, які перевіряє демон Antenna на комп’ютері, де працює Claude Code, а схвалювати можна з будь-якого вашого комп’ютера, за яким ви зараз.
  • Інших агентів так само: Codex працює так само, як Claude Code.

Налаштування

  1. Встановіть Antenna на обидва комп’ютери: застосунок на ноутбук (macOS чи Linux), а на інший комп’ютер — застосунок або, якщо це Linux-сервер, вузол: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
  2. Один раз з’єднайте їх. На ноутбуці: Новий контакт → Запросити, поставте позначку Це мій власний комп’ютер (∞), натисніть Створити посилання і скопіюйте посилання. На сервері: antenna join '<link>' --trust 5 --label mac; на десктопі: Новий контакт → Приєднатися, з тією самою позначкою. Введіть на одній стороні код, який показує інша, і натисніть на ноутбуці Контакт підтвердив — коди збігаються.
  3. Запустіть Claude Code через Antenna на іншому комп’ютері. На сервері — в теці проєкту (потрібен tmux): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Дайте відповідь на перші запитання Claude Code і вийдіть через Ctrl-b d: він працюватиме далі, а на ноутбуці з’явиться чат api-dev. На десктопі: Агенти → ШІ-застосунки → Запустити в режимі Code, і Claude Code працюватиме там у вкладці вікна Antenna; один раз попросіть його привітатися з вашим ноутбуком через Antenna, і його чат з’явиться на ноутбуці.
  4. Дозвольте ноутбуку відповідати на запити на схвалення з того комп’ютера. На сервері: antenna devices confirm mac. На десктопі: Мої пристрої → картка ноутбука → Схвалення → Приймати схвалення, підписані за допомогою …, з вашим паролем.

Керуйте ним з ноутбука

  • Давайте завдання. Пишіть у чат сесії так само, як людині. Коли Claude Code простоює на своєму запрошенні командного рядка, Antenna друкує один вбудований рядок, щоб він прочитав ваше повідомлення; ваш текст вона ніколи не друкує в термінал і ніколи не відповідає на запитання, яке Claude Code там ставить. Експериментальна функція.
  • Переривайте. Перед надсиланням увімкніть Терміново: перервати зараз: Antenna один раз натисне Esc, щоб завершити поточний хід, — але ніколи поверх відкритого там запитання чи запиту дозволу, — і Claude Code прочитає ваше повідомлення. Експериментальна функція.
  • Схвалюйте його кроки. Крок, для якого потрібні ви, з’являється в картці іншого комп’ютера в розділі Мої пристрої разом зі сповіщенням. Натисніть Схвалити паролем, Схвалити через Touch ID на Mac або Відхилити. Експериментальна функція.
  • Зупиняйте. Зупинити агента та його процеси… поруч з агентом у цій картці завершує Claude Code і все, що він там запустив. Експериментальна функція.

Власний запит дозволу Claude Code («Do you want to proceed?») лишається в його терміналі на іншому комп’ютері, і Antenna на нього ніколи не відповідає. Інструменти, якими ви користуєтеся постійно, дозвольте в налаштуваннях Claude Code або відповідайте на цей запит через antenna session attach.

Codex та інші агенти

З Codex усе так само: antenna connect codex і --cli codex на сервері або Запустити в режимі Code поруч із Codex на десктопі (див. Віддалене керування Codex CLI). Gemini CLI підключається в розділі Агенти → ШІ-застосунки й надсилає та читає повідомлення через Antenna, але будити його Antenna поки не вміє: нове повідомлення він прочитає, коли наступного разу звернеться до Antenna.

Запитання

Чи видно термінал Claude Code на ноутбуці?

Ні. Завдання ви даєте й відповіді читаєте в чаті; термінал лишається на іншому комп’ютері. Щоб зазирнути в нього, виконайте там antenna session attach, за бажання — через SSH.

Чи потрібні іншому комп’ютеру публічна IP-адреса чи відкриті порти?

Ні. Обидва комп’ютери самі підключаються назовні — напряму, якщо дозволяє мережа, а інакше через ретранслятор. Ретранслятор пересилає лише зашифрований трафік.

Хто ще може давати йому завдання?

Лише контакти, з’єднані з тим комп’ютером, чиї повідомлення агентові дозволено читати (з --links mac — лише ваш ноутбук), і агенти, яких ви з’єднаєте з ним на мапі агентів. Що повідомлення контакту може змусити його зробити, вирішує демон Antenna на тому комп’ютері, а не Claude Code, — за рівнем довіри цього контакту.

Чи потрібен API-ключ?

Ні. Claude Code зберігає ваш власний вхід на комп’ютері, де працює, а Antenna лише передає повідомлення, файли й схвалення.

Чи можна керувати ним з телефона?

Ще ні. Наразі Antenna працює на macOS і Linux.
