Підключіть Cursor до Antenna одним кліком, запустіть Claude Code у вікні Antenna й проведіть між ними лінію на мапі агентів Antenna. Відтоді вони пишуть одне одному через MCP-інструменти Antenna: агент Cursor просить Claude Code переглянути зміну, Claude Code передає Cursor завдання, а відповідь повертається тим самим шляхом. Обидва працюють із вашими власними входами в Cursor і Claude.

На одному комп’ютері

  1. Встановіть Antenna (macOS чи Linux) і створіть свій вузол: один пароль, без акаунта.
  2. Відкрийте Агенти → ШІ-застосунки і натисніть Підключити навпроти Cursor. Виберіть Асистент із доступом до моїх проєктів, введіть пароль і натисніть Продовжити. Antenna попередить, що відкриє посилання для встановлення в Cursor; натисніть Відкрити Cursor, і Cursor покаже Antenna та попросить її встановити. Потім почніть у Cursor новий чат і попросіть «Перевір мої повідомлення в Antenna»: рядок зміниться на Підключено, і в ньому з’явиться «Контакти пишуть йому як cursor». MCP у Cursor указано в платному тарифі.
  3. На тій самій сторінці натисніть Запустити в режимі Code навпроти Claude Code. Виберіть Новий агент…, назвіть агента reviewer, виберіть ту саму роль, у полі Робоча тека вкажіть проєкт, відкритий у Cursor, введіть пароль і натисніть Запустити. Claude Code працюватиме у вкладці термінала всередині вікна.
  4. Відкрийте Агенти → Мапа, протягніть лінію від маркера одного агента до іншого, введіть пароль і натисніть З’єднати. Обидва отримають локальний маршрут: їхні повідомлення ніколи не залишають комп’ютер, і кожен приймає повідомлення іншого як завдання, якщо ви не знімете цю галочку.

Дайте обом ту саму роль: Antenna не дозволяє агентові, який бачив більше ваших даних, писати агентові, який бачив менше. І дайте кожному свою роботу, наприклад один пише код, а інший його перевіряє, щоб вони не редагували один файл одночасно.

Як вони звертаються одне до одного

Коли лінію проведено, кожен агент стає для іншого співрозмовником за замовчуванням: досить сказати «надішли це своєму співрозмовникові». Щоб назвати іншого на ім’я, агент викликає send_message, указавши в local_agent cursor або reviewer. Отримувач читає повідомлення через read_inbox або чекає на них через wait_for_message, до 10 хвилин за один виклик.

Чекають вони по-різному. Claude Code у режимі Code прокидається сам: коли надходить повідомлення, а він простоює, Antenna друкує за нього один рядок із проханням прочитати вхідні (експериментально). У Cursor Antenna ніколи нічого не друкує, тож агент Cursor читає повідомлення лише тоді, коли наступного разу звертається до Antenna. Тому природніше починати обмін із Cursor: «Попроси reviewer переглянути diff у src/, потім дочекайся відповіді й виправ те, що він знайде». Claude Code прокинеться, перегляне й відповість. Щоб передати роботу Cursor, спершу скажіть йому чекати на повідомлення.

На двох комп’ютерах

Cursor може залишитися на ноутбуці, а Claude Code працювати на десктопі чи сервері. Встановіть Antenna на кожен і один раз з’єднайте їх посиланням-запрошенням і шестизначним кодом, позначивши Це мій власний комп’ютер (∞), а потім проведіть лінію на мапі. Інший комп’ютер попросить вас схвалити свою частину, там само або в розділі Мої пристрої. На сервері без екрана Claude Code запускається через antenna connect claude-code і antenna session start: дивіться Claude Code на VPS.

Що схвалюєте ви і що лишається обмеженим

  • З’єднання — тільки ваші. Щоб провести лінію, потрібен ваш пароль; жоден агент не може створити чи змінити з’єднання.
  • Antenna перевіряє кожне повідомлення. Між двома агентами одного комп’ютера повідомлення, схоже на таке, що містить ключ, пароль чи токен, відхиляється, а ланцюжок зупиняється після 8 повідомлень за 10 хвилин, тож два агенти не можуть без кінця займати одне одного.
  • Рівень довіри йде за тим, що прочитав агент. Якщо на одному комп’ютері агент прочитав повідомлення від контакту, його власне повідомлення переносить обмеження цього контакту на іншого агента, і той обмежений так, ніби теж його прочитав.
  • Claude Code перевіряється перед кожним інструментом. У режимі Code Antenna питає свій демон перед кожною командою й кожною правкою. Власні правки й команди Cursor лишаються під налаштуваннями самого Cursor; Antenna перевіряє те, що проходить через неї.

Запитання

Чи потрібен для цього API-ключ?

Ні. Cursor працює через ваш акаунт Cursor, а Claude Code — через ваш тариф Claude, як завжди. Antenna лише передає повідомлення.

Чи можна натомість запустити Claude Code в терміналі Cursor?

Так: Покрокова інструкція у меню Claude Code в розділі ШІ-застосунки дає рядок claude mcp add. Запущеного так Claude Code Antenna не будить; режим Code будить його й додає перевірку Antenna перед кожним інструментом.

Це вже готово?

З’єднання агентів на мапі й пробудження агентів, що простоюють, в Antenna 0.1 позначено як експериментальні: вони працюють і протестовані, але ще можуть змінитися.
