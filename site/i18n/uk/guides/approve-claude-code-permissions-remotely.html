Запустіть Claude Code через Antenna — у режимі Code у вікні або командою antenna session на сервері, — і демон Antenna перевірятиме кожен інструмент, яким він користується, і кожне повідомлення, яке він надсилає. Коли для кроку потрібні ви, крок стає запитом на підтвердження: він зі сповіщенням з’являється в розділі My devices (мої пристрої) на кожному комп’ютері, який ви з’єднали як власний. Підтвердьте його там паролем цього комп’ютера або Touch ID: комп’ютер, де працює Claude Code, перевірить вашу відповідь і виконає крок, а Claude Code продовжить роботу.

Що приходить до вас

  • Кроки після читання повідомлення контакту. Щойно Claude Code прочитав повідомлення колеги, рівень довіри колеги визначає, що агентові можна: на рівні 4 кожна команда чекає на вас; на рівнях 2 і 3 на вас чекає кожна правка, а команди відхиляються.
  • Зміни його власних налаштувань. Після читання повідомлення будь-якого контакту, навіть із вашого власного ноутбука, правки CLAUDE.md, .claude/, профілів оболонки, ключів і файлів збирання на кшталт package.json чекають на вас.
  • Повідомлення, що винесли б ваші дані. Щойно він прочитав файли вашого проєкту, кожне його повідомлення контакту нижче ∞ чекає на вас, як і будь-яке повідомлення такому контакту, що, схоже, містить ключ, пароль чи токен. Якщо він прочитав одне листування, повідомлення в інше теж чекає.
  • Запитання. Експериментальна функція. Запитання агента з’являються на комп’ютері, де він працює, у розділі Questions from your agents (запитання від ваших агентів). Щоб натомість отримувати їх на ноутбуці, виконайте на тому комп’ютері antenna agent escalate api-dev --to mac: тоді кожне запитання приходитиме в чат агента, і ви відповідатимете в чаті.

Власний запит дозволу Claude Code («Do you want to proceed?») лишається в його терміналі: Antenna ніколи нічого туди не вводить. Інструменти, якими ви користуєтеся постійно, дозвольте в налаштуваннях Claude Code або відповідайте на цей запит через antenna session attach.

Налаштування

  1. Встановіть Antenna на обидва комп’ютери й один раз з’єднайте їх із позначкою This is my own computer (∞) (це мій власний комп’ютер), як у посібнику Claude Code на VPS.
  2. Запустіть Claude Code через Antenna. На десктопі: Agents → AI apps → Start in Code mode. На сервері: 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
  3. На комп’ютері, де працює Claude Code, дозвольте відповіді з того комп’ютера, з якого ви підтверджуватимете: My devices → картка того комп’ютера → Approvals (підтвердження) → Accept approvals signed with … (приймати підтвердження, підписані…), з вашим паролем. На сервері: antenna devices confirm mac.

Відповідайте з будь-якого комп’ютера

Запит з’являється в картці комп’ютера, що питає, у розділі My devices (експериментально), разом зі сповіщенням на кшталт «Antenna: approval needed on Mac mini». У картці видно, який агент питає, про що й чому, і наведено його текст — крім тексту із секретом: такий текст ніколи не залишає комп’ютер, який спитав. Натисніть Approve with Touch ID на Mac (експериментально), Approve with password з паролем комп’ютера, за яким ви зараз, або Deny (відхилити).

Комп’ютер, який спитав, звіряє підпис із ключами, які ви на ньому прийняли, зі своїм одноразовим challenge і саме з цим запитом, а потім сам виконує запит, один раз. На самому цьому комп’ютері запит видно в розділі Approval requests (запити на підтвердження), а в терміналі — через antenna approvals і antenna approve <id>.

Claude Code чекає до 50 секунд, і крок, підтверджений за цей час, виконується одразу. Якщо пізніше, він береться за іншу роботу, а коли ви підтвердите, Antenna введе в його рядок введення «Approved — continue.», і він виконає крок знову.

Якщо ніхто не відповів

Запит закривається через 10 хвилин: нічого не виконується й не надсилається, а Claude Code дізнається, що ніхто його не підтвердив. Незадовго до цього вас попередить сповіщення. Після Deny, для якого пароль не потрібен, Claude Code дізнається, що ви відповіли «ні».

Агент, який підтверджує за вас

Експериментальна функція. Can approve for… (може підтверджувати за…) у розділі Agents дозволяє агентові, якому ви довіряєте, відповідати на запити інших ваших агентів щодо повідомлень і файлів, і його відповідь зараховується, лише якщо все, чого стосується запит, перебуває на рівні ∞. Команди й правки завжди приходять до вас.

Запитання

Чи працює це з Codex?

Частково. Те, що Codex надсилає через Antenna, перевіряється так само, і ці запити приходять на всі ваші комп’ютери, а власні команди Codex і далі підтверджуються в його терміналі його ж засобами.

Чи може підтвердити будь-який комп’ютер?

Ні. Лише комп’ютер, який ви з’єднали як власний і чиї ключі прийняли на комп’ютері, що питає, і лише з паролем. Якщо комп’ютер загубився, натисніть Revoke this computer (відкликати цей комп’ютер) на кожному з інших.

Чи можна підтверджувати з телефона?

Ще ні. Наразі Antenna працює на macOS і Linux.
