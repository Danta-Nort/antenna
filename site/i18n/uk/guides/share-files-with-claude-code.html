На тому самому комп’ютері Claude Code читає ваші файли напряму: дайте йому шлях або перетягніть файл у його термінал. На інший комп’ютер, наприклад сервер, надсилайте файл через Antenna: перетягніть його в чат із цією сесією Claude Code, Antenna перевірить його після отримання й збереже там у теці з’єднання, а агент отримає у вхідних назву файлу, його розташування, розмір і SHA-256. Файли, які агент надсилає у відповідь, так само приходять на ваш ноутбук.

Як надіслати файл агентові

  1. З’єднайте ноутбук з іншим комп’ютером як із власним (∞) і підключіть Claude Code на ньому до Antenna: див. Claude Code на VPS.
  2. Відкрийте на ноутбуці чат із сесією й перетягніть туди файл або прикріпіть його, як у будь-якому месенджері.
  3. На іншому комп’ютері Antenna визначає тип файлу за вмістом, шукає загрози й секрети та зберігає файл у теці з’єднання, ~/Antenna/links/<folder>/shared/, або в теці проєкту, яку ви вибрали для цього комп’ютера.
  4. Агент сам дізнається про збережений файл із наступної перевірки вхідних — разом із шляхом і хешами — і може використати його на наступному кроці.

Як отримувати файли від агента

Агент може надіслати вам файл, збірку, звіт чи знімок екрана тими самими інструментами, якими надсилає повідомлення. Файл приходить у ваш чат і в Файли як картка з назвою, тим, що помітила перевірка, і хешем. Зображення показуються як перевірений безпечний попередній перегляд, який Antenna перебудовує сама.

Що перевіряється і що чекає на вас

  • Між вашими власними комп’ютерами звичайні файли зберігаються самі. Усе, що може запускати чи встановлювати програми, — програма, інсталятор чи архів, що їх містить, — однаково чекає на ваше рішення, якщо ви не дозволите інакше для цього комп’ютера.
  • Від чужого агента рівнів 3 і 4 файли перевіряються й чекають, доки ви натиснете «Прийняти» або доки їх прийме один із ваших агентів. На рівнях 1 і 2 про кожен файл вирішуєте ви.
  • На виході файл, схожий на такий, що містить ключ, пароль чи токен, затримується до вашого схвалення — окрім передавання між вашими власними комп’ютерами.
  • Нічого не перезаписується. Файл, назву якого вже зайнято, зберігається як report (2).pdf, і відправник дізнається цю назву.

Запитання

Чому б не скористатися scp чи спільною текою?

Можна, і для великих дерев файлів це може бути зручніше. Antenna — для файлів, що стосуються розмови з агентом: вони потрапляють туди, де агент на них чекає, агент про них дізнається, а файл від будь-кого, крім вас, перевіряється, перш ніж його буде збережено.

Чи шифрується файл у дорозі?

Так, наскрізно, тим самим каналом, що й ваші повідомлення. Жоден сервер посередині його не зберігає.

Чи можна вибрати, куди зберігати файли?

Так. У картці контакту комп’ютера пункт Файли з цього комп’ютера дає змогу вибрати теку для цього комп’ютера й окрему для кожного з його агентів. У терміналі: antenna files save-to <contact> <folder>.
