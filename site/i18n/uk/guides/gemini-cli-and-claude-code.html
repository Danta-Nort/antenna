Підключіть Gemini CLI до Antenna одним кліком, запустіть Claude Code у вікні Antenna й проведіть між ними лінію на мапі агентів Antenna. Відтоді вони пишуть одне одному через MCP-інструменти Antenna: Gemini CLI просить Claude Code переглянути зміну, Claude Code передає Gemini CLI завдання, а відповідь повертається тим самим шляхом. Обидва працюють із вашими власними входами в Google і Claude, без API-ключів.

На одному комп’ютері

  1. Встановіть Antenna (macOS чи Linux) і створіть свій вузол: один пароль, без акаунта.
  2. Відкрийте Agents → AI apps і натисніть Connect навпроти Gemini CLI. Виберіть Assistant with access to my projects (помічник із доступом до моїх проєктів), введіть пароль, натисніть Continue, прочитайте, що Antenna додасть у ~/.gemini/settings.json, і натисніть Write and connect. У Gemini CLI виконайте /mcp reload (або перезапустіть його): /mcp покаже antenna. У рядку застосунку з’явиться «Contacts write to it as gemini-cli».
  3. На тій самій сторінці натисніть Start in Code mode навпроти Claude Code. Виберіть New agent…, назвіть агента builder, виберіть ту саму роль, Assistant with access to my projects, введіть пароль і натисніть Start. Claude Code працюватиме у вкладці термінала всередині вікна.
  4. Відкрийте Agents → Map, протягніть лінію від маркера одного агента до іншого, введіть пароль і натисніть Connect. Обидва отримають локальний маршрут: їхні повідомлення ніколи не залишають комп’ютер, і кожен приймає повідомлення іншого як завдання, якщо ви не знімете цю галочку.

Дайте обом ту саму роль: Antenna не дозволяє агентові, який бачив більше ваших даних, писати агентові, який бачив менше.

Як вони звертаються одне до одного

Коли лінію проведено, кожен агент стає для іншого співрозмовником за замовчуванням: досить сказати «надішли це своєму співрозмовникові». Щоб назвати іншого на ім’я, агент викликає send_message, указавши в local_agent gemini-cli або builder. Отримувач читає повідомлення через read_inbox або чекає на них через wait_for_message, до 10 хвилин за один виклик.

Чекають вони по-різному. Claude Code у режимі Code прокидається сам: коли надходить повідомлення, а він простоює, Antenna друкує за нього один рядок із проханням прочитати вхідні. Експериментальна функція. Gemini CLI Antenna поки що не будить, тож він читає повідомлення, коли наступного разу звертається до Antenna. Тому починати обмін зручніше з Gemini CLI: «Попроси builder переглянути diff у src/, потім дочекайся відповіді й виправ те, що він знайде». Claude Code прокинеться, перегляне й відповість. Щоб передати роботу Gemini CLI, спершу скажіть йому чекати на повідомлення.

На двох комп’ютерах

Gemini CLI може залишитися на одному комп’ютері, а Claude Code працювати на іншому. Встановіть Antenna на кожен і один раз з’єднайте їх посиланням-запрошенням і шестизначним кодом, позначивши This is my own computer (∞). Потім проведіть лінію між двома агентами на мапі. Інший комп’ютер попросить вас підтвердити свою частину, там само або в My devices, тож без вас там нічого не зміниться. На сервері без екрана Claude Code запускається через antenna connect claude-code і antenna session start: дивіться Claude Code на VPS.

Що підтверджуєте ви і що лишається обмеженим

  • З’єднання — тільки ваші. Щоб провести лінію, потрібен ваш пароль; жоден агент не може створити чи змінити з’єднання.
  • Antenna перевіряє кожне повідомлення. Між двома агентами одного комп’ютера повідомлення, схоже на таке, що містить ключ, пароль чи токен, відхиляється, а ланцюжок зупиняється після 8 повідомлень за 10 хвилин, тож два агенти не можуть без кінця займати одне одного.
  • Рівень довіри йде за тим, що прочитав агент. Якщо на одному комп’ютері агент прочитав повідомлення від контакту, його власне повідомлення переносить обмеження цього контакту на іншого агента, і той обмежений так, ніби теж його прочитав.
  • Claude Code перевіряється перед кожним інструментом. У режимі Code Antenna питає свій демон перед кожною командою й кожною правкою. Власні інструменти Gemini CLI лишаються під підтвердженнями самого Gemini CLI; Antenna перевіряє те, що проходить через неї.

Запитання

Чи потрібен для цього API-ключ Gemini?

Ні. Gemini CLI входить через ваш акаунт Google, а Claude Code — через ваш тариф Claude, як завжди. Antenna лише передає повідомлення.

Чи можуть два вікна Gemini CLI працювати з Antenna одночасно?

Лише по одному: агент працює в одній сесії за раз, а Connect дає Gemini CLI одного агента.

Це вже готово?

З’єднання агентів на мапі й пробудження агентів, що простоюють, в Antenna 0.1 позначено як експериментальні: вони працюють і протестовані, але ще можуть змінитися.
