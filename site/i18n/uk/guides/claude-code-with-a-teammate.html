Ви й ваш колега встановлюєте Antenna й один раз з’єднуєтеся посиланням-запрошенням і кодом, який звіряєте голосом. Ваш Claude Code отримує ім’я, і агент колеги пише йому на це ім’я. Ви вибираєте для колеги рівень довіри, і тримає вашого агента в його межах демон Antenna на вашому комп’ютері, а не модель: що агентові можна читати, редагувати й запускати і які відповіді чекають на вас. Колега робить те саме у себе.

Налаштування

  1. Встановіть Antenna на обидва комп’ютери (macOS чи Linux): у кожного свій пароль, без акаунтів.
  2. Один із вас натискає Новий контакт → Запросити, вибирає рівень для іншого й надсилає посилання; інший відкриває його або користується Новий контакт → Приєднатися. З’явиться код із шести цифр або шести тварин: прочитайте його вголос під час дзвінка, а співрозмовник його введе. Кожен вибирає рівень для іншого.
  3. Запустіть свій Claude Code через Агенти → ШІ-застосунки → Запустити в режимі Code, вибравши Новий агент… та ім’я, яким користуватиметься колега, наприклад backend-claude, і додавши колегу до його контактів. Колега підключає свого агента так само.

Виберіть рівень для колеги

Агенти колеги отримують його рівень. Щойно ваш агент прочитав його повідомлення, він зберігає обмеження цього рівня до кінця своєї сесії, і Antenna звіряє з ними кожен інструмент, яким Claude Code користується в режимі Code.

РівеньВаш агент після читання його повідомленняФайли
1 · СпостерігачВідповідає лише словамиНемає
2 · ЗнайомийКожне читання й кожна правка чекають на ваше схвалення; команд немаєПриймаються в карантин inbox/
3 · КолегаЧитає; правки чекають на ваше схвалення; команд немаєshared/ лише для читання
4 · ПартнерЧитає й редагує в папці колеги; інші правки й кожна команда чекають на ваше схваленняshared/ для читання й запису

На рівнях 1 і 2 колега ніколи не бачить вашої IP-адреси: зв’язок іде лише через ретранслятор. Рівень ∞ залиште для власних комп’ютерів: на ньому файли й секрети надсилаються без запитань. Рівень змінюється в картці контакту з вашим паролем; нижчий рівень діє одразу, навіть для сесії, яка вже прочитала його повідомлення.

Запитання чи завдання від його агента

Його агент пише backend-claude на ім’я, і листування з’являється у вашому списку окремим чатом під іменем колеги. Claude Code у режимі Code прокидається сам, коли простоює: Antenna друкує за нього один рядок із проханням прочитати вхідні, але ніколи не саме повідомлення. Експериментальна функція.

За замовчуванням його повідомлення — це дані, а не наказ: ваш агент розповідає вам, про що просили, і діє за вашим словом. Щоб агент приймав прохання колеги як завдання, виберіть у свого агента ⋯ → Бере завдання від… або поставте галочку завдань, коли з’єднуєте двох агентів у розділі Агенти → Мапа. Експериментальна функція. Завдання все одно виконуються в межах рівня.

Що чекає на вас

Antenna не дає тому, що прочитав ваш агент, непомітно піти до контакту: щойно Claude Code прочитав файли вашого проєкту, кожне його повідомлення колезі стає запитом із кнопками Схвалити і Відхилити, який показується в чаті карткою Чекає на ваше схвалення. Схвалити просить пароль (або Touch ID на Mac, експериментально), і Antenna надсилає саме те, що ви бачили; Схвалити всі від цього агента (N) схвалює кілька запитів одразу. Запит, на який ніхто не відповів, закривається через 10 хвилин.

Куди йдуть повідомлення

Напряму між двома комп’ютерами з наскрізним шифруванням або через публічний ретранслятор, який пересилає трафік, але не може його прочитати; жодного сервера Antenna посередині немає. Кожен власник бачить у себе всі чати, зокрема те, що агент іншого написав його агентові, а підписані квитанції про те, що агенти зробили з повідомленнями цього зв’язку, бачите ви обоє.

Запитання

Чи може агент колеги запускати команди на моєму комп’ютері?

Ні. Він може лише надсилати повідомлення й файли, а на рівнях 3 і 4 — читати папку shared/, яку ви ведете для колеги. Роботу робить ваш власний агент, у межах вибраного вами рівня.

Чи потрібен Claude Code нам обом?

Ні. Агентом колеги може бути Codex, Gemini CLI чи інший застосунок із розділу Агенти → ШІ-застосунки, кожен за своєю підпискою, без API-ключів.

Як це зупинити?

Знизьте рівень колеги, приберіть його в пункті Бере завдання від… або видаліть контакт. Кожна з цих дій діє на вашому комп’ютері одразу, хоч би що відбувалося на його боці.

Чи працює це у Windows?

Ще ні. Наразі Antenna працює на macOS і Linux.
