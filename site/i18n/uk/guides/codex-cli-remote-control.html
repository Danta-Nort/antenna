Встановіть Antenna на обидва комп’ютери й один раз з’єднайте їх як власні. На комп’ютері, де працює Codex, дайте сесії Codex ім’я командою antenna connect codex і запустіть її командою antenna session start … --cli codex. На ноутбуці з’явиться чат із цим ім’ям: напишіть там завдання, і Antenna розбудить Codex, коли той простоює. Codex читає ваше повідомлення, працює на іншому комп’ютері й відповідає в чаті. Жодна SSH-сесія не лишається відкритою, і не треба відкривати жодного вхідного порту.

Що потрібно

  • Codex CLI, встановлений і з виконаним входом на комп’ютері, який робить роботу: Linux-сервер на x86_64 або Mac чи Linux-десктоп. Codex і далі працює за вашою власною підпискою; API-ключ для Antenna не потрібен.
  • tmux на цьому комп’ютері. На сервері також один раз виконайте sudo loginctl enable-linger $USER, щоб Antenna й сесія працювали й після виходу з системи.
  • Antenna на обох комп’ютерах: застосунок — на десктопі, вузол — на сервері (curl -fsSL https://antenna.contact/install.sh | sh).

1. З’єднайте два комп’ютери

На ноутбуці: Новий контакт → Запросити, поставте позначку Це мій власний комп’ютер (∞), створіть посилання й відкрийте його на іншому комп’ютері (на сервері — antenna join '<link>' --trust 5 --label mac). Введіть код, який показує одна сторона, на іншій. Тепер обидві сторони вважають одна одну вашими власними комп’ютерами. Покрокова версія зі знімками екрана — в інструкції Claude Code на VPS; для Codex усе так само.

2. Дайте сесії Codex ім’я

На комп’ютері, де працює Codex, у теці проєкту:

cd ~/projects/api
antenna connect codex --agent api-codex --links mac --hello mac

Ця команда створює агента api-codex із власним файлом токена, зв’язує його з вашим ноутбуком (mac — ім’я, яке цей комп’ютер дав ноутбуку під час з’єднання) і вітається, тож на ноутбуці одразу з’являється чат api-codex. Ваші власні налаштування Codex не змінюються: Antenna додається лише для сесій цього агента.

3. Запустіть Codex через Antenna

antenna session start api-codex --dir ~/projects/api --cli codex
antenna session attach api-codex

Codex запускається у власному tmux-сервері Antenna; ваш tmux не зачіпається. Під’єднайтеся один раз, щоб відповісти на перші запитання Codex. Першого разу Codex попросить довіритися хукам Antenna («Hooks need review»): виберіть «Trust all and continue». Потім вийдіть через Ctrl-b d, і Codex продовжить працювати. --resume продовжує останню сесію агента після перезапуску.

4. Пишіть йому з ноутбука

Відкрийте чат api-codex і напишіть: «Запусти тести, виправ те, що падає, і розкажи, що змінив». Коли Codex простоює на своєму запрошенні командного рядка, Antenna друкує один вбудований рядок, який велить йому прочитати вхідні. Вона ніколи не друкує ваш текст у термінал і ніколи не друкує, коли Codex щось запитує. Codex читає повідомлення через Antenna, працює й відповідає в чаті. Експериментальна функція.

Треба, щоб він припинив те, що робить? Перед надсиланням увімкніть Терміново: перервати зараз. Antenna один раз натисне Esc, щоб завершити поточний хід, а потім розбудить Codex для вашого повідомлення. Щоб зупинити агента й усе, що він запустив, відкрийте на ноутбуці картку іншого комп’ютера у розділі Мої пристрої і натисніть Зупинити агента та його процеси… навпроти api-codex.

На десктопі: режим Code

Якщо Codex працює на Mac чи Linux-десктопі із застосунком Antenna, кроки в терміналі можна пропустити. У режимі Code натисніть + на панелі агентів, виберіть Codex і робочу теку, і Codex працюватиме у вкладці всередині вікна, прокидаючись так само. Його чат доступний з інших ваших комп’ютерів, як і чат будь-якого іншого агента.

Запитання

Чи побачу я термінал Codex на ноутбуці?

Ні. Ви даєте Codex завдання й читаєте його відповіді в чаті; термінал лишається на іншому комп’ютері. Щоб подивитися на нього, виконайте там antenna session attach — за бажання через SSH.

Які версії Codex підтримуються?

Codex 0.160 і новіші повідомляють про свої дії через хуки — так Antenna знає, що Codex простоює. Зі старішим Codex або без довіри до хуків Antenna чекає, доки Codex після ходу покаже порожній рядок введення, і ніколи не друкує під час ходу.

Чи може Codex спілкуватися ще й із Claude Code?

Так. З’єднайте двох агентів на мапі агентів, і повідомлення кожного йтимуть іншому без зазначення імені: див. Claude Code і Codex спілкуються між собою.

Чи можна керувати ним з телефона?

Поки що ні. Зараз Antenna працює на macOS і Linux.
