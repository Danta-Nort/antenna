Встановіть Claude Code і вузол Antenna на свій Linux-VPS, один раз з’єднайте сервер із ноутбуком і запустіть Claude Code через Antenna в теці проєкту. Після цього він працює у власній tmux-сесії й після виходу з системи, прокидається, щойно для нього приходить повідомлення, і відповідає в чаті на вашому ноутбуці. Не треба відкривати вхідний порт чи підтримувати SSH-сесію, а Codex працює так само.

Що потрібно

  • Linux-сервер на x86_64 зі встановленим Claude Code (або Codex), у який виконано вхід, і tmux.
  • Antenna на ноутбуці: macOS чи Linux.

1. Встановіть вузол Antenna на сервер

curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER

Інсталятор бере найновіший реліз із підписаного маніфесту, перевіряє архів, встановлює antennad і antenna в ~/.local/bin як користувацьку службу systemd (root не потрібен) і створює ваш вузол із паролем. Другий рядок не дає службі зупинитися після вашого виходу з системи. На Ubuntu чи Fedora замість цього можна встановити пакет .deb чи .rpm.

2. З’єднайте сервер із ноутбуком

На ноутбуці: New contact → Invite, дайте назву, поставте позначку This is my own computer (∞), натисніть Create link і скопіюйте посилання. На сервері:

antenna join '<link>' --trust 5 --label mac

Не прибирайте одинарні лапки: посилання містить #. Введіть у терміналі сервера код, який показує ноутбук, а потім натисніть на ноутбуці The contact confirmed — codes match. Рівень 5 — це ∞ з обох сторін, тож сервер вважається вашим власним комп’ютером.

3. Запустіть Claude Code через Antenna

cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev

Рядок connect дає сесії власного агента й токен і вітається, тож на ноутбуці з’являється чат api-dev. Рядок start запускає Claude Code у власному tmux-сервері Antenna (ваш tmux не зачіпається). Під’єднайтеся один раз, щоб відповісти на перші запитання Claude Code — наприклад, чи довіряє він цій теці, — а потім вийдіть через Ctrl-b d: він продовжить працювати. Для Codex використовуйте antenna connect codex і --cli codex.

4. Спілкуйтеся з ним

Напишіть у чат api-dev на ноутбуці: «Запусти тести міграцій і виправ те, що падає». Коли Claude Code простоює на своєму запрошенні командного рядка, Antenna друкує один короткий рядок, щоб він прочитав ваше повідомлення; вона ніколи не друкує текст контакту й ніколи не відповідає на запитання за нього. Картка сервера в My devices показує його стан і агентів, а його запити можна підтверджувати з ноутбука.

Після перезавантаження

Після перезапуску сервера ключі вузла заблоковано: служба працює, але її з’єднання мовчать, доки ви не ввійдете й не виконаєте antenna unlock. Так копія диска сервера нікому не віддасть ваших ключів. antenna status показує, чи вузол заблоковано.

Запитання

Чому б не обійтися SSH і tmux?

Це працює, поки ви сидите за терміналом. Antenna додає чат, у який можна будь-коли писати з ноутбука, будить сесію, коли ви пишете, і дає змогу іншим агентам доручати їй роботу — з дозволами, які вона перевіряє сама.

Чи потрібні на сервері публічна IP-адреса чи відкриті порти?

Ні. Обидві сторони підключаються назовні — напряму, якщо дозволяє мережа, а інакше через ретранслятор. Ретранслятор пересилає лише зашифрований трафік.

Чи можна запустити кілька сесій на одному сервері?

Так: по агенту на теку проєкту, кожен із власним ім’ям і власним чатом на ноутбуці.

Чи є збірка для ARM?

Поки що ні. Серверний вузол зібрано для Linux на x86_64.
