Дайте Claude Code завдання в чаті Antenna зі свого ноутбука, і, закінчивши, він надішле результат у той самий чат: інструкції Antenna кажуть підключеному агентові надсилати результати тому контакту, який дав завдання. Ноутбук покаже сповіщення «New message in server · api-dev» (нове повідомлення), якщо вікно Antenna не на передньому плані. Запити на підтвердження теж приходять сповіщенням, тож робота, що зупинилася на півдорозі, не чекатиме непомітно. Сама Antenna не стежить за ходами Claude Code: звіт — це власне повідомлення Claude Code.

Про що приходять сповіщення

  • Повідомлення від Claude Code вам. Сповіщення називає чат, але ніколи не показує текст, і приходить не частіше ніж раз на 10 секунд для одного чату.
  • Запит на підтвердження. Крок, якому потрібне ваше слово, приходить як «Antenna: approval needed on server»: з агентом, тим, що він хоче зробити, і часом, що лишився («expires in 9 min», спливає за 9 хв), але без тексту запиту. Друге сповіщення приходить приблизно за дві хвилини до закриття запиту; закривається він через 10 хвилин. Запити з іншого комп’ютера доходять до вас через My devices (мої пристрої; експериментально).
  • Запитання. Експериментальна функція. Запитання агента приходить сповіщенням на комп’ютері, де агент працює: «A question from your agent» (запитання від вашого агента). Для сервера виконайте там antenna agent escalate api-dev --to mac, і його запитання натомість приходитимуть у чат агента на вашому ноутбуці.

Сповіщення працюють на macOS і на робочих столах Linux, які вміють їх показувати. Antenna має бути відкрита на ноутбуці; коли її вікно на передньому плані, вистачає лічильників непрочитаного в списку чатів.

Налаштування

  1. Встановіть Antenna на обидва комп’ютери й один раз з’єднайте їх із позначкою This is my own computer (∞) (це мій власний комп’ютер). Як налаштувати сервер, описано в посібнику Claude Code на VPS.
  2. Запустіть Claude Code через Antenna. На сервері: 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
    На другому десктопі: Agents → AI apps → Start in Code mode.
  3. На ноутбуці нічого налаштовувати не треба. Чат з агентом від самого початку сповіщає про повідомлення особисто вам і про запити на підтвердження.

Попросіть надіслати звіт

Напишіть завдання в чаті api-dev і скажіть, що хочете отримати у відповідь: «Прожени тести міграцій і виправ те, що падає. Коли закінчиш, відповідай тут, що змінилося». Якщо Claude Code простоює в рядку введення, Antenna друкує один рядок, щоб він прочитав ваше повідомлення (експериментально); він виконує роботу й відповідає в тому самому чаті, а ноутбук показує сповіщення.

Якщо роботу ви починаєте в його терміналі (antenna session attach api-dev), закінчіть запит словами «коли закінчиш, надішли мені підсумок в Antenna». Щоб це стало звичкою, додайте рядок у CLAUDE.md проєкту: «Закінчивши завдання, надішли короткий підсумок контакту mac через send_message Antenna».

Звіт приходить, коли Claude Code сам вирішить, що закінчив, як і з будь-якою інструкцією, якої він дотримується. Якщо він зупинився на власному запиті дозволу в терміналі («Do you want to proceed?»), Antenna цього не бачить і сповіщення не буде: дозвольте інструменти, якими користуєтеся постійно, у налаштуваннях Claude Code.

Які чати надсилають сповіщення

Натисніть ⋮ у рядку чату або клацніть його правою кнопкою миші, потім виберіть Notifications (сповіщення):

  • All messages (усі повідомлення): кожне нове повідомлення в цьому чаті (за замовчуванням для людини).
  • Only when it asks for me (лише коли звертаються до мене): повідомлення особисто вам і запити на підтвердження (за замовчуванням для агента).
  • Off (вимкнено): про запити на підтвердження сповіщення однаково приходять.

Якщо Claude Code звітує не вам, а іншому вашому агентові, ці повідомлення приходять без сповіщень, доки ви не ввімкнете Notify about messages between agents (сповіщати про повідомлення між агентами) у тому самому меню. У терміналі: antenna chats notify server --agent api-dev all.

На комп’ютері, за яким ви сидите

Коли Claude Code працює в режимі Code на вашому власному ноутбуці, Antenna сповіщає про його запити на підтвердження й запитання, поки вікно у фоні, але не про кінець ходу: агент не може написати вам на своєму ж комп’ютері. Для цього є власні хуки Claude Code: вони можуть запустити вашу команду, коли він зупиняється.

Запитання

Чи видно в сповіщенні, що написав Claude Code?

Ні. У ньому лише «New message in» і назва чату, бо сповіщення може з’явитися на заблокованому екрані. Щоб прочитати звіт, відкрийте чат.

А якщо ноутбук спить?

Повідомлення чекатиме на сервері, і Antenna доставить його разом зі сповіщенням, коли ноутбук знову буде в мережі.

Чи можна отримувати сповіщення на телефон?

Ще ні. Наразі Antenna працює на macOS і Linux.
