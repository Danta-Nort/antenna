Installa Antenna su entrambi i computer, abbinali una volta come ∞ · My computer e collega ad Antenna la sessione di Claude Code che gira lì, con un nome tutto suo. Da quel momento scrivi a quella sessione dal tuo Mac come a un contatto in chat, oppure lasci che sia il tuo Claude Code locale a scriverle. Se avvii la sessione tramite Antenna, viene svegliata quando è inattiva, e un messaggio urgente può interromperla a metà turno. Due sessioni sullo stesso computer? Allora collegale sulla mappa degli agenti: due agenti che parlano.

Quando ti serve

  • Claude Code gira su un server o su un desktop per lavori lunghi, e vuoi dargli il compito successivo dal portatile.
  • Una sessione pianifica e un'altra costruisce, ognuna sulla propria macchina.
  • Usi più macchine e vuoi una chat per sessione invece di un terminale per macchina.

1. Abbina i due computer

Installa Antenna su entrambi: l'app su un desktop Mac o Linux, il nodo server su un server Linux (Claude Code su una VPS ti guida passo passo). Su uno dei due crea un invito di livello ∞, aprilo sull'altro e inserisci in un lato il codice di sei cifre mostrato dall'altro. L'abbinamento è identico a quello con una persona, e puoi farlo solo tu: serve la tua password da proprietario su entrambi i lati.

2. Dai un nome alla sessione

Sull'altro computer, nella cartella del progetto:

antenna connect claude-code --agent api-dev --links mac --hello mac

Qui mac è il nome che il server ha dato al tuo Mac durante l'abbinamento. Il comando crea l'agente api-dev, aggiunge Antenna a Claude Code solo per questa cartella (dopo il tuo sì) e manda un saluto al tuo Mac, così lì compare subito una chat chiamata api-dev. Una sessione in un'altra cartella ha un nome e una chat propri. Codex funziona allo stesso modo con antenna connect codex.

3. Tienila sveglia

Claude Code legge Antenna solo mentre lavora a qualcosa. Perché raccolga un messaggio anche quando è fermo su un prompt vuoto, avvialo invece tramite Antenna:

antenna session start api-dev --dir ~/projects/api

(Per questo sul server serve tmux.) Quando arriva un messaggio, Antenna digita una breve riga nel prompt vuoto, e la sessione legge il messaggio come dati e si mette al lavoro. Su un desktop, la modalità Code di Antenna fa lo stesso in una scheda di terminale dentro la finestra. Sperimentale.

4. Scrivile

Apri la chat api-dev sul Mac e scrivi, come faresti con una persona. Oppure fallo fare al tuo Claude Code locale: “Chiedi ad api-dev di eseguire i test di migrazione e di riferirmi.” Quando non può aspettare, attiva Urgent: interrupt now (il pulsante col fulmine accanto a Invia) prima di inviare (da terminale, antenna send --urgent): per una sessione gestita da Antenna, in modalità Code o con antenna session start, Antenna interrompe una volta il turno in corso, come se premessi Esc, e la sessione legge il tuo messaggio. Non preme mai Esc sopra una domanda o una richiesta di permesso aperta nel terminale. Sperimentale.

Che cosa viaggia e che cosa no

Il messaggio viene cifrato su un computer e decifrato sull'altro. Nessun terminale viene condiviso e non serve aprire o inoltrare porte: l'altra sessione riceve solo messaggi, e la sua Antenna decide che cosa può farne. Il token dell'agente resta sul computer su cui è stato creato.

Domande

È un controllo remoto del terminale?

No. Non vedi l'altro terminale e non ci scrivi dentro. Mandi alla sessione messaggi e compiti, e lei risponde in chat. Per il terminale completo, usa SSH come prima.

Posso vedere che cosa sta facendo la sessione?

La chat mostra le sue risposte, e la mappa degli agenti mostra chi ha parlato con chi. In My devices puoi anche vedere gli agenti degli altri tuoi computer e fermarne uno insieme a tutto ciò che ha avviato.

Il server ha bisogno di un indirizzo pubblico?

No. Entrambi i computer si collegano verso l'esterno; quando non riescono a raggiungersi direttamente, un relay inoltra il traffico cifrato.

Che cosa succede dopo un riavvio del server?

Dopo un riavvio le chiavi sono bloccate. Accedi una volta ed esegui antenna unlock; poi la sessione si può avviare di nuovo.
