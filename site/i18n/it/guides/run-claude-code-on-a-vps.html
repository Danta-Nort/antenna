Installa Claude Code e il nodo Antenna sulla tua VPS Linux, abbina una volta il server al portatile e avvia Claude Code tramite Antenna nella cartella del progetto. Da lì gira nella propria sessione tmux anche dopo il logout, si sveglia quando arriva un messaggio per lui e risponde in una chat sul portatile. Nessuna porta in ingresso da aprire, nessuna sessione SSH da tenere viva, e Codex funziona allo stesso modo.

Che cosa ti serve

  • Un server Linux x86_64, con Claude Code (o Codex) installato e con l'accesso effettuato, e tmux.
  • Antenna sul portatile: macOS o Linux.

1. Installa il nodo Antenna sul server

curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER

L'installer legge la versione più recente dal manifest firmato, verifica l'archivio, installa antennad e antenna in ~/.local/bin come servizio utente systemd (senza bisogno di root) e crea il tuo nodo con una password. La seconda riga mantiene attivo il servizio dopo il logout. Su Ubuntu o Fedora puoi installare invece il pacchetto .deb o .rpm.

2. Abbinalo al portatile

Sul portatile: New contact → Invite, dagli un nome, spunta This is my own computer (∞), premi Create link e copialo. Sul server:

antenna join '<link>' --trust 5 --label mac

Lascia gli apici singoli: il link contiene un #. Digita nel terminale del server il codice che mostra il portatile, poi premi The contact confirmed — codes match sul portatile. Il livello 5 corrisponde a ∞ su entrambi i lati, quindi il server conta come un tuo computer.

3. Avvia Claude Code tramite Antenna

cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev

La riga connect dà alla sessione un agente e un token propri e manda un saluto, così sul portatile compare una chat chiamata api-dev. La riga start avvia Claude Code nel server tmux di Antenna (il tuo tmux non viene toccato). Collegati una volta per rispondere alle prime domande di Claude Code, per esempio se si fida della cartella, poi esci con Ctrl-b d: continua a girare. Per Codex usa antenna connect codex e --cli codex.

4. Parlagli

Scrivi nella chat api-dev sul portatile: “Esegui i test di migrazione e correggi ciò che fallisce.” Quando Claude Code è fermo al suo prompt, Antenna digita una breve riga perché legga il tuo messaggio; non digita mai il testo di un contatto e non risponde mai a una domanda al suo posto. La scheda del server in My devices mostra il suo stato e i suoi agenti, e puoi approvare le sue richieste dal portatile.

Dopo un riavvio

Dopo il riavvio del server le chiavi del nodo sono bloccate: il servizio gira, ma i suoi collegamenti restano muti finché non accedi ed esegui antenna unlock. Così una copia del disco del server non dà a nessuno le tue chiavi. antenna status ti dice se è bloccato.

Domande

Perché non usare semplicemente SSH e tmux?

Funziona finché stai davanti a un terminale. Antenna aggiunge una chat a cui puoi scrivere dal portatile in qualsiasi momento, sveglia la sessione quando lo fai e permette ad altri agenti di affidarle lavoro, con permessi che controlla da sé.

Il server ha bisogno di un IP pubblico o di porte aperte?

No. Entrambi i lati si collegano verso l'esterno, direttamente quando la rete lo permette e tramite un relay altrimenti. Il relay inoltra solo traffico cifrato.

Posso far girare più sessioni sullo stesso server?

Sì: un agente per cartella di progetto, ognuno con il proprio nome e la propria chat sul portatile.

Esiste una build per ARM?

Non ancora. Il nodo server è compilato per Linux x86_64.
