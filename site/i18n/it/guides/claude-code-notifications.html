Dai a Claude Code il suo compito in una chat di Antenna dal tuo portatile, e quando ha finito ti rimanda il risultato in quella stessa chat: le istruzioni di Antenna dicono a un agente collegato di inviare i risultati al contatto che gli ha dato il compito. Il portatile mostra allora una notifica, “New message in server · api-dev”, mentre la finestra di Antenna non è in primo piano. Anche le richieste di approvazione mandano una notifica, così un lavoro che si ferma a metà non resta in attesa senza che te ne accorga. Antenna non osserva da sé i turni di Claude Code: il resoconto è un messaggio di Claude Code stesso.

Che cosa ti manda una notifica

  • Un messaggio di Claude Code per te. La notifica indica il nome della chat, mai il testo, al massimo una volta ogni 10 secondi per chat.
  • Una richiesta di approvazione. Un passo che ha bisogno del tuo via libera compare come “Antenna: approval needed on server”, con l'agente, che cosa vuole fare e il tempo rimasto (“expires in 9 min”), ma mai con il testo della richiesta. Una seconda notifica arriva circa due minuti prima che la richiesta si chiuda; si chiude dopo 10 minuti. Le richieste da un altro computer ti arrivano tramite My devices (i miei dispositivi, sperimentale).
  • Una domanda. Sperimentale. La domanda di un agente manda una notifica sul computer dove gira: “A question from your agent”. Per un server, esegui lì antenna agent escalate api-dev --to mac, e le sue domande arrivano invece nella chat dell'agente sul tuo portatile.

Le notifiche funzionano su macOS e sui desktop Linux che mostrano notifiche. Antenna deve essere aperto sul portatile; con la sua finestra in primo piano, i contatori dei non letti nell'elenco delle chat fanno lo stesso lavoro.

Come configurarlo

  1. Installa Antenna su entrambi i computer e abbinali una volta con la casella This is my own computer (∞) (questo è il mio computer) spuntata. Claude Code su una VPS spiega passo passo la parte del server.
  2. Avvia Claude Code tramite Antenna. Su un server: 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
    Su un secondo desktop: Agents → AI apps → Start in Code mode.
  3. Sul portatile non c'è niente da impostare. Fin dall'inizio, una chat con un agente manda notifiche per i messaggi rivolti a te di persona e per le richieste di approvazione.

Chiedi il resoconto

Scrivi il compito nella chat api-dev e di' che cosa vuoi in risposta: “Esegui i test della migrazione e correggi quello che fallisce. Quando hai finito, rispondi qui con che cosa è cambiato.” Se Claude Code è fermo al suo prompt, Antenna scrive una riga perché legga il tuo messaggio (sperimentale); lui lavora, poi risponde nella stessa chat, e il portatile mostra la notifica.

Per il lavoro che avvii nel suo terminale (antenna session attach api-dev), chiudi il prompt con “mandami un riepilogo su Antenna quando hai finito”. Per farlo diventare un'abitudine, aggiungi una riga al CLAUDE.md del progetto: “Quando finisci un compito, manda un breve riepilogo a mac con send_message di Antenna.”

Il resoconto arriva quando Claude Code decide di aver finito, come per qualsiasi istruzione che segue. Se si ferma alla sua richiesta di permesso nel terminale (“Do you want to proceed?”), Antenna non lo vede e non ti arriva nessuna notifica: consenti nelle impostazioni di Claude Code gli strumenti che usi di solito.

Scegli quali chat mandano notifiche

Apri ⋮ sulla riga di una chat, oppure fai clic destro su di essa, poi Notifications (notifiche):

  • All messages (tutti i messaggi): ogni nuovo messaggio in questa chat (l'impostazione predefinita per una persona).
  • Only when it asks for me (solo quando mi cerca): i messaggi rivolti a te di persona e le richieste di approvazione (l'impostazione predefinita per un agente).
  • Off (disattivate): le richieste di approvazione mandano comunque una notifica.

Quando Claude Code fa rapporto a un altro dei tuoi agenti invece che a te, quei messaggi restano silenziosi, a meno che tu non attivi Notify about messages between agents (notifica i messaggi tra agenti) nello stesso menu. In un terminale: antenna chats notify server --agent api-dev all.

Sul computer dove ti trovi

Con Claude Code nella modalità Code sul tuo stesso portatile, Antenna ti notifica le sue richieste di approvazione e le sue domande mentre la finestra è in secondo piano, ma non la fine di un turno: un agente non può scriverti sul suo stesso computer. Per questo, gli hook di Claude Code possono eseguire un tuo comando quando si ferma.

Domande

La notifica mostra che cosa ha scritto Claude Code?

No. Dice solo “New message in” e il nome della chat, perché una notifica può comparire a schermo bloccato. Apri la chat per leggere il resoconto.

E se il portatile è in stop?

Il messaggio aspetta sul server, e Antenna lo consegna, con la sua notifica, quando il portatile torna online.

Posso ricevere la notifica sul telefono?

Non ancora. Per ora Antenna gira su macOS e Linux.
