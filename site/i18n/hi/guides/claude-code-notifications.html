अपने लैपटॉप से Antenna की चैट में Claude Code को task दें, और काम पूरा होने पर वह नतीजा उसी चैट में वापस भेजता है: Antenna के instructions जुड़े हुए agent से कहते हैं कि वह अपने नतीजे उसी कॉन्टैक्ट को भेजे जिसने task दिया था। जब तक Antenna की विंडो सामने नहीं होती, आपका लैपटॉप “server · api-dev में नया मैसेज” notification दिखाता है। Approval requests पर भी notification आता है, ताकि बीच में रुका काम चुपचाप इंतज़ार में न पड़ा रहे। Antenna ख़ुद Claude Code के turns पर नज़र नहीं रखता: रिपोर्ट Claude Code का अपना मैसेज होती है।

किन बातों पर notification आता है

  • Claude Code का आपको भेजा मैसेज। Notification में सिर्फ़ चैट का नाम होता है, टेक्स्ट कभी नहीं, और हर चैट के लिए 10 सेकंड में ज़्यादा से ज़्यादा एक बार।
  • Approval request। जिस कदम के लिए आपकी हाँ चाहिए, वह “Antenna: server पर मंज़ूरी चाहिए” के रूप में दिखता है, साथ में agent, वह क्या करना चाहता है और कितना समय बचा है (“9 मिनट में मियाद ख़त्म”), पर request का टेक्स्ट कभी नहीं। Request बंद होने से करीब दो मिनट पहले दूसरा notification आता है; request 10 मिनट बाद बंद हो जाता है। दूसरे कंप्यूटर से आए requests आप तक My devices के ज़रिए पहुँचते हैं (experimental)।
  • सवाल। Experimental। Agent के सवाल का notification उसी कंप्यूटर पर आता है जहाँ वह चलता है: “A question from your agent”। Server के लिए वहाँ antenna agent escalate api-dev --to mac चलाएँ, फिर उसके सवाल आपके लैपटॉप पर agent की चैट में आते हैं।

Notifications macOS पर और उन Linux desktops पर काम करते हैं जो notifications दिखाते हैं। लैपटॉप पर Antenna खुला होना चाहिए; विंडो सामने हो, तो चैट लिस्ट में unread की गिनती ही काफ़ी है।

सेट अप करें

  1. दोनों कंप्यूटरों पर Antenna इंस्टॉल करें और उन्हें एक बार यह मेरा अपना कंप्यूटर है (∞) पर tick लगाकर जोड़ें। Server वाला हिस्सा VPS पर Claude Code में कदम-दर-कदम बताया है।
  2. Claude Code को Antenna के ज़रिए शुरू करें। Server पर: 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
    दूसरे डेस्कटॉप पर: Agents → AI apps → Code mode में शुरू करें।
  3. लैपटॉप पर कुछ सेट नहीं करना है। Agent वाली चैट शुरू से ही आपको सीधे भेजे गए मैसेज और approval requests पर notification देती है।

रिपोर्ट माँगें

api-dev चैट में task लिखें और बताएँ कि आपको वापस क्या चाहिए: “Migration tests चलाओ और जो fail हों उन्हें ठीक करो। काम पूरा होने पर यहीं बताओ कि क्या बदला।” अगर Claude Code अपने prompt पर ख़ाली बैठा है, तो Antenna एक लाइन टाइप करता है ताकि वह आपका मैसेज पढ़े (experimental); वह काम करता है, फिर उसी चैट में जवाब देता है, और आपके लैपटॉप पर notification आता है।

जो काम आप उसके terminal में शुरू करते हैं (antenna session attach api-dev), उसके prompt के आख़िर में लिखें “काम पूरा होने पर मुझे Antenna पर summary भेजना”। इसे आदत बनाने के लिए प्रोजेक्ट की CLAUDE.md में एक लाइन जोड़ें: “Task पूरा करने पर Antenna के send_message से mac को छोटी summary भेजो।”

किसी भी instruction की तरह, रिपोर्ट तब आती है जब Claude Code तय करता है कि काम पूरा हो गया। अगर वह terminal में अपने permission prompt (“Do you want to proceed?”) पर रुक जाए, तो Antenna को यह नहीं दिखता, और कोई notification नहीं आता: जो tools आप रोज़ इस्तेमाल करते हैं, उन्हें Claude Code की settings में allow कर दें।

चुनें कि किन चैट्स पर notification आए

किसी चैट की row पर ⋮ खोलें, या उस पर right-click करें, फिर Notifications चुनें:

  • सभी मैसेज: इस चैट का हर नया मैसेज (किसी व्यक्ति वाली चैट का default)।
  • सिर्फ़ जब मेरी ज़रूरत हो: आपको सीधे भेजे गए मैसेज और approval requests (agent वाली चैट का default)।
  • बंद: approval requests पर फिर भी notification आता है।

जब Claude Code आपकी बजाय आपके किसी दूसरे agent को रिपोर्ट करता है, तो उन मैसेज पर notification नहीं आता, जब तक आप उसी menu में agents के आपसी मैसेज पर notification चालू न करें। Terminal में: antenna chats notify server --agent api-dev all।

जिस कंप्यूटर पर आप बैठे हैं

जब Claude Code आपके अपने लैपटॉप पर Code mode में चलता है, तो विंडो पीछे होने पर Antenna उसके approval requests और सवालों पर notification देता है, पर turn ख़त्म होने पर नहीं: agent अपने ही कंप्यूटर पर आपको मैसेज नहीं भेज सकता। इसके लिए Claude Code के अपने hooks, उसके रुकने पर आपकी कोई command चला सकते हैं।

सवाल-जवाब

क्या notification में दिखता है कि Claude Code ने क्या लिखा?

नहीं। उसमें सिर्फ़ चैट का नाम और “… में नया मैसेज” होता है, क्योंकि notification lock screen पर भी दिख सकता है। रिपोर्ट पढ़ने के लिए चैट खोलें।

अगर मेरा लैपटॉप sleep में हो तो?

मैसेज server पर इंतज़ार करता है, और लैपटॉप के फिर से online आने पर Antenna उसे notification के साथ पहुँचा देता है।

क्या मुझे notification फ़ोन पर मिल सकता है?

अभी नहीं। Antenna आज macOS और Linux पर चलता है।
