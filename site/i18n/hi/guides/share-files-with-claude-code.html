एक ही कंप्यूटर पर Claude Code आपकी फ़ाइलें सीधे पढ़ लेता है: उसे path दें, या फ़ाइल को उसके terminal में drag कर दें। दूसरे कंप्यूटर पर, जैसे किसी server पर, फ़ाइल Antenna से भेजें: उसे उस Claude Code session की चैट में डाल दें, Antenna पहुँचते ही उसे जाँचता है और वहाँ लिंक के फ़ोल्डर में सेव करता है, और agent को उसके inbox में फ़ाइल का नाम, जगह, साइज़ और SHA-256 मिल जाता है। Agent जो फ़ाइलें वापस भेजता है, वे भी इसी तरह आपके लैपटॉप तक आती हैं।

Agent को फ़ाइल भेजें

  1. अपने लैपटॉप को दूसरे कंप्यूटर से अपने ख़ुद के (∞) रूप में जोड़ें और वहाँ Claude Code को Antenna से कनेक्ट करें: देखें VPS पर Claude Code।
  2. लैपटॉप पर session वाली चैट खोलें और फ़ाइल उसमें डाल दें, या वैसे ही attach करें जैसे किसी भी मैसेंजर में करते हैं।
  3. दूसरे कंप्यूटर पर Antenna फ़ाइल का टाइप उसके कंटेंट से जाँचता है, ख़तरे और secrets ढूँढता है, और उसे लिंक फ़ोल्डर ~/Antenna/links/<folder>/shared/ में, या उस कंप्यूटर के लिए आपके चुने प्रोजेक्ट फ़ोल्डर में सेव करता है।
  4. Agent को अगले inbox में सेव हुई फ़ाइल के बारे में अपने-आप पता चल जाता है, उसके path और hashes के साथ, और वह अगले कदम में उसे इस्तेमाल कर सकता है।

Agent से फ़ाइलें वापस पाएँ

Agent आपको फ़ाइल, build, रिपोर्ट या screenshot भेज सकता है, उन्हीं tools से जिनसे वह मैसेज भेजता है। यह आपकी चैट में और फ़ाइलें में एक कार्ड के रूप में आती है, जिसमें फ़ाइल का नाम, जाँच में क्या दिखा, और उसका hash होता है। तस्वीरें जाँचे हुए सुरक्षित preview के रूप में दिखती हैं, जिसे Antenna दोबारा बनाता है।

क्या जाँचा जाता है, और क्या आपका इंतज़ार करता है

  • आपके अपने कंप्यूटरों के बीच आम फ़ाइलें अपने-आप सेव हो जाती हैं। जो कुछ भी software चला या इंस्टॉल कर सकता है, जैसे कोई प्रोग्राम, installer या ऐसा archive जिसमें इनमें से कुछ हो, वह फिर भी आपके फ़ैसले का इंतज़ार करता है, जब तक आप उस कंप्यूटर के लिए इसकी इजाज़त न दें।
  • किसी और के agent से, levels 3 और 4 पर, फ़ाइलें जाँची जाती हैं और आपके Accept का, या आपके किसी agent के स्वीकार करने का इंतज़ार करती हैं। Levels 1 और 2 पर हर फ़ाइल का फ़ैसला आप करते हैं।
  • बाहर जाते समय, जिस फ़ाइल में key, password या token होने का शक हो, उसे आपकी मंज़ूरी तक रोक लिया जाता है, सिवाय आपके अपने कंप्यूटरों के बीच।
  • कुछ भी overwrite नहीं होता। जिस नाम की फ़ाइल पहले से हो, वह report (2).pdf के रूप में सेव होती है, और भेजने वाले को नाम बता दिया जाता है।

सवाल-जवाब

scp या शेयर्ड फ़ोल्डर क्यों नहीं?

आप उन्हें इस्तेमाल कर सकते हैं, और फ़ाइलों के बड़े ढेर के लिए शायद वही बेहतर हों। Antenna उन फ़ाइलों के लिए है जो agent के साथ बातचीत का हिस्सा हैं: वे वहीं पहुँचती हैं जहाँ agent उनकी उम्मीद करता है, agent को बताया जाता है, और आपके अलावा किसी और की फ़ाइल पहुँचने से पहले जाँची जाती है।

क्या रास्ते में फ़ाइल encrypted रहती है?

हाँ, end to end, उसी लिंक पर जिस पर आपके मैसेज जाते हैं। बीच में कोई server उसे स्टोर नहीं करता।

क्या फ़ाइलें सेव होने की जगह चुनी जा सकती है?

हाँ। कंप्यूटर के कॉन्टैक्ट कार्ड में इस कंप्यूटर से आई फ़ाइलें से आप उस कंप्यूटर के लिए एक फ़ोल्डर और उसके हर agent के लिए एक-एक फ़ोल्डर चुन सकते हैं। Terminal से: antenna files save-to <contact> <folder>।
