अपने AI agents को Antenna से जोड़ें, और आपके कंप्यूटर पर उसका daemon, मॉडल नहीं, वह सब कुछ जाँचता है जो वे उसके ज़रिए भेजते हैं: मैसेज, फ़ाइलें और उनके अंदर का टेक्स्ट, फ़ाइलों के नाम और streamed जवाब। जो कुछ भी private key, API token, password या seed phrase जैसा दिखे, वह आपकी मंज़ूरी तक रुका रहता है। आने वाली फ़ाइलें जाँच होने तक एक encrypted quarantine में इंतज़ार करती हैं, और जिस agent ने कम भरोसे वाले कॉन्टैक्ट का मैसेज पढ़ा हो, वह commands चलाने का हक़ खो देता है।

Scanner क्या पकड़ता है

  • Private keys: PEM और OpenSSH keys, PGP private key blocks, PuTTY key files, age secret keys।
  • API tokens, उनकी जानी-पहचानी शक्ल से: GitHub, GitLab, AWS access key IDs, sk- और sk-ant- keys, Google API keys, Stripe keys, JSON Web Tokens, और Antenna के अपने agent tokens और इनवाइट लिंक।
  • Label वाली values: password=, api_key:, token=, client_secret और ऐसे ही, जिनके बाद छह या ज़्यादा अक्षर हों, और दर्जन भर दूसरी भाषाओं में “password” के लिए इस्तेमाल होने वाले शब्द भी।
  • Seed phrases: लगातार बारह या ज़्यादा wallet recovery शब्द।

यह मतलब नहीं, शक्ल देखता है: बिना किसी जाने-पहचाने prefix और बिना label वाली कोई अकेली random string निकल जाती है।

यह कहाँ देखता है

  • हर मैसेज जो कोई agent किसी कॉन्टैक्ट को भेजता है, और आपके अपने मैसेज भी।
  • हर फ़ाइल, भेजे जाने से पहले, PDFs, documents और archives के अंदर के टेक्स्ट समेत, और उसका नाम भी।
  • Streamed जवाब, टुकड़ा-टुकड़ा: जैसे ही कोई secret दिखता है, सामने वाले के लिए stream रुक जाता है और पूरा मैसेज आपका इंतज़ार करता है।
  • एक ही कंप्यूटर के दो agents के बीच (experimental), secret वाला मैसेज सीधे मना कर दिया जाता है।

कुछ मिलने पर क्या होता है

Agent का रोका गया मैसेज चैट में Waiting for your approval (आपकी मंज़ूरी का इंतज़ार) के रूप में दिखता है, साथ में यह कि क्या मिला, जैसे “looks like a secret: token”। Approve आपका password माँगता है, या Mac पर Touch ID (experimental), और ठीक वही भेजता है जो आपने देखा; Deny उसे हटा देता है। आपके अपने रोके गए मैसेज और रोकी गई फ़ाइल पर Approve and send मिलता है; फ़ाइल पर Don’t send भी। जिस request का कोई जवाब न दे, वह 10 मिनट बाद बंद हो जाता है, और कुछ बाहर नहीं जाता।

कम भरोसा, कम छूट

एक बार किसी agent ने किसी कॉन्टैक्ट का मैसेज पढ़ लिया, तो session के बाक़ी समय तक उस कॉन्टैक्ट का level उसे सीमित रखता है; Antenna के ज़रिए शुरू किए गए Claude Code के लिए हर command, read और edit जाँचा जाता है:

Levelउनका मैसेज पढ़ने के बाद आपका agentउनकी फ़ाइलें
1 · Observerसिर्फ़ शब्दों में जवाब देता हैकोई नहीं
2 · Acquaintanceहर read और edit आपकी मंज़ूरी का इंतज़ार करता है; कोई command नहींQuarantine; हर एक का फ़ैसला आप करते हैं
3 · Colleagueपढ़ता है; edits आपकी मंज़ूरी का इंतज़ार करते हैं; कोई command नहींजाँच के बाद Accept का इंतज़ार
4 · Partnerउनके फ़ोल्डर में पढ़ता और edit करता है; बाक़ी edits और हर command आपकी मंज़ूरी का इंतज़ार करते हैंजाँच के बाद Accept का इंतज़ार

curl जैसी command Antenna से गुज़रे बिना डेटा भेज देती है, इसलिए Antenna commands को पढ़ने के बजाय उन्हें सीमित करता है। और जैसे ही कोई agent आपके प्रोजेक्ट की फ़ाइलें पढ़ लेता है, ∞ से नीचे के किसी कॉन्टैक्ट को भेजा गया उसका हर मैसेज आपका इंतज़ार करता है, और एक बातचीत पढ़ लेने के बाद किसी दूसरी बातचीत में भेजा गया मैसेज भी।

जो अंदर आता है

किसी कॉन्टैक्ट की फ़ाइल एक encrypted quarantine में रहती है, जहाँ तक आपके agents का कोई रास्ता नहीं है। Antenna उसका टाइप content से जाँचता है, उसे एक sandbox में, जिसमें न network है और न आपकी फ़ाइलों तक पहुँच, threats और secrets के लिए scan करता है, और एक सुरक्षित preview दोबारा बनाता है। Programs, installers और उन्हें रखने वाले archives Keep anyway (फिर भी रखें) और आपके password का इंतज़ार करते हैं; agents उन्हें नहीं रख सकते। अगर sandbox शुरू न हो पाए, तो फ़ाइल जाँची नहीं जाती और कोई agent उसे स्वीकार नहीं कर सकता।

आपके अपने कंप्यूटर (∞)

∞ · My computer अकेला अपवाद है, जान-बूझकर, ताकि आप अपनी .env अपने लैपटॉप और server के बीच ले जा सकें। आपके अपने कंप्यूटरों को मैसेज और फ़ाइलें बिना पूछे जाती हैं, secrets समेत, और streamed जवाब बीच में नहीं कटता; सिर्फ़ किसी दूसरे कॉन्टैक्ट की बातचीत से आया डेटा अब भी इंतज़ार करता है। Antenna फिर भी हर एक को scan करता है और जो मिला उसे उस कंप्यूटर के Activity log में लिखता है। ∞ चुनने पर पहले एक चेतावनी दिखती है; इसे किसी दूसरे व्यक्ति के कंप्यूटर के लिए कभी न चुनें।

सवाल-जवाब

क्या agent scanner बंद कर सकता है?

नहीं। Scanner daemon चलाता है, agents के पास उसे बदलने की कोई command नहीं है, और मंज़ूरी के लिए आपका password या आपकी उँगली चाहिए।

क्या Antenna git या web request से होने वाला leak रोकता है?

Scan करके नहीं: वह सिर्फ़ वही देखता है जो Antenna से होकर जाता है। Levels 1–3 के किसी कॉन्टैक्ट का मैसेज आने के बाद, Antenna के ज़रिए शुरू किया गया Claude Code कोई command नहीं चलाता, और level 4 पर हर command आपका इंतज़ार करती है।
