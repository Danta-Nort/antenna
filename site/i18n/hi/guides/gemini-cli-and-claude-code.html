एक क्लिक में Gemini CLI को Antenna से जोड़ें, Antenna की विंडो में Claude Code शुरू करें, और Antenna के agent map पर दोनों के बीच एक लाइन खींचें। उसके बाद दोनों Antenna के MCP tools से एक-दूसरे को लिखते हैं: Gemini CLI, Claude Code से किसी बदलाव का review माँगता है, Claude Code, Gemini CLI को कोई task सौंपता है, और जवाब उसी रास्ते वापस आता है। दोनों आपके अपने Google और Claude sign-in पर चलते रहते हैं, बिना API keys के।

एक कंप्यूटर पर

  1. Antenna इंस्टॉल करें (macOS या Linux) और अपना node बनाएँ: एक password, कोई अकाउंट नहीं।
  2. Agents → AI apps खोलें और Gemini CLI के आगे Connect दबाएँ। Assistant with access to my projects (मेरे प्रोजेक्ट्स तक पहुँच वाला assistant) चुनें, अपना password डालें, Continue दबाएँ, पढ़ें कि Antenna ~/.gemini/settings.json में क्या जोड़ेगा, और Write and connect दबाएँ। Gemini CLI में /mcp reload चलाएँ (या उसे दोबारा शुरू करें): /mcp में antenna दिखेगा। उसकी row में लिखा होता है “Contacts write to it as gemini-cli”, यानी कॉन्टैक्ट्स उसे gemini-cli नाम से लिखते हैं।
  3. उसी पेज पर Claude Code के आगे Start in Code mode दबाएँ। New agent… चुनें, उसका नाम builder रखें, वही role Assistant with access to my projects चुनें, अपना password डालें और Start दबाएँ। Claude Code विंडो के अंदर एक terminal टैब में चलता है।
  4. Agents → Map खोलें, एक agent के handle से दूसरे तक drag करें, अपना password डालें और Connect दबाएँ। दोनों को एक local route मिलता है: उनके मैसेज कभी कंप्यूटर से बाहर नहीं जाते, और हर एक दूसरे के मैसेज को task की तरह लेता है, जब तक आप वह tick न हटा दें।

दोनों को एक ही role दें: Antenna ऐसे agent को, जिसने आपका ज़्यादा डेटा देखा है, कम डेटा देखने वाले agent को लिखने नहीं देता।

वे एक-दूसरे को कैसे पुकारते हैं

लाइन खिंचने के बाद हर agent दूसरे का default साथी होता है: “इसे अपने साथी को भेज दो” कहना काफ़ी है। नाम से बुलाने के लिए agent send_message call करता है, जिसमें local_agent को gemini-cli या builder पर सेट किया जाता है। पाने वाला read_inbox से पढ़ता है, या wait_for_message से इंतज़ार करता है, हर call में ज़्यादा से ज़्यादा 10 मिनट।

दोनों अलग तरह से इंतज़ार करते हैं। Code mode में Claude Code अपने-आप जाग जाता है: अगर मैसेज आने पर वह ख़ाली बैठा हो, तो Antenna उसके लिए एक लाइन टाइप कर देता है कि वह अपना inbox पढ़े। Experimental। Antenna अभी Gemini CLI को नहीं जगाता, इसलिए Gemini CLI अपने मैसेज तब पढ़ता है जब वह अगली बार Antenna को call करता है। इसलिए बातचीत शुरू करने के लिए Gemini CLI ही सही रहता है: “builder से src/ के diff का review करवाओ, फिर उसके जवाब का इंतज़ार करो और जो मिले उसे ठीक करो।” Claude Code जागता है, review करता है और जवाब देता है। Gemini CLI को काम सौंपना हो, तो पहले उसे मैसेज का इंतज़ार करने को कहें।

दो कंप्यूटरों पर

Gemini CLI एक कंप्यूटर पर और Claude Code दूसरे पर रह सकता है। दोनों पर Antenna इंस्टॉल करें और उन्हें एक बार इनवाइट लिंक और छह अंकों के कोड से जोड़ें, This is my own computer (∞) पर tick लगाकर। फिर map पर दोनों agents के बीच लाइन खींचें। दूसरा कंप्यूटर अपनी तरफ़ के लिए आपसे मंज़ूरी माँगता है, वहीं पर या My devices में, इसलिए वहाँ आपके बिना कुछ नहीं बदलता। बिना स्क्रीन वाले server पर Claude Code antenna connect claude-code और antenna session start से चलता है: देखें VPS पर Claude Code।

आप क्या मंज़ूर करते हैं, और क्या सीमित रहता है

  • कनेक्शन आपके हाथ में हैं। लाइन खींचने के लिए आपका password चाहिए; कोई भी agent कनेक्शन बना या बदल नहीं सकता।
  • Antenna हर मैसेज जाँचता है। एक ही कंप्यूटर के दो agents के बीच ऐसा मैसेज रोक दिया जाता है जिसमें key, password या token होने का शक हो, और 10 मिनट में 8 मैसेज के बाद सिलसिला रुक जाता है, ताकि दोनों एक-दूसरे को हमेशा व्यस्त न रख सकें।
  • Trust levels वहीं जाते हैं जहाँ agent का पढ़ा हुआ जाता है। एक ही कंप्यूटर पर, अगर एक agent ने किसी कॉन्टैक्ट का मैसेज पढ़ा है, तो उसका मैसेज उस कॉन्टैक्ट की पाबंदियाँ दूसरे agent तक ले जाता है, और दूसरा agent भी ऐसे सीमित हो जाता है जैसे उसने ख़ुद वह मैसेज पढ़ा हो।
  • Claude Code हर tool से पहले जाँचा जाता है। Code mode में Antenna हर command और हर edit से पहले अपने daemon से पूछता है। Gemini CLI के अपने tools, Gemini CLI की अपनी पुष्टि (confirmation) के तहत रहते हैं; Antenna वह जाँचता है जो उससे होकर गुज़रता है।

सवाल-जवाब

क्या इसके लिए Gemini API key चाहिए?

नहीं। Gemini CLI हमेशा की तरह आपके Google अकाउंट से साइन-इन करता है और Claude Code आपके Claude plan से। Antenna सिर्फ़ मैसेज ले जाता है।

क्या दो Gemini CLI विंडो एक साथ Antenna इस्तेमाल कर सकती हैं?

एक समय में एक: एक agent एक समय में एक ही session में काम करता है, और Connect Gemini CLI को एक agent देता है।

क्या यह पूरी तरह तैयार है?

Map पर agents को जोड़ना और ख़ाली बैठे agents को जगाना Antenna 0.1 में experimental के रूप में चिह्नित हैं: ये काम करते हैं और इनके tests हैं, पर अभी बदल सकते हैं।
