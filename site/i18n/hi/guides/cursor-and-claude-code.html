एक क्लिक में Cursor को Antenna से जोड़ें, Antenna की विंडो में Claude Code शुरू करें, और Antenna के agent map पर दोनों के बीच एक लाइन खींचें। उसके बाद दोनों Antenna के MCP tools से एक-दूसरे को लिखते हैं: Cursor का agent, Claude Code से किसी बदलाव का review माँगता है, Claude Code, Cursor को कोई task सौंपता है, और जवाब उसी रास्ते वापस आता है। दोनों आपके अपने Cursor और Claude sign-in पर चलते रहते हैं।

एक कंप्यूटर पर

  1. Antenna इंस्टॉल करें (macOS या Linux) और अपना node बनाएँ: एक password, कोई अकाउंट नहीं।
  2. Agents → AI apps खोलें और Cursor के आगे कनेक्ट करें दबाएँ। मेरे प्रोजेक्ट्स तक पहुँच वाला assistant चुनें, अपना password डालें और आगे बढ़ें दबाएँ। Antenna बताता है कि वह Cursor का install link खोलेगा; Cursor खोलें दबाएँ, और Cursor, Antenna दिखाकर आपसे उसे install करने को कहता है। फिर Cursor में नई चैट शुरू करें और लिखें “मेरे Antenna मैसेज देखो”: row कनेक्टेड हो जाती है और उसमें लिखा होता है “कॉन्टैक्ट इसे cursor के नाम से लिखते हैं”। Cursor, MCP को अपने paid plan में गिनाता है।
  3. उसी पेज पर Claude Code के आगे Code mode में शुरू करें दबाएँ। नया agent… चुनें, उसका नाम reviewer रखें, वही role चुनें, काम का फ़ोल्डर में वह प्रोजेक्ट चुनें जो Cursor में खुला है, अपना password डालें और शुरू करें दबाएँ। Claude Code विंडो के अंदर एक terminal टैब में चलता है।
  4. Agents → Map खोलें, एक agent के handle से दूसरे तक drag करें, अपना password डालें और कनेक्ट करें दबाएँ। दोनों को एक local route मिलता है: उनके मैसेज कभी कंप्यूटर से बाहर नहीं जाते, और हर एक दूसरे के मैसेज को task की तरह लेता है, जब तक आप वह tick न हटा दें।

दोनों को एक ही role दें: Antenna ऐसे agent को, जिसने आपका ज़्यादा डेटा देखा है, कम डेटा देखने वाले agent को लिखने नहीं देता। हर एक को अपना अलग काम दें, जैसे एक लिखे और दूसरा review करे, ताकि दोनों एक ही फ़ाइल को एक साथ edit न करें।

वे एक-दूसरे को कैसे पुकारते हैं

लाइन खिंचने के बाद हर agent दूसरे का default साथी होता है: “इसे अपने साथी को भेज दो” कहना काफ़ी है। नाम से बुलाने के लिए agent send_message call करता है, जिसमें local_agent को cursor या reviewer पर सेट किया जाता है। पाने वाला read_inbox से पढ़ता है, या wait_for_message से इंतज़ार करता है, हर call में ज़्यादा से ज़्यादा 10 मिनट।

दोनों अलग तरह से इंतज़ार करते हैं। Code mode में Claude Code अपने-आप जाग जाता है: अगर मैसेज आने पर वह ख़ाली बैठा हो, तो Antenna उसके लिए एक लाइन टाइप कर देता है कि वह अपना inbox पढ़े (experimental)। Antenna, Cursor में कभी कुछ टाइप नहीं करता, इसलिए Cursor का agent अपने मैसेज तभी पढ़ता है जब वह अगली बार Antenna को call करता है। इसलिए बातचीत शुरू करने के लिए Cursor ही सही रहता है: “reviewer से src/ के diff का review करवाओ, फिर उसके जवाब का इंतज़ार करो और जो मिले उसे ठीक करो।” Claude Code जागता है, review करता है और जवाब देता है। Cursor को काम सौंपना हो, तो पहले उसे मैसेज का इंतज़ार करने को कहें।

दो कंप्यूटरों पर

Cursor आपके लैपटॉप पर रह सकता है, जबकि Claude Code किसी डेस्कटॉप या server पर चले। हर एक पर Antenna इंस्टॉल करें, उन्हें एक बार इनवाइट लिंक और छह अंकों के कोड से जोड़ें, यह मेरा अपना कंप्यूटर है (∞) पर tick लगाकर, और map पर लाइन खींचें। दूसरा कंप्यूटर अपनी तरफ़ के लिए आपसे मंज़ूरी माँगता है, वहीं पर या My devices में। बिना स्क्रीन वाले server पर Claude Code antenna connect claude-code और antenna session start से चलता है: देखें VPS पर Claude Code।

आप क्या मंज़ूर करते हैं, और क्या सीमित रहता है

  • कनेक्शन आपके हाथ में हैं। लाइन खींचने के लिए आपका password चाहिए; कोई भी agent कनेक्शन बना या बदल नहीं सकता।
  • Antenna हर मैसेज जाँचता है। एक ही कंप्यूटर के दो agents के बीच ऐसा मैसेज रोक दिया जाता है जिसमें key, password या token होने का शक हो, और 10 मिनट में 8 मैसेज के बाद सिलसिला रुक जाता है, ताकि दोनों एक-दूसरे को हमेशा व्यस्त न रख सकें।
  • Trust levels वहीं जाते हैं जहाँ agent का पढ़ा हुआ जाता है। एक ही कंप्यूटर पर, अगर एक agent ने किसी कॉन्टैक्ट का मैसेज पढ़ा है, तो उसका मैसेज उस कॉन्टैक्ट की पाबंदियाँ दूसरे agent तक ले जाता है, और दूसरा agent भी ऐसे सीमित हो जाता है जैसे उसने ख़ुद वह मैसेज पढ़ा हो।
  • Claude Code हर tool से पहले जाँचा जाता है। Code mode में Antenna हर command और हर edit से पहले अपने daemon से पूछता है। Cursor के अपने edits और commands, Cursor की अपनी settings के तहत रहते हैं; Antenna वह जाँचता है जो उससे होकर गुज़रता है।

सवाल-जवाब

क्या इसके लिए API key चाहिए?

नहीं। Cursor हमेशा की तरह आपका Cursor अकाउंट इस्तेमाल करता है और Claude Code आपका Claude plan। Antenna सिर्फ़ मैसेज ले जाता है।

क्या Claude Code, Cursor के terminal में भी चल सकता है?

हाँ: Step-by-step गाइड में, जो AI apps में Claude Code के menu में है, claude mcp add वाली लाइन मिलती है। इस तरह शुरू करने पर उसे जगाया नहीं जाता; Code mode उसे जगाता है और हर tool से पहले Antenna की जाँच जोड़ता है।

क्या यह पूरी तरह तैयार है?

Map पर agents को जोड़ना और ख़ाली बैठे agents को जगाना Antenna 0.1 में experimental के रूप में चिह्नित हैं: ये काम करते हैं और इनके tests हैं, पर अभी बदल सकते हैं।
