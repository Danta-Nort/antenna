प्राइवेसी पॉलिसी

संक्षेप में: यह साइट आपके बारे में कुछ भी जमा नहीं करती। इसमें न कोई फ़ॉर्म है, न ट्रैकर, न एनालिटिक्स, न कुकीज़, और यह दूसरी साइटों से कुछ भी लोड नहीं करती। Antenna ऐप से हम सिर्फ़ नए इंस्टॉल गिन पाते हैं: न कोई पता, न कोई कंटेंट।

यह साइट

  • न एनालिटिक्स, न ट्रैकिंग पिक्सेल, न विज्ञापन, न कुकीज़।
  • न बाहरी स्क्रिप्ट, न फ़ॉन्ट, न तस्वीरें — सब कुछ antenna.contact से ही आता है।
  • इनवाइट लिंक: पते में “#” के बाद वाला हिस्सा आपके ब्राउज़र में ही रहता है। यह साइट उसे कभी नहीं पाती।
  • डाउनलोड बटन आपको GitHub पर फ़ाइल तक ले जाते हैं, जहाँ GitHub की प्राइवेसी नीति लागू होती है।

यह साइट Cloudflare Workers पर चलती है। किसी भी वेब server की तरह, पेज आप तक पहुँचाने के लिए Cloudflare आपके IP address का इस्तेमाल करता है; हम कोई request log नहीं रखते।

Antenna ऐप

Antenna में न कोई अकाउंट है, न हमारा कोई server जो आपके मैसेज ले जाता हो: मैसेज और फ़ाइलें बातचीत करने वाले लोगों के डिवाइस के बीच end-to-end encrypted होकर जाती हैं, सीधे या किसी relay के ज़रिए, जो सिर्फ़ encrypted ट्रैफ़िक आगे भेजता है। नए इंस्टॉल गिनने के अलावा ऐप कोई usage डेटा या crash report नहीं भेजता; हमारे server को वह सिर्फ़ एक ही request भेजता है — नीचे बताया गया अपडेट चेक।

दिन में एक बार ऐप updates.stillbyte.dev से पूछता है कि कोई नई signed release है या नहीं। इस request में आपके, आपके कॉन्टैक्ट्स या आपके मैसेज के बारे में कुछ नहीं होता; किसी भी वेब request की तरह इससे host को कंप्यूटर का IP address दिखता है। वर्ज़न 0.1.1 से, Antenna इंस्टॉल करने के बाद पहले चेक में एक निशान होता है जो बताता है “पहला चेक”, और कुछ नहीं, ताकि हम नए इंस्टॉल गिन सकें। अपडेट server गिनता है कि उसे रोज़ कितने अपडेट चेक मिले, और उनमें से कितने किसी नए इंस्टॉल का पहला चेक थे; वह कोई address सेव नहीं करता। चेक बंद करने के लिए ~/.config/antenna/update-url में off लिख दें।

क्लोज़्ड बीटा के अनुरोध

पब्लिक रिलीज़ से पहले इस साइट पर क्लोज़्ड बीटा के लिए एक फ़ॉर्म था। उसके ज़रिए भेजे गए ईमेल पते सिर्फ़ यह बताने के लिए इस्तेमाल होते हैं कि Antenna अब उपलब्ध है, और फिर डिलीट कर दिए जाते हैं। अगर आप चाहते हैं कि आपका पता अभी डिलीट हो, तो हमें लिखें।

आपके अधिकार

हमारे पास आपके बारे में क्या है, यह जानने, उसे सुधरवाने या डिलीट करवाने के लिए hello@antenna.contact पर लिखें। हम 30 दिन के भीतर जवाब देंगे।
