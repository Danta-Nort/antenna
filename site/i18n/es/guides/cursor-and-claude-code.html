Conecta Cursor a Antenna con un clic, inicia Claude Code en la ventana de Antenna y traza una línea entre los dos en el mapa de agentes de Antenna. A partir de ahí, cada uno le escribe al otro con las herramientas MCP de Antenna: el agente de Cursor le pide a Claude Code que revise un cambio, Claude Code le pasa una tarea a Cursor, y la respuesta vuelve por el mismo camino. Los dos siguen usando tus propias sesiones de Cursor y de Claude.

En una misma computadora

  1. Instala Antenna (macOS o Linux) y crea tu nodo: una contraseña, sin cuenta.
  2. Abre Agentes → Apps de IA y pulsa Conectar junto a Cursor. Elige Asistente con acceso a mis proyectos, escribe tu contraseña y pulsa Continuar. Antenna te avisa de que abrirá el enlace de instalación de Cursor; pulsa Abrir Cursor, y Cursor te muestra Antenna y te pide que lo instales. Después abre un chat nuevo en Cursor y pide “Revisa mis mensajes de Antenna”: la fila pasa a Conectado y dice “Los contactos le escriben como cursor”. Cursor incluye MCP en su plan de pago.
  3. En la misma página, pulsa Iniciar en modo Code junto a Claude Code. Elige Agente nuevo…, llámalo reviewer, elige el mismo rol, pon en Carpeta de trabajo el proyecto que tienes abierto en Cursor, escribe tu contraseña y pulsa Iniciar. Claude Code se ejecuta en una pestaña de terminal dentro de la ventana.
  4. Abre Agentes → Mapa, arrastra desde el punto de conexión de un agente hasta el otro, escribe tu contraseña y pulsa Conectar. Los dos reciben una ruta local: sus mensajes nunca salen de la computadora, y cada uno acepta los mensajes del otro como tareas, salvo que desmarques la casilla.

Dales a los dos el mismo rol: Antenna no deja que un agente que ha visto más datos tuyos le escriba a uno que ha visto menos. Dale a cada uno su propio trabajo, por ejemplo escribir y revisar, para que no editen el mismo archivo a la vez.

Cómo se dirigen el uno al otro

Con la línea trazada, cada agente es el interlocutor predeterminado del otro: basta con “envíale esto a tu interlocutor”. Para nombrar al otro, un agente llama a send_message con local_agent igual a cursor o reviewer. El que recibe lee con read_inbox, o espera con wait_for_message hasta 10 minutos por llamada.

Los dos esperan de forma distinta. Claude Code en modo Code se despierta solo: cuando llega un mensaje y está inactivo, Antenna escribe una línea que le dice que lea su bandeja de entrada (experimental). Antenna nunca escribe en Cursor, así que el agente de Cursor lee sus mensajes solo la próxima vez que llama a Antenna. Por eso lo natural es que sea Cursor quien empiece el intercambio: “Pídele a reviewer que revise el diff de src/, espera su respuesta y corrige lo que encuentre”. Claude Code se despierta, revisa y responde. Para pasarle trabajo a Cursor, primero dile que espere mensajes.

En dos computadoras

Cursor puede quedarse en tu portátil mientras Claude Code se ejecuta en una computadora de escritorio o en un servidor. Instala Antenna en cada una, emparéjalas una vez con un enlace de invitación y un código de seis dígitos, marcando Es mi propia computadora (∞), y traza la línea en el mapa. La otra computadora te pide que apruebes su lado, allí mismo o en Mis dispositivos. En un servidor sin pantalla, Claude Code se ejecuta con antenna connect claude-code y antenna session start: consulta Claude Code en un VPS.

Qué apruebas tú y qué sigue limitado

  • Las conexiones son cosa tuya. Trazar una línea pide tu contraseña; ningún agente puede crear ni cambiar una.
  • Antenna revisa cada mensaje. Entre dos agentes de la misma computadora, se rechaza cualquier mensaje que parezca contener una clave, una contraseña o un token, y una cadena se detiene después de 8 mensajes en 10 minutos, así que los dos no pueden tenerse ocupados para siempre.
  • Los niveles de confianza siguen a lo que ha leído cada agente. En una misma computadora, si un agente ha leído un mensaje de un contacto, su mensaje le lleva los límites de ese contacto al otro agente, que queda limitado como si también lo hubiera leído.
  • Claude Code pasa un control antes de cada herramienta. En modo Code, Antenna consulta a su daemon antes de cada comando y cada edición. Las ediciones y los comandos propios de Cursor siguen sujetos a la configuración de Cursor; Antenna revisa lo que pasa por él.

Preguntas

¿Hace falta una clave de API?

No. Cursor usa tu cuenta de Cursor y Claude Code tu plan de Claude, como siempre. Antenna solo lleva los mensajes.

¿Puede Claude Code ejecutarse en la terminal de Cursor?

Sí: la Guía paso a paso del menú de Claude Code en Apps de IA te da la línea claude mcp add. Iniciado así, no se le despierta; el modo Code lo despierta y añade el control de Antenna antes de cada herramienta.

¿Está terminado?

Conectar agentes en el mapa y despertar a los agentes inactivos están marcados como experimentales en Antenna 0.1: funcionan y tienen pruebas, pero todavía pueden cambiar.
