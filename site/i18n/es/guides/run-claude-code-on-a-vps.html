Instala Claude Code y el nodo de Antenna en tu VPS Linux, empareja el servidor con tu portátil una vez e inicia Claude Code a través de Antenna en la carpeta de tu proyecto. A partir de ahí se ejecuta en su propia sesión de tmux aunque cierres la sesión, se despierta cuando le llega un mensaje y responde en un chat de tu portátil. Sin puertos de entrada que abrir ni sesiones SSH que mantener vivas, y con Codex funciona igual.

Qué necesitas

  • Un servidor Linux x86_64, con Claude Code (o Codex) instalado y con la sesión iniciada, y tmux.
  • Antenna en tu portátil: macOS o Linux.

1. Instala el nodo de Antenna en el servidor

curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER

El instalador lee la versión más reciente del manifiesto firmado, comprueba el archivo, instala antennad y antenna en ~/.local/bin como servicio de usuario de systemd (sin necesidad de root) y crea tu nodo con una contraseña. La segunda línea mantiene el servicio en marcha cuando cierras la sesión. En Ubuntu o Fedora también puedes instalar el .deb o el .rpm.

2. Emparéjalo con tu portátil

En tu portátil: Contacto nuevo → Invitar, ponle un nombre, marca Es mi propia computadora (∞), pulsa Crear enlace y cópialo. En el servidor:

antenna join '<link>' --trust 5 --label mac

No quites las comillas simples: el enlace contiene un #. Escribe en la terminal del servidor el código que muestra tu portátil y luego pulsa El contacto lo confirmó: los códigos coinciden en el portátil. El nivel 5 es ∞ en los dos lados, así que el servidor cuenta como una computadora tuya.

3. Inicia Claude Code a través de Antenna

cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev

La línea con «connect» le da a la sesión su propio agente y su propio token, y saluda para que en tu portátil aparezca un chat llamado api-dev. La línea con «start» inicia Claude Code en el servidor tmux propio de Antenna (tu tmux no se toca). Conéctate una vez para responder a las primeras preguntas de Claude Code, como si confía en la carpeta, y luego sal con Ctrl-b d: sigue en marcha. Para Codex, usa antenna connect codex y --cli codex.

4. Háblale

Escribe en el chat api-dev de tu portátil: “Ejecuta las pruebas de la migración y arregla lo que falle”. Cuando Claude Code está inactivo en su prompt, Antenna escribe una línea corta para que lea tu mensaje; nunca escribe el texto de un contacto ni responde por él a una pregunta. La ficha del servidor en Mis dispositivos muestra su estado y sus agentes, y puedes aprobar sus peticiones desde el portátil.

Después de un reinicio

Las claves del nodo quedan bloqueadas cuando el servidor se reinicia: el servicio sigue en marcha, pero sus enlaces se quedan en silencio hasta que inicias sesión y ejecutas antenna unlock. Así, una copia del disco del servidor no le da tus claves a nadie. antenna status te dice si está bloqueado.

Preguntas

¿Por qué no usar simplemente SSH y tmux?

Eso funciona mientras estás delante de una terminal. Antenna añade un chat al que puedes escribir desde tu portátil en cualquier momento, despierta a la sesión cuando lo haces y deja que otros agentes le pasen trabajo, con permisos que comprueba él mismo.

¿El servidor necesita una IP pública o puertos abiertos?

No. Los dos lados se conectan hacia fuera, directamente cuando la red lo permite y, si no, a través de un relay. El relay solo reenvía tráfico cifrado.

¿Puedo ejecutar varias sesiones en un mismo servidor?

Sí: un agente por carpeta de proyecto, cada uno con su propio nombre y su propio chat en tu portátil.

¿Hay versión para ARM?

Todavía no. El nodo de servidor está compilado para Linux x86_64.
