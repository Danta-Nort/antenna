Instala Antenna en tu portátil y en la computadora donde se ejecuta Claude Code, empareja las dos una vez como computadoras tuyas e inicia Claude Code allí a través de Antenna. En tu portátil aparece un chat con esa sesión: escribe en él una tarea, Antenna despierta a Claude Code cuando está inactivo y su respuesta vuelve al chat. Los mensajes viajan por un enlace peer-to-peer cifrado de extremo a extremo entre tus dos computadoras, Antenna no necesita ninguna cuenta y los pasos que requieren tu aprobación llegan al portátil, donde respondes con tu contraseña.

El Remote Control de Claude Code y Antenna

Claude Code tiene su propia función Remote Control integrada; la documentación de Anthropic la describe. Esta guía trata de otra configuración: Claude Code se ejecuta en una computadora tuya que sigue encendida, un servidor o un escritorio, y lo manejas desde Antenna en tu portátil. Te conviene si quieres:

  • Varias sesiones en varias computadoras, en una sola lista. Cada sesión es su propio chat, y Mis dispositivos muestra el estado de cada computadora, sus agentes y las peticiones que esperan allí.
  • Tu propio enlace. Los mensajes se cifran en una computadora y se descifran en la otra. Tus computadoras se conectan directamente cuando la red lo permite y, si no, a través de un relay que solo reenvía tráfico cifrado. Sin cuenta y sin puertos de entrada.
  • Permisos que comprueba el daemon de Antenna en la computadora donde se ejecuta Claude Code, con aprobaciones que respondes desde la computadora tuya en la que estés.
  • Otros agentes de la misma forma: Codex funciona igual que Claude Code.

Cómo configurarlo

  1. Instala Antenna en las dos computadoras: la app en tu portátil (macOS o Linux) y, en la otra computadora, la app o, en un servidor Linux, el nodo: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
  2. Emparéjalas una vez. En el portátil: Contacto nuevo → Invitar, marca Es mi propia computadora (∞), pulsa Crear enlace y cópialo. En un servidor: antenna join '<link>' --trust 5 --label mac; en un escritorio: Contacto nuevo → Unirse, con la misma casilla marcada. Escribe en un lado el código que muestra el otro y pulsa El contacto lo confirmó: los códigos coinciden en el portátil.
  3. Inicia Claude Code a través de Antenna en la otra computadora. En un servidor, en la carpeta del proyecto (hace falta tmux): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Responde a las primeras preguntas de Claude Code y sal con Ctrl-b d: sigue en marcha, y en tu portátil tienes un chat llamado api-dev. En un escritorio: Agentes → Apps de IA → Iniciar en modo Code, y Claude Code se ejecuta allí en una pestaña de la ventana de Antenna; pídele una vez que salude a tu portátil a través de Antenna y su chat aparecerá en el portátil.
  4. Deja que el portátil responda a las peticiones de aprobación de esa computadora. En un servidor: antenna devices confirm mac. En un escritorio: Mis dispositivos → la ficha del portátil → Aprobaciones → Aceptar aprobaciones firmadas con …, con tu contraseña.

Manéjalo desde tu portátil

  • Dale una tarea. Escribe en el chat de la sesión como le escribirías a una persona. Cuando Claude Code está inactivo en su prompt, Antenna escribe una línea fija para que lea tu mensaje; nunca escribe tu texto en la terminal ni responde a una pregunta que Claude Code haga allí. Experimental.
  • Interrúmpelo. Activa Urgente: interrumpir ahora antes de enviar: Antenna pulsa Esc una vez para terminar el turno en curso, nunca encima de una pregunta o un aviso de permisos abierto allí, y Claude Code lee tu mensaje. Experimental.
  • Aprueba sus pasos. Un paso que te necesita aparece en la ficha de la otra computadora en Mis dispositivos, con una notificación. Pulsa Aprobar con contraseña, Aprobar con Touch ID en un Mac, o Rechazar. Experimental.
  • Detenlo. Detener el agente y sus procesos…, junto al agente en esa ficha, termina Claude Code y todo lo que inició allí. Experimental.

El aviso de permisos propio de Claude Code («Do you want to proceed?») se queda en su terminal en la otra computadora, y Antenna nunca lo responde. Permite en la configuración de Claude Code las herramientas que usas a diario, o respóndelo con antenna session attach.

Codex y otros agentes

Codex funciona igual: antenna connect codex y --cli codex en un servidor, o Iniciar en modo Code junto a Codex en un escritorio (consulta Controlar Codex CLI en remoto). Gemini CLI se conecta desde Agentes → Apps de IA y envía y lee mensajes a través de Antenna, pero Antenna todavía no lo despierta: lee un mensaje nuevo la próxima vez que llama a Antenna.

Preguntas

¿Veo la terminal de Claude Code en mi portátil?

No. Das tareas y lees respuestas en un chat; la terminal se queda en la otra computadora. Para verla, ejecuta allí antenna session attach, por SSH si quieres.

¿La otra computadora necesita una IP pública o puertos abiertos?

No. Las dos computadoras se conectan hacia fuera, directamente cuando la red lo permite y, si no, a través de un relay. El relay solo reenvía tráfico cifrado.

¿Quién más puede darle tareas?

Solo los contactos emparejados con esa computadora cuyos mensajes el agente puede leer (con --links mac, solo tu portátil) y los agentes que conectes con él en el mapa de agentes. Lo que el mensaje de un contacto puede hacerle hacer lo decide el daemon de Antenna en esa computadora, no Claude Code, según el nivel de confianza de ese contacto.

¿Necesita una clave de API?

No. Claude Code mantiene tu propio inicio de sesión en la computadora donde se ejecuta, y Antenna solo transporta mensajes, archivos y aprobaciones.

¿Puedo controlarlo desde el móvil?

Todavía no. Por ahora Antenna funciona en macOS y Linux.
