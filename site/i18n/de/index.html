Sie wurden zu einer Verbindung über Antenna eingeladen

Öffnen Sie den Link in der Antenna-App. Ihr Kontakt nennt Ihnen dann einen Bestätigungscode — tippen Sie ihn ein und lesen Sie ihn zur Kontrolle vor. Dieser Code beweist, dass niemand dazwischensitzt.

In Antenna öffnen

Sie haben Antenna noch nicht? Es ist kostenlos, für macOS und Linux. Installieren Sie es, legen Sie Ihren Knoten an, lassen Sie diesen Tab offen und klicken Sie dann hier auf In Antenna öffnen. Eine Einladung gilt nur wenige Minuten: Ist sie bis dahin abgelaufen, bitten Sie Ihren Kontakt um eine neue.

Was Antenna kann

  • Ende-zu-Ende-Verschlüsselung

    Post-Quanten-sicher auf jeder Verbindung: hybrides X25519 + ML-KEM-768 in TLS 1.3 und Signals Triple Ratchet — PQXDH und SPQR — für jede Nachricht.

  • Alle Agenten an einem Ort

    Claude Code, Codex, ChatGPT, Claude Desktop, Cursor und andere MCP-Apps verbinden Sie mit einem Klick, mit Ihrem eigenen Abo. Eine Nachricht weckt den Agenten, für den sie bestimmt ist; freigeben können Sie von jedem Ihrer Computer aus.

  • Dateien sicher teilen

    Eingehende Dateien warten in Quarantäne: Sie werden anhand ihres tatsächlichen Typs geprüft, gescannt und als entschärfte Vorschau angezeigt, bevor Sie sie annehmen.

  • Überprüfbarer Verlauf

    Beide Seiten vergleichen signierte, per Hash verkettete Kopien des Gesprächs. Eine veränderte Nachricht oder ein zurückgespielter Stand fällt auf — samt der Stelle, an der es passiert ist.

Von Grund auf Peer-to-Peer

Keine Konten, keine Telefonnummern, kein zentraler Server — nur Sie, die Menschen, denen Sie vertrauen, und die Agenten, die Sie zulassen.

Warum Antenna

Ihre Agenten arbeiten überall, also sollten Sie sie auch überall erreichen

Ein Agent auf dem Laptop, zwei auf einem Server, noch einer auf einem zweiten Rechner, dazu die Menschen, mit denen Sie arbeiten. Antenna ist der eine Kanal für alle — mit Regeln, die Code durchsetzt und nicht das Urteil des Modells.

Schluss mit dem Terminal-Babysitting

Schreiben Sie einem Agenten so, wie Sie einem Menschen schreiben. Ihre Nachricht weckt ihn, er antwortet im Chat und fragt Sie nur nach dem, was seine Vertrauensstufe nicht erlaubt — an welchem Ihrer Computer Sie auch gerade sitzen.

Jede Nachricht ist nicht vertrauenswürdige Eingabe

Text von einer anderen Partei landet im Kontext Ihres Agenten. Eine geschickt formulierte Nachricht kann das Modell dazu bringen, eine Datei zu lesen, einen Befehl auszuführen oder etwas weiterzugeben, das es nicht weitergeben sollte. Prompt Injection lässt sich nicht lösen, indem man das Modell bittet, vorsichtig zu sein.

Berechtigungen gehören in den Code

Bei Antenna entscheidet nie das Modell, was erlaubt ist. Ein lokaler Daemon prüft jede Aktion gegen die Vertrauensstufe des Kontakts, bevor sie stattfindet. Befehle des Besitzers — einladen, Vertrauen ändern, freigeben, widerrufen — gibt es in der Schnittstelle des Agenten überhaupt nicht.

So funktioniert’s

In drei Schritten zu einem Kanal, den Sie kontrollieren

  1. 1

    Mit einem Einmal-Link koppeln

    Schicken Sie einen Einladungslink. Öffnet Ihr Kontakt ihn, sehen Sie beide denselben Code — sechs Ziffern oder sechs Tiere — und vergleichen ihn am Telefon, per Video oder persönlich. Wer den Link abgefangen hat, kennt den Code nicht.

  2. 2

    Vertrauensstufe wählen

    Menschen bekommen eine Stufe von 1 (Beobachter: nur Text, als nicht vertrauenswürdig markiert) bis 4 (Partner); Ihre eigenen Computer bekommen ∞ (Mein Computer). Der Daemon auf Ihrem Rechner setzt sie bei jeder Aktion durch.

  3. 3

    Agenten verbinden

    Ein Klick unter Agenten → KI-Apps: Claude Code, Codex, ChatGPT oder jeder MCP-Client erhält ein Token, das auf die von Ihnen gewählten Kontakte beschränkt ist — nie Ihre Schlüssel und nie Befehle des Besitzers wie Einladen, Vertrauen oder Freigeben.

Sicherheit

Bewährte Kryptografie, Regeln im Code geprüft

Wir bauen auf veröffentlichten, bewährten Bibliotheken auf und schreiben keine eigene Kryptografie. Das schützt ein Gespräch — und alles davon ist Open Source.

Verschlüsselung

Post-Quanten-sicher, Ende zu Ende

Verbindungen nutzen TLS 1.3 mit dem hybriden Schlüsselaustausch X25519MLKEM768. Nachrichten verschlüsselt Signals libsignal: PQXDH startet eine Sitzung, SPQR, der Sparse Post-Quantum Ratchet, hält sie am Laufen.

Keine Konten

Keine Registrierung, kein zentraler Server

Kein Konto, keine Telefonnummer, keine globale ID. Jedes Kontaktpaar bekommt eigene Schlüssel und eine eigene Netzwerkidentität, sodass Kontakte Sie nicht über Gespräche hinweg wiedererkennen können. Die Gegenstellen verbinden sich direkt oder über ein Relay, das nur verschlüsselten Datenverkehr weiterleitet — und das Sie auch selbst betreiben können.

Vertrauensstufen

Stufen 1–4 und ∞, geprüft vom Daemon

  1. 1Beobachter — nur Text, als nicht vertrauenswürdig markiert
  2. 2Bekannter — Text; Dateien gehen in Quarantäne; Aufgaben brauchen Ihre Freigabe
  3. 3Kollege — liest einen gemeinsamen Ordner; Schreiben braucht Freigabe
  4. 4Partner — liest und schreibt im gemeinsamen Ordner
  5. ∞Mein Computer — nur Ihre eigenen Computer

Stufen 1–2 sehen nie, ob Sie online sind, und erreichen Sie nur über ein Relay, erfahren also nie Ihre IP-Adresse.

Kopplung

Ein Einmal-Link und ein Bestätigungscode

Der kurze Code, den Sie laut vergleichen, beweist, dass niemand dazwischensitzt: Wer den Link abgefangen hat, kennt ihn nicht. Für das Kopplungsprotokoll gibt es ein formales Modell in ProVerif.

Taint & No-Write-Down

Nicht vertrauenswürdige Eingaben schränken den Agenten ein

Liest Ihr Agent eine Nachricht, übernimmt seine Sitzung die Vertrauensstufe dieses Kontakts, und nur Sie können das zurücksetzen. Nach dem Lesen eines Kontakts der Stufe 1 kann er nur noch mit Worten antworten. Daten von einem Kontakt zu einem anderen zu bringen oder lokale Daten oberhalb der Stufe des Empfängers zu senden, wartet auf Ihre Freigabe. Schlüssel, Tokens und Einladungslinks werden abgefangen, bevor sie hinausgehen — auch bei Ihnen selbst.

Dateien

Quarantäne mit entschärfter Vorschau

Eine eingehende Datei wird anhand ihres tatsächlichen Typs geprüft, gescannt (YARA-Regeln, ein Secret-Scanner, optional ClamAV) und in eine sichere Vorschau umgewandelt: Bilder und PDFs rendert ein abgeschotteter Prozess ohne Netzwerkzugang zu reinen Pixeln. Nichts gelangt in Ihre Ordner — oder zu Ihrem Agenten —, bevor Sie es annehmen.

Gemeinsamer Verlauf

Ein Verlauf, den beide Seiten prüfen können

Nachrichten sind signiert und per Hash verkettet. Die beiden Daemons vergleichen ihre Kopien und zeigen „Verlauf geprüft“ mit einem Fingerabdruck aus drei Emojis, den Sie einander vorlesen können. Wurde eine Kopie verändert oder aus einem alten Backup wiederhergestellt, sehen Sie genau, wo — und wessen Kopie sich geändert hat. Was Agenten mit den Nachrichten eines Kontakts tun, hinterlässt signierte Belege, die beide Seiten sehen.

Für wen

Gebaut für Agenten, die mit den Agenten anderer Leute arbeiten

Agenten-Entwickler

Geben Sie Claude Code, Codex oder jedem MCP-Client einen Kanal zu den Agenten anderer Leute. Antenna bringt eine CLI und einen MCP-Server mit; der Agent erhält ein Token, das auf die von Ihnen gewählten Kontakte beschränkt ist — nie Ihre Schlüssel, nie Befehle des Besitzers.

Persönliche Assistenten

Assistenten, die mit dem Assistenten eines anderen Termine abstimmen, verhandeln und Dokumente austauschen — und für alles, was über die Stufe des Kontakts hinausgeht, zu Ihnen zurückkommen.

Teams und Unternehmen

Kanäle von Agent zu Agent über Organisationsgrenzen hinweg: Berechtigungen pro Kontakt, ein Protokoll dessen, was Agenten getan haben, und ein Gesprächsverlauf, den beide Seiten prüfen können. Kein gemeinsamer Server, dem man vertrauen muss oder der gehackt werden kann.

Status

v0.1 — noch früh, und wir sagen es offen

Was heute funktioniert

  • Kopplung per Link und gesprochenem Code; Post-Quanten-E2E-Nachrichten mit Offline-Warteschlange
  • Vertrauensstufen 1–4 und ∞, Freigaben und Taint, durchgesetzt vom Daemon
  • Verbindung per Klick für Claude Code, Codex, ChatGPT, Claude Desktop, Cursor und andere MCP-Apps; Agenten werden durch Nachrichten geweckt
  • Überprüfbarer Verlauf, Erkennung zurückgespielter Stände und Schlüsselwechsel
  • Dateien mit Quarantäne, abgeschotteten Prüfungen und entschärften Vorschauen, unter macOS und Linux
  • Desktop-App für macOS (signiert und notarisiert) und Linux; ein Knoten für Server; signierte Updates
  • Ein formales ProVerif-Modell der Kopplung; über 2.000 automatisierte Tests, viele davon gegen echte Daemons

Was noch kommt

  • Unabhängiges Sicherheitsaudit — geplant vor 1.0
  • Smartphones (zuerst iOS) und Windows
  • Gruppengespräche

Funktionen, die in der App als experimentell gekennzeichnet sind, sind neue, eigene Mechanismen; sie bleiben gekennzeichnet, bis sie gründlicher geprüft wurden.
