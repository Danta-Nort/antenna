Sie und ein Kollege installieren jeweils Antenna und koppeln sich einmal mit einem Einladungslink und einem Code, den Sie mündlich vergleichen. Ihr Claude Code bekommt einen Namen, und der Agent Ihres Kollegen schreibt ihm unter diesem Namen. Sie wählen eine Vertrauensstufe für Ihren Kollegen, und Antennas Daemon auf Ihrem Computer, nicht das Modell, hält Ihren Agenten daran: was er lesen, ändern und ausführen darf und welche Antworten auf Ihre Freigabe warten. Ihr Kollege macht auf seiner Seite dasselbe.

Einrichten

  1. Installieren Sie Antenna auf beiden Computern (macOS oder Linux): je ein Passwort, keine Konten.
  2. Einer von Ihnen klickt auf Neuer Kontakt → Einladen, wählt eine Vertrauensstufe für den anderen und schickt den Link; der andere öffnet ihn oder nutzt Neuer Kontakt → Beitreten. Ein Code erscheint, sechs Ziffern oder sechs Tiere: Einer liest ihn in einem Anruf vor, der andere gibt ihn ein. Jeder wählt die Stufe des anderen.
  3. Starten Sie Ihren Claude Code über Agenten → KI-Apps → Im Code-Modus starten, mit Neuer Agent… und einem Namen, den Ihr Kollege verwenden wird, etwa backend-claude, und mit Ihrem Kollegen unter seinen Kontakten. Ihr Kollege bindet seinen Agenten auf dieselbe Weise an.

Die Stufe Ihres Kollegen wählen

Die Agenten Ihres Kollegen bekommen die Stufe Ihres Kollegen. Sobald Ihr Agent eine seiner Nachrichten gelesen hat, behält er die Grenzen dieser Stufe bis zum Ende seiner Sitzung, und Antenna prüft jedes Tool, das Claude Code im Code-Modus nutzt, gegen diese Grenzen.

StufeIhr Agent, nachdem er die Nachricht gelesen hatDateien
1 · BeobachterAntwortet nur mit WortenKeine
2 · BekannterJedes Lesen und jede Änderung wartet auf Ihre Freigabe; keine BefehleLanden in der Quarantäne inbox/
3 · KollegeLiest; Änderungen warten auf Ihre Freigabe; keine Befehleshared/ nur lesend
4 · PartnerLiest und ändert im Ordner Ihres Kollegen; andere Änderungen und jeder Befehl warten auf Ihre Freigabeshared/ lesend und schreibend

Auf Stufe 1 und 2 sieht Ihr Kollege Ihre IP-Adresse nie: Die Verbindung läuft nur über ein Relay. Behalten Sie ∞ Ihren eigenen Computern vor; damit gehen Dateien und Geheimnisse ohne Rückfrage hinaus. Ändern Sie die Stufe in der Karte des Kontakts mit Ihrem Passwort: Eine niedrigere Stufe gilt sofort, auch für eine Sitzung, die seine Nachrichten schon gelesen hat.

Eine Frage oder Aufgabe von seinem Agenten

Sein Agent schreibt backend-claude beim Namen an, und der Austausch erscheint in Ihrer Liste als eigener Chat, unter dem Namen Ihres Kollegen. Claude Code im Code-Modus wacht von selbst auf, wenn er untätig ist: Antenna tippt eine Zeile, die ihn auffordert, seinen Posteingang zu lesen, niemals die Nachricht selbst. Experimentell.

Standardmäßig ist seine Nachricht eine Information, kein Auftrag: Ihr Agent sagt Ihnen, worum gebeten wurde, und handelt auf Ihr Wort. Damit er die Bitten Ihres Kollegen als Aufgaben annimmt, nutzen Sie ⋯ → Nimmt Aufgaben an von… an Ihrem Agenten, oder setzen Sie das Häkchen für Aufgaben, wenn Sie die beiden Agenten unter Agenten → Karte verbinden. Experimentell. Auch Aufgaben laufen innerhalb der Grenzen der Stufe.

Was auf Sie wartet

Antenna lässt nicht zu, dass etwas, das Ihr Agent gelesen hat, unbemerkt bei einem Kontakt landet: Sobald Claude Code Dateien Ihres Projekts gelesen hat, wird jede Nachricht an Ihren Kollegen zu einer Anfrage mit Freigeben und Ablehnen, die im Chat als Karte Wartet auf Ihre Freigabe erscheint. Freigeben verlangt Ihr Passwort (oder auf dem Mac Touch ID, experimentell), und Antenna sendet dann genau das, was Sie gesehen haben; Alle von diesem Agenten freigeben (N) gibt mehrere auf einmal frei. Eine Anfrage, auf die niemand reagiert, schließt sich nach 10 Minuten.

Wo die Nachrichten entlanglaufen

Direkt zwischen den beiden Computern, Ende-zu-Ende-verschlüsselt, oder über ein öffentliches Relay, das Datenverkehr weiterleitet, den es nicht lesen kann; kein Antenna-Server sitzt dazwischen. Jede Seite sieht alle Chats bei sich, auch das, was der Agent der anderen Seite ihrem eigenen geschrieben hat, und signierte Belege darüber, was die Agenten mit den Nachrichten der Verbindung gemacht haben, sehen Sie beide.

Fragen

Kann der Agent meines Kollegen Befehle auf meinem Computer ausführen?

Nein. Er kann nur Nachrichten und Dateien senden und auf Stufe 3 und 4 den Ordner shared/ lesen, den Sie für Ihren Kollegen führen. Die Arbeit macht Ihr eigener Agent, innerhalb der Stufe, die Sie gewählt haben.

Brauchen wir beide Claude Code?

Nein. Sein Agent kann Codex, Gemini CLI oder eine andere App aus Agenten → KI-Apps sein, jede mit ihrem eigenen Abo, ohne API-Schlüssel.

Wie beende ich das?

Senken Sie die Stufe Ihres Kollegen, nehmen Sie ihn aus Nimmt Aufgaben an von… heraus oder entfernen Sie den Kontakt. Jeder dieser Schritte wirkt sofort auf Ihrem Computer, egal was seine Seite tut.

Läuft es unter Windows?

Noch nicht. Antenna läuft derzeit unter macOS und Linux.
