Auf dem Laptop selbst geht das nicht: Zuklappen schickt den Laptop in den Ruhezustand, ein schlafender Computer führt nichts aus, und Claude Code pausiert mit ihm. Der Ausweg: Claude Code auf einem Computer betreiben, der eingeschaltet bleibt, etwa einem Linux-Server oder einem Mac mini, der nicht in den Ruhezustand geht, es dort über Antenna starten und ihm Aufgaben aus dem Antenna-Chat Ihres Laptops geben. Klappen Sie den Laptop zu: Claude Code arbeitet auf dem anderen Computer weiter, und seine Antworten warten auf den Laptop und kommen an, sobald er wieder online ist.

Warum es anhält

Claude Code läuft auf dem Computer, auf dem Sie es starten. Geht dieser Computer in den Ruhezustand, hält jedes Programm darauf an, Claude Code eingeschlossen, bis er wieder aufwacht. Auch wer das Terminal oder das SSH-Fenster schließt, in dem es läuft, beendet es. Man kann einen Laptop auch zugeklappt wach halten, aber dann muss er am Strom und eingeschaltet bleiben, und er ist zum Server geworden. Also wandert die Arbeit auf einen Computer, der immer an ist, und der Laptop spricht nur noch mit ihm.

Was Sie brauchen

  • Einen Computer, der eingeschaltet bleibt: einen Linux-Server auf x86_64 (einen VPS oder einen zu Hause) oder einen Mac oder Linux-Desktop, der nicht in den Ruhezustand geht.
  • Claude Code, dort installiert und angemeldet.
  • Antenna auf beiden Computern: die App auf Ihrem Laptop (macOS oder Linux), den Knoten oder die App auf dem anderen.

Auf einem Server

  1. Installieren Sie den Antenna-Knoten und lassen Sie ihn nach dem Abmelden weiterlaufen: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
    Das Installationsskript richtet Antenna als systemd-User-Service ein und legt Ihren Knoten mit einem Passwort an. Lingering schaltet es nicht ein, es erinnert Sie nur daran: Ohne die zweite Zeile hält der Dienst an, wenn Sie sich abmelden.
  2. Koppeln Sie den Server einmal mit Ihrem Laptop. Auf dem Laptop: Neuer Kontakt → Einladen, Häkchen bei Das ist mein eigener Computer (∞) setzen, auf Link erstellen klicken und den Link kopieren. Auf dem Server: antenna join '<link>' --trust 5 --label mac, den Code eintippen, den der Laptop zeigt, und dann auf dem Laptop auf Kontakt hat bestätigt — Codes stimmen klicken.
  3. Starten Sie Claude Code über Antenna im Projektordner (der Server braucht tmux): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Beantworten Sie die ersten Fragen von Claude Code, etwa ob es dem Ordner vertraut, und verlassen Sie die Sitzung dann mit Ctrl-b d. Auf Ihrem Laptop gibt es jetzt einen Chat namens api-dev.
  4. Lassen Sie den Laptop die Freigabeanfragen des Servers beantworten: antenna devices confirm mac.

Melden Sie sich jetzt von SSH ab. Der Dienst läuft weiter, und Claude Code läuft in Antennas eigenem tmux-Server weiter; Ihr eigenes tmux bleibt unberührt. Claude Code auf einem VPS beschreibt jeden Schritt ausführlicher.

Auf einem Mac oder Desktop, der an bleibt

  1. Stellen Sie in den Systemeinstellungen des Computers ein, dass er nicht von selbst in den Ruhezustand geht. Antenna hält keinen Computer wach.
  2. Koppeln Sie ihn wie oben mit Ihrem Laptop, mit Häkchen bei Das ist mein eigener Computer (∞).
  3. Öffnen Sie dort Agenten → KI-Apps und klicken Sie neben Claude Code auf Im Code-Modus starten. Wählen Sie Neuer Agent… und geben Sie ihm einen Namen, wählen Sie den Arbeitsordner, geben Sie Ihr Passwort ein und klicken Sie auf Starten. Das Fenster wechselt in den Code-Modus, und Claude Code läuft darin in einem Tab.
  4. Bitten Sie Claude Code einmal in seinem Tab, Ihrem Laptop über Antenna Hallo zu sagen. Dann erscheint sein Chat auf dem Laptop.
  5. Lassen Sie den Laptop seine Freigabeanfragen beantworten: Meine Geräte → die Karte des Laptops → Freigaben → Mit … signierte Freigaben annehmen, mit Ihrem Passwort.

Lassen Sie das Fenster von Antenna offen: Wer es schließt, stoppt die Agenten, die darin laufen, und das Fenster fragt vorher nach.

Es arbeiten lassen

Schreiben Sie die Aufgabe im Chat des Agenten auf Ihrem Laptop: „Führ die Migrationstests aus, behebe, was fehlschlägt, und antworte hier, was sich geändert hat.“ Wartet Claude Code untätig an seiner Eingabezeile, tippt Antenna eine fest eingebaute Zeile, damit es Ihre Nachricht liest; steckt es mitten in einem Durchgang, bekommt es die Nachricht, wenn der Durchgang endet. Antenna tippt Ihren Text nie ins Terminal. Experimentell. Dann klappen Sie den Laptop zu.

Prüfen Sie vor einem langen Lauf, was ihn anhalten könnte, während niemand da ist:

  • Die eigene Berechtigungsabfrage von Claude Code („Do you want to proceed?“) wartet in seinem Terminal, bis jemand antwortet, und Antenna beantwortet sie nie. Erlauben Sie die Tools, die die Aufgabe braucht, in den Einstellungen von Claude Code.
  • Die Freigabeanfragen von Antenna warten 10 Minuten. Danach läuft nichts, und Claude Code erfährt, dass niemand freigegeben hat. Eine Aufgabe, die Sie von Ihrem eigenen Computer auf ∞ geben, führt ihre Befehle und Änderungen aus, ohne zu fragen; Änderungen an der eigenen Einrichtung von Claude Code, etwa an CLAUDE.md oder .claude/, fragen trotzdem nach.

Wenn der Laptop aufwacht

Während der Laptop schläft, warten die Antworten von Claude Code in der Warteschlange des anderen Computers, und Antenna versucht weiter, sie zuzustellen. Sobald der Laptop wieder online ist, kommen sie im Chat an, mit einer Benachrichtigung, solange das Fenster von Antenna nicht im Vordergrund ist. Eine Nachricht, die Sie offline geschrieben haben, zeigt eine Uhr und geht von selbst raus. Anfragen, die noch auf Ihre Freigabe warten, erscheinen auf der Karte des anderen Computers unter Meine Geräte (experimentell).

Nach einem Neustart des anderen Computers

Nach einem Neustart sind die Schlüssel gesperrt, seine Verbindungen bleiben also stumm, bis Sie das Passwort eingeben. Auf einem Server melden Sie sich an, führen antenna unlock aus und starten die Sitzung neu; --resume setzt die letzte Sitzung von Claude Code fort:

antenna session start api-dev --dir ~/projects/api --resume

Auf einem Mac geben Sie das Passwort im Fenster von Antenna ein und starten den Agenten neu.

Fragen

Läuft Claude Code weiter, wenn ich den Laptop zuklappe?

Nicht, wenn der Laptop beim Zuklappen in den Ruhezustand geht, und so ist er üblicherweise eingestellt: Claude Code pausiert, bis Sie ihn wieder aufklappen. Lassen Sie es auf einem Computer laufen, der eingeschaltet bleibt, dann arbeitet es weiter.

Kann Claude Code auf meinem Laptop im Hintergrund laufen?

Solange der Laptop wach ist, ja: Im Code-Modus läuft es in einem Tab des Antenna-Fensters, den Sie nicht ansehen müssen, und Antenna weckt es, wenn eine Nachricht eintrifft. Schläft der Laptop, hält es trotzdem an.

Muss ich eine SSH-Sitzung offen halten?

Nein. Claude Code läuft in Antennas tmux auf dem Server, und Sie erreichen es über den Chat. Beide Computer bauen die Verbindung nach außen auf, es wird also auch kein eingehender Port geöffnet.

Hält Antenna meinen Mac wach?

Nein. Stellen Sie in den Systemeinstellungen des Mac ein, dass er nicht in den Ruhezustand geht. Für den Code-Modus muss das Fenster von Antenna offen bleiben.

Kann ich vom Handy aus nachsehen?

Noch nicht. Antenna läuft derzeit unter macOS und Linux.
