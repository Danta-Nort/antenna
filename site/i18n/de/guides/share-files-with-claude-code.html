Auf demselben Computer liest Claude Code Ihre Dateien direkt: Nennen Sie ihm den Pfad oder ziehen Sie die Datei in sein Terminal. Auf einem anderen Computer, etwa einem Server, schicken Sie die Datei über Antenna: Ziehen Sie sie in den Chat mit dieser Claude-Code-Sitzung, Antenna prüft sie beim Eintreffen und speichert sie dort im Ordner der Verbindung, und der Agent bekommt Name, Ort, Größe und SHA-256 der Datei in seinen Posteingang. Dateien, die der Agent zurückschickt, kommen auf demselben Weg auf Ihren Laptop.

Eine Datei an den Agenten senden

  1. Koppeln Sie Ihren Laptop mit dem anderen Computer als Ihrem eigenen (∞) und verbinden Sie Claude Code dort mit Antenna: siehe Claude Code auf einem VPS.
  2. Öffnen Sie auf Ihrem Laptop den Chat mit der Sitzung und ziehen Sie die Datei hinein, oder hängen Sie sie an wie in jedem Messenger.
  3. Auf dem anderen Computer prüft Antenna den Dateityp anhand des Inhalts, sucht nach Bedrohungen und Geheimnissen und speichert die Datei im Ordner der Verbindung, ~/Antenna/links/<folder>/shared/, oder in einem Projektordner, den Sie für diesen Computer gewählt haben.
  4. Der Agent erfährt beim nächsten Blick in den Posteingang von selbst von der gespeicherten Datei, mit Pfad und Hashes, und kann sie im nächsten Schritt verwenden.

Dateien vom Agenten zurückbekommen

Der Agent kann Ihnen eine Datei, einen Build, einen Bericht oder einen Screenshot schicken, mit denselben Tools, die er für Nachrichten nutzt. Sie kommt in Ihrem Chat und unter Dateien an, als Karte mit dem Dateinamen, dem, was die Prüfung bemerkt hat, und ihrem Hash. Bilder erscheinen als geprüfte, sichere Vorschau, die Antenna neu aufgebaut hat.

Was geprüft wird und was auf Sie wartet

  • Zwischen Ihren eigenen Computern werden gewöhnliche Dateien von selbst gespeichert. Alles, was Software ausführen oder installieren kann, etwa ein Programm, ein Installer oder ein Archiv, das so etwas enthält, wartet weiter auf Ihre Entscheidung, es sei denn, Sie erlauben es für diesen Computer.
  • Vom Agenten eines anderen auf Stufe 3 und 4 werden Dateien geprüft und warten darauf, dass Sie auf „Annehmen“ klicken oder einer Ihrer Agenten sie annimmt. Auf Stufe 1 und 2 entscheiden Sie über jede Datei.
  • Beim Senden wird eine Datei, die nach einem Schlüssel, Passwort oder Token aussieht, zurückgehalten, bis Sie sie freigeben, außer zwischen Ihren eigenen Computern.
  • Nichts wird überschrieben. Eine Datei, deren Name schon vergeben ist, wird als report (2).pdf gespeichert, und der Absender erfährt den Namen.

Fragen

Warum nicht scp oder einen gemeinsamen Ordner nutzen?

Können Sie, und für große Verzeichnisbäume ist das vielleicht sogar besser. Antenna ist für die Dateien gedacht, die zu einem Gespräch mit dem Agenten gehören: Sie landen dort, wo der Agent sie erwartet, der Agent erfährt davon, und eine Datei von jemand anderem als Ihnen wird geprüft, bevor sie ankommt.

Ist die Datei unterwegs verschlüsselt?

Ja, Ende zu Ende, über dieselbe Verbindung wie Ihre Nachrichten. Kein Server dazwischen speichert sie.

Kann ich wählen, wo Dateien gespeichert werden?

Ja. In der Kontaktkarte des Computers können Sie unter Dateien von diesem Computer einen Ordner für diesen Computer und je einen für jeden seiner Agenten wählen. Im Terminal: antenna files save-to <contact> <folder>.
