In Antenna können Sie einen Kontakt und einen Agenten wählen (Claude Code, Codex oder einen eigenen Befehl), und ab dann startet jede Nachricht dieses Kontakts den Agenten, der sie liest und antwortet. Antenna führt ihn in einer Sandbox aus, mit nicht mehr Rechten als die Vertrauensstufe dieses Kontakts, und die Antwort erscheint beim Gegenüber, während sie geschrieben wird. Er läuft mit Ihrer eigenen Claude- oder ChatGPT-Anmeldung, und eine Antwort, die nach einem Geheimnis aussieht, wartet auf Ihre Freigabe.

Typische Einsätze

  • Ihr eigener Assistent auf einem Server. Sie schreiben vom Laptop an Ihren Server, und Claude Code antwortet dort, baut Ihr Projekt und lässt die Tests laufen.
  • Ein Empfang für einen Kontakt. Die Fragen einer Kollegin zu Ihrem Projekt werden sofort beantwortet, von einem Agenten, der nur den Ordner dieses Gesprächs sieht.
  • Ein Skript, das Bericht erstattet. Die Ausgabe jedes Programms lässt sich als Live-Stream senden: my-program | antenna send --stream <contact>.

Im Fenster einrichten

  1. Öffnen Sie auf dem Computer, auf dem der Agent laufen soll, Agents → Set up for a contact… (oder in einem Gespräch auf der Kontaktkarte Agent replies → Set up…).
  2. Wählen Sie den Kontakt und das Programm: Claude Code, Codex oder einen eigenen Befehl.
  3. Fügen Sie bei Bedarf ein langlebiges Anmelde-Token (aus claude setup-token) in Value (optional) ein. Es geht einmal an Ihren Knoten und wird in dessen verschlüsselter Datenbank aufbewahrt. Auf dem Mac ist das der zuverlässige Weg, weil die Sandbox den Schlüsselbund nicht öffnen kann.
  4. Bestätigen Sie mit Ihrem Besitzer-Passwort. Die Regel, ihr letzter Lauf und das Run log (Ausführungsprotokoll) erscheinen unter Agents.

Im Terminal ist es eine Zeile: antenna wake set <contact> --cmd "claude -p --output-format stream-json". antenna wake list zeigt die Regeln und die letzten Läufe; antenna wake off <contact> schaltet sie ab.

Was der Agent darf und was nicht

  • Sein Prompt ist fest vorgegeben: „Sie haben eine neue Nachricht, lesen Sie sie und antworten Sie“. Die Nachricht selbst wird nie zum Prompt; der Agent liest sie als Daten, mit nicht mehr Rechten als die Vertrauensstufe des Kontakts.
  • Er läuft in einer Sandbox (bubblewrap oder Landlock unter Linux, Seatbelt unter macOS): Er sieht seinen eigenen temporären Ordner und den Ordner dieses Gesprächs und erreicht nur seinen Modellanbieter. Ihre Projekte, Ihre übrigen Dateien und die Schlüssel des Knotens bleiben außer Reichweite. Ohne Sandbox startet Antenna ihn nicht.
  • Jeder Lauf beginnt sauber, solange Sie den Agenten nicht resident machen (siehe unten). Eine frühere Nachricht kann einem späteren Lauf also keine Anweisungen hinterlassen.
  • Grenzen: ein Zeitlimit pro Lauf und eine Höchstzahl von Läufen pro Stunde, damit ein gesprächiger Kontakt Ihr Kontingent nicht aufbraucht.

Den Agenten in einem Ihrer Projekte arbeiten lassen

Nur für Ihre eigenen Computer (∞) darf der Agent zusätzlich in einem Projektordner mit Ihrer Toolchain arbeiten: --project ~/code/payments, dazu schreibgeschützte --tool-path-Ordner und die Paket-Registries, die er mit --allow-host erreichen darf. Für jeden anderen Kontakt lehnt Antenna das ab, und Ihr Home-Verzeichnis, die eigenen Daten von Antenna oder Ordner mit Geheimnissen wie ~/.ssh öffnet es nie.

Fragen

Sieht das Gegenüber die Antwort, während sie getippt wird?

Ja, bei Kontakten ab Stufe 3: eine Live-Sprechblase, die wächst, während der Agent schreibt, und am Ende zu einer gewöhnlichen Nachricht wird. Stufen 1 und 2 bekommen die fertige Antwort.

Was, wenn der Agent ein Passwort oder einen Schlüssel in die Antwort schreibt?

Der Stream stoppt für das Gegenüber, und die Nachricht wartet auf Ihre Freigabe. Nur an Ihre eigenen Computer geht sie weiter.

Erinnert er sich an frühere Gespräche?

Standardmäßig nicht: Jede Nachricht startet einen neuen Lauf. Für Arbeit, die Stunden dauert, fügen Sie --resident hinzu: Dann bleibt dieselbe Claude-Code-Sitzung beim Gespräch, behält, was gesagt und entschieden wurde, und jede neue Nachricht wird zu ihrer nächsten Runde. Die Nachrichten erreichen sie trotzdem als Daten einer anderen Partei.
