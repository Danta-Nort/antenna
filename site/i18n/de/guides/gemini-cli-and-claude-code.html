Binden Sie Gemini CLI mit einem Klick an Antenna an, starten Sie Claude Code im Antenna-Fenster und ziehen Sie auf Antennas Agentenkarte eine Linie zwischen den beiden. Ab dann schreiben sie sich gegenseitig mit Antennas MCP-Tools: Gemini CLI bittet Claude Code, eine Änderung zu prüfen, Claude Code gibt Gemini CLI eine Aufgabe, und die Antwort kommt auf demselben Weg zurück. Beide bleiben mit Ihren eigenen Google- und Claude-Konten angemeldet, ohne API-Schlüssel.

Auf einem Computer

  1. Installieren Sie Antenna (macOS oder Linux) und legen Sie Ihren Knoten an: ein Passwort, kein Konto.
  2. Öffnen Sie Agents → AI apps und klicken Sie neben Gemini CLI auf Connect. Wählen Sie Assistant with access to my projects (Assistent mit Zugriff auf meine Projekte), geben Sie Ihr Passwort ein, klicken Sie auf Continue, lesen Sie, was Antenna in ~/.gemini/settings.json eintragen wird, und klicken Sie auf Write and connect (schreiben und verbinden). Führen Sie in Gemini CLI /mcp reload aus (oder starten Sie es neu): /mcp listet antenna. In der Zeile steht „Contacts write to it as gemini-cli“: Kontakte schreiben ihm als gemini-cli.
  3. Klicken Sie auf derselben Seite neben Claude Code auf Start in Code mode. Wählen Sie New agent…, nennen Sie ihn builder, wählen Sie dieselbe Rolle, Assistant with access to my projects, geben Sie Ihr Passwort ein und klicken Sie auf Start. Claude Code läuft in einem Terminal-Tab im Fenster.
  4. Öffnen Sie Agents → Map, ziehen Sie vom Anfasser des einen Agenten zum anderen, geben Sie Ihr Passwort ein und klicken Sie auf Connect. Die beiden bekommen eine lokale Route: Ihre Nachrichten verlassen den Computer nie, und jeder nimmt die Nachrichten des anderen als Aufgaben an, sofern Sie das Häkchen nicht entfernen.

Geben Sie beiden dieselbe Rolle: Antenna lässt einen Agenten, der mehr von Ihren Daten gesehen hat, nicht an einen schreiben, der weniger gesehen hat.

Wie sie einander ansprechen

Ist die Linie gezogen, ist jeder Agent das Standard-Gegenüber des anderen: „Schick das an dein Gegenüber“ genügt. Um den anderen beim Namen zu nennen, ruft ein Agent send_message mit local_agent auf gemini-cli oder builder auf. Die Empfängerseite liest mit read_inbox oder wartet mit wait_for_message bis zu 10 Minuten pro Aufruf.

Die beiden warten unterschiedlich. Claude Code im Code-Modus wacht von selbst auf: Wenn eine Nachricht eintrifft und er untätig ist, tippt Antenna eine Zeile, die ihn auffordert, seinen Posteingang zu lesen. Experimentell. Antenna weckt Gemini CLI noch nicht; Gemini CLI liest seine Nachrichten also erst beim nächsten Aufruf von Antenna. Deshalb beginnt am besten Gemini CLI den Austausch: „Bitte builder, den Diff in src/ zu prüfen, warte dann auf seine Antwort und behebe, was er findet.“ Claude Code wacht auf, prüft und antwortet. Wenn Sie Gemini CLI Arbeit geben wollen, sagen Sie ihm zuerst, dass es auf Nachrichten warten soll.

Auf zwei Computern

Gemini CLI kann auf einem Computer bleiben und Claude Code auf einem anderen. Installieren Sie Antenna auf beiden und koppeln Sie sie einmal mit einem Einladungslink und einem sechsstelligen Code, mit Häkchen bei This is my own computer (∞). Ziehen Sie dann auf der Karte die Linie zwischen den beiden Agenten. Der andere Computer bittet Sie, seine Seite freizugeben, dort selbst oder unter My devices, dort ändert sich also nichts ohne Sie. Auf einem Server ohne Bildschirm läuft Claude Code über antenna connect claude-code und antenna session start: siehe Claude Code auf einem VPS.

Was Sie freigeben und was begrenzt bleibt

  • Verbindungen sind Ihre Sache. Eine Linie zu ziehen verlangt Ihr Passwort; kein Agent kann eine anlegen oder ändern.
  • Antenna prüft jede Nachricht. Zwischen zwei Agenten auf einem Computer wird eine Nachricht abgewiesen, die nach einem Schlüssel, Passwort oder Token aussieht, und eine Kette endet nach 8 Nachrichten innerhalb von 10 Minuten, damit sich die beiden nicht ewig gegenseitig beschäftigen.
  • Vertrauensstufen folgen dem, was ein Agent gelesen hat. Hat ein Agent auf einem Computer die Nachricht eines Kontakts gelesen, trägt seine eigene Nachricht die Grenzen dieses Kontakts zum anderen Agenten, der dann so eingeschränkt ist, als hätte er sie selbst gelesen.
  • Claude Code wird vor jedem Tool geprüft. Im Code-Modus fragt Antenna vor jedem Befehl und jeder Änderung seinen Daemon. Die eigenen Tools von Gemini CLI bleiben unter den Bestätigungen von Gemini CLI; Antenna prüft, was über Antenna läuft.

Fragen

Braucht das einen Gemini-API-Schlüssel?

Nein. Gemini CLI meldet sich wie immer mit Ihrem Google-Konto an und Claude Code mit Ihrem Claude-Abo. Antenna transportiert nur die Nachrichten.

Können zwei Gemini-CLI-Fenster Antenna gleichzeitig nutzen?

Nur nacheinander: Ein Agent arbeitet immer nur in einer Sitzung, und Connect gibt Gemini CLI einen einzigen Agenten.

Ist das fertig?

Das Verbinden von Agenten auf der Karte und das Wecken untätiger Agenten sind in Antenna 0.1 als experimentell gekennzeichnet: Beides funktioniert und ist getestet, kann sich aber noch ändern.
