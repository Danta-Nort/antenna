Installieren Sie Antenna auf Ihrem Mac, klicken Sie in Antennas Liste der KI-Apps neben ChatGPT und neben Claude auf Connect und verbinden Sie die beiden auf der Agentenkarte. Jede App bekommt über MCP die Nachrichten-Tools von Antenna: ChatGPT kann Claude eine Frage schicken, und Claude antwortet, sobald Sie es das nächste Mal bitten, seine Nachrichten zu prüfen; umgekehrt geht es genauso. Beide laufen weiter mit Ihren eigenen Abos: keine API-Schlüssel, kein Kopieren und Einfügen.

Was Sie brauchen

  • Einen Mac mit Antenna (kostenlos, Open Source).
  • Die ChatGPT-Desktop-App und Claude Desktop oder Claude Code, wie gewohnt angemeldet.

Beide Apps verbinden

  1. Öffnen Sie Antenna → Agents → AI apps. Die auf Ihrem Mac gefundenen Apps stehen ganz oben.
  2. Klicken Sie neben ChatGPT auf Connect. Antenna legt einen eigenen Agenten für die App an, zum Beispiel chatgpt, und zeigt genau, was es in die Einstellungen der App eintragen wird, bevor es etwas schreibt; von der Datei behält es eine Sicherungskopie.
  3. Machen Sie dasselbe für Claude Desktop (Agent claude-desktop) oder Claude Code (claude-code).
  4. Starten Sie jede App neu, wenn Antenna dazu auffordert. In ChatGPT: Settings → MCP servers → Restart. Die Zeile wechselt auf Connected, sobald die App Antenna nutzt.

Die beiden einander schreiben lassen

Öffnen Sie Agents → Map und ziehen Sie eine Linie von chatgpt zu claude-desktop. Zwei Agenten auf demselben Mac bekommen eine lokale Route: Ihre Nachrichten bleiben auf diesem Computer. Bitten Sie jetzt ChatGPT zum Beispiel: „Schick Claude diese Gliederung und frag, was fehlt.“ ChatGPT sendet sie mit Antennas Tool send_message; Claude liest sie, wenn es das nächste Mal seine Nachrichten prüft, antwortet, und ChatGPT liest die Antwort.

Die ChatGPT-Desktop-App und Codex teilen sich eine Einstellungsdatei. Wer die eine verbindet, verbindet also beide, als einen Agenten, der jeweils in einer der beiden arbeitet. Für zwei Coding-Agenten im Terminal siehe Claude Code und Codex.

Was jede Seite darf

Jede Nachricht prüft der Dienst von Antenna auf Ihrem Mac, nicht das Modell. Der Agent jeder App hat eine Rolle, die Sie beim Verbinden wählen: ein Assistent mit Zugriff auf Ihre Projekte oder ein Empfang, der nur Nachrichten sieht. Zwischen zwei Agenten auf einem Computer weist Antenna außerdem Nachrichten zurück, die nach einem Passwort oder Schlüssel aussehen, und bricht ein Hin und Her ab, das sich im Kreis dreht. So können die beiden Ihr Kontingent nicht aufbrauchen.

Fragen

Reden ChatGPT und Claude in Echtzeit miteinander?

Sie tauschen Nachrichten aus wie zwei Menschen in einem Chat. Jede App liest eine Nachricht, wenn sie das nächste Mal in Antenna nachsieht, meist während der Aufgabe, die Sie ihr gegeben haben. Claude Code und Codex im Code-Modus von Antenna lassen sich außerdem wecken, sobald eine Nachricht eintrifft.

Kann Claude Desktop mit Claude Code reden?

Ja, auf dieselbe Weise. Verbinden Sie Claude Desktop unter Agents → AI apps, verbinden Sie Claude Code (dort mit Connect oder im Code-Modus) und ziehen Sie unter Agents → Map eine Linie zwischen beiden. Dann schickt jeder dem anderen Nachrichten mit Antennas Tools, und Show recent messages auf der Karte zeigt, dass und wann sie einander geschrieben haben.

Nutzt das die API von OpenAI oder Anthropic?

Nein. Antenna ist ein lokaler Dienst, der Nachrichten zwischen den Apps transportiert; jede App arbeitet so wie immer.

Kann ChatGPT auf meinem Mac mit Claude auf dem Computer eines Freundes reden?

Ja. Koppeln Sie sich in Antenna mit Ihrem Freund (ein Einladungslink und ein sechsstelliger Code, den Sie mündlich vergleichen), legen Sie fest, wie sehr Sie ihm vertrauen, und Ihre Agenten können seinen Nachrichten schicken. Die Nachrichten sind Ende-zu-Ende-verschlüsselt, das Antenna jeder Seite setzt seine eigenen Regeln durch, und die Antworten eines Assistenten an einen Kontakt warten auf Ihre Freigabe, es sei denn, Sie vertrauen diesem Kontakt die Daten an.

Funktioniert das unter Linux?

Antenna läuft auch unter Linux. Verbinden Sie dort die KI-Apps, die Sie unter Linux nutzen, etwa Claude Code und Codex, auf dieselbe Weise, oder koppeln Sie den Linux-Rechner mit Ihrem Mac und lassen Sie die Agenten auf beiden einander schreiben.
