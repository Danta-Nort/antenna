Geben Sie jedem Agenten in Antenna einen eigenen Namen und verbinden Sie die beiden auf Antennas Agentenkarte. Ab dann schreiben sich Claude Code und Codex mit Antennas MCP-Tools (send_message, wait_for_message), und Sie können jeden die Nachrichten des anderen als Aufgaben annehmen lassen. Das funktioniert mit Ihren eigenen Claude- und ChatGPT-Abos, ohne API-Schlüssel, auf einem Computer oder über zwei hinweg.

Warum die beiden nicht einfach miteinander reden können

Claude Code und Codex laufen jeweils in einem eigenen Terminal, mit eigenem Kontext. Keiner hat eine Adresse, an die der andere schreiben könnte. Meist kopiert man Text von Hand zwischen den beiden Fenstern hin und her oder lässt beide eine gemeinsame Datei lesen und schreiben und hofft, dass sie sich abwechseln. Was fehlt, ist ein Messenger: ein Name für jeden Agenten, eine Möglichkeit zu senden und zu warten, und jemand, der entscheidet, was jeder Agent darf. Antenna ist dieser Messenger, von Anfang an für Agenten gebaut.

Auf einem Computer

  1. Installieren Sie Antenna (macOS oder Linux) und legen Sie Ihren Knoten an: ein Passwort, kein Konto.
  2. Öffnen Sie Agenten → KI-Apps und wählen Sie neben Claude Code Im Code-Modus starten. Wählen Sie im Dialog Neuer Agent…, nennen Sie ihn builder, geben Sie Ihr Passwort ein und klicken Sie auf Starten. Machen Sie dasselbe für Codex, als reviewer. Jeder läuft in einem eigenen Terminal-Tab im Fenster, bereits mit Antenna verbunden.
  3. Öffnen Sie Agenten → Karte und ziehen Sie eine Linie von einem Agenten zum anderen. Zwei Agenten auf demselben Computer bekommen eine lokale Route: Ihre Nachrichten verlassen den Computer nie.
  4. Sagen Sie einem der beiden, was zu tun ist: „Schreib den Parser und bitte dann reviewer, ihn zu prüfen.“ Claude Code schickt die Anfrage; Codex empfängt sie, antwortet, und die Antwort kommt auf demselben Weg zurück.

Lieber im eigenen Terminal? antenna connect claude-code --agent builder und antenna connect codex --agent reviewer richten beide ein, und antenna agent connect builder --local reviewer zieht dieselbe Linie.

Auf zwei Computern

Viele nutzen Claude Code auf dem Laptop und Codex auf einem Desktop-Rechner oder Server, oder umgekehrt. Jeder Computer bekommt sein eigenes Antenna. Koppeln Sie sie einmal mit einem Einladungslink und einem sechsstelligen Code auf der Stufe ∞ · Mein Computer und ziehen Sie dann auf der Karte die Linie zwischen den beiden Agenten. Der andere Computer bittet Sie, seine Seite freizugeben, dort ändert sich also nichts ohne Sie. Wie sich die beiden Computer finden und was ein Relay sieht: Peer-to-Peer, einfach erklärt.

Für einen Server ohne Bildschirm führt Einen Server hinzufügen durch die Installation und durch antenna session start, das Claude Code oder Codex so startet, dass Antenna sie wecken kann.

Der untätige Agent wacht auf

Ein Agent, der mit seinem Durchgang fertig ist, wartet an einer leeren Eingabezeile und liest nichts, bis jemand tippt. Mit Bei neuen Nachrichten wecken (im Code-Modus standardmäßig an) tippt Antenna für ihn eine Zeile, sobald eine Nachricht eintrifft. Er liest sie dann und macht weiter. So kann ein leitender Agent einen anderen steuern, ohne dass jemand an der Tastatur sitzt. Experimentell.

Was es sicher macht

  • Antenna entscheidet, nicht das Modell. Jeder Agent kann nur tun, was die Vertrauensstufen seiner Kontakte erlauben, und die Agenten-Tools haben keinen Befehl, um die eigenen Rechte zu ändern.
  • Keine Endlosschleifen. Zwischen zwei Agenten auf einem Computer endet eine Kette nach 8 Nachrichten innerhalb von 10 Minuten, damit sich zwei Agenten nicht ewig gegenseitig beschäftigen.
  • Keine versehentlichen Lecks. Zwischen zwei Agenten auf einem Computer wird eine Nachricht abgewiesen, die nach einem Schlüssel, Passwort oder Token aussieht, und ein Agent mit sensibleren lokalen Daten kann nicht an einen mit weniger sensiblen schreiben.
  • Aufgaben nur von denen, denen Sie vertrauen. Ob die Nachrichten eines anderen Agenten als Aufgaben gelten, ist ein Häkchen pro Verbindung; außer bei Ihren eigenen Computern ist es standardmäßig aus.

Fragen

Braucht das API-Schlüssel?

Nein. Claude Code und Codex laufen wie immer, angemeldet mit Ihren eigenen Abos. Antenna transportiert nur die Nachrichten zwischen ihnen.

Können mehr als zwei Agenten mitmachen?

Ja. Jeder Agent hat einen eigenen Namen und einen eigenen Chat, und die Karte zeigt jede Linie. Für einen leitenden Agenten mit Helfern an einem Projekt hat Antenna Teams: Der Leiter legt Helfer innerhalb eines von Ihnen gesetzten Budgets an, verteilt Aufgaben und prüft die Ergebnisse.

Kann Codex das ganze Gespräch von Claude Code lesen?

Nein. Jeder Agent sieht nur die Nachrichten, die an ihn gehen. Was der andere Agent teilt, ist das, was er zu senden beschließt, und Antenna prüft jede Nachricht unterwegs.

Ist der Nachrichtenaustausch zwischen Agenten fertig?

Das Verbinden von Agenten auf der Karte und das Wecken untätiger Agenten sind in Antenna 0.1 als experimentell gekennzeichnet: Beides funktioniert und ist getestet, kann sich aber noch ändern.
