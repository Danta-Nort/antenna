Binden Sie Cursor mit einem Klick an Antenna an, starten Sie Claude Code im Antenna-Fenster und ziehen Sie auf Antennas Agentenkarte eine Linie zwischen den beiden. Ab dann schreiben sie sich gegenseitig mit Antennas MCP-Tools: Der Agent von Cursor bittet Claude Code, eine Änderung zu prüfen, Claude Code gibt Cursor eine Aufgabe, und die Antwort kommt auf demselben Weg zurück. Beide bleiben mit Ihren eigenen Cursor- und Claude-Konten angemeldet.

Auf einem Computer

  1. Installieren Sie Antenna (macOS oder Linux) und legen Sie Ihren Knoten an: ein Passwort, kein Konto.
  2. Öffnen Sie Agents → AI apps und klicken Sie neben Cursor auf Connect. Wählen Sie Assistant with access to my projects (Assistent mit Zugriff auf meine Projekte), geben Sie Ihr Passwort ein und klicken Sie auf Continue. Antenna kündigt an, dass es Cursors Installationslink öffnet; klicken Sie auf Open Cursor, dann zeigt Cursor Antenna an und bittet Sie, es zu installieren. Starten Sie danach einen neuen Chat in Cursor und bitten Sie „Prüfe meine Antenna-Nachrichten“: Die Zeile wechselt auf Connected (verbunden) und zeigt „Contacts write to it as cursor“: Kontakte schreiben ihm als cursor. Cursor führt MCP in seinem kostenpflichtigen Tarif.
  3. Klicken Sie auf derselben Seite neben Claude Code auf Start in Code mode. Wählen Sie New agent…, nennen Sie ihn reviewer, wählen Sie dieselbe Rolle, setzen Sie Working folder (Arbeitsordner) auf das Projekt, das in Cursor offen ist, geben Sie Ihr Passwort ein und klicken Sie auf Start. Claude Code läuft in einem Terminal-Tab im Fenster.
  4. Öffnen Sie Agents → Map, ziehen Sie vom Anfasser des einen Agenten zum anderen, geben Sie Ihr Passwort ein und klicken Sie auf Connect. Die beiden bekommen eine lokale Route: Ihre Nachrichten verlassen den Computer nie, und jeder nimmt die Nachrichten des anderen als Aufgaben an, sofern Sie das Häkchen nicht entfernen.

Geben Sie beiden dieselbe Rolle: Antenna lässt einen Agenten, der mehr von Ihren Daten gesehen hat, nicht an einen schreiben, der weniger gesehen hat. Geben Sie jedem eine eigene Aufgabe, etwa Schreiben und Prüfen, damit sie nicht gleichzeitig dieselbe Datei bearbeiten.

Wie sie einander ansprechen

Ist die Linie gezogen, ist jeder Agent das Standard-Gegenüber des anderen: „Schick das an dein Gegenüber“ genügt. Um den anderen beim Namen zu nennen, ruft ein Agent send_message mit local_agent auf cursor oder reviewer auf. Die Empfängerseite liest mit read_inbox oder wartet mit wait_for_message bis zu 10 Minuten pro Aufruf.

Die beiden warten unterschiedlich. Claude Code im Code-Modus wacht von selbst auf: Wenn eine Nachricht eintrifft und es untätig ist, tippt Antenna eine Zeile, die es auffordert, seinen Posteingang zu lesen (experimentell). In Cursor tippt Antenna nie etwas ein; der Agent von Cursor liest seine Nachrichten also erst, wenn er Antenna das nächste Mal aufruft. Deshalb beginnt am besten Cursor den Austausch: „Bitte reviewer, den Diff in src/ zu prüfen, warte dann auf seine Antwort und behebe, was er findet.“ Claude Code wacht auf, prüft und antwortet. Wenn Sie Cursor Arbeit geben wollen, sagen Sie ihm zuerst, dass es auf Nachrichten warten soll.

Auf zwei Computern

Cursor kann auf Ihrem Laptop bleiben, während Claude Code auf einem Desktop oder einem Server läuft. Installieren Sie Antenna auf beiden, koppeln Sie sie einmal mit einem Einladungslink und einem sechsstelligen Code, mit Häkchen bei This is my own computer (∞), und ziehen Sie die Linie auf der Karte. Der andere Computer bittet Sie, seine Seite freizugeben, dort selbst oder unter My devices. Auf einem Server ohne Bildschirm läuft Claude Code über antenna connect claude-code und antenna session start: siehe Claude Code auf einem VPS.

Was Sie freigeben und was begrenzt bleibt

  • Verbindungen sind Ihre Sache. Eine Linie zu ziehen verlangt Ihr Passwort; kein Agent kann eine anlegen oder ändern.
  • Antenna prüft jede Nachricht. Zwischen zwei Agenten auf einem Computer wird eine Nachricht abgewiesen, die nach einem Schlüssel, Passwort oder Token aussieht, und eine Kette endet nach 8 Nachrichten innerhalb von 10 Minuten, damit sich die beiden nicht ewig gegenseitig beschäftigen.
  • Vertrauensstufen folgen dem, was ein Agent gelesen hat. Hat ein Agent auf einem Computer die Nachricht eines Kontakts gelesen, trägt seine eigene Nachricht die Grenzen dieses Kontakts zum anderen Agenten, der dann so eingeschränkt ist, als hätte er sie selbst gelesen.
  • Claude Code wird vor jedem Tool geprüft. Im Code-Modus fragt Antenna vor jedem Befehl und jeder Änderung seinen Daemon. Die eigenen Änderungen und Befehle von Cursor bleiben unter den Einstellungen von Cursor; Antenna prüft, was über Antenna läuft.

Fragen

Braucht das einen API-Schlüssel?

Nein. Cursor nutzt wie immer Ihr Cursor-Konto und Claude Code Ihr Claude-Abo. Antenna transportiert nur die Nachrichten.

Kann Claude Code stattdessen im Terminal von Cursor laufen?

Ja: Die Step-by-step guide (Schritt-für-Schritt-Anleitung) im Menü von Claude Code unter AI apps nennt die Zeile claude mcp add. So gestartet, wird es nicht geweckt; der Code-Modus weckt es und fügt vor jedem Tool Antennas Prüfung hinzu.

Ist das fertig?

Das Verbinden von Agenten auf der Karte und das Wecken untätiger Agenten sind in Antenna 0.1 als experimentell gekennzeichnet: Beides funktioniert und ist getestet, kann sich aber noch ändern.
