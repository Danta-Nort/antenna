Installieren Sie Claude Code und den Antenna-Knoten auf Ihrem Linux-VPS, koppeln Sie den Server einmal mit Ihrem Laptop und starten Sie Claude Code über Antenna in Ihrem Projektordner. Dann läuft es nach dem Abmelden in einer eigenen tmux-Sitzung weiter, wacht auf, wenn eine Nachricht für es eintrifft, und antwortet in einem Chat auf Ihrem Laptop. Kein eingehender Port muss geöffnet werden, keine SSH-Sitzung muss am Leben bleiben, und mit Codex funktioniert es genauso.

Was Sie brauchen

  • Einen Linux-Server auf x86_64 mit installiertem und angemeldetem Claude Code (oder Codex) sowie tmux.
  • Antenna auf Ihrem Laptop: macOS oder Linux.

1. Den Antenna-Knoten auf dem Server installieren

curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER

Das Installationsskript liest die neueste Version aus dem signierten Manifest, prüft das Archiv, installiert antennad und antenna nach ~/.local/bin als systemd-User-Service (ohne Root) und legt Ihren Knoten mit einem Passwort an. Die zweite Zeile sorgt dafür, dass der Dienst nach dem Abmelden weiterläuft. Unter Ubuntu oder Fedora können Sie stattdessen das .deb- oder .rpm-Paket installieren.

2. Mit dem Laptop koppeln

Auf Ihrem Laptop: New contact → Invite, einen Namen vergeben, Häkchen bei This is my own computer (∞) setzen, auf Create link klicken und den Link kopieren. Auf dem Server:

antenna join '<link>' --trust 5 --label mac

Behalten Sie die einfachen Anführungszeichen bei: Der Link enthält ein #. Tippen Sie den Code, den Ihr Laptop zeigt, ins Terminal des Servers und klicken Sie dann auf dem Laptop auf The contact confirmed — codes match. Stufe 5 ist auf beiden Seiten ∞, der Server gilt also als Ihr eigener Computer.

3. Claude Code über Antenna starten

cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev

Die connect-Zeile gibt der Sitzung einen eigenen Agenten samt Token und sagt Hallo, sodass auf Ihrem Laptop ein Chat namens api-dev erscheint. Die start-Zeile startet Claude Code in Antennas eigenem tmux-Server (Ihr tmux bleibt unberührt). Hängen Sie sich einmal an, um die ersten Fragen von Claude Code zu beantworten, etwa ob es dem Ordner vertraut, und verlassen Sie die Sitzung dann mit Ctrl-b d: Claude Code läuft weiter. Für Codex nehmen Sie antenna connect codex und --cli codex.

4. Mit ihm reden

Schreiben Sie im Chat api-dev auf Ihrem Laptop: „Führ die Migrationstests aus und behebe, was fehlschlägt.“ Wartet Claude Code untätig an seiner Eingabezeile, tippt Antenna eine kurze Zeile, damit es Ihre Nachricht liest; den Text eines Kontakts tippt es nie, und eine Frage beantwortet es nie an seiner Stelle. Die Karte des Servers unter My devices zeigt seinen Zustand und seine Agenten, und Sie können seine Anfragen vom Laptop aus freigeben.

Nach einem Neustart

Nach einem Neustart des Servers sind die Schlüssel des Knotens gesperrt: Der Dienst läuft, aber seine Verbindungen bleiben stumm, bis Sie sich anmelden und antenna unlock ausführen. So verschafft eine Kopie der Server-Festplatte niemandem Ihre Schlüssel. antenna status zeigt, ob er gesperrt ist.

Fragen

Warum nicht einfach SSH und tmux?

Das funktioniert, solange Sie am Terminal sitzen. Antenna bringt einen Chat dazu, in den Sie jederzeit vom Laptop aus schreiben können, weckt die Sitzung, wenn Sie das tun, und lässt auch andere Agenten ihr Arbeit geben, mit Rechten, die es selbst prüft.

Braucht der Server eine öffentliche IP oder offene Ports?

Nein. Beide Seiten bauen die Verbindung nach außen auf, direkt, wenn das Netz es zulässt, sonst über ein Relay. Das Relay leitet nur verschlüsselten Datenverkehr weiter.

Kann ich mehrere Sitzungen auf einem Server betreiben?

Ja: ein Agent pro Projektordner, jeder mit eigenem Namen und eigenem Chat auf Ihrem Laptop.

Gibt es einen Build für ARM?

Noch nicht. Der Server-Knoten wird für x86_64-Linux gebaut.
