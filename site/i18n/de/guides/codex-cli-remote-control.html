Installieren Sie Antenna auf beiden Computern und koppeln Sie sie einmal als Ihre eigenen. Auf dem Computer, auf dem Codex läuft, geben Sie der Codex-Sitzung mit antenna connect codex einen Namen und starten sie mit antenna session start … --cli codex. Auf Ihrem Laptop erscheint ein Chat mit diesem Namen: Schreiben Sie dort eine Aufgabe hinein, und Antenna weckt Codex, wenn es untätig ist. Codex liest Ihre Nachricht, arbeitet auf dem anderen Computer und antwortet im Chat. Keine SSH-Sitzung muss offen bleiben, und kein eingehender Port muss geöffnet werden.

Was Sie brauchen

  • Codex CLI, installiert und angemeldet auf dem Computer, der die Arbeit macht: ein Linux-Server auf x86_64 oder ein Mac- bzw. Linux-Desktop. Codex nutzt weiter Ihr eigenes Abo; Antenna braucht keinen API-Schlüssel.
  • tmux auf diesem Computer. Auf einem Server führen Sie außerdem einmal sudo loginctl enable-linger $USER aus, damit Antenna und die Sitzung nach dem Abmelden weiterlaufen.
  • Antenna auf beiden Computern: die App auf einem Desktop, den Knoten auf einem Server (curl -fsSL https://antenna.contact/install.sh | sh).

1. Die beiden Computer koppeln

Auf Ihrem Laptop: Neuer Kontakt → Einladen, Häkchen bei Das ist mein eigener Computer (∞) setzen, den Link erstellen und auf dem anderen Computer öffnen (auf einem Server mit antenna join '<link>' --trust 5 --label mac). Geben Sie den Code, den die eine Seite zeigt, auf der anderen ein. Jetzt behandeln sich beide Seiten gegenseitig als Ihre eigenen Computer. Die Schritt-für-Schritt-Fassung mit Screenshots steht in Claude Code auf einem VPS; für Codex ist sie identisch.

2. Der Codex-Sitzung einen Namen geben

Auf dem Computer, auf dem Codex läuft, im Projektordner:

cd ~/projects/api
antenna connect codex --agent api-codex --links mac --hello mac

Das legt den Agenten api-codex mit eigener Token-Datei an, verknüpft ihn mit Ihrem Laptop (mac ist der Name, den dieser Computer Ihrem Laptop beim Koppeln gegeben hat) und sagt Hallo, sodass auf dem Laptop sofort ein Chat namens api-codex erscheint. Ihre eigenen Codex-Einstellungen bleiben unverändert: Antenna wird nur für die Sitzungen dieses Agenten hinzugefügt.

3. Codex über Antenna starten

antenna session start api-codex --dir ~/projects/api --cli codex
antenna session attach api-codex

Codex startet in Antennas eigenem tmux-Server; Ihr tmux bleibt unberührt. Hängen Sie sich einmal an, um die ersten Fragen von Codex zu beantworten. Beim ersten Mal bittet Codex Sie, Antennas Hooks zu vertrauen („Hooks need review“): Wählen Sie „Trust all and continue“. Verlassen Sie die Sitzung dann mit Ctrl-b d, und Codex läuft weiter. --resume setzt nach einem Neustart die letzte Sitzung des Agenten fort.

4. Vom Laptop aus schreiben

Öffnen Sie den Chat api-codex und schreiben Sie: „Führ die Tests aus, behebe, was fehlschlägt, und sag mir, was du geändert hast.“ Wartet Codex untätig an seiner Eingabezeile, tippt Antenna eine fest eingebaute Zeile, die es auffordert, seinen Posteingang zu lesen. Ihren Text tippt es nie ins Terminal, und in eine laufende Rückfrage von Codex tippt es nie. Codex liest die Nachricht über Antenna, arbeitet und antwortet im Chat. Experimentell.

Soll es aufhören, woran es gerade arbeitet? Schalten Sie vor dem Senden Dringend: jetzt unterbrechen ein. Antenna drückt einmal Esc, um den laufenden Durchgang zu beenden, und weckt Codex dann für Ihre Nachricht. Um den Agenten und alles, was er gestartet hat, zu stoppen, öffnen Sie auf dem Laptop unter Meine Geräte die Karte des anderen Computers und klicken auf Agent und seine Prozesse stoppen… neben api-codex.

Auf dem Desktop: Code-Modus

Läuft Codex auf einem Mac- oder Linux-Desktop mit der Antenna-App, können Sie die Terminal-Schritte überspringen. Klicken Sie im Code-Modus im Agentenbereich auf +, wählen Sie Codex und den Arbeitsordner, und Codex läuft in einem Tab im Fenster und wird auf dieselbe Weise geweckt. Sein Chat ist von Ihren anderen Computern aus erreichbar wie der jedes anderen Agenten.

Fragen

Sehe ich auf dem Laptop das Terminal von Codex?

Nein. Sie geben Codex Aufgaben und lesen seine Antworten in einem Chat; das Terminal bleibt auf dem anderen Computer. Wenn Sie zusehen möchten, nutzen Sie dort antenna session attach, gern auch über SSH.

Welche Codex-Versionen funktionieren?

Codex ab 0.160 meldet über Hooks, was es tut, und daran erkennt Antenna, wann Codex untätig ist. Mit einem älteren Codex oder ohne Vertrauen in die Hooks wartet Antenna, bis Codex nach einem Durchgang seine leere Eingabezeile zeigt, und tippt nie, während ein Durchgang läuft.

Kann Codex auch mit Claude Code reden?

Ja. Verbinden Sie die beiden Agenten auf der Agentenkarte, dann gehen die Nachrichten des einen an den anderen, ohne dass man ihn nennen muss: siehe Claude Code und Codex reden miteinander.

Kann ich es vom Smartphone aus steuern?

Noch nicht. Antenna läuft derzeit unter macOS und Linux.
