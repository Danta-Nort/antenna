Sur le même ordinateur, Claude Code lit vos fichiers directement : donnez-lui le chemin, ou faites glisser le fichier dans son terminal. Sur un autre ordinateur, un serveur par exemple, envoyez le fichier via Antenna : déposez-le dans la conversation avec cette session Claude Code, Antenna le vérifie à l’arrivée et l’enregistre là-bas dans le dossier de la liaison, et l’agent reçoit dans sa boîte de réception le nom du fichier, son emplacement, sa taille et son SHA-256. Les fichiers que l’agent vous renvoie arrivent sur votre portable de la même façon.

Envoyer un fichier à l’agent

  1. Associez votre portable à l’autre ordinateur comme étant le vôtre (∞) et connectez à Antenna le Claude Code qui y tourne : voir Claude Code sur un VPS.
  2. Ouvrez la conversation avec la session sur votre portable et déposez-y le fichier, ou joignez-le comme dans n’importe quelle messagerie.
  3. Sur l’autre ordinateur, Antenna vérifie le type du fichier d’après son contenu, recherche les menaces et les secrets, et l’enregistre dans le dossier de la liaison, ~/Antenna/links/<folder>/shared/, ou dans un dossier de projet que vous avez choisi pour cet ordinateur.
  4. L’agent apprend de lui-même l’arrivée du fichier dans sa prochaine consultation de la boîte de réception, avec son chemin et ses empreintes, et peut s’en servir à l’étape suivante.

Récupérer des fichiers de l’agent

L’agent peut vous envoyer un fichier, un build, un rapport ou une capture d’écran, avec les mêmes outils que pour les messages. Il arrive dans votre conversation et dans Files, sous forme de fiche indiquant le nom du fichier, ce que la vérification a relevé et son empreinte. Les images s’affichent sous forme d’aperçu sûr et vérifié, reconstruit par Antenna.

Ce qui est vérifié, et ce qui attend votre décision

  • Entre vos propres ordinateurs, les fichiers ordinaires sont enregistrés automatiquement. Tout ce qui peut exécuter ou installer un logiciel, comme un programme, un installeur ou une archive qui en contient un, attend toujours votre décision, sauf si vous l’autorisez pour cet ordinateur.
  • Venant de l’agent de quelqu’un d’autre aux niveaux 3 et 4, les fichiers sont vérifiés et attendent que vous cliquiez sur Accept, ou qu’un de vos agents les accepte. Aux niveaux 1 et 2, vous décidez pour chaque fichier.
  • À l’envoi, un fichier qui semble contenir une clé, un mot de passe ou un jeton est retenu jusqu’à votre accord, sauf entre vos propres ordinateurs.
  • Rien n’est écrasé. Un fichier dont le nom est déjà pris est enregistré sous report (2).pdf, et l’expéditeur est informé de ce nom.

Questions

Pourquoi ne pas utiliser scp ou un dossier partagé ?

Vous pouvez, et pour de grandes arborescences de fichiers, c’est peut-être préférable. Antenna sert aux fichiers qui font partie d’une conversation avec l’agent : ils arrivent là où l’agent les attend, l’agent en est informé, et un fichier venant de quelqu’un d’autre que vous est vérifié avant d’arriver.

Le fichier est-il chiffré pendant le transfert ?

Oui, de bout en bout, par la même liaison que vos messages. Aucun serveur intermédiaire ne le stocke.

Puis-je choisir où les fichiers sont enregistrés ?

Oui. Dans la fiche de contact de l’ordinateur, Files from this computer vous permet de choisir un dossier pour cet ordinateur et un pour chacun de ses agents. Depuis un terminal : antenna files save-to <contact> <folder>.
