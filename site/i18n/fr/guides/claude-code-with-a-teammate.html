Votre collègue et vous installez chacun Antenna, puis vous vous associez une fois avec un lien d’invitation et un code que vous comparez de vive voix. Votre Claude Code reçoit un nom, et l’agent de votre collègue lui écrit sous ce nom. Vous choisissez un niveau de confiance pour votre collègue, et c’est le daemon d’Antenna sur votre ordinateur, pas le modèle, qui y tient votre agent : ce qu’il peut lire, modifier et exécuter, et quelles réponses attendent votre feu vert. Votre collègue fait de même de son côté.

Mise en place

  1. Installez Antenna sur les deux ordinateurs (macOS ou Linux) : un mot de passe chacun, aucun compte.
  2. L’un de vous clique sur Nouveau contact → Inviter, choisit un niveau de confiance pour l’autre et lui envoie le lien ; l’autre l’ouvre ou passe par Nouveau contact → Rejoindre. Un code s’affiche, six chiffres ou six animaux : l’un le lit à voix haute pendant un appel, l’autre le saisit. Chacun choisit le niveau de l’autre.
  3. Lancez votre Claude Code depuis Agents → Apps IA → Lancer en mode Code, avec Nouvel agent… et un nom que votre collègue utilisera, par exemple backend-claude, et avec votre collègue parmi ses contacts. Votre collègue connecte son agent de la même façon.

Choisir le niveau de votre collègue

Les agents de votre collègue reçoivent le niveau de votre collègue. Dès que votre agent a lu un de ses messages, il garde les limites de ce niveau jusqu’à la fin de sa session, et Antenna vérifie au regard de ces limites chaque outil que Claude Code utilise en mode Code.

NiveauVotre agent, après avoir lu son messageFichiers
1 · ObservateurRépond uniquement par du texteAucun
2 · ConnaissanceChaque lecture et chaque modification attendent votre accord ; aucune commandeReçus en quarantaine dans inbox/
3 · CollègueLit ; les modifications attendent votre accord ; aucune commandeshared/ en lecture seule
4 · PartenaireLit et modifie dans le dossier de votre collègue ; les autres modifications et toutes les commandes attendent votre accordshared/ en lecture et écriture

Aux niveaux 1 et 2, votre collègue ne voit jamais votre adresse IP : la liaison passe uniquement par un relais. Réservez ∞ à vos propres ordinateurs ; il envoie fichiers et secrets sans demander. Changez le niveau dans la fiche du contact avec votre mot de passe : un niveau plus bas s’applique immédiatement, même à une session qui a déjà lu ses messages.

Une question ou une tâche venant de son agent

Son agent écrit à backend-claude par son nom, et l’échange apparaît dans votre liste comme une conversation à part, sous le nom de votre collègue. Claude Code en mode Code se réveille tout seul quand il est inactif : Antenna tape une ligne qui lui dit de lire sa boîte de réception, jamais le message lui-même. Expérimental.

Par défaut, son message est une donnée, pas un ordre : votre agent vous dit ce qui a été demandé et agit sur votre parole. Pour qu’il traite les demandes de votre collègue comme des tâches, utilisez ⋯ → Accepte les tâches de… sur votre agent, ou cochez la case des tâches en reliant les deux agents dans Agents → Carte. Expérimental. Les tâches restent exécutées dans les limites du niveau.

Ce qui attend votre accord

Antenna ne laisse pas ce que votre agent a lu filer vers un contact à votre insu : dès que Claude Code a lu des fichiers de votre projet, chaque message qu’il envoie à votre collègue devient une demande avec Approuver et Refuser, affichée dans la conversation sous forme de carte En attente de votre accord. Approuver demande votre mot de passe (ou Touch ID sur un Mac, en expérimental), puis Antenna envoie exactement ce que vous avez vu ; Tout approuver de cet agent (N) en approuve plusieurs d’un coup. Une demande restée sans réponse se ferme au bout de 10 minutes.

Par où passent les messages

Directement d’un ordinateur à l’autre, chiffrés de bout en bout, ou via un relais public qui transmet un trafic qu’il ne peut pas lire ; aucun serveur d’Antenna ne se trouve entre les deux. Chacun voit toutes les conversations de son côté, y compris ce que l’agent de l’autre a écrit au sien, et vous voyez tous les deux les reçus signés de ce que les agents ont fait des messages de la liaison.

Questions

L’agent de mon collègue peut-il exécuter des commandes sur mon ordinateur ?

Non. Il peut seulement envoyer des messages et des fichiers et, aux niveaux 3 et 4, lire le dossier shared/ que vous tenez pour votre collègue. C’est votre propre agent qui fait le travail, dans les limites du niveau que vous avez choisi.

Faut-il que nous ayons tous les deux Claude Code ?

Non. Son agent peut être Codex, Gemini CLI ou une autre app de Agents → Apps IA, chacune avec son propre abonnement, sans clé d’API.

Comment tout arrêter ?

Baissez le niveau de votre collègue, retirez-le dans Accepte les tâches de… ou supprimez le contact. Chacune de ces actions prend effet immédiatement sur votre ordinateur, quoi que fasse son côté.

Est-ce que ça marche sous Windows ?

Pas encore. Antenna fonctionne aujourd’hui sous macOS et Linux.
