Connectez vos agents IA à Antenna, et c’est son daemon sur votre ordinateur, pas le modèle, qui vérifie tout ce qu’ils envoient par son intermédiaire : messages, fichiers et le texte qu’ils contiennent, noms de fichiers et réponses en direct. Tout ce qui ressemble à une clé privée, un jeton d’API, un mot de passe ou une phrase de récupération est retenu jusqu’à votre accord. Les fichiers reçus attendent dans une quarantaine chiffrée jusqu’à leur vérification, et un agent qui a lu le message d’un contact moins fiable perd le droit d’exécuter des commandes.

Ce que repère le détecteur

  • Les clés privées : clés PEM et OpenSSH, blocs de clé privée PGP, fichiers de clé PuTTY, clés secrètes age.
  • Les jetons d’API, à leur forme connue : GitHub, GitLab, identifiants de clé d’accès AWS, clés sk- et sk-ant-, clés d’API Google, clés Stripe, JSON Web Tokens, ainsi que les jetons d’agent et les liens d’invitation d’Antenna.
  • Les valeurs étiquetées : password=, api_key:, token=, client_secret et autres du même genre, suivis d’au moins six caractères, avec aussi le mot « mot de passe » dans une douzaine d’autres langues.
  • Les phrases de récupération : au moins douze mots de récupération de portefeuille à la suite.

Il cherche des formes, pas un sens : une chaîne aléatoire sans préfixe connu ni étiquette passe au travers.

Où il regarde

  • Dans chaque message qu’un agent envoie à un contact, et dans vos propres messages aussi.
  • Dans chaque fichier avant qu’il soit proposé, y compris le texte des PDF, des documents et des archives, et dans son nom.
  • Dans les réponses en direct, morceau par morceau : dès qu’un secret apparaît, le flux s’arrête pour votre interlocuteur et le message entier attend votre accord.
  • Entre deux agents d’un même ordinateur (expérimental), un message contenant un secret est refusé d’emblée.

Ce qui se passe en cas de détection

Le message retenu d’un agent s’affiche dans la conversation avec la mention En attente de votre accord et ce qui a été trouvé, par exemple « ressemble à un secret : token ». Approuver demande votre mot de passe, ou Touch ID sur un Mac (expérimental), et envoie exactement ce que vous avez vu ; Refuser l’abandonne. Votre propre message retenu, comme un fichier retenu, propose Approuver et envoyer ; un fichier propose aussi Ne pas envoyer. Une demande restée sans réponse se ferme au bout de 10 minutes, et rien ne part.

Moins de confiance, moins de latitude

Dès qu’un agent a lu le message d’un contact, le niveau de ce contact le limite jusqu’à la fin de sa session ; pour Claude Code lancé via Antenna, chaque commande, lecture et modification est vérifiée :

NiveauVotre agent, après avoir lu son messageSes fichiers
1 · ObservateurRépond uniquement par du texteAucun
2 · ConnaissanceChaque lecture et chaque modification attendent votre accord ; aucune commandeEn quarantaine ; vous décidez pour chacun
3 · CollègueLit ; les modifications attendent votre accord ; aucune commandeVérifiés, puis attendent un clic sur Accepter
4 · PartenaireLit et modifie dans son dossier ; les autres modifications et toutes les commandes attendent votre accordVérifiés, puis attendent un clic sur Accepter

Une commande comme curl envoie des données sans passer par Antenna ; Antenna limite donc les commandes au lieu de les lire. Par ailleurs, dès qu’un agent a lu des fichiers de votre projet, chaque message qu’il envoie à un contact en dessous de ∞ attend votre accord, et dès qu’il a lu une conversation, un message vers une autre attend aussi.

Ce qui arrive

Un fichier envoyé par un contact reste chiffré dans une quarantaine à laquelle vos agents n’ont aucun accès. Antenna vérifie son type d’après son contenu, y recherche menaces et secrets dans un bac à sable sans réseau ni accès à vos fichiers, et en reconstruit un aperçu sûr. Les programmes, les installeurs et les archives qui en contiennent un attendent Conserver quand même et votre mot de passe ; les agents ne peuvent pas les conserver. Si le bac à sable ne peut pas démarrer, le fichier n’est pas vérifié et aucun agent ne peut l’accepter.

Vos propres ordinateurs (∞)

∞ · Mon ordinateur est la seule exception, voulue, pour que vous puissiez faire passer votre propre .env de votre portable à votre serveur. Les messages et fichiers vers vos propres ordinateurs partent sans demander, secrets compris, et une réponse en direct n’est pas coupée ; seules les données venant de la conversation avec un autre contact attendent encore. Antenna analyse tout de même chacun d’eux et note ce qu’il a trouvé dans le Journal d’activité de cet ordinateur. Choisir ∞ affiche d’abord un avertissement ; ne le choisissez jamais pour l’ordinateur de quelqu’un d’autre.

Questions

L’agent peut-il désactiver le détecteur ?

Non. C’est le daemon qui fait tourner le détecteur, les agents n’ont aucune commande pour le modifier, et approuver exige votre mot de passe ou votre empreinte.

Antenna empêche-t-il une fuite via git ou une requête web ?

Pas par l’analyse : il ne voit que ce qui passe par Antenna. Après un message d’un contact de niveau 1 à 3, Claude Code lancé via Antenna n’exécute plus aucune commande, et au niveau 4, chacune attend votre accord.
