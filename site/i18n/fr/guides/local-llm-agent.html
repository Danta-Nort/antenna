Dans Antenna, ouvrez Agents → Modèles locaux, téléchargez le modèle recommandé pour votre ordinateur, puis cliquez sur Créer un agent. Le modèle tourne sur votre propre machine avec llama.cpp, sans compte, sans clé d’API et sans internet une fois téléchargé, dans un bac à sable qui ne peut ni accéder au réseau ni lire vos fichiers. L’agent a sa propre conversation et, dans une équipe, il peut tenir des rôles légers comme le tri, les résumés et la documentation. Expérimental.

Antenna regarde votre mémoire et votre espace libre, et vous recommande l’un des modèles Qwen3.5 :

Mise en place

  1. Ouvrez Agents → Modèles locaux et cliquez sur Télécharger à côté du modèle recommandé. Il provient de Hugging Face, dans une version figée ; fermer la fenêtre n’interrompt pas le téléchargement, et un téléchargement interrompu reprend.
  2. Avant de le charger, Antenna vérifie le fichier par rapport à la taille et au SHA-256 inscrits dans cette version de l’app. Un fichier qui ne correspond pas est supprimé.
  3. Cliquez sur Créer un agent et donnez-lui un nom. Sa conversation apparaît sous Sur cet ordinateur dans Discussions.
  4. Écrivez-lui. La première réponse prend quelques secondes, le temps que le modèle se charge.

Depuis un terminal : antenna local install qwen3.5-2b --wait (ou --from-file pour une copie que vous avez déjà), puis antenna local add helper --model qwen3.5-2b et antenna local say helper "hello".

Deux bacs à sable

Le modèle tourne dans son propre bac à sable : il ne lit que son fichier de modèle et ne peut se connecter nulle part, ni à internet, ni à Antenna, ni à d’autres programmes. Le programme de l’agent lui-même tourne dans un second bac à sable qui ne peut joindre que le modèle. La conversation est conservée dans la base de données chiffrée d’Antenna. Dans cette version, un agent local n’a ni liaison ni outil : il ne peut donc rien envoyer à personne, et Antenna ne vous demande jamais de coller une commande tirée de ses réponses.

La mémoire, gérée pour vous

Plusieurs agents peuvent partager un même modèle, et des modèles de tailles différentes peuvent tourner côte à côte. Quand un autre modèle occupe la mémoire dont une réponse a besoin, la réponse attend (« En attente de mémoire… ») au lieu de faire swapper l’ordinateur, et un modèle inutilisé depuis 30 minutes est déchargé.

Des modèles locaux dans une équipe

Quand vous créez une équipe d’agents, un modèle local peut y être exécutant pour les rôles adaptés à sa taille : les petits modèles pour le tri et les résumés, les plus grands aussi pour la documentation, les brouillons et la traduction. Avec Local uniquement, toute l’équipe, agent principal compris, tourne sans aucun modèle dans le cloud. Les modèles locaux n’écrivent pas encore de code dans une équipe.

Questions

Est-ce que ça utilise le GPU ?

Sur Mac, le modèle est prévu pour utiliser le GPU via Metal. Sous Linux, il tourne sur le CPU, avec des builds adaptés aux jeux d’instructions de ce processeur.

Mes autres agents peuvent-ils parler au modèle local ?

Pas encore. Dans cette version, un agent local discute avec vous dans sa conversation, et avec l’agent principal de votre équipe quand il travaille dans une équipe.

Est-ce que quelque chose quitte mon ordinateur ?

Seulement le téléchargement du modèle, depuis Hugging Face. Ensuite, le modèle tourne hors ligne, et son bac à sable n’a aucun accès au réseau.
