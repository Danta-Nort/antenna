Installez Antenna sur votre portable et sur l’ordinateur où tourne Claude Code, associez-les une fois comme vos propres ordinateurs, puis lancez-y Claude Code via Antenna. Une conversation avec cette session apparaît sur votre portable : écrivez-y une tâche, Antenna réveille Claude Code quand il est inactif, et sa réponse revient dans la conversation. Les messages passent par une liaison pair-à-pair chiffrée de bout en bout entre vos deux ordinateurs, Antenna n’a besoin d’aucun compte, et les étapes qui demandent votre accord arrivent sur le portable, où vous répondez avec votre mot de passe.

Le Remote Control de Claude Code, et Antenna

Claude Code possède sa propre fonction Remote Control, intégrée ; la documentation d’Anthropic la décrit. Ce guide porte sur une autre configuration : Claude Code tourne sur un de vos ordinateurs qui reste allumé, un serveur ou un poste de bureau, et vous le pilotez depuis Antenna sur votre portable. Elle vous convient si vous voulez :

  • Plusieurs sessions sur plusieurs ordinateurs dans une seule liste. Chaque session a sa propre conversation, et Mes appareils affiche pour chaque ordinateur son état de santé, ses agents et les demandes qui y attendent.
  • Votre propre liaison. Les messages sont chiffrés sur un ordinateur et déchiffrés sur l’autre. Vos ordinateurs se connectent directement quand le réseau le permet, sinon via un relais qui ne transmet que du trafic chiffré. Ni compte, ni port entrant.
  • Des permissions vérifiées par le daemon d’Antenna sur l’ordinateur où tourne Claude Code, avec des approbations auxquelles vous répondez depuis celui de vos ordinateurs devant lequel vous êtes.
  • D’autres agents de la même façon : Codex fonctionne comme Claude Code.

Mise en place

  1. Installez Antenna sur les deux ordinateurs : l’app sur votre portable (macOS ou Linux) et, sur l’autre ordinateur, l’app, ou le nœud sur un serveur Linux : 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
  2. Associez-les une fois. Sur le portable : Nouveau contact → Inviter, cochez C’est mon propre ordinateur (∞), cliquez sur Créer le lien et copiez-le. Sur un serveur : antenna join '<link>' --trust 5 --label mac ; sur un poste de bureau : Nouveau contact → Rejoindre, avec la même case cochée. Saisissez sur l’un le code affiché par l’autre, et cliquez sur Le contact a confirmé — les codes correspondent sur le portable.
  3. Lancez Claude Code via Antenna sur l’autre ordinateur. Sur un serveur, dans le dossier du projet (tmux nécessaire) : 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Répondez aux premières questions de Claude Code, puis détachez-vous avec Ctrl-b d : il continue de tourner, et une conversation nommée api-dev se trouve sur votre portable. Sur un poste de bureau : Agents → Apps IA → Lancer en mode Code, et Claude Code tourne dans un onglet de la fenêtre d’Antenna sur cet ordinateur ; demandez-lui une fois de dire bonjour à votre portable via Antenna, et sa conversation apparaît sur le portable.
  4. Autorisez le portable à répondre aux demandes d’approbation de cet ordinateur. Sur un serveur : antenna devices confirm mac. Sur un poste de bureau : Mes appareils → la fiche du portable → Approbations → Accepter les approbations signées avec …, avec votre mot de passe.

Le piloter depuis votre portable

  • Lui confier une tâche. Écrivez dans la conversation de la session comme vous écririez à quelqu’un. Quand Claude Code attend, inactif, devant son invite, Antenna tape une ligne prédéfinie pour qu’il lise votre message ; il ne tape jamais votre texte dans le terminal et ne répond jamais à une question que Claude Code y pose. Expérimental.
  • L’interrompre. Activez Urgent : interrompre maintenant avant d’envoyer : Antenna appuie une fois sur Échap pour mettre fin au tour en cours, jamais par-dessus une question ou une invite de permission ouverte, et Claude Code lit votre message. Expérimental.
  • Approuver ses étapes. Une étape qui a besoin de vous s’affiche sur la fiche de l’autre ordinateur dans Mes appareils, avec une notification. Cliquez sur Approuver avec le mot de passe, sur Approuver avec Touch ID sur un Mac, ou sur Refuser. Expérimental.
  • L’arrêter. Arrêter l’agent et ses processus…, à côté de l’agent sur cette fiche, met fin à Claude Code et à tout ce qu’il a lancé sur cet ordinateur. Expérimental.

L’invite de permission de Claude Code lui-même (« Do you want to proceed? ») reste dans son terminal sur l’autre ordinateur, et Antenna n’y répond jamais. Autorisez dans les réglages de Claude Code les outils dont vous vous servez couramment, ou répondez-y avec antenna session attach.

Codex et les autres agents

Codex fonctionne de la même façon : antenna connect codex et --cli codex sur un serveur, ou Lancer en mode Code à côté de Codex sur un poste de bureau (voir Codex CLI à distance). Gemini CLI se connecte depuis Agents → Apps IA et envoie et lit des messages via Antenna, mais Antenna ne le réveille pas encore : il lit un nouveau message lors de son prochain appel à Antenna.

Questions

Est-ce que je vois le terminal de Claude Code sur mon portable ?

Non. Vous confiez des tâches et lisez les réponses dans une conversation ; le terminal reste sur l’autre ordinateur. Pour le regarder, lancez antenna session attach là-bas, en SSH si vous le souhaitez.

L’autre ordinateur a-t-il besoin d’une IP publique ou de ports ouverts ?

Non. Les deux ordinateurs établissent des connexions sortantes, directes quand le réseau le permet et via un relais sinon. Le relais ne transmet que du trafic chiffré.

Qui d’autre peut lui confier des tâches ?

Seulement les contacts associés à cet ordinateur dont l’agent a le droit de lire les messages (avec --links mac, uniquement votre portable), et les agents que vous lui reliez sur la carte des agents. C’est le daemon d’Antenna sur cet ordinateur, et non Claude Code, qui décide de ce que le message d’un contact peut lui faire faire, selon le niveau de confiance de ce contact.

Faut-il une clé d’API ?

Non. Claude Code garde votre propre connexion sur l’ordinateur où il tourne, et Antenna ne transporte que des messages, des fichiers et des approbations.

Puis-je le piloter depuis mon téléphone ?

Pas encore. Antenna fonctionne aujourd’hui sous macOS et Linux.
