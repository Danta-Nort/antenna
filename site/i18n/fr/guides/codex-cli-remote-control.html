Installez Antenna sur les deux ordinateurs et associez-les une fois comme étant les vôtres. Sur l’ordinateur où tourne Codex, donnez un nom à la session Codex avec antenna connect codex et lancez-la avec antenna session start … --cli codex. Une conversation portant ce nom apparaît sur votre portable : écrivez-y une tâche, et Antenna réveille Codex quand il est inactif. Codex lit votre message, travaille sur l’autre ordinateur et répond dans la conversation. Aucune session SSH ne reste ouverte et aucun port entrant n’est à ouvrir.

Ce qu’il vous faut

  • Codex CLI installé et connecté sur l’ordinateur qui fait le travail : un serveur Linux en x86_64, ou un Mac ou un poste Linux. Codex continue d’utiliser votre propre abonnement ; Antenna n’a besoin d’aucune clé d’API.
  • tmux sur cet ordinateur. Sur un serveur, lancez aussi une fois sudo loginctl enable-linger $USER, pour qu’Antenna et la session continuent de tourner après votre déconnexion.
  • Antenna sur les deux ordinateurs : l’app sur un poste de bureau, le nœud sur un serveur (curl -fsSL https://antenna.contact/install.sh | sh).

1. Associer les deux ordinateurs

Sur votre portable : Nouveau contact → Inviter, cochez C’est mon propre ordinateur (∞), créez le lien et ouvrez-le sur l’autre ordinateur (sur un serveur, antenna join '<link>' --trust 5 --label mac). Saisissez sur l’un le code affiché par l’autre. Les deux côtés se considèrent désormais comme vos propres ordinateurs. La version pas à pas, avec captures d’écran, se trouve dans Claude Code sur un VPS ; c’est la même chose pour Codex.

2. Donner un nom à la session Codex

Sur l’ordinateur où tourne Codex, dans le dossier du projet :

cd ~/projects/api
antenna connect codex --agent api-codex --links mac --hello mac

Cette commande crée l’agent api-codex avec son propre fichier de jeton, le relie à votre portable (mac est le nom que cet ordinateur a donné à votre portable lors de l’association) et envoie un bonjour, si bien qu’une conversation nommée api-codex apparaît aussitôt sur le portable. Vos propres réglages de Codex ne sont pas modifiés : Antenna n’est ajouté que pour les sessions de cet agent.

3. Lancer Codex via Antenna

antenna session start api-codex --dir ~/projects/api --cli codex
antenna session attach api-codex

Codex démarre dans le serveur tmux propre à Antenna ; votre tmux n’est pas touché. Attachez-vous une fois pour répondre aux premières questions de Codex. La première fois, Codex vous demande de faire confiance aux hooks d’Antenna (« Hooks need review ») : choisissez « Trust all and continue ». Détachez-vous ensuite avec Ctrl-b d, et Codex continue de tourner. --resume reprend la dernière session de l’agent après un redémarrage.

4. Lui écrire depuis votre portable

Ouvrez la conversation api-codex et écrivez : « Lance les tests, corrige ce qui échoue et dis-moi ce que tu as changé. » Quand Codex attend, inactif, devant son invite, Antenna tape une ligne prédéfinie qui lui dit de lire sa boîte de réception. Il ne tape jamais votre texte dans le terminal et ne tape jamais par-dessus une question que pose Codex. Codex lit le message via Antenna, travaille et répond dans la conversation. Expérimental.

Besoin qu’il arrête ce qu’il fait ? Activez Urgent : interrompre maintenant avant d’envoyer. Antenna appuie une fois sur Échap pour mettre fin au tour en cours, puis réveille Codex pour votre message. Pour arrêter l’agent et tout ce qu’il a lancé, ouvrez la fiche de l’autre ordinateur dans Mes appareils sur votre portable et cliquez sur Arrêter l’agent et ses processus… à côté de api-codex.

Sur un poste de bureau : le mode Code

Si Codex tourne sur un Mac ou un poste Linux avec l’app Antenna, vous pouvez sauter les étapes en terminal. En mode Code, cliquez sur + dans le panneau des agents, choisissez Codex et le dossier de travail : Codex tourne alors dans un onglet à l’intérieur de la fenêtre, réveillé de la même façon. Sa conversation est joignable depuis vos autres ordinateurs comme celle de n’importe quel autre agent.

Questions

Est-ce que je vois le terminal de Codex sur mon portable ?

Non. Vous confiez des tâches à Codex et lisez ses réponses dans une conversation ; le terminal reste sur l’autre ordinateur. Pour le regarder travailler, lancez antenna session attach là-bas, en SSH si vous le souhaitez.

Quelles versions de Codex fonctionnent ?

Codex 0.160 et les versions suivantes signalent ce qu’elles font via des hooks : c’est ainsi qu’Antenna sait quand Codex est inactif. Avec un Codex plus ancien, ou si vous ne faites pas confiance aux hooks, Antenna attend que Codex affiche sa ligne de saisie vide après un tour, et ne tape jamais pendant qu’un tour est en cours.

Codex peut-il aussi discuter avec Claude Code ?

Oui. Reliez les deux agents sur la carte des agents, et les messages de chacun vont à l’autre sans avoir à le nommer : voir faire communiquer Claude Code et Codex.

Puis-je le piloter depuis mon téléphone ?

Pas encore. Antenna fonctionne aujourd’hui sous macOS et Linux.
