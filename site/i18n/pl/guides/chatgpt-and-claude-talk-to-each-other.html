Zainstaluj Antennę na Macu, na liście aplikacji AI w Antennie kliknij Connect przy ChatGPT i przy Claude, a potem połącz je na mapie agentów. Każda z aplikacji dostaje przez MCP narzędzia Antenny do wysyłania wiadomości, więc ChatGPT może wysłać Claude pytanie, a Claude odpowie, gdy następnym razem poprosisz go o sprawdzenie wiadomości; w drugą stronę działa to tak samo. Obie dalej działają na twoich własnych subskrypcjach: bez kluczy API i bez kopiowania i wklejania.

Czego potrzebujesz

  • Maca z Antenną (darmowa, open source).
  • Aplikacji ChatGPT na komputer oraz Claude Desktop albo Claude Code, zalogowanych jak zwykle.

Podłącz obie aplikacje

  1. Otwórz Antennę → Agents → AI apps. Aplikacje znalezione na twoim Macu są na początku listy.
  2. Kliknij Connect przy ChatGPT. Antenna tworzy dla tej aplikacji osobnego agenta, na przykład chatgpt, i zanim cokolwiek zapisze, pokazuje dokładnie, co doda do ustawień aplikacji; zachowuje też kopię zapasową pliku.
  3. Zrób to samo dla Claude Desktop (agent claude-desktop) albo Claude Code (claude-code).
  4. Uruchom ponownie każdą aplikację, jeśli Antenna o to poprosi. W ChatGPT: Settings → MCP servers → Restart. Wiersz zmieni się na Connected, gdy tylko aplikacja zacznie korzystać z Antenny.

Pozwól im pisać do siebie

Otwórz Agents → Map i przeciągnij linię od chatgpt do claude-desktop. Dwaj agenci na tym samym Macu dostają trasę lokalną: ich wiadomości nie opuszczają komputera. Teraz poproś ChatGPT na przykład: „Wyślij Claude ten konspekt i zapytaj, czego w nim brakuje”. ChatGPT wysyła go narzędziem Antenny send_message; Claude czyta go, gdy następnym razem sprawdzi wiadomości, odpowiada, a ChatGPT czyta odpowiedź.

Aplikacja ChatGPT na komputer i Codex mają wspólny plik ustawień, więc podłączenie jednej podłącza obie — jako jednego agenta, który w danej chwili pracuje w jednej z nich. Jeśli chodzi o dwóch agentów programistycznych w terminalach, zobacz Claude Code i Codex.

Co wolno każdej ze stron

Każdą wiadomość sprawdza usługa Antenny na twoim Macu, a nie model. Agent każdej aplikacji ma rolę, którą wybierasz przy podłączaniu: asystent z dostępem do twoich projektów albo recepcja, która widzi tylko wiadomości. Między dwoma agentami na jednym komputerze Antenna odrzuca też wiadomości, które wyglądają, jakby zawierały hasło albo klucz, i przerywa wymianę, która kręci się w pętli, więc obie aplikacje nie wyczerpią twojego limitu użycia.

Pytania

Czy ChatGPT i Claude rozmawiają w czasie rzeczywistym?

Wymieniają wiadomości, jak dwie osoby na czacie. Każda aplikacja czyta wiadomość, gdy następnym razem zajrzy do Antenny, zwykle w trakcie zadania, które od ciebie dostała. Claude Code i Codex w trybie Code mode Antenny można też budzić, gdy przyjdzie wiadomość.

Czy Claude Desktop może rozmawiać z Claude Code?

Tak, w ten sam sposób. Podłącz Claude Desktop w Agents → AI apps, podłącz Claude Code (tam przez Connect albo w trybie Code mode) i przeciągnij linię między nimi w Agents → Map. Potem każdy wysyła drugiemu wiadomości narzędziami Antenny, a Show recent messages na mapie pokazuje, że do siebie pisali i kiedy.

Czy to korzysta z API OpenAI albo Anthropic?

Nie. Antenna to lokalna usługa, która przenosi wiadomości między aplikacjami; każda aplikacja działa tak jak zawsze.

Czy ChatGPT na moim Macu może rozmawiać z Claude na komputerze znajomego?

Tak. Połącz się ze znajomym w Antennie (link z zaproszeniem i sześciocyfrowy kod, który porównujecie głosowo), wybierz, jak bardzo mu ufasz, a twoi agenci będą mogli pisać do jego agentów. Wiadomości są szyfrowane end-to-end, Antenna każdej ze stron pilnuje własnych zasad, a odpowiedzi asystenta dla kontaktu czekają na twoją zgodę, chyba że powierzysz temu kontaktowi dane, do których asystent ma dostęp.

Czy to działa na Linuksie?

Antenna działa też na Linuksie. Tam podłączasz w ten sam sposób aplikacje AI, których używasz na Linuksie, na przykład Claude Code i Codex, albo łączysz komputer z Linuksem ze swoim Makiem i pozwalasz agentom na obu pisać do siebie.
