Na samym laptopie się nie da: zamknięcie pokrywy usypia laptopa, uśpiony komputer niczego nie wykonuje, a Claude Code zatrzymuje się razem z nim. Wyjście jest takie: uruchom Claude Code na komputerze, który stale działa, na przykład na serwerze z Linuksem albo na Macu mini ustawionym tak, żeby nie przechodził w uśpienie, uruchom go tam przez Antennę i zlecaj mu zadania z czatu Antenny na laptopie. Zamknij laptopa: Claude Code pracuje dalej na drugim komputerze, a jego odpowiedzi czekają na laptopa i docierają, gdy ten wróci do sieci.

Dlaczego się zatrzymuje

Claude Code działa na komputerze, na którym go uruchomisz. Gdy ten komputer przechodzi w uśpienie, zatrzymuje się każdy program, łącznie z Claude Code, aż do wybudzenia. Zamknięcie terminala albo okna SSH, w którym działa, też go kończy. Laptopa można utrzymać w stanie czuwania przy zamkniętej pokrywie, ale wtedy musi być stale podłączony do zasilania i włączony, czyli w praktyce staje się serwerem. Dlatego praca przenosi się na komputer, który stale działa, a laptop tylko z nim rozmawia.

Czego potrzebujesz

  • Komputera, który stale działa: serwera z Linuksem na x86_64 (VPS albo w domu) albo desktopa z macOS lub Linuksem ustawionego tak, żeby nie przechodził w uśpienie.
  • Zainstalowanego i zalogowanego tam Claude Code.
  • Antenny na obu komputerach: aplikacji na laptopie (macOS albo Linux), węzła albo aplikacji na drugim.

Na serwerze

  1. Zainstaluj węzeł Antenny i pozwól mu działać po wylogowaniu: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
    Instalator konfiguruje Antennę jako usługę użytkownika systemd i tworzy twój węzeł z hasłem. Nie włącza lingeringu, tylko o nim przypomina: bez drugiej linii usługa zatrzyma się po wylogowaniu.
  2. Raz połącz serwer z laptopem. Na laptopie: Nowy kontakt → Zaproś, zaznacz To mój własny komputer (∞), kliknij Utwórz link i skopiuj link. Na serwerze: antenna join '<link>' --trust 5 --label mac, wpisz kod pokazany na laptopie, a potem na laptopie kliknij Kontakt potwierdził — kody się zgadzają.
  3. Uruchom Claude Code przez Antennę w folderze projektu (serwer potrzebuje tmuxa): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Odpowiedz na pierwsze pytania Claude Code, na przykład czy ufa temu folderowi, a potem odłącz się skrótem Ctrl-b d. Na laptopie jest już czat api-dev.
  4. Pozwól laptopowi odpowiadać na prośby serwera o zgodę: antenna devices confirm mac.

Teraz możesz wylogować się z SSH. Usługa działa dalej, a Claude Code działa dalej na własnym serwerze tmux Antenny; twojego tmuxa nic nie dotyka. Poradnik Claude Code na VPS opisuje każdy krok dokładniej.

Na stale włączonym Macu albo desktopie

  1. W ustawieniach systemowych ustaw komputer tak, żeby sam nie przechodził w uśpienie. Antenna nie utrzymuje komputera w stanie czuwania.
  2. Połącz go z laptopem jak wyżej, z zaznaczonym polem To mój własny komputer (∞).
  3. Na nim otwórz Agenci → Aplikacje AI i kliknij Uruchom w trybie Code mode obok Claude Code. Wybierz Nowy agent… i nadaj mu nazwę, wskaż folder w polu Folder roboczy, wpisz hasło i kliknij Uruchom. Okno przełącza się w tryb Code mode, a Claude Code działa w karcie w tym oknie.
  4. Poproś raz Claude Code, w jego karcie, żeby przywitał się z twoim laptopem przez Antennę. Wtedy jego czat pojawi się na laptopie.
  5. Pozwól laptopowi odpowiadać na jego prośby o zgodę: Moje urządzenia → karta laptopa → Zgody → Przyjmuj zgody podpisane kluczem: …, z twoim hasłem.

Nie zamykaj okna Antenny: jego zamknięcie zatrzymuje agentów, którzy w nim działają, a okno najpierw o to zapyta.

Zostaw go przy pracy

Napisz zadanie na czacie agenta na laptopie: „Uruchom testy migracji, napraw to, co nie przechodzi, i odpisz tutaj, co się zmieniło”. Gdy Claude Code czeka bezczynnie przy swoim prompcie, Antenna wpisuje jedną wbudowaną linię, żeby przeczytał twoją wiadomość; jeśli jest w trakcie tury, dostanie wiadomość, gdy tura się skończy. Antenna nigdy nie wpisuje twojego tekstu do terminala. Funkcja eksperymentalna. Potem zamknij laptopa.

Przed długą pracą sprawdź, co mogłoby ją zatrzymać, gdy nikogo nie ma:

  • Własne pytanie Claude Code o zgodę („Do you want to proceed?”) czeka w jego terminalu, aż ktoś odpowie, a Antenna nigdy na nie nie odpowiada. Zezwól w ustawieniach Claude Code na narzędzia, których potrzebuje zadanie.
  • Prośby Antenny o zgodę czekają 10 minut. Potem nic się nie wykonuje, a Claude Code dowiaduje się, że nikt ich nie zatwierdził. Zadanie zlecone z twojego własnego komputera na poziomie ∞ wykonuje polecenia i edycje bez pytania; zmiany we własnej konfiguracji Claude Code, takiej jak CLAUDE.md czy .claude/, nadal wymagają zgody.

Gdy laptop się wybudzi

Gdy laptop śpi, odpowiedzi Claude Code czekają w kolejce na drugim komputerze, a Antenna wciąż próbuje je dostarczyć. Gdy laptop wróci do sieci, trafiają na czat, z powiadomieniem, jeśli okno Antenny nie jest na wierzchu. Wiadomość napisana offline pokazuje zegar i wychodzi sama. Prośby, które wciąż czekają na twoją zgodę, widać na karcie drugiego komputera w sekcji Moje urządzenia (funkcja eksperymentalna).

Po restarcie drugiego komputera

Po restarcie klucze są zablokowane, więc jego połączenia milczą, dopóki nie wpiszesz hasła. Na serwerze zaloguj się i uruchom antenna unlock, a potem znowu uruchom sesję; --resume wznawia ostatnią sesję Claude Code:

antenna session start api-dev --dir ~/projects/api --resume

Na Macu wpisz hasło w oknie Antenny i znowu uruchom agenta.

Pytania

Czy Claude Code działa dalej, gdy zamknę laptopa?

Nie, jeśli zamknięcie pokrywy usypia laptopa, a tak jest zwykle ustawione: Claude Code stoi, dopóki go nie otworzysz. Uruchom go na komputerze, który stale działa, a będzie pracował dalej.

Czy Claude Code może działać w tle na moim laptopie?

Dopóki laptop nie śpi, tak: w trybie Code mode działa w karcie okna Antenny, na którą nie musisz patrzeć, a Antenna budzi go, gdy przyjdzie wiadomość. Ale gdy laptop przejdzie w uśpienie, i tak się zatrzyma.

Czy muszę trzymać otwartą sesję SSH?

Nie. Claude Code działa w tmuxie Antenny na serwerze, a ty docierasz do niego przez czat. Oba komputery łączą się na zewnątrz, więc nie otwiera się też żaden port przychodzący.

Czy Antenna nie pozwala Macowi zasnąć?

Nie. Ustaw Maca tak, żeby nie przechodził w uśpienie, w jego ustawieniach systemowych. Do trybu Code mode okno Antenny musi być otwarte.

Czy mogę sprawdzić postęp z telefonu?

Jeszcze nie. Antenna działa dziś na macOS i Linuksie.
