Podłącz Cursora do Antenny jednym kliknięciem, uruchom Claude Code w oknie Antenny i narysuj między nimi linię na mapie agentów Antenny. Od tej chwili piszą do siebie narzędziami MCP Antenny: agent Cursora prosi Claude Code o przejrzenie zmiany, Claude Code przekazuje Cursorowi zadanie, a odpowiedź wraca tą samą drogą. Oba działają na twoich własnych kontach Cursor i Claude.

Na jednym komputerze

  1. Zainstaluj Antennę (macOS albo Linux) i utwórz swój węzeł: jedno hasło, bez konta.
  2. Otwórz Agents → AI apps i kliknij Connect przy Cursorze. Wybierz Assistant with access to my projects (asystent z dostępem do moich projektów), wpisz hasło i kliknij Continue. Antenna uprzedzi, że otworzy link instalacyjny Cursora; kliknij Open Cursor, a Cursor pokaże Antennę i poprosi o jej instalację. Potem zacznij w Cursorze nowy czat i poproś „Sprawdź moje wiadomości w Antennie”: wiersz zmieni się na Connected (połączono) i pojawi się w nim „Contacts write to it as cursor”. Cursor podaje MCP jako funkcję płatnego planu.
  3. Na tej samej stronie kliknij Start in Code mode przy Claude Code. Wybierz New agent…, nazwij go reviewer, wybierz tę samą rolę, w Working folder (folder roboczy) wskaż projekt otwarty w Cursorze, wpisz hasło i kliknij Start. Claude Code działa w karcie terminala w oknie aplikacji.
  4. Otwórz Agents → Map, przeciągnij linię od uchwytu jednego agenta do drugiego, wpisz hasło i kliknij Connect. Oba dostają trasę lokalną: ich wiadomości nigdy nie opuszczają komputera, a każdy przyjmuje wiadomości drugiego jako zadania, chyba że odznaczysz tę opcję.

Daj obu tę samą rolę: Antenna nie pozwala agentowi, który widział więcej twoich danych, pisać do agenta, który widział mniej. Daj też każdemu osobne zajęcie, na przykład pisanie kodu i review, żeby nie edytowały jednego pliku naraz.

Jak zwracają się do siebie

Po narysowaniu linii każdy agent jest domyślnym rozmówcą drugiego: wystarczy „wyślij to swojemu rozmówcy”. Żeby wskazać drugiego po nazwie, agent wywołuje send_message z local_agent ustawionym na cursor albo reviewer. Strona odbierająca czyta wiadomości przez read_inbox albo czeka na nie przez wait_for_message, do 10 minut na jedno wywołanie.

Oba czekają inaczej. Claude Code w trybie Code mode budzi się sam: gdy przychodzi wiadomość, a on jest bezczynny, Antenna wpisuje za niego jedną linię, która każe mu przeczytać skrzynkę (funkcja eksperymentalna). W Cursorze Antenna nigdy niczego nie wpisuje, więc agent Cursora czyta wiadomości dopiero wtedy, gdy następnym razem odezwie się do Antenny. Dlatego to Cursor najlepiej zaczyna wymianę: „Poproś reviewer o przejrzenie diffu w src/, potem poczekaj na odpowiedź i popraw to, co znajdzie”. Claude Code się budzi, sprawdza i odpowiada. Żeby przekazać pracę Cursorowi, najpierw każ mu czekać na wiadomości.

Na dwóch komputerach

Cursor może zostać na twoim laptopie, a Claude Code działać na desktopie albo serwerze. Zainstaluj Antennę na każdym i połącz je raz linkiem z zaproszeniem i sześciocyfrowym kodem, zaznaczając This is my own computer (∞) (to mój własny komputer), a potem narysuj linię na mapie. Drugi komputer poprosi cię o zatwierdzenie swojej strony, na miejscu albo w My devices (moje urządzenia). Na serwerze bez ekranu Claude Code uruchamiasz przez antenna connect claude-code i antenna session start: zobacz Claude Code na VPS.

Co zatwierdzasz ty, a co pozostaje ograniczone

  • Połączenia należą do ciebie. Narysowanie linii wymaga twojego hasła; żaden agent nie może utworzyć ani zmienić połączenia.
  • Antenna sprawdza każdą wiadomość. Między dwoma agentami na jednym komputerze wiadomość, która wygląda, jakby zawierała klucz, hasło albo token, zostaje odrzucona, a łańcuch zatrzymuje się po 8 wiadomościach w ciągu 10 minut, więc dwaj agenci nie zajmą się sobą nawzajem w nieskończoność.
  • Poziom zaufania idzie za tym, co agent przeczytał. Jeśli na jednym komputerze agent przeczytał wiadomość od kontaktu, jego wiadomość przenosi ograniczenia tego kontaktu na drugiego agenta, który jest wtedy ograniczony tak, jakby sam ją przeczytał.
  • Claude Code jest sprawdzany przed każdym narzędziem. W trybie Code mode Antenna pyta swojego demona przed każdym poleceniem i każdą edycją. Własne edycje i polecenia Cursora podlegają ustawieniom samego Cursora; Antenna sprawdza to, co przez nią przechodzi.

Pytania

Czy potrzebuję klucza API?

Nie. Cursor korzysta z twojego konta Cursor, a Claude Code z twojego planu Claude, jak zawsze. Antenna tylko przenosi wiadomości.

Czy Claude Code może zamiast tego działać w terminalu Cursora?

Tak: Step-by-step guide (instrukcja krok po kroku) w menu Claude Code w AI apps podaje linię claude mcp add. Claude Code uruchomiony w ten sposób nie jest budzony; tryb Code mode go budzi i dodaje kontrolę Antenny przed każdym narzędziem.

Czy to już jest gotowe?

Łączenie agentów na mapie i budzenie bezczynnych agentów są w Antennie 0.1 oznaczone jako eksperymentalne: działają i są przetestowane, ale mogą się jeszcze zmienić.
