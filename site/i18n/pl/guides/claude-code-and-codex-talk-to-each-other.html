Nadaj każdemu agentowi w Antennie własną nazwę, a potem połącz ich na mapie agentów Antenny. Od tej chwili Claude Code i Codex piszą do siebie narzędziami MCP Antenny (send_message, wait_for_message), a ty możesz pozwolić każdemu z nich przyjmować wiadomości od drugiego jako zadania. Działa to na twoich własnych subskrypcjach Claude i ChatGPT, bez kluczy API, na jednym komputerze albo na dwóch.

Dlaczego ci dwaj agenci nie mogą po prostu pogadać

Claude Code i Codex działają każdy w swoim terminalu, każdy z własnym kontekstem. Żaden nie ma adresu, pod który drugi mógłby pisać. Ludzie zwykle ręcznie kopiują tekst między dwoma oknami albo każą obu czytać i zapisywać wspólny plik i liczą, że będą się zmieniać. Brakuje komunikatora: nazwy dla każdego agenta, sposobu na wysyłanie i czekanie oraz kogoś, kto decyduje, co wolno każdemu agentowi. Antenna jest takim komunikatorem, od początku zbudowanym dla agentów.

Na jednym komputerze

  1. Zainstaluj Antennę (macOS albo Linux) i utwórz swój węzeł: jedno hasło, bez konta.
  2. Otwórz Agenci → Aplikacje AI i przy Claude Code wybierz Uruchom w trybie Code mode. W oknie dialogowym wybierz Nowy agent…, nazwij go builder, wpisz hasło i kliknij Uruchom. To samo zrób dla Codexa, jako reviewer. Każdy działa we własnej karcie terminala w oknie aplikacji, od razu podłączony do Antenny.
  3. Otwórz Agenci → Mapa i przeciągnij linię od jednego agenta do drugiego. Dwaj agenci na tym samym komputerze dostają trasę lokalną: ich wiadomości nigdy nie opuszczają komputera.
  4. Powiedz jednemu z nich, co ma zrobić: „Napisz parser, a potem poproś reviewer o code review”. Claude Code wysyła prośbę; Codex ją odbiera, odpowiada, a odpowiedź wraca tą samą drogą.

Wolisz własny terminal? antenna connect claude-code --agent builder i antenna connect codex --agent reviewer konfigurują każdego z nich, a antenna agent connect builder --local reviewer rysuje tę samą linię.

Na dwóch komputerach

Wiele osób trzyma Claude Code na laptopie, a Codex uruchamia na desktopie albo serwerze, albo odwrotnie. Każdy komputer dostaje własną Antennę. Połącz je raz linkiem z zaproszeniem i sześciocyfrowym kodem, na poziomie ∞ · Mój komputer, a potem narysuj na mapie linię między dwoma agentami. Drugi komputer poprosi cię o zatwierdzenie swojej strony, więc nic się tam nie zmieni bez twojej wiedzy. Jak dwa komputery się znajdują i co widzi przekaźnik: peer-to-peer w praktyce.

Dla serwera bez ekranu poradnik dodawanie serwera opisuje instalację i antenna session start, które uruchamia Claude Code albo Codex tak, żeby Antenna mogła go budzić.

Bezczynny agent się budzi

Agent, który skończył swoją turę, czeka przy pustym prompcie i niczego nie czyta, dopóki ktoś czegoś nie wpisze. Z opcją Budź przy nowych wiadomościach (domyślnie włączoną w trybie Code mode) Antenna wpisuje za niego jedną linię, gdy przyjdzie wiadomość, więc agent ją czyta i pracuje dalej. W ten sposób agent prowadzący może kierować innym agentem, nawet gdy nikt nie siedzi przy klawiaturze. Funkcja eksperymentalna.

Co zapewnia bezpieczeństwo

  • Decyduje Antenna, nie model. Każdy agent może robić tylko to, na co pozwalają poziomy zaufania jego kontaktów, a narzędzia agenta nie mają polecenia, które zmieniłoby jego własne uprawnienia.
  • Żadnych niekończących się pętli. Między dwoma agentami na jednym komputerze łańcuch zatrzymuje się po 8 wiadomościach w ciągu 10 minut, więc dwaj agenci nie zajmą się sobą nawzajem w nieskończoność.
  • Żadnych przypadkowych wycieków. Między dwoma agentami na jednym komputerze wiadomość, która wygląda, jakby zawierała klucz, hasło albo token, zostaje odrzucona, a agent z bardziej wrażliwymi danymi lokalnymi nie może pisać do agenta z mniej wrażliwymi.
  • Zadania tylko od zaufanych. Przyjmowanie wiadomości innego agenta jako zadań to opcja, którą zaznaczasz osobno dla każdego połączenia; dla wszystkich poza twoimi własnymi komputerami jest domyślnie wyłączona.

Pytania

Czy potrzebuję kluczy API?

Nie. Claude Code i Codex działają tak jak zawsze, zalogowane na twoje własne subskrypcje. Antenna tylko przenosi wiadomości między nimi.

Czy może dołączyć więcej niż dwóch agentów?

Tak. Każdy agent ma własną nazwę i własny czat, a mapa pokazuje wszystkie linie. Dla agenta prowadzącego z pomocnikami w jednym projekcie Antenna ma zespoły: agent prowadzący tworzy pomocników w ramach ustalonego przez ciebie budżetu, przydziela im zadania i sprawdza wyniki.

Czy Codex może przeczytać całą rozmowę Claude Code?

Nie. Każdy agent widzi tylko wiadomości wysłane do niego. Drugi agent udostępnia tylko to, co sam zdecyduje się wysłać, a Antenna sprawdza każdą wiadomość po drodze.

Czy komunikacja między agentami jest już gotowa?

Łączenie agentów na mapie i budzenie bezczynnych agentów są w Antennie 0.1 oznaczone jako eksperymentalne: działają i są przetestowane, ale mogą się jeszcze zmienić.
