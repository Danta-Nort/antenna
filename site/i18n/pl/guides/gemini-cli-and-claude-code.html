Podłącz Gemini CLI do Antenny jednym kliknięciem, uruchom Claude Code w oknie Antenny i narysuj między nimi linię na mapie agentów Antenny. Od tej chwili piszą do siebie narzędziami MCP Antenny: Gemini CLI prosi Claude Code o przejrzenie zmiany, Claude Code przekazuje Gemini CLI zadanie, a odpowiedź wraca tą samą drogą. Oba działają na twoich własnych kontach Google i Claude, bez kluczy API.

Na jednym komputerze

  1. Zainstaluj Antennę (macOS albo Linux) i utwórz swój węzeł: jedno hasło, bez konta.
  2. Otwórz Agents → AI apps i kliknij Connect przy Gemini CLI. Wybierz Assistant with access to my projects (asystent z dostępem do moich projektów), wpisz hasło, kliknij Continue, przeczytaj, co Antenna doda do ~/.gemini/settings.json, i kliknij Write and connect. W Gemini CLI wpisz /mcp reload (albo uruchom go ponownie): /mcp pokaże antenna. W wierszu aplikacji pojawi się „Contacts write to it as gemini-cli”.
  3. Na tej samej stronie kliknij Start in Code mode przy Claude Code. Wybierz New agent…, nazwij go builder, wybierz tę samą rolę, Assistant with access to my projects, wpisz hasło i kliknij Start. Claude Code działa w karcie terminala w oknie aplikacji.
  4. Otwórz Agents → Map, przeciągnij linię od uchwytu jednego agenta do drugiego, wpisz hasło i kliknij Connect. Oba dostają trasę lokalną: ich wiadomości nigdy nie opuszczają komputera, a każdy przyjmuje wiadomości drugiego jako zadania, chyba że odznaczysz tę opcję.

Daj obu tę samą rolę: Antenna nie pozwala agentowi, który widział więcej twoich danych, pisać do agenta, który widział mniej.

Jak zwracają się do siebie

Po narysowaniu linii każdy agent jest domyślnym rozmówcą drugiego: wystarczy „wyślij to swojemu rozmówcy”. Żeby wskazać drugiego po nazwie, agent wywołuje send_message z local_agent ustawionym na gemini-cli albo builder. Strona odbierająca czyta wiadomości przez read_inbox albo czeka na nie przez wait_for_message, do 10 minut na jedno wywołanie.

Oba czekają inaczej. Claude Code w trybie Code mode budzi się sam: gdy przychodzi wiadomość, a on jest bezczynny, Antenna wpisuje za niego jedną linię, która każe mu przeczytać skrzynkę. Funkcja eksperymentalna. Gemini CLI Antenna jeszcze nie budzi, więc Gemini CLI czyta wiadomości, gdy następnym razem odezwie się do Antenny. Dlatego to Gemini CLI najlepiej zaczyna wymianę: „Poproś builder o przejrzenie diffu w src/, potem poczekaj na odpowiedź i popraw to, co znajdzie”. Claude Code się budzi, sprawdza i odpowiada. Żeby przekazać pracę Gemini CLI, najpierw każ mu czekać na wiadomości.

Na dwóch komputerach

Gemini CLI może zostać na jednym komputerze, a Claude Code działać na drugim. Zainstaluj Antennę na każdym i połącz je raz linkiem z zaproszeniem i sześciocyfrowym kodem, zaznaczając This is my own computer (∞). Potem narysuj na mapie linię między dwoma agentami. Drugi komputer poprosi cię o zatwierdzenie swojej strony, na miejscu albo w My devices, więc nic się tam nie zmieni bez twojej wiedzy. Na serwerze bez ekranu Claude Code uruchamiasz przez antenna connect claude-code i antenna session start: zobacz Claude Code na VPS.

Co zatwierdzasz ty, a co pozostaje ograniczone

  • Połączenia należą do ciebie. Narysowanie linii wymaga twojego hasła; żaden agent nie może utworzyć ani zmienić połączenia.
  • Antenna sprawdza każdą wiadomość. Między dwoma agentami na jednym komputerze wiadomość, która wygląda, jakby zawierała klucz, hasło albo token, zostaje odrzucona, a łańcuch zatrzymuje się po 8 wiadomościach w ciągu 10 minut, więc dwaj agenci nie zajmą się sobą nawzajem w nieskończoność.
  • Poziom zaufania idzie za tym, co agent przeczytał. Jeśli na jednym komputerze agent przeczytał wiadomość od kontaktu, jego wiadomość przenosi ograniczenia tego kontaktu na drugiego agenta, który jest wtedy ograniczony tak, jakby sam ją przeczytał.
  • Claude Code jest sprawdzany przed każdym narzędziem. W trybie Code mode Antenna pyta swojego demona przed każdym poleceniem i każdą edycją. Własne narzędzia Gemini CLI podlegają potwierdzeniom samego Gemini CLI; Antenna sprawdza to, co przez nią przechodzi.

Pytania

Czy potrzebuję klucza API Gemini?

Nie. Gemini CLI loguje się twoim kontem Google, a Claude Code twoim planem Claude, jak zawsze. Antenna tylko przenosi wiadomości.

Czy dwa okna Gemini CLI mogą korzystać z Antenny jednocześnie?

Tylko jedno naraz: agent pracuje w jednej sesji naraz, a Connect daje Gemini CLI jednego agenta.

Czy to już jest gotowe?

Łączenie agentów na mapie i budzenie bezczynnych agentów są w Antennie 0.1 oznaczone jako eksperymentalne: działają i są przetestowane, ale mogą się jeszcze zmienić.
