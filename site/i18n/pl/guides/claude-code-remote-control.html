Zainstaluj Antennę na laptopie i na komputerze, na którym działa Claude Code, raz połącz je jako własne komputery i uruchom tam Claude Code przez Antennę. Na laptopie pojawi się czat z tą sesją: napisz w nim zadanie, Antenna obudzi Claude Code, gdy będzie bezczynny, a jego odpowiedź wróci na czat. Wiadomości idą połączeniem peer-to-peer szyfrowanym end-to-end między twoimi dwoma komputerami, Antenna nie potrzebuje konta, a kroki wymagające twojej zgody trafiają na laptopa, gdzie odpowiadasz hasłem.

Remote Control w Claude Code a Antenna

Claude Code ma własną, wbudowaną funkcję Remote Control; opisuje ją dokumentacja Anthropic. Ten poradnik dotyczy innego układu: Claude Code działa na twoim stale włączonym komputerze, serwerze albo desktopie, a ty sterujesz nim z Antenny na laptopie. To rozwiązanie dla ciebie, jeśli chcesz mieć:

  • Kilka sesji na kilku komputerach na jednej liście. Każda sesja to osobny czat, a sekcja Moje urządzenia pokazuje stan każdego komputera, jego agentów i czekające tam prośby.
  • Własne połączenie. Wiadomości są szyfrowane na jednym komputerze i odszyfrowywane na drugim. Twoje komputery łączą się bezpośrednio, gdy pozwala na to sieć, a w przeciwnym razie przez przekaźnik (relay), który przekazuje wyłącznie zaszyfrowany ruch. Bez konta i bez portu przychodzącego.
  • Uprawnienia sprawdzane przez demona Antenny na komputerze, na którym działa Claude Code, ze zgodami udzielanymi z tego twojego komputera, przy którym akurat siedzisz.
  • Inni agenci tak samo: Codex działa jak Claude Code.

Konfiguracja

  1. Zainstaluj Antennę na obu komputerach: aplikację na laptopie (macOS albo Linux), a na drugim komputerze aplikację albo, na serwerze z Linuksem, węzeł: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
  2. Raz je połącz. Na laptopie: Nowy kontakt → Zaproś, zaznacz To mój własny komputer (∞), kliknij Utwórz link i skopiuj link. Na serwerze: antenna join '<link>' --trust 5 --label mac; na desktopie: Nowy kontakt → Dołącz, z tym samym zaznaczonym polem. Wpisz po jednej stronie kod pokazany po drugiej i na laptopie kliknij Kontakt potwierdził — kody się zgadzają.
  3. Uruchom Claude Code przez Antennę na drugim komputerze. Na serwerze, w folderze projektu (potrzebny tmux): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Odpowiedz na pierwsze pytania Claude Code, a potem odłącz się skrótem Ctrl-b d: Claude Code działa dalej, a na laptopie jest czat api-dev. Na desktopie: Agenci → Aplikacje AI → Uruchom w trybie Code mode, a Claude Code działa tam w karcie okna Antenny; poproś go raz, żeby przywitał się z twoim laptopem przez Antennę, a jego czat pojawi się na laptopie.
  4. Pozwól laptopowi odpowiadać na prośby o zgodę z tamtego komputera. Na serwerze: antenna devices confirm mac. Na desktopie: Moje urządzenia → karta laptopa → Zgody → Przyjmuj zgody podpisane kluczem: …, z twoim hasłem.

Steruj nim z laptopa

  • Zlecaj zadania. Pisz na czacie sesji tak, jak do człowieka. Gdy Claude Code czeka bezczynnie przy swoim prompcie, Antenna wpisuje jedną wbudowaną linię, żeby przeczytał twoją wiadomość; nigdy nie wpisuje twojego tekstu do terminala i nigdy nie odpowiada na pytanie, które Claude Code tam zadaje. Funkcja eksperymentalna.
  • Przerywaj. Przed wysłaniem włącz Pilne: przerwij teraz: Antenna raz naciska Esc, żeby zakończyć trwającą turę, nigdy wtedy, gdy jest tam otwarte pytanie albo prośba o zgodę, a Claude Code czyta twoją wiadomość. Funkcja eksperymentalna.
  • Zatwierdzaj jego kroki. Krok, który wymaga twojej decyzji, pojawia się z powiadomieniem na karcie drugiego komputera w sekcji Moje urządzenia. Naciśnij Zatwierdź hasłem, Zatwierdź przez Touch ID na Macu albo Odrzuć. Funkcja eksperymentalna.
  • Zatrzymuj. Zatrzymaj agenta i jego procesy… obok agenta na tej karcie kończy Claude Code i wszystko, co tam uruchomił. Funkcja eksperymentalna.

Własne pytanie Claude Code o zgodę („Do you want to proceed?”) zostaje w jego terminalu na drugim komputerze, a Antenna nigdy na nie nie odpowiada. Narzędziom, których używasz na co dzień, zezwól w ustawieniach Claude Code albo odpowiadaj na to pytanie przez antenna session attach.

Codex i inni agenci

Codex działa tak samo: antenna connect codex i --cli codex na serwerze albo Uruchom w trybie Code mode obok Codexa na desktopie (zobacz Zdalne sterowanie Codex CLI). Gemini CLI łączy się z sekcji Agenci → Aplikacje AI i wysyła oraz czyta wiadomości przez Antennę, ale Antenna jeszcze go nie budzi: nową wiadomość przeczyta, gdy następnym razem wywoła Antennę.

Pytania

Czy widzę terminal Claude Code na laptopie?

Nie. Zadania zlecasz i odpowiedzi czytasz na czacie; terminal zostaje na drugim komputerze. Żeby do niego zajrzeć, uruchom tam antenna session attach, jeśli chcesz, przez SSH.

Czy drugi komputer potrzebuje publicznego IP albo otwartych portów?

Nie. Oba komputery łączą się na zewnątrz, bezpośrednio, gdy pozwala na to sieć, a w przeciwnym razie przez przekaźnik. Przekaźnik przekazuje wyłącznie zaszyfrowany ruch.

Kto jeszcze może zlecać mu zadania?

Tylko kontakty połączone z tym komputerem, których wiadomości agent może czytać (z --links mac tylko twój laptop), oraz agenci, których połączysz z nim na mapie agentów. To demon Antenny na tamtym komputerze, a nie Claude Code, decyduje, do czego może go skłonić wiadomość kontaktu, zależnie od poziomu zaufania tego kontaktu.

Czy potrzebny jest klucz API?

Nie. Claude Code korzysta z twojego własnego logowania na komputerze, na którym działa, a Antenna tylko przenosi wiadomości, pliki i zgody.

Czy mogę sterować nim z telefonu?

Jeszcze nie. Antenna działa dziś na macOS i Linuksie.
