Uruchom Claude Code przez Antennę, w trybie Code mode w oknie albo poleceniem antenna session na serwerze, a demon Antenny sprawdzi każde narzędzie, którego Claude Code używa, i każdą wiadomość, którą wysyła. Gdy jakiś krok wymaga twojej decyzji, staje się prośbą o zgodę, która pojawia się z powiadomieniem w My devices (moje urządzenia) na każdym komputerze połączonym jako twój własny. Zatwierdź ją tam hasłem tego komputera albo Touch ID: komputer, na którym działa Claude Code, sprawdza twoją odpowiedź i wykonuje krok, a Claude Code pracuje dalej.

Co do ciebie trafia

  • Kroki po przeczytaniu wiadomości od kontaktu. Gdy Claude Code przeczyta wiadomość od kogoś z zespołu, poziom zaufania tej osoby wyznacza, co mu wolno: na poziomie 4 każde polecenie czeka na ciebie; na poziomach 2 i 3 czeka każda edycja, a polecenia są odrzucane.
  • Zmiany w jego własnej konfiguracji. Po przeczytaniu wiadomości od dowolnego kontaktu, nawet z twojego własnego laptopa, edycje CLAUDE.md, .claude/, profili powłoki, kluczy i plików budowania, takich jak package.json, czekają na ciebie.
  • Wiadomości, które wyniosłyby twoje dane. Gdy Claude Code przeczyta pliki twojego projektu, każda jego wiadomość do kontaktu poniżej ∞ czeka na ciebie, podobnie jak każda wiadomość do takiego kontaktu, która wygląda, jakby zawierała klucz, hasło albo token. Gdy przeczyta jedną rozmowę, wiadomość do innej też czeka.
  • Pytania. Funkcja eksperymentalna. Pytania agenta pojawiają się na komputerze, na którym działa, w Questions from your agents (pytania od twoich agentów). Żeby zamiast tego dostawać je na laptopie, uruchom na tamtym komputerze antenna agent escalate api-dev --to mac: wtedy każde pytanie trafi do czatu agenta i odpowiesz w czacie.

Własne pytanie Claude Code o zgodę („Do you want to proceed?”) zostaje w jego terminalu: Antenna nigdy niczego w nim nie wpisuje. Narzędziom, których używasz na co dzień, zezwól w ustawieniach Claude Code albo odpowiadaj na to pytanie przez antenna session attach.

Konfiguracja

  1. Zainstaluj Antennę na obu komputerach i połącz je raz z zaznaczonym This is my own computer (∞) (to mój własny komputer), jak w poradniku Claude Code na VPS.
  2. Uruchom Claude Code przez Antennę. Na desktopie: Agents → AI apps → Start in Code mode. Na serwerze: 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
  3. Na komputerze, na którym działa Claude Code, przyjmij odpowiedzi z tego, z którego będziesz zatwierdzać: My devices → karta tego komputera → Approvals (zgody) → Accept approvals signed with … (przyjmuj zgody podpisane kluczem…), z twoim hasłem. Na serwerze: antenna devices confirm mac.

Odpowiadaj z dowolnego komputera

Prośba pojawia się na karcie pytającego komputera w My devices (funkcja eksperymentalna), z powiadomieniem w rodzaju „Antenna: approval needed on Mac mini”. Karta mówi, który agent pyta, o co i dlaczego, i cytuje jego tekst, chyba że w tekście jest sekret: taki tekst nigdy nie opuszcza komputera, który pyta. Naciśnij Approve with Touch ID na Macu (funkcja eksperymentalna), Approve with password z hasłem komputera, przy którym siedzisz, albo Deny (odrzuć).

Komputer, który pytał, sprawdza podpis względem przyjętych na nim kluczy, własnego jednorazowego wyzwania (challenge) i dokładnie tej prośby, a potem sam wykonuje prośbę, jeden raz. Na tym komputerze prośba jest też w Approval requests (prośby o zgodę), a w terminalu pod antenna approvals i antenna approve <id>.

Claude Code czeka do 50 sekund i krok zatwierdzony w tym czasie wykonuje się od razu. Później zajmuje się inną pracą; gdy zatwierdzisz, Antenna wpisuje w jego wiersz poleceń „Approved — continue.”, a Claude Code ponawia krok.

Jeśli nikt nie odpowie

Prośba zamyka się po 10 minutach: nic się nie wykonuje i nic nie jest wysyłane, a Claude Code dowiaduje się, że nikt jej nie zatwierdził. Krótko wcześniej ostrzeże cię powiadomienie. Po Deny, które nie wymaga hasła, Claude Code dowiaduje się, że twoja odpowiedź brzmi „nie”.

Agent, który zatwierdza za ciebie

Funkcja eksperymentalna. Can approve for… (może zatwierdzać za…) w Agents pozwala agentowi, któremu ufasz, odpowiadać na prośby twoich pozostałych agentów dotyczące wiadomości i plików, a jego odpowiedź liczy się tylko wtedy, gdy wszystko, czego dotyczy prośba, jest na poziomie ∞. Polecenia i edycje zawsze trafiają do ciebie.

Pytania

Czy to działa z Codex?

Częściowo. To, co Codex wysyła przez Antennę, jest sprawdzane tak samo i te prośby trafiają na wszystkie twoje komputery; własne polecenia Codex nadal podlegają jego własnym zgodom w terminalu.

Czy każdy komputer może zatwierdzać?

Nie. Tylko komputer połączony jako twój własny, którego klucze przyjęto na pytającym komputerze, i tylko z hasłem. Gdy zgubisz komputer, na każdym z pozostałych użyj Revoke this computer (unieważnij ten komputer).

Czy mogę zatwierdzać z telefonu?

Jeszcze nie. Antenna działa dziś na macOS i Linuksie.
