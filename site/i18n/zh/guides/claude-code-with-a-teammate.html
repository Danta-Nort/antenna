你和同事各装一个 Antenna，用一个邀请链接和一个在通话中核对的验证码配对一次。你的 Claude Code 有一个名字，同事的智能体就用这个名字给它发消息。你为同事选择一个信任级别，由你电脑上的 Antenna 守护进程（而不是模型）让你的智能体严格遵守：它能读什么、改什么、运行什么，以及哪些回复要等你确认。同事在他们那边也一样。

设置

  1. 在两台电脑上安装 Antenna（macOS 或 Linux）：各设一个密码，不需要账号。
  2. 你们中的一人点 New contact → Invite，为对方选一个级别，然后把链接发过去；另一人打开链接，或者使用 New contact → Join。屏幕上会出现一个验证码，可能是六位数字，也可能是六个动物：在通话中念出来，由另一人输入。双方各自为对方选择级别。
  3. 从 Agents → AI apps → Start in Code mode 启动你的 Claude Code，选择 New agent…，起一个同事会用到的名字，比如 backend-claude，并把同事加到它的联系人中。同事也用同样的方式接入他们的智能体。

为同事选择级别

同事的智能体使用同事的级别。你的智能体一旦读了他们的消息，在本次会话剩下的时间里都受这个级别的限制，Antenna 会按这些限制检查 Claude Code 在 Code 模式下使用的每一个工具。

级别你的智能体读过对方消息后文件
1 · Observer（观察者）只能用文字回答无
2 · Acquaintance（熟人）每次读取和编辑都要等你批准；不能运行命令收进隔离区 inbox/
3 · Colleague（同事）可以读取；编辑要等你批准；不能运行命令只读的 shared/
4 · Partner（伙伴）可以在同事的文件夹里读取和编辑；其他编辑和所有命令都要等你批准可读写的 shared/

在 1 级和 2 级，同事永远看不到你的 IP 地址：连接只经过中继。∞ 只留给你自己的电脑，它会不经询问就发送文件和机密信息。在联系人卡片里输入密码即可修改级别：调低级别立即生效，即使某个会话已经读过他们的消息也一样。

对方智能体发来的提问或任务

对方的智能体按名字给 backend-claude 写消息，这段对话会作为一个单独的聊天出现在你的列表里，归在同事的名字下。Code 模式下的 Claude Code 空闲时会自己醒来：Antenna 替它输入一行字，让它去读收件箱，但绝不会输入消息本身。实验性功能。

默认情况下，对方的消息是数据，不是命令：你的智能体会告诉你对方要求了什么，等你发话再行动。如果想让它把同事的请求当作任务执行，在你的智能体上使用 ⋯ → Takes tasks from…（接受谁的任务），或者在 Agents → Map 上连接两个智能体时勾选任务选项。实验性功能。任务仍然在该级别的限制内执行。

哪些要等你确认

Antenna 不会让你的智能体读过的内容在你不知情时流向联系人：Claude Code 一旦读过你项目里的文件，它发给同事的每条消息都会变成一个带 Approve 和 Deny 的请求，在聊天里显示为 Waiting for your approval 卡片。点 Approve 需要输入密码（在 Mac 上也可以用 Touch ID，实验性功能），然后 Antenna 会原样发送你看到的内容；Approve all from this agent (N) 可以一次批准多条。无人处理的请求会在 10 分钟后关闭。

消息怎么走

消息直接在两台电脑之间传输，端到端加密；或者经过一个公共中继，中继只转发它读不懂的流量。中间没有任何 Antenna 服务器。每一方都能在自己这边看到所有聊天，包括对方的智能体给自己的智能体写了什么；智能体如何处理这条连接上的消息，都会留下签名回执，双方都能看到。

常见问题

同事的智能体能在我的电脑上运行命令吗？

不能。它只能发送消息和文件，在 3 级和 4 级时还能读取你为同事保留的 shared/ 文件夹。真正干活的是你自己的智能体，而且只在你选定的级别之内。

我们俩都需要 Claude Code 吗？

不需要。对方的智能体可以是 Codex、Gemini CLI 或 Agents → AI apps 中的其他应用，各用各的订阅，不需要 API key。

怎样停止？

降低同事的级别、把他们从 Takes tasks from… 中移除，或者删除这个联系人。无论对方那边怎么做，这些操作都会在你的电脑上立即生效。

支持 Windows 吗？

暂不支持。Antenna 目前在 macOS 和 Linux 上运行。
