在你的 Linux VPS 上安装 Claude Code 和 Antenna 节点，把服务器和笔记本配对一次，然后在项目文件夹里通过 Antenna 启动 Claude Code。之后即使你退出登录，它也会在自己的 tmux 会话里继续运行，有发给它的消息时就会被唤醒，并在你笔记本的聊天里回复。不需要开放入站端口，不需要一直挂着 SSH 会话，Codex 的用法也完全一样。

你需要准备

  • 一台 x86_64 的 Linux 服务器，装好并登录 Claude Code（或 Codex），另外装好 tmux。
  • 笔记本上装好 Antenna：macOS 或 Linux。

1. 在服务器上安装 Antenna 节点

curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER

安装脚本会从签名清单中读取最新版本，校验压缩包，把 antennad 和 antenna 安装到 ~/.local/bin 并注册为 systemd 用户服务（不需要 root），然后用一个密码创建你的节点。第二行让服务在你退出登录后继续运行。在 Ubuntu 或 Fedora 上，也可以改装 .deb 或 .rpm 包。

2. 和笔记本配对

在笔记本上：新联系人 → 邀请，起个名字，勾选 这是我自己的电脑（∞），点 创建链接 并复制链接。在服务器上：

antenna join '<link>' --trust 5 --label mac

别漏了单引号：链接里有一个 #。把笔记本上显示的验证码输入服务器的终端，然后在笔记本上点 联系人已确认，验证码一致。5 级在两边都对应 ∞，所以服务器会被当作你自己的电脑。

3. 通过 Antenna 启动 Claude Code

cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev

connect 这一行给会话分配专属的智能体和令牌，并打个招呼，于是你的笔记本上会出现一个名为 api-dev 的聊天。start 这一行在 Antenna 自己的 tmux 服务器里运行 Claude Code（不会碰你的 tmux）。先 attach 一次，回答 Claude Code 一开始的几个问题（比如是否信任这个文件夹），然后按 Ctrl-b d 退出：它会继续运行。如果是 Codex，就用 antenna connect codex 和 --cli codex。

4. 和它对话

在笔记本的 api-dev 聊天里写：“跑一下迁移测试，修好失败的。”当 Claude Code 停在提示符前闲着时，Antenna 会输入一行简短的文字，让它去读你的消息；Antenna 永远不会把联系人的原文输入进去，也永远不会替它回答问题。我的设备 中的服务器卡片会显示它的运行状况和上面的智能体，你可以在笔记本上批准它的请求。

重启之后

服务器重启后，节点的密钥会被锁定：服务在运行，但它的连接保持静默，直到你登录并运行 antenna unlock。这样一来，即使有人拿到服务器磁盘的副本，也拿不到你的密钥。antenna status 会显示它是否处于锁定状态。

常见问题

为什么不直接用 SSH 加 tmux？

你坐在终端前时，那样确实可行。Antenna 额外提供了一个聊天，你随时都能在笔记本上给它写消息，写的时候会唤醒会话，还能让其他智能体给它派活，而权限由 Antenna 自己检查。

服务器需要公网 IP 或开放端口吗？

不需要。两边都是主动向外连接，网络允许时直连，否则经过中继。中继只转发加密流量。

一台服务器上能跑多个会话吗？

能：每个项目文件夹一个智能体，各自有自己的名字，在你笔记本上也各有一个聊天。

有 ARM 版本吗？

暂时还没有。服务器节点目前只为 x86_64 Linux 构建。
