隐私政策

简单来说：本网站不收集任何关于你的信息。这里没有表单、跟踪器、统计分析或 Cookie，也不从其他网站加载任何内容。Antenna 应用只让我们统计新安装数量，不涉及地址，也不涉及内容。

本网站

  • 没有统计分析，没有跟踪像素，没有广告，没有 Cookie。
  • 没有外部脚本、字体或图片，所有内容都由 antenna.contact 提供。
  • 邀请链接：地址中“#”后面的部分只留在你的浏览器里，本网站永远不会收到它。
  • 下载按钮会把你带到 GitHub 上的文件，那里适用 GitHub 的隐私声明。

本网站运行在 Cloudflare Workers 上。和任何 Web 服务器一样，Cloudflare 需要处理你的 IP 地址才能把页面发给你；我们不保留任何请求日志。

Antenna 应用

Antenna 没有账号，也没有替你传递消息的我方服务器：消息和文件在聊天双方的设备之间端到端加密传输，要么直接连接，要么经过只转发加密流量的中继。除了统计新安装数量之外，应用不发送任何使用数据，也不发送崩溃报告；它向我方服务器发出的唯一请求就是下面说的更新检查。

应用每天会询问一次 updates.stillbyte.dev，看是否有更新的签名版本。这个请求不携带任何关于你、你的联系人或你的消息的信息；和任何网络请求一样，它会向服务器暴露这台电脑的 IP 地址。从 0.1.1 版开始，安装 Antenna 后的第一次检查会带上一个“首次检查”标记，除此之外什么都没有，这样我们才能统计新安装数量。更新服务器只统计每天收到多少次更新检查，以及其中有多少是新安装的首次检查；它不存储任何地址。如果想关闭更新检查，在 ~/.config/antenna/update-url 中写入 off 即可。
