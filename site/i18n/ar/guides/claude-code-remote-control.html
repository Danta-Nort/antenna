ثبّت Antenna على حاسوبك المحمول وعلى الحاسوب الذي يعمل عليه Claude Code، واقرن الاثنين مرة واحدة على أنهما حاسوباك، وشغّل Claude Code هناك عبر Antenna. تظهر على حاسوبك المحمول محادثة مع تلك الجلسة: اكتب فيها مهمة، فيوقظ Antenna ‏Claude Code حين يكون خاملًا، ويعود رده إلى المحادثة. تنتقل الرسائل عبر رابط ند لند (peer-to-peer) مشفّر تشفيرًا تامًا بين الطرفين بين حاسوبيك، ولا يحتاج Antenna إلى أي حساب، والخطوات التي تحتاج إلى موافقتك تصل إلى الحاسوب المحمول، فتجيب عنها بكلمة مرورك.

ميزة Remote Control في Claude Code، وAntenna

لدى Claude Code ميزة Remote Control مدمجة خاصة به، وتشرحها وثائق Anthropic. أما هذا الدليل فيتناول إعدادًا مختلفًا: يعمل Claude Code على حاسوب من حواسيبك يبقى قيد التشغيل، خادم أو حاسوب مكتبي، وتتحكم فيه من Antenna على حاسوبك المحمول. ويناسبك إن كنت تريد:

  • عدة جلسات على عدة حواسيب في قائمة واحدة. كل جلسة محادثة مستقلة، وتعرض My devices (أجهزتي) حالة كل حاسوب ووكلاءه والطلبات التي تنتظر هناك.
  • رابطك الخاص. تُشفَّر الرسائل على حاسوب وتُفك على الآخر. تتصل حواسيبك مباشرة حين تسمح الشبكة، وإلا فعبر خادم ترحيل (relay) لا يمرر إلا حركة مرور مشفرة. لا حساب ولا منفذ وارد.
  • أذونات تفحصها الخدمة الخلفية لـ Antenna على الحاسوب الذي يعمل عليه Claude Code، مع موافقات تجيب عنها من أي حاسوب من حواسيبك تجلس أمامه.
  • وكلاء آخرون بالطريقة نفسها: يعمل Codex كما يعمل Claude Code.

الإعداد

  1. ثبّت Antenna على الحاسوبين: التطبيق على حاسوبك المحمول (macOS أو Linux)، وعلى الحاسوب الآخر التطبيق، أو العقدة إن كان خادم Linux: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
  2. اقرنهما مرة واحدة. على الحاسوب المحمول: New contact → Invite (جهة اتصال جديدة ← دعوة)، وحدّد This is my own computer (∞) (هذا حاسوبي أنا)، واضغط Create link (إنشاء رابط) وانسخه. وعلى خادم: antenna join '<link>' --trust 5 --label mac؛ وعلى حاسوب مكتبي: New contact → Join (جهة اتصال جديدة ← انضمام)، مع تحديد الخانة نفسها. أدخل الرمز الذي يعرضه أحد الطرفين في الطرف الآخر، واضغط The contact confirmed — codes match على الحاسوب المحمول.
  3. شغّل Claude Code عبر Antenna على الحاسوب الآخر. على خادم، في مجلد المشروع (يلزم tmux): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    أجب عن أسئلة Claude Code الأولى، ثم اخرج بـ Ctrl-b d: فيواصل العمل، وتظهر على حاسوبك المحمول محادثة باسم api-dev. وعلى حاسوب مكتبي: Agents → AI apps → Start in Code mode (الوكلاء ← تطبيقات الذكاء الاصطناعي ← البدء في وضع Code)، فيعمل Claude Code هناك في تبويب من نافذة Antenna؛ اطلب منه مرة واحدة أن يلقي التحية على حاسوبك المحمول عبر Antenna، فتظهر محادثته على الحاسوب المحمول.
  4. دع الحاسوب المحمول يجيب عن طلبات الموافقة الآتية من ذلك الحاسوب. على خادم: antenna devices confirm mac. وعلى حاسوب مكتبي: My devices → بطاقة الحاسوب المحمول → Approvals (الموافقات) → Accept approvals signed with …، بكلمة مرورك.

تحكّم فيه من حاسوبك المحمول

  • أعطه مهمة. اكتب في محادثة الجلسة كما تكتب لشخص. حين يكون Claude Code خاملًا أمام موجّهه، يكتب Antenna سطرًا ثابتًا واحدًا كي يقرأ رسالتك؛ ولا يكتب نصك في الطرفية أبدًا، ولا يجيب أبدًا عن سؤال يطرحه Claude Code هناك. تجريبي.
  • قاطعه. فعّل Urgent: interrupt now (عاجل: قاطِع الآن) قبل الإرسال: يضغط Antenna مفتاح Esc مرة واحدة لإنهاء الدورة الجارية، ولا يفعل ذلك أبدًا فوق سؤال أو نافذة أذونات مفتوحة هناك، ثم يقرأ Claude Code رسالتك. تجريبي.
  • وافق على خطواته. تظهر الخطوة التي تحتاج إليك على بطاقة الحاسوب الآخر في My devices، مع إشعار. اضغط Approve with password (الموافقة بكلمة المرور)، أو Approve with Touch ID على Mac، أو Deny (رفض). تجريبي.
  • أوقفه. يُنهي Stop agent and its processes… (إيقاف الوكيل وعملياته)، بجوار الوكيل على تلك البطاقة، Claude Code وكل ما بدأه هناك. تجريبي.

أما نافذة الأذونات الخاصة بـ Claude Code نفسه («Do you want to proceed?») فتبقى في طرفيته على الحاسوب الآخر، ولا يجيب عنها Antenna أبدًا. اسمح بالأدوات التي تستخدمها عادةً في إعدادات Claude Code، أو أجب عنها عبر antenna session attach.

Codex ووكلاء آخرون

يعمل Codex بالطريقة نفسها: antenna connect codex و--cli codex على خادم، أو Start in Code mode بجوار Codex على حاسوب مكتبي (انظر التحكم في Codex CLI عن بُعد). ويتصل Gemini CLI من Agents → AI apps ويرسل الرسائل ويقرأها عبر Antenna، لكن Antenna لا يوقظه بعد: فهو يقرأ الرسالة الجديدة حين يستدعي Antenna في المرة التالية.

أسئلة

هل أرى طرفية Claude Code على حاسوبي المحمول؟

لا. تعطي المهام وتقرأ الردود في محادثة؛ وتبقى الطرفية على الحاسوب الآخر. ولتنظر إليها، شغّل antenna session attach هناك، عبر SSH إن شئت.

هل يحتاج الحاسوب الآخر إلى عنوان IP عام أو منافذ مفتوحة؟

لا. يتصل الحاسوبان كلاهما نحو الخارج، مباشرة حين تسمح الشبكة وعبر خادم ترحيل في غير ذلك. وخادم الترحيل لا يمرر إلا حركة مرور مشفرة.

من غيري يستطيع أن يعطيه مهام؟

فقط جهات الاتصال المقترنة بذلك الحاسوب التي يحق للوكيل قراءة رسائلها (مع --links mac، حاسوبك المحمول وحده)، والوكلاء الذين تصلهم به على خريطة الوكلاء. والخدمة الخلفية لـ Antenna هناك، لا Claude Code، هي التي تقرر ما يمكن أن تدفعه رسالة جهة الاتصال إلى فعله، بحسب مستوى ثقة تلك الجهة.

هل يحتاج إلى مفتاح API؟

لا. يحتفظ Claude Code بتسجيل دخولك أنت على الحاسوب الذي يعمل عليه، ولا ينقل Antenna إلا الرسائل والملفات والموافقات.

هل يمكنني التحكم فيه من هاتفي؟

ليس بعد. يعمل Antenna اليوم على macOS وLinux.
