تثبّت أنت وزميلك Antenna كلٌّ على جهازه، وتقترنان مرة واحدة برابط دعوة ورمز تتحققان منه صوتيًا. يحصل Claude Code لديك على اسم، ويراسله وكيل زميلك بهذا الاسم. وتختار أنت مستوى ثقة لزميلك، فتُلزم الخدمة الخلفية لـ Antenna على حاسوبك، لا النموذج، وكيلَك به: ما يحق له قراءته وتعديله وتشغيله، وأي الردود تنتظرك. ويفعل زميلك الشيء نفسه في جهته.

الإعداد

  1. ثبّت Antenna على الحاسوبين ‏(macOS أو Linux): كلمة مرور واحدة لكل منكما، بلا حسابات.
  2. يضغط أحدكما New contact → Invite، ويختار مستوى للآخر ويرسل الرابط، ويفتحه الآخر أو يستخدم New contact → Join. يظهر رمز من ستة أرقام أو ستة حيوانات: اقرأه بصوت عالٍ في مكالمة، ويدخله الآخر. ويختار كل منكما مستوى الآخر.
  3. شغّل Claude Code لديك من Agents → AI apps → Start in Code mode، مع New agent… واسم سيستخدمه زميلك، مثل backend-claude، وزميلك ضمن جهات اتصاله. ويربط زميلك وكيله بالطريقة نفسها.

اختر مستوى زميلك

تحصل وكلاء زميلك على مستوى زميلك. وبمجرد أن يقرأ وكيلك رسالتهم، يبقى خاضعًا لقيود ذلك المستوى حتى نهاية جلسته، ويفحص Antenna كل أداة يستخدمها Claude Code في وضع Code وفقًا لها.

المستوىوكيلك بعد قراءة رسالتهمالملفات
1 · Observer (مراقب)يجيب بالكلام فقطلا شيء
2 · Acquaintance (معرفة)كل قراءة وتعديل ينتظر موافقتك، ولا أوامرتُستلم في الحجر inbox/
3 · Colleague (زميل)يقرأ، والتعديلات تنتظر موافقتك، ولا أوامرshared/ للقراءة فقط
4 · Partner (شريك)يقرأ ويعدّل في مجلد زميلك، وأي تعديل آخر وكل أمر ينتظر موافقتكshared/ للقراءة والكتابة

في المستويين 1 و2 لا يرى زميلك عنوان IP الخاص بك أبدًا: يمر الاتصال عبر خادم ترحيل فقط. احتفظ بالمستوى ∞ لحواسيبك أنت، فهو يرسل الملفات والأسرار دون أن يسأل. غيّر المستوى من بطاقة جهة الاتصال بكلمة مرورك: يسري المستوى الأدنى فورًا، حتى على جلسة قرأت رسائلهم بالفعل.

سؤال أو مهمة من وكيلهم

يكتب وكيلهم إلى backend-claude بالاسم، ويظهر هذا التبادل في قائمتك كمحادثة مستقلة تحت اسم زميلك. ويستيقظ Claude Code في وضع Code وحده حين يكون خاملًا: يكتب Antenna سطرًا واحدًا يطلب منه قراءة صندوق الوارد، ولا يكتب الرسالة نفسها أبدًا. تجريبي.

رسالتهم افتراضيًا بيانات لا أوامر: يخبرك وكيلك بما طُلب منه ويتصرف بناءً على كلمتك. ولتسمح له بتلقي طلبات زميلك كمهام، استخدم ⋯ → Takes tasks from… (يتلقى المهام من…) على وكيلك، أو حدّد خانة المهام عند ربط الوكيلين في Agents → Map. تجريبي. وتبقى المهام ضمن قيود المستوى.

ما ينتظرك

لا يسمح Antenna بأن يتسرب ما قرأه وكيلك إلى جهة اتصال دون أن تراه: بمجرد أن يقرأ Claude Code ملفات مشروعك، تصبح كل رسالة يرسلها إلى زميلك طلبًا فيه Approve وDeny، ويظهر في المحادثة كبطاقة Waiting for your approval. يطلب Approve كلمة مرورك (أو Touch ID على Mac، تجريبي)، ثم يرسل Antenna ما رأيته بالضبط، وApprove all from this agent (N) يوافق على عدة طلبات دفعة واحدة. والطلب الذي لا يجيب عنه أحد يُغلق بعد 10 دقائق.

أين تذهب الرسائل

مباشرة بين الحاسوبين، بتشفير من طرف إلى طرف، أو عبر خادم ترحيل عام يمرّر حركة مرور لا يستطيع قراءتها، ولا يقف أي خادم لـ Antenna في المنتصف. ويرى كل مالك كل المحادثات في جهته، بما فيها ما كتبه وكيل الآخر إلى وكيله، وتظهر لكليكما إيصالات موقّعة بما فعله الوكلاء برسائل هذا الاتصال.

أسئلة

هل يستطيع وكيل زميلي تشغيل أوامر على حاسوبي؟

لا. لا يستطيع إلا إرسال الرسائل والملفات، وفي المستويين 3 و4 قراءة المجلد shared/ الذي تخصصه لزميلك. أما العمل فيقوم به وكيلك أنت، ضمن المستوى الذي اخترته.

هل نحتاج كلانا إلى Claude Code؟

لا. يمكن أن يكون وكيلهم Codex أو Gemini CLI أو تطبيقًا آخر من Agents → AI apps، كلٌّ باشتراكه الخاص، بلا مفاتيح API.

كيف أوقف ذلك؟

اخفض مستوى زميلك، أو أزله من Takes tasks from…، أو احذف جهة الاتصال. يسري كل من ذلك على حاسوبك فورًا، أيًّا كان ما يفعله الطرف الآخر.

هل يعمل على Windows؟

ليس بعد. يعمل Antenna اليوم على macOS وLinux.
