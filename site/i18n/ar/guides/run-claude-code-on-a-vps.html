ثبّت Claude Code وعقدة Antenna على خادم Linux VPS الخاص بك، واقرن الخادم بحاسوبك المحمول مرة واحدة، وشغّل Claude Code عبر Antenna في مجلد مشروعك. بعدها يعمل في جلسة tmux خاصة به بعد تسجيل خروجك، ويستيقظ عند وصول رسالة موجهة إليه، ويجيب في محادثة على حاسوبك المحمول. لا منفذ وارد يلزم فتحه، ولا جلسة SSH يلزم إبقاؤها حية، ويعمل Codex بالطريقة نفسها.

ما تحتاجه

  • خادم Linux بمعمارية x86_64، مثبّت عليه Claude Code (أو Codex) مع تسجيل الدخول، وtmux.
  • Antenna على حاسوبك المحمول: macOS أو Linux.

1. ثبّت عقدة Antenna على الخادم

curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER

يقرأ المثبّت أحدث إصدار من البيان الموقّع (manifest)، ويتحقق من الأرشيف، ويثبّت antennad وantenna في ~/.local/bin كخدمة systemd على مستوى المستخدم (دون الحاجة إلى root)، وينشئ عقدتك بكلمة مرور. أما السطر الثاني فيُبقي الخدمة تعمل بعد تسجيل خروجك. وعلى Ubuntu أو Fedora يمكنك تثبيت حزمة .deb أو .rpm بدلًا من ذلك.

2. اقرنه بحاسوبك المحمول

على حاسوبك المحمول: New contact → Invite، وسمّه، وحدّد This is my own computer (∞)، واضغط Create link وانسخه. وعلى الخادم:

antenna join '<link>' --trust 5 --label mac

أبقِ علامتي الاقتباس المفردتين: فالرابط يحتوي على #. اكتب الرمز الذي يعرضه حاسوبك المحمول في طرفية الخادم، ثم اضغط The contact confirmed — codes match على الحاسوب المحمول. المستوى 5 هو ∞ على الطرفين، فيُعدّ الخادم حاسوبك أنت.

3. شغّل Claude Code عبر Antenna

cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev

يمنح سطر connect الجلسةَ وكيلها ورمز وصولها الخاصين، ويلقي التحية فتظهر محادثة باسم api-dev على حاسوبك المحمول. ويشغّل سطر start ‏Claude Code في خادم tmux الخاص بـ Antenna (ولا يُمَس tmux الخاص بك). اتصل بالجلسة مرة واحدة لتجيب عن أسئلة Claude Code الأولى، مثل هل يثق بالمجلد، ثم اخرج بـ Ctrl-b d: فيواصل العمل. ومع Codex، استخدم antenna connect codex و--cli codex.

4. تحدّث إليه

اكتب في محادثة api-dev على حاسوبك المحمول: «شغّل اختبارات الترحيل (migration) وأصلح ما يفشل». حين يكون Claude Code خاملًا أمام موجّهه، يكتب Antenna سطرًا قصيرًا واحدًا كي يقرأ رسالتك؛ ولا يكتب أبدًا نص جهة اتصال، ولا يجيب أبدًا عن سؤال نيابة عنه. تعرض بطاقة الخادم في My devices حالته ووكلاءه، ويمكنك الموافقة على طلباته من الحاسوب المحمول.

بعد إعادة التشغيل

تُقفل مفاتيح العقدة بعد إعادة تشغيل الخادم: تعمل الخدمة، لكن اتصالاتها تبقى صامتة حتى تسجّل الدخول وتشغّل antenna unlock. وبهذا لا تمنح نسخةٌ من قرص الخادم أحدًا مفاتيحك. ويخبرك antenna status هل العقدة مقفلة.

أسئلة

لماذا لا أكتفي بـ SSH وtmux؟

هذا يعمل ما دمت جالسًا أمام طرفية. يضيف Antenna محادثة يمكنك الكتابة فيها من حاسوبك المحمول في أي وقت، ويوقظ الجلسة حين تفعل، ويتيح لوكلاء آخرين إسناد العمل إليها، بصلاحيات يتحقق منها بنفسه.

هل يحتاج الخادم إلى عنوان IP عام أو منافذ مفتوحة؟

لا. يتصل الطرفان نحو الخارج، مباشرة حين تسمح الشبكة وعبر خادم ترحيل (relay) في غير ذلك. وخادم الترحيل لا يمرر إلا حركة مرور مشفرة.

هل يمكنني تشغيل عدة جلسات على خادم واحد؟

نعم: وكيل لكل مجلد مشروع، لكل منها اسمها ومحادثتها الخاصة على حاسوبك المحمول.

هل توجد نسخة لمعالجات ARM؟

ليس بعد. عقدة الخادم مبنية لـ Linux على x86_64.
