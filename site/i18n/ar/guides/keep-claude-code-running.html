لا يمكن ذلك على الحاسوب المحمول نفسه: فإغلاق الغطاء يُدخل الحاسوب المحمول في وضع السكون، والحاسوب النائم لا يشغّل شيئًا، فيتوقف Claude Code مؤقتًا معه. والحل أن تشغّل Claude Code على حاسوب يبقى قيد التشغيل، مثل خادم Linux أو جهاز Mac mini مضبوط كي لا ينام، وأن تبدأه هناك عبر Antenna، وتعطيه المهام من محادثة Antenna على حاسوبك المحمول. أغلق الحاسوب المحمول: يواصل Claude Code العمل على الحاسوب الآخر، وتنتظر ردوده حاسوبك المحمول وتصل حين يعود إلى الاتصال.

لماذا يتوقف

يعمل Claude Code على الحاسوب الذي تبدأه عليه. وحين ينام ذلك الحاسوب، يتوقف كل برنامج عليه، ومنها Claude Code، حتى يستيقظ. وإغلاق الطرفية أو نافذة SSH التي يعمل فيها يُنهيه أيضًا. يمكن إبقاء الحاسوب المحمول مستيقظًا والغطاء مغلق، لكنه عندئذ يجب أن يبقى موصولًا بالكهرباء وقيد التشغيل، أي أنه صار خادمًا. لذلك ينتقل العمل إلى حاسوب يعمل دائمًا، ولا يفعل الحاسوب المحمول سوى التحدث إليه.

ما تحتاجه

  • حاسوب يبقى قيد التشغيل: خادم Linux بمعمارية x86_64 (خادم VPS أو خادم في المنزل)، أو جهاز Mac أو حاسوب مكتبي بنظام Linux مضبوط كي لا ينام.
  • Claude Code مثبّت عليه مع تسجيل الدخول.
  • Antenna على الحاسوبين: التطبيق على حاسوبك المحمول (macOS أو Linux)، والعقدة أو التطبيق على الآخر.

على خادم

  1. ثبّت عقدة Antenna واتركها تعمل بعد تسجيل خروجك: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
    يُعدّ المثبّت Antenna كخدمة systemd على مستوى المستخدم، وينشئ عقدتك بكلمة مرور. ولا يفعّل خاصية lingering، بل يذكّرك بها فقط: فبدون السطر الثاني تتوقف الخدمة حين تسجّل خروجك.
  2. اقرن الخادم بحاسوبك المحمول مرة واحدة. على الحاسوب المحمول: New contact → Invite (جهة اتصال جديدة ← دعوة)، وحدّد This is my own computer (∞) (هذا حاسوبي أنا)، واضغط Create link (إنشاء رابط) وانسخه. وعلى الخادم: antenna join '<link>' --trust 5 --label mac، واكتب الرمز الذي يعرضه الحاسوب المحمول، ثم اضغط The contact confirmed — codes match على الحاسوب المحمول.
  3. شغّل Claude Code عبر Antenna في مجلد المشروع (يحتاج الخادم إلى tmux): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    أجب عن أسئلة Claude Code الأولى، مثل هل يثق بالمجلد، ثم اخرج بـ Ctrl-b d. صارت على حاسوبك المحمول الآن محادثة باسم api-dev.
  4. دع الحاسوب المحمول يجيب عن طلبات الموافقة الآتية من الخادم: antenna devices confirm mac.

سجّل الآن خروجك من SSH. تواصل الخدمة العمل، ويواصل Claude Code العمل في خادم tmux الخاص بـ Antenna؛ ولا يُمَس tmux الخاص بك. وتجد كل خطوة بتفصيل أكثر في Claude Code على VPS.

على جهاز Mac أو حاسوب مكتبي يبقى قيد التشغيل

  1. اضبط الحاسوب كي لا ينام من تلقاء نفسه، من إعدادات النظام فيه. فـ Antenna لا يُبقي الحاسوب مستيقظًا.
  2. اقرنه بحاسوبك المحمول كما سبق، مع تحديد This is my own computer (∞).
  3. افتح عليه Agents → AI apps (الوكلاء ← تطبيقات الذكاء الاصطناعي) واضغط Start in Code mode (البدء في وضع Code) بجوار Claude Code. اختر New agent… (وكيل جديد) وسمّه، واختر Working folder (مجلد العمل)، وأدخل كلمة مرورك واضغط Start (ابدأ). تنتقل النافذة إلى وضع Code، ويعمل Claude Code في تبويب داخلها.
  4. اطلب من Claude Code مرة واحدة، في تبويبه، أن يلقي التحية على حاسوبك المحمول عبر Antenna. فتظهر محادثته على الحاسوب المحمول.
  5. دع الحاسوب المحمول يجيب عن طلبات الموافقة الآتية منه: My devices (أجهزتي) → بطاقة الحاسوب المحمول → Approvals (الموافقات) → Accept approvals signed with …، بكلمة مرورك.

اترك نافذة Antenna مفتوحة: فإغلاقها يوقف الوكلاء الذين يعملون فيها، والنافذة تسألك قبل ذلك.

اتركه يعمل

اكتب المهمة في محادثة الوكيل على حاسوبك المحمول: «شغّل اختبارات الترحيل (migration)، وأصلح ما يفشل، وأخبرني هنا بما تغيّر». حين يكون Claude Code خاملًا أمام موجّهه، يكتب Antenna سطرًا ثابتًا واحدًا كي يقرأ رسالتك؛ وإن كان في منتصف دورة، تصله الرسالة حين تنتهي الدورة. ولا يكتب Antenna نصك في الطرفية أبدًا. تجريبي. ثم أغلق الحاسوب المحمول.

قبل مهمة طويلة، تحقّق مما قد يوقفها حين لا يكون أحد موجودًا:

  • نافذة الأذونات الخاصة بـ Claude Code نفسه («Do you want to proceed?») تنتظر في طرفيته حتى يجيب أحد، ولا يجيب عنها Antenna أبدًا. اسمح في إعدادات Claude Code بالأدوات التي تحتاجها المهمة.
  • طلبات الموافقة في Antenna تنتظر 10 دقائق. بعدها لا يُنفَّذ شيء، ويعرف Claude Code أن أحدًا لم يوافق. والمهمة التي تعطيها من حاسوبك أنت في المستوى ∞ تنفّذ أوامرها وتعديلاتها دون أن تسأل؛ أما التغييرات في إعدادات Claude Code نفسه، مثل CLAUDE.md أو .claude/، فما زالت تطلب الموافقة.

حين يستيقظ الحاسوب المحمول

بينما ينام الحاسوب المحمول، تنتظر ردود Claude Code في طابور الحاسوب الآخر، ويواصل Antenna محاولة تسليمها. وما إن يعود الحاسوب المحمول إلى الاتصال حتى تصل إلى المحادثة، مع إشعار إن لم تكن نافذة Antenna في المقدمة. والرسالة التي كتبتها وأنت غير متصل تظهر بجوارها ساعة، وتُرسَل من تلقاء نفسها. أما الطلبات التي ما زالت تنتظر موافقتك فتظهر على بطاقة الحاسوب الآخر في My devices ‏(تجريبي).

بعد إعادة تشغيل الحاسوب الآخر

تُقفل المفاتيح بعد إعادة التشغيل، فتبقى اتصالاته صامتة حتى تُدخل كلمة المرور. على خادم، سجّل الدخول وشغّل antenna unlock، ثم ابدأ الجلسة من جديد؛ ويتيح --resume مواصلة آخر جلسة لـ Claude Code:

antenna session start api-dev --dir ~/projects/api --resume

وعلى Mac، أدخل كلمة المرور في نافذة Antenna وابدأ الوكيل من جديد.

أسئلة

هل يبقى Claude Code يعمل إذا أغلقت حاسوبي المحمول؟

لا، إذا كان إغلاق الغطاء يُدخل الحاسوب المحمول في وضع السكون، وهو الإعداد المعتاد: يتوقف Claude Code مؤقتًا حتى تفتحه. شغّله على حاسوب يبقى قيد التشغيل، فيواصل العمل.

هل يمكن أن يعمل Claude Code في الخلفية على حاسوبي المحمول؟

ما دام الحاسوب المحمول مستيقظًا، نعم: في وضع Code يعمل في تبويب من نافذة Antenna لا حاجة إلى أن تنظر إليه، ويوقظه Antenna حين تصل رسالة. لكنه يتوقف مع ذلك حين ينام الحاسوب المحمول.

هل عليّ أن أُبقي جلسة SSH مفتوحة؟

لا. يعمل Claude Code في tmux الخاص بـ Antenna على الخادم، وتصل إليه عبر المحادثة. ويتصل الحاسوبان كلاهما نحو الخارج، فلا يُفتح أي منفذ وارد كذلك.

هل يُبقي Antenna جهاز Mac مستيقظًا؟

لا. اضبط Mac كي لا ينام من إعدادات النظام فيه. ويجب أن تبقى نافذة Antenna مفتوحة لوضع Code.

هل يمكنني متابعته من هاتفي؟

ليس بعد. يعمل Antenna اليوم على macOS وLinux.
