Cómo mantener Claude Code en marcha con el portátil cerrado

En el propio portátil no se puede: al cerrar la tapa, el portátil entra en reposo, una computadora en reposo no ejecuta nada y Claude Code se queda en pausa con ella. La solución es ejecutar Claude Code en una computadora que siga encendida, como un servidor Linux o un Mac mini configurado para no entrar en reposo, iniciarlo allí a través de Antenna y darle tareas desde el chat de Antenna de tu portátil. Cierra el portátil: Claude Code sigue trabajando en la otra computadora, y sus respuestas esperan al portátil y llegan cuando vuelve a estar en línea.

Por qué se detiene

Claude Code se ejecuta en la computadora donde lo inicias. Cuando esa computadora entra en reposo, todos sus programas se detienen, Claude Code incluido, hasta que despierta. Cerrar la terminal o la ventana de SSH donde se ejecuta también lo termina. Puedes mantener despierto un portátil con la tapa cerrada, pero entonces tiene que seguir enchufado y encendido, y ya se ha convertido en un servidor. Por eso el trabajo pasa a una computadora que siempre está encendida, y el portátil solo habla con ella.

Qué necesitas

  • Una computadora que siga encendida: un servidor Linux x86_64 (un VPS o uno en casa), o un Mac o un escritorio Linux configurado para no entrar en reposo.
  • Claude Code instalado en ella y con la sesión iniciada.
  • Antenna en las dos computadoras: la app en tu portátil (macOS o Linux) y el nodo o la app en la otra.

En un servidor

  1. Instala el nodo de Antenna y deja que siga en marcha cuando cierres la sesión: 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
    El instalador configura Antenna como servicio de usuario de systemd y crea tu nodo con una contraseña. No activa el lingering, solo te lo recuerda: sin la segunda línea, el servicio se detiene cuando cierras la sesión.
  2. Empareja el servidor con tu portátil una vez. En el portátil: Contacto nuevo → Invitar, marca Es mi propia computadora (∞), pulsa Crear enlace y cópialo. En el servidor: antenna join '<link>' --trust 5 --label mac, escribe el código que muestra el portátil y luego pulsa El contacto lo confirmó: los códigos coinciden en el portátil.
  3. Inicia Claude Code a través de Antenna en la carpeta del proyecto (el servidor necesita tmux): 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    Responde a las primeras preguntas de Claude Code, como si confía en la carpeta, y luego sal con Ctrl-b d. En tu portátil ya tienes un chat llamado api-dev.
  4. Deja que el portátil responda a las peticiones de aprobación del servidor: antenna devices confirm mac.

Ahora cierra la sesión de SSH. El servicio sigue en marcha, y Claude Code sigue ejecutándose en el servidor tmux propio de Antenna; tu tmux no se toca. En Claude Code en un VPS tienes cada paso con más detalle.

En un Mac o un escritorio siempre encendido

  1. Configura la computadora para que no entre en reposo por sí sola, en sus ajustes del sistema. Antenna no mantiene despierta una computadora.
  2. Emparéjala con tu portátil como arriba, con Es mi propia computadora (∞) marcado.
  3. En ella, abre Agentes → Apps de IA y pulsa Iniciar en modo Code junto a Claude Code. Elige Agente nuevo… y ponle un nombre, elige la Carpeta de trabajo, escribe tu contraseña y pulsa Iniciar. La ventana pasa al modo Code, y Claude Code se ejecuta en una pestaña dentro de ella.
  4. Pídele una vez a Claude Code, en su pestaña, que salude a tu portátil a través de Antenna. Entonces su chat aparece en el portátil.
  5. Deja que el portátil responda a sus peticiones de aprobación: Mis dispositivos → la ficha del portátil → Aprobaciones → Aceptar aprobaciones firmadas con …, con tu contraseña.

Deja abierta la ventana de Antenna: cerrarla detiene los agentes que se ejecutan en ella, y la ventana te pregunta antes.

Déjalo trabajando

Escribe la tarea en el chat del agente en tu portátil: «Ejecuta las pruebas de la migración, arregla lo que falle y responde aquí con lo que cambiaste». Cuando Claude Code está inactivo en su prompt, Antenna escribe una línea fija para que lea tu mensaje; si está a mitad de un turno, recibe el mensaje cuando el turno termina. Antenna nunca escribe tu texto en la terminal. Experimental. Luego cierra el portátil.

Antes de una tarea larga, revisa qué podría detenerla mientras no hay nadie:

  • El aviso de permisos propio de Claude Code («Do you want to proceed?») espera en su terminal hasta que alguien responde, y Antenna nunca lo responde. Permite en la configuración de Claude Code las herramientas que necesita la tarea.
  • Las peticiones de aprobación de Antenna esperan 10 minutos. Después no se ejecuta nada, y Claude Code se entera de que nadie aprobó. Una tarea que das desde tu propia computadora en ∞ ejecuta sus comandos y ediciones sin preguntar; los cambios en la configuración propia de Claude Code, como CLAUDE.md o .claude/, siguen pidiendo aprobación.

Cuando el portátil despierta

Mientras el portátil duerme, las respuestas de Claude Code esperan en la cola de la otra computadora, y Antenna sigue intentando entregarlas. En cuanto el portátil vuelve a estar en línea, llegan al chat, con una notificación si la ventana de Antenna no está en primer plano. Un mensaje que escribiste sin conexión muestra un reloj y se envía solo. Las peticiones que aún esperan tu aprobación aparecen en la ficha de la otra computadora en Mis dispositivos (experimental).

Si la otra computadora se reinicia

Tras un reinicio las claves quedan bloqueadas, así que sus enlaces se quedan en silencio hasta que escribes la contraseña. En un servidor, inicia sesión, ejecuta antenna unlock y vuelve a iniciar la sesión de Claude Code; --resume continúa la última sesión de Claude Code:

antenna session start api-dev --dir ~/projects/api --resume

En un Mac, escribe la contraseña en la ventana de Antenna y vuelve a iniciar el agente.

Preguntas

¿Claude Code sigue funcionando si cierro el portátil?

No, si al cerrar la tapa el portátil entra en reposo, que es lo habitual: Claude Code se queda en pausa hasta que lo abres. Ejecútalo en una computadora que siga encendida y seguirá trabajando.

¿Puede Claude Code ejecutarse en segundo plano en mi portátil?

Mientras el portátil está despierto, sí: en modo Code se ejecuta en una pestaña de la ventana de Antenna que no necesitas mirar, y Antenna lo despierta cuando llega un mensaje. Aun así, se detiene cuando el portátil entra en reposo.

¿Tengo que mantener abierta una sesión de SSH?

No. Claude Code se ejecuta en el tmux de Antenna en el servidor, y llegas a él a través del chat. Las dos computadoras se conectan hacia fuera, así que tampoco se abre ningún puerto de entrada.

¿Antenna mantiene despierto mi Mac?

No. Configura el Mac para que no entre en reposo en sus ajustes del sistema. Para el modo Code, la ventana de Antenna tiene que seguir abierta.

¿Puedo revisarlo desde el móvil?

Todavía no. Por ahora Antenna funciona en macOS y Linux.

Antenna es gratis y de código abierto, para macOS y Linux. Sin cuenta y sin número de teléfono.
