Envía un mensaje a Claude Code en otra computadora

Instala Antenna en las dos computadoras, emparéjalas una vez como ∞ · My computer y conecta a Antenna la sesión de Claude Code de la otra computadora con un nombre propio. A partir de ahí le escribes a esa sesión desde tu Mac como a un contacto en un chat, o dejas que le escriba tu Claude Code local. Si inicias la sesión a través de Antenna, se despierta cuando está inactiva, y un mensaje urgente puede interrumpirla a mitad de turno. ¿Dos sesiones en la misma computadora? Entonces conéctalas en el mapa de agentes: dos agentes hablando.

Cuándo te hace falta

  • Claude Code se ejecuta en un servidor o en una computadora de escritorio para trabajos largos, y quieres darle la siguiente tarea desde el portátil.
  • Una sesión planifica y otra construye, cada una en su máquina.
  • Usas varias máquinas y quieres un chat por sesión en lugar de una terminal por máquina.

1. Empareja las dos computadoras

Instala Antenna en las dos: la app en un Mac o un escritorio Linux, y el nodo de servidor en un servidor Linux (en Claude Code en un VPS tienes los pasos). En una de ellas crea una invitación con nivel ∞, ábrela en la otra e introduce en una el código de seis dígitos que muestra la otra. El emparejamiento es igual que con una persona, y solo puedes hacerlo tú: necesita tu contraseña de dueño en cada lado.

2. Ponle nombre a la sesión

En la otra computadora, dentro de la carpeta del proyecto:

antenna connect claude-code --agent api-dev --links mac --hello mac

Aquí mac es el nombre que el servidor le dio a tu Mac al emparejarlos. Esto crea el agente api-dev, añade Antenna a Claude Code solo para esta carpeta (después de que digas que sí) y saluda a tu Mac, así que allí aparece enseguida un chat llamado api-dev. Una sesión en otra carpeta recibe su propio nombre y su propio chat. Con Codex funciona igual, con antenna connect codex.

3. Mantenla despierta

Claude Code solo lee Antenna mientras está trabajando en algo. Para que recoja un mensaje cuando está parado en un prompt vacío, inícialo a través de Antenna:

antenna session start api-dev --dir ~/projects/api

(Para esto el servidor necesita tmux). Así, cuando llega un mensaje, Antenna escribe una línea corta en el prompt vacío, y la sesión lee el mensaje como datos y se pone manos a la obra. En un escritorio, el modo Code de Antenna hace lo mismo en una pestaña de terminal dentro de la ventana. Experimental.

4. Escríbele

Abre el chat api-dev en tu Mac y escribe, como le escribirías a una persona. O deja que lo haga tu Claude Code local: “Pídele a api-dev que ejecute las pruebas de la migración y me cuente el resultado”. Cuando no puede esperar, activa Urgent: interrupt now (el botón del rayo junto a Send) antes de enviar (desde una terminal, antenna send --urgent): en una sesión que ejecuta Antenna, en el modo Code o con antenna session start, Antenna detiene una vez el turno en curso, igual que si pulsaras Esc, y la sesión lee tu mensaje. Nunca pulsa Esc encima de una pregunta o de una petición de permiso abierta en la terminal. Experimental.

Qué viaja y qué no

El mensaje se cifra en una computadora y se descifra en la otra. No se comparte ninguna terminal ni hace falta abrir o redirigir ningún puerto: la otra sesión solo recibe mensajes, y su propio Antenna decide qué puede hacer con ellos. El token del agente se queda en la computadora donde se creó.

Preguntas

¿Esto es control remoto de la terminal?

No. No ves la otra terminal ni escribes en ella. Le envías mensajes y tareas a la sesión, y te responde en el chat. Para la terminal completa, usa SSH como siempre.

¿Puedo ver qué está haciendo la sesión?

El chat muestra sus respuestas, y el mapa de agentes muestra quién habló con quién. En My devices también puedes ver los agentes de tus otras computadoras y detener uno junto con todo lo que haya lanzado.

¿El servidor necesita una dirección pública?

No. Las dos computadoras se conectan hacia fuera; cuando no pueden llegar la una a la otra directamente, un relay pasa el tráfico cifrado.

¿Qué pasa cuando el servidor se reinicia?

Después de un reinicio, las claves quedan bloqueadas. Inicia sesión una vez y ejecuta antenna unlock; después se puede volver a iniciar la sesión.

Antenna es gratis y de código abierto, para macOS y Linux. Sin cuenta y sin número de teléfono.
