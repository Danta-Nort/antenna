Usa Gemini CLI y Claude Code juntos

Conecta Gemini CLI a Antenna con un clic, inicia Claude Code en la ventana de Antenna y traza una línea entre los dos en el mapa de agentes de Antenna. A partir de ahí, cada uno le escribe al otro con las herramientas MCP de Antenna: Gemini CLI le pide a Claude Code que revise un cambio, Claude Code le pasa una tarea a Gemini CLI, y la respuesta vuelve por el mismo camino. Los dos siguen usando tus propias sesiones de Google y de Claude, sin claves de API.

En una misma computadora

  1. Instala Antenna (macOS o Linux) y crea tu nodo: una contraseña, sin cuenta.
  2. Abre Agents → AI apps y pulsa Connect junto a Gemini CLI. Elige Assistant with access to my projects (asistente con acceso a mis proyectos), escribe tu contraseña, pulsa Continue, lee lo que Antenna va a añadir a ~/.gemini/settings.json y pulsa Write and connect (escribir y conectar). En Gemini CLI, ejecuta /mcp reload (o vuelve a iniciarlo): /mcp muestra antenna. La fila dice “Contacts write to it as gemini-cli”: los contactos le escriben como gemini-cli.
  3. En la misma página, pulsa Start in Code mode junto a Claude Code. Elige New agent…, llámalo builder, elige el mismo rol, Assistant with access to my projects, escribe tu contraseña y pulsa Start. Claude Code se ejecuta en una pestaña de terminal dentro de la ventana.
  4. Abre Agents → Map, arrastra desde el punto de conexión de un agente hasta el otro, escribe tu contraseña y pulsa Connect. Los dos reciben una ruta local: sus mensajes nunca salen de la computadora, y cada uno acepta los mensajes del otro como tareas, salvo que desmarques la casilla.

Dales a los dos el mismo rol: Antenna no deja que un agente que ha visto más datos tuyos le escriba a uno que ha visto menos.

Cómo se dirigen el uno al otro

Con la línea trazada, cada agente es el interlocutor predeterminado del otro: basta con “envíale esto a tu interlocutor”. Para nombrar al otro, un agente llama a send_message con local_agent igual a gemini-cli o builder. El que recibe lee con read_inbox, o espera con wait_for_message hasta 10 minutos por llamada.

Los dos esperan de forma distinta. Claude Code en modo Code se despierta solo: cuando llega un mensaje y está inactivo, Antenna escribe una línea que le dice que lea su bandeja de entrada. Experimental. Antenna todavía no despierta a Gemini CLI, así que Gemini CLI lee sus mensajes la próxima vez que llama a Antenna. Por eso lo natural es que sea Gemini CLI quien empiece el intercambio: “Pídele a builder que revise el diff de src/, espera su respuesta y corrige lo que encuentre”. Claude Code se despierta, revisa y responde. Para pasarle trabajo a Gemini CLI, primero dile que espere mensajes.

En dos computadoras

Gemini CLI puede quedarse en una computadora y Claude Code en otra. Instala Antenna en cada una y emparéjalas una vez con un enlace de invitación y un código de seis dígitos, marcando This is my own computer (∞). Luego traza la línea entre los dos agentes en el mapa. La otra computadora te pide que apruebes su lado, allí mismo o en My devices, así que allí no cambia nada sin ti. En un servidor sin pantalla, Claude Code se ejecuta con antenna connect claude-code y antenna session start: consulta Claude Code en un VPS.

Qué apruebas tú y qué sigue limitado

  • Las conexiones son cosa tuya. Trazar una línea pide tu contraseña; ningún agente puede crear ni cambiar una.
  • Antenna revisa cada mensaje. Entre dos agentes de la misma computadora, se rechaza cualquier mensaje que parezca contener una clave, una contraseña o un token, y una cadena se detiene después de 8 mensajes en 10 minutos, así que los dos no pueden tenerse ocupados para siempre.
  • Los niveles de confianza siguen a lo que ha leído cada agente. En una misma computadora, si un agente ha leído un mensaje de un contacto, su mensaje le lleva los límites de ese contacto al otro agente, que queda limitado como si también lo hubiera leído.
  • Claude Code pasa un control antes de cada herramienta. En modo Code, Antenna consulta a su daemon antes de cada comando y cada edición. Las herramientas propias de Gemini CLI siguen sujetas a las confirmaciones de Gemini CLI; Antenna revisa lo que pasa por él.

Preguntas

¿Hace falta una clave de API de Gemini?

No. Gemini CLI inicia sesión con tu cuenta de Google y Claude Code con tu plan de Claude, como siempre. Antenna solo lleva los mensajes.

¿Pueden usar Antenna dos ventanas de Gemini CLI a la vez?

De una en una: un agente trabaja en una sola sesión a la vez, y Connect le da a Gemini CLI un solo agente.

¿Está terminado?

Conectar agentes en el mapa y despertar a los agentes inactivos están marcados como experimentales en Antenna 0.1: funcionan y tienen pruebas, pero todavía pueden cambiar.

Antenna es gratis y de código abierto, para macOS y Linux. Sin cuenta y sin número de teléfono.
