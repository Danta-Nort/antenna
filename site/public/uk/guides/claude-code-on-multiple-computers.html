Як працювати з Claude Code на кількох комп’ютерах з одного місця

Нехай Claude Code працює там, де робота: на ноутбуці, стаціонарному комп’ютері й сервері, — а на кожен із них встановіть Antenna. Один раз з’єднайте комп’ютери як власні (∞). Після цього з будь-якого з них ви бачите всі сесії в одному списку чатів, пишете будь-якій на ім’я, відповідаєте на її запити на схвалення й зупиняєте сесію, яка вийшла з-під контролю, — не відкриваючи термінал на тій машині. Codex працює так само.

Що ви отримуєте

  • Окремий чат для кожної сесії, хоч би на якому комп’ютері вона працювала. Сесія на сервері й сесія на стаціонарному комп’ютері — в одному списку з вашими контактами.
  • Мої пристрої: картка для кожного вашого комп’ютера з його системою й версією Antenna, станом за його власними перевірками, агентами й тим, чи підключений кожен із них, а також запитами, які там на вас чекають.
  • Схвалення звідти, де ви є. Запит від агента на сервері можна схвалити на Mac — через Touch ID або пароль Mac. Сервер перевіряє підпис і виконує запит сам.
  • Кнопка зупинки для кожного агента на іншому комп’ютері: вона зупиняє агента й усі процеси, які він там запустив.
  • Мапа агентів, де ви з’єднуєте сесію на одному комп’ютері із сесією на іншому, щоб вони писали одна одній.

Налаштування

  1. Встановіть Antenna на кожен комп’ютер: застосунок — на Mac чи Linux-десктоп, вузол — на Linux-сервер (curl -fsSL https://antenna.contact/install.sh | sh).
  2. З’єднайте комп’ютери між собою як власні. Створіть запрошення з позначкою Це мій власний комп’ютер (∞), відкрийте його на іншому комп’ютері й введіть код, який показує одна сторона, на іншій. З’єднайте кожен комп’ютер з усіма іншими, які хочете з нього бачити чи підключати: кожен має мати інший на рівні ∞.
  3. Дайте кожній сесії Claude Code ім’я. На десктопі запустіть її в режимі Code через + на панелі агентів. На сервері в теці проєкту виконайте antenna connect claude-code --agent api-dev --links mac --hello mac і тримайте сесію запущеною за допомогою antenna session start api-dev --dir ~/projects/api; усі кроки — в інструкції Claude Code на VPS.
  4. Дозвольте основному комп’ютеру відповідати на запити. На сервері один раз виконайте antenna devices confirm mac; на десктопі прийміть ключ основного комп’ютера у розділі Мої пристрої → його картка → Схвалення.

Як передавати роботу між комп’ютерами

Пишіть сесії так, як писали б людині: «api-dev, запусти міграції на сервері й розкажи, що змінилося». Файли, які ви перетягуєте в її чат, зберігаються на тому комп’ютері, і агент дізнається, де вони; між вашими власними комп’ютерами звичайні файли зберігаються без запитань, а програми й інсталятори все одно чекають на вас. Щоб сесія на десктопі могла передавати роботу сесії на сервері, з’єднайте їх на мапі агентів. Сесія там прокидається, щойно приходить повідомлення, а термінове повідомлення може перервати її поточний хід. Експериментальна функція.

Запитання

Чи синхронізує Antenna налаштування чи історію Claude Code між комп’ютерами?

Ні. Claude Code зберігає налаштування, історію й вхід на кожному комп’ютері окремо, а ваш код переміщується як і раніше — через git. Antenna передає між сесіями повідомлення, файли й схвалення.

Чи потрібні на сервері публічна IP-адреса чи відкриті порти?

Ні. Кожен комп’ютер підключається назовні — напряму, якщо дозволяє мережа, а інакше через ретранслятор, який пересилає лише зашифрований трафік.

Чи можна звідси змінити налаштування на іншому комп’ютері?

Ні. Між вашими комп’ютерами передаються лише схвалення, зупинки й запити на з’єднання з мапи агентів, які той комп’ютер попросить вас схвалити. Довіра, запрошення, оновлення й налаштування змінюються на самому комп’ютері, тож украдений ноутбук не зможе переписати правила сервера.

Чи працює це на Windows чи телефоні?

Поки що ні. Зараз Antenna працює на macOS і Linux.

Antenna безкоштовна й має відкритий код, працює на macOS і Linux. Без акаунта й без номера телефону.
