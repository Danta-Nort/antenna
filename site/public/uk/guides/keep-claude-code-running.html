Хай Claude Code працює, поки ноутбук закритий

На самому ноутбуці так не вийде: якщо закрити кришку, ноутбук засинає, сплячий комп’ютер нічого не виконує, і Claude Code стає на паузу разом із ним. Вихід — запустити Claude Code на комп’ютері, який завжди ввімкнений, наприклад на Linux-сервері чи на Mac mini, якому заборонено засинати, зробити це через Antenna й давати йому завдання з чату Antenna на ноутбуці. Закрийте ноутбук: Claude Code працюватиме далі на іншому комп’ютері, а його відповіді дочекаються ноутбука й прийдуть, щойно той знову буде в мережі.

Чому він зупиняється

Claude Code працює на тому комп’ютері, де ви його запустили. Коли цей комп’ютер засинає, зупиняються всі програми на ньому, зокрема Claude Code, аж до пробудження. Якщо закрити термінал чи вікно SSH, у якому він працює, він теж завершиться. Можна зробити так, щоб ноутбук не засинав і з закритою кришкою, але тоді він має весь час бути ввімкненим і під’єднаним до живлення — тобто він уже став сервером. Тож робота переїжджає на комп’ютер, який завжди ввімкнений, а ноутбук лише з ним листується.

Що потрібно

  • Комп’ютер, який завжди ввімкнений: Linux-сервер на x86_64 (VPS чи домашній) або десктоп на macOS чи Linux, якому заборонено засинати.
  • Claude Code, встановлений на ньому, у який виконано вхід.
  • Antenna на обох комп’ютерах: застосунок на ноутбуці (macOS чи Linux), вузол або застосунок на іншому.

На сервері

  1. Встановіть вузол Antenna й дайте йому працювати після виходу з системи: 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
    Інсталятор налаштовує Antenna як користувацьку службу systemd і створює ваш вузол із паролем. Lingering він не вмикає, а лише нагадує про нього: без другого рядка служба зупиниться, щойно ви вийдете з системи.
  2. Один раз з’єднайте сервер із ноутбуком. На ноутбуці: Новий контакт → Запросити, поставте позначку Це мій власний комп’ютер (∞), натисніть Створити посилання і скопіюйте посилання. На сервері: antenna join '<link>' --trust 5 --label mac, введіть код, який показує ноутбук, а потім натисніть на ноутбуці Контакт підтвердив — коди збігаються.
  3. Запустіть Claude Code через Antenna в теці проєкту (на сервері потрібен tmux): 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    Дайте відповідь на перші запитання Claude Code — наприклад, чи довіряє він цій теці, — і вийдіть через Ctrl-b d. Тепер на ноутбуці є чат api-dev.
  4. Дозвольте ноутбуку відповідати на запити сервера на схвалення: antenna devices confirm mac.

Тепер можна вийти з SSH. Служба працює далі, а Claude Code — у власному tmux-сервері Antenna; ваш tmux не зачіпається. У посібнику Claude Code на VPS кожен крок описано докладніше.

На Mac чи десктопі, який завжди ввімкнений

  1. У системних налаштуваннях забороніть комп’ютеру засинати самостійно. Antenna не тримає комп’ютер увімкненим.
  2. З’єднайте його з ноутбуком, як описано вище, з позначкою Це мій власний комп’ютер (∞).
  3. На ньому відкрийте Агенти → ШІ-застосунки і натисніть Запустити в режимі Code поруч із Claude Code. Виберіть Новий агент… і дайте йому назву, вкажіть теку в полі Робоча тека, введіть пароль і натисніть Запустити. Вікно перемкнеться в режим Code, і Claude Code працюватиме у вкладці всередині нього.
  4. Один раз попросіть Claude Code в його вкладці привітатися з вашим ноутбуком через Antenna. Після цього його чат з’явиться на ноутбуці.
  5. Дозвольте ноутбуку відповідати на його запити на схвалення: Мої пристрої → картка ноутбука → Схвалення → Приймати схвалення, підписані за допомогою …, з вашим паролем.

Не закривайте вікно Antenna: якщо його закрити, зупиняться агенти, що в ньому працюють, і вікно спершу про це спитає.

Залиште його працювати

Напишіть завдання в чат агента на ноутбуці: «Запусти тести міграцій, виправ те, що падає, і напиши сюди, що змінилося». Коли Claude Code простоює на своєму запрошенні командного рядка, Antenna друкує один вбудований рядок, щоб він прочитав ваше повідомлення; якщо він посеред ходу, то отримає повідомлення, коли хід закінчиться. Ваш текст Antenna ніколи не друкує в термінал. Експериментальна функція. Тепер закрийте ноутбук.

Перед довгою роботою перевірте, що може її зупинити, поки поруч нікого немає:

  • Власний запит дозволу Claude Code («Do you want to proceed?») чекає в його терміналі, доки хтось не відповість, а Antenna на нього ніколи не відповідає. Дозвольте в налаштуваннях Claude Code інструменти, потрібні для завдання.
  • Запити Antenna на схвалення чекають 10 хвилин. Потім нічого не виконується, і Claude Code дізнається, що ніхто їх не схвалив. Завдання, яке ви дали зі свого власного комп’ютера на рівні ∞, виконує команди й правки без запитань; зміни власних налаштувань Claude Code, як-от CLAUDE.md чи .claude/, однаково чекають на схвалення.

Коли ноутбук прокинеться

Поки ноутбук спить, відповіді Claude Code чекають у черзі на іншому комп’ютері, і Antenna й далі намагається їх доставити. Щойно ноутбук знову в мережі, вони приходять у чат — зі сповіщенням, якщо вікно Antenna не на передньому плані. Повідомлення, яке ви написали без мережі, показує годинник і надсилається саме. Запити, що досі чекають на ваше схвалення, видно в картці іншого комп’ютера в розділі Мої пристрої (експериментально).

Після перезавантаження іншого комп’ютера

Після перезавантаження ключі заблоковано, тож його з’єднання мовчать, доки ви не введете пароль. На сервері ввійдіть і виконайте antenna unlock, а потім знову запустіть сесію; --resume продовжує останню сесію Claude Code:

antenna session start api-dev --dir ~/projects/api --resume

На Mac введіть пароль у вікні Antenna й знову запустіть агента.

Запитання

Чи працюватиме Claude Code далі, якщо закрити ноутбук?

Ні, якщо із закритою кришкою ноутбук засинає, а зазвичай так і налаштовано: Claude Code стоїть на паузі, доки ви його не відкриєте. Запустіть його на комп’ютері, який завжди ввімкнений, і він працюватиме далі.

Чи може Claude Code працювати у фоні на моєму ноутбуці?

Поки ноутбук не спить — так: у режимі Code він працює у вкладці вікна Antenna, на яку можна не дивитися, і Antenna будить його, коли приходить повідомлення. Але коли ноутбук засинає, він однаково зупиняється.

Чи треба тримати SSH-сесію відкритою?

Ні. Claude Code працює в tmux Antenna на сервері, а ви звертаєтеся до нього через чат. Обидва комп’ютери самі підключаються назовні, тож вхідний порт теж не відкривається.

Чи не дає Antenna моєму Mac заснути?

Ні. Забороніть Mac засинати в його системних налаштуваннях. Для режиму Code вікно Antenna має лишатися відкритим.

Чи можна перевірити, як ідуть справи, з телефона?

Ще ні. Наразі Antenna працює на macOS і Linux.

Antenna безкоштовна й має відкритий код, працює на macOS і Linux. Без акаунта й без номера телефону.
