Як налаштувати ШІ-агента, що відповідає на ваші повідомлення

В Antenna можна вибрати контакт і агента (Claude Code, Codex чи власну команду), і відтоді кожне повідомлення від цього контакту запускає агента, який його читає й відповідає. Antenna запускає агента в пісочниці з дозволами не ширшими за рівень довіри цього контакту, а співрозмовник бачить відповідь ще під час її написання. Агент працює через ваш власний вхід у Claude чи ChatGPT, а відповідь, схожа на таку, що містить секрет, чекає на ваше підтвердження.

Типові сценарії

  • Власний асистент на сервері. Ви пишете на свій сервер з ноутбука, і Claude Code там відповідає, збирає проєкт і запускає тести.
  • Приймальня для контакту. Колега одразу отримує відповіді на запитання про ваш проєкт від агента, який бачить лише теку цієї розмови.
  • Скрипт, що звітує. Вивід будь-якої програми можна надсилати живим потоком: my-program | antenna send --stream <contact>.

Налаштування у вікні

  1. На комп’ютері, де має працювати агент, відкрийте Agents → Set up for a contact… (або в розмові — Agent replies → Set up… у картці контакту).
  2. Виберіть контакт і програму: Claude Code, Codex чи власну команду.
  3. За бажання вставте довготривалий токен входу (з claude setup-token) у поле Value (optional). Він один раз передається вашому вузлу й зберігається в його зашифрованій базі даних. На Mac це надійний спосіб, бо пісочниця не може відкрити Зв’язку ключів (Keychain).
  4. Підтвердьте паролем власника. Правило, його останній запуск і Run log (журнал запусків) з’являться в Agents.

У терміналі це один рядок: antenna wake set <contact> --cmd "claude -p --output-format stream-json". antenna wake list показує правила й останні запуски; antenna wake off <contact> вимикає правило.

Що агентові можна, а що ні

  • Його промпт незмінний: «у вас нове повідомлення, прочитайте його й дайте відповідь». Саме повідомлення ніколи не стає промптом; агент читає його як дані, з дозволами не ширшими за рівень довіри контакту.
  • Він працює в пісочниці (bubblewrap чи Landlock на Linux, Seatbelt на macOS): бачить власну тимчасову теку й теку цієї розмови і може звертатися лише до свого постачальника моделі. Ваші проєкти, інші файли й ключі вузла йому недоступні. Без пісочниці Antenna агента не запускає.
  • Кожен запуск починається з чистого аркуша, якщо ви не зробите агента постійним (див. нижче), тож попереднє повідомлення не може залишити інструкцій для наступного запуску.
  • Обмеження: ліміт часу на запуск і кількість запусків на годину, щоб балакучий контакт не вичерпав ваш ліміт використання.

Дозвольте агентові працювати у вашому проєкті

Лише для ваших власних комп’ютерів (∞) агент може також працювати в одній теці проєкту з вашими інструментами: --project ~/code/payments, плюс теки лише для читання через --tool-path і реєстри пакетів, до яких він може звертатися, через --allow-host. Для будь-якого іншого контакту Antenna цього не дозволяє і ніколи не відкриває вашу домашню теку, власні дані чи теки із секретами, як-от ~/.ssh.

Запитання

Чи бачить співрозмовник відповідь під час її набору?

Так, для контактів рівня 3 і вище: живе повідомлення росте, поки агент пише, а наприкінці стає звичайним повідомленням. Рівні 1 і 2 отримують готову відповідь.

Що, як агент напише у відповіді пароль чи ключ?

Потік для співрозмовника зупиняється, а повідомлення чекає на ваше підтвердження. Без зупинки воно йде лише на ваші власні комп’ютери.

Чи пам’ятає агент попередні розмови?

За замовчуванням ні: кожне повідомлення запускає агента з нуля. Для роботи, що триває годинами, додайте --resident: тоді одна й та сама сесія Claude Code лишається з розмовою, пам’ятає, що було сказано й вирішено, а кожне нове повідомлення стає її наступним кроком. Повідомлення й надалі надходять до неї як дані від іншої сторони.

Antenna безкоштовна й має відкритий код, працює на macOS і Linux. Без акаунта й без номера телефону.
