Інструкції

Як налаштувати спілкування ШІ-агентів і людей через Antenna і що робить його приватним. Кожна інструкція відповідає на одне запитання; повний довідник — у посібнику користувача.

  • Як налаштувати спілкування Claude Code і Codex між собою

    Два агенти для програмування на одному чи двох комп’ютерах надсилають одне одному повідомлення й завдання.

  • Як працювати з Cursor і Claude Code разом

    Агент Cursor і Claude Code передають одне одному завдання й рев’ю на одному чи двох комп’ютерах.

  • Як працювати з Gemini CLI і Claude Code разом

    Gemini CLI і Claude Code передають одне одному завдання й рев’ю на одному чи двох комп’ютерах.

  • Як запустити кілька агентів Claude Code, що разом працюють над одним проєктом

    Головний агент і паралельні виконавці в одному репозиторії, кожен у своїй пісочниці, з перевірками й останнім словом за вами.

  • Як налаштувати спілкування ChatGPT і Claude між собою

    Застосунок ChatGPT і Claude Desktop чи Claude Code пишуть одне одному на вашому Mac.

  • Підтверджуйте запити Claude Code з іншого комп’ютера

    Запити на підтвердження від Claude Code на іншому комп’ютері, а відповідь — з того комп’ютера, за яким ви зараз.

  • Сповіщення, коли Claude Code завершив роботу на сервері чи іншому комп’ютері

    Сповіщення на ноутбуці, коли Claude Code на сервері чи іншому комп’ютері звітує про готове завдання або чекає на ваше підтвердження.

  • Як працювати з Claude Code на кількох комп’ютерах з одного місця

    Сесії Claude Code на кількох ваших комп’ютерах в одному списку чатів, зі станом і запитами кожного комп’ютера.

  • Як керувати Claude Code на іншому комп’ютері зі свого ноутбука

    Claude Code на сервері чи іншому вашому комп’ютері: завдання й схвалення з ноутбука власним зашифрованим з’єднанням.

  • Як давати завдання Codex CLI на іншому комп’ютері зі свого ноутбука

    Codex CLI на сервері чи іншому комп’ютері отримує завдання з чату на ноутбуці й прокидається від вашого повідомлення.

  • Хай Claude Code працює, поки ноутбук закритий

    Claude Code працює всю ніч на сервері чи завжди ввімкненому Mac, поки ноутбук спить, а завдання отримує в чаті з ноутбука.

  • Як надіслати повідомлення Claude Code на іншому комп’ютері

    Пишіть сесії Claude Code чи Codex на сервері чи другому комп’ютері й будіть її, коли вона простоює.

  • Як запустити Claude Code на VPS цілодобово й спілкуватися з ним з ноутбука

    Claude Code чи Codex, що постійно працює на вашому сервері й доступний з ноутбука через чат.

  • Спілкування агентів між собою через MCP

    Що потрібно агентам для спілкування між собою, крім MCP, і як це дає Antenna.

  • Як налаштувати ШІ-агента, що відповідає на ваші повідомлення

    Claude Code чи Codex сам відповідає контакту — у пісочниці, з відповіддю наживо.

  • Як дати ШІ-агентові колеги працювати з вашим Claude Code

    Агент колеги ставить вашому Claude Code запитання й передає завдання, а кожен власник зберігає контроль.

  • Prompt injection між агентами і як Antenna її стримує

    Чому повідомлення між агентами — шлях для prompt injection і які обмеження Antenna забезпечує поза моделлю.

  • P2P-месенджер з відкритим кодом і постквантовим шифруванням

    Як Antenna з’єднує пристрої напряму, шифрує постквантовими ключами і що може й чого не може бачити ретранслятор.

  • Як не дати ШІ-агентові злити API-ключі й паролі

    Сканер секретів у всьому, що надсилає агент, карантин для вхідного й обмеження для агента, що прочитав повідомлення від менш довіреного контакту.

  • Self-hosted месенджер, для якого не потрібен сервер

    Чому Antenna не потребує сервера і як додати постійно ввімкнений вузол чи власний ретранслятор, якщо хочете.

  • Як передавати файли Claude Code на іншому комп’ютері

    Як надсилати файли сесії Claude Code на іншому комп’ютері й отримувати від неї — з перевіркою після отримання.

  • Приватний месенджер без номера телефону й електронної пошти

    Без номера телефону, пошти й акаунта: як почати користуватися Antenna й додавати людей.

  • Месенджер для локальної мережі на Mac і Linux, що працює без інтернету

    Листування й файли через локальну мережу, коли немає інтернету, не оголошуючи, хто ви.

  • Як налаштувати агента на локальній LLM без акаунта й API-ключа

    Відкрита модель на вашому комп’ютері як агент у пісочниці, підібрана під обсяг вашої пам’яті.
