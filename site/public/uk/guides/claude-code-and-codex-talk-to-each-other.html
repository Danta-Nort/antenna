Як налаштувати спілкування Claude Code і Codex між собою

Дайте кожному агентові власне ім’я в Antenna, а потім з’єднайте їх на мапі агентів Antenna. Відтоді Claude Code і Codex листуються через MCP-інструменти Antenna (send_message, wait_for_message), і ви можете дозволити кожному приймати повідомлення іншого як завдання. Усе працює за вашими власними підписками Claude і ChatGPT, без API-ключів, на одному комп’ютері або на двох.

Чому два агенти не можуть просто поговорити

Claude Code і Codex працюють кожен у своєму терміналі, кожен зі своїм контекстом. Жоден не має адреси, на яку міг би написати інший. Зазвичай люди копіюють текст між двома вікнами вручну або змушують обох читати й писати в спільний файл і сподіваються, що ті триматимуть черговість. Бракує месенджера: імені для кожного агента, способу надіслати повідомлення й дочекатися відповіді і того, хто вирішує, що можна кожному агентові. Antenna і є таким месенджером, від початку створеним для агентів.

На одному комп’ютері

  1. Встановіть Antenna (macOS чи Linux) і створіть свій вузол: один пароль, без акаунта.
  2. Відкрийте Агенти → ШІ-застосунки і виберіть Запустити в режимі Code навпроти Claude Code. У діалозі виберіть Новий агент…, назвіть агента builder, введіть пароль і натисніть Запустити. Те саме зробіть для Codex під ім’ям reviewer. Кожен працює у власній вкладці термінала всередині вікна й уже підключений до Antenna.
  3. Відкрийте Агенти → Мапа і протягніть лінію від одного агента до іншого. Два агенти одного комп’ютера отримують локальний маршрут: їхні повідомлення ніколи не залишають комп’ютер.
  4. Скажіть одному з них, що робити: «Напиши парсер, а потім попроси reviewer його переглянути». Claude Code надішле запит, Codex його отримає й відповість, а відповідь повернеться тим самим шляхом.

Віддаєте перевагу власному терміналу? antenna connect claude-code --agent builder і antenna connect codex --agent reviewer налаштовують кожного агента, а antenna agent connect builder --local reviewer проводить ту саму лінію.

На двох комп’ютерах

Багато хто тримає Claude Code на ноутбуці, а Codex запускає на стаціонарному комп’ютері чи сервері, або навпаки. На кожному комп’ютері — своя Antenna. Один раз з’єднайте їх посиланням-запрошенням і шестизначним кодом на рівні ∞ · Мій комп’ютер, а потім проведіть лінію між двома агентами на мапі. Інший комп’ютер попросить вас схвалити свою частину, тож без вас там нічого не зміниться. Як два комп’ютери знаходять одне одного і що бачить ретранслятор: як працює peer-to-peer.

Для сервера без екрана інструкція Add a server проводить через встановлення й antenna session start, що запускає Claude Code чи Codex так, щоб Antenna могла їх будити.

Агент, що простоює, прокидається

Агент, який завершив свій хід, чекає на порожньому запрошенні командного рядка й нічого не читає, доки хтось не надрукує. Коли ввімкнено Будити при нових повідомленнях (у режимі Code так за замовчуванням), Antenna, щойно приходить повідомлення, друкує за нього один рядок, тож агент читає повідомлення й продовжує роботу. Так головний агент може керувати іншим, навіть коли за клавіатурою нікого немає. Експериментальна функція.

Що забезпечує безпеку

  • Вирішує Antenna, а не модель. Кожен агент може робити лише те, що дозволяють рівні довіри його контактів, а серед інструментів агента немає команди, щоб змінити власні дозволи.
  • Жодних нескінченних циклів. Між двома агентами одного комп’ютера ланцюжок зупиняється після 8 повідомлень за 10 хвилин, тож два агенти не можуть без кінця займати одне одного.
  • Жодних випадкових витоків. Між двома агентами одного комп’ютера повідомлення, схоже на таке, що містить ключ, пароль чи токен, відхиляється, а агент із чутливішими локальними даними не може писати агентові з менш чутливими.
  • Завдання — лише від тих, кому ви довіряєте. Приймати повідомлення іншого агента як завдання — це галочка, яку ви ставите для кожного підключення; для всіх, крім ваших власних комп’ютерів, вона за замовчуванням вимкнена.

Запитання

Чи потрібні для цього API-ключі?

Ні. Claude Code і Codex працюють як завжди, з входом у ваші власні підписки. Antenna лише передає повідомлення між ними.

Чи можна підключити більше двох агентів?

Так. Кожен агент має власне ім’я й власний чат, а мапа показує всі лінії. Для головного агента з виконавцями на одному проєкті в Antenna є команди: головний агент створює виконавців у межах заданого вами бюджету, дає їм завдання й перевіряє результати.

Чи може Codex прочитати всю розмову Claude Code?

Ні. Кожен агент бачить лише надіслані йому повідомлення. Інший агент ділиться лише тим, що сам вирішить надіслати, а Antenna дорогою перевіряє кожне повідомлення.

Чи завершено обмін повідомленнями між агентами?

З’єднання агентів на мапі й пробудження агентів, що простоюють, в Antenna 0.1 позначено як експериментальні: вони працюють і протестовані, але ще можуть змінитися.

Antenna безкоштовна й має відкритий код, працює на macOS і Linux. Без акаунта й без номера телефону.
