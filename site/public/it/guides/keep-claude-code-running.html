Claude Code continua a lavorare anche a portatile chiuso

Sul portatile stesso non si può: chiudendo lo schermo il portatile va in sospensione, un computer in sospensione non esegue nulla e Claude Code si ferma con lui. La soluzione è far girare Claude Code su un computer che resta acceso, per esempio un server Linux o un Mac mini impostato per non andare in sospensione, avviarlo lì tramite Antenna e dargli i compiti dalla chat di Antenna sul portatile. Chiudi il portatile: Claude Code continua a lavorare sull'altro computer, e le sue risposte aspettano il portatile e arrivano quando torna online.

Perché si ferma

Claude Code gira sul computer su cui lo avvii. Quando quel computer va in sospensione, ogni programma si ferma, Claude Code compreso, finché non si risveglia. Anche chiudere il terminale o la finestra SSH in cui gira lo termina. Puoi tenere sveglio un portatile con lo schermo chiuso, ma allora deve restare collegato alla corrente e acceso, e in pratica è diventato un server. Quindi il lavoro passa a un computer sempre acceso, e il portatile si limita a parlargli.

Che cosa ti serve

  • Un computer che resta acceso: un server Linux x86_64 (una VPS o uno a casa), oppure un desktop Mac o Linux impostato per non andare in sospensione.
  • Claude Code installato lì, con l'accesso effettuato.
  • Antenna su entrambi i computer: l'app sul portatile (macOS o Linux), il nodo o l'app sull'altro.

Su un server

  1. Installa il nodo Antenna e lascialo girare anche dopo il logout: 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
    L'installer configura Antenna come servizio utente systemd e crea il tuo nodo con una password. Il lingering non lo attiva, te lo ricorda soltanto: senza la seconda riga il servizio si ferma quando fai logout.
  2. Abbina una volta il server al portatile. Sul portatile: Nuovo contatto → Invita, spunta Questo è un mio computer (∞), premi Crea il link e copialo. Sul server: antenna join '<link>' --trust 5 --label mac, digita il codice che mostra il portatile, poi premi Il contatto ha confermato: i codici corrispondono sul portatile.
  3. Avvia Claude Code tramite Antenna nella cartella del progetto (sul server serve tmux): 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    Rispondi alle prime domande di Claude Code, per esempio se si fida della cartella, poi esci con Ctrl-b d. Sul portatile c'è ora una chat chiamata api-dev.
  4. Lascia che sia il portatile a rispondere alle richieste di approvazione del server: antenna devices confirm mac.

Ora puoi chiudere la sessione SSH. Il servizio continua a girare, e Claude Code continua a girare nel server tmux di Antenna; il tuo tmux non viene toccato. In Claude Code su una VPS trovi ogni passaggio più in dettaglio.

Su un Mac o un desktop sempre acceso

  1. Nelle impostazioni di sistema, imposta il computer perché non vada in sospensione da solo. Antenna non tiene sveglio il computer.
  2. Abbinalo al portatile come sopra, con Questo è un mio computer (∞) spuntato.
  3. Su quel computer apri Agenti → App AI e premi Avvia in modalità Code accanto a Claude Code. Scegli Nuovo agente… e dagli un nome, scegli la Cartella di lavoro, inserisci la password e premi Avvia. La finestra passa alla modalità Code e Claude Code gira in una scheda al suo interno.
  4. Chiedi una volta a Claude Code, nella sua scheda, di salutare il tuo portatile tramite Antenna. A quel punto la sua chat compare sul portatile.
  5. Lascia che sia il portatile a rispondere alle sue richieste di approvazione: I miei dispositivi → la scheda del portatile → Approvazioni → Accetta le approvazioni firmate con …, con la tua password.

Lascia aperta la finestra di Antenna: chiuderla ferma gli agenti che ci girano dentro, e la finestra prima te lo chiede.

Lascialo al lavoro

Scrivi il compito nella chat dell'agente sul portatile: “Esegui i test di migrazione, correggi ciò che fallisce e rispondi qui con che cosa hai cambiato.” Quando Claude Code è fermo al suo prompt, Antenna digita una riga predefinita perché legga il tuo messaggio; se è a metà di un turno, riceve il messaggio quando il turno finisce. Antenna non digita mai il tuo testo nel terminale. Sperimentale. Poi chiudi il portatile.

Prima di un lavoro lungo, controlla che cosa potrebbe fermarlo mentre non c'è nessuno:

  • La richiesta di permesso di Claude Code stesso (“Do you want to proceed?”) aspetta nel suo terminale finché qualcuno non risponde, e Antenna non ci risponde mai. Consenti nelle impostazioni di Claude Code gli strumenti che servono al compito.
  • Le richieste di approvazione di Antenna aspettano 10 minuti. Dopo non viene eseguito nulla, e Claude Code viene a sapere che nessuno le ha approvate. Un compito che dai da un tuo computer a ∞ esegue comandi e modifiche senza chiedere; le modifiche alla configurazione di Claude Code stesso, come CLAUDE.md o .claude/, chiedono comunque.

Quando il portatile si risveglia

Mentre il portatile è in sospensione, le risposte di Claude Code aspettano in coda sull'altro computer, e Antenna continua a provare a consegnarle. Appena il portatile torna online arrivano nella chat, con una notifica se la finestra di Antenna non è in primo piano. Un messaggio che hai scritto mentre eri offline mostra un orologio e parte da solo. Le richieste ancora in attesa della tua approvazione compaiono sulla scheda dell'altro computer in I miei dispositivi (sperimentale).

Dopo il riavvio dell'altro computer

Dopo un riavvio le chiavi sono bloccate, quindi i suoi collegamenti restano muti finché non inserisci la password. Su un server, accedi ed esegui antenna unlock, poi avvia di nuovo la sessione; --resume riprende l'ultima sessione di Claude Code:

antenna session start api-dev --dir ~/projects/api --resume

Su un Mac, inserisci la password nella finestra di Antenna e avvia di nuovo l'agente.

Domande

Claude Code continua a girare se chiudo il portatile?

No, se chiudendo lo schermo il portatile va in sospensione, come succede di solito: Claude Code si ferma finché non lo riapri. Fallo girare su un computer che resta acceso e continua a lavorare.

Claude Code può girare in background sul mio portatile?

Finché il portatile è sveglio, sì: in modalità Code gira in una scheda della finestra di Antenna che non devi per forza guardare, e Antenna lo sveglia quando arriva un messaggio. Ma si ferma comunque quando il portatile va in sospensione.

Devo tenere aperta una sessione SSH?

No. Claude Code gira nel tmux di Antenna sul server, e lo raggiungi tramite la chat. Entrambi i computer si collegano verso l'esterno, quindi non si apre nemmeno una porta in ingresso.

Antenna tiene sveglio il mio Mac?

No. Imposta il Mac perché non vada in sospensione nelle sue impostazioni di sistema. Per la modalità Code la finestra di Antenna deve restare aperta.

Posso controllarlo dallo smartphone?

Non ancora. Oggi Antenna gira su macOS e Linux.

Antenna è gratuita e open source, per macOS e Linux. Niente account, niente numero di telefono.
