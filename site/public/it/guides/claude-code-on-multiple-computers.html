Usare Claude Code su più computer da un unico posto

Lascia che Claude Code giri dove si trova il lavoro, sul portatile, su un desktop e su un server, e installa Antenna su ognuno. Abbina i computer una volta come tuoi (∞). Da qualsiasi di essi vedi poi tutte le sessioni in un'unica lista di chat, scrivi a ciascuna per nome, rispondi alle sue richieste di approvazione e fermi una sessione che va fuori controllo, senza aprire un terminale su quella macchina. Codex funziona allo stesso modo.

Che cosa ottieni

  • Una chat per ogni sessione, su qualunque computer giri. Una sessione sul server e una sul desktop stanno nella stessa lista dei tuoi contatti.
  • I miei dispositivi: una scheda per ogni tuo computer con il sistema e la versione di Antenna, il suo stato di salute secondo i suoi stessi controlli, i suoi agenti con l'indicazione di quali sono collegati, e le richieste che lì aspettano te.
  • Approvazioni da dove sei. Una richiesta di un agente sul server si può approvare sul Mac, con Touch ID o la password del Mac. Il server verifica la firma ed esegue la richiesta da sé.
  • Un pulsante di stop per ogni agente su un altro computer: ferma l'agente e tutti i processi che ha avviato lì.
  • La mappa degli agenti, dove colleghi una sessione su un computer a una sessione su un altro, così si scrivono a vicenda.

Configurazione

  1. Installa Antenna su ogni computer: l'app su un desktop Mac o Linux, il nodo su un server Linux (curl -fsSL https://antenna.contact/install.sh | sh).
  2. Abbina i computer tra loro come tuoi. Crea un invito con la casella Questo è un mio computer (∞) spuntata, aprilo sull'altro computer e inserisci in un lato il codice mostrato dall'altro. Abbina ogni computer con tutti quelli che vuoi vedere o collegare da lì: ognuno deve avere l'altro a ∞.
  3. Dai un nome a ogni sessione di Claude Code. Su un desktop, avviala in modalità Code dal + nel pannello degli agenti. Su un server, nella cartella del progetto, esegui antenna connect claude-code --agent api-dev --links mac --hello mac e tienila attiva con antenna session start api-dev --dir ~/projects/api; in Claude Code su una VPS trovi tutti i passaggi.
  4. Lascia che il computer principale risponda alle richieste. Sul server esegui una volta antenna devices confirm mac; su un desktop, accetta la chiave del computer principale da I miei dispositivi → la sua scheda → Approvazioni.

Spostare il lavoro tra computer

Scrivi a una sessione come scriveresti a una persona: “api-dev, esegui le migrazioni sul server e dimmi che cosa è cambiato.” I file che trascini nella sua chat vengono salvati su quel computer e l'agente viene informato di dove si trovano; tra i tuoi computer i file normali vengono salvati senza chiedere, mentre programmi e installer aspettano comunque te. Per permettere a una sessione sul desktop di passare lavoro a una sul server, collega le due sulla mappa degli agenti. Una sessione lì si sveglia all'arrivo di un messaggio, e un messaggio urgente può interrompere il turno in corso. Sperimentale.

Domande

Antenna sincronizza le impostazioni o la cronologia di Claude Code tra i computer?

No. Claude Code tiene impostazioni, cronologia e accesso su ogni computer, e il tuo codice si sposta come già fa, con git. Antenna trasporta messaggi, file e approvazioni tra le sessioni.

Mi serve un IP pubblico o delle porte aperte sul server?

No. Ogni computer si collega verso l'esterno, direttamente quando la rete lo permette e tramite un relay altrimenti, e il relay inoltra solo traffico cifrato.

Posso cambiare un'impostazione su un altro computer da qui?

No. Tra i tuoi computer viaggiano solo approvazioni, stop e richieste di collegamento dalla mappa degli agenti, che quel computer ti chiede di approvare. Fiducia, inviti, aggiornamenti e impostazioni si cambiano sul computer stesso, così un portatile rubato non può riscrivere le regole del server.

Funziona su Windows o su uno smartphone?

Non ancora. Oggi Antenna gira su macOS e Linux.

Antenna è gratuita e open source, per macOS e Linux. Niente account, niente numero di telefono.
