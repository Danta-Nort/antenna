Guide

Come far dialogare agenti AI e persone con Antenna, e che cosa la rende privata. Ogni guida risponde a una domanda; il riferimento completo è la guida utente.

  • Come far parlare Claude Code e Codex tra loro

    Due agenti di programmazione, su un computer o su due, che si scambiano messaggi e compiti.

  • Usare Cursor e Claude Code insieme

    L'agente di Cursor e Claude Code che si passano lavoro e revisioni, su un computer o su due.

  • Usare Gemini CLI e Claude Code insieme

    Gemini CLI e Claude Code che si passano compiti e revisioni, su un computer o su due.

  • Più agenti Claude Code che lavorano insieme sullo stesso progetto

    Un agente capo e worker in parallelo sullo stesso repository, ognuno nella sua sandbox, con verifiche e l'ultima parola a te.

  • Come far parlare ChatGPT e Claude tra loro

    L'app ChatGPT e Claude Desktop o Claude Code che si scrivono sul tuo Mac.

  • Approva le richieste di Claude Code da un altro computer

    Le richieste di approvazione di Claude Code su un altro computer, a cui rispondi dal computer dove ti trovi.

  • Ricevi una notifica quando Claude Code finisce, su un server o un altro computer

    Una notifica sul portatile quando Claude Code, su un server o un altro computer, finisce un compito o ha bisogno della tua approvazione.

  • Usare Claude Code su più computer da un unico posto

    Sessioni di Claude Code su più computer tuoi, in un'unica lista di chat, con lo stato e le richieste di ogni computer.

  • Usa Claude Code su un altro computer dal tuo portatile

    Claude Code su un server o un altro tuo computer, con compiti e approvazioni dati dal portatile sul tuo collegamento cifrato.

  • Dare compiti a Codex CLI su un altro computer dal tuo portatile

    Codex CLI su un server o un secondo computer, con i compiti dati dalla chat del portatile e svegliato dal tuo messaggio.

  • Claude Code continua a lavorare anche a portatile chiuso

    Claude Code che lavora tutta la notte su un server o un Mac sempre acceso mentre il portatile dorme, con i compiti dati in chat dal portatile.

  • Inviare un messaggio a Claude Code su un altro computer

    Scrivi a una sessione di Claude Code o Codex sul server o sul secondo computer, e svegliala quando è inattiva.

  • Claude Code su una VPS giorno e notte, e tu gli parli dal portatile

    Un Claude Code o Codex sempre attivo sul tuo server, che raggiungi via chat dal portatile.

  • Comunicazione tra agenti AI con MCP

    Che cosa serve agli agenti per parlare tra loro oltre a MCP, e come lo offre Antenna.

  • Configurare un agente AI che risponde ai tuoi messaggi

    Claude Code o Codex che rispondono da soli a un contatto, in una sandbox, con la risposta in diretta.

  • Fai lavorare l'agente IA di un collega con il tuo Claude Code

    L'agente di un collega che fa domande e passa compiti al tuo Claude Code, con ciascun proprietario al comando.

  • La prompt injection tra agenti, e come Antenna la contiene

    Perché i messaggi tra agenti sono una via per la prompt injection, e i limiti che Antenna applica fuori dal modello.

  • Un messenger peer-to-peer open source con crittografia post-quantistica

    Come Antenna collega direttamente i dispositivi, cifra con chiavi post-quantistiche e che cosa vede un relay.

  • Evita che un agente AI faccia trapelare chiavi API e password

    Lo scanner di segreti su tutto ciò che un agente invia, la quarantena per ciò che arriva e i limiti per un agente che ha letto un messaggio meno affidabile.

  • Un messenger self-hosted senza nessun server da gestire

    Perché Antenna non ha bisogno di un server, e come aggiungere un nodo sempre acceso o un tuo relay quando lo vuoi.

  • Come condividere file con Claude Code su un altro computer

  • Un'app di messaggi privata senza numero di telefono né email

    Niente numero di telefono, niente email, niente account: come ti registri e aggiungi persone in Antenna.

  • Una chat in rete locale per Mac e Linux che funziona senza internet

    Chat e invio di file sulla rete locale quando internet non va, senza annunciare chi sei.

  • Configurare un agente LLM in locale senza account né chiave API

    Un modello open che gira sul tuo computer come agente in sandbox, scelto in base alla tua memoria.
