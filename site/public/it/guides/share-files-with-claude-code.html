Come condividere file con Claude Code su un altro computer

Sullo stesso computer, Claude Code legge direttamente i tuoi file: gli dai il percorso o trascini il file nel suo terminale. Su un altro computer, per esempio un server, mandi il file tramite Antenna: lo trascini nella chat con quella sessione di Claude Code, Antenna lo controlla all'arrivo e lo salva lì nella cartella del collegamento, e l'agente trova nella sua casella il nome del file, la posizione, la dimensione e lo SHA-256. I file che l'agente ti rimanda arrivano sul portatile allo stesso modo.

Inviare un file all'agente

  1. Abbina il portatile all'altro computer come tuo (∞) e collega ad Antenna il Claude Code che gira lì: vedi Claude Code su una VPS.
  2. Sul portatile apri la chat con la sessione e trascinaci il file, oppure allegalo come faresti in qualsiasi messenger.
  3. Sull'altro computer, Antenna controlla il tipo del file in base al contenuto, cerca minacce e segreti e lo salva nella cartella del collegamento, ~/Antenna/links/<folder>/shared/, o in una cartella di progetto che hai scelto per quel computer.
  4. L'agente viene a sapere da solo del file salvato alla successiva lettura della casella, con percorso e hash, e può usarlo nel passo successivo.

Ricevere file dall'agente

L'agente può mandarti un file, una build, un report o uno screenshot, con gli stessi strumenti che usa per i messaggi. Arriva nella tua chat e in File, come una scheda con il nome del file, ciò che il controllo ha notato e il suo hash. Le immagini compaiono come anteprima sicura già controllata, ricostruita da Antenna.

Che cosa viene controllato e che cosa aspetta te

  • Tra i tuoi computer, i file normali vengono salvati da soli. Tutto ciò che può eseguire o installare software, come un programma, un installer o un archivio che ne contiene uno, aspetta comunque una tua decisione, a meno che tu non lo consenta per quel computer.
  • Dall'agente di un'altra persona di livello 3 e 4, i file vengono controllati e aspettano che tu prema “Accetta”, o che li accetti uno dei tuoi agenti. Ai livelli 1 e 2 decidi tu ogni file.
  • In uscita, un file che sembra contenere una chiave, una password o un token viene trattenuto finché non lo approvi, tranne che tra i tuoi computer.
  • Non viene sovrascritto nulla. Un file con un nome già usato viene salvato come report (2).pdf, e chi lo ha inviato viene informato del nome.

Domande

Perché non usare scp o una cartella condivisa?

Puoi farlo, e per grandi alberi di file potresti preferirlo. Antenna è pensata per i file che fanno parte di una conversazione con l'agente: arrivano dove l'agente se li aspetta, l'agente viene avvisato, e un file che arriva da chiunque non sia tu viene controllato prima di essere salvato.

Il file è cifrato durante il trasferimento?

Sì, end-to-end, sullo stesso collegamento dei tuoi messaggi. Nessun server intermedio lo conserva.

Posso scegliere dove vengono salvati i file?

Sì. Nella scheda contatto del computer, File da questo computer ti permette di scegliere una cartella per quel computer e una per ciascuno dei suoi agenti. Da terminale: antenna files save-to <contact> <folder>.

Antenna è gratuita e open source, per macOS e Linux. Niente account, niente numero di telefono.
