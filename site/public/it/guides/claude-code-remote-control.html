Usa Claude Code su un altro computer dal tuo portatile

Installa Antenna sul portatile e sul computer dove gira Claude Code, abbinali una volta come computer tuoi e avvia lì Claude Code tramite Antenna. Sul portatile compare una chat con quella sessione: scrivi un compito, Antenna sveglia Claude Code quando è inattivo e la sua risposta torna nella chat. I messaggi viaggiano su un collegamento peer-to-peer cifrato end-to-end tra i tuoi due computer, Antenna non ha bisogno di nessun account, e i passi che richiedono la tua approvazione arrivano sul portatile, dove rispondi con la tua password.

Il Remote Control di Claude Code e Antenna

Claude Code ha una sua funzione Remote Control integrata, descritta nella documentazione di Anthropic. Questa guida parla di una configurazione diversa: Claude Code gira su un tuo computer che resta acceso, un server o un desktop, e tu lo comandi da Antenna sul portatile. Fa per te se vuoi:

  • Più sessioni su più computer in un'unica lista. Ogni sessione ha la sua chat, e la sezione I miei dispositivi mostra lo stato di ogni computer, i suoi agenti e le richieste in attesa lì.
  • Un collegamento tutto tuo. I messaggi vengono cifrati su un computer e decifrati sull'altro. I tuoi computer si collegano direttamente quando la rete lo permette, altrimenti tramite un relay che inoltra solo traffico cifrato. Nessun account, nessuna porta in ingresso.
  • Permessi controllati dal daemon di Antenna sul computer dove gira Claude Code, con le approvazioni date da qualunque tuo computer tu stia usando.
  • Altri agenti allo stesso modo: Codex funziona come Claude Code.

Configurazione

  1. Installa Antenna su entrambi i computer: l'app sul portatile (macOS o Linux) e, sull'altro computer, l'app oppure, su un server Linux, il nodo: 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
  2. Abbinali una volta. Sul portatile: Nuovo contatto → Invita, spunta Questo è un mio computer (∞), premi Crea il link e copialo. Su un server: antenna join '<link>' --trust 5 --label mac; su un desktop: Nuovo contatto → Unisciti, con la stessa casella spuntata. Inserisci in un lato il codice mostrato dall'altro e premi Il contatto ha confermato: i codici corrispondono sul portatile.
  3. Avvia Claude Code tramite Antenna sull'altro computer. Su un server, nella cartella del progetto (serve tmux): 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    Rispondi alle prime domande di Claude Code, poi esci con Ctrl-b d: continua a girare, e sul portatile c'è una chat chiamata api-dev. Su un desktop: Agenti → App AI → Avvia in modalità Code, e Claude Code gira lì in una scheda della finestra di Antenna; chiedigli una volta di salutare il tuo portatile tramite Antenna, e la sua chat compare sul portatile.
  4. Lascia che sia il portatile a rispondere alle richieste di approvazione di quel computer. Su un server: antenna devices confirm mac. Su un desktop: I miei dispositivi → la scheda del portatile → Approvazioni → Accetta le approvazioni firmate con …, con la tua password.

Comandalo dal portatile

  • Dagli un compito. Scrivi nella chat della sessione come scriveresti a una persona. Quando Claude Code è fermo al suo prompt, Antenna digita una riga predefinita perché legga il tuo messaggio; non digita mai il tuo testo nel terminale e non risponde mai a una domanda che Claude Code fa lì. Sperimentale.
  • Interrompilo. Attiva Urgente: interrompi ora prima di inviare: Antenna preme Esc una volta per chiudere il turno in corso, mai sopra una domanda o una richiesta di permesso aperta lì, e Claude Code legge il tuo messaggio. Sperimentale.
  • Approva i suoi passi. Un passo che ha bisogno di te compare sulla scheda dell'altro computer in I miei dispositivi, con una notifica. Premi Approva con la password, Approva con Touch ID su un Mac, oppure Rifiuta. Sperimentale.
  • Fermalo. Ferma l'agente e i suoi processi… accanto all'agente su quella scheda chiude Claude Code e tutto ciò che ha avviato lì. Sperimentale.

La richiesta di permesso di Claude Code stesso (“Do you want to proceed?”) resta nel suo terminale sull'altro computer, e Antenna non ci risponde mai. Consenti nelle impostazioni di Claude Code gli strumenti che usi di solito, oppure rispondi con antenna session attach.

Codex e altri agenti

Codex funziona allo stesso modo: antenna connect codex e --cli codex su un server, oppure Avvia in modalità Code accanto a Codex su un desktop (vedi Controllare Codex CLI da remoto). Gemini CLI si collega da Agenti → App AI e invia e legge messaggi tramite Antenna, ma Antenna non lo sveglia ancora: legge un nuovo messaggio la prossima volta che chiama Antenna.

Domande

Vedo il terminale di Claude Code sul portatile?

No. Dai i compiti e leggi le risposte in una chat; il terminale resta sull'altro computer. Per guardarlo, esegui antenna session attach lì, anche via SSH se vuoi.

L'altro computer ha bisogno di un IP pubblico o di porte aperte?

No. Entrambi i computer si collegano verso l'esterno, direttamente quando la rete lo permette e tramite un relay altrimenti. Il relay inoltra solo traffico cifrato.

Chi altro può dargli compiti?

Solo i contatti abbinati a quel computer i cui messaggi l'agente può leggere (con --links mac, solo il tuo portatile), e gli agenti che gli colleghi sulla mappa degli agenti. È il daemon di Antenna su quel computer, non Claude Code, a decidere che cosa il messaggio di un contatto può fargli fare, in base al livello di fiducia di quel contatto.

Serve una chiave API?

No. Claude Code mantiene il tuo accesso sul computer dove gira, e Antenna trasporta solo messaggi, file e approvazioni.

Posso controllarlo dallo smartphone?

Non ancora. Oggi Antenna gira su macOS e Linux.

Antenna è gratuita e open source, per macOS e Linux. Niente account, niente numero di telefono.
