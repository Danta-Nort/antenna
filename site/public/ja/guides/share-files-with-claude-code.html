別のコンピューターの Claude Code とファイルを共有する方法

同じコンピューターなら、Claude Code はファイルを直接読めます。パスを伝えるか、ファイルをターミナルにドラッグするだけです。サーバーのような別のコンピューターの場合は、Antenna でファイルを送ります。その Claude Code セッションとのチャットにファイルをドロップすると、Antenna が受信時に検査して向こうのリンク用フォルダーに保存し、エージェントの受信箱にはファイル名、場所、サイズ、SHA-256 が届きます。エージェントが送り返すファイルも、同じようにノート PC に届きます。

エージェントにファイルを送る

  1. ノート PC ともう一方のコンピューターを自分のもの（∞）としてペアリングし、そちらの Claude Code を Antenna に接続します。VPS で Claude Code を動かすをご覧ください。
  2. ノート PC でそのセッションとのチャットを開き、ファイルをドロップします。ほかのメッセンジャーと同じように添付することもできます。
  3. もう一方のコンピューターで、Antenna はファイルの形式を中身から判定し、脅威や秘密情報がないかを調べて、リンク用フォルダー ~/Antenna/links/<folder>/shared/、またはそのコンピューター用に選んだプロジェクトフォルダーに保存します。
  4. エージェントは次に受信箱を見たときに、保存されたファイルのことをパスとハッシュ付きで自動的に知り、次のステップで使えます。

エージェントからファイルを受け取る

エージェントは、メッセージと同じツールで、ファイル、ビルド成果物、レポート、スクリーンショットをあなたに送れます。届いたファイルはチャットと ファイル に、ファイル名、検査で気づいたこと、ハッシュを載せたカードとして表示されます。画像は、Antenna が作り直した検査済みの安全なプレビューで表示されます。

検査されるもの、あなたの判断を待つもの

  • 自分のコンピューター同士では、普通のファイルは自動的に保存されます。プログラム、インストーラー、それらを含むアーカイブなど、ソフトウェアを実行したりインストールしたりできるものは、そのコンピューターに対して許可していない限り、あなたの判断を待ちます。
  • ほかの人のエージェントからのファイルは、レベル 3 と 4 なら検査されたうえで、あなたが「受け取る」を押すか、あなたのエージェントのどれかが受け取るのを待ちます。レベル 1 と 2 では、すべてのファイルをあなたが判断します。
  • 送信時には、鍵、パスワード、トークンを含んでいそうなファイルは、あなたが承認するまで保留されます。自分のコンピューター同士の場合を除きます。
  • 上書きはされません。すでに使われている名前のファイルは report (2).pdf のように保存され、送信者にはその名前が伝えられます。

よくある質問

scp や共有フォルダーではだめなのですか？

使ってもかまいませんし、大量のファイルツリーならそちらのほうがよいかもしれません。Antenna が向いているのは、エージェントとの会話に属するファイルです。エージェントが期待する場所に届き、エージェントにそれが伝えられ、あなた以外の誰かからのファイルは保存される前に検査されます。

ファイルは送信中に暗号化されますか？

はい。メッセージと同じリンクで、エンドツーエンドで暗号化されます。途中でファイルを保存するサーバーはありません。

ファイルの保存先を選べますか？

はい。そのコンピューターの連絡先カードにある このコンピューターからのファイル で、そのコンピューター用のフォルダーと、そこにいるエージェントごとのフォルダーを選べます。ターミナルからなら antenna files save-to <contact> <folder> です。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
