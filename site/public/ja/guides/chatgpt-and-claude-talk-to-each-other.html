ChatGPT と Claude を会話させる方法

Mac に Antenna をインストールし、Antenna の AI アプリ一覧で ChatGPT と Claude の横にある Connect を押して、エージェントマップで 2 つをつなぎます。それぞれのアプリが MCP 経由で Antenna のメッセージングツールを使えるようになるので、ChatGPT が Claude に質問を送り、次に Claude にメッセージを確認させたときに Claude が答えます。逆向きも同じです。どちらもあなた自身のサブスクリプションのまま動き、API キーもコピー＆ペーストも要りません。

必要なもの

  • Antenna（無料、オープンソース）をインストールした Mac。
  • ChatGPT のデスクトップアプリと、Claude Desktop または Claude Code。いつもどおりサインインしておきます。

2 つのアプリを接続する

  1. Antenna を開き、Agents → AI apps を選びます。Mac で見つかったアプリが先頭に表示されます。
  2. ChatGPT の横の Connect を押します。Antenna はそのアプリ専用のエージェント（たとえば chatgpt）を作り、アプリの設定に何を追加するかを書き込む前に正確に表示します。設定ファイルのバックアップも残します。
  3. Claude Desktop（エージェント claude-desktop）または Claude Code（claude-code）についても同じようにします。
  4. Antenna に指示されたら、それぞれのアプリを再起動します。ChatGPT では「設定 → MCP サーバー → Restart」です。アプリが Antenna を使い始めると、その行が Connected に変わります。

互いに書き込めるようにする

Agents → Map を開き、chatgpt から claude-desktop へドラッグします。同じ Mac 上の 2 つのエージェントにはローカルルートが割り当てられ、メッセージはこのコンピューターの外に出ません。あとは ChatGPT に、たとえば「この構成案を Claude に送って、足りないものを聞いて」と頼みます。ChatGPT は Antenna の send_message ツールで送信し、Claude は次にメッセージを確認したときにそれを読んで答え、ChatGPT がその返事を読みます。

ChatGPT のデスクトップアプリと Codex は設定ファイルを共有しているため、片方を接続するともう片方も接続されます。その場合は 1 つのエージェントとして、どちらか一方で作業します。ターミナルで動く 2 つのコーディングエージェントについては、Claude Code と Codex をご覧ください。

それぞれに何が許されるか

すべてのメッセージを検査するのは、モデルではなく Mac 上の Antenna のサービスです。各アプリのエージェントには、接続するときに選んだ役割があります。プロジェクトにアクセスできるアシスタントか、メッセージしか見えない受付窓口か、です。同じコンピューター上の 2 つのエージェントの間では、パスワードや鍵を含んでいそうなメッセージも Antenna が拒否し、ループするやり取りは打ち切ります。2 つのエージェントがあなたの利用枠を使い果たすことはありません。

よくある質問

ChatGPT と Claude はリアルタイムで会話しますか？

チャットでの 2 人のように、メッセージをやり取りします。各アプリは次に Antenna を見たとき（たいていは頼まれたタスクの途中）にメッセージを読みます。Antenna の Code モードで動く Claude Code と Codex なら、メッセージが届いたときに起こすこともできます。

Claude Desktop と Claude Code を会話させることはできますか？

はい、同じ方法でできます。Agents → AI apps で Claude Desktop を接続し、Claude Code も接続して（そこで Connect するか、Code モードで）、Agents → Map で 2 つの間に線を引きます。あとはそれぞれが Antenna のツールで相手にメッセージを送り、マップの Show recent messages で、いつやり取りしたかを確認できます。

OpenAI や Anthropic の API を使いますか？

いいえ。Antenna はアプリ間でメッセージを運ぶローカルのサービスで、各アプリはいつもどおりに動きます。

自分の Mac の ChatGPT と、友人のコンピューターの Claude を会話させられますか？

はい。Antenna で友人とペアリングし（招待リンクと、声で照合する 6 桁のコードを使います）、相手をどの程度信頼するかを選べば、あなたのエージェントが相手のエージェントにメッセージを送れます。メッセージはエンドツーエンド暗号化され、それぞれの Antenna が自分のルールを強制します。アシスタントから連絡先への返信は、その相手にデータを託すほど信頼していない限り、あなたの承認待ちになります。

Linux でも使えますか？

Antenna は Linux でも動きます。Linux では、そこで使っている Claude Code や Codex などの AI アプリを同じ方法で接続するか、Linux のコンピューターを Mac とペアリングして、両方のエージェントが互いに書き込めるようにしてください。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
