ノート PC を閉じている間も Claude Code に作業を続けさせる

ノート PC そのものでは無理です。ふたを閉じるとノート PC はスリープし、スリープ中のコンピューターでは何も動かず、Claude Code も一緒に止まります。解決策は、Linux サーバーや、スリープしないよう設定した Mac mini のような、電源が入ったままのコンピューターで Claude Code を動かすことです。そこで Antenna 経由で Claude Code を起動し、ノート PC の Antenna のチャットからタスクを渡します。ノート PC を閉じても、Claude Code はもう一方のコンピューターで作業を続け、返信はノート PC を待って、オンラインに戻ったときに届きます。

なぜ止まるのか

Claude Code は、起動したコンピューターの上で動きます。そのコンピューターがスリープすると、Claude Code を含むすべてのプログラムが、起きるまで止まります。Claude Code を動かしているターミナルや SSH のウィンドウを閉じても終了します。ふたを閉じたままノート PC を起こしておくこともできますが、それには電源につないで電源を入れたままにする必要があり、もはやサーバーです。そこで作業は常に電源の入ったコンピューターに移し、ノート PC はそれと話すだけにします。

必要なもの

  • 電源が入ったままのコンピューター。x86_64 の Linux サーバー（VPS でも自宅のマシンでも）、またはスリープしないよう設定した Mac か Linux デスクトップ。
  • そのコンピューターにインストール済みでサインイン済みの Claude Code。
  • 両方のコンピューターに Antenna。ノート PC にはアプリ（macOS または Linux）、もう一方にはノードかアプリ。

サーバーの場合

  1. Antenna のノードをインストールし、ログアウト後も動き続けるようにします。 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
    インストーラーは Antenna を systemd のユーザーサービスとして設定し、パスワード付きでノードを作成します。lingering は有効にせず、注意を促すだけです。2 行目がないと、ログアウトしたときにサービスが止まります。
  2. サーバーとノート PC を一度だけペアリングします。ノート PC で 新しい連絡先 → 招待 を開き、これは自分のコンピューターです（∞） にチェックを入れて リンクを作成 を押し、リンクをコピーします。サーバーで antenna join '<link>' --trust 5 --label mac を実行し、ノート PC に表示されたコードを入力したら、ノート PC で 相手が確認しました — コードは一致 を押します。
  3. プロジェクトフォルダーで、Antenna 経由で Claude Code を起動します（サーバーには tmux が必要です）。 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    フォルダーを信頼するかどうかといった Claude Code の最初の質問に答え、Ctrl-b d で抜けます。これでノート PC に api-dev という名前のチャットができています。
  4. サーバーからの承認リクエストにノート PC で答えられるようにします：antenna devices confirm mac。

ここで SSH からログアウトしてかまいません。サービスは動き続け、Claude Code も Antenna 専用の tmux サーバーで動き続けます。あなた自身の tmux には触れません。各手順の詳しい説明は VPS で Claude Code を動かすにあります。

電源の入ったままの Mac やデスクトップの場合

  1. システム設定で、コンピューターが勝手にスリープしないようにします。Antenna がコンピューターを起こしておくことはありません。
  2. 上と同じように、これは自分のコンピューターです（∞） にチェックを入れてノート PC とペアリングします。
  3. そのコンピューターで エージェント → AI アプリ を開き、Claude Code の横の Code モードで起動 を押します。新しいエージェント… を選んで名前を付け、作業フォルダー を選び、パスワードを入力して 起動 を押します。ウィンドウが Code モードに切り替わり、その中のタブで Claude Code が動きます。
  4. Claude Code のタブで一度だけ、Antenna を通じてノート PC にあいさつするよう頼みます。すると、そのチャットがノート PC に現れます。
  5. その承認リクエストにノート PC で答えられるようにします。自分のデバイス → ノート PC のカード → 承認 → … で署名された承認を受け付ける を開き、パスワードを入力します。

Antenna のウィンドウは開いたままにしてください。閉じると、そこで動いているエージェントが止まります。閉じる前にはウィンドウが確認します。

作業を任せる

ノート PC のエージェントのチャットにタスクを書きます：「マイグレーションのテストを実行して、失敗したものを直し、何を変えたかここに返信して」。Claude Code がプロンプトで待機していると、Antenna が組み込みの 1 行を入力してあなたのメッセージを読ませます。ターンの途中なら、ターンが終わったときにメッセージを受け取ります。Antenna があなたのテキストをターミナルに入力することはありません。実験的機能です。あとはノート PC を閉じるだけです。

長い作業の前に、誰もいない間にそれを止めてしまうものがないか確認しておきましょう。

  • Claude Code 自身の権限確認（「Do you want to proceed?」）は、誰かが答えるまでターミナルで待ち続け、Antenna がそれに答えることはありません。タスクに必要なツールは Claude Code の設定で許可しておいてください。
  • Antenna の承認リクエストは 10 分待ちます。その後は何も実行されず、Claude Code には誰も承認しなかったことが伝わります。∞ の自分のコンピューターから渡したタスクは、コマンドも編集も確認なしで実行します。ただし、CLAUDE.md や .claude/ など Claude Code 自身の設定の変更は、それでも確認を求めます。

ノート PC が起きたら

ノート PC がスリープしている間、Claude Code の返信はもう一方のコンピューターのキューで待ち、Antenna は配信を試み続けます。ノート PC がオンラインに戻ると返信はチャットに届き、Antenna のウィンドウが前面にないときは通知も出ます。オフラインの間に書いたメッセージには時計のマークが付き、自動で送信されます。まだ承認を待っているリクエストは、自分のデバイス にあるもう一方のコンピューターのカードに表示されます（実験的機能）。

もう一方のコンピューターが再起動したら

再起動後は鍵がロックされるので、パスワードを入力するまで、そのコンピューターのリンクは沈黙したままです。サーバーではログインして antenna unlock を実行し、セッションをもう一度起動します。--resume を付けると Claude Code の前回のセッションを続けられます。

antenna session start api-dev --dir ~/projects/api --resume

Mac では、Antenna のウィンドウでパスワードを入力し、エージェントをもう一度起動します。

よくある質問

ノート PC を閉じても Claude Code は動き続けますか？

ふたを閉じるとスリープする設定（ふつうはそうです）なら、動き続けません。開くまで Claude Code は止まったままです。電源の入ったままのコンピューターで動かせば、作業を続けます。

Claude Code をノート PC のバックグラウンドで動かせますか？

ノート PC が起きている間なら、できます。Code モードでは、見ていなくてもかまわない Antenna のウィンドウのタブで動き、メッセージが届くと Antenna が起こします。それでも、ノート PC がスリープすれば止まります。

SSH セッションを開いたままにする必要はありますか？

いいえ。Claude Code はサーバー上の Antenna の tmux で動き、チャットを通じてやり取りします。どちらのコンピューターも外向きに接続するので、受信用のポートを開けることもありません。

Antenna は Mac をスリープさせないようにしてくれますか？

いいえ。Mac のシステム設定でスリープしないように設定してください。Code モードを使うには、Antenna のウィンドウを開いたままにしておく必要があります。

スマートフォンから様子を確認できますか？

まだできません。現在、Antenna は macOS と Linux で動作します。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
