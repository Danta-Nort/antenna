サーバーや別のコンピューターの Claude Code が作業を終えたら通知を受け取る

ノート PC から Antenna のチャットで Claude Code にタスクを渡すと、終わったときに結果をそのチャットへ送り返してきます。接続されたエージェントには、タスクをくれた連絡先へ結果を返すよう Antenna の指示が伝えているからです。Antenna のウィンドウが前面にないあいだは、ノート PC に「server · api-dev に新着メッセージ」という通知が表示されます。承認リクエストも通知されるので、途中で止まった作業が誰にも気づかれずに待ち続けることはありません。Antenna 自身が Claude Code のターンを見張っているわけではなく、報告は Claude Code 自身が送るメッセージです。

通知されるもの

  • Claude Code からあなたへのメッセージ。通知に出るのはチャット名だけで、本文は表示されません。通知は 1 つのチャットにつき 10 秒に 1 回までです。
  • 承認リクエスト。あなたの判断が必要な手順は「Antenna: server で承認が必要です」と表示され、エージェント、やろうとしていること、残り時間（「残り 9 分」）が示されますが、リクエストの文面は表示されません。リクエストが閉じる約 2 分前にもう一度通知が届き、リクエストは 10 分で閉じます。別のコンピューターからのリクエストは 自分のデバイス経由で届きます（実験的機能）。
  • 質問。実験的機能です。エージェントの質問は、それが動いているコンピューターで「エージェントからの質問」と通知されます。サーバーの場合は、サーバーで antenna agent escalate api-dev --to mac を実行すると、質問はノート PC にあるそのエージェントのチャットに届くようになります。

通知は macOS と、通知を表示できる Linux デスクトップで使えます。ノート PC で Antenna を開いておく必要があります。ウィンドウが前面にあるときは、チャット一覧の未読数で十分に用が足ります。

セットアップ

  1. 両方のコンピューターに Antenna をインストールし、これは自分のコンピューターです（∞） にチェックを入れて一度だけペアリングします。サーバー側の手順は VPS で Claude Code を動かすで説明しています。
  2. Antenna 経由で Claude Code を起動します。サーバーでは次のとおりです。 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    2 台目のデスクトップでは エージェント → AI アプリ → Code モードで起動 です。
  3. ノート PC で設定することはありません。エージェントとのチャットは、最初からあなた宛てのメッセージと承認リクエストを通知します。

報告を頼む

api-dev のチャットにタスクを書き、何を返してほしいかも伝えます。たとえば「マイグレーションのテストを実行して、失敗したところを直して。終わったら、何を変えたかここで返信して」。Claude Code がプロンプトで待機中なら、Antenna があなたのメッセージを読ませる 1 行を入力します（実験的機能）。Claude Code は作業を終えると同じチャットで返信し、ノート PC に通知が表示されます。

ターミナルで始めた作業（antenna session attach api-dev）では、プロンプトの最後に「終わったら Antenna で概要を送って」と書き添えます。毎回そうさせたいなら、プロジェクトの CLAUDE.md に次の 1 行を加えます。「タスクを終えたら、Antenna の send_message で mac に短い概要を送ること。」

報告が届くのは、ほかの指示と同じく、Claude Code が終わったと判断したときです。ターミナルで Claude Code 自身の権限確認（「Do you want to proceed?」）で止まった場合、Antenna にはそれが見えないため、何も通知されません。いつも使うツールは Claude Code の設定で許可しておいてください。

通知するチャットを選ぶ

チャットの行の ⋮ を開くか右クリックして、通知を選びます。

  • すべてのメッセージ：このチャットの新しいメッセージすべて（人とのチャットのデフォルト）。
  • 自分が呼ばれたときだけ：あなた宛てのメッセージと承認リクエスト（エージェントとのチャットのデフォルト）。
  • オフ：承認リクエストは引き続き通知されます。

Claude Code があなたではなく、あなたの別のエージェントに報告する場合、同じメニューで エージェント間のメッセージを通知をオンにしない限り、それらのメッセージは通知されません。ターミナルでは antenna chats notify server --agent api-dev all です。

いま使っているコンピューターでは

自分のノート PC で Claude Code を Code モードで動かしている場合、ウィンドウが背面にあるあいだ、Antenna はその承認リクエストと質問を通知しますが、ターンの終わりは通知しません。エージェントは、同じコンピューターにいるあなたにメッセージを送れないからです。その用途には、Claude Code 自身のフックを使えば、止まったときに任意のコマンドを実行できます。

よくある質問

通知に Claude Code が書いた内容は表示されますか？

いいえ。通知はロック画面に表示されることもあるため、出るのはチャット名と「に新着メッセージ」だけです。報告を読むにはチャットを開いてください。

ノート PC がスリープしていたらどうなりますか？

メッセージはサーバーで待機し、ノート PC がオンラインに戻ったときに、Antenna が通知とともに届けます。

スマートフォンで通知を受け取れますか？

まだできません。現在、Antenna は macOS と Linux で動作します。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
