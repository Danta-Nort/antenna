Cursor と Claude Code を一緒に使う

Cursor をワンクリックで Antenna に接続し、Antenna のウィンドウで Claude Code を起動して、Antenna のエージェントマップで 2 つを線でつなぎます。それ以降は、どちらも Antenna の MCP ツールで相手にメッセージを送ります。Cursor のエージェントが Claude Code に変更のレビューを頼み、Claude Code が Cursor にタスクを渡し、答えは同じ経路で返ってきます。どちらもいつもどおり、あなた自身の Cursor と Claude のアカウントでサインインしたままです。

1 台のコンピューターで

  1. Antenna をインストール（macOS または Linux）してノードを作成します。必要なのはパスワード 1 つで、アカウントは要りません。
  2. Agents → AI apps を開き、Cursor の横の Connect を押します。Assistant with access to my projects（プロジェクトにアクセスできるアシスタント）を選んでパスワードを入力し、Continue を押します。Antenna が Cursor のインストールリンクを開くと知らせるので、Open Cursor を押すと、Cursor に Antenna が表示され、インストールを求められます。次に Cursor で新しいチャットを始めて「Antenna のメッセージを確認して」と頼むと、行が Connected（接続済み）に変わり、「Contacts write to it as cursor」と表示されます。連絡先からは cursor という名前でメッセージが届く、という意味です。Cursor では、MCP は有料プランの機能とされています。
  3. 同じページで、Claude Code の横の Start in Code mode を押します。New agent… を選んで reviewer と名付け、同じロールを選び、Working folder（作業フォルダー）に Cursor で開いているプロジェクトを指定してパスワードを入力し、Start を押します。Claude Code はウィンドウ内のターミナルタブで動きます。
  4. Agents → Map を開き、一方のエージェントのハンドルからもう一方へドラッグして、パスワードを入力し Connect を押します。2 つにはローカルルートが割り当てられ、メッセージはコンピューターの外に出ません。また、チェックを外さない限り、それぞれが相手のメッセージをタスクとして受け取ります。

2 つには同じロールを選んでください。Antenna は、あなたのデータをより多く見たエージェントが、それより少なく見たエージェントに書き込むことを許しません。また、書く役とレビューする役のように別々の仕事を与えれば、2 つが同じファイルを同時に編集することはありません。

互いの呼び方

線を引くと、それぞれのエージェントにとって相手がデフォルトの相手役になります。「これを相手に送って」と言えば十分です。名前で指定するときは、エージェントが local_agent に cursor または reviewer を指定して send_message を呼び出します。受け取る側は read_inbox で読むか、wait_for_message で待ちます（1 回の呼び出しで最大 10 分）。

2 つは待ち方が違います。Code モードの Claude Code は自分で目を覚まします。待機中にメッセージが届くと、Antenna が受信箱を読むよう促す 1 行を代わりに入力します（実験的機能）。Antenna が Cursor に何かを入力することはないので、Cursor のエージェントがメッセージを読むのは、次に Antenna を呼び出したときです。そのため、やり取りを始めるのは Cursor にするのが自然です。たとえば「reviewer に src/ の diff のレビューを頼んで、返事を待ってから、見つかった問題を直して」。Claude Code が目を覚まし、レビューして返信します。Cursor に作業を渡すときは、まずメッセージを待つように伝えてください。

2 台のコンピューターで

Cursor はノート PC に置いたまま、Claude Code をデスクトップやサーバーで動かすこともできます。それぞれに Antenna をインストールし、招待リンクと 6 桁のコードで一度だけペアリングします。そのとき This is my own computer (∞) にチェックを入れ、あとはマップで線を引きます。もう一方のコンピューターでは、そちら側の承認を、そのコンピューター上か My devices で求められます。画面のないサーバーでは、Claude Code を antenna connect claude-code と antenna session start で動かします。詳しくはVPS で Claude Code を動かすをご覧ください。

あなたが承認するもの、制限が残るもの

  • 接続を決めるのはあなたです。線を引くにはパスワードが必要で、エージェントが接続を作ったり変えたりすることはできません。
  • Antenna がすべてのメッセージを検査します。同じコンピューター上の 2 つのエージェントの間では、鍵、パスワード、トークンを含んでいそうなメッセージは拒否されます。また、10 分以内に 8 通のメッセージが続くとそのやり取りは止まるので、2 つが永遠に互いを忙しくさせることはできません。
  • 信頼レベルは、エージェントが読んだものについて回ります。同じコンピューター上で、一方のエージェントがある連絡先のメッセージを読んでいた場合、そのエージェントのメッセージにはその連絡先の制限が付いてもう一方に届き、受け取った側も自分で読んだのと同じように制限されます。
  • Claude Code はツールを使うたびに確認されます。Code モードでは、Antenna はすべてのコマンドと編集の前に自分のデーモンに確認します。Cursor 自身の編集とコマンドは、これまでどおり Cursor 自身の設定で管理されます。Antenna が検査するのは、Antenna を通るものです。

よくある質問

API キーは必要ですか？

いいえ。Cursor はいつもどおりあなたの Cursor アカウントで、Claude Code は Claude のプランで動きます。Antenna はメッセージを運ぶだけです。

Claude Code を Cursor のターミナルで動かすこともできますか？

はい。Step-by-step guide（手順ガイド）を AI apps にある Claude Code のメニューから開くと、claude mcp add の行が載っています。ただし、その方法で起動した Claude Code は起こされません。Code モードなら起こされ、ツールを使う前に毎回 Antenna の確認も入ります。

この機能は完成していますか？

マップでのエージェントの接続と待機中のエージェントの起動は、Antenna 0.1 では実験的機能とされています。動作し、テストもされていますが、今後変わる可能性があります。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
