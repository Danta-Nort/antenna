別のコンピューターの Claude Code にメッセージを送る

両方のコンピューターに Antenna をインストールし、一度だけ ∞ · My computer としてペアリングして、向こうの Claude Code セッションに名前を付けて Antenna に接続します。あとは Mac から、チャットの連絡先に書くようにそのセッションにメッセージを送れます。手元の Claude Code に書かせることもできます。セッションを Antenna 経由で起動しておけば、待機中でも起こされ、緊急のメッセージならターンの途中でも中断させられます。同じコンピューター上の 2 つのセッションなら、代わりにエージェントマップでつなぎましょう：2 つのエージェントを会話させる。

こんなときに

  • 長時間の作業のために Claude Code をサーバーやデスクトップで動かしていて、次のタスクをノート PC から渡したい。
  • あるセッションが計画を立て、別のセッションが実装する。それぞれが自分のマシンで動いている。
  • 複数のマシンを使っていて、マシンごとのターミナルではなく、セッションごとのチャットにまとめたい。

1. 2 台のコンピューターをペアリングする

両方に Antenna をインストールします。Mac や Linux のデスクトップにはアプリを、Linux サーバーにはサーバー用のノードを入れます（VPS で Claude Code を動かすで手順を解説しています）。片方でレベル ∞ の招待を作り、もう片方で開いて、片方に表示された 6 桁のコードをもう片方に入力します。ペアリングは人との場合と同じで、行えるのはあなただけです。両側でオーナーパスワードが必要です。

2. セッションに名前を付ける

もう一方のコンピューターの、プロジェクトフォルダーで：

antenna connect claude-code --agent api-dev --links mac --hello mac

ここで mac は、ペアリング時にサーバーがあなたの Mac に付けた名前です。これでエージェント api-dev が作られ、（あなたが了承すると）このフォルダーの Claude Code にだけ Antenna が追加され、Mac にあいさつが送られるので、Mac にはすぐに api-dev という名前のチャットが現れます。別のフォルダーのセッションには、別の名前と別のチャットが付きます。Codex も antenna connect codex で同じように使えます。

3. 起きたままにしておく

Claude Code が Antenna を読むのは、何かの作業をしている間だけです。空のプロンプトで待機しているときにもメッセージを拾わせたいなら、代わりに Antenna 経由で起動します：

antenna session start api-dev --dir ~/projects/api

（このためにはサーバーに tmux が必要です。）メッセージが届くと Antenna が空のプロンプトに短い 1 行を入力し、セッションはメッセージをデータとして読んで作業に取りかかります。デスクトップでは、Antenna の Code モードがウィンドウ内のターミナルタブで同じことをします。実験的機能です。

4. メッセージを送る

Mac で api-dev のチャットを開き、人に書くように書きます。手元の Claude Code に頼むこともできます：「api-dev にマイグレーションのテストを実行して結果を報告するよう頼んで」。待てないときは、送信前に Urgent: interrupt now（送信ボタンの横の稲妻ボタン）をオンにします（ターミナルからなら antenna send --urgent）。Code モードや antenna session start で Antenna が動かしているセッションなら、Antenna が Esc を押すのと同じように実行中のターンを一度だけ止め、セッションがあなたのメッセージを読みます。ターミナルに質問や権限の確認が表示されているときに Esc を押すことはありません。実験的機能です。

送られるもの、送られないもの

メッセージは一方のコンピューターで暗号化され、もう一方で復号されます。ターミナルを共有することはなく、ポートを開けたり転送したりする必要もありません。向こうのセッションはメッセージを受け取るだけで、それで何をしてよいかはそちらの Antenna が決めます。エージェントのトークンは、作られたコンピューターから出ません。

よくある質問

これはターミナルのリモート操作ですか？

いいえ。向こうのターミナルを見たり、そこに入力したりはしません。セッションにメッセージやタスクを送り、セッションがチャットで答えます。ターミナルそのものを使いたいときは、これまでどおり SSH を使ってください。

セッションが何をしているか確認できますか？

チャットには返信が表示され、エージェントマップには誰が誰と話したかが表示されます。My devices では、ほかのコンピューターのエージェントを確認したり、エージェントをそれが起動したすべてのものと一緒に止めたりもできます。

サーバーにグローバル IP アドレスは必要ですか？

いいえ。どちらのコンピューターも外向きに接続し、直接つながれないときはリレーが暗号化された通信を中継します。

サーバーを再起動したらどうなりますか？

再起動後は鍵がロックされます。一度ログインして antenna unlock を実行すれば、セッションを再び起動できます。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
