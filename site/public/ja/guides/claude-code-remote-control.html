別のコンピューターの Claude Code をノート PC から操作する

ノート PC と、Claude Code を動かすコンピューターの両方に Antenna をインストールし、2 台を自分のコンピューターとして一度だけペアリングして、そちらで Antenna 経由で Claude Code を起動します。するとノート PC にそのセッションとのチャットが現れます。そこにタスクを書くと、Claude Code が待機中なら Antenna が起こし、返信はチャットに戻ってきます。メッセージは 2 台のコンピューターの間をエンドツーエンド暗号化された P2P のリンクで行き来し、Antenna にアカウントは要りません。あなたの承認が必要な手順はノート PC に届き、パスワードで答えます。

Claude Code 自身の Remote Control と Antenna

Claude Code には、組み込みの Remote Control という独自の機能があり、Anthropic のドキュメントで説明されています。このガイドで扱うのは、それとは別の構成です。Claude Code は、電源の入ったままの自分のコンピューター（サーバーやデスクトップ）で動き、あなたはノート PC の Antenna からそれを操作します。次のようなことをしたい場合に向いています。

  • 複数のコンピューターの複数のセッションを、1 つのリストで。セッションごとにチャットが分かれ、自分のデバイス には各コンピューターの健全性、エージェント、そこで待っているリクエストが表示されます。
  • 自分専用のリンク。メッセージは一方のコンピューターで暗号化され、もう一方で復号されます。ネットワークが許せばコンピューター同士が直接つながり、そうでなければ暗号化された通信を転送するだけのリレーを経由します。アカウントも受信用のポートも要りません。
  • Antenna のデーモンによる権限の検査。検査は Claude Code が動くコンピューターで行われ、承認にはいま使っている自分のコンピューターから答えられます。
  • ほかのエージェントも同じように：Codex も Claude Code と同じように使えます。

セットアップ

  1. 両方のコンピューターに Antenna をインストールします。ノート PC にはアプリ（macOS または Linux）、もう一方のコンピューターにはアプリを、Linux サーバーならノードを入れます。 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
  2. 一度だけペアリングします。ノート PC で 新しい連絡先 → 招待 を開き、これは自分のコンピューターです（∞） にチェックを入れて リンクを作成 を押し、リンクをコピーします。サーバーでは antenna join '<link>' --trust 5 --label mac、デスクトップでは同じチェックを入れて 新しい連絡先 → 参加 を開きます。一方に表示されたコードをもう一方に入力し、ノート PC で 相手が確認しました — コードは一致 を押します。
  3. もう一方のコンピューターで、Antenna 経由で Claude Code を起動します。サーバーではプロジェクトフォルダーで（tmux が必要です）： 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    Claude Code の最初の質問に答えたら Ctrl-b d で抜けます。Claude Code は動き続け、ノート PC には api-dev という名前のチャットができています。デスクトップでは エージェント → AI アプリ → Code モードで起動 を押すと、そのコンピューターの Antenna のウィンドウのタブで Claude Code が動きます。一度だけ、Antenna を通じてノート PC にあいさつするよう頼むと、そのチャットがノート PC に現れます。
  4. そのコンピューターからの承認リクエストにノート PC で答えられるようにします。サーバーでは antenna devices confirm mac。デスクトップでは 自分のデバイス → ノート PC のカード → 承認 → … で署名された承認を受け付ける を開き、パスワードを入力します。

ノート PC から操作する

  • タスクを渡す。人に頼むように、セッションのチャットに書きます。Claude Code がプロンプトで待機していると、Antenna が組み込みの 1 行を入力してあなたのメッセージを読ませます。あなたのテキストをターミナルに入力することも、Claude Code がそこで尋ねた質問に答えることもありません。実験的機能です。
  • 中断する。送信する前に 緊急: 今すぐ中断 をオンにします。Antenna が Esc を 1 回押して実行中のターンを終わらせ（そこで質問や権限確認が開いているときは押しません）、Claude Code があなたのメッセージを読みます。実験的機能です。
  • 手順を承認する。あなたの判断が必要な手順は、自分のデバイス にあるもう一方のコンピューターのカードに、通知付きで表示されます。パスワードで承認、Mac なら Touch ID で承認、または 拒否 を押します。実験的機能です。
  • 止める。そのカードのエージェントの横にある エージェントとそのプロセスを停止… を押すと、Claude Code と、それがそのコンピューターで起動したものがすべて終了します。実験的機能です。

Claude Code 自身の権限確認（「Do you want to proceed?」）は、もう一方のコンピューターのターミナルに残り、Antenna がそれに答えることはありません。いつも使うツールは Claude Code の設定で許可しておくか、antenna session attach で入って答えてください。

Codex やほかのエージェント

Codex も同じように使えます。サーバーでは antenna connect codex と --cli codex、デスクトップでは Codex の横の Code モードで起動 です（Codex CLI をリモート操作するを参照）。Gemini CLI は エージェント → AI アプリ から接続して Antenna でメッセージを送受信できますが、Antenna はまだ Gemini CLI を起こせません。新しいメッセージは、次に Antenna を呼び出したときに読みます。

よくある質問

ノート PC で Claude Code のターミナルが見えますか？

いいえ。タスクを渡すのも返信を読むのもチャットで、ターミナルはもう一方のコンピューターに残ります。見たいときは、そちらで antenna session attach を実行してください。SSH 経由でもかまいません。

もう一方のコンピューターにグローバル IP やポート開放は必要ですか？

いいえ。どちらのコンピューターも外向きに接続します。ネットワークが許せば直接、そうでなければリレーを経由し、リレーは暗号化された通信を転送するだけです。

ほかに誰がタスクを渡せますか？

そのコンピューターとペアリングした連絡先のうち、エージェントがメッセージを読んでよい相手（--links mac ならノート PC だけ）と、エージェントマップでそのエージェントとつないだエージェントだけです。連絡先のメッセージで何をさせてよいかは、Claude Code ではなく、そのコンピューターの Antenna のデーモンが、その連絡先の信頼レベルに応じて決めます。

API キーは必要ですか？

いいえ。Claude Code は動いているコンピューターで、あなた自身のサインインのまま使われます。Antenna が運ぶのはメッセージ、ファイル、承認だけです。

スマートフォンから操作できますか？

まだできません。現在、Antenna は macOS と Linux で動作します。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
