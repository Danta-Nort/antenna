メッセージに返信する AI エージェントを設定する

Antenna では、連絡先とエージェント（Claude Code、Codex、または自作のコマンド）を選んでおくと、それ以降その連絡先からメッセージが届くたびにエージェントが起動し、メッセージを読んで返信します。エージェントはサンドボックス内で、その連絡先の信頼レベルを超えない権限で動き、返信は書かれていくそばから相手の画面に表示されます。使うのはあなた自身の Claude や ChatGPT のサインインで、秘密情報を含んでいそうな返信はあなたの承認待ちになります。

主な使い方

  • サーバー上の自分専用アシスタント。ノート PC からサーバーにメッセージを送ると、そこで Claude Code が返事をし、プロジェクトのビルドやテストを実行します。
  • 連絡先向けの受付窓口。同僚からのプロジェクトに関する質問に、その会話のフォルダーしか見えないエージェントがすぐに答えます。
  • 結果を報告するスクリプト。どんなプログラムの出力でもライブストリームとして送れます：my-program | antenna send --stream <contact>。

ウィンドウで設定する

  1. エージェントを動かしたいコンピューターで、Agents → Set up for a contact… を開きます（会話の中からなら、連絡先カードの Agent replies → Set up…）。
  2. 連絡先とプログラムを選びます：Claude Code、Codex、または自作のコマンド。
  3. 必要に応じて、長期間有効なサインイントークン（claude setup-token で取得）を Value (optional) に貼り付けます。トークンは一度だけノードに送られ、暗号化されたデータベースに保存されます。Mac ではサンドボックスからキーチェーンを開けないため、これが確実な方法です。
  4. オーナーパスワードで確定します。ルール、最後の実行、Run log（実行ログ）が Agents に表示されます。

ターミナルからなら 1 行です：antenna wake set <contact> --cmd "claude -p --output-format stream-json"。antenna wake list でルールと最近の実行を確認でき、antenna wake off <contact> で無効にできます。

エージェントにできること、できないこと

  • プロンプトは固定です：「新しいメッセージが届いています。読んで返信してください」。メッセージそのものがプロンプトになることはなく、エージェントはそれをデータとして、連絡先の信頼レベルを超えない権限で読みます。
  • サンドボックス内で動きます（Linux では bubblewrap または Landlock、macOS では Seatbelt）。見えるのは自分用の一時フォルダーとその会話のフォルダーだけで、通信できるのはモデルのプロバイダーだけです。あなたのプロジェクト、そのほかのファイル、ノードの鍵には手が届きません。サンドボックスが使えなければ、Antenna はエージェントを起動しません。
  • 毎回まっさらな状態で始まります。エージェントを常駐させない限り（後述）、以前のメッセージが後の実行に指示を残すことはできません。
  • 制限：1 回の実行あたりの時間制限と、1 時間あたりの実行回数の上限があるため、よくしゃべる相手のせいで利用枠を使い果たすことはありません。

自分のプロジェクトで作業させる

自分のコンピューター（∞）に限り、エージェントがあなたのツールチェーンを使って 1 つのプロジェクトフォルダーで作業することもできます：--project ~/code/payments に加え、読み取り専用の --tool-path フォルダーと、--allow-host で接続を許すパッケージレジストリを指定します。ほかの連絡先に対しては Antenna はこれを拒否し、ホームフォルダー、Antenna 自身のデータ、~/.ssh のような秘密情報を含むフォルダーを開くことは決してありません。

よくある質問

相手には返信が入力されていく様子が見えますか？

はい、レベル 3 以上の連絡先には見えます。エージェントが書くにつれて大きくなるライブの吹き出しが表示され、最後に通常のメッセージになります。レベル 1 と 2 の相手には完成した返信が届きます。

エージェントが返信にパスワードや鍵を書いてしまったら？

相手へのストリームは止まり、メッセージはあなたの承認待ちになります。そのまま送られ続けるのは、自分のコンピューター宛ての場合だけです。

以前の会話を覚えていますか？

デフォルトでは覚えていません。メッセージごとに新しい実行が始まります。何時間も続く作業には --resident を付けてください。同じ Claude Code のセッションがその会話に付き添い、話したことや決めたことを保ったまま、新しいメッセージを次のターンとして受け取ります。その場合も、メッセージは相手から届いたデータとして扱われます。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
