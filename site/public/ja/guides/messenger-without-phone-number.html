電話番号もメールアドレスも要らないプライベートなメッセンジャー

Antenna は macOS と Linux 向けの無料・オープンソースのメッセンジャーで、電話番号もメールアドレスもアカウントも求めません。あなたの ID は自分のコンピューター上で作られる鍵で、あなただけが知るパスワードで保護されます。相手を追加するには、1 回限りの招待リンクを送り、6 桁のコードを声や対面で照合します。そのため、誰かがあなたの番号であなたを探し出すことはできず、どのサーバーもあなたの会話を読んだり結び付けたりできません。

メッセンジャーが電話番号を求める理由

電話番号は連絡先を見つけたりスパムを防いだりするのに手軽な手段で、だからこそ多くのメッセンジャーが番号を必要とします。しかし番号はあなたの名前や通信キャリア、多くの場合は住所とも結び付いていて、番号を知っている人なら誰でもあなたを調べられます。番号を渡したくないなら、別の方法で相手を見つけるメッセンジャーが必要です。

Antenna の始め方

  1. Antenna をダウンロードして開きます。
  2. パスワードを決めます。このパスワードはこのコンピューター上の鍵を保護するもので、復元できないので大切に保管してください。
  3. 登録はこれで終わりです。サーバー上のプロフィールはありません。プロフィールを保管するサーバーがそもそもないからです。

相手の追加方法

New contact → Invite を押し、相手をどの程度信頼するかを選んで、好きな方法でリンクを送ります。相手がそれを開くと、あなたの画面に 6 桁のコード（または 6 匹の動物）が表示されます。通話や対面でそれを相手に読み上げ、相手が入力すると、Antenna が照合します。一致すれば、間に誰もいなかったということです。リンクは 1 回だけ、しかも選んだ時間内しか使えないので、後から漏れたリンクは役に立たず、途中でリンクを盗み見た人もコードはわかりません。

アカウントの代わりに得られるもの

  • 連絡先ごとに独立したリンク。会話ごとに専用の鍵があり、耐量子の保護付きでエンドツーエンド暗号化されます。
  • 信頼レベル。テキストのみの 1 からパートナー向けの 4 まで、自分のコンピューターには ∞。レベルによって、相手があなたに送れるもの、あなたがオンラインかどうかが相手に見えるか、相手にあなたの IP アドレスが見えるかが決まります。レベル 1 と 2 は常にリレーを経由します。
  • 確認できる履歴。メッセージは署名されてつながっており、双方がコピーを照合するので、変更されたメッセージや消えたメッセージがあればわかります。
  • エージェントも歓迎。Claude Code や ChatGPT のような AI アシスタントが、自分の名前で、あなたが与えた権限だけを持ってチャットに参加できます。

よくある質問

スマートフォンアプリはありますか？

まだありません。Antenna 0.1 はコンピューター向けで、Apple Silicon の macOS と Linux に対応しています。

パスワードを忘れたら？

復元はできません。あなたの鍵のコピーをほかの誰も持っていないことこそが要点だからです。その場合はノードを作り直し、連絡先をもう一度招待することになります。

誰かに検索で見つけられることはありますか？

いいえ。ディレクトリはありません。相手があなたに届くのは、どちらかがもう一方に渡した招待リンクを通じてだけです。

無料ですか？

はい。AGPL-3.0 のオープンソースです。プロトコルは Apache-2.0 で公開されています。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
