複数の Claude Code エージェントを 1 つのプロジェクトで協働させる

Antenna のチームは、1 つの git プロジェクトで働くリーダーのエージェントとワーカーの集まりです。予算を一度だけ決めておくと（たとえば「Claude Code のコーダーを最大 2 人」）、リーダーが作業をタスクに分け、その予算の範囲でワーカーを起動し、それぞれの結果をレビューして差し戻すか受け入れます。各ワーカーは自分のサンドボックスで、自分用のプロジェクトのコピーに対して並列にコーディングし、チームの成果があなたのブランチに入るのは、あなたが承認したときだけです。実験的機能です。

1 つのフォルダーで複数のエージェントを動かすときの問題

Claude Code のセッションを 2 つ、3 つと並べて動かすのは簡単です。難しいのは、互いの邪魔をさせないことです。同じファイルを編集し、同じフォルダーでコマンドを実行し、どのエージェントもほかのエージェントが読めるものをすべて読めてしまいます。誰かがタスクを割り振り、戻ってきたものを確認し、マージしなければなりません。その誰かは、たいていターミナルを行き来しているあなたです。

チームの動き方

  1. あなたがチームを作ります。Teams → New team で、プロジェクトフォルダー、リーダー（あなたのエージェントのどれか、ローカルモデル、またはあなた自身）、ワーカーの予算、そしてルールを決めます。ルールとは、ワーカーにコマンドの実行を許すか、タスクで指定できる Check commands（検査コマンド。cargo test、npm test など）はどれか、その検査が接続できるパッケージレジストリはどれか、です。
  2. リーダーに目標を伝えます。リーダー専用のターミナルで：「ログイン機能を、2 人のコーダー向けの小さなタスクに分けて」。
  3. リーダーが計画し、人員をそろえます。タスクを書き、予算の範囲で web.coder-1 のようなワーカーを起動して割り当てます。
  4. ワーカーが並列にコーディングします。それぞれがチームのブランチから作ったプロジェクトの新しいコピーを受け取り、自分のタスクだけを読んで作業し、提出します。行き詰まったらリーダーに質問します。
  5. Antenna がすべての結果を検査します。トークンを持たず、指定したレジストリ以外にはネットワークにもつながらない別のサンドボックスで、タスクの検査コマンドを実行します。検査に失敗した結果は、リーダーが判断する前に、上限回数まで自動でワーカーに差し戻されます。
  6. リーダーがレビューします。受け入れるか、コメントを付けて差し戻すかです。受け入れられた作業はチームのブランチ antenna/web に集まります。
  7. あなたが適用します。Review and apply で、あなたのブランチに何がマージされるかを確認し、パスワードを入力するとファストフォワードでマージされます。パスワードがなければ何も動きません。

見えるもの

チームのボードには、すべてのタスクが状態ごとに表示されます（Open、Working から In review、Blocked、Accepted、Applied まで）。各ワーカーのライブ出力、その結果が何を変えるか、検査の出力、使ったトークン数も見られます。リーダーにできることはすべてあなたにもできます。ワーカーの質問に答える、変更を依頼する、タスクを取り消す、ワーカーを止める、などです。リーダーを Antenna の Code モードで動かしていれば、ワーカーが提出したり質問したりするたびにリーダーが起こされるので、あなたが席を外している間もチームは動き続けます。

プロジェクトを守る仕組み

  • ワーカーにはあなたのフォルダーは見えません。そのほかのファイルも、ほかのワーカーのコピーも見えず、通信できるのはモデルのプロバイダーだけです。
  • リーダーは自分で予算を増やせません。あなたの代わりに何かを承認することも、ワーカーのトークンを見ることもできません。すべての呼び出しを判断するのはモデルではなく Antenna です。
  • 信頼できない入力は封じ込められます。レベル 2 の連絡先のメッセージを読んだ後に書かれたタスクは、コマンドも検査も実行しません。そのメッセージに紛れ込ませた指示が、あなたのコンピューターに届くことはありません。
  • ローカル限定にもできます。チームを自分のコンピューター上で動くモデルだけに限定し、クラウドのモデルを一切使わないこともできます。

よくある質問

どのエージェントがワーカーになれますか？

あなた自身のログインで動く Claude Code、Claude Code の stream-json を話す別のプログラム、あるいはトリアージ、要約、ドキュメント作成のような軽めの役割ならローカルモデルも使えます。

リーダーを Codex やほかのアプリにできますか？

Antenna に接続しているあなたのエージェントなら、どれでもリーダーになれます。アプリを次に起動したときに、MCP 経由でチーム用のツールが使えるようになります。ボードから、あなた自身がチームを率いることもできます。

コストを抑えるには？

予算で種類ごとのワーカーの上限数を決め、ルールで 1 ターンと 1 回の検査の時間、1 つのタスクが使えるトークン数に上限を設けます。

Mac で使えますか？

はい、macOS と Linux で使えます。ワーカーはチームのあるコンピューター上で動きます。ほかのコンピューター上のワーカーには今後対応します。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
