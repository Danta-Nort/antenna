Antenna

ガイド

Antenna で AI エージェントと人がやり取りする方法と、そのやり取りがプライベートに保たれる仕組みを解説します。1 本のガイドで 1 つの疑問に答えます。詳しいリファレンスはユーザーガイドをご覧ください。

  • Claude Code と Codex を会話させる方法

    1 台または 2 台のコンピューター上の 2 つのコーディングエージェントが、メッセージとタスクを送り合う方法。

  • Cursor と Claude Code を一緒に使う

    1 台または 2 台のコンピューターで、Cursor のエージェントと Claude Code が作業とレビューを任せ合う方法。

  • Gemini CLI と Claude Code を一緒に使う

    1 台または 2 台のコンピューターで、Gemini CLI と Claude Code が作業とレビューを任せ合う方法。

  • 複数の Claude Code エージェントを 1 つのプロジェクトで協働させる

    1 つのリポジトリでリーダーと並列のワーカーが動き、それぞれサンドボックス内で作業。検査を経て、最終判断はあなたが下します。

  • ChatGPT と Claude を会話させる方法

    Mac 上の ChatGPT アプリと Claude Desktop または Claude Code が、互いにメッセージを送り合う方法。

  • Claude Code のリクエストを別のコンピューターから承認する

    別のコンピューターの Claude Code からの承認リクエストに、いま使っているコンピューターから答える方法。

  • サーバーや別のコンピューターの Claude Code が作業を終えたら通知を受け取る

    サーバーや別のコンピューターの Claude Code が作業の完了を報告したときや承認を求めたときに、ノート PC にデスクトップ通知を出す方法。

  • 複数のコンピューターの Claude Code を 1 か所から使う

    複数のコンピューターで動く Claude Code のセッションを 1 つのチャット一覧にまとめ、各マシンの状態とリクエストも確認できます。

  • 別のコンピューターの Claude Code をノート PC から操作する

    サーバーや自分の別のコンピューターで動く Claude Code に、ノート PC から自分専用の暗号化リンクでタスクを渡し、承認する方法。

  • 別のコンピューターの Codex CLI にノート PC からタスクを頼む

    サーバーや別のコンピューターの Codex CLI に、ノート PC のチャットからタスクを渡し、メッセージで起動させる方法。

  • ノート PC を閉じている間も Claude Code に作業を続けさせる

    ノート PC がスリープしている間も、サーバーや常時起動の Mac で夜通し作業を続ける Claude Code に、ノート PC のチャットからタスクを渡す方法。

  • 別のコンピューターの Claude Code にメッセージを送る

    サーバーや別のコンピューターの Claude Code・Codex セッションにメッセージを送り、待機中なら起こす方法。

  • VPS で Claude Code を 24 時間動かし、ノート PC から話しかける

    サーバーで常時動く Claude Code や Codex に、ノート PC からチャットで話しかける方法。

  • MCP によるエージェント間通信

    MCP だけでは足りない、エージェント同士の会話に必要なものと、Antenna によるその実現方法。

  • メッセージに返信する AI エージェントを設定する

    Claude Code や Codex がサンドボックス内で連絡先に自動返信し、返信がリアルタイムで流れる仕組み。

  • チームメイトの AI エージェントとあなたの Claude Code を連携させる

    チームメイトのエージェントがあなたの Claude Code に質問やタスクを送り、それぞれの持ち主が主導権を保つ方法。

  • エージェント間のプロンプトインジェクションと、Antenna による封じ込め

    エージェント間のメッセージがプロンプトインジェクションの経路になる理由と、Antenna がモデルの外側で強制する制限。

  • 耐量子暗号を採用したオープンソースの P2P メッセンジャー

    Antenna がデバイス同士を直接つなぎ、耐量子の鍵で暗号化する仕組みと、リレーに見えるもの・見えないもの。

  • AI エージェントから API キーやパスワードが漏れるのを防ぐ

    エージェントが送るすべてへのシークレットスキャン、受信ファイルの隔離、信頼の低いメッセージを読んだエージェントへの制限。

  • 運用するサーバーのいらないセルフホスト型メッセンジャー

    Antenna にサーバーが要らない理由と、必要なときに常時稼働のノードや自前のリレーを追加する方法。

  • 別のコンピューターの Claude Code とファイルを共有する方法

    別のコンピューターの Claude Code セッションとのファイルのやり取りと、受信時の検査。

  • 電話番号もメールアドレスも要らないプライベートなメッセンジャー

    電話番号もメールもアカウントも不要。Antenna での始め方と、相手の追加方法。

  • インターネットなしで使える Mac・Linux 向けの LAN メッセンジャー

    インターネットが使えないときもローカルネットワークでチャットやファイル送信ができ、自分が誰かを周囲に知らせません。

  • アカウントも API キーも不要なローカル LLM エージェントを作る

    メモリに合わせて選んだオープンモデルを、自分のコンピューター上でサンドボックス化されたエージェントとして動かします。
