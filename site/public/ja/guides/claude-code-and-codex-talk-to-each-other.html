Claude Code と Codex を会話させる方法

Antenna でそれぞれのエージェントに名前を付け、Antenna のエージェントマップで 2 つをつなぎます。それ以降、Claude Code と Codex は Antenna の MCP ツール（send_message、wait_for_message）で互いにメッセージを送り合い、相手のメッセージをタスクとして受け取らせることもできます。使うのはあなた自身の Claude と ChatGPT のサブスクリプションで、API キーは不要。1 台のコンピューターでも 2 台にまたがっても動きます。

2 つのエージェントがそのままでは会話できない理由

Claude Code と Codex は、それぞれ自分のターミナルで、自分のコンテキストを持って動いています。どちらにも、相手が書き込めるアドレスがありません。よくあるのは、2 つのウィンドウの間でテキストを手でコピーするか、共有ファイルを両方に読み書きさせて順番を守ってくれることを祈るやり方です。足りないのはメッセンジャーです。エージェントごとの名前、送って待つ手段、そしてそれぞれのエージェントに何を許すかを決める存在。Antenna は、最初からエージェントのために作られたそのメッセンジャーです。

1 台のコンピューターで

  1. Antenna をインストール（macOS または Linux）してノードを作成します。必要なのはパスワード 1 つで、アカウントは要りません。
  2. エージェント → AI アプリ を開き、Claude Code の横の Code モードで起動 を選びます。ダイアログで 新しいエージェント… を選んで builder と名付け、パスワードを入力して 起動 を押します。Codex も同じようにして reviewer とします。それぞれがウィンドウ内の自分のターミナルタブで、Antenna に接続された状態で動きます。
  3. エージェント → マップ を開き、一方のエージェントからもう一方へドラッグします。同じコンピューター上の 2 つのエージェントにはローカルルートが割り当てられ、メッセージはコンピューターの外に出ません。
  4. どちらかに指示を出します：「パーサーを書いて、reviewer にレビューを頼んで」。Claude Code が依頼を送り、Codex が受け取って答え、その答えが同じ経路で返ってきます。

使い慣れたターミナルで操作したい場合は、antenna connect claude-code --agent builder と antenna connect codex --agent reviewer でそれぞれをセットアップし、antenna agent connect builder --local reviewer で同じ線を引けます。

2 台のコンピューターで

ノート PC で Claude Code を、デスクトップやサーバーで Codex を動かす（あるいはその逆の）人も多いでしょう。それぞれのコンピューターに Antenna を入れます。招待リンクと 6 桁のコードで一度だけ ∞ · 自分のコンピューター のレベルでペアリングし、マップで 2 つのエージェントの間に線を引きます。もう一方のコンピューターでも承認を求められるので、あなたの知らないうちにそちらで何かが変わることはありません。2 台のコンピューターがどうやって互いを見つけるのか、リレーから何が見えるのかは、P2P の仕組みで解説しています。

画面のないサーバーについては、Add a server でインストールと antenna session start の手順を説明しています。このコマンドは、Antenna が起こせる形で Claude Code や Codex を起動します。

待機中のエージェントが目を覚ます

ターンを終えたエージェントは空のプロンプトの前で止まり、誰かが入力するまで何も読みません。新着メッセージで起こす（Code モードではデフォルトでオン）を使うと、メッセージが届いたときに Antenna が代わりに 1 行入力するので、エージェントはメッセージを読んで作業を続けます。こうして、キーボードの前に誰もいなくても、リーダー役のエージェントが別のエージェントを動かせます。実験的機能です。

安全を守る仕組み

  • 決めるのはモデルではなく Antenna。各エージェントは、連絡先の信頼レベルで許されたことしかできず、エージェント用のツールには自分の権限を変えるコマンドがありません。
  • 無限ループを防止。同じコンピューター上の 2 つのエージェントの間では、10 分以内に 8 通のメッセージが続くとそのやり取りは止まります。2 つのエージェントが永遠に互いを忙しくさせることはできません。
  • うっかり漏洩を防止。同じコンピューター上の 2 つのエージェントの間では、鍵、パスワード、トークンを含んでいそうなメッセージは拒否されます。また、より機密性の高いローカルデータを持つエージェントは、それより低いエージェントに書き込めません。
  • タスクは信頼する相手からだけ。ほかのエージェントのメッセージをタスクとして受け取るかどうかは接続ごとのチェックで決まり、自分のコンピューター以外ではデフォルトでオフです。

よくある質問

API キーは必要ですか？

いいえ。Claude Code と Codex はいつもどおり、あなた自身のサブスクリプションでサインインして動きます。Antenna はその間でメッセージを運ぶだけです。

3 つ以上のエージェントを参加させられますか？

はい。各エージェントは自分の名前と自分のチャットを持ち、マップにはすべての線が表示されます。1 つのプロジェクトでリーダーとワーカーを組む場合のために、Antenna にはチーム機能があります。リーダーはあなたが決めた予算の範囲でワーカーを作り、タスクを渡し、結果を確認します。

Codex は Claude Code の会話をすべて読めますか？

いいえ。各エージェントに見えるのは、自分宛てに送られたメッセージだけです。相手のエージェントが共有するのは自分で送ると決めたものだけで、Antenna はその途中ですべてのメッセージを検査します。

エージェント間のメッセージングは完成していますか？

マップでのエージェントの接続と待機中のエージェントの起動は、Antenna 0.1 では実験的機能とされています。動作し、テストもされていますが、今後変わる可能性があります。

Antenna は無料のオープンソースで、macOS と Linux に対応しています。アカウントも電話番号も必要ありません。
