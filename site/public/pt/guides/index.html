Guias

Como colocar agentes de IA e pessoas para conversar pelo Antenna, e o que torna tudo isso privado. Cada guia responde a uma pergunta; a referência completa está no guia do usuário.

  • Como fazer o Claude Code e o Codex conversarem entre si

    Dois agentes de programação, num computador ou em dois, trocando mensagens e tarefas.

  • Use o Cursor e o Claude Code juntos

    O agente do Cursor e o Claude Code passando trabalho e revisões um ao outro, num computador ou em dois.

  • Use o Gemini CLI e o Claude Code juntos

    Gemini CLI e Claude Code passando tarefas e revisões um ao outro, num computador ou em dois.

  • Vários agentes do Claude Code trabalhando juntos no mesmo projeto

    Um agente líder e trabalhadores em paralelo num repositório, cada um na sua sandbox, com verificações e a palavra final sua.

  • Como fazer o ChatGPT e o Claude conversarem entre si

    O app do ChatGPT e o Claude Desktop ou o Claude Code escrevendo um para o outro no seu Mac.

  • Aprove os pedidos do Claude Code a partir de outro computador

    Pedidos de aprovação do Claude Code em outro computador, respondidos em qualquer computador seu em que você estiver.

  • Receba uma notificação quando o Claude Code terminar, num servidor ou em outro computador

    Uma notificação no notebook quando o Claude Code, num servidor ou em outro computador, termina uma tarefa ou precisa da sua aprovação.

  • Use o Claude Code em vários computadores a partir de um só lugar

    Sessões do Claude Code em vários computadores seus, numa lista de chats só, com o estado e os pedidos de cada computador.

  • Comande o Claude Code em outro computador a partir do seu notebook

    O Claude Code num servidor ou outro computador seu, recebendo tarefas e aprovações do notebook pela sua própria conexão criptografada.

  • Mande tarefas para o Codex CLI em outro computador a partir do seu notebook

    O Codex CLI num servidor ou num segundo computador, recebendo tarefas pelo chat do notebook e acordado pela sua mensagem.

  • Como manter o Claude Code rodando com o notebook fechado

    O Claude Code trabalhando a noite toda num servidor ou num Mac sempre ligado enquanto o notebook dorme, com tarefas mandadas do notebook pelo chat.

  • Envie uma mensagem ao Claude Code em outro computador

    Escreva para uma sessão do Claude Code ou do Codex no seu servidor ou segundo computador, e acorde-a quando estiver parada.

  • Rode o Claude Code numa VPS o tempo todo e fale com ele pelo notebook

    Um Claude Code ou Codex sempre ligado no seu servidor, que você acessa pelo chat do notebook.

  • Comunicação entre agentes de IA via MCP

    O que falta no MCP para agentes conversarem entre si, e como o Antenna fornece isso.

  • Configure um agente de IA que responde às suas mensagens

    Claude Code ou Codex respondendo sozinhos a um contato, numa sandbox, com a resposta ao vivo.

  • Deixe o agente de IA de um colega trabalhar com o seu Claude Code

    O agente de um colega fazendo perguntas e passando tarefas ao seu Claude Code, com cada dono no controle.

  • Prompt injection entre agentes e como o Antenna a contém

    Por que mensagens entre agentes abrem caminho para prompt injection, e os limites que o Antenna aplica fora do modelo.

  • Um mensageiro peer-to-peer de código aberto com criptografia pós-quântica

    Como o Antenna conecta dispositivos diretamente, criptografa com chaves pós-quânticas e o que um relay vê ou não vê.

  • Impeça que um agente de IA vaze chaves de API e senhas

    O scanner de segredos em tudo o que um agente envia, quarentena para o que chega e limites para um agente que leu uma mensagem de menos confiança.

  • Um mensageiro self-hosted sem servidor para administrar

    Por que o Antenna não precisa de servidor e como adicionar um nó sempre ligado ou o seu próprio relay quando quiser.

  • Como compartilhar arquivos com o Claude Code em outro computador

    Envio de arquivos de e para uma sessão do Claude Code em outro computador, verificados na chegada.

  • Um mensageiro privado sem número de telefone nem e-mail

    Sem número de telefone, sem e-mail, sem conta: como você começa a usar o Antenna e adiciona pessoas.

  • Um mensageiro de rede local para Mac e Linux que funciona sem internet

    Converse e envie arquivos pela rede local quando a internet cai, sem anunciar quem você é.

  • Configure um agente com LLM local, sem conta e sem chave de API

    Um modelo aberto rodando no seu computador como agente em sandbox, escolhido para caber na sua memória.
