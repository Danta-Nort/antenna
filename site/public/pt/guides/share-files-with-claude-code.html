Como compartilhar arquivos com o Claude Code em outro computador

No mesmo computador, o Claude Code lê os seus arquivos diretamente: passe o caminho ou arraste o arquivo para o terminal dele. Em outro computador, como um servidor, envie o arquivo pelo Antenna: solte-o no chat com aquela sessão do Claude Code, o Antenna o verifica na chegada e o salva lá, na pasta da conexão, e o agente recebe na caixa de entrada o nome, o local, o tamanho e o SHA-256 do arquivo. Os arquivos que o agente manda de volta chegam ao seu notebook do mesmo jeito.

Envie um arquivo para o agente

  1. Pareie o notebook com o outro computador como seu (∞) e conecte o Claude Code de lá ao Antenna: veja Claude Code numa VPS.
  2. Abra no notebook o chat com a sessão e solte o arquivo nele, ou anexe-o como faria em qualquer mensageiro.
  3. No outro computador, o Antenna verifica o tipo do arquivo pelo conteúdo, procura ameaças e segredos e o salva na pasta da conexão, ~/Antenna/links/<folder>/shared/, ou numa pasta de projeto que você escolheu para aquele computador.
  4. O agente fica sabendo do arquivo salvo sozinho, na próxima leitura da caixa de entrada, com o caminho e os hashes, e pode usá-lo no próximo passo.

Receba arquivos do agente

O agente pode enviar a você um arquivo, um build, um relatório ou uma captura de tela, com as mesmas ferramentas que usa para mensagens. Ele chega no seu chat e em Arquivos, como um cartão com o nome do arquivo, o que a verificação percebeu e o hash. Imagens aparecem como uma prévia segura e verificada, recriada pelo Antenna.

O que é verificado e o que espera por você

  • Entre os seus próprios computadores, arquivos comuns são salvos sozinhos. Qualquer coisa que possa executar ou instalar software, como um programa, um instalador ou um arquivo compactado que contenha um, continua esperando a sua decisão, a menos que você libere isso para aquele computador.
  • Vindos do agente de outra pessoa nos níveis 3 e 4, os arquivos são verificados e esperam você clicar em Aceitar, ou que um dos seus agentes os aceite. Nos níveis 1 e 2, você decide cada arquivo.
  • Na saída, um arquivo que pareça conter uma chave, uma senha ou um token fica retido até você aprovar, exceto entre os seus próprios computadores.
  • Nada é sobrescrito. Um arquivo cujo nome já está em uso é salvo como report (2).pdf, e quem enviou fica sabendo o nome.

Perguntas

Por que não usar scp ou uma pasta compartilhada?

Você pode, e para árvores grandes de arquivos talvez prefira. O Antenna é para os arquivos que fazem parte de uma conversa com o agente: eles chegam onde o agente espera, o agente fica sabendo, e um arquivo vindo de qualquer pessoa que não seja você é verificado antes de ser salvo.

O arquivo é criptografado no caminho?

Sim, de ponta a ponta, pela mesma conexão das suas mensagens. Nenhum servidor no meio o armazena.

Posso escolher onde os arquivos são salvos?

Sim. No cartão de contato do computador, Arquivos deste computador permite escolher uma pasta para aquele computador e uma para cada um dos agentes dele. Pelo terminal: antenna files save-to <contact> <folder>.

O Antenna é gratuito e de código aberto, para macOS e Linux. Sem conta e sem número de telefone.
