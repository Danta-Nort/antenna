Use o Claude Code em vários computadores a partir de um só lugar

Deixe o Claude Code rodar onde o trabalho está, no notebook, num desktop e num servidor, e instale o Antenna em cada um deles. Pareie os computadores uma vez como seus (∞). A partir de qualquer um deles, você vê todas as sessões numa única lista de chats, escreve para qualquer uma pelo nome, responde aos pedidos de aprovação e para uma sessão que saiu do controle, sem abrir um terminal naquela máquina. O Codex funciona do mesmo jeito.

O que você ganha

  • Um chat por sessão, seja qual for o computador em que ela roda. Uma sessão no servidor e outra no desktop ficam na mesma lista que os seus contatos.
  • My devices (meus dispositivos): um cartão para cada computador seu, com o sistema e a versão do Antenna, o estado de saúde segundo as próprias verificações dele, os agentes e se cada um está conectado, e os pedidos que esperam por você lá.
  • Aprovações de onde você estiver. Um pedido de um agente no servidor pode ser aprovado no seu Mac, com Touch ID ou com a senha do Mac. O servidor confere a assinatura e executa o pedido por conta própria.
  • Um botão de parar para cada agente em outro computador: ele para o agente e todos os processos que ele iniciou lá.
  • O mapa de agentes, onde você liga uma sessão de um computador a uma sessão de outro, para que elas escrevam uma para a outra.

Configure

  1. Instale o Antenna em cada computador: o app num Mac ou num desktop Linux, o nó num servidor Linux (curl -fsSL https://antenna.contact/install.sh | sh).
  2. Pareie os computadores entre si como seus. Crie um convite com This is my own computer (∞) (este é o meu próprio computador) marcado, abra-o no outro computador e digite em um lado o código que o outro mostra. Pareie cada computador com todos os outros que você quer ver ou conectar a partir dele: cada um precisa ter o outro em ∞.
  3. Dê um nome a cada sessão do Claude Code. Num desktop, inicie-a em Code mode pelo + do painel de agentes. Num servidor, na pasta do projeto, rode antenna connect claude-code --agent api-dev --links mac --hello mac e mantenha-a rodando com antenna session start api-dev --dir ~/projects/api; o guia Claude Code numa VPS tem todos os passos.
  4. Deixe o seu computador principal responder aos pedidos. No servidor, rode antenna devices confirm mac uma vez; num desktop, aceite a chave do computador principal em My devices → o cartão dele → Approvals.

Passando trabalho de um computador para outro

Escreva para uma sessão como escreveria para uma pessoa: “api-dev, rode as migrations no servidor e me diga o que mudou.” Os arquivos que você solta no chat dela são salvos naquele computador, e o agente fica sabendo onde estão; entre os seus próprios computadores, arquivos comuns são salvos sem perguntar, enquanto programas e instaladores continuam esperando por você. Para deixar uma sessão do desktop passar trabalho para uma do servidor, ligue as duas no mapa de agentes. Uma sessão lá acorda quando chega uma mensagem, e uma mensagem urgente pode interromper o turno atual. Experimental.

Perguntas

O Antenna sincroniza as configurações ou o histórico do Claude Code entre computadores?

Não. O Claude Code mantém as configurações, o histórico e o login em cada computador, e o seu código circula como já circula hoje, com git. O Antenna leva mensagens, arquivos e aprovações entre as sessões.

Preciso de IP público ou de portas abertas no servidor?

Não. Todo computador se conecta para fora, diretamente quando a rede permite e por um relay quando não, e o relay só repassa tráfego criptografado.

Posso mudar uma configuração de outro computador daqui?

Não. Só aprovações, comandos de parar e pedidos de conexão vindos do mapa de agentes, que aquele computador pede para você aprovar, circulam entre os seus computadores. Confiança, convites, atualizações e configurações são alterados no próprio computador, então um notebook roubado não consegue reescrever as regras do servidor.

Funciona no Windows ou no celular?

Ainda não. Hoje o Antenna roda no macOS e no Linux.

O Antenna é gratuito e de código aberto, para macOS e Linux. Sem conta e sem número de telefone.
