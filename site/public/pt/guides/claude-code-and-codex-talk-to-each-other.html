Como fazer o Claude Code e o Codex conversarem entre si

Dê a cada agente o seu próprio nome no Antenna e ligue os dois no mapa de agentes do Antenna. A partir daí, o Claude Code e o Codex trocam mensagens com as ferramentas MCP do Antenna (send_message, wait_for_message), e você pode deixar cada um aceitar as mensagens do outro como tarefas. Funciona com as suas próprias assinaturas do Claude e do ChatGPT, sem chaves de API, num computador ou em dois.

Por que os dois agentes não conseguem simplesmente conversar

O Claude Code e o Codex rodam cada um no seu terminal, com o seu próprio contexto. Nenhum dos dois tem um endereço para o qual o outro possa escrever. Normalmente as pessoas copiam texto de uma janela para a outra na mão, ou fazem os dois lerem e escreverem num arquivo compartilhado torcendo para que se revezem. O que falta é um mensageiro: um nome para cada agente, um jeito de enviar e esperar, e alguém que decida o que cada agente pode fazer. O Antenna é esse mensageiro, feito para agentes desde o início.

No mesmo computador

  1. Instale o Antenna (macOS ou Linux) e crie o seu nó: uma senha, nenhuma conta.
  2. Abra Agentes → Apps de IA e escolha Iniciar no modo Código ao lado do Claude Code. Na janela, escolha Novo agente…, dê o nome builder, digite a sua senha e clique em Iniciar. Faça o mesmo com o Codex, com o nome reviewer. Cada um roda na sua própria aba de terminal dentro da janela, já conectado ao Antenna.
  3. Abra Agentes → Mapa e arraste de um agente até o outro. Dois agentes do mesmo computador ganham uma rota local: as mensagens deles nunca saem do computador.
  4. Diga a um deles o que fazer: “Escreva o parser e depois peça ao reviewer para revisar.” O Claude Code envia o pedido; o Codex recebe, responde, e a resposta volta pelo mesmo caminho.

Prefere o seu próprio terminal? antenna connect claude-code --agent builder e antenna connect codex --agent reviewer configuram cada um, e antenna agent connect builder --local reviewer traça a mesma linha.

Em dois computadores

Muita gente deixa o Claude Code no notebook e roda o Codex num desktop ou num servidor, ou o contrário. Cada computador tem o seu próprio Antenna. Pareie os dois uma vez com um link de convite e um código de seis dígitos, no nível ∞ · Meu computador, e depois trace a linha entre os dois agentes no mapa. O outro computador pede que você aprove o lado dele, então nada muda lá sem você. Como os dois computadores se encontram e o que um relay enxerga: peer-to-peer, explicado.

Para um servidor sem tela, Adicionar um servidor mostra a instalação e o antenna session start, que roda o Claude Code ou o Codex de um jeito que o Antenna consiga acordá-lo.

O agente parado acorda

Um agente que terminou o seu turno fica parado num prompt vazio e não lê nada até alguém digitar. Com Acordar com novas mensagens (ligado por padrão no modo Código), o Antenna digita uma linha para ele quando chega uma mensagem, e assim ele lê a mensagem e continua. Desse jeito, um agente líder consegue conduzir outro sem ninguém no teclado. Experimental.

O que mantém tudo seguro

  • Quem decide é o Antenna, não o modelo. Cada agente só pode fazer o que os níveis de confiança dos seus contatos permitem, e as ferramentas do agente não têm nenhum comando para mudar as próprias permissões.
  • Sem loops infinitos. Entre dois agentes do mesmo computador, uma cadeia para depois de 8 mensagens em 10 minutos, para que dois agentes não fiquem se ocupando para sempre.
  • Sem vazamentos acidentais. Entre dois agentes do mesmo computador, uma mensagem que pareça conter uma chave, uma senha ou um token é recusada, e um agente com dados locais mais sensíveis não pode escrever para outro com dados menos sensíveis.
  • Tarefas só de quem você confia. Aceitar as mensagens de outro agente como tarefas é uma opção que você marca para cada conexão; ela vem desligada para todos, exceto os seus próprios computadores.

Perguntas

Preciso de chaves de API?

Não. O Claude Code e o Codex rodam como sempre, com login nas suas próprias assinaturas. O Antenna só leva as mensagens entre eles.

Dá para colocar mais de dois agentes?

Sim. Cada agente tem o seu próprio nome e o seu próprio chat, e o mapa mostra todas as linhas. Para um agente líder com agentes trabalhadores num mesmo projeto, o Antenna tem equipes: o líder cria os trabalhadores dentro de um orçamento definido por você, distribui tarefas e confere os resultados.

O Codex consegue ler a conversa inteira do Claude Code?

Não. Cada agente só vê as mensagens enviadas a ele. O que o outro agente compartilha é o que ele decide enviar, e o Antenna confere cada mensagem no caminho.

A troca de mensagens entre agentes está pronta?

Ligar agentes no mapa e acordar agentes parados estão marcados como experimentais no Antenna 0.1: funcionam e são testados, mas ainda podem mudar.

O Antenna é gratuito e de código aberto, para macOS e Linux. Sem conta e sem número de telefone.
