Aprove os pedidos do Claude Code a partir de outro computador

Inicie o Claude Code pelo Antenna, no Code mode da janela ou com antenna session num servidor, e o daemon do Antenna confere cada ferramenta que ele usa e cada mensagem que ele envia. Quando um passo precisa de você, ele vira um pedido de aprovação que aparece, com uma notificação, em cada computador que você pareou como seu, em My devices (meus dispositivos). Aprove ali com a senha daquele computador ou com Touch ID: o computador onde o Claude Code roda confere a sua resposta, executa o passo e o Claude Code segue em frente.

O que chega até você

  • Passos depois de ler a mensagem de um contato. Depois que o Claude Code leu uma mensagem de um colega, o nível de confiança desse colega define o que ele pode fazer: no nível 4, cada comando espera por você; nos níveis 2 e 3, cada edição espera, e os comandos são recusados.
  • Mudanças na própria configuração. Depois de ler a mensagem de qualquer contato, mesmo do seu próprio notebook, edições em CLAUDE.md, .claude/, perfis do shell, chaves e arquivos de build como package.json esperam por você.
  • Mensagens que levariam os seus dados para fora. Depois que ele leu arquivos do seu projeto, cada mensagem para um contato abaixo de ∞ espera, assim como qualquer mensagem para um contato desses que pareça conter uma chave, uma senha ou um token. Depois que ele leu uma conversa, uma mensagem para outra conversa também espera.
  • Perguntas. Experimental. As perguntas de um agente aparecem no computador onde ele roda, em Questions from your agents (perguntas dos seus agentes). Para recebê-las no notebook, rode antenna agent escalate api-dev --to mac naquele computador: a partir daí, cada pergunta chega no chat do agente, e você responde no chat.

O próprio aviso de permissão do Claude Code (“Do you want to proceed?”) fica no terminal dele: o Antenna nunca digita nele. Libere nas configurações do Claude Code as ferramentas que você usa no dia a dia, ou responda com antenna session attach.

Como configurar

  1. Instale o Antenna nos dois computadores e pareie-os uma vez com This is my own computer (∞) (este é o meu próprio computador) marcado, como em Claude Code numa VPS.
  2. Inicie o Claude Code pelo Antenna. Num desktop: Agents → AI apps → Start in Code mode. Num servidor: 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
  3. No computador onde o Claude Code roda, aceite as respostas do computador de onde você vai aprovar: My devices → o cartão desse computador → Approvals → Accept approvals signed with …, com a sua senha. Num servidor: antenna devices confirm mac.

Responda de qualquer computador

O pedido aparece no cartão do computador que pergunta, em My devices (experimental), com uma notificação como “Antenna: approval needed on Mac mini”. O cartão diz qual agente pede, o quê e por quê, e cita o texto dele, exceto um texto com um segredo, que nunca sai do computador que perguntou. Clique em Approve with Touch ID num Mac (experimental), em Approve with password com a senha do computador em que você está, ou em Deny (recusar).

O computador que perguntou confere a assinatura com as chaves que você aceitou nele, com o seu próprio desafio de uso único e com exatamente este pedido, e então executa o pedido ele mesmo, uma única vez. No próprio computador, o pedido fica em Approval requests, ou num terminal com antenna approvals e antenna approve <id>.

O Claude Code espera até 50 segundos, e um passo aprovado nesse prazo roda na hora. Depois disso, ele segue com outro trabalho; quando você aprova, o Antenna digita “Approved — continue.” no prompt dele e ele roda o passo de novo.

Se ninguém responder

Um pedido se fecha depois de 10 minutos: nada roda, nada é enviado, e o Claude Code fica sabendo que ninguém aprovou. Uma notificação avisa você pouco antes. Depois de Deny, que não pede senha, o Claude Code fica sabendo que você disse não.

Um agente que aprova por você

Experimental. Can approve for… (pode aprovar por…) em Agents deixa um agente de sua confiança responder aos pedidos dos seus outros agentes sobre mensagens e arquivos, e a resposta dele só vale quando tudo o que o pedido envolve está em ∞. Comandos e edições sempre chegam a você.

Perguntas

Funciona com o Codex?

Em parte. O que o Codex envia pelo Antenna é conferido do mesmo jeito, e esses pedidos chegam a todos os seus computadores; os comandos do próprio Codex continuam com as aprovações do Codex, no terminal dele.

Qualquer computador pode aprovar?

Não. Só um computador que você pareou como seu e cujas chaves você aceitou, com a senha, no computador que pergunta. Se perder um, use Revoke this computer (revogar este computador) em cada um dos outros.

Posso aprovar pelo celular?

Ainda não. Hoje o Antenna roda no macOS e no Linux.

O Antenna é gratuito e de código aberto, para macOS e Linux. Sem conta e sem número de telefone.
