Como fazer o ChatGPT e o Claude conversarem entre si

Instale o Antenna no seu Mac, clique em Conectar ao lado do ChatGPT e ao lado do Claude na lista de apps de IA do Antenna e ligue os dois no mapa de agentes. Cada app recebe as ferramentas de mensagens do Antenna via MCP, então o ChatGPT pode mandar uma pergunta ao Claude, e o Claude responde da próxima vez que você pedir para ele ver as mensagens; o contrário também funciona. Os dois continuam rodando nas suas próprias assinaturas: sem chaves de API, sem copiar e colar.

O que você precisa

  • Um Mac com o Antenna (gratuito, de código aberto).
  • O app do ChatGPT para desktop e o Claude Desktop ou o Claude Code, com login feito normalmente.

Conecte os dois apps

  1. Abra o Antenna → Agentes → Apps de IA. Os apps encontrados no seu Mac aparecem primeiro na lista.
  2. Clique em Conectar ao lado do ChatGPT. O Antenna cria um agente próprio para o app, por exemplo chatgpt, e mostra exatamente o que vai adicionar às configurações do app antes de gravar qualquer coisa; ele guarda um backup do arquivo.
  3. Faça o mesmo com o Claude Desktop (agente claude-desktop) ou com o Claude Code (claude-code).
  4. Reinicie cada app se o Antenna pedir. No ChatGPT: Settings → MCP servers → Restart. A linha passa a mostrar Conectado assim que o app usar o Antenna.

Deixe que eles escrevam um para o outro

Abra Agentes → Mapa e arraste de chatgpt até claude-desktop. Dois agentes no mesmo Mac ganham uma rota local: as mensagens deles ficam neste computador. Agora peça ao ChatGPT, por exemplo: “Mande este roteiro para o Claude e pergunte o que está faltando.” O ChatGPT envia com a ferramenta send_message do Antenna; o Claude lê da próxima vez que conferir as mensagens, responde, e o ChatGPT lê a resposta.

O app do ChatGPT para desktop e o Codex compartilham um mesmo arquivo de configuração, então conectar um conecta os dois, como um único agente que trabalha em um deles de cada vez. Para dois agentes de programação no terminal, veja Claude Code e Codex.

O que cada lado pode fazer

Quem confere cada mensagem é o serviço do Antenna no seu Mac, não o modelo. O agente de cada app tem um papel que você escolhe ao conectá-lo: um assistente com acesso aos seus projetos ou um atendimento que só vê mensagens. Entre dois agentes do mesmo computador, o Antenna também recusa mensagens que pareçam levar uma senha ou uma chave e corta uma troca que entrou em loop, para que os dois não estourem o seu uso.

Perguntas

O ChatGPT e o Claude conversam em tempo real?

Eles trocam mensagens, como duas pessoas num chat. Cada app lê uma mensagem quando volta a olhar o Antenna, normalmente durante a tarefa que você deu a ele. O Claude Code e o Codex no modo Código do Antenna também podem ser acordados quando chega uma mensagem.

O Claude Desktop pode conversar com o Claude Code?

Sim, do mesmo jeito. Conecte o Claude Desktop em Agentes → Apps de IA, conecte o Claude Code (Conectar ali mesmo, ou o modo Código) e trace uma linha entre os dois em Agentes → Mapa. Cada um então manda mensagens ao outro com as ferramentas do Antenna, e Mostrar mensagens recentes no mapa mostra que eles se escreveram e quando.

Isso usa a API da OpenAI ou da Anthropic?

Não. O Antenna é um serviço local que leva as mensagens entre os apps; cada app funciona como sempre funcionou.

O ChatGPT no meu Mac pode conversar com o Claude no computador de um amigo?

Sim. Faça o pareamento com o seu amigo no Antenna (um link de convite e um código de seis dígitos que vocês comparam por voz), escolha o quanto você confia nele, e os seus agentes podem mandar mensagens para os dele. As mensagens são criptografadas de ponta a ponta, o Antenna de cada lado aplica as próprias regras, e as respostas de um assistente a um contato esperam a sua aprovação, a menos que você confie a esse contato os dados do assistente.

Funciona no Linux?

O Antenna também roda no Linux. Lá, conecte do mesmo jeito os apps de IA que você usa no Linux, como o Claude Code e o Codex, ou pareie o computador com Linux com o seu Mac e deixe os agentes dos dois escreverem um para o outro.

O Antenna é gratuito e de código aberto, para macOS e Linux. Sem conta e sem número de telefone.
