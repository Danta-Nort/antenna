लैपटॉप से दूसरे कंप्यूटर पर Codex CLI को tasks दें

दोनों कंप्यूटरों पर Antenna इंस्टॉल करें और उन्हें एक बार अपने ख़ुद के कंप्यूटरों के रूप में जोड़ें। जिस कंप्यूटर पर Codex चलता है, वहाँ antenna connect codex से Codex session को एक नाम दें और antenna session start … --cli codex से उसे शुरू करें। आपके लैपटॉप पर उसी नाम की एक चैट आ जाती है: वहाँ task लिखें, और जब Codex ख़ाली बैठा हो, Antenna उसे जगा देता है। Codex आपका मैसेज पढ़ता है, दूसरे कंप्यूटर पर काम करता है, और चैट में जवाब देता है। कोई SSH session खुला नहीं रहता और कोई inbound port खोलने की ज़रूरत नहीं।

आपको क्या चाहिए

  • काम करने वाले कंप्यूटर पर इंस्टॉल और साइन-इन किया हुआ Codex CLI: x86_64 पर Linux server, या Mac या Linux डेस्कटॉप। Codex आपका अपना subscription ही इस्तेमाल करता रहता है; Antenna को किसी API key की ज़रूरत नहीं।
  • उस कंप्यूटर पर tmux। Server पर एक बार sudo loginctl enable-linger $USER भी चलाएँ, ताकि logout के बाद भी Antenna और session चलते रहें।
  • दोनों कंप्यूटरों पर Antenna: डेस्कटॉप पर ऐप, server पर node (curl -fsSL https://antenna.contact/install.sh | sh)।

1. दोनों कंप्यूटरों को जोड़ें

अपने लैपटॉप पर: New contact → Invite, This is my own computer (∞) पर tick करें, लिंक बनाएँ, और उसे दूसरे कंप्यूटर पर खोलें (server पर antenna join '<link>' --trust 5 --label mac)। एक तरफ़ दिखा कोड दूसरी तरफ़ डालें। अब दोनों तरफ़ एक-दूसरे को आपके अपने कंप्यूटर माना जाता है। Screenshots के साथ step-by-step तरीक़ा VPS पर Claude Code में है; Codex के लिए भी यही है।

2. Codex session को नाम दें

जिस कंप्यूटर पर Codex चलता है, वहाँ प्रोजेक्ट फ़ोल्डर में:

cd ~/projects/api
    antenna connect codex --agent api-codex --links mac --hello mac

यह अपनी token फ़ाइल के साथ agent api-codex बनाता है, उसे आपके लैपटॉप से जोड़ता है (mac वह नाम है जो pairing के समय इस कंप्यूटर ने आपके लैपटॉप को दिया था), और hello भेजता है, ताकि लैपटॉप पर api-codex नाम की चैट तुरंत दिख जाए। आपकी अपनी Codex settings नहीं बदलतीं: Antenna सिर्फ़ इस agent के sessions के लिए जोड़ा जाता है।

3. Antenna के ज़रिए Codex शुरू करें

antenna session start api-codex --dir ~/projects/api --cli codex
    antenna session attach api-codex

Codex, Antenna के अपने tmux server में शुरू होता है; आपके tmux को छुआ नहीं जाता। Codex के पहले सवालों का जवाब देने के लिए एक बार attach करें। पहली बार Codex आपसे Antenna के hooks पर भरोसा करने को कहता है (“Hooks need review”): “Trust all and continue” चुनें। फिर Ctrl-b d से बाहर निकलें, और Codex चलता रहता है। Restart के बाद --resume agent का पिछला session आगे बढ़ाता है।

4. लैपटॉप से उसे लिखें

api-codex चैट खोलें और लिखें: “tests चलाओ, जो fail हों उन्हें ठीक करो, और बताओ क्या बदला।” जब Codex अपने prompt पर ख़ाली बैठा होता है, Antenna एक built-in लाइन टाइप करता है जो उसे अपना inbox पढ़ने को कहती है। वह आपका टेक्स्ट कभी terminal में टाइप नहीं करता, और Codex के पूछे किसी सवाल में कभी टाइप नहीं करता। Codex, Antenna के ज़रिए मैसेज पढ़ता है, काम करता है, और चैट में जवाब देता है। Experimental।

उसका मौजूदा काम रुकवाना है? भेजने से पहले Urgent: interrupt now चालू करें। Antenna एक बार Esc दबाकर चल रही बारी ख़त्म करता है और फिर आपके मैसेज के लिए Codex को जगाता है। Agent और उसके शुरू किए सब कुछ को रोकने के लिए, लैपटॉप पर My devices में दूसरे कंप्यूटर का कार्ड खोलें और Stop agent and its processes… दबाएँ, जो api-codex के आगे है।

डेस्कटॉप पर: Code mode

अगर Codex, Antenna ऐप वाले Mac या Linux डेस्कटॉप पर चलता है, तो आप terminal वाले कदम छोड़ सकते हैं। Code mode में agents पैनल का + दबाएँ, Codex और काम का फ़ोल्डर चुनें, और Codex विंडो के अंदर एक टैब में चलने लगता है, उसी तरह जगाया जाता है। उसकी चैट आपके दूसरे कंप्यूटरों से वैसे ही पहुँच में रहती है जैसे किसी भी दूसरे agent की।

सवाल-जवाब

क्या इससे लैपटॉप पर Codex का terminal दिखता है?

नहीं। आप Codex को tasks देते हैं और उसके जवाब चैट में पढ़ते हैं; terminal दूसरे कंप्यूटर पर ही रहता है। उसे देखने के लिए वहाँ antenna session attach करें, चाहें तो SSH से।

Codex के कौन-से वर्ज़न काम करते हैं?

Codex 0.160 और उसके बाद के वर्ज़न hooks के ज़रिए बताते हैं कि वे क्या कर रहे हैं, और इसी से Antenna को पता चलता है कि Codex कब ख़ाली है। पुराने Codex के साथ, या hooks पर भरोसा किए बिना, Antenna इंतज़ार करता है जब तक Codex बारी के बाद अपनी ख़ाली input लाइन न दिखा दे, और बारी चलते समय कभी टाइप नहीं करता।

क्या Codex, Claude Code से भी बात कर सकता है?

हाँ। Agent map पर दोनों agents को जोड़ें, और हर एक के मैसेज बिना नाम लिए दूसरे तक पहुँचते हैं: देखें Claude Code और Codex की आपसी बातचीत।

क्या इसे फ़ोन से कंट्रोल किया जा सकता है?

अभी नहीं। Antenna आज macOS और Linux पर चलता है।

Antenna फ़्री और ओपन सोर्स है, macOS और Linux के लिए। न अकाउंट चाहिए, न फ़ोन नंबर।
