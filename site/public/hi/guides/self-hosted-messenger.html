अपडेट किया गया 9 नवंबर 2026

ऐसा self-hosted मैसेंजर, जिसके लिए server चलाना ज़रूरी नहीं

लोग मैसेंजर को self-host इसलिए करते हैं ताकि उनके मैसेज किसी और के server पर न रहें। Antenna यह बिना किसी server के कर देता है: हर व्यक्ति अपने कंप्यूटर पर Antenna चलाता है, मैसेज इन कंप्यूटरों के बीच end-to-end encrypted होकर जाते हैं, और हिस्ट्री सिर्फ़ वहीं, एक encrypted database में रहती है। ज़्यादा कंट्रोल चाहिए, तो आप हमेशा चालू Linux node जोड़ सकते हैं या अपना relay चला सकते हैं, दोनों ओपन सोर्स।

Self-hosted server का आमतौर पर क्या मतलब होता है

क्लासिक self-hosted मैसेंजर एक server है जिसे आप इंस्टॉल, अपडेट और back up करते हैं और ऑनलाइन रखते हैं, और उसमें इस्तेमाल करने वाले हर व्यक्ति का हर अकाउंट और हर मैसेज होता है। इससे भरोसा किसी कंपनी से हटकर आप पर आ जाता है, और साथ में काम और जोखिम भी: server में सेंध लगी, तो सबकी हिस्ट्री भी गई।

Antenna इसकी जगह क्या करता है

  • Host करने के लिए कोई अकाउंट नहीं। आपकी पहचान आपके कंप्यूटर पर एक key है, जिसे आपका password बचाता है। आप लोगों को एक बार के इनवाइट लिंक और आवाज़ से मिलाए गए कोड से जोड़ते हैं।
  • बीच में कोई message store नहीं। आपकी हिस्ट्री आपके कंप्यूटर पर, SQLCipher से encrypted database में रहती है, और दूसरे व्यक्ति के कंप्यूटर पर।
  • ऑनलाइन रखने के लिए कोई server नहीं। Network इजाज़त दे तो दो कंप्यूटर सीधे जुड़ते हैं, वरना एक relay के ज़रिए, जो encrypted ट्रैफ़िक आगे भेजता है और कुछ भी नहीं रखता।

हमेशा चालू node जोड़ें

लैपटॉप सो जाता है; server नहीं। अपने AI agents तक चौबीसों घंटे पहुँच बनाए रखने के लिए, Linux server (x86_64) पर Antenna node इंस्टॉल करें: release को unpack करें और ./install.sh चलाएँ, जो बिना root के systemd user service सेट करता है, या .deb या .rpm पैकेज इंस्टॉल करें। फिर उसे अपने कंप्यूटर से किसी कॉन्टैक्ट की तरह ∞ · My computer पर जोड़ें। पूरा तरीक़ा: Add a server।

Reboot के बाद node की keys तब तक लॉक रहती हैं जब तक आप login करके antenna unlock न चलाएँ: चोरी हुई disk image से किसी को आपकी keys नहीं मिलतीं।

अपना relay चलाएँ

Relay ही एकमात्र साझा हिस्सा है, और उसे सिर्फ़ encrypted packets दिखते हैं और यह कि कौन-से endpoints उसके ज़रिए बात करते हैं। अगर आप चाहते हैं कि यह आपकी अपनी मशीन हो, तो ओपन सोर्स iroh-relay चलाएँ और अपना node antennad --relay <your relay URL> से शुरू करें। Levels 1 और 2 पर भरोसे वाले कॉन्टैक्ट्स हमेशा relay से होकर जुड़ते हैं, इसलिए उन्हें आपका IP address कभी पता नहीं चलता।

सवाल-जवाब

क्या मेरा परिवार इसे इस्तेमाल कर सकता है?

कंप्यूटरों पर, हाँ: Antenna 0.1 macOS (Apple Silicon) और Linux पर चलता है। फ़ोन ऐप अभी नहीं है।

क्या relay ऑफ़लाइन कॉन्टैक्ट्स के लिए मैसेज स्टोर करता है?

नहीं। ऑफ़लाइन कॉन्टैक्ट के लिए मैसेज आपके अपने कंप्यूटर पर इंतज़ार करता है और उनके वापस आते ही ख़ुद चला जाता है।

क्या कुछ host करना ज़रूरी है?

नहीं। Antenna default relay के साथ और आपके किसी server के बिना काम करता है। Node और relay तब के लिए हैं जब आप उन्हें चाहें।

Server पर अपडेट कैसे होते हैं?

install.sh से इंस्टॉल किया गया node antenna update से अपडेट होता है, जो पहले release का signature जाँचता है; पैकेज से किया गया इंस्टॉल आपके package manager से अपडेट होता है।

Antenna फ़्री और ओपन सोर्स है, macOS और Linux के लिए। न अकाउंट चाहिए, न फ़ोन नंबर।
