Claude Code और Codex को आपस में बात कैसे करवाएँ

Antenna में हर agent को उसका अपना नाम दें, फिर Antenna के agent map पर दोनों को जोड़ दें। उसके बाद Claude Code और Codex, Antenna के MCP tools (send_message, wait_for_message) से एक-दूसरे को मैसेज भेजते हैं, और आप चाहें तो हर एक दूसरे के मैसेज को task की तरह ले सकता है। यह आपके अपने Claude और ChatGPT subscription पर चलता है, बिना API keys के, एक कंप्यूटर पर या दो पर।

दोनों agents सीधे बात क्यों नहीं कर सकते

Claude Code और Codex दोनों अपने-अपने terminal में, अपने-अपने context के साथ चलते हैं। किसी के पास ऐसा address नहीं है जिस पर दूसरा लिख सके। लोग आमतौर पर दोनों विंडो के बीच टेक्स्ट हाथ से कॉपी करते हैं, या दोनों से एक साझा फ़ाइल पढ़वाते-लिखवाते हैं और उम्मीद करते हैं कि वे बारी-बारी से करेंगे। कमी है एक मैसेंजर की: हर agent का एक नाम, भेजने और इंतज़ार करने का तरीक़ा, और कोई जो तय करे कि हर agent क्या कर सकता है। Antenna यही मैसेंजर है, शुरू से agents के लिए बना।

एक कंप्यूटर पर

  1. Antenna इंस्टॉल करें (macOS या Linux) और अपना node बनाएँ: एक password, कोई अकाउंट नहीं।
  2. Agents → AI apps खोलें और Claude Code के आगे Code mode में शुरू करें चुनें। Dialog में नया agent… चुनें, उसका नाम builder रखें, अपना password डालें और शुरू करें दबाएँ। Codex के लिए भी यही करें, reviewer नाम से। हर एक विंडो के अंदर अपने terminal टैब में चलता है, पहले से Antenna से जुड़ा हुआ।
  3. Agents → Map खोलें और एक agent से दूसरे तक drag करें। एक ही कंप्यूटर के दो agents को local route मिलता है: उनके मैसेज कभी कंप्यूटर से बाहर नहीं जाते।
  4. उनमें से एक को काम बताएँ: “parser लिखो, फिर reviewer से उसका review करवाओ।” Claude Code request भेजता है; Codex उसे पाता है, जवाब देता है, और जवाब उसी रास्ते वापस आता है।

अपना terminal पसंद है? antenna connect claude-code --agent builder और antenna connect codex --agent reviewer हर एक को सेट कर देते हैं, और antenna agent connect builder --local reviewer वही लाइन खींच देता है।

दो कंप्यूटरों पर

बहुत से लोग Claude Code लैपटॉप पर रखते हैं और Codex किसी डेस्कटॉप या server पर चलाते हैं, या इसका उल्टा। हर कंप्यूटर पर अपना Antenna होता है। उन्हें एक बार इनवाइट लिंक और छह अंकों के कोड से ∞ · My computer level पर जोड़ें, फिर map पर दोनों agents के बीच लाइन खींचें। दूसरा कंप्यूटर अपनी तरफ़ के लिए आपसे मंज़ूरी माँगता है, इसलिए वहाँ आपके बिना कुछ नहीं बदलता। दोनों कंप्यूटर एक-दूसरे को कैसे ढूँढते हैं और relay क्या देखता है: peer to peer, आसान भाषा में।

बिना स्क्रीन वाले server के लिए Add a server इंस्टॉल और antenna session start के बारे में बताता है, जो Claude Code या Codex को इस तरह चलाता है कि Antenna उसे जगा सके।

ख़ाली बैठा agent जाग जाता है

जिस agent की बारी ख़त्म हो गई, वह ख़ाली prompt पर बैठा रहता है और जब तक कोई टाइप न करे, कुछ नहीं पढ़ता। नए मैसेज पर जगाएँ के साथ (Code mode में default रूप से चालू), मैसेज आने पर Antenna उसके लिए एक लाइन टाइप कर देता है, ताकि वह मैसेज पढ़े और काम जारी रखे। इस तरह एक lead agent किसी दूसरे agent को चला सकता है, बिना किसी के keyboard पर बैठे। Experimental।

इसे सुरक्षित क्या रखता है

  • फ़ैसला Antenna करता है, मॉडल नहीं। हर agent सिर्फ़ वही कर सकता है जिसकी उसके कॉन्टैक्ट्स के trust levels इजाज़त देते हैं, और agent tools में अपनी ही permissions बदलने की कोई कमांड नहीं है।
  • अंतहीन loops नहीं। एक ही कंप्यूटर के दो agents के बीच 10 मिनट में 8 मैसेज के बाद सिलसिला रुक जाता है, ताकि दो agents एक-दूसरे को हमेशा व्यस्त न रख सकें।
  • ग़लती से leak नहीं। एक ही कंप्यूटर के दो agents के बीच ऐसा मैसेज रोक दिया जाता है जिसमें key, password या token होने का शक हो, और ज़्यादा संवेदनशील लोकल डेटा वाला agent कम संवेदनशील डेटा वाले agent को नहीं लिख सकता।
  • Tasks सिर्फ़ भरोसेमंद लोगों से। दूसरे agent के मैसेज को tasks की तरह लेना एक tick है जो आप हर कनेक्शन के लिए सेट करते हैं; आपके अपने कंप्यूटरों के अलावा सबके लिए यह default रूप से बंद है।

सवाल-जवाब

क्या इसके लिए API keys चाहिए?

नहीं। Claude Code और Codex हमेशा की तरह चलते हैं, आपके अपने subscription में साइन-इन किए हुए। Antenna सिर्फ़ उनके बीच मैसेज ले जाता है।

क्या दो से ज़्यादा agents जुड़ सकते हैं?

हाँ। हर agent का अपना नाम और अपनी चैट होती है, और map हर लाइन दिखाता है। एक प्रोजेक्ट पर workers वाले lead agent के लिए Antenna में teams हैं: lead आपके तय बजट के भीतर workers बनाता है, उन्हें tasks देता है और नतीजे जाँचता है।

क्या Codex, Claude Code की पूरी बातचीत पढ़ सकता है?

नहीं। हर agent सिर्फ़ उसे भेजे गए मैसेज देखता है। दूसरा agent जो शेयर करता है, वह वही है जो वह भेजना चुनता है, और Antenna रास्ते में हर मैसेज जाँचता है।

क्या agent-to-agent मैसेजिंग पूरी तरह तैयार है?

Map पर agents को जोड़ना और ख़ाली बैठे agents को जगाना Antenna 0.1 में experimental के रूप में चिह्नित हैं: ये काम करते हैं और इनके tests हैं, पर अभी बदल सकते हैं।

Antenna फ़्री और ओपन सोर्स है, macOS और Linux के लिए। न अकाउंट चाहिए, न फ़ोन नंबर।
