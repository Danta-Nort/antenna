कई कंप्यूटरों पर Claude Code एक ही जगह से इस्तेमाल करें

Claude Code को वहीं चलने दें जहाँ काम है, आपके लैपटॉप, डेस्कटॉप और server पर, और हर एक पर Antenna इंस्टॉल करें। कंप्यूटरों को एक बार अपने ख़ुद के (∞) रूप में जोड़ें। उसके बाद उनमें से किसी से भी आप हर session को एक चैट लिस्ट में देखते हैं, किसी को भी नाम से लिखते हैं, उनके approval requests का जवाब देते हैं, और बेक़ाबू हुए session को रोक देते हैं, उस मशीन पर terminal खोले बिना। Codex भी इसी तरह काम करता है।

आपको क्या मिलता है

  • हर session के लिए एक चैट, चाहे वह किसी भी कंप्यूटर पर चल रहा हो। Server का session और डेस्कटॉप का session आपके कॉन्टैक्ट्स के साथ एक ही लिस्ट में होते हैं।
  • My devices: आपके हर कंप्यूटर का एक कार्ड, जिसमें उसका सिस्टम और Antenna वर्ज़न, उसकी अपनी जाँच के मुताबिक़ उसकी हालत, उसके agents और हर एक जुड़ा है या नहीं, और वहाँ आपका इंतज़ार कर रहे requests दिखते हैं।
  • जहाँ आप हैं, वहीं से approvals। Server पर किसी agent का request आपके Mac पर Touch ID या Mac के password से मंज़ूर किया जा सकता है। Server signature जाँचता है और request ख़ुद पूरा करता है।
  • Stop बटन दूसरे कंप्यूटर के हर agent के लिए: यह agent को और उसके वहाँ शुरू किए हर process को रोक देता है।
  • Agent map, जहाँ आप एक कंप्यूटर के session को दूसरे कंप्यूटर के session से जोड़ते हैं, ताकि वे एक-दूसरे को लिखें।

सेट करें

  1. हर कंप्यूटर पर Antenna इंस्टॉल करें: Mac या Linux डेस्कटॉप पर ऐप, Linux server पर node (curl -fsSL https://antenna.contact/install.sh | sh)।
  2. कंप्यूटरों को अपने ख़ुद के रूप में आपस में जोड़ें। यह मेरा अपना कंप्यूटर है (∞) पर tick करके इनवाइट बनाएँ, उसे दूसरे कंप्यूटर पर खोलें, और एक तरफ़ दिखा कोड दूसरी तरफ़ डालें। हर कंप्यूटर को उन सभी कंप्यूटरों से जोड़ें जिन्हें आप उससे देखना या जोड़ना चाहते हैं: हर एक के पास दूसरा ∞ पर होना चाहिए।
  3. हर Claude Code session को एक नाम दें। डेस्कटॉप पर उसे agents पैनल के + से Code mode में शुरू करें। Server पर, प्रोजेक्ट फ़ोल्डर में, antenna connect claude-code --agent api-dev --links mac --hello mac चलाएँ और antenna session start api-dev --dir ~/projects/api से उसे चालू रखें; हर कदम VPS पर Claude Code में है।
  4. अपने मुख्य कंप्यूटर को requests का जवाब देने दें। Server पर एक बार antenna devices confirm mac चलाएँ; डेस्कटॉप पर मुख्य कंप्यूटर की key My devices → उसका कार्ड → मंज़ूरियाँ में स्वीकार करें।

कंप्यूटरों के बीच काम आगे बढ़ाना

Session को वैसे ही लिखें जैसे किसी इंसान को: “api-dev, server पर migrations चलाओ और बताओ क्या बदला।” उसकी चैट में डाली गई फ़ाइलें उसी कंप्यूटर पर सेव होती हैं और agent को बता दिया जाता है कि वे कहाँ हैं; आपके अपने कंप्यूटरों के बीच आम फ़ाइलें बिना पूछे सेव हो जाती हैं, जबकि प्रोग्राम और installers फिर भी आपका इंतज़ार करते हैं। डेस्कटॉप के session को server के session को काम सौंपने देने के लिए, agent map पर दोनों को जोड़ दें। वहाँ का session मैसेज आने पर जागता है, और कोई urgent मैसेज उसकी मौजूदा बारी को बीच में रोक सकता है। Experimental।

सवाल-जवाब

क्या Antenna कंप्यूटरों के बीच Claude Code की settings या हिस्ट्री sync करता है?

नहीं। Claude Code अपनी settings, हिस्ट्री और साइन-इन हर कंप्यूटर पर अलग रखता है, और आपका कोड वैसे ही आता-जाता है जैसे अभी, git से। Antenna sessions के बीच मैसेज, फ़ाइलें और approvals ले जाता है।

क्या server पर public IP या खुले ports चाहिए?

नहीं। हर कंप्यूटर बाहर की ओर कनेक्ट करता है, network इजाज़त दे तो सीधे, वरना relay के ज़रिए, और relay सिर्फ़ encrypted ट्रैफ़िक आगे भेजता है।

क्या यहीं से दूसरे कंप्यूटर की कोई setting बदली जा सकती है?

नहीं। आपके कंप्यूटरों के बीच सिर्फ़ approvals, stops और agent map के connection requests जाते हैं, जिन्हें वह कंप्यूटर आपसे मंज़ूर करवाता है। Trust, इनवाइट, अपडेट और settings उसी कंप्यूटर पर बदले जाते हैं, ताकि चोरी हुआ लैपटॉप server के नियम दोबारा न लिख सके।

क्या यह Windows या फ़ोन पर काम करता है?

अभी नहीं। Antenna आज macOS और Linux पर चलता है।

Antenna फ़्री और ओपन सोर्स है, macOS और Linux के लिए। न अकाउंट चाहिए, न फ़ोन नंबर।
