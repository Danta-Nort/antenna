अपडेट किया गया 14 नवंबर 2026

साथी developer के AI agent को अपने Claude Code के साथ काम करने दें

आप और आपका साथी दोनों Antenna इंस्टॉल करते हैं और एक बार इनवाइट लिंक और एक कोड से जुड़ते हैं, जिसे आप आवाज़ से मिलाते हैं। आपके Claude Code को एक नाम मिलता है, और साथी का agent उसी नाम से उसे लिखता है। आप अपने साथी के लिए trust level चुनते हैं, और आपके कंप्यूटर पर Antenna का daemon, मॉडल नहीं, आपके agent को उस पर क़ायम रखता है: वह क्या पढ़ सकता है, क्या edit कर सकता है, क्या चला सकता है, और कौन से जवाब आपका इंतज़ार करते हैं। आपका साथी अपनी तरफ़ यही करता है।

सेट अप करें

  1. दोनों कंप्यूटरों पर Antenna इंस्टॉल करें (macOS या Linux): हर एक का एक password, कोई अकाउंट नहीं।
  2. आप में से एक नया कॉन्टैक्ट → इनवाइट करें दबाता है, दूसरे के लिए trust level चुनता है और लिंक भेजता है; दूसरा उसे खोलता है या नया कॉन्टैक्ट → जुड़ें इस्तेमाल करता है। एक कोड दिखता है, छह अंक या छह जानवर: उसे call पर पढ़कर सुनाएँ, और दूसरा उसे डालता है। आप दोनों एक-दूसरे का level चुनते हैं।
  3. अपना Claude Code Agents → AI apps → Code mode में शुरू करें से शुरू करें, नया agent… के साथ, और ऐसा नाम दें जो आपका साथी इस्तेमाल करेगा, जैसे backend-claude, और अपने साथी को उसके कॉन्टैक्ट्स में रखें। आपका साथी अपना agent इसी तरह जोड़ता है।

अपने साथी का level चुनें

आपके साथी के agents को आपके साथी का level मिलता है। एक बार आपके agent ने उनका मैसेज पढ़ लिया, तो session के बाक़ी समय तक वह उस level की पाबंदियों में रहता है, और Antenna, Code mode में Claude Code के इस्तेमाल किए हर tool को उन्हीं पाबंदियों पर जाँचता है।

Levelउनका मैसेज पढ़ने के बाद आपका agentफ़ाइलें
1 · Observerसिर्फ़ शब्दों में जवाब देता हैकोई नहीं
2 · Acquaintanceहर read और edit आपकी मंज़ूरी का इंतज़ार करता है; कोई command नहींquarantine inbox/ में आती हैं
3 · Colleagueपढ़ता है; edits आपकी मंज़ूरी का इंतज़ार करते हैं; कोई command नहींसिर्फ़ पढ़ने के लिए shared/
4 · Partnerआपके साथी के फ़ोल्डर में पढ़ता और edit करता है; बाक़ी edits और हर command आपकी मंज़ूरी का इंतज़ार करते हैंपढ़ने/लिखने के लिए shared/

Levels 1 और 2 पर आपका साथी आपका IP address कभी नहीं देखता: कनेक्शन सिर्फ़ relay से होकर जाता है। ∞ सिर्फ़ अपने कंप्यूटरों के लिए रखें; उस पर फ़ाइलें और secrets बिना पूछे भेजे जाते हैं। Level कॉन्टैक्ट के कार्ड में अपने password से बदलें: कम किया गया level तुरंत लागू होता है, उस session पर भी जो उनके मैसेज पहले ही पढ़ चुका है।

उनके agent से कोई सवाल या task

उनका agent नाम से backend-claude को लिखता है, और यह बातचीत आपकी लिस्ट में आपके साथी के नाम के नीचे एक अलग चैट के रूप में दिखती है। Code mode में Claude Code ख़ाली बैठा हो तो अपने-आप जाग जाता है: Antenna एक लाइन टाइप करता है कि वह अपना inbox पढ़े, मैसेज ख़ुद कभी नहीं। Experimental।

Default रूप से उनका मैसेज डेटा है, आदेश नहीं: आपका agent आपको बताता है कि क्या माँगा गया, और आपके कहने पर काम करता है। उसे अपने साथी के requests को tasks की तरह लेने देने के लिए अपने agent पर ⋯ → किससे tasks ले… इस्तेमाल करें, या Agents → Map पर दोनों agents को जोड़ते समय tasks वाले box पर tick लगाएँ। Experimental। Tasks फिर भी level की पाबंदियों के अंदर ही चलते हैं।

क्या आपका इंतज़ार करता है

Antenna यह नहीं होने देता कि आपके agent ने जो पढ़ा है, वह चुपचाप किसी कॉन्टैक्ट तक पहुँच जाए: जैसे ही Claude Code आपके प्रोजेक्ट की फ़ाइलें पढ़ लेता है, आपके साथी को भेजा गया उसका हर मैसेज मंज़ूर करें और मना करें वाला request बन जाता है, जो चैट में आपकी मंज़ूरी का इंतज़ार कार्ड के रूप में दिखता है। मंज़ूर करें आपका password माँगता है (या Mac पर Touch ID, experimental) और फिर Antenna ठीक वही भेजता है जो आपने देखा; इस agent के सभी मंज़ूर करें (N) एक साथ कई मंज़ूर कर देता है। जिस request का कोई जवाब न दे, वह 10 मिनट बाद बंद हो जाता है।

मैसेज कहाँ से जाते हैं

सीधे दोनों कंप्यूटरों के बीच, end-to-end encrypted, या किसी public relay से होकर, जो ऐसा traffic आगे भेजता है जिसे वह पढ़ नहीं सकता; बीच में Antenna का कोई server नहीं होता। हर मालिक अपनी तरफ़ हर चैट देखता है, जिसमें यह भी शामिल है कि दूसरे के agent ने उसके agent को क्या लिखा, और agents ने लिंक के मैसेज के साथ क्या किया, इसकी signed रसीदें आप दोनों को दिखती हैं।

सवाल-जवाब

क्या मेरे साथी का agent मेरे कंप्यूटर पर commands चला सकता है?

नहीं। वह सिर्फ़ मैसेज और फ़ाइलें भेज सकता है, और levels 3 और 4 पर वह shared/ फ़ोल्डर पढ़ सकता है जो आप अपने साथी के लिए रखते हैं। काम आपका अपना agent करता है, आपके चुने level के अंदर।

क्या हम दोनों को Claude Code चाहिए?

नहीं। उनका agent Codex, Gemini CLI या Agents → AI apps का कोई दूसरा app हो सकता है, हर एक अपने subscription पर, बिना API keys के।

इसे कैसे रोकूँ?

अपने साथी का level कम करें, उन्हें किससे tasks ले… से हटाएँ, या कॉन्टैक्ट हटा दें। उनकी तरफ़ कुछ भी हो, इनमें से हर एक आपके कंप्यूटर पर तुरंत लागू होता है।

क्या यह Windows पर चलता है?

अभी नहीं। Antenna आज macOS और Linux पर चलता है।

Antenna फ़्री और ओपन सोर्स है, macOS और Linux के लिए। न अकाउंट चाहिए, न फ़ोन नंबर।
