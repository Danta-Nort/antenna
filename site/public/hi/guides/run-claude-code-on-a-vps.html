अपडेट किया गया 9 नवंबर 2026

VPS पर Claude Code चौबीसों घंटे चलाएँ, और लैपटॉप से उससे बात करें

अपने Linux VPS पर Claude Code और Antenna node इंस्टॉल करें, server को एक बार अपने लैपटॉप से जोड़ें, और अपने प्रोजेक्ट फ़ोल्डर में Antenna के ज़रिए Claude Code शुरू करें। उसके बाद वह आपके logout करने के बाद भी अपने tmux session में चलता रहता है, उसके लिए मैसेज आने पर जागता है, और आपके लैपटॉप पर चैट में जवाब देता है। न कोई inbound port खोलना, न SSH session चालू रखना, और Codex भी इसी तरह काम करता है।

आपको क्या चाहिए

  • x86_64 पर एक Linux server, जिस पर Claude Code (या Codex) इंस्टॉल और साइन-इन हो, और tmux।
  • आपके लैपटॉप पर Antenna: macOS या Linux।

1. Server पर Antenna node इंस्टॉल करें

curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER

Installer signed manifest से सबसे नई release पढ़ता है, archive जाँचता है, antennad और antenna को ~/.local/bin में systemd user service के रूप में इंस्टॉल करता है (root की ज़रूरत नहीं) और एक password के साथ आपका node बनाता है। दूसरी लाइन logout के बाद भी service चालू रखती है। Ubuntu या Fedora पर आप इसकी जगह .deb या .rpm इंस्टॉल कर सकते हैं।

2. इसे अपने लैपटॉप से जोड़ें

अपने लैपटॉप पर: New contact → Invite, नाम दें, This is my own computer (∞) पर tick करें, Create link दबाएँ और लिंक कॉपी करें। Server पर:

antenna join '<link>' --trust 5 --label mac

Single quotes रहने दें: लिंक में # है। लैपटॉप पर दिखा कोड server के terminal में टाइप करें, फिर लैपटॉप पर The contact confirmed — codes match दबाएँ। Level 5 दोनों तरफ़ ∞ है, इसलिए server को आपका अपना कंप्यूटर माना जाता है।

3. Antenna के ज़रिए Claude Code शुरू करें

cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev

Connect वाली लाइन session को उसका अपना agent और token देती है, और hello भेजती है ताकि आपके लैपटॉप पर api-dev नाम की चैट आ जाए। Start वाली लाइन Claude Code को Antenna के अपने tmux server में चलाती है (आपके tmux को छुआ नहीं जाता)। Claude Code के पहले सवालों का जवाब देने के लिए एक बार attach करें, जैसे कि क्या वह फ़ोल्डर पर भरोसा करे, फिर Ctrl-b d से बाहर निकलें: वह चलता रहता है। Codex के लिए antenna connect codex और --cli codex इस्तेमाल करें।

4. उससे बात करें

लैपटॉप पर api-dev चैट में लिखें: “migration tests चलाओ और जो fail हों उन्हें ठीक करो।” जब Claude Code अपने prompt पर ख़ाली बैठा होता है, Antenna एक छोटी लाइन टाइप करता है ताकि वह आपका मैसेज पढ़े; वह कभी किसी कॉन्टैक्ट का टेक्स्ट टाइप नहीं करता और कभी उसकी ओर से किसी सवाल का जवाब नहीं देता। My devices में server का कार्ड उसकी हालत और उसके agents दिखाता है, और आप उसके requests लैपटॉप से मंज़ूर कर सकते हैं।

Reboot के बाद

Server restart होने के बाद node की keys लॉक हो जाती हैं: service चलती रहती है, लेकिन उसके लिंक तब तक चुप रहते हैं जब तक आप login करके antenna unlock न चलाएँ। इस तरह server की डिस्क की कॉपी से किसी को आपकी keys नहीं मिलतीं। antenna status बताता है कि वह लॉक है या नहीं।

सवाल-जवाब

सीधे SSH और tmux क्यों नहीं?

वह तब तक काम करता है जब तक आप terminal पर बैठे हैं। Antenna एक चैट जोड़ता है जिसमें आप कभी भी लैपटॉप से लिख सकते हैं, लिखते ही session को जगाता है, और दूसरे agents को भी उसे काम देने देता है, उन permissions के साथ जिन्हें वह ख़ुद जाँचता है।

क्या server को public IP या खुले ports चाहिए?

नहीं। दोनों तरफ़ बाहर की ओर कनेक्ट करते हैं, network इजाज़त दे तो सीधे, वरना relay के ज़रिए। Relay सिर्फ़ encrypted ट्रैफ़िक आगे भेजता है।

क्या एक server पर कई sessions चल सकते हैं?

हाँ: हर प्रोजेक्ट फ़ोल्डर के लिए एक agent, हर एक का अपना नाम और आपके लैपटॉप पर अपनी चैट।

क्या ARM build है?

अभी नहीं। Server node x86_64 Linux के लिए बना है।

Antenna फ़्री और ओपन सोर्स है, macOS और Linux के लिए। न अकाउंट चाहिए, न फ़ोन नंबर।
