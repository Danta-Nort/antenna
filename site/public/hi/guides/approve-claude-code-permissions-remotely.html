दूसरे कंप्यूटर से Claude Code के requests मंज़ूर करें

Claude Code को Antenna के ज़रिए शुरू करें, window में Code mode में या server पर antenna session से, और Antenna का daemon उसके इस्तेमाल किए हर tool और भेजे गए हर मैसेज को जाँचता है। जब किसी कदम के लिए आपकी ज़रूरत होती है, तो वह एक approval request बन जाता है, जो हर उस कंप्यूटर पर, जिसे आपने अपने कंप्यूटर के रूप में जोड़ा है, My devices में notification के साथ दिखता है। वहीं उस कंप्यूटर के password या Touch ID से उसे मंज़ूर करें: जिस कंप्यूटर पर Claude Code चल रहा है, वह आपका जवाब जाँचता है, कदम पूरा करता है, और Claude Code आगे बढ़ता है।

आप तक क्या पहुँचता है

  • किसी कॉन्टैक्ट का मैसेज पढ़ने के बाद के कदम। जैसे ही Claude Code किसी साथी का मैसेज पढ़ लेता है, उसका trust level तय करता है कि वह क्या कर सकता है: level 4 पर हर command आपका इंतज़ार करती है; levels 2 और 3 पर हर edit आपका इंतज़ार करता है, और commands मना हो जाती हैं।
  • उसके अपने setup में बदलाव। किसी भी कॉन्टैक्ट का मैसेज पढ़ने के बाद, चाहे वह आपके अपने लैपटॉप से ही क्यों न हो, CLAUDE.md, .claude/, shell profiles, keys और package.json जैसी build files में edits आपका इंतज़ार करते हैं।
  • ऐसे मैसेज जो आपका डेटा बाहर ले जा सकते हैं। जैसे ही वह आपके प्रोजेक्ट की फ़ाइलें पढ़ लेता है, ∞ से नीचे के किसी कॉन्टैक्ट को भेजा गया हर मैसेज इंतज़ार करता है, और ऐसे कॉन्टैक्ट को भेजा गया वह हर मैसेज भी जिसमें key, password या token होने का शक हो। एक बातचीत पढ़ लेने के बाद, किसी दूसरी बातचीत में भेजा गया मैसेज भी इंतज़ार करता है।
  • सवाल। Experimental। Agent के सवाल उसी कंप्यूटर पर दिखते हैं जहाँ वह चलता है, आपके agents के सवाल में। उन्हें अपने लैपटॉप पर पाने के लिए वहाँ antenna agent escalate api-dev --to mac चलाएँ: फिर हर सवाल agent की चैट में आता है, और आप चैट में जवाब देते हैं।

Claude Code का अपना permission prompt (“Do you want to proceed?”) उसके terminal में ही रहता है: Antenna उसमें कभी कुछ टाइप नहीं करता। जो tools आप रोज़ इस्तेमाल करते हैं, उन्हें Claude Code की settings में allow कर दें, या antenna session attach से उसका जवाब दें।

सेट अप करें

  1. दोनों कंप्यूटरों पर Antenna इंस्टॉल करें और उन्हें एक बार यह मेरा अपना कंप्यूटर है (∞) पर tick लगाकर जोड़ें, जैसा VPS पर Claude Code में बताया है।
  2. Claude Code को Antenna के ज़रिए शुरू करें। डेस्कटॉप पर: Agents → AI apps → Code mode में शुरू करें। Server पर: 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
  3. जिस कंप्यूटर पर Claude Code चलता है, वहाँ उस कंप्यूटर के जवाब स्वीकार करें जिससे आप मंज़ूरी देंगे: My devices → उस कंप्यूटर का कार्ड → मंज़ूरियाँ → … से signed मंज़ूरियाँ स्वीकार करें, अपने password के साथ। Server पर: antenna devices confirm mac।

किसी भी कंप्यूटर से जवाब दें

Request पूछने वाले कंप्यूटर के कार्ड पर My devices में दिखता है (experimental), “Antenna: Mac mini पर मंज़ूरी चाहिए” जैसे notification के साथ। कार्ड बताता है कि कौन सा agent पूछ रहा है, किस लिए, क्यों, और उसका टेक्स्ट दिखाता है, सिवाय ऐसे टेक्स्ट के जिसमें कोई secret हो: वह पूछने वाले कंप्यूटर से कभी बाहर नहीं जाता। Mac पर Touch ID से मंज़ूर करें (experimental) दबाएँ, जिस कंप्यूटर पर आप हैं उसके password से Password से मंज़ूर करें, या मना करें।

पूछने वाला कंप्यूटर signature को उन keys से जाँचता है जिन्हें आपने वहाँ स्वीकार किया है, साथ ही अपने one-time challenge और ठीक इसी request से, फिर request को ख़ुद, एक बार, पूरा करता है। उसी कंप्यूटर पर request मंज़ूरी के requests में होता है, या terminal में antenna approvals और antenna approve <id> से।

Claude Code 50 सेकंड तक इंतज़ार करता है, और तब तक मंज़ूर हुआ कदम तुरंत चलता है। उसके बाद वह दूसरे काम में लग जाता है; जब आप मंज़ूरी देते हैं, Antenna उसके prompt में “Approved — continue.” टाइप करता है और वह कदम फिर से चलाता है।

अगर कोई जवाब न दे

Request 10 मिनट बाद बंद हो जाता है: कुछ नहीं चलता, कुछ नहीं भेजा जाता, और Claude Code को पता चलता है कि किसी ने मंज़ूरी नहीं दी। उससे थोड़ा पहले एक notification आपको याद दिलाता है। मना करें के बाद, जिसके लिए password नहीं चाहिए, Claude Code को पता चलता है कि आपने मना किया।

आपकी ओर से मंज़ूरी देने वाला agent

Experimental। Agents में किसकी ओर से मंज़ूरी दे… आपके भरोसे वाले agent को आपके दूसरे agents के मैसेज और फ़ाइलों से जुड़े requests का जवाब देने देता है, और उसका जवाब तभी गिना जाता है जब request से जुड़ी हर चीज़ ∞ पर हो। Commands और edits हमेशा आपके पास आते हैं।

सवाल-जवाब

क्या यह Codex के साथ काम करता है?

कुछ हद तक। Codex जो कुछ Antenna से भेजता है, वह इसी तरह जाँचा जाता है, और वे requests आपके सभी कंप्यूटरों तक पहुँचते हैं; Codex की अपनी commands उसके terminal में Codex की approvals के पास ही रहती हैं।

क्या कोई भी कंप्यूटर मंज़ूरी दे सकता है?

नहीं। सिर्फ़ वही कंप्यूटर, जिसे आपने अपने कंप्यूटर के रूप में जोड़ा है और जिसकी keys आपने पूछने वाले कंप्यूटर पर स्वीकार की हैं, और वह भी password के साथ। खोए हुए कंप्यूटर के लिए बाक़ी हर कंप्यूटर पर इस कंप्यूटर की पहुँच वापस लें दबाएँ।

क्या मैं फ़ोन से मंज़ूरी दे सकता हूँ?

अभी नहीं। Antenna आज macOS और Linux पर चलता है।

Antenna फ़्री और ओपन सोर्स है, macOS और Linux के लिए। न अकाउंट चाहिए, न फ़ोन नंबर।
