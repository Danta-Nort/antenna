दूसरे कंप्यूटर पर चल रहे Claude Code को अपने लैपटॉप से चलाएँ

अपने लैपटॉप पर और उस कंप्यूटर पर Antenna इंस्टॉल करें जहाँ Claude Code चलता है, दोनों को एक बार अपने कंप्यूटरों के रूप में जोड़ें, और वहाँ Claude Code को Antenna के ज़रिए शुरू करें। आपके लैपटॉप पर उस session की चैट आ जाती है: उसमें task लिखें, Claude Code ख़ाली बैठा हो तो Antenna उसे जगाता है, और उसका जवाब चैट में लौट आता है। मैसेज आपके दोनों कंप्यूटरों के बीच end-to-end encrypted, peer-to-peer लिंक पर जाते हैं, Antenna को किसी अकाउंट की ज़रूरत नहीं, और जिन कदमों के लिए आपकी मंज़ूरी चाहिए वे लैपटॉप तक पहुँचते हैं, जहाँ आप अपने password से जवाब देते हैं।

Claude Code का अपना Remote Control, और Antenna

Claude Code में अपना built-in Remote Control feature है; Anthropic का documentation उसके बारे में बताता है। यह guide एक अलग setup के बारे में है: Claude Code आपके किसी ऐसे कंप्यूटर पर चलता है जो चालू रहता है, server या डेस्कटॉप, और आप उसे अपने लैपटॉप पर Antenna से चलाते हैं। यह आपके काम का है अगर आप चाहते हैं:

  • कई कंप्यूटरों पर कई sessions, एक ही list में। हर session की अपनी चैट होती है, और My devices हर कंप्यूटर की हालत, उसके agents और वहाँ इंतज़ार कर रहे requests दिखाता है।
  • आपका अपना लिंक। मैसेज एक कंप्यूटर पर encrypt होते हैं और दूसरे पर decrypt। Network इजाज़त दे तो आपके कंप्यूटर सीधे कनेक्ट होते हैं, वरना ऐसे relay के ज़रिए जो सिर्फ़ encrypted ट्रैफ़िक आगे भेजता है। न अकाउंट, न inbound port।
  • Permissions Antenna का daemon जाँचता है, उसी कंप्यूटर पर जहाँ Claude Code चलता है, और approvals का जवाब आप अपने उस कंप्यूटर से देते हैं जिस पर आप बैठे हैं।
  • दूसरे agents भी इसी तरह: Codex भी Claude Code की तरह काम करता है।

सेट अप करें

  1. दोनों कंप्यूटरों पर Antenna इंस्टॉल करें: आपके लैपटॉप पर app (macOS या Linux), और दूसरे कंप्यूटर पर app, या Linux server पर node: 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
  2. दोनों को एक बार जोड़ें। लैपटॉप पर: नया कॉन्टैक्ट → इनवाइट करें, यह मेरा अपना कंप्यूटर है (∞) पर tick करें, लिंक बनाएँ दबाएँ और लिंक कॉपी करें। Server पर: antenna join '<link>' --trust 5 --label mac; डेस्कटॉप पर: नया कॉन्टैक्ट → जुड़ें, उसी box पर tick लगाकर। एक तरफ़ दिखा कोड दूसरी तरफ़ डालें, और लैपटॉप पर कॉन्टैक्ट ने पुष्टि की — कोड मेल खाते हैं दबाएँ।
  3. दूसरे कंप्यूटर पर Claude Code को Antenna के ज़रिए शुरू करें। Server पर, प्रोजेक्ट फ़ोल्डर में (tmux चाहिए): 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    Claude Code के पहले सवालों का जवाब दें, फिर Ctrl-b d से बाहर निकलें: वह चलता रहता है, और आपके लैपटॉप पर api-dev नाम की चैट आ जाती है। डेस्कटॉप पर: Agents → AI apps → Code mode में शुरू करें, और Claude Code वहाँ Antenna की window के एक tab में चलता है; उससे एक बार कहें कि वह Antenna के ज़रिए आपके लैपटॉप को hello भेजे, और उसकी चैट लैपटॉप पर आ जाती है।
  4. लैपटॉप को उस कंप्यूटर के approval requests का जवाब देने दें। Server पर: antenna devices confirm mac। डेस्कटॉप पर: My devices → लैपटॉप का कार्ड → मंज़ूरियाँ → … से signed मंज़ूरियाँ स्वीकार करें, अपने password के साथ।

अपने लैपटॉप से चलाएँ

  • Task दें। Session की चैट में वैसे ही लिखें जैसे किसी इंसान को लिखते। जब Claude Code अपने prompt पर ख़ाली बैठा होता है, Antenna एक तय लाइन टाइप करता है ताकि वह आपका मैसेज पढ़े; वह आपका टेक्स्ट कभी terminal में टाइप नहीं करता और Claude Code के वहाँ पूछे गए किसी सवाल का जवाब कभी नहीं देता। Experimental।
  • उसे बीच में रोकें। भेजने से पहले Urgent: अभी रोकें चालू करें: Antenna चल रहा turn ख़त्म करने के लिए एक बार Esc दबाता है, वहाँ खुले किसी सवाल या permission prompt के ऊपर कभी नहीं, और Claude Code आपका मैसेज पढ़ता है। Experimental।
  • उसके कदम मंज़ूर करें। जिस कदम के लिए आपकी ज़रूरत है, वह My devices में दूसरे कंप्यूटर के कार्ड पर notification के साथ दिखता है। Password से मंज़ूर करें, Mac पर Touch ID से मंज़ूर करें, या मना करें दबाएँ। Experimental।
  • उसे रोक दें। उस कार्ड पर agent के बगल में Agent और उसके processes रोकें… Claude Code को और उसने वहाँ जो कुछ शुरू किया है, सबको ख़त्म कर देता है। Experimental।

Claude Code का अपना permission prompt (“Do you want to proceed?”) दूसरे कंप्यूटर पर उसके terminal में ही रहता है, और Antenna उसका जवाब कभी नहीं देता। जो tools आप रोज़ इस्तेमाल करते हैं, उन्हें Claude Code की settings में allow कर दें, या antenna session attach से उसका जवाब दें।

Codex और दूसरे agents

Codex भी इसी तरह काम करता है: server पर antenna connect codex और --cli codex, या डेस्कटॉप पर Codex के बगल में Code mode में शुरू करें (देखें Codex CLI remote control)। Gemini CLI Agents → AI apps से कनेक्ट होता है और Antenna के ज़रिए मैसेज भेजता और पढ़ता है, लेकिन Antenna अभी उसे जगाता नहीं: वह नया मैसेज तब पढ़ता है जब वह अगली बार Antenna को call करता है।

सवाल-जवाब

क्या मुझे लैपटॉप पर Claude Code का terminal दिखता है?

नहीं। आप चैट में tasks देते हैं और जवाब पढ़ते हैं; terminal दूसरे कंप्यूटर पर रहता है। उसे देखने के लिए वहाँ antenna session attach चलाएँ, चाहें तो SSH से।

क्या दूसरे कंप्यूटर को public IP या खुले ports चाहिए?

नहीं। दोनों कंप्यूटर बाहर की ओर कनेक्ट करते हैं, network इजाज़त दे तो सीधे, वरना relay के ज़रिए। Relay सिर्फ़ encrypted ट्रैफ़िक आगे भेजता है।

और कौन उसे tasks दे सकता है?

सिर्फ़ उस कंप्यूटर से जुड़े वे कॉन्टैक्ट्स जिनके मैसेज agent पढ़ सकता है (--links mac के साथ, सिर्फ़ आपका लैपटॉप), और वे agents जिन्हें आप agent map पर उससे जोड़ते हैं। किसी कॉन्टैक्ट का मैसेज उससे क्या करवा सकता है, यह वहाँ Antenna का daemon उस कॉन्टैक्ट के trust level के हिसाब से तय करता है, Claude Code नहीं।

क्या इसके लिए API key चाहिए?

नहीं। Claude Code जिस कंप्यूटर पर चलता है, वहाँ आपका अपना साइन-इन रखता है, और Antenna सिर्फ़ मैसेज, फ़ाइलें और approvals पहुँचाता है।

क्या मैं इसे फ़ोन से चला सकता हूँ?

अभी नहीं। Antenna आज macOS और Linux पर चलता है।

Antenna फ़्री और ओपन सोर्स है, macOS और Linux के लिए। न अकाउंट चाहिए, न फ़ोन नंबर।
