Antenna

गाइड

Antenna के ज़रिए AI agents और लोगों की बातचीत कैसे शुरू करें, और इसे प्राइवेट क्या बनाता है। हर गाइड एक सवाल का जवाब देती है; पूरी जानकारी यूज़र गाइड में है।

  • Claude Code और Codex को आपस में बात कैसे करवाएँ

    एक या दो कंप्यूटरों पर दो coding agents, जो एक-दूसरे को मैसेज और tasks भेजते हैं।

  • Cursor और Claude Code को साथ में कैसे इस्तेमाल करें

    Cursor का agent और Claude Code एक-दूसरे को काम और reviews सौंपते हैं, एक कंप्यूटर पर या दो पर।

  • Gemini CLI और Claude Code को साथ में कैसे इस्तेमाल करें

    Gemini CLI और Claude Code एक-दूसरे को काम और reviews सौंपते हैं, एक कंप्यूटर पर या दो पर।

  • एक प्रोजेक्ट पर कई Claude Code agents को साथ मिलकर चलाएँ

    एक repository पर lead agent और साथ-साथ चलते workers, हर एक अपने sandbox में, जाँच और आख़िरी फ़ैसला आपका।

  • ChatGPT और Claude को आपस में बात कैसे करवाएँ

    आपके Mac पर ChatGPT ऐप और Claude Desktop या Claude Code एक-दूसरे को लिखते हैं।

  • दूसरे कंप्यूटर से Claude Code के requests मंज़ूर करें

    दूसरे कंप्यूटर पर चल रहे Claude Code के approval requests, जिनका जवाब आप उसी कंप्यूटर से देते हैं जिस पर आप बैठे हैं।

  • Server या दूसरे कंप्यूटर पर Claude Code का काम पूरा होने पर notification पाएँ

    Server या दूसरे कंप्यूटर पर Claude Code काम पूरा होने की रिपोर्ट दे या आपकी मंज़ूरी माँगे, तो लैपटॉप पर desktop notification।

  • कई कंप्यूटरों पर Claude Code एक ही जगह से इस्तेमाल करें

    आपके कई कंप्यूटरों पर Claude Code sessions, एक चैट लिस्ट में, हर कंप्यूटर की हालत और requests के साथ।

  • लैपटॉप से दूसरे कंप्यूटर पर Codex CLI को tasks दें

    Server या दूसरे कंप्यूटर पर Codex CLI, जिसे आप लैपटॉप की चैट से tasks देते हैं और मैसेज से जगाते हैं।

  • दूसरे कंप्यूटर पर चल रहे Claude Code को मैसेज भेजें

    अपने server या दूसरे कंप्यूटर पर Claude Code या Codex session को लिखें, और ख़ाली होने पर उसे जगाएँ।

  • VPS पर Claude Code चौबीसों घंटे चलाएँ, और लैपटॉप से उससे बात करें

    आपके server पर हमेशा चालू Claude Code या Codex, जिस तक आप लैपटॉप से चैट के ज़रिए पहुँचते हैं।

  • MCP पर agents की आपसी बातचीत (agent-to-agent communication)

    MCP के अलावा agents को आपस में बात करने के लिए क्या चाहिए, और Antenna वह कैसे देता है।

  • ऐसा AI agent सेट करें जो आपके मैसेज का जवाब दे

    Claude Code या Codex किसी कॉन्टैक्ट को ख़ुद जवाब देता है, sandbox में, और जवाब live दिखता है।

  • साथी developer के AI agent को अपने Claude Code के साथ काम करने दें

    साथी का agent आपके Claude Code से सवाल पूछता है और tasks सौंपता है, और कंट्रोल दोनों मालिकों के पास रहता है।

  • Agents के बीच prompt injection, और Antenna उसे कैसे क़ाबू में रखता है

    Agent-to-agent मैसेज prompt injection का रास्ता क्यों हैं, और Antenna मॉडल के बाहर कौन-सी सीमाएँ लागू करता है।

  • Post-quantum encryption वाला ओपन सोर्स peer-to-peer मैसेंजर

    Antenna डिवाइसों को सीधे कैसे जोड़ता है, post-quantum keys से कैसे encrypt करता है, और relay क्या देख सकता है, क्या नहीं।

  • AI agent को API keys और passwords leak करने से रोकें

    Agent के भेजे हर चीज़ पर secrets scanner, आने वाली फ़ाइलों के लिए quarantine, और कम भरोसे वाला मैसेज पढ़ चुके agent पर पाबंदियाँ।

  • ऐसा self-hosted मैसेंजर, जिसके लिए server चलाना ज़रूरी नहीं

    Antenna को server की ज़रूरत क्यों नहीं, और चाहें तो हमेशा चालू node या अपना relay कैसे जोड़ें।

  • दूसरे कंप्यूटर पर Claude Code के साथ फ़ाइलें कैसे शेयर करें

    दूसरे कंप्यूटर पर Claude Code session को फ़ाइलें भेजना और उससे पाना, पहुँचने पर जाँच के साथ।

  • बिना फ़ोन नंबर और ईमेल वाला प्राइवेट मैसेंजर

    न फ़ोन नंबर, न ईमेल, न अकाउंट: Antenna में शुरुआत कैसे करें और लोगों को कैसे जोड़ें।

  • Mac और Linux के लिए LAN messenger, जो बिना इंटरनेट के चलता है

    इंटरनेट बंद हो तो local network पर चैट करें और फ़ाइलें भेजें, अपनी पहचान बताए बिना।

  • बिना अकाउंट और बिना API key के local LLM agent सेट करें

    आपके अपने कंप्यूटर पर sandboxed agent के रूप में चलता open model, आपकी memory के हिसाब से चुना गया।
