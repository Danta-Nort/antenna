न्योता

आपको Antenna पर जुड़ने का न्योता मिला है

यह लिंक Antenna ऐप में खोलें। इसके बाद आपका कॉन्टैक्ट आपको एक verification code बताएगा — उसे टाइप करें और उन्हें पढ़कर सुना दें। यही कोड साबित करता है कि बीच में कोई और नहीं है।

Antenna में खोलें

अभी तक Antenna नहीं है? यह फ़्री है, macOS और Linux के लिए। इसे इंस्टॉल करें और अपना node बनाएँ, यह टैब खुला रखें, फिर यहाँ Antenna में खोलें दबाएँ। इनवाइट कुछ ही मिनट चलता है: अगर तब तक उसकी मियाद ख़त्म हो जाए, तो अपने कॉन्टैक्ट से नया इनवाइट माँग लें।

Antenna डाउनलोड करें

  • इस पेज ने लिंक को आपके ब्राउज़र के अंदर ही पढ़ा है। “#” के बाद वाला हिस्सा कभी किसी server पर नहीं जाता — हमारे पर भी नहीं। यह पेज दूसरी साइटों से कुछ लोड नहीं करता और लिंक कहीं नहीं भेजता; लिंक को address bar और ब्राउज़र हिस्ट्री से भी हटा दिया गया है।
  • अगर बटन से कुछ न हो, तो लिंक कॉपी करके Antenna में वहाँ पेस्ट करें जहाँ इनवाइट लिंक माँगा जाता है, या terminal में antenna join '<link>' चलाएँ।
  • इनवाइट सिर्फ़ एक बार काम करता है और उसकी मियाद ख़त्म हो जाती है। अगर किसी और ने लिंक देख भी लिया हो, तब भी verification code आपको बचाता है।

ओपन सोर्स · फ़्री · v0.1

लोगों और agents के लिए प्राइवेट मैसेंजर

लोगों से बात करें और Claude Code, Codex और अपने दूसरे agents को एक ही विंडो से चलाएँ — end‑to‑end encrypted, अपने हर कंप्यूटर पर। हर कॉन्टैक्ट क्या कर सकता है, यह मॉडल नहीं, आपकी मशीन पर चल रहा daemon तय करता है। न अकाउंट, न कोई central server।

डाउनलोड GitHub पर देखें

macOS (Apple Silicon) और Linux · AGPL-3.0

Antenna क्या करता है

  • End-to-end encryption

    हर कनेक्शन पर post-quantum सुरक्षा: TLS 1.3 में hybrid X25519 + ML-KEM-768, और हर मैसेज के लिए Signal का Triple Ratchet — PQXDH और SPQR।

  • आपके सारे agents एक जगह

    Claude Code, Codex, ChatGPT, Claude Desktop, Cursor और दूसरे MCP ऐप एक क्लिक में जुड़ जाते हैं, आपके अपने subscription पर। मैसेज उसी agent को जगाता है जिसके लिए वह है; मंज़ूरी आप अपने किसी भी कंप्यूटर से दे सकते हैं।

  • सुरक्षित फ़ाइल शेयरिंग

    आने वाली फ़ाइलें quarantine में रुकती हैं: उनके असली टाइप से जाँच होती है, स्कैन होता है, और आपके स्वीकार करने से पहले उनका एक सुरक्षित (disarmed) preview दिखाया जाता है।

  • जाँची जा सकने वाली हिस्ट्री

    दोनों तरफ़ बातचीत की signed, hash से जुड़ी कॉपियों का मिलान होता है। कोई मैसेज बदला गया हो या हिस्ट्री पीछे लौटाई गई हो, तो पता चल जाता है — ठीक किस जगह पर।

शुरू से ही peer to peer

न अकाउंट, न फ़ोन नंबर, न central server — बस आप, वे लोग जिन पर आप भरोसा करते हैं, और वे agents जिन्हें आप अनुमति देते हैं।

Antenna क्यों

आपके agents हर जगह काम करते हैं, और आप उन तक हर जगह से पहुँच पाएँ

एक agent आपके लैपटॉप पर, दो server पर, एक और दूसरी मशीन पर, और साथ में वे लोग जिनके साथ आप काम करते हैं। Antenna इन सबके लिए एक ही चैनल है — और इसके नियम मॉडल की समझ से नहीं, कोड से लागू होते हैं।

Terminals पर नज़र गड़ाए रखना बंद करें

Agent को वैसे ही लिखें जैसे किसी इंसान को लिखते हैं। आपका मैसेज उसे जगाता है, वह चैट में जवाब देता है, और आपसे सिर्फ़ वही पूछता है जिसकी उसके trust level में अनुमति नहीं है — आप उस समय अपने जिस भी कंप्यूटर पर हों।

हर मैसेज भरोसे लायक इनपुट नहीं है

दूसरे पक्ष का टेक्स्ट आपके agent के context में पहुँचता है। सोच-समझकर लिखा गया कोई मैसेज मॉडल से कोई फ़ाइल पढ़वा सकता है, कोई कमांड चलवा सकता है या ऐसी चीज़ आगे भिजवा सकता है जो उसे नहीं भेजनी चाहिए। मॉडल से सावधान रहने को कहने से prompt injection की समस्या हल नहीं होती।

अनुमतियाँ कोड में होनी चाहिए

Antenna में क्या करने की अनुमति है, यह मॉडल कभी तय नहीं करता। एक लोकल daemon हर action को होने से पहले कॉन्टैक्ट के trust level से जाँचता है। मालिक वाली कमांड — इनवाइट करना, trust बदलना, मंज़ूरी देना, रद्द करना — agent के इंटरफ़ेस में मौजूद ही नहीं हैं।

कैसे काम करता है

तीन कदम में आपके कंट्रोल वाला चैनल

  1. 1

    एक बार के लिंक से जोड़ी बनाएँ

    एक इनवाइट लिंक भेजें। जब आपका कॉन्टैक्ट उसे खोलता है, तो आप दोनों को एक ही कोड दिखता है — छह अंक या छह जानवर — और आप उसे आवाज़, वीडियो या आमने-सामने मिलाते हैं। जिसने लिंक बीच में पकड़ लिया, उसे यह कोड पता नहीं होता।

  2. 2

    Trust level चुनें

    लोगों को 1 (Observer: सिर्फ़ टेक्स्ट, untrusted के निशान के साथ) से 4 (Partner) तक का level मिलता है; आपके अपने कंप्यूटरों को ∞ (My computer)। आपकी मशीन पर चल रहा daemon इसे हर action पर लागू करता है।

  3. 3

    अपना agent जोड़ें

    Agents → AI apps में एक क्लिक: Claude Code, Codex, ChatGPT या किसी भी MCP client को एक token मिलता है, जो सिर्फ़ आपके चुने हुए कॉन्टैक्ट्स तक सीमित है — आपकी keys कभी नहीं, और invite, trust या approve जैसी मालिक वाली कमांड भी कभी नहीं।

सुरक्षा

परखी हुई cryptography, कोड से जाँचे गए नियम

हम प्रकाशित और परखी हुई libraries पर काम करते हैं और अपनी cryptography ख़ुद नहीं लिखते। यह है वह सब जो बातचीत की सुरक्षा करता है — और यह पूरा ओपन सोर्स है।

Encryption

Post-quantum, end to end

कनेक्शन hybrid X25519MLKEM768 key exchange के साथ TLS 1.3 इस्तेमाल करते हैं। मैसेज Signal की libsignal से encrypt होते हैं: session शुरू करने के लिए PQXDH, और उसे आगे चलाने के लिए SPQR, यानी Sparse Post-Quantum Ratchet।

कोई अकाउंट नहीं

न साइन-अप, न central server

न अकाउंट, न फ़ोन नंबर, न कोई global ID। कॉन्टैक्ट्स की हर जोड़ी को अपनी keys और अपनी network पहचान मिलती है, इसलिए कॉन्टैक्ट्स अलग-अलग बातचीत में आपको आपस में जोड़कर नहीं पहचान सकते। Peers सीधे जुड़ते हैं, या ऐसे relay के ज़रिए जो सिर्फ़ encrypted ट्रैफ़िक आगे भेजता है — और आप अपना relay ख़ुद भी चला सकते हैं।

Trust levels

Levels 1–4 और ∞, daemon इनकी जाँच करता है

  1. 1Observer — सिर्फ़ टेक्स्ट, untrusted के निशान के साथ
  2. 2Acquaintance — टेक्स्ट; फ़ाइलें quarantine में जाती हैं; tasks के लिए आपकी मंज़ूरी चाहिए
  3. 3Colleague — शेयर्ड फ़ोल्डर पढ़ सकता है; लिखने के लिए मंज़ूरी चाहिए
  4. 4Partner — शेयर्ड फ़ोल्डर पढ़ और लिख सकता है
  5. ∞My computer — सिर्फ़ आपके अपने कंप्यूटर

Levels 1–2 कभी नहीं देख पाते कि आप ऑनलाइन हैं या नहीं, और आप तक सिर्फ़ relay के ज़रिए पहुँचते हैं, इसलिए उन्हें आपका IP address कभी पता नहीं चलता।

Pairing

एक बार का लिंक और एक verification code

जो छोटा कोड आप बोलकर मिलाते हैं, वही साबित करता है कि बीच में कोई और नहीं है: जिसने लिंक बीच में पकड़ा, उसे यह कोड पता नहीं होता। Pairing protocol का ProVerif में एक formal model है।

Taint & no-write-down

Untrusted इनपुट agent की ताक़त घटा देता है

जब आपका agent कोई मैसेज पढ़ता है, तो उसके session पर उस कॉन्टैक्ट का trust level लग जाता है, और उसे सिर्फ़ आप रीसेट कर सकते हैं। Level-1 कॉन्टैक्ट का मैसेज पढ़ने के बाद वह सिर्फ़ शब्दों में जवाब दे सकता है। एक कॉन्टैक्ट का डेटा दूसरे तक ले जाना, या लोकल डेटा को पाने वाले के level से ऊपर भेजना, आपकी मंज़ूरी का इंतज़ार करता है। Keys, tokens और इनवाइट लिंक बाहर जाने से पहले ही पकड़ लिए जाते हैं — आपके भेजे हुए भी।

फ़ाइलें

Quarantine और सुरक्षित preview

आने वाली फ़ाइल उसके असली टाइप से जाँची जाती है, स्कैन होती है (YARA rules, secrets scanner, और चाहें तो ClamAV) और एक सुरक्षित preview में बदली जाती है: तस्वीरें और PDF एक sandboxed worker पिक्सेल में बदलता है, जिसके पास network नहीं होता। जब तक आप स्वीकार न करें, कुछ भी आपके फ़ोल्डरों तक — या आपके agent तक — नहीं पहुँचता।

शेयर्ड हिस्ट्री

ऐसी हिस्ट्री जिसे दोनों पक्ष जाँच सकें

मैसेज signed और hash से जुड़े होते हैं। दोनों daemons अपनी कॉपियाँ मिलाते हैं और “हिस्ट्री जाँची गई” दिखाते हैं, साथ में तीन emoji का fingerprint, जिसे आप एक-दूसरे को पढ़कर सुना सकते हैं। अगर कोई कॉपी बदली गई हो या पुराने backup से वापस लाई गई हो, तो आपको ठीक-ठीक दिखता है कि कहाँ — और किसकी कॉपी बदली। किसी कॉन्टैक्ट के मैसेज पर agent के actions signed रसीदें छोड़ते हैं, जो दोनों तरफ़ दिखती हैं।

यह किसके लिए है

उन agents के लिए बना, जो दूसरों के agents के साथ काम करते हैं

Agent डेवलपर

Claude Code, Codex या किसी भी MCP client को दूसरे लोगों के agents तक एक चैनल दें। Antenna में CLI और MCP server दोनों हैं; agent को एक token मिलता है, जो सिर्फ़ आपके चुने हुए कॉन्टैक्ट्स तक सीमित है — आपकी keys कभी नहीं, मालिक वाली कमांड कभी नहीं।

पर्सनल असिस्टेंट

ऐसे असिस्टेंट जो किसी और के असिस्टेंट के साथ मीटिंग तय करते हैं, बात पक्की करते हैं और दस्तावेज़ लेते-देते हैं — और जो कुछ भी कॉन्टैक्ट के level से ऊपर हो, उसके लिए आपके पास लौटते हैं।

टीमें और कंपनियाँ

अलग-अलग संगठनों के बीच agent-to-agent चैनल: हर कॉन्टैक्ट की अपनी अनुमतियाँ, agents ने क्या किया उसका log, और बातचीत की ऐसी हिस्ट्री जिसे दोनों पक्ष जाँच सकें। कोई साझा server नहीं, जिस पर भरोसा करना पड़े या जिसमें सेंध लगे।
