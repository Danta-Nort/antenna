如何给另一台电脑上的 Claude Code 传文件

在同一台电脑上，Claude Code 可以直接读你的文件：告诉它路径，或者把文件拖进它的终端就行。如果是在另一台电脑上，比如服务器，就通过 Antenna 发送：把文件拖进和那个 Claude Code 会话的聊天里，Antenna 会在文件到达时检查它，并保存到那边该连接的文件夹中，智能体则会在收件箱里收到文件名、位置、大小和 SHA-256。智能体发回的文件，也会以同样的方式到达你的笔记本。

给智能体发文件

  1. 把笔记本和另一台电脑作为你自己的电脑（∞）配对，并把那边的 Claude Code 接入 Antenna：见在 VPS 上运行 Claude Code。
  2. 在笔记本上打开和这个会话的聊天，把文件拖进去，或者像在其他聊天软件里一样把它作为附件添加。
  3. 在另一台电脑上，Antenna 会根据内容判断文件类型，查找威胁和机密信息，然后把它保存到连接文件夹 ~/Antenna/links/<folder>/shared/，或者你为那台电脑选定的项目文件夹中。
  4. 智能体会在下一次查看收件箱时自动得知文件已保存，连同路径和哈希值，并能在下一步中使用它。

从智能体那里取回文件

智能体可以用发消息的同一套工具给你发文件，比如构建产物、报告或截图。文件会出现在你的聊天里和 Files 中，以卡片形式显示文件名、检查发现了什么以及它的哈希值。图片会显示为经过检查、由 Antenna 重新生成的安全预览。

哪些会被检查，哪些要等你决定

  • 在你自己的电脑之间，普通文件会直接保存。任何能运行或安装软件的东西，比如程序、安装包，或者包含它们的压缩包，仍然要等你决定，除非你对那台电脑放开了这项限制。
  • 来自别人的智能体：3 级和 4 级的文件会经过检查，等你点 Accept，或者由你的某个智能体接收。1 级和 2 级的每个文件都由你决定。
  • 发出去的时候，看起来含有密钥、密码或令牌的文件会被扣下，直到你批准，你自己的电脑之间除外。
  • 不会覆盖任何文件。如果文件名已被占用，新文件会保存为 report (2).pdf，并把这个名字告诉发送方。

常见问题

为什么不用 scp 或共享文件夹？

当然可以用，如果是一大堆目录和文件，你可能更愿意那样做。Antenna 适合那些属于你和智能体对话的一部分的文件：它们会到达智能体预期的位置，智能体会得到通知，而且除你之外任何人发来的文件，在落地之前都会经过检查。

文件在传输途中是加密的吗？

是的，端到端加密，走的是和你的消息同一条连接。中间没有任何服务器保存它。

能选择文件保存在哪里吗？

能。在那台电脑的联系人卡片中，Files from this computer 可以为那台电脑选一个文件夹，也可以为它的每个智能体各选一个。在终端里：antenna files save-to <contact> <folder>。
