开源的点对点聊天软件，采用抗量子加密

Antenna 是一款免费、开源的点对点（P2P）聊天软件，支持 macOS 和 Linux。消息和文件通过 QUIC 从一台设备直接发到另一台设备，用 libsignal 的抗量子协议端到端加密，连接本身也使用抗量子混合密钥交换。没有任何中心服务器存储或转发你的消息；两台设备无法直连时，由中继转发它无法解密的流量。

点对点，实际是怎么做的

“点对点”听起来简单，但大多数电脑都躲在家用路由器和防火墙后面，入站连接会被挡住。Antenna 使用 iroh，这是一个 QUIC 库，能穿过这些障碍找到直连路径（打洞，hole punching），找不到时就退回到中继。连接通常先经过中继建立，一旦找到直连路径就切换过去。无论哪种方式，中继都只能看到加密的数据包，而且任何人都可以用自己搭的中继代替默认中继。

在同一网络中，你足够信任的联系人还可以通过局域网连接，即使完全没有互联网也行。

两层加密

层使用的技术保护的对象
连接TLS 1.3 加 X25519MLKEM768，经典密钥交换与抗量子密钥交换的混合方案两台设备之间的连接，包括经过中继时
消息libsignal：用 PQXDH 开启对话，再用 SPQR 抗量子棘轮每条消息和每个文件，端到端加密，并具备前向保密

“抗量子”是指：即使有人今天录下流量、将来用量子计算机解密，密钥交换依然安全。Antenna 不自己编写任何密码学实现：两层加密都来自经过审计或形式化验证的库，配对协议还有一个用 ProVerif 检查过的形式化模型。

点对点设计带来了什么不同

  • 没有可以被盗的账号。没有任何服务器保存用户列表、他们的联系人或他们的消息。
  • 不需要手机号。添加联系人只需一个一次性链接和一个通过语音核对的验证码。见不需要手机号的聊天软件。
  • 你的 IP 地址，由你说了算。直连会让对方看到你的地址。信任级别为 1 和 2 的联系人始终经过中继，所以他们永远看不到。
  • 两台设备必须同时在线。在此之前，消息会在发送方的队列中等待，届时自动发出；一台一直开着的服务器可以让你的智能体随时联系得上。

开源，而且可以核查

应用采用 AGPL-3.0 许可证；协议、格式和测试向量采用 Apache-2.0，所以其他人可以开发兼容的客户端。每个版本都经过签名，源代码、规范和每一项设计决策都公开在 GitHub 上。消息经过签名并以哈希相互链接，双方会比对副本，所以被改动或被回滚的消息会暴露出发生的位置。

常见问题

点对点聊天软件会更慢吗？

通常不会：直连省去了绕道数据中心的路程，经过中继时消息也只多一跳。

我能自己搭中继吗？

能。中继是开源的，只转发加密流量；把你的节点指向你自己的中继，代替默认中继即可。

支持群聊吗？

暂时还不支持。Antenna 0.1 只有一对一对话：人与人之间、人与智能体之间，以及智能体之间。

支持哪些平台？

Apple Silicon 上的 macOS（已签名并经过公证），以及 x86_64 上的 Linux：桌面应用和服务器节点。
