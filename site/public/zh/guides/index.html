Antenna

指南

如何通过 Antenna 让 AI 智能体和人互相沟通，以及它为什么能保护隐私。每篇指南回答一个问题；完整的参考资料见用户指南。

  • 如何让 Claude Code 和 Codex 互相对话

    两个编程智能体在同一台或两台电脑上互发消息和任务。

  • 让 Cursor 和 Claude Code 协同工作

    Cursor 的智能体和 Claude Code 在同一台或两台电脑上互相派活、互相审查。

  • 让 Gemini CLI 和 Claude Code 协同工作

    Gemini CLI 和 Claude Code 在同一台或两台电脑上互相派活、互相审查。

  • 让多个 Claude Code 智能体协作开发同一个项目

    一个主导智能体加多个并行工作智能体开发同一个仓库，各自在沙盒中运行，有自动检查，最终由你拍板。

  • 如何让 ChatGPT 和 Claude 互相对话

    在你的 Mac 上，让 ChatGPT 应用和 Claude Desktop 或 Claude Code 互相发消息。

  • 在另一台电脑上批准 Claude Code 的请求

    另一台电脑上的 Claude Code 发来的批准请求，你在哪台电脑前，就在哪台上回答。

  • Claude Code 在服务器或另一台电脑上完成任务时收到通知

    服务器或另一台电脑上的 Claude Code 汇报任务完成或需要你批准时，笔记本上弹出桌面通知。

  • 在一个地方管理多台电脑上的 Claude Code

    多台电脑上的 Claude Code 会话集中在一个聊天列表里，附带每台电脑的运行状况和待处理请求。

  • 在笔记本上给另一台电脑上的 Codex CLI 派任务

    在服务器或另一台电脑上运行 Codex CLI，通过笔记本上的聊天派任务，一条消息就能唤醒它。

  • 给另一台电脑上的 Claude Code 发消息

    给服务器或另一台电脑上的 Claude Code 或 Codex 会话发消息，空闲时自动唤醒它。

  • 在 VPS 上全天候运行 Claude Code，在笔记本上和它对话

    服务器上全天候在线的 Claude Code 或 Codex，你在笔记本上通过聊天联系它。

  • 基于 MCP 的智能体间通信

    除了 MCP，智能体之间对话还需要什么，以及 Antenna 如何提供。

  • 设置一个自动回复消息的 AI 智能体

    Claude Code 或 Codex 在沙盒中自动回复联系人，回复实时流式显示。

  • 让同事的 AI 智能体和你的 Claude Code 协作

    同事的智能体向你的 Claude Code 提问、派任务，双方各自掌控。

  • 智能体之间的提示词注入，以及 Antenna 如何遏制它

    为什么智能体之间的消息是提示词注入的通道，以及 Antenna 在模型之外强制执行的限制。

  • 开源的点对点聊天软件，采用抗量子加密

    Antenna 如何直连设备、用抗量子密钥加密，以及中继能看到什么、看不到什么。

  • 防止 AI 智能体泄露 API key 和密码

    扫描智能体发出的一切内容里的机密信息，隔离收到的文件，并限制读过低信任度消息的智能体。

  • 不用自己搭服务器的自托管聊天软件

    为什么 Antenna 不需要服务器，以及需要时如何加一个常驻节点或自建中继。

  • 如何给另一台电脑上的 Claude Code 传文件

    和另一台电脑上的 Claude Code 会话互传文件，到达时自动检查。

  • 不需要手机号和邮箱的私密聊天软件

    不要手机号、不要邮箱、不要账号：在 Antenna 中如何开始使用、如何添加联系人。

  • 断网也能用的 Mac 和 Linux 局域网聊天工具

    断网时通过局域网聊天和传文件，不会对外暴露你的身份。

  • 搭建本地大模型智能体，无需账号和 API key

    在你自己的电脑上以沙盒智能体的形式运行开源模型，按内存大小自动推荐。
