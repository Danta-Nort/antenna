在笔记本上操控另一台电脑上的 Claude Code

在笔记本和运行 Claude Code 的电脑上都安装 Antenna，把两台电脑作为你自己的电脑配对一次，然后在那台电脑上通过 Antenna 启动 Claude Code。你的笔记本上会出现这个会话的聊天：在里面写下任务，Claude Code 闲着时 Antenna 会唤醒它，它的回复会回到聊天里。消息通过两台电脑之间端到端加密的点对点连接传输，Antenna 不需要任何账号，需要你批准的步骤会送到笔记本上，你用密码回答即可。

Claude Code 自带的 Remote Control 与 Antenna

Claude Code 内置了自己的 Remote Control 功能，Anthropic 的文档里有介绍。本指南讲的是另一种方案：Claude Code 运行在你自己一台常开的电脑上（服务器或台式机），你在笔记本上通过 Antenna 操控它。如果你有以下需求，这个方案适合你：

  • 多台电脑上的多个会话，集中在一个列表里。每个会话都是一个独立的聊天，我的设备 会显示每台电脑的运行状况、上面的智能体，以及在那里等待处理的请求。
  • 属于你自己的连接。消息在一台电脑上加密，在另一台电脑上解密。网络允许时两台电脑直连，否则经过一个只转发加密流量的中继。无需账号，也不用开放入站端口。
  • 由 Antenna 守护进程检查权限，检查发生在运行 Claude Code 的那台电脑上；你在哪台自己的电脑前，就在哪台上回答批准请求。
  • 其他智能体用法相同：Codex 的用法和 Claude Code 一样。

设置

  1. 在两台电脑上安装 Antenna：笔记本上装应用（macOS 或 Linux）；另一台电脑上装应用，如果是 Linux 服务器则装节点： 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
  2. 配对一次。在笔记本上：新联系人 → 邀请，勾选 这是我自己的电脑（∞），点 创建链接 并复制。在服务器上：antenna join '<link>' --trust 5 --label mac；在台式机上：新联系人 → 加入，同样勾选这一项。把一边显示的验证码输入另一边，然后在笔记本上点 联系人已确认，验证码一致。
  3. 在另一台电脑上通过 Antenna 启动 Claude Code。如果是服务器，在项目文件夹里执行（需要 tmux）： 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    回答 Claude Code 一开始的几个问题，然后按 Ctrl-b d 退出：它会继续运行，你的笔记本上会出现一个名为 api-dev 的聊天。如果是台式机：智能体 → AI 应用 → 以 Code 模式启动，Claude Code 会在那台电脑上 Antenna 窗口的一个标签页里运行；让它通过 Antenna 跟你的笔记本打个招呼（只需一次），它的聊天就会出现在笔记本上。
  4. 让笔记本来回答那台电脑的批准请求。在服务器上：antenna devices confirm mac。在台式机上：我的设备 → 笔记本的卡片 → 批准 → 接受用 … 签名的批准，输入你的密码。

在笔记本上操控它

  • 派任务。像给人发消息一样在会话的聊天里写。Claude Code 停在提示符前闲着时，Antenna 会输入一行固定的文字，让它去读你的消息；Antenna 永远不会把你的原文输入终端，也永远不会替你回答 Claude Code 在终端里提出的问题。实验性功能。
  • 打断它。发送前打开 紧急：立即打断：Antenna 会按一次 Esc 结束正在进行的这一轮（如果那里正开着问题或权限提示，则绝不会按），然后 Claude Code 会读你的消息。实验性功能。
  • 批准它的步骤。需要你批准的步骤会显示在 我的设备 中另一台电脑的卡片上，并弹出通知。点 用密码批准，在 Mac 上也可以点 用 Touch ID 批准，或者点 拒绝。实验性功能。
  • 停止它。点该卡片上智能体旁边的 停止智能体及其进程…，会结束 Claude Code 以及它在那台电脑上启动的所有进程。实验性功能。

Claude Code 自己的权限提示（“Do you want to proceed?”）留在另一台电脑上它的终端里，Antenna 从不替你回答。你可以在 Claude Code 的设置里放行日常使用的工具，或者用 antenna session attach 进去回答。

Codex 和其他智能体

Codex 的用法完全一样：在服务器上用 antenna connect codex 和 --cli codex，在台式机上点 Codex 旁边的 以 Code 模式启动（见 Codex CLI 远程控制）。Gemini CLI 可以从 智能体 → AI 应用 接入，通过 Antenna 收发消息，但 Antenna 暂时还不会唤醒它：它要等下一次调用 Antenna 时才会读到新消息。

常见问题

我能在笔记本上看到 Claude Code 的终端吗？

不能。你在聊天里派任务、看回复；终端留在另一台电脑上。想看终端，就在那台电脑上运行 antenna session attach，也可以通过 SSH 进去运行。

另一台电脑需要公网 IP 或开放端口吗？

不需要。两台电脑都是主动向外连接，网络允许时直连，否则经过中继。中继只转发加密流量。

还有谁能给它派任务？

只有与那台电脑配对、并且该智能体可以读取其消息的联系人（加了 --links mac 时，只有你的笔记本），以及你在智能体地图上与它连接的智能体。联系人的消息能让它做什么，由那台电脑上的 Antenna 守护进程根据该联系人的信任级别决定，而不是由 Claude Code 决定。

需要 API key 吗？

不需要。Claude Code 在它运行的电脑上使用你自己的登录，Antenna 只负责传递消息、文件和批准。

能用手机控制吗？

暂时还不能。Antenna 目前在 macOS 和 Linux 上运行。

Antenna 免费且开源，支持 macOS 和 Linux。不需要账号，也不需要手机号。
