在另一台电脑上批准 Claude Code 的请求

通过 Antenna 启动 Claude Code（在窗口里用 Code 模式，或在服务器上用 antenna session），Antenna 守护进程就会检查它使用的每一个工具和发出的每一条消息。某一步需要你点头时，它会变成一个批准请求，出现在你配对为自己电脑的每一台机器上，位于 My devices（我的设备）中，并弹出通知。在那里用这台电脑的密码或 Touch ID 批准：运行 Claude Code 的那台电脑会核验你的答复，执行这一步，然后 Claude Code 继续工作。

哪些请求会找到你

  • 读过联系人消息之后的操作。Claude Code 一旦读过同事的消息，同事的信任级别就决定了它能做什么：在 4 级，每条命令都要等你批准；在 2 级和 3 级，每次编辑都要等你批准，命令则一律拒绝。
  • 修改它自身配置的操作。读过任何联系人的消息之后，哪怕消息来自你自己的笔记本，对 CLAUDE.md、.claude/、shell 配置文件、密钥以及 package.json 这类构建文件的编辑都要等你批准。
  • 可能把你的数据带出去的消息。它一旦读过你项目里的文件，发给 ∞ 以下联系人的每条消息都要等你批准，发给这类联系人、看起来含有密钥、密码或令牌的任何消息也一样。它一旦读过某一段对话，发往另一段对话的消息同样要等你批准。
  • 提问。实验性功能。智能体的提问显示在它所运行的那台电脑上，位于 Questions from your agents（来自智能体的提问）下。想改在笔记本上收到，就在那台电脑上运行 antenna agent escalate api-dev --to mac：之后每个问题都会出现在该智能体的聊天里，你直接在聊天里回答。

Claude Code 自己的权限提示（“Do you want to proceed?”）仍然留在它的终端里：Antenna 从不往里面输入任何内容。你可以在 Claude Code 的设置里放行日常使用的工具，或者用 antenna session attach 进去回答。

设置

  1. 在两台电脑上安装 Antenna，勾选 This is my own computer (∞) 配对一次，做法见在 VPS 上运行 Claude Code。
  2. 通过 Antenna 启动 Claude Code。在桌面电脑上：Agents → AI apps → Start in Code mode。在服务器上： 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
  3. 在运行 Claude Code 的电脑上，接受你打算用来批准的那台电脑的答复：My devices → 那台电脑的卡片 → Approvals → Accept approvals signed with …，输入你的密码。在服务器上：antenna devices confirm mac。

在任意一台电脑上回答

请求显示在 My devices 中发出请求的那台电脑的卡片上（实验性功能），同时会弹出通知，比如“Antenna: approval needed on Mac mini”。卡片会写明是哪个智能体在请求、要做什么、为什么，并引用它的原文；但如果原文里含有机密信息，它就不会离开发出请求的那台电脑。在 Mac 上可以点 Approve with Touch ID（实验性功能），也可以点 Approve with password 并输入你眼前这台电脑的密码，或者点 Deny。

发出请求的电脑会用你在它上面接受过的密钥核验签名，同时核对它自己生成的一次性质询和这一个具体的请求，然后由它自己执行该请求，而且只执行一次。在那台电脑本机上，请求位于 Approval requests（批准请求）中，在终端里则用 antenna approvals 和 antenna approve <id>。

Claude Code 最多等待 50 秒，在此之前批准的步骤会立即执行。超过这个时间，它会先去做别的事；等你批准后，Antenna 会在它的提示符里输入“Approved — continue.”，它就会重新执行这一步。

如果没人回答

请求在 10 分钟后关闭：什么都不会执行，什么也不会发出，Claude Code 会得知没人批准。关闭前不久会有通知提醒你。点 Deny 不需要密码，Claude Code 会得知你拒绝了。

让智能体替你批准

实验性功能。Can approve for…（可以替谁批准）位于 Agents 中，它让你信任的某个智能体回答你其他智能体关于消息和文件的请求，而且只有当请求涉及的一切都处于 ∞ 级别时，它的回答才算数。命令和编辑始终由你亲自批准。

常见问题

Codex 也能用吗？

部分可以。Codex 通过 Antenna 发送的内容会接受同样的检查，这些请求也会送到你所有的电脑上；Codex 自己的命令仍由 Codex 在它终端里的批准机制处理。

任何电脑都能批准吗？

不能。只有你配对为自己电脑、并且在发出请求的那台电脑上接受过其密钥的电脑才行，而且要输入密码。如果丢了一台，就在其余每台电脑上点 Revoke this computer（吊销这台电脑）。

能用手机批准吗？

暂时还不能。Antenna 目前在 macOS 和 Linux 上运行。

Antenna 免费且开源，支持 macOS 和 Linux。不需要账号，也不需要手机号。
