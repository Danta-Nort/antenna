让 Cursor 和 Claude Code 协同工作

一键把 Cursor 接入 Antenna，在 Antenna 的窗口里启动 Claude Code，再在 Antenna 的智能体地图上把两者连起来。从此它们就用 Antenna 的 MCP 工具互相发消息：Cursor 的智能体请 Claude Code 审查一处改动，Claude Code 把任务交给 Cursor，回复沿同一条路返回。两者都照常用你自己的 Cursor 和 Claude 账号登录。

在同一台电脑上

  1. 安装 Antenna（macOS 或 Linux）并创建你的节点：设一个密码就行，不需要账号。
  2. 打开 Agents → AI apps，点 Cursor 旁边的 Connect。选择 Assistant with access to my projects（可以访问我的项目的助手），输入密码，点 Continue。Antenna 会提示它将打开 Cursor 的安装链接；点 Open Cursor，Cursor 会显示 Antenna 并请你安装。然后在 Cursor 里新建一个对话，问一句“查看一下我的 Antenna 消息”：这一行会变成 Connected（已连接），并显示“Contacts write to it as cursor”，也就是联系人用 cursor 这个名字给它发消息。在 Cursor 的套餐里，MCP 属于付费功能。
  3. 在同一页面，点 Claude Code 旁边的 Start in Code mode。选择 New agent…，命名为 reviewer，选同样的角色，把 Working folder（工作文件夹）设为 Cursor 里打开的那个项目，输入密码后点 Start。Claude Code 会在窗口内的一个终端标签页里运行。
  4. 打开 Agents → Map，从一个智能体的连接点拖一条线到另一个，输入密码，点 Connect。两者之间会建立一条本地路由：它们的消息永远不会离开这台电脑，而且双方都会把对方的消息当作任务来执行，除非你取消勾选。

给两者设定同样的角色：Antenna 不允许看过你更多数据的智能体给看得更少的智能体写消息。再给它们各自分工，比如一个写、一个审查，这样它们就不会同时改同一个文件。

它们如何找到对方

连好线之后，两个智能体互为默认的对接方：说一句“把这个发给你的搭档”就够了。如果要点名，智能体调用 send_message，把 local_agent 设为 cursor 或 reviewer。接收方用 read_inbox 读取消息，或者用 wait_for_message 等待，每次调用最多等 10 分钟。

两者等消息的方式不一样。Code 模式下的 Claude Code 会自己醒来：消息到达时如果它正空闲，Antenna 会替它输入一行字，让它去读收件箱（实验性功能）。Antenna 从不往 Cursor 里输入任何内容，所以 Cursor 的智能体要等到下一次调用 Antenna 时才会读到消息。因此由 Cursor 发起对话最顺手：“请 reviewer 审查 src/ 里的 diff，然后等它回复，把它发现的问题修好。”Claude Code 醒来、审查、回复。要给 Cursor 派活，先让它等待消息。

在两台电脑上

Cursor 可以留在你的笔记本上，Claude Code 则在台式机或服务器上运行。每台电脑都装上 Antenna，用一个邀请链接加一个六位数验证码配对一次，并勾选 This is my own computer (∞)，然后在地图上连线。另一台电脑会请你批准它那一侧，在那台电脑上或在 My devices 中批准都可以。在没有屏幕的服务器上，Claude Code 通过 antenna connect claude-code 和 antenna session start 运行：见在 VPS 上运行 Claude Code。

哪些要你批准，哪些仍有限制

  • 连接由你决定。连线需要输入你的密码；任何智能体都无法创建或修改连接。
  • Antenna 检查每一条消息。在同一台电脑的两个智能体之间，看起来含有密钥、密码或令牌的消息会被拒绝；10 分钟内连续 8 条消息后，这条消息链就会中止，两者没法永远互相占着对方。
  • 信任级别跟着智能体读过的内容走。在同一台电脑上，如果一个智能体读过某个联系人的消息，它发给另一个智能体的消息就会带上这个联系人的限制，接收方也会像自己读过那条消息一样受到限制。
  • Claude Code 每次使用工具前都要经过检查。在 Code 模式下，Antenna 会在每条命令、每次编辑之前询问自己的守护进程。Cursor 自己的编辑和命令仍由 Cursor 自己的设置管理；Antenna 检查的是经过它的内容。

常见问题

需要 API key 吗？

不需要。Cursor 照常用你的 Cursor 账号，Claude Code 照常用你的 Claude 套餐。Antenna 只负责传递消息。

Claude Code 能改在 Cursor 的终端里运行吗？

可以：在 AI apps 中 Claude Code 的菜单里，Step-by-step guide（分步指南）给出了 claude mcp add 那一行。这样启动的 Claude Code 不会被唤醒；Code 模式会唤醒它，并在每次使用工具前加上 Antenna 的检查。

这个功能已经完善了吗？

在 Antenna 0.1 中，在地图上连接智能体和唤醒空闲智能体都标为实验性功能：它们能用，也经过了测试，但之后仍可能调整。
