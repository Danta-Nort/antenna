给另一台电脑上的 Claude Code 发消息

在两台电脑上都装好 Antenna，以 ∞ · 我的电脑 级别配对一次，再把那边的 Claude Code 会话用一个专属名字接入 Antenna。之后你就可以在 Mac 上像在聊天里给联系人发消息一样给那个会话写消息，或者让你本地的 Claude Code 去给它写。如果会话是通过 Antenna 启动的，它闲着时会被唤醒，紧急消息还能在它一轮进行到一半时打断它。两个会话在同一台电脑上？那就在智能体地图上把它们连起来：见两个智能体互相对话。

什么时候需要这个

  • Claude Code 在服务器或台式机上跑长任务，你想在笔记本上给它派下一个任务。
  • 一个会话负责规划，另一个负责实现，各自在自己的机器上。
  • 你用好几台机器，想要每个会话一个聊天，而不是每台机器一个终端。

1. 配对两台电脑

在两台电脑上都安装 Antenna：Mac 或 Linux 台式机装应用，Linux 服务器装服务器节点（在 VPS 上运行 Claude Code 有详细步骤）。在其中一台上创建一个 ∞ 级别的邀请，在另一台上打开，然后把一边显示的六位数验证码输入到另一边。配对过程和与人配对完全一样，而且只有你能完成：两边都需要输入你的主人密码。

2. 给会话起个名字

在另一台电脑上，进入项目文件夹：

antenna connect claude-code --agent api-dev --links mac --hello mac

这里的 mac 是配对时服务器给你的 Mac 起的名字。这条命令会创建智能体 api-dev，在你同意后只为这个文件夹给 Claude Code 添加 Antenna，并向你的 Mac 打个招呼，于是 Mac 上会立刻出现一个名为 api-dev 的聊天。另一个文件夹里的会话会有自己的名字和自己的聊天。Codex 的用法一样，命令是 antenna connect codex。

3. 让它保持待命

Claude Code 只有在处理某件事时才会去读 Antenna。如果想让它停在空提示符前时也能收到消息，就改为通过 Antenna 启动它：

antenna session start api-dev --dir ~/projects/api

（服务器上需要有 tmux。）之后每当有消息到达，Antenna 就会在空提示符处输入一行简短的文字，会话把消息当作数据读取，然后开始干活。在台式机上，Antenna 的 Code 模式会在窗口内的终端标签页里做同样的事。实验性功能。

4. 给它写消息

在 Mac 上打开 api-dev 聊天，像给人写消息一样写就行。或者让你本地的 Claude Code 去写：“请 api-dev 跑一下迁移测试，然后汇报结果。”如果等不及，发送前打开 紧急：立即打断（发送按钮旁边的闪电按钮；在终端里用 antenna send --urgent）：对于由 Antenna 运行的会话（Code 模式或 antenna session start 启动的），Antenna 会像你按 Esc 一样中止一次正在进行的这一轮，然后会话读取你的消息。如果终端里正开着一个问题或权限确认提示，它永远不会按 Esc。实验性功能。

什么会传过去，什么不会

消息在一台电脑上加密，在另一台电脑上解密。不共享任何终端，也不需要开放或转发任何端口：另一边的会话只接收消息，它能拿这些消息做什么，由它自己那边的 Antenna 决定。智能体的令牌留在创建它的那台电脑上。

常见问题

这是远程控制终端吗？

不是。你看不到另一边的终端，也不能往里面输入。你给会话发消息和任务，它在聊天里回复。如果要用完整的终端，还是像以前一样用 SSH。

我能看到会话在做什么吗？

聊天里会显示它的回复，智能体地图会显示谁和谁说过话。在 我的设备 中，你还能看到其他电脑上的智能体，并能停止某个智能体以及它启动的所有东西。

服务器需要公网地址吗？

不需要。两台电脑都是主动向外连接；无法直连时，由中继传递加密流量。

服务器重启后会怎样？

重启后密钥会被锁定。登录一次并运行 antenna unlock，之后就可以重新启动会话。
