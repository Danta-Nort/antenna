在笔记本上给另一台电脑上的 Codex CLI 派任务

在两台电脑上都装好 Antenna，把它们作为你自己的电脑配对一次。在运行 Codex 的那台电脑上，用 antenna connect codex 给 Codex 会话起个名字，再用 antenna session start … --cli codex 启动它。你的笔记本上就会出现一个同名的聊天：在里面写下任务，Codex 闲着时 Antenna 就会唤醒它。Codex 读取你的消息，在另一台电脑上干活，然后在聊天里回复。不需要一直开着 SSH 会话，也不需要开放任何入站端口。

你需要准备

  • 在干活的那台电脑上安装并登录 Codex CLI：可以是 x86_64 的 Linux 服务器，也可以是 Mac 或 Linux 台式机。Codex 继续使用你自己的订阅；Antenna 不需要任何 API key。
  • 那台电脑上要有 tmux。如果是服务器，还要运行一次 sudo loginctl enable-linger $USER，这样你退出登录后 Antenna 和会话仍会继续运行。
  • 两台电脑上都装好 Antenna：台式机装应用，服务器装节点（curl -fsSL https://antenna.contact/install.sh | sh）。

1. 配对两台电脑

在笔记本上：New contact → Invite，勾选 This is my own computer (∞)，生成链接，在另一台电脑上打开它（服务器上用 antenna join '<link>' --trust 5 --label mac）。把一边显示的验证码输入到另一边。现在双方都把对方当作你自己的电脑。带截图的分步说明见 在 VPS 上运行 Claude Code，对 Codex 来说步骤完全一样。

2. 给 Codex 会话起个名字

在运行 Codex 的电脑上，进入项目文件夹：

cd ~/projects/api
    antenna connect codex --agent api-codex --links mac --hello mac

这会创建智能体 api-codex 及其专属的令牌文件，把它和你的笔记本关联起来（mac 是配对时这台电脑给你笔记本起的名字），并打个招呼，于是笔记本上会立刻出现一个名为 api-codex 的聊天。你自己的 Codex 设置不会被修改：Antenna 只为这个智能体的会话添加。

3. 通过 Antenna 启动 Codex

antenna session start api-codex --dir ~/projects/api --cli codex
    antenna session attach api-codex

Codex 在 Antenna 自己的 tmux 服务器里启动，不会碰你的 tmux。先 attach 一次，回答 Codex 一开始的几个问题。第一次运行时，Codex 会请你信任 Antenna 的 hooks（“Hooks need review”）：选择 “Trust all and continue”。然后按 Ctrl-b d 退出，Codex 会继续运行。重启后用 --resume 可以接着这个智能体上一次的会话继续。

4. 在笔记本上给它写消息

打开 api-codex 聊天，写下：“跑一下测试，修好失败的，然后告诉我你改了什么。”当 Codex 停在提示符前闲着时，Antenna 会输入一行内置的文字，让它去读收件箱。Antenna 永远不会把你的文字输入终端，也永远不会在 Codex 正在提问时输入任何东西。Codex 通过 Antenna 读取消息，开始干活，然后在聊天里回复。实验性功能。

需要它立刻停下手头的事？发送前打开 Urgent: interrupt now。Antenna 会按一次 Esc 结束当前这一轮，然后唤醒 Codex 处理你的消息。如果要停止这个智能体以及它启动的所有东西，在笔记本的 My devices 中打开另一台电脑的卡片，点 Stop agent and its processes…（就在 api-codex 旁边）。

在台式机上：Code 模式

如果 Codex 运行在装有 Antenna 应用的 Mac 或 Linux 台式机上，可以跳过终端里的这些步骤。在 Code 模式下，点智能体面板里的 +，选择 Codex 和工作文件夹，Codex 就会在窗口内的一个标签页里运行，唤醒方式相同。和其他智能体一样，你在其他电脑上也能访问它的聊天。

常见问题

笔记本上能看到 Codex 的终端吗？

不能。你在聊天里给 Codex 派任务、看它的回复；终端留在另一台电脑上。想看终端的话，就在那台电脑上 antenna session attach，愿意的话也可以通过 SSH。

哪些 Codex 版本可以用？

Codex 0.160 及以后的版本会通过 hooks 报告自己在做什么，Antenna 正是靠这个知道 Codex 是否闲着。如果 Codex 版本更旧，或者你没有信任这些 hooks，Antenna 会等到 Codex 在一轮结束后显示空的输入行，并且在一轮进行中永远不会输入任何东西。

Codex 也能和 Claude Code 对话吗？

能。在智能体地图上把两个智能体连起来，它们各自的消息就会发给对方，无需指定名字：见让 Claude Code 和 Codex 互相对话。

能用手机控制吗？

暂时还不能。Antenna 目前支持 macOS 和 Linux。
