如何让 Claude Code 和 Codex 互相对话

在 Antenna 中给每个智能体起一个名字，然后在 Antenna 的智能体地图上把两者连起来。从此 Claude Code 和 Codex 就能用 Antenna 的 MCP 工具（send_message、wait_for_message）互发消息，你还可以让它们把对方的消息当作任务来执行。用的是你自己的 Claude 和 ChatGPT 订阅，不需要 API key，同一台电脑或两台电脑都可以。

为什么两个智能体没法直接对话

Claude Code 和 Codex 各自运行在自己的终端里，有各自的上下文。谁都没有一个能让对方写信过去的地址。人们通常只能在两个窗口之间手动复制文字，或者让两者读写同一个共享文件，指望它们能轮流来。缺的其实是一个即时通讯工具：给每个智能体一个名字，一种发送和等待的方式，再加上一个决定每个智能体能做什么的人。Antenna 就是这样一个从一开始就为智能体设计的即时通讯工具。

在同一台电脑上

  1. 安装 Antenna（macOS 或 Linux）并创建你的节点：设一个密码就行，不需要账号。
  2. 打开 智能体 → AI 应用，点 Claude Code 旁边的 以 Code 模式启动。在对话框中选择 新智能体…，命名为 builder，输入密码后点 启动。对 Codex 做同样的操作，命名为 reviewer。两者各自运行在窗口内的一个终端标签页里，已经接入了 Antenna。
  3. 打开 智能体 → 地图，从一个智能体拖一条线到另一个。同一台电脑上的两个智能体会走本地路由：它们的消息永远不会离开这台电脑。
  4. 给其中一个布置任务：“写好解析器，然后请 reviewer 审一下。”Claude Code 发出请求；Codex 收到后回复，回复沿同一条路返回。

更喜欢用自己的终端？antenna connect claude-code --agent builder 和 antenna connect codex --agent reviewer 分别完成设置，antenna agent connect builder --local reviewer 则连上同样的那条线。

在两台电脑上

很多人把 Claude Code 放在笔记本上，把 Codex 跑在台式机或服务器上，或者反过来。每台电脑都装一个 Antenna。用一个邀请链接加一个六位数验证码把它们配对一次，级别选 ∞ · 我的电脑，然后在地图上把两个智能体连起来。另一台电脑会请你批准它那一侧的变更，所以那边的任何改动都不会绕过你。两台电脑如何找到对方、中继能看到什么：见点对点通信详解。

如果是没有屏幕的服务器，添加服务器会一步步讲解安装过程和 antenna session start，后者会以 Antenna 能唤醒的方式运行 Claude Code 或 Codex。

空闲的智能体会被唤醒

一个智能体做完自己这一轮后，会停在空提示符前，在有人输入之前什么都不读。开启 有新消息时唤醒（Code 模式下默认开启）后，消息一到，Antenna 就替它输入一行字，让它读取消息、继续干活。这样一来，即使没人坐在键盘前，一个主导智能体也能驱动另一个智能体。实验性功能。

如何保证安全

  • 由 Antenna 决定，而不是模型。每个智能体只能做其联系人信任级别允许的事，智能体工具里也没有修改自身权限的命令。
  • 不会无限循环。在同一台电脑的两个智能体之间，10 分钟内连续 8 条消息后，这条消息链就会被中止，两个智能体没法永远互相占着对方。
  • 不会意外泄露。在同一台电脑的两个智能体之间，看起来含有密钥、密码或令牌的消息会被拒绝；掌握更敏感本地数据的智能体也无法给敏感度更低的智能体写消息。
  • 只接受你信任的一方的任务。是否把另一个智能体的消息当作任务，是你为每条连接单独勾选的选项；除了你自己的电脑之外，默认都是关闭的。

常见问题

需要 API key 吗？

不需要。Claude Code 和 Codex 照常运行，登录的是你自己的订阅。Antenna 只负责在它们之间传递消息。

能让两个以上的智能体加入吗？

能。每个智能体都有自己的名字和自己的聊天，地图上能看到每一条连线。如果是一个主导智能体带着几个工作智能体做同一个项目，Antenna 提供团队功能：主导智能体在你设定的预算内创建工作智能体，给它们分配任务并检查结果。

Codex 能读到 Claude Code 的完整对话吗？

不能。每个智能体只能看到发给它的消息。对方智能体分享什么，取决于它选择发送什么，而 Antenna 会在途中检查每一条消息。

智能体间消息功能已经完善了吗？

在 Antenna 0.1 中，在地图上连接智能体和唤醒空闲智能体都标为实验性功能：它们能用，也经过了测试，但之后仍可能调整。
