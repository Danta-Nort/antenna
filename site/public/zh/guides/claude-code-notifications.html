Claude Code 在服务器或另一台电脑上完成任务时收到通知

在笔记本上通过 Antenna 聊天给 Claude Code 布置任务，它做完后会把结果发回这个聊天：Antenna 给已接入的智能体的说明里写明，要把结果发回给布置任务的联系人。只要 Antenna 的窗口不在前台，你的笔记本就会弹出通知“New message in server · api-dev”。批准请求也会通知你，所以跑到一半停下来的任务不会无人察觉地干等着。Antenna 本身并不监视 Claude Code 的每一轮对话：这份汇报是 Claude Code 自己发的消息。

哪些情况会通知你

  • Claude Code 发给你的消息。通知只写聊天的名字，从不显示内容，同一个聊天每 10 秒最多通知一次。
  • 批准请求。需要你点头的步骤会显示为“Antenna: approval needed on server”，写明是哪个智能体、它要做什么以及剩余时间（“expires in 9 min”），但从不显示请求的原文。请求关闭前大约两分钟会再通知一次；请求在 10 分钟后关闭。来自另一台电脑的请求通过 My devices（我的设备）送到你这里（实验性功能）。
  • 提问。实验性功能。智能体的提问会在它所运行的那台电脑上通知：“A question from your agent”。如果它在服务器上，就在服务器上运行 antenna agent escalate api-dev --to mac，它的问题就会改为出现在你笔记本上该智能体的聊天里。

通知在 macOS 和能显示通知的 Linux 桌面上都可用。笔记本上的 Antenna 必须开着；窗口在前台时，聊天列表里的未读数就够用了。

设置

  1. 在两台电脑上安装 Antenna，勾选 This is my own computer (∞) 配对一次。服务器那一侧的做法见在 VPS 上运行 Claude Code。
  2. 通过 Antenna 启动 Claude Code。在服务器上： 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    在另一台桌面电脑上：Agents → AI apps → Start in Code mode。
  3. 笔记本上什么都不用设置。与智能体的聊天从一开始就会通知你发给你本人的消息和批准请求。

让它向你汇报

在 api-dev 聊天里写下任务，并说明你想收到什么：“运行迁移测试，把失败的地方修好。做完后在这里回复改了哪些内容。”如果 Claude Code 正停在提示符处空闲，Antenna 会替它输入一行字，让它去读你的消息（实验性功能）；它干完活就在同一个聊天里回复，你的笔记本随即弹出通知。

如果是你在它终端里布置的工作（antenna session attach api-dev），就在提示词末尾加上“完成后在 Antenna 上给我发一份总结”。想让它每次都这样做，就在项目的 CLAUDE.md 里加一行：“完成任务后，用 Antenna 的 send_message 给 mac 发一段简短的总结。”

和它遵循的任何指令一样，汇报要等 Claude Code 自己认为做完了才会发出。如果它停在终端里自己的权限提示上（“Do you want to proceed?”），Antenna 看不到，也就不会有任何通知：请在 Claude Code 的设置里放行日常使用的工具。

选择哪些聊天会通知

在聊天那一行点 ⋮，或者右键点击它，然后选 Notifications（通知）：

  • All messages（所有消息）：这个聊天里的每条新消息（与人聊天时的默认设置）。
  • Only when it asks for me（仅在找我时）：发给你本人的消息和批准请求（与智能体聊天时的默认设置）。
  • Off（关闭）：批准请求仍会通知。

如果 Claude Code 不是向你汇报，而是向你的另一个智能体汇报，这些消息默认不会通知你，除非你在同一个菜单里打开 Notify about messages between agents（通知智能体之间的消息）。在终端里：antenna chats notify server --agent api-dev all。

在你眼前这台电脑上

如果 Claude Code 以 Code 模式在你自己的笔记本上运行，窗口在后台时，Antenna 会通知你它的批准请求和提问，但不会通知一轮对话的结束：智能体无法在它自己所在的电脑上给你发消息。这种情况可以用 Claude Code 自己的 hooks，在它停下时运行你指定的命令。

常见问题

通知会显示 Claude Code 写了什么吗？

不会。通知只写“New message in”和聊天的名字，因为通知可能显示在锁定的屏幕上。打开聊天才能看到汇报。

如果我的笔记本在睡眠怎么办？

消息会在服务器上等着，笔记本重新联网后，Antenna 会把它连同通知一起送达。

能在手机上收到通知吗？

暂时还不能。Antenna 目前在 macOS 和 Linux 上运行。

Antenna 免费且开源，支持 macOS 和 Linux。不需要账号，也不需要手机号。
