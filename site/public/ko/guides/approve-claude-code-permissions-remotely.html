다른 컴퓨터에서 Claude Code의 요청 승인하기

Claude Code를 Antenna로 시작하면(창에서는 Code 모드, 서버에서는 antenna session), Antenna 데몬이 Claude Code가 쓰는 모든 도구와 보내는 모든 메시지를 확인해요. 내 판단이 필요한 단계는 승인 요청이 되어, 내 컴퓨터로 페어링한 모든 컴퓨터의 내 기기에 알림과 함께 나타나요. 거기서 그 컴퓨터의 비밀번호나 Touch ID로 승인하면, Claude Code가 돌아가는 컴퓨터가 내 답을 확인하고 그 단계를 실행하고, Claude Code는 하던 일을 이어가요.

나에게 오는 것

  • 연락처의 메시지를 읽은 뒤의 단계. Claude Code가 팀원의 메시지를 읽고 나면, 그 팀원의 신뢰 레벨이 할 수 있는 일을 정해요. 레벨 4에서는 명령마다 내 승인을 기다리고, 레벨 2와 3에서는 편집마다 승인을 기다리며 명령은 거부돼요.
  • 자기 설정을 바꾸는 단계. 어떤 연락처의 메시지든, 내 노트북에서 온 메시지라도 읽고 나면, CLAUDE.md, .claude/, 셸 프로필, 키, package.json 같은 빌드 파일의 편집은 내 승인을 기다려요.
  • 내 데이터를 밖으로 가져갈 수 있는 메시지. 프로젝트 파일을 읽고 나면 ∞보다 낮은 연락처에 보내는 메시지는 모두 승인을 기다리고, 그런 연락처에 보내는 메시지 중 키나 비밀번호, 토큰이 든 것처럼 보이는 메시지도 마찬가지예요. 한 대화를 읽고 나면, 다른 대화로 보내는 메시지도 승인을 기다려요.
  • 질문. 실험적 기능이에요. 에이전트의 질문은 그 에이전트가 돌아가는 컴퓨터의 내 에이전트의 질문에 나타나요. 노트북에서 받고 싶다면 그 컴퓨터에서 antenna agent escalate api-dev --to mac을 실행하세요. 그러면 질문이 에이전트의 채팅으로 오고, 채팅에서 답하면 돼요.

Claude Code 자체의 권한 확인 창(“Do you want to proceed?”)은 Claude Code의 터미널에 그대로 남아요. Antenna는 거기에 아무것도 입력하지 않아요. 자주 쓰는 도구는 Claude Code 설정에서 허용해 두거나, antenna session attach로 들어가서 답하세요.

설정하기

  1. 두 컴퓨터 모두에 Antenna를 설치하고, 내 컴퓨터예요(∞)를 체크해서 한 번 페어링하세요. 방법은 VPS에서 Claude Code 돌리기와 같아요.
  2. Antenna로 Claude Code를 시작하세요. 데스크톱에서는 에이전트 → AI 앱 → Code 모드로 시작, 서버에서는 이렇게 해요. 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
  3. Claude Code가 돌아가는 컴퓨터에서, 승인에 쓸 컴퓨터의 답을 받아들이세요. 내 기기 → 그 컴퓨터의 카드 → 승인 → …(으)로 서명된 승인 받아들이기에서 비밀번호를 입력하면 돼요. 서버에서는 antenna devices confirm mac을 실행하세요.

어느 컴퓨터에서든 답하기

요청은 내 기기에서 요청한 컴퓨터의 카드에 나타나고(실험적 기능), “Antenna: Mac mini에서 승인 필요” 같은 알림이 와요. 카드에는 어떤 에이전트가, 무엇을, 왜 요청하는지와 그 문구가 그대로 보여요. 단, 비밀 정보가 든 문구는 요청한 컴퓨터 밖으로 나가지 않아요. Mac에서는 Touch ID로 승인(실험적 기능)을, 지금 쓰는 컴퓨터의 비밀번호로는 비밀번호로 승인을 누르거나, 거부를 누르세요.

요청한 컴퓨터는 거기서 받아들인 키, 자신이 낸 일회용 챌린지, 그리고 바로 이 요청에 비춰 서명을 확인한 다음, 요청을 직접 한 번만 실행해요. 요청한 컴퓨터 자체에서는 요청이 승인 요청에 있고, 터미널에서는 antenna approvals와 antenna approve <id>로 다룰 수 있어요.

Claude Code는 최대 50초 동안 기다리고, 그 안에 승인된 단계는 바로 실행돼요. 그보다 늦으면 다른 일을 하고 있다가, 내가 승인하면 Antenna가 프롬프트에 “Approved — continue.”를 입력하고 Claude Code가 그 단계를 다시 실행해요.

아무도 답하지 않으면

요청은 10분 뒤에 닫혀요. 아무것도 실행되지 않고 아무것도 보내지지 않으며, Claude Code는 아무도 승인하지 않았다는 걸 알게 돼요. 닫히기 조금 전에 알림으로 알려 줘요. 거부는 비밀번호가 필요 없고, 누르면 Claude Code는 내가 거절했다는 걸 알게 돼요.

나 대신 승인하는 에이전트

실험적 기능이에요. 대신 승인할 대상…을 에이전트에서 설정하면, 내가 믿는 에이전트가 다른 에이전트들의 메시지와 파일에 관한 요청에 답할 수 있어요. 그 답은 요청이 건드리는 모든 것이 ∞일 때만 인정돼요. 명령과 편집은 언제나 나에게 와요.

자주 묻는 질문

Codex에서도 되나요?

일부는 돼요. Codex가 Antenna를 통해 보내는 것은 똑같이 확인되고, 그 요청은 내 모든 컴퓨터로 와요. Codex 자체의 명령은 여전히 Codex의 터미널에서 Codex의 승인을 거쳐요.

아무 컴퓨터나 승인할 수 있나요?

아니요. 내 컴퓨터로 페어링했고 요청하는 컴퓨터에서 키를 받아들인 컴퓨터만, 비밀번호로 승인할 수 있어요. 잃어버린 컴퓨터는 나머지 컴퓨터마다 이 컴퓨터 회수를 누르세요.

휴대폰으로 승인할 수 있나요?

아직은 안 돼요. 지금은 Antenna가 macOS와 Linux에서 돌아가요.

Antenna는 무료 오픈소스예요. macOS와 Linux에서 쓸 수 있고, 계정도 전화번호도 필요 없어요.
