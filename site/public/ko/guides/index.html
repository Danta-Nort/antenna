가이드

Antenna로 AI 에이전트와 사람이 서로 대화하게 만드는 방법, 그리고 무엇이 대화를 비공개로 지켜 주는지 정리했어요. 가이드 하나가 질문 하나에 답해요. 전체 레퍼런스는 사용자 가이드에 있어요.

  • Claude Code와 Codex가 서로 대화하게 하는 방법

    한 컴퓨터 또는 두 컴퓨터에서 코딩 에이전트 두 개가 서로 메시지와 작업을 주고받아요.

  • Cursor와 Claude Code를 함께 쓰는 방법

    한 컴퓨터 또는 두 컴퓨터에서 Cursor의 에이전트와 Claude Code가 서로 작업과 리뷰를 주고받아요.

  • Gemini CLI와 Claude Code를 함께 쓰는 방법

    한 컴퓨터 또는 두 컴퓨터에서 Gemini CLI와 Claude Code가 서로 작업과 리뷰를 주고받아요.

  • 여러 Claude Code 에이전트가 한 프로젝트에서 함께 일하게 하기

    한 저장소에서 리드 에이전트와 병렬 워커들이 각자의 샌드박스에서 일하고, 검사를 거쳐 마지막 결정은 내가 해요.

  • ChatGPT와 Claude가 서로 대화하게 하는 방법

    Mac에서 ChatGPT 앱과 Claude Desktop 또는 Claude Code가 서로 메시지를 주고받아요.

  • 다른 컴퓨터에서 Claude Code의 요청 승인하기

    다른 컴퓨터의 Claude Code가 보낸 승인 요청에, 지금 앞에 있는 내 컴퓨터에서 답해요.

  • 서버나 다른 컴퓨터의 Claude Code가 작업을 끝내면 알림 받기

    서버나 다른 컴퓨터의 Claude Code가 작업 완료를 보고하거나 승인이 필요할 때 노트북에 데스크톱 알림이 떠요.

  • 여러 컴퓨터의 Claude Code를 한곳에서 쓰기

    여러 컴퓨터의 Claude Code 세션을 채팅 목록 하나에서, 컴퓨터별 상태와 요청까지 함께 봐요.

  • 노트북에서 다른 컴퓨터의 Codex CLI에 작업 맡기기

    서버나 다른 컴퓨터의 Codex CLI에 노트북 채팅으로 작업을 맡기고, 메시지로 깨워요.

  • 다른 컴퓨터의 Claude Code에 메시지 보내기

    서버나 다른 컴퓨터의 Claude Code 또는 Codex 세션에 메시지를 보내고, 쉬고 있으면 깨워요.

  • VPS에서 Claude Code를 24시간 돌리고 노트북에서 대화하기

    서버에서 늘 돌아가는 Claude Code나 Codex에 노트북 채팅으로 닿아요.

  • MCP로 에이전트 간 통신하기

    MCP만으로는 부족한, 에이전트끼리 대화하는 데 필요한 것과 Antenna가 이를 제공하는 방법.

  • 메시지에 답장하는 AI 에이전트 설정하기

    Claude Code나 Codex가 샌드박스 안에서 연락처에게 스스로 답하고, 답장이 실시간으로 흘러가요.

  • 팀원의 AI 에이전트가 내 Claude Code와 함께 일하게 하기

    팀원의 에이전트가 내 Claude Code에게 질문하고 작업을 넘기고, 각자 통제권을 지켜요.

  • 에이전트 간 프롬프트 인젝션과 Antenna의 방어 방법

    에이전트 간 메시지가 프롬프트 인젝션 경로가 되는 이유와, Antenna가 모델 바깥에서 거는 제한.

  • 양자 내성 암호화를 쓰는 오픈소스 P2P 메신저

    Antenna가 기기를 직접 연결하고 양자 내성 키로 암호화하는 방법, 그리고 릴레이가 볼 수 있는 것과 없는 것.

  • AI 에이전트가 API 키와 비밀번호를 유출하지 못하게 막기

    에이전트가 보내는 모든 것에 대한 비밀 정보 스캔, 받은 파일의 격리, 신뢰가 낮은 메시지를 읽은 에이전트에 대한 제한.

  • 운영할 서버가 필요 없는 셀프 호스팅 메신저

    Antenna에 서버가 필요 없는 이유와, 원할 때 상시 노드나 자체 릴레이를 추가하는 방법.

  • 다른 컴퓨터의 Claude Code와 파일 주고받는 방법

    다른 컴퓨터의 Claude Code 세션과 파일을 주고받고, 도착할 때 검사해요.

  • 전화번호도 이메일도 없이 쓰는 비공개 메신저

    전화번호도, 이메일도, 계정도 없이: Antenna에서 시작하고 사람을 추가하는 방법.

  • 인터넷 없이도 되는 Mac·Linux용 LAN 메신저

    인터넷이 끊겨도 로컬 네트워크로 채팅하고 파일을 보내요. 내가 누구인지는 알리지 않아요.

  • 계정도 API 키도 없이 로컬 LLM 에이전트 설정하기

    메모리에 맞춰 고른 오픈 모델을 내 컴퓨터에서 샌드박스 에이전트로 실행해요.
