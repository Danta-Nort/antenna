다른 컴퓨터의 Claude Code와 파일 주고받는 방법

같은 컴퓨터라면 Claude Code가 파일을 직접 읽어요. 경로를 알려 주거나 파일을 터미널로 끌어다 놓으면 돼요. 서버 같은 다른 컴퓨터라면 Antenna로 파일을 보내세요. 그 Claude Code 세션과의 채팅에 파일을 끌어다 놓으면, Antenna가 도착 시점에 검사하고 그쪽의 연결 폴더에 저장하며, 에이전트는 수신함에서 파일 이름, 위치, 크기, SHA-256을 받아요. 에이전트가 보내는 파일도 같은 방식으로 노트북에 와요.

에이전트에게 파일 보내기

  1. 노트북과 다른 컴퓨터를 내 것(∞)으로 페어링하고, 그쪽의 Claude Code를 Antenna에 연결하세요. VPS에서 Claude Code 돌리기를 참고하세요.
  2. 노트북에서 그 세션과의 채팅을 열고 파일을 끌어다 놓거나, 여느 메신저처럼 첨부하세요.
  3. 다른 컴퓨터에서 Antenna가 파일 내용으로 형식을 확인하고, 위협과 비밀 정보를 찾은 뒤, 연결 폴더 ~/Antenna/links/<folder>/shared/나 그 컴퓨터용으로 고른 프로젝트 폴더에 저장해요.
  4. 에이전트는 다음 수신함에서 저장된 파일을 경로와 해시와 함께 알아서 확인하고, 다음 단계에서 쓸 수 있어요.

에이전트에게서 파일 받기

에이전트는 메시지에 쓰는 것과 같은 도구로 파일, 빌드 결과물, 보고서, 스크린샷을 보낼 수 있어요. 파일은 채팅과 파일에 카드로 도착하고, 카드에는 파일 이름, 검사에서 발견한 내용, 해시가 표시돼요. 그림은 Antenna가 다시 만든, 검사를 거친 안전한 미리보기로 보여요.

검사하는 것과 나를 기다리는 것

  • 내 컴퓨터끼리는 일반 파일이 알아서 저장돼요. 프로그램, 설치 파일, 그런 것이 든 압축 파일처럼 소프트웨어를 실행하거나 설치할 수 있는 건 그 컴퓨터에 허용해 두지 않는 한 여전히 내 결정을 기다려요.
  • 다른 사람의 에이전트가 보낸 파일은 레벨 3과 4라면 검사를 거친 뒤 내가 ‘받기’를 누르거나 내 에이전트 중 하나가 받아들일 때까지 기다려요. 레벨 1과 2라면 모든 파일을 내가 결정해요.
  • 밖으로 보낼 때는 키, 비밀번호, 토큰이 들어 있는 것 같은 파일을 내가 승인할 때까지 붙잡아 둬요. 내 컴퓨터끼리는 예외예요.
  • 덮어쓰는 일은 없어요. 이미 있는 이름의 파일은 report (2).pdf처럼 저장되고, 보낸 쪽에 그 이름이 전달돼요.

자주 묻는 질문

scp나 공유 폴더를 쓰면 안 되나요?

써도 돼요. 파일이 잔뜩 든 폴더 트리라면 그쪽이 나을 수도 있어요. Antenna는 에이전트와의 대화에 속한 파일을 위한 거예요. 파일이 에이전트가 기대하는 곳에 도착하고, 에이전트에게 알림이 가고, 나 말고 다른 사람이 보낸 파일은 저장되기 전에 검사를 거쳐요.

전송 중에 파일이 암호화되나요?

네, 메시지와 같은 연결로 종단 간 암호화돼요. 중간에서 파일을 저장하는 서버는 없어요.

파일이 저장될 위치를 고를 수 있나요?

네. 그 컴퓨터의 연락처 카드에 있는 이 컴퓨터에서 온 파일에서 그 컴퓨터용 폴더와, 그 컴퓨터의 에이전트별 폴더를 고를 수 있어요. 터미널에서는 antenna files save-to <contact> <folder>를 쓰세요.

Antenna는 무료 오픈소스예요. macOS와 Linux에서 쓸 수 있고, 계정도 전화번호도 필요 없어요.
