VPS에서 Claude Code를 24시간 돌리고 노트북에서 대화하기

Linux VPS에 Claude Code와 Antenna 노드를 설치하고, 서버와 노트북을 한 번 페어링한 다음, 프로젝트 폴더에서 Antenna로 Claude Code를 시작하세요. 그러면 로그아웃한 뒤에도 Claude Code가 자기 tmux 세션에서 계속 돌고, 메시지가 오면 깨어나서 노트북의 채팅으로 답해요. 열어야 할 인바운드 포트도, 유지해야 할 SSH 세션도 없고, Codex도 똑같이 돼요.

준비물

  • Claude Code(또는 Codex)가 설치되고 로그인된 x86_64 Linux 서버, 그리고 tmux.
  • 노트북의 Antenna: macOS 또는 Linux.

1. 서버에 Antenna 노드 설치하기

curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER

설치 스크립트는 서명된 매니페스트에서 최신 릴리스를 읽고, 아카이브를 확인한 뒤, antennad와 antenna를 ~/.local/bin에 systemd 사용자 서비스로 설치하고(root 권한 불필요), 비밀번호로 노드를 만들어요. 두 번째 줄은 로그아웃한 뒤에도 서비스가 계속 돌게 해요. Ubuntu나 Fedora라면 .deb나 .rpm으로 설치해도 돼요.

2. 노트북과 페어링하기

노트북에서 New contact → Invite로 가서 이름을 붙이고, This is my own computer (∞)를 체크한 다음, Create link를 눌러 링크를 복사하세요. 서버에서는:

antenna join '<link>' --trust 5 --label mac

작은따옴표를 꼭 붙이세요. 링크에 #이 들어 있거든요. 노트북에 표시된 코드를 서버 터미널에 입력한 다음, 노트북에서 The contact confirmed — codes match를 누르세요. 레벨 5는 양쪽 모두 ∞라서, 서버가 내 컴퓨터로 취급돼요.

3. Antenna로 Claude Code 시작하기

cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev

connect 줄은 세션에 전용 에이전트와 토큰을 주고, 인사를 보내서 노트북에 api-dev라는 채팅이 나타나게 해요. start 줄은 Antenna 전용 tmux 서버에서 Claude Code를 실행해요(내 tmux는 건드리지 않아요). 한 번 붙어서 폴더를 신뢰할지 같은 Claude Code의 첫 질문에 답한 다음, Ctrl-b d로 빠져나오세요. Claude Code는 계속 돌아요. Codex라면 antenna connect codex와 --cli codex를 쓰세요.

4. 대화하기

노트북의 api-dev 채팅에 쓰세요: “마이그레이션 테스트 돌리고 실패하는 거 고쳐 줘.” Claude Code가 프롬프트에서 쉬고 있으면 Antenna가 짧은 한 줄을 입력해서 메시지를 읽게 해요. 연락처의 텍스트를 입력하거나 Claude Code 대신 질문에 답하는 일은 절대 없어요. My devices의 서버 카드에는 서버 상태와 에이전트가 보이고, 서버의 요청을 노트북에서 승인할 수 있어요.

재부팅한 뒤에는

서버가 재시작되면 노드의 키가 잠겨요. 서비스는 돌지만, 내가 로그인해서 antenna unlock을 실행할 때까지 연결은 조용히 있어요. 그래서 서버 디스크를 복사해 가도 누구도 내 키를 얻을 수 없어요. 잠겨 있는지는 antenna status로 확인할 수 있어요.

자주 묻는 질문

그냥 SSH와 tmux를 쓰면 안 되나요?

터미널 앞에 앉아 있는 동안은 그것도 돼요. Antenna는 노트북에서 언제든 메시지를 보낼 수 있는 채팅을 더해 주고, 메시지를 보내면 세션을 깨우고, 다른 에이전트도 일을 맡길 수 있게 해 줘요. 권한은 Antenna가 직접 확인하고요.

서버에 공인 IP나 열린 포트가 필요한가요?

아니요. 양쪽 모두 바깥으로 연결해요. 네트워크가 허락하면 직접, 아니면 릴레이를 거쳐서요. 릴레이는 암호화된 트래픽만 전달해요.

서버 하나에서 세션을 여러 개 돌릴 수 있나요?

네. 프로젝트 폴더마다 에이전트 하나씩, 각자 자기 이름과 노트북의 자기 채팅을 가져요.

ARM 빌드가 있나요?

아직은 없어요. 서버 노드는 x86_64 Linux용으로 빌드돼요.

Antenna는 무료 오픈소스예요. macOS와 Linux에서 쓸 수 있고, 계정도 전화번호도 필요 없어요.
