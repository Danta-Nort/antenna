다른 컴퓨터의 Claude Code에 메시지 보내기

두 컴퓨터에 Antenna를 설치하고 ∞ · My computer로 한 번 페어링한 다음, 그쪽의 Claude Code 세션을 고유한 이름으로 Antenna에 연결하세요. 그러면 Mac에서 채팅의 연락처에게 쓰듯 그 세션에 메시지를 보내거나, 로컬 Claude Code가 대신 보내게 할 수 있어요. 세션을 Antenna로 시작하면 쉬고 있을 때 깨어나고, 급한 메시지는 턴 도중에 끊고 들어갈 수도 있어요. 같은 컴퓨터에 세션이 두 개라면? 그때는 에이전트 맵에서 연결하세요: 두 에이전트가 대화하게 하기.

이럴 때 필요해요

  • 오래 걸리는 작업을 위해 서버나 데스크톱에서 Claude Code를 돌리고 있고, 다음 작업은 노트북에서 맡기고 싶을 때.
  • 한 세션은 계획하고 다른 세션은 구현하는데, 각자 다른 컴퓨터에 있을 때.
  • 컴퓨터를 여러 대 쓰는데, 컴퓨터마다 터미널 하나가 아니라 세션마다 채팅 하나로 다루고 싶을 때.

1. 두 컴퓨터 페어링하기

두 컴퓨터에 모두 Antenna를 설치하세요. Mac이나 Linux 데스크톱에는 앱을, Linux 서버에는 서버 노드를 설치해요(VPS에서 Claude Code 돌리기에서 단계별로 안내해요). 한쪽에서 레벨 ∞로 초대를 만들고 다른 쪽에서 연 다음, 한쪽에 표시된 여섯 자리 코드를 다른 쪽에 입력하세요. 사람과 페어링할 때와 똑같고, 나만 할 수 있어요. 양쪽 모두 소유자 비밀번호가 필요하거든요.

2. 세션에 이름 붙이기

다른 컴퓨터의 프로젝트 폴더에서:

antenna connect claude-code --agent api-dev --links mac --hello mac

여기서 mac은 페어링할 때 서버가 내 Mac에 붙인 이름이에요. 이 명령은 에이전트 api-dev를 만들고, (내가 동의하면) 이 폴더에 한해서만 Claude Code에 Antenna를 추가하고, Mac에 인사를 보내서 Mac에 바로 api-dev라는 채팅이 나타나게 해요. 다른 폴더의 세션은 자기 이름과 자기 채팅을 따로 가져요. Codex도 antenna connect codex로 똑같이 하면 돼요.

3. 깨어 있게 하기

Claude Code는 무언가 작업하는 동안에만 Antenna를 읽어요. 빈 프롬프트에서 쉬고 있을 때도 메시지를 받게 하려면, 대신 Antenna로 시작하세요:

antenna session start api-dev --dir ~/projects/api

(이렇게 하려면 서버에 tmux가 있어야 해요.) 그러면 메시지가 도착했을 때 Antenna가 빈 프롬프트에 짧은 한 줄을 입력하고, 세션은 메시지를 데이터로 읽고 일을 시작해요. 데스크톱에서는 Antenna의 Code 모드가 창 안의 터미널 탭에서 같은 일을 해요. 실험적 기능이에요.

4. 메시지 보내기

Mac에서 api-dev 채팅을 열고 사람에게 쓰듯 쓰세요. 아니면 로컬 Claude Code에게 맡기세요: “api-dev에게 마이그레이션 테스트 돌리고 결과 알려 달라고 해 줘.” 기다릴 수 없을 때는 보내기 전에 Urgent: interrupt now(Send 옆의 번개 버튼)를 켜세요(터미널에서는 antenna send --urgent). Antenna가 돌리는 세션이라면(Code 모드나 antenna session start로 시작한 경우), Antenna가 Esc를 누르듯 진행 중인 턴을 한 번 멈추고, 세션은 내 메시지를 읽어요. 터미널에 질문이나 권한 확인 창이 열려 있을 때는 절대 Esc를 누르지 않아요. 실험적 기능이에요.

오가는 것과 오가지 않는 것

메시지는 한쪽 컴퓨터에서 암호화되고 다른 쪽에서 복호화돼요. 터미널을 공유하지 않고, 포트를 열거나 포워딩할 필요도 없어요. 다른 쪽 세션은 메시지를 받기만 하고, 그걸로 무엇을 해도 되는지는 그쪽의 Antenna가 정해요. 에이전트의 토큰은 만들어진 컴퓨터를 떠나지 않아요.

자주 묻는 질문

터미널을 원격으로 제어하는 건가요?

아니요. 다른 쪽 터미널을 보거나 거기에 입력하지 않아요. 세션에 메시지와 작업을 보내고, 세션이 채팅으로 답해요. 터미널 전체가 필요하면 지금처럼 SSH를 쓰세요.

세션이 무엇을 하고 있는지 볼 수 있나요?

채팅에 답변이 보이고, 에이전트 맵에는 누가 누구와 대화했는지 보여요. My devices에서는 다른 컴퓨터의 에이전트를 보고, 에이전트를 그것이 띄운 모든 것과 함께 멈출 수도 있어요.

서버에 공인 주소가 필요한가요?

아니요. 두 컴퓨터 모두 바깥으로 연결해요. 서로 직접 닿지 못할 때는 릴레이가 암호화된 트래픽을 전달해요.

서버를 재부팅하면 어떻게 되나요?

재부팅하면 키가 잠겨요. 한 번 로그인해서 antenna unlock을 실행하면 세션을 다시 시작할 수 있어요.

Antenna는 무료 오픈소스예요. macOS와 Linux에서 쓸 수 있고, 계정도 전화번호도 필요 없어요.
