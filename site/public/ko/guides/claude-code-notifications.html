서버나 다른 컴퓨터의 Claude Code가 작업을 끝내면 알림 받기

노트북에서 Antenna 채팅으로 Claude Code에게 작업을 주면, 끝났을 때 결과를 그 채팅으로 다시 보내요. Antenna의 안내문이 연결된 에이전트에게, 작업을 준 연락처로 결과를 돌려보내라고 알려 주거든요. Antenna 창이 앞에 있지 않으면 노트북에 “New message in server · api-dev” 알림이 떠요. 승인 요청도 알려 주니, 중간에 멈춘 작업이 아무도 모르게 기다리고 있을 일이 없어요. Antenna가 Claude Code의 턴을 직접 지켜보는 건 아니에요. 보고는 Claude Code가 직접 보내는 메시지예요.

알림이 오는 경우

  • Claude Code가 나에게 보낸 메시지. 알림에는 채팅 이름만 나오고 내용은 절대 나오지 않으며, 채팅마다 10초에 한 번까지만 와요.
  • 승인 요청. 내 판단이 필요한 단계는 “Antenna: approval needed on server”로 나타나요. 에이전트, 하려는 일, 남은 시간(“expires in 9 min”)은 보이지만 요청 문구는 절대 보이지 않아요. 요청이 닫히기 2분쯤 전에 알림이 한 번 더 오고, 요청은 10분 뒤에 닫혀요. 다른 컴퓨터에서 온 요청은 My devices(내 기기)로 와요(실험적 기능).
  • 질문. 실험적 기능이에요. 에이전트의 질문은 그 에이전트가 돌아가는 컴퓨터에서 “A question from your agent”라는 알림으로 와요. 서버라면 서버에서 antenna agent escalate api-dev --to mac을 실행하세요. 그러면 질문이 노트북의 그 에이전트 채팅으로 와요.

알림은 macOS와, 알림을 표시하는 Linux 데스크톱에서 동작해요. 노트북에서 Antenna가 열려 있어야 해요. 창이 앞에 있을 때는 채팅 목록의 안 읽은 메시지 수로 충분해요.

설정하기

  1. 두 컴퓨터 모두에 Antenna를 설치하고, This is my own computer (∞)를 체크해서 한 번 페어링하세요. 서버 쪽은 VPS에서 Claude Code 돌리기에서 차근차근 설명해요.
  2. Antenna로 Claude Code를 시작하세요. 서버에서는 이렇게 해요. 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    두 번째 데스크톱에서는 Agents → AI apps → Start in Code mode를 쓰세요.
  3. 노트북에서는 설정할 게 없어요. 에이전트와의 채팅은 처음부터 나에게 직접 온 메시지와 승인 요청을 알려 줘요.

보고 부탁하기

api-dev 채팅에 작업을 쓰고, 무엇을 돌려받고 싶은지도 말하세요. 예를 들면 “마이그레이션 테스트를 돌리고 실패하는 걸 고쳐 줘. 끝나면 무엇을 바꿨는지 여기에 답해 줘.” Claude Code가 프롬프트에서 쉬고 있으면, Antenna가 내 메시지를 읽도록 한 줄을 입력해 줘요(실험적 기능). Claude Code는 작업을 마치고 같은 채팅에 답하고, 노트북에 알림이 떠요.

터미널에서 시작한 작업(antenna session attach api-dev)이라면, 프롬프트 끝에 “끝나면 Antenna로 요약을 보내 줘”를 붙이세요. 매번 그렇게 하게 하려면 프로젝트의 CLAUDE.md에 한 줄을 추가하세요. “작업을 끝내면 Antenna의 send_message로 mac에 짧은 요약을 보낼 것.”

보고는 다른 지시를 따를 때와 마찬가지로, Claude Code가 끝났다고 판단할 때 와요. Claude Code가 터미널에서 자체 권한 확인 창(“Do you want to proceed?”)에 멈춰 있으면 Antenna는 그걸 보지 못하고, 아무 알림도 오지 않아요. 자주 쓰는 도구는 Claude Code 설정에서 허용해 두세요.

알림 받을 채팅 고르기

채팅 줄의 ⋮을 열거나 오른쪽 클릭한 다음 Notifications(알림)를 고르세요.

  • All messages(모든 메시지): 이 채팅의 새 메시지 전부(사람과의 채팅 기본값).
  • Only when it asks for me(나를 찾을 때만): 나에게 직접 온 메시지와 승인 요청(에이전트와의 채팅 기본값).
  • Off(끄기): 승인 요청은 그래도 알려 줘요.

Claude Code가 나 대신 내 다른 에이전트에게 보고하면, 같은 메뉴에서 Notify about messages between agents(에이전트끼리 주고받는 메시지 알림)를 켜지 않는 한 그 메시지는 알림 없이 와요. 터미널에서는 antenna chats notify server --agent api-dev all을 실행하세요.

지금 앞에 있는 컴퓨터에서

내 노트북에서 Claude Code를 Code 모드로 돌리면, 창이 뒤에 있을 때 Antenna가 승인 요청과 질문은 알려 주지만 턴이 끝난 건 알려 주지 않아요. 에이전트는 자기가 돌아가는 컴퓨터에 있는 나에게 메시지를 보낼 수 없거든요. 이럴 때는 Claude Code 자체의 hooks로, 멈출 때 내 명령을 실행하게 할 수 있어요.

자주 묻는 질문

알림에 Claude Code가 쓴 내용이 보이나요?

아니요. 알림은 잠긴 화면에도 뜰 수 있어서 “New message in”과 채팅 이름만 보여 줘요. 보고를 읽으려면 채팅을 여세요.

노트북이 잠자기 상태면 어떻게 되나요?

메시지는 서버에서 기다리다가, 노트북이 다시 온라인이 되면 Antenna가 알림과 함께 전해 줘요.

휴대폰으로 알림을 받을 수 있나요?

아직은 안 돼요. 지금은 Antenna가 macOS와 Linux에서 돌아가요.

Antenna는 무료 오픈소스예요. macOS와 Linux에서 쓸 수 있고, 계정도 전화번호도 필요 없어요.
