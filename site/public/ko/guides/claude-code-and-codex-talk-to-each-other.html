Claude Code와 Codex가 서로 대화하게 하는 방법

Antenna에서 에이전트마다 이름을 하나씩 붙이고, Antenna의 에이전트 맵에서 둘을 연결하세요. 그때부터 Claude Code와 Codex는 Antenna의 MCP 도구(send_message, wait_for_message)로 서로 메시지를 보내고, 원하면 상대의 메시지를 작업으로 받게 할 수도 있어요. 내 Claude와 ChatGPT 구독으로 동작하고, API 키는 필요 없어요. 한 컴퓨터에서도, 두 컴퓨터에 걸쳐서도 돼요.

두 에이전트가 그냥은 대화할 수 없는 이유

Claude Code와 Codex는 각자 자기 터미널에서, 자기 컨텍스트를 갖고 돌아가요. 어느 쪽에도 상대가 메시지를 보낼 주소가 없어요. 그래서 보통은 두 창 사이에서 텍스트를 손으로 복사하거나, 둘이 같은 파일을 읽고 쓰게 해 놓고 차례를 잘 지키길 바라죠. 빠진 건 메신저예요. 에이전트마다 이름이 있고, 보내고 기다리는 방법이 있고, 각 에이전트가 무엇을 할 수 있는지 정해 주는 누군가가 있어야 해요. Antenna가 바로 그 메신저이고, 처음부터 에이전트를 위해 만들었어요.

한 컴퓨터에서

  1. Antenna를 설치하고(macOS 또는 Linux) 노드를 만드세요. 비밀번호 하나면 되고, 계정은 없어요.
  2. Agents → AI apps를 열고 Claude Code 옆의 Start in Code mode를 고르세요. 대화상자에서 New agent…를 고르고 이름을 builder로 정한 뒤, 비밀번호를 입력하고 Start를 누르세요. Codex도 reviewer라는 이름으로 똑같이 하세요. 각각 창 안의 자기 터미널 탭에서 돌고, 이미 Antenna에 연결돼 있어요.
  3. Agents → Map을 열고 한 에이전트에서 다른 에이전트로 끌어다 놓으세요. 같은 컴퓨터의 두 에이전트는 로컬 경로로 연결돼서, 메시지가 컴퓨터 밖으로 절대 나가지 않아요.
  4. 둘 중 하나에게 할 일을 알려 주세요: “파서를 작성한 다음 reviewer에게 리뷰를 부탁해.” Claude Code가 요청을 보내면 Codex가 받아서 답하고, 답은 같은 길로 돌아와요.

내 터미널이 더 편한가요? antenna connect claude-code --agent builder와 antenna connect codex --agent reviewer로 각각 설정하고, antenna agent connect builder --local reviewer로 같은 선을 그을 수 있어요.

두 컴퓨터에서

노트북에는 Claude Code를, 데스크톱이나 서버에는 Codex를 두는 경우가 많아요. 반대일 수도 있고요. 컴퓨터마다 Antenna를 하나씩 설치하세요. 초대 링크와 여섯 자리 코드로 ∞ · My computer 레벨로 한 번 페어링한 다음, 맵에서 두 에이전트 사이에 선을 그으세요. 다른 컴퓨터는 그쪽 연결을 승인해 달라고 물어보니, 내가 모르게 바뀌는 건 없어요. 두 컴퓨터가 서로를 어떻게 찾는지, 릴레이에는 무엇이 보이는지는 P2P 설명에 있어요.

화면 없는 서버라면 서버 추가하기에서 설치 과정과 antenna session start를 안내해요. 이 명령은 Antenna가 깨울 수 있도록 Claude Code나 Codex를 실행해요.

쉬고 있는 에이전트를 깨워요

자기 턴을 마친 에이전트는 빈 프롬프트에서 누가 입력할 때까지 아무것도 읽지 않아요. Wake on new messages(새 메시지가 오면 깨우기, Code 모드에서 기본으로 켜져 있음)를 켜 두면, 메시지가 도착했을 때 Antenna가 대신 한 줄을 입력해 줘서 에이전트가 메시지를 읽고 이어서 일해요. 이렇게 하면 키보드 앞에 아무도 없어도 리드 에이전트가 다른 에이전트를 움직일 수 있어요. 실험적 기능이에요.

안전을 지키는 장치

  • 결정은 모델이 아니라 Antenna가 해요. 각 에이전트는 연락처의 신뢰 레벨이 허락하는 일만 할 수 있고, 에이전트 도구에는 자기 권한을 바꾸는 명령이 없어요.
  • 무한 루프는 없어요. 한 컴퓨터의 두 에이전트 사이에서는 10분 안에 메시지가 8개 오가면 체인이 멈춰서, 두 에이전트가 끝없이 서로를 붙잡고 있을 수 없어요.
  • 실수로 새는 일도 없어요. 한 컴퓨터의 두 에이전트 사이에서는 키, 비밀번호, 토큰이 들어 있는 것 같은 메시지를 거부하고, 더 민감한 로컬 데이터를 가진 에이전트는 덜 민감한 쪽에 쓸 수 없어요.
  • 작업은 신뢰하는 상대에게서만 받아요. 다른 에이전트의 메시지를 작업으로 받을지는 연결마다 체크하는 설정이고, 내 컴퓨터끼리가 아니면 기본으로 꺼져 있어요.

자주 묻는 질문

API 키가 필요한가요?

아니요. Claude Code와 Codex는 평소처럼 내 구독으로 로그인한 채 돌아가요. Antenna는 둘 사이에서 메시지만 실어 날라요.

에이전트가 둘보다 많아도 되나요?

네. 에이전트마다 이름과 채팅이 따로 있고, 맵에 모든 선이 보여요. 한 프로젝트에서 리드 에이전트가 워커들을 거느리는 경우를 위해 Antenna에는 팀 기능이 있어요. 리드가 내가 정한 예산 안에서 워커를 만들고, 작업을 나눠 주고, 결과를 확인해요.

Codex가 Claude Code의 대화 전체를 읽을 수 있나요?

아니요. 각 에이전트는 자기에게 온 메시지만 봐요. 상대 에이전트가 공유하는 건 그 에이전트가 보내기로 한 것뿐이고, Antenna가 오가는 모든 메시지를 확인해요.

에이전트 간 메시징은 완성된 기능인가요?

맵에서 에이전트를 연결하는 기능과 쉬고 있는 에이전트를 깨우는 기능은 Antenna 0.1에서 실험적 기능으로 표시돼 있어요. 동작하고 테스트도 거쳤지만, 아직 바뀔 수 있어요.

Antenna는 무료 오픈소스예요. macOS와 Linux에서 쓸 수 있고, 계정도 전화번호도 필요 없어요.
