여러 컴퓨터의 Claude Code를 한곳에서 쓰기

Claude Code는 일이 있는 곳, 그러니까 노트북, 데스크톱, 서버에서 돌리고, 각 컴퓨터에 Antenna를 설치하세요. 컴퓨터들을 내 것(∞)으로 한 번 페어링하면, 그중 어디서든 모든 세션을 채팅 목록 하나에서 보고, 이름으로 아무 세션에나 메시지를 보내고, 승인 요청에 답하고, 폭주하는 세션을 멈출 수 있어요. 해당 컴퓨터에서 터미널을 열 필요가 없어요. Codex도 똑같이 돼요.

할 수 있는 것

  • 세션마다 채팅 하나. 어느 컴퓨터에서 돌든 상관없어요. 서버의 세션과 데스크톱의 세션이 연락처와 같은 목록에 나란히 있어요.
  • 내 기기: 컴퓨터마다 카드가 있어서 시스템과 Antenna 버전, 자체 점검 기준의 상태, 에이전트 목록과 각 에이전트의 연결 여부, 그 컴퓨터에서 나를 기다리는 요청을 보여 줘요.
  • 지금 있는 곳에서 승인. 서버의 에이전트가 보낸 요청을 Mac에서 Touch ID나 Mac 비밀번호로 승인할 수 있어요. 서버가 서명을 확인하고 요청을 직접 실행해요.
  • 중지 버튼. 다른 컴퓨터의 에이전트마다 있어서, 에이전트와 그 에이전트가 거기서 띄운 모든 프로세스를 멈춰요.
  • 에이전트 맵. 한 컴퓨터의 세션을 다른 컴퓨터의 세션과 연결해서 서로 메시지를 주고받게 해요.

설정하기

  1. 각 컴퓨터에 Antenna를 설치하세요. Mac이나 Linux 데스크톱에는 앱을, Linux 서버에는 노드를 설치해요(curl -fsSL https://antenna.contact/install.sh | sh).
  2. 컴퓨터끼리 내 것으로 페어링하세요. 내 컴퓨터예요(∞)를 체크해서 초대를 만들고, 다른 컴퓨터에서 연 다음, 한쪽에 표시된 코드를 다른 쪽에 입력하세요. 보거나 연결하고 싶은 컴퓨터마다 서로 페어링해야 해요. 양쪽 모두 상대를 ∞로 두고 있어야 해요.
  3. Claude Code 세션마다 이름을 붙이세요. 데스크톱에서는 에이전트 패널의 +로 Code 모드에서 시작해요. 서버에서는 프로젝트 폴더에서 antenna connect claude-code --agent api-dev --links mac --hello mac을 실행하고, antenna session start api-dev --dir ~/projects/api로 계속 돌게 해 두세요. 모든 단계는 VPS에서 Claude Code 돌리기에 있어요.
  4. 메인 컴퓨터가 요청에 답할 수 있게 하세요. 서버에서는 antenna devices confirm mac을 한 번 실행하고, 데스크톱에서는 내 기기 → 해당 카드 → 승인에서 메인 컴퓨터의 키를 받아들이세요.

컴퓨터 사이로 일 옮기기

사람에게 쓰듯 세션에 메시지를 보내세요: “api-dev, 서버에서 마이그레이션 돌리고 뭐가 바뀌었는지 알려 줘.” 채팅에 끌어다 놓은 파일은 그 컴퓨터에 저장되고, 에이전트는 파일 위치를 전달받아요. 내 컴퓨터끼리는 일반 파일은 묻지 않고 저장하지만, 프로그램과 설치 파일은 여전히 내 확인을 기다려요. 데스크톱의 세션이 서버의 세션에 일을 넘기게 하려면 에이전트 맵에서 둘을 연결하세요. 그쪽 세션은 메시지가 오면 깨어나고, 급한 메시지는 진행 중인 턴을 끊을 수도 있어요. 실험적 기능이에요.

자주 묻는 질문

Antenna가 컴퓨터 간에 Claude Code 설정이나 기록을 동기화하나요?

아니요. Claude Code는 설정, 기록, 로그인을 컴퓨터마다 따로 갖고 있고, 코드는 지금처럼 git으로 옮기면 돼요. Antenna는 세션 사이에서 메시지, 파일, 승인을 실어 날라요.

서버에 공인 IP나 열린 포트가 필요한가요?

아니요. 모든 컴퓨터가 바깥으로 연결해요. 네트워크가 허락하면 직접, 아니면 릴레이를 거쳐서요. 릴레이는 암호화된 트래픽만 전달해요.

여기서 다른 컴퓨터의 설정을 바꿀 수 있나요?

아니요. 내 컴퓨터들 사이를 오가는 건 승인, 중지, 그리고 에이전트 맵에서 보내는 연결 요청뿐이고, 연결 요청은 그 컴퓨터가 내게 승인을 받아요. 신뢰 레벨, 초대, 업데이트, 설정은 그 컴퓨터에서 직접 바꿔야 해서, 노트북을 도난당해도 서버의 규칙을 다시 쓸 수 없어요.

Windows나 스마트폰에서도 되나요?

아직은 아니에요. 지금 Antenna는 macOS와 Linux에서 돌아가요.

Antenna는 무료 오픈소스예요. macOS와 Linux에서 쓸 수 있고, 계정도 전화번호도 필요 없어요.
