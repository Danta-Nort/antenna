메시지에 답장하는 AI 에이전트 설정하기

Antenna에서 연락처 하나와 에이전트(Claude Code, Codex 또는 직접 만든 명령)를 고르면, 그때부터 그 연락처가 보내는 모든 메시지가 에이전트를 실행해요. 에이전트는 메시지를 읽고 답장해요. Antenna는 에이전트를 샌드박스 안에서, 그 연락처의 신뢰 레벨을 넘지 않는 권한으로 실행하고, 상대방에게는 답장이 쓰이는 동안 실시간으로 보여요. 내 Claude 또는 ChatGPT 로그인으로 동작하고, 비밀 정보가 들어 있는 것 같은 답장은 내 승인을 기다려요.

이럴 때 써요

  • 서버에 둔 나만의 비서. 노트북에서 서버로 메시지를 보내면, 서버의 Claude Code가 답하고 프로젝트를 빌드하고 테스트까지 돌려요.
  • 연락처를 위한 안내 창구. 동료가 내 프로젝트에 대해 물으면 바로 답이 가요. 답하는 에이전트는 그 대화의 폴더만 볼 수 있어요.
  • 결과를 알려 주는 스크립트. 어떤 프로그램의 출력이든 실시간 스트림으로 보낼 수 있어요: my-program | antenna send --stream <contact>.

창에서 설정하기

  1. 에이전트를 실행할 컴퓨터에서 Agents → Set up for a contact…를 여세요(또는 대화 안에서 연락처 카드의 Agent replies → Set up…).
  2. 연락처와 프로그램을 고르세요: Claude Code, Codex 또는 직접 만든 명령.
  3. 필요하면 장기 로그인 토큰(claude setup-token으로 발급)을 Value (optional)에 붙여 넣으세요. 토큰은 노드로 한 번 전달되어 암호화된 데이터베이스에 보관돼요. Mac에서는 샌드박스가 키체인을 열 수 없어서 이 방법이 확실해요.
  4. 소유자 비밀번호로 확인하세요. 규칙, 마지막 실행, Run log(실행 로그)가 Agents에 나타나요.

터미널에서는 한 줄이면 돼요: antenna wake set <contact> --cmd "claude -p --output-format stream-json". antenna wake list는 규칙과 최근 실행을 보여 주고, antenna wake off <contact>는 기능을 꺼요.

에이전트가 할 수 있는 것과 없는 것

  • 프롬프트는 고정돼 있어요: “새 메시지가 왔어요. 읽고 답장하세요.” 메시지 자체는 절대 프롬프트가 되지 않아요. 에이전트는 메시지를 데이터로 읽고, 연락처의 신뢰 레벨을 넘는 권한은 갖지 않아요.
  • 샌드박스 안에서 실행돼요(Linux에서는 bubblewrap 또는 Landlock, macOS에서는 Seatbelt). 자기 임시 폴더와 그 대화의 폴더만 볼 수 있고, 연결할 수 있는 곳은 모델 제공자뿐이에요. 내 프로젝트, 다른 파일, 노드의 키에는 닿을 수 없어요. 샌드박스가 없으면 Antenna는 에이전트를 실행하지 않아요.
  • 실행할 때마다 깨끗한 상태에서 시작해요. 에이전트를 상주 모드(아래 참고)로 두지 않는 한, 앞선 메시지가 다음 실행에 지시를 남겨 둘 수 없어요.
  • 제한: 실행마다 시간 제한이 있고, 시간당 실행 횟수도 정해져 있어요. 말 많은 연락처 때문에 사용량이 치솟을 일이 없어요.

내 프로젝트에서 작업하게 하기

내 컴퓨터끼리(∞)에 한해서, 에이전트가 내 툴체인으로 프로젝트 폴더 하나에서 작업하게 할 수도 있어요: --project ~/code/payments, 여기에 읽기 전용 --tool-path 폴더와 --allow-host로 접근을 허용할 패키지 레지스트리를 더하면 돼요. 다른 연락처에 대해서는 Antenna가 이를 거부하고, 홈 폴더나 Antenna 자체 데이터, ~/.ssh처럼 비밀 정보가 있는 폴더는 절대 열지 않아요.

자주 묻는 질문

상대방이 답장이 쓰이는 걸 실시간으로 보나요?

네, 레벨 3 이상 연락처라면요. 에이전트가 쓰는 만큼 말풍선이 자라다가 끝나면 일반 메시지가 돼요. 레벨 1과 2는 완성된 답장을 받아요.

에이전트가 답장에 비밀번호나 키를 쓰면 어떻게 되나요?

상대방에게 가던 스트림이 멈추고, 메시지는 내 승인을 기다려요. 내 컴퓨터끼리일 때만 그대로 이어져요.

이전 대화를 기억하나요?

기본적으로는 아니에요. 메시지마다 새로 실행돼요. 몇 시간씩 이어지는 작업이라면 --resident를 추가하세요. 그러면 같은 Claude Code 세션이 대화에 계속 붙어 있으면서 오간 말과 결정을 기억하고, 새 메시지는 다음 턴이 돼요. 그래도 메시지는 여전히 상대방이 보낸 데이터로 전달돼요.

Antenna는 무료 오픈소스예요. macOS와 Linux에서 쓸 수 있고, 계정도 전화번호도 필요 없어요.
