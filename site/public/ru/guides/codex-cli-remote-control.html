Как давать задачи Codex CLI на другом компьютере со своего ноутбука

Установите Antenna на оба компьютера и один раз свяжите их как свои. На компьютере, где работает Codex, дайте сессии Codex имя командой antenna connect codex и запустите её командой antenna session start … --cli codex. На ноутбуке появится чат с этим именем: напишите туда задачу, и Antenna разбудит Codex, если тот простаивает. Codex прочитает сообщение, сделает работу на другом компьютере и ответит в чате. Открытая SSH-сессия не нужна, и входящий порт открывать тоже не придётся.

Что понадобится

  • Codex CLI, установленный на компьютере, который будет делать работу, и с выполненным входом: сервер с Linux на x86_64 или Mac либо компьютер с Linux. Codex по-прежнему работает по вашей подписке, API-ключ для Antenna не нужен.
  • tmux на том же компьютере. На сервере ещё один раз выполните sudo loginctl enable-linger $USER, чтобы Antenna и сессия продолжали работать после того, как вы выйдете из системы.
  • Antenna на обоих компьютерах: приложение — на обычном компьютере, узел — на сервере (curl -fsSL https://antenna.contact/install.sh | sh).

1. Свяжите два компьютера

На ноутбуке: Новая связь → Пригласить, отметьте Это мой собственный компьютер (∞), создайте ссылку и откройте её на другом компьютере (на сервере — antenna join '<link>' --trust 5 --label mac). Введите код, который показывает одна сторона, на другой. Теперь оба компьютера считают друг друга вашими. Подробная пошаговая версия со снимками экрана — в инструкции «Claude Code на VPS»; для Codex всё так же.

2. Дайте сессии Codex имя

На компьютере, где работает Codex, в папке проекта выполните:

cd ~/projects/api
    antenna connect codex --agent api-codex --links mac --hello mac

Команда создаёт агента api-codex со своим файлом токена, связывает его с вашим ноутбуком (mac — имя, которое этот компьютер дал ноутбуку при знакомстве) и здоровается, поэтому на ноутбуке сразу появляется чат api-codex. Ваши собственные настройки Codex не меняются: Antenna добавляется только для сессий этого агента.

3. Запустите Codex через Antenna

antenna session start api-codex --dir ~/projects/api --cli codex
    antenna session attach api-codex

Codex запускается на собственном tmux-сервере Antenna, ваш tmux остаётся нетронутым. Подключитесь один раз, чтобы ответить на первые вопросы Codex. В первый раз Codex попросит доверять хукам Antenna («Hooks need review»): выберите «Trust all and continue». Потом отключитесь сочетанием Ctrl-b d, и Codex продолжит работать. С флагом --resume после перезапуска продолжится последняя сессия агента.

4. Пишите ему с ноутбука

Откройте чат api-codex и напишите: «Прогони тесты, исправь то, что падает, и расскажи, что поменял». Когда Codex простаивает у строки ввода, Antenna набирает одну встроенную строку с просьбой прочитать входящие. Ваш текст она в терминал никогда не вводит, как и не печатает ничего в ответ на вопрос, который задаёт Codex. Codex читает сообщение через Antenna, работает и отвечает в чате. Экспериментально.

Нужно, чтобы он бросил текущее дело? Перед отправкой включите Срочно: прервать сейчас. Antenna один раз нажмёт Esc, чтобы закончить текущий ход, а потом разбудит Codex ради вашего сообщения. Чтобы остановить агента и всё, что он запустил, откройте на ноутбуке карточку другого компьютера в разделе Мои устройства и нажмите Остановить агента и его процессы… рядом с api-codex.

На обычном компьютере: режим «Код»

Если Codex работает на Mac или компьютере с Linux, где установлено приложение Antenna, шаги в терминале можно пропустить. В режиме «Код» нажмите + на панели агентов, выберите Codex и рабочую папку, и Codex запустится во вкладке прямо в окне программы, а будить его будут так же. До его чата можно достучаться с других ваших компьютеров, как и до чата любого другого агента.

Вопросы

Я увижу терминал Codex на ноутбуке?

Нет. Вы даёте Codex задачи и читаете ответы в чате, а терминал остаётся на другом компьютере. Чтобы понаблюдать за ним, выполните там antenna session attach, хоть через SSH.

Какие версии Codex подходят?

Codex 0.160 и новее сообщает о своих действиях через хуки, и по ним Antenna понимает, что Codex простаивает. Со старым Codex или если не доверять хукам Antenna ждёт, пока после хода Codex не покажет пустую строку ввода, и никогда ничего не набирает, пока ход идёт.

А Codex может общаться ещё и с Claude Code?

Да. Соедините двух агентов на карте агентов, и сообщения каждого будут уходить другому без указания имени. Подробнее — в инструкции о том, как Claude Code и Codex общаются друг с другом.

А с телефона им можно управлять?

Пока нет. Сейчас Antenna работает на macOS и Linux.

Antenna — бесплатная программа с открытым кодом для macOS и Linux. Регистрация и номер телефона не нужны.
