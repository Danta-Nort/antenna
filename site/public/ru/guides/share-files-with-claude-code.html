Как передать файлы Claude Code на другом компьютере

На том же компьютере Claude Code читает ваши файлы напрямую: назовите ему путь или перетащите файл в его терминал. На другой компьютер, например на сервер, отправьте файл через Antenna: бросьте его в чат с этой сессией Claude Code, и Antenna там проверит файл при получении и сохранит в папке связи, а агент получит во входящих имя файла, его расположение, размер и SHA-256. Файлы, которые отправляет агент, приходят на ваш ноутбук тем же путём.

Как отправить файл агенту

  1. Свяжите ноутбук с другим компьютером как со своим (∞) и подключите Claude Code на нём к Antenna — см. инструкцию «Claude Code на VPS».
  2. Откройте на ноутбуке чат с сессией и перетащите туда файл или прикрепите его, как в любом мессенджере.
  3. На другом компьютере Antenna определяет тип файла по содержимому, ищет угрозы и секреты и сохраняет файл в папке связи ~/Antenna/links/<folder>/shared/ или в папке проекта, которую вы выбрали для этого компьютера.
  4. Агент сам узнаёт о сохранённом файле при следующей проверке входящих — с путём и хешами — и может использовать его на следующем шаге.

Как получить файлы от агента

Агент может прислать вам файл, сборку, отчёт или снимок экрана теми же инструментами, что и сообщения. Файл приходит в ваш чат и в раздел Файлы карточкой с именем, замечаниями проверки и хешем. Картинки показываются как проверенное безопасное превью, которое Antenna собрала заново.

Что проверяется и что ждёт вашего решения

  • Между вашими собственными компьютерами обычные файлы сохраняются сами. Всё, что может запустить или установить программу, — программа, установщик или архив с ними — всё равно ждёт вашего решения, если только вы не разрешили это для этого компьютера.
  • От чужого агента уровня 3 или 4 файлы проверяются и ждут, пока вы нажмёте «Принять» или их примет один из ваших агентов. На уровнях 1 и 2 вы решаете судьбу каждого файла.
  • При отправке файл, в котором похоже есть ключ, пароль или токен, задерживается до вашего одобрения, кроме передачи между вашими собственными компьютерами.
  • Ничего не перезаписывается. Если имя уже занято, файл сохраняется как report (2).pdf, а отправителю сообщают новое имя.

Вопросы

Почему не scp или общая папка?

Можно и так, а для больших деревьев файлов это, возможно, даже удобнее. Antenna нужна для файлов, которые относятся к переписке с агентом: они оказываются там, где агент их ждёт, агенту об этом сообщают, а файл от кого угодно, кроме вас, проверяется до того, как попадёт на диск.

Файл шифруется при передаче?

Да, из конца в конец, по той же связи, что и ваши сообщения. Никакой сервер посередине его не хранит.

Можно выбрать, куда сохранять файлы?

Да. В карточке контакта этого компьютера раздел Файлы с этого компьютера позволяет выбрать папку для самого компьютера и по папке для каждого его агента. В терминале: antenna files save-to <contact> <folder>.
