Как работать с Gemini CLI и Claude Code вместе

Подключите Gemini CLI к Antenna в один клик, запустите Claude Code в окне Antenna и проведите между ними линию на карте агентов. После этого они пишут друг другу через MCP-инструменты Antenna: Gemini CLI просит Claude Code посмотреть изменения, Claude Code передаёт Gemini CLI задачу, а ответ возвращается тем же путём. Оба работают под вашими собственными входами в Google и Claude, без API-ключей.

На одном компьютере

  1. Установите Antenna (macOS или Linux) и создайте свой узел: один пароль, никакого аккаунта.
  2. Откройте Агенты → ИИ-приложения и нажмите Подключить рядом с Gemini CLI. Выберите Помощник с доступом к моим проектам, введите пароль, нажмите Далее, прочитайте, что Antenna добавит в ~/.gemini/settings.json, и нажмите Записать и подключить. В Gemini CLI выполните /mcp reload (или перезапустите его): /mcp покажет antenna. В строке приложения появится «Контакты пишут ему как gemini-cli».
  3. На той же странице нажмите Запустить в режиме «Код» рядом с Claude Code. Выберите Новый агент…, назовите его builder, выберите ту же роль, Помощник с доступом к моим проектам, введите пароль и нажмите Запустить. Claude Code заработает во вкладке терминала прямо в окне программы.
  4. Откройте Агенты → Карта, протяните линию от маркера одного агента к другому, введите пароль и нажмите Соединить. Два агента получат локальный маршрут: их сообщения никогда не покидают компьютер, и каждый принимает сообщения другого как задачи, если вы не снимете эту галочку.

Дайте обоим одну и ту же роль: Antenna не позволяет агенту, который видел больше ваших данных, писать агенту, который видел меньше.

Как они обращаются друг к другу

Когда линия проведена, каждый агент становится для другого собеседником по умолчанию: достаточно сказать «отправь это своему собеседнику». Чтобы назвать другого по имени, агент вызывает send_message с local_agent, равным gemini-cli или builder. Получатель читает сообщения через read_inbox или ждёт их через wait_for_message, до 10 минут за один вызов.

Ждут они по-разному. Claude Code в режиме «Код» просыпается сам: когда приходит сообщение, а он простаивает, Antenna набирает за него одну строку с просьбой прочитать входящие. Экспериментально. Gemini CLI Antenna пока не будит, поэтому он читает сообщения, когда в следующий раз обращается к Antenna. Значит, начинать обмен удобнее с Gemini CLI: «Попроси builder проверить diff в src/, потом дождись ответа и исправь то, что он найдёт». Claude Code проснётся, проверит и ответит. Чтобы передать работу Gemini CLI, сначала скажите ему ждать сообщений.

На двух компьютерах

Gemini CLI может остаться на одном компьютере, а Claude Code работать на другом. Установите Antenna на каждый и один раз свяжите их ссылкой-приглашением и шестизначным кодом, отметив Это мой собственный компьютер (∞). Потом проведите линию между двумя агентами на карте. Другой компьютер попросит вас одобрить подключение со своей стороны, там же или в разделе Мои устройства, так что без вас там ничего не изменится. На сервере без экрана Claude Code запускается командами antenna connect claude-code и antenna session start: подробнее в статье Claude Code на VPS.

Что одобряете вы и что остаётся ограниченным

  • Соединения создаёте только вы. Чтобы провести линию, нужен ваш пароль; ни один агент не может создать или изменить её.
  • Antenna проверяет каждое сообщение. Между двумя агентами одного компьютера сообщение, в котором похоже есть ключ, пароль или токен, не пропускается, а цепочка обрывается после 8 сообщений за 10 минут, так что два агента не смогут вечно занимать друг друга.
  • Уровень доверия следует за тем, что агент прочитал. Если на одном компьютере агент прочитал сообщение от контакта, его собственное сообщение переносит ограничения этого контакта на другого агента, и тот ограничен так, будто тоже его прочитал.
  • Claude Code проверяется перед каждым инструментом. В режиме «Код» Antenna спрашивает свой daemon перед каждой командой и правкой. Собственные инструменты Gemini CLI остаются под подтверждениями самого Gemini CLI; Antenna проверяет то, что проходит через неё.

Вопросы

Нужен ли API-ключ Gemini?

Нет. Gemini CLI входит через ваш аккаунт Google, а Claude Code — через ваш тариф Claude, как обычно. Antenna только передаёт сообщения.

Могут ли два окна Gemini CLI работать с Antenna одновременно?

Только по одному: агент работает в одной сессии за раз, а Подключить даёт Gemini CLI одного агента.

Это уже готово?

Соединение агентов на карте и пробуждение простаивающих агентов в Antenna 0.1 помечены как экспериментальные: они работают и покрыты тестами, но ещё могут измениться.
