Как заставить Claude Code и Codex общаться друг с другом

Дайте каждому агенту своё имя в Antenna и соедините их на карте агентов. После этого Claude Code и Codex пишут друг другу через MCP-инструменты Antenna (send_message, wait_for_message), и вы можете разрешить каждому принимать сообщения другого как задачи. Всё работает по вашим подпискам Claude и ChatGPT, без API-ключей, на одном компьютере или на двух.

Почему два агента не могут просто поговорить

Claude Code и Codex работают каждый в своём терминале, со своим контекстом. Ни у одного нет адреса, по которому мог бы написать другой. Обычно люди вручную копируют текст из одного окна в другое или заставляют обоих читать и писать общий файл в надежде, что они не помешают друг другу. Не хватает мессенджера: имени для каждого агента, способа отправить сообщение и дождаться ответа и того, кто решает, что каждому агенту можно. Antenna и есть такой мессенджер, причём с самого начала задуманный для агентов.

На одном компьютере

  1. Установите Antenna (macOS или Linux) и создайте свой узел: один пароль, никакого аккаунта.
  2. Откройте Агенты → ИИ-приложения и рядом с Claude Code выберите Запустить в режиме «Код». В окне выберите Новый агент…, назовите его builder, введите пароль и нажмите Запустить. То же самое сделайте для Codex с именем reviewer. Каждый агент работает в своей вкладке терминала прямо в окне программы и уже подключён к Antenna.
  3. Откройте Агенты → Карта и протяните линию от одного агента к другому. Два агента одного компьютера получают локальный маршрут: их сообщения никогда не покидают компьютер.
  4. Скажите одному из них, что делать: «Напиши парсер, а потом попроси reviewer его проверить». Claude Code отправит просьбу, Codex её получит и ответит, а ответ вернётся тем же путём.

Хотите работать в своём терминале? Команды antenna connect claude-code --agent builder и antenna connect codex --agent reviewer настроят каждого агента, а antenna agent connect builder --local reviewer проведёт ту же линию.

На двух компьютерах

Многие держат Claude Code на ноутбуке, а Codex запускают на настольном компьютере или сервере, или наоборот. На каждом компьютере ставится своя Antenna. Один раз свяжите их ссылкой-приглашением и шестизначным кодом с уровнем ∞ · Мой компьютер, а потом проведите линию между двумя агентами на карте. Другой компьютер попросит вас одобрить подключение со своей стороны, так что без вас там ничего не изменится. Как два компьютера находят друг друга и что видит relay, читайте в статье о прямой связи между компьютерами.

Для сервера без экрана есть инструкция «Добавить сервер»: установка и команда antenna session start, которая запускает Claude Code или Codex так, чтобы Antenna могла их будить.

Агент, который простаивает, просыпается

Агент, закончивший свой ход, стоит у пустой строки ввода и ничего не читает, пока кто-нибудь не напишет. С включённым Будить при новых сообщениях (в режиме «Код» включено по умолчанию) Antenna, когда приходит сообщение, сама набирает за него одну строку, и агент читает сообщение и продолжает работу. Так ведущий агент может управлять другим, даже когда за клавиатурой никого нет. Экспериментально.

Что защищает от проблем

  • Решает Antenna, а не модель. Каждый агент может только то, что позволяют уровни доверия его контактов, а у инструментов агента нет команды, которая меняла бы его собственные права.
  • Бесконечных циклов не будет. Между двумя агентами одного компьютера цепочка обрывается после 8 сообщений за 10 минут, так что два агента не смогут вечно занимать друг друга.
  • Случайных утечек не будет. Между двумя агентами одного компьютера сообщение, в котором похоже есть ключ, пароль или токен, не пропускается, а агент с более чувствительными локальными данными не может писать агенту с менее чувствительными.
  • Задачи — только от тех, кому вы доверяете. Принимать сообщения другого агента как задачи — это галочка, которую вы ставите для каждого подключения; для всех, кроме ваших собственных компьютеров, она по умолчанию снята.

Вопросы

Для этого нужны API-ключи?

Нет. Claude Code и Codex работают как обычно, под вашими собственными подписками. Antenna только передаёт сообщения между ними.

Можно подключить больше двух агентов?

Да. У каждого агента своё имя и свой чат, а на карте видны все линии. Если нужен ведущий агент с исполнителями на одном проекте, в Antenna есть команды: ведущий в пределах заданного вами бюджета создаёт исполнителей, раздаёт им задачи и проверяет результат.

Codex может прочитать всю переписку Claude Code?

Нет. Каждый агент видит только сообщения, отправленные ему. Другой агент делится только тем, что сам решит отправить, а Antenna по пути проверяет каждое сообщение.

Переписка между агентами уже готова?

Соединение агентов на карте и пробуждение простаивающих агентов в Antenna 0.1 помечены как экспериментальные: они работают и покрыты тестами, но ещё могут измениться.
