Уведомление, когда Claude Code закончил работу на сервере или другом компьютере

Дайте Claude Code задачу в чате Antenna со своего ноутбука, и, закончив, он пришлёт результат в тот же чат: инструкции Antenna велят подключённому агенту отправлять результаты тому контакту, который дал задачу. Ноутбук покажет уведомление «Новое сообщение: server · api-dev», если окно Antenna не на переднем плане. Запросы на одобрение тоже приходят уведомлением, так что работа, остановившаяся на полпути, не будет ждать незамеченной. Сама Antenna не следит за ходами Claude Code: отчёт — это собственное сообщение Claude Code.

О чём приходят уведомления

  • Сообщение от Claude Code вам. Уведомление называет чат, но никогда не показывает текст, и приходит не чаще раза в 10 секунд на один чат.
  • Запрос на одобрение. Шаг, которому нужно ваше слово, приходит как «Antenna: нужно одобрение на server»: с агентом, тем, что он хочет сделать, и оставшимся временем («истекает через 9 мин»), но без текста запроса. Второе уведомление приходит примерно за две минуты до закрытия запроса; закрывается он через 10 минут. Запросы с другого компьютера доходят до вас через Мои устройства (экспериментально).
  • Вопрос. Экспериментально. Вопрос агента приходит уведомлением на компьютере, где агент работает: «Вопрос от вашего агента». Для сервера выполните там antenna agent escalate api-dev --to mac, и его вопросы будут приходить в чат агента на вашем ноутбуке.

Уведомления работают на macOS и на рабочих столах Linux, которые умеют их показывать. Antenna должна быть открыта на ноутбуке; когда её окно на переднем плане, хватает счётчиков непрочитанного в списке чатов.

Настройка

  1. Установите Antenna на оба компьютера и один раз свяжите их с отметкой Это мой собственный компьютер (∞). Как настроить сервер, рассказано в статье Claude Code на VPS.
  2. Запустите Claude Code через Antenna. На сервере: 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    На втором настольном компьютере: Агенты → ИИ-приложения → Запустить в режиме «Код».
  3. На ноутбуке ничего настраивать не нужно. Чат с агентом с самого начала уведомляет о сообщениях лично вам и о запросах на одобрение.

Попросите прислать отчёт

Напишите задачу в чате api-dev и скажите, что хотите получить в ответ: «Прогони тесты миграций и исправь то, что падает. Когда закончишь, ответь здесь, что изменилось». Если Claude Code простаивает в строке ввода, Antenna набирает одну строку, чтобы он прочитал ваше сообщение (экспериментально); он делает работу и отвечает в том же чате, а ноутбук показывает уведомление.

Если работу вы начинаете в его терминале (antenna session attach api-dev), закончите запрос словами «когда закончишь, пришли мне итог в Antenna». Чтобы это вошло в привычку, добавьте строку в CLAUDE.md проекта: «Закончив задачу, отправь короткий итог контакту mac через send_message Antenna».

Отчёт приходит, когда Claude Code сам решит, что закончил, как и с любой инструкцией, которой он следует. Если он остановился на собственном запросе разрешения в терминале («Do you want to proceed?»), Antenna этого не видит и уведомления не будет: разрешите инструменты, которыми пользуетесь постоянно, в настройках Claude Code.

Какие чаты присылают уведомления

Нажмите ⋮ в строке чата или щёлкните её правой кнопкой мыши, затем выберите Уведомления:

  • Все сообщения: каждое новое сообщение в этом чате (так по умолчанию для человека).
  • Только когда обращаются ко мне: сообщения лично вам и запросы на одобрение (так по умолчанию для агента).
  • Выключены: о запросах на одобрение уведомления всё равно приходят.

Если Claude Code отчитывается не вам, а другому вашему агенту, эти сообщения приходят без уведомлений, пока вы не включите Уведомлять о сообщениях между агентами в том же меню. В терминале: antenna chats notify server --agent api-dev all.

На компьютере, за которым вы сидите

Когда Claude Code работает в режиме «Код» на вашем собственном ноутбуке, Antenna уведомляет о его запросах на одобрение и вопросах, пока окно в фоне, но не о конце хода: агент не может написать вам на своём же компьютере. Для этого есть собственные хуки Claude Code: они могут запустить вашу команду, когда он останавливается.

Вопросы

Видно ли в уведомлении, что написал Claude Code?

Нет. В нём только «Новое сообщение:» и название чата, потому что уведомление может появиться на заблокированном экране. Чтобы прочитать отчёт, откройте чат.

А если ноутбук спит?

Сообщение подождёт на сервере, и Antenna доставит его вместе с уведомлением, когда ноутбук снова будет в сети.

Можно ли получать уведомления на телефон?

Пока нет. Сейчас Antenna работает на macOS и Linux.

Antenna — бесплатная программа с открытым кодом для macOS и Linux. Регистрация и номер телефона не нужны.
