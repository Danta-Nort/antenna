Пусть Claude Code работает, пока ноутбук закрыт

На самом ноутбуке так не получится: если закрыть крышку, ноутбук засыпает, спящий компьютер ничего не выполняет, и Claude Code встаёт на паузу вместе с ним. Выход — запустить Claude Code на компьютере, который всегда включён, например на сервере с Linux или на Mac mini, которому запрещено засыпать, сделать это через Antenna и давать ему задачи из чата Antenna на ноутбуке. Закройте ноутбук: Claude Code продолжит работать на другом компьютере, а его ответы дождутся ноутбука и придут, когда тот снова будет в сети.

Почему он останавливается

Claude Code работает на том компьютере, где вы его запустили. Когда этот компьютер засыпает, останавливаются все программы на нём, включая Claude Code, до пробуждения. Если закрыть терминал или окно SSH, в котором он работает, он тоже завершится. Можно сделать так, чтобы ноутбук не засыпал и с закрытой крышкой, но тогда он должен всё время быть включён и подключён к сети — то есть он уже стал сервером. Поэтому работа переезжает на компьютер, который всегда включён, а ноутбук только с ним переписывается.

Что понадобится

  • Компьютер, который всегда включён: сервер с Linux на x86_64 (VPS или домашний) либо настольный Mac или компьютер с Linux, которому запрещено засыпать.
  • Claude Code, установленный на нём, с выполненным входом.
  • Antenna на обоих компьютерах: приложение на ноутбуке (macOS или Linux), узел или приложение на другом.

На сервере

  1. Установите узел Antenna и оставьте его работать после выхода из системы: 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
    Установщик настраивает Antenna как пользовательскую службу systemd и создаёт ваш узел с паролем. Lingering он не включает, а только напоминает о нём: без второй строки служба остановится, когда вы выйдете из системы.
  2. Один раз свяжите сервер с ноутбуком. На ноутбуке: Новая связь → Пригласить, отметьте Это мой собственный компьютер (∞), нажмите Создать ссылку и скопируйте её. На сервере: antenna join '<link>' --trust 5 --label mac, введите код, который показывает ноутбук, а потом нажмите на ноутбуке Контакт подтвердил — коды совпадают.
  3. Запустите Claude Code через Antenna в папке проекта (на сервере нужен tmux): 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    Ответьте на первые вопросы Claude Code, например доверяет ли он этой папке, и отключитесь сочетанием Ctrl-b d. На ноутбуке теперь есть чат api-dev.
  4. Разрешите ноутбуку отвечать на запросы сервера на одобрение: antenna devices confirm mac.

Теперь можно выйти из SSH. Служба продолжает работать, а Claude Code — в собственном tmux-сервере Antenna; ваш tmux остаётся нетронутым. В инструкции Claude Code на VPS каждый шаг описан подробнее.

На Mac или настольном компьютере, который всегда включён

  1. В системных настройках запретите компьютеру засыпать самому. Antenna не мешает компьютеру уснуть.
  2. Свяжите его с ноутбуком, как описано выше, с отметкой Это мой собственный компьютер (∞).
  3. На нём откройте Агенты → ИИ-приложения и нажмите Запустить в режиме «Код» рядом с Claude Code. Выберите Новый агент… и дайте ему имя, укажите папку в поле Рабочая папка, введите пароль и нажмите Запустить. Окно переключится в режим «Код», и Claude Code заработает во вкладке внутри него.
  4. Один раз попросите Claude Code в его вкладке поздороваться с вашим ноутбуком через Antenna. После этого его чат появится на ноутбуке.
  5. Разрешите ноутбуку отвечать на его запросы на одобрение: Мои устройства → карточка ноутбука → Одобрения → Разрешить одобрения, подписанные: …, с вашим паролем.

Не закрывайте окно Antenna: если его закрыть, остановятся агенты, работающие в нём, и окно сначала спросит вас об этом.

Оставьте его работать

Напишите задачу в чат агента на ноутбуке: «Прогони тесты миграций, исправь то, что падает, и напиши сюда, что изменилось». Когда Claude Code простаивает у строки ввода, Antenna набирает одну встроенную строку, чтобы он прочитал ваше сообщение; если он посреди хода, он получит сообщение, когда ход закончится. Ваш текст Antenna в терминал никогда не набирает. Экспериментально. Теперь закройте ноутбук.

Перед долгой работой проверьте, что может её остановить, пока никого нет рядом:

  • Собственный запрос разрешения Claude Code («Do you want to proceed?») ждёт в его терминале, пока кто-нибудь не ответит, а Antenna на него никогда не отвечает. Разрешите в настройках Claude Code инструменты, которые нужны для задачи.
  • Запросы Antenna на одобрение ждут 10 минут. Потом ничего не выполняется, и Claude Code узнаёт, что одобрения не было. Задача, которую вы дали со своего собственного компьютера на уровне ∞, выполняет команды и правки без вопросов; изменения собственной настройки Claude Code, например CLAUDE.md или .claude/, всё равно ждут одобрения.

Когда ноутбук проснётся

Пока ноутбук спит, ответы Claude Code ждут в очереди на другом компьютере, и Antenna продолжает пытаться их доставить. Как только ноутбук снова в сети, они приходят в чат — с уведомлением, если окно Antenna не на переднем плане. Сообщение, которое вы написали без сети, показывает часы и уходит само. Запросы, которые всё ещё ждут вашего одобрения, видны в карточке другого компьютера в разделе Мои устройства (экспериментально).

После перезагрузки другого компьютера

После перезагрузки ключи закрыты, поэтому его связи молчат, пока вы не введёте пароль. На сервере войдите и выполните antenna unlock, а потом снова запустите сессию; --resume продолжит последнюю сессию Claude Code:

antenna session start api-dev --dir ~/projects/api --resume

На Mac введите пароль в окне Antenna и снова запустите агента.

Вопросы

Продолжит ли Claude Code работать, если закрыть ноутбук?

Нет, если при закрытой крышке ноутбук засыпает, а обычно так и настроено: Claude Code стоит на паузе, пока вы его не откроете. Запустите его на компьютере, который всегда включён, и он продолжит работать.

Может ли Claude Code работать в фоне на моём ноутбуке?

Пока ноутбук не спит — да: в режиме «Код» он работает во вкладке окна Antenna, на которую можно не смотреть, и Antenna будит его, когда приходит сообщение. Но когда ноутбук засыпает, он всё равно останавливается.

Нужно ли держать SSH-сессию открытой?

Нет. Claude Code работает в tmux Antenna на сервере, а вы обращаетесь к нему через чат. Оба компьютера сами подключаются наружу, так что входящий порт тоже не открывается.

Не даёт ли Antenna моему Mac уснуть?

Нет. Запретите Mac засыпать в его системных настройках. Для режима «Код» окно Antenna должно оставаться открытым.

Можно ли проверить, как идут дела, с телефона?

Пока нет. Сейчас Antenna работает на macOS и Linux.

Antenna — бесплатная программа с открытым кодом для macOS и Linux. Регистрация и номер телефона не нужны.
