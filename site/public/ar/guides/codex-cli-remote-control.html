آخر تحديث 14 نوفمبر 2026

أعطِ Codex CLI مهام على حاسوب آخر من حاسوبك المحمول

ثبّت Antenna على الحاسوبين واقرنهما مرة واحدة على أنهما حاسوباك أنت. على الحاسوب الذي يعمل عليه Codex، امنح جلسة Codex اسمًا بالأمر antenna connect codex وشغّلها بالأمر antenna session start … --cli codex. تظهر محادثة بهذا الاسم على حاسوبك المحمول: اكتب فيها مهمة، فيوقظ Antenna ‏Codex حين يكون خاملًا. يقرأ Codex رسالتك، ويعمل على الحاسوب الآخر، ويجيب في المحادثة. لا جلسة SSH تبقى مفتوحة، ولا منفذ وارد يلزم فتحه.

ما تحتاجه

  • Codex CLI مثبّتًا ومسجَّل الدخول على الحاسوب الذي سينجز العمل: خادم Linux بمعمارية x86_64، أو جهاز Mac أو حاسوب Linux مكتبي. يواصل Codex العمل باشتراكك أنت، ولا يحتاج Antenna إلى أي مفتاح API.
  • tmux على ذلك الحاسوب. وعلى الخادم، شغّل أيضًا sudo loginctl enable-linger $USER مرة واحدة، كي يستمر Antenna والجلسة في العمل بعد تسجيل خروجك.
  • Antenna على الحاسوبين: التطبيق على الحاسوب المكتبي، والعقدة على الخادم (curl -fsSL https://antenna.contact/install.sh | sh).

1. اقرن الحاسوبين

على حاسوبك المحمول: New contact → Invite، وحدّد This is my own computer (∞)، وأنشئ الرابط، وافتحه على الحاسوب الآخر (على الخادم: antenna join '<link>' --trust 5 --label mac). أدخل الرمز الذي يعرضه أحد الطرفين في الطرف الآخر. يعامل كل طرف الآن الآخر على أنه حاسوبك أنت. وتجد الخطوات بالتفصيل مع لقطات الشاشة في دليل Claude Code على خادم VPS، وهي نفسها مع Codex.

2. امنح جلسة Codex اسمًا

على الحاسوب الذي يعمل عليه Codex، في مجلد المشروع:

cd ~/projects/api
    antenna connect codex --agent api-codex --links mac --hello mac

ينشئ هذا الوكيل api-codex مع ملف رمز وصول خاص به، ويربطه بحاسوبك المحمول (mac هو الاسم الذي أعطاه هذا الحاسوب لحاسوبك المحمول عند الاقتران)، ويلقي التحية، فتظهر فورًا محادثة باسم api-codex على الحاسوب المحمول. لا تتغير إعدادات Codex الخاصة بك: يُضاف Antenna لجلسات هذا الوكيل فقط.

3. شغّل Codex عبر Antenna

antenna session start api-codex --dir ~/projects/api --cli codex
    antenna session attach api-codex

يبدأ Codex في خادم tmux الخاص بـ Antenna، ولا يُمَس tmux الخاص بك. اتصل بالجلسة مرة واحدة لتجيب عن أسئلة Codex الأولى. في المرة الأولى يطلب منك Codex الوثوق بخطافات (hooks) ‏Antenna ‏(“Hooks need review”): اختر “Trust all and continue”. ثم اخرج بـ Ctrl-b d، ويواصل Codex العمل. ويستأنف الخيار --resume آخر جلسة للوكيل بعد إعادة التشغيل.

4. اكتب إليه من حاسوبك المحمول

افتح محادثة api-codex واكتب: «شغّل الاختبارات، وأصلح ما يفشل، وأخبرني بما غيّرت». حين يكون Codex خاملًا أمام موجّهه، يكتب Antenna سطرًا مدمجًا واحدًا يطلب منه قراءة صندوق الوارد. ولا يكتب أبدًا نصك في الطرفية، ولا يكتب أبدًا أثناء سؤال يطرحه Codex. يقرأ Codex الرسالة عبر Antenna، ويعمل، ويرد في المحادثة. تجريبي.

تريد أن يتوقف عمّا يفعله؟ فعّل Urgent: interrupt now قبل الإرسال. يضغط Antenna مفتاح Esc مرة واحدة لإنهاء الدور الجاري، ثم يوقظ Codex لرسالتك. ولإيقاف الوكيل وكل ما شغّله، افتح بطاقة الحاسوب الآخر في My devices على حاسوبك المحمول واضغط Stop agent and its processes… بجوار api-codex.

على الحاسوب المكتبي: وضع Code

إذا كان Codex يعمل على جهاز Mac أو حاسوب Linux مكتبي عليه تطبيق Antenna، يمكنك تخطي خطوات الطرفية. في وضع Code، اضغط + في لوحة الوكلاء، واختر Codex ومجلد العمل، فيعمل Codex في علامة تبويب داخل النافذة، ويُوقَظ بالطريقة نفسها. ويمكن الوصول إلى محادثته من حواسيبك الأخرى كأي وكيل آخر.

أسئلة

هل يعرض لي هذا طرفية Codex على الحاسوب المحمول؟

لا. تعطي Codex المهام وتقرأ إجاباته في محادثة، وتبقى الطرفية على الحاسوب الآخر. ولمشاهدتها، شغّل antenna session attach هناك، عبر SSH إن شئت.

أي إصدارات Codex تعمل؟

يبلّغ Codex 0.160 وما بعده عمّا يفعله عبر الخطافات (hooks)، وبهذا يعرف Antenna متى يكون Codex خاملًا. ومع إصدار أقدم من Codex، أو دون الوثوق بالخطافات، ينتظر Antenna حتى يُظهر Codex سطر الإدخال الفارغ بعد الدور، ولا يكتب أبدًا أثناء دور جارٍ.

هل يستطيع Codex التحدث مع Claude Code أيضًا؟

نعم. اربط الوكيلين على خريطة الوكلاء، فتذهب رسائل كل منهما إلى الآخر دون الحاجة إلى تسميته: انظر Claude Code وCodex يتحدثان مع بعضهما.

هل يمكنني التحكم فيه من هاتفي؟

ليس بعد. يعمل Antenna حاليًا على macOS وLinux.

Antenna مجاني ومفتوح المصدر، لنظامي macOS وLinux. بلا حساب وبلا رقم هاتف.
