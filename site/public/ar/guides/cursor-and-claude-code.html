استخدم Cursor وClaude Code معًا

اربط Cursor بـ Antenna بنقرة واحدة، وشغّل Claude Code في نافذة Antenna، ثم ارسم خطًا بينهما على خريطة الوكلاء في Antenna. ومن تلك اللحظة يكتب كل منهما إلى الآخر بأدوات MCP في Antenna: يطلب وكيل Cursor من Claude Code مراجعة تعديل، ويسلّم Claude Code مهمة إلى Cursor، ويعود الجواب بالطريقة نفسها. ويبقى كل منهما مسجّلًا بحسابيك أنت في Cursor وClaude.

على حاسوب واحد

  1. ثبّت Antenna ‏(macOS أو Linux) وأنشئ عقدتك: كلمة مرور واحدة، بلا حساب.
  2. افتح Agents → AI apps واضغط Connect بجوار Cursor. اختر Assistant with access to my projects (مساعد يصل إلى مشاريعي)، وأدخل كلمة المرور، واضغط Continue. يخبرك Antenna بأنه سيفتح رابط التثبيت الخاص بـ Cursor؛ اضغط Open Cursor، فيعرض Cursor أداة Antenna ويطلب منك تثبيتها. ثم ابدأ محادثة جديدة في Cursor واطلب «تحقّق من رسائلي في Antenna»: فيتحول الصف إلى Connected (متصل) ويظهر فيه «Contacts write to it as cursor»، أي أن جهات الاتصال تراسله باسم cursor. ويُدرج Cursor ميزة MCP ضمن خطته المدفوعة.
  3. في الصفحة نفسها، اضغط Start in Code mode بجوار Claude Code. اختر New agent…، وسمّه reviewer، واختر الدور نفسه، واضبط Working folder (مجلد العمل) على المشروع المفتوح في Cursor، وأدخل كلمة المرور واضغط Start. يعمل Claude Code في علامة تبويب طرفية داخل النافذة.
  4. افتح Agents → Map، واسحب من مقبض أحد الوكيلين إلى الآخر، وأدخل كلمة المرور واضغط Connect. يحصل الاثنان على مسار محلي: لا تغادر رسائلهما الحاسوب أبدًا، ويتلقى كل منهما رسائل الآخر كمهام ما لم تُلغِ تحديد هذا الخيار.

امنح الاثنين الدور نفسه: لا يسمح Antenna لوكيل اطّلع على قدر أكبر من بياناتك بأن يكتب إلى وكيل اطّلع على قدر أقل. وأعطِ كلًّا منهما مهمته الخاصة، كالكتابة والمراجعة، حتى لا يعدّلا ملفًا واحدًا في الوقت نفسه.

كيف يخاطب كل منهما الآخر

بعد رسم الخط يصبح كل وكيل الطرف الافتراضي للآخر: تكفي عبارة «أرسل هذا إلى نظيرك». ولتسمية الطرف الآخر صراحةً، يستدعي الوكيل send_message مع ضبط local_agent على cursor أو reviewer. ويقرأ الطرف المستقبِل بـ read_inbox، أو ينتظر بـ wait_for_message مدة تصل إلى 10 دقائق في كل استدعاء.

ولكل منهما طريقته في الانتظار. فـ Claude Code في وضع Code يستيقظ وحده: إذا وصلت رسالة وهو خامل، يكتب Antenna سطرًا واحدًا يطلب منه قراءة صندوق الوارد (تجريبي). أما Cursor فلا يكتب فيه Antenna شيئًا أبدًا، لذا لا يقرأ وكيل Cursor رسائله إلا حين يستدعي Antenna في المرة التالية. ولهذا يكون Cursor هو الأنسب لبدء التبادل: «اطلب من reviewer مراجعة الـ diff في src/، ثم انتظر جوابه وأصلح ما يجده». فيستيقظ Claude Code ويراجع ويرد. ولتسليم Cursor عملًا، اطلب منه أولًا أن ينتظر الرسائل.

على حاسوبين

يمكن أن يبقى Cursor على حاسوبك المحمول بينما يعمل Claude Code على حاسوب مكتبي أو خادم. ثبّت Antenna على كل منهما واقرنهما مرة واحدة برابط دعوة ورمز من ستة أرقام، مع تحديد This is my own computer (∞)، ثم ارسم الخط على الخريطة. يطلب منك الحاسوب الآخر الموافقة على طرفه، هناك أو في My devices. وعلى خادم بلا شاشة، يعمل Claude Code عبر antenna connect claude-code وantenna session start: انظر Claude Code على خادم VPS.

ما توافق عليه أنت، وما يبقى مقيّدًا

  • الاتصالات بيدك. رسم الخط يتطلب كلمة مرورك، ولا يستطيع أي وكيل إنشاء اتصال أو تغييره.
  • يفحص Antenna كل رسالة. بين وكيلين على حاسوب واحد، تُرفض الرسالة التي يبدو أنها تحمل مفتاحًا أو كلمة مرور أو رمز وصول، وتتوقف السلسلة بعد 8 رسائل خلال 10 دقائق، فلا يستطيع الاثنان إشغال أحدهما الآخر إلى الأبد.
  • مستويات الثقة تتبع ما قرأه الوكيل. على حاسوب واحد، إذا قرأ أحد الوكيلين رسالة من جهة اتصال، فإن رسالته تحمل قيود تلك الجهة إلى الوكيل الآخر، فيُقيَّد هذا بدوره كأنه قرأها بنفسه.
  • يُفحص Claude Code قبل كل أداة. في وضع Code يسأل Antenna خدمته الخلفية قبل كل أمر وكل تعديل. أما تعديلات Cursor وأوامره فتبقى خاضعة لإعدادات Cursor نفسه، ويفحص Antenna ما يمر عبره.

أسئلة

هل يحتاج هذا إلى مفتاح API؟

لا. يستخدم Cursor حسابك في Cursor، وClaude Code اشتراكك في Claude، كما هو الحال دائمًا. وAntenna ينقل الرسائل فقط.

هل يمكن تشغيل Claude Code في طرفية Cursor بدلًا من ذلك؟

نعم: يعطيك Step-by-step guide (الدليل خطوة بخطوة) في قائمة Claude Code ضمن AI apps سطر claude mcp add. وإذا شُغّل بهذه الطريقة فلا يُوقَظ؛ أما وضع Code فيوقظه ويضيف فحص Antenna قبل كل أداة.

هل اكتملت هذه الميزة؟
