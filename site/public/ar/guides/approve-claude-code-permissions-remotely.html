وافق على طلبات Claude Code من حاسوب آخر

شغّل Claude Code عبر Antenna، في وضع Code من النافذة أو بالأمر antenna session على خادم، فتفحص الخدمة الخلفية لـ Antenna كل أداة يستخدمها وكل رسالة يرسلها. وحين تحتاج خطوة ما إليك، تصبح طلب موافقة يظهر على كل حاسوب اقترنت به على أنه حاسوبك، في My devices (أجهزتي)، مع إشعار. وافق عليه هناك بكلمة مرور ذلك الحاسوب أو Touch ID: فيتحقق الحاسوب الذي يعمل عليه Claude Code من إجابتك، وينفّذ الخطوة، ويواصل Claude Code عمله.

ما يصل إليك

  • الخطوات بعد قراءة رسالة من جهة اتصال. بمجرد أن يقرأ Claude Code رسالة زميل، يحدد مستوى ثقة الزميل ما يحق له فعله: في المستوى 4 ينتظرك كل أمر، وفي المستويين 2 و3 ينتظرك كل تعديل وتُرفض الأوامر.
  • التغييرات في إعداداته هو. بعد قراءة رسالة من أي جهة اتصال، حتى لو كانت من حاسوبك المحمول، تنتظرك التعديلات على CLAUDE.md و.claude/ وملفات تعريف الصدفة (shell) والمفاتيح وملفات البناء مثل package.json.
  • الرسائل التي قد تُخرج بياناتك. بمجرد أن يقرأ ملفات مشروعك، تنتظر كل رسالة إلى جهة اتصال أدنى من ∞، وكذلك أي رسالة إلى جهة كهذه يبدو أنها تحمل مفتاحًا أو كلمة مرور أو رمز وصول. وبمجرد أن يقرأ محادثة واحدة، تنتظر أيضًا أي رسالة إلى محادثة أخرى.
  • الأسئلة. تجريبي. تظهر أسئلة الوكيل على الحاسوب الذي يعمل عليه، تحت Questions from your agents (أسئلة وكلائك). ولتصلك على حاسوبك المحمول بدلًا من ذلك، شغّل antenna agent escalate api-dev --to mac هناك: فيصل كل سؤال بعدها إلى محادثة الوكيل، وتجيب في المحادثة.

أما نافذة الأذونات الخاصة بـ Claude Code نفسه («Do you want to proceed?») فتبقى في طرفيته: لا يكتب Antenna فيها شيئًا أبدًا. اسمح بالأدوات التي تستخدمها عادةً في إعدادات Claude Code، أو أجب عنها عبر antenna session attach.

الإعداد

  1. ثبّت Antenna على الحاسوبين واقرنهما مرة واحدة مع تحديد This is my own computer (∞)، كما في Claude Code على VPS.
  2. شغّل Claude Code عبر Antenna. على حاسوب مكتبي: Agents → AI apps → Start in Code mode. وعلى خادم: 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
  3. على الحاسوب الذي يعمل عليه Claude Code، اقبل الإجابات من الحاسوب الذي ستوافق منه: My devices → بطاقة ذلك الحاسوب → Approvals → Accept approvals signed with …، بكلمة مرورك. وعلى خادم: antenna devices confirm mac.

أجب من أي حاسوب

يظهر الطلب على بطاقة الحاسوب الذي طلبه في My devices ‏(تجريبي)، مع إشعار مثل «Antenna: approval needed on Mac mini». تذكر البطاقة أي وكيل يطلب، ولماذا، والغرض من الطلب، وتقتبس نصه، إلا النص الذي فيه سرّ، فهذا لا يغادر الحاسوب الذي طلبه أبدًا. اضغط Approve with Touch ID على Mac ‏(تجريبي)، أو Approve with password بكلمة مرور الحاسوب الذي تجلس أمامه، أو Deny.

يتحقق الحاسوب الذي طلب من التوقيع بالمفاتيح التي قبلتها عليه، وبالتحدي الخاص به لمرة واحدة، وبهذا الطلب بعينه، ثم ينفّذ الطلب بنفسه مرة واحدة. وعلى ذلك الحاسوب نفسه، تجد الطلب في Approval requests (طلبات الموافقة)، أو عبر antenna approvals وantenna approve <id> في الطرفية.

ينتظر Claude Code حتى 50 ثانية، وتُنفَّذ فورًا أي خطوة وافقت عليها خلالها. وبعد ذلك ينتقل إلى عمل آخر؛ وحين توافق، يكتب Antenna «Approved — continue.» في موجّهه فيعيد تنفيذ الخطوة.

إذا لم يُجب أحد

يُغلق الطلب بعد 10 دقائق: لا يُنفَّذ شيء ولا يُرسل شيء، ويعرف Claude Code أن أحدًا لم يوافق. ويُنبّهك إشعار قبل ذلك بقليل. وبعد Deny، الذي لا يحتاج إلى كلمة مرور، يعرف Claude Code أنك رفضت.

وكيل يوافق نيابة عنك

تجريبي. يتيح Can approve for… (يوافق نيابة عن…) في Agents لوكيل تثق به أن يجيب عن طلبات وكلائك الآخرين المتعلقة بالرسائل والملفات، ولا تُحتسب إجابته إلا إذا كان كل ما يمسّه الطلب في المستوى ∞. أما الأوامر والتعديلات فتصلك أنت دائمًا.

أسئلة

هل يعمل هذا مع Codex؟

جزئيًا. ما يرسله Codex عبر Antenna يُفحص بالطريقة نفسها، وتصل تلك الطلبات إلى كل حواسيبك؛ أما أوامر Codex نفسه فتبقى خاضعة لموافقات Codex في طرفيته.

هل يستطيع أي حاسوب الموافقة؟

لا. فقط حاسوب اقترنت به على أنه حاسوبك وقبلت مفاتيحه، بكلمة المرور، على الحاسوب الذي يطلب. وإذا فُقد حاسوب، فاضغط Revoke this computer (إلغاء هذا الحاسوب) على كل حاسوب من الحواسيب الأخرى.

هل أستطيع الموافقة من هاتفي؟

ليس بعد. يعمل Antenna اليوم على macOS وLinux.

Antenna مجاني ومفتوح المصدر، لنظامي macOS وLinux. بلا حساب وبلا رقم هاتف.
