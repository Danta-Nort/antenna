إعداد وكيل ذكاء اصطناعي يرد على رسائلك

في Antenna يمكنك اختيار جهة اتصال ووكيل (Claude Code أو Codex أو أمرك الخاص)، ومن ثم فإن كل رسالة من جهة الاتصال تلك تشغّل الوكيل، فيقرؤها ويرد عليها. يشغّله Antenna في بيئة معزولة (sandbox)، بصلاحيات لا تتجاوز مستوى ثقة جهة الاتصال، ويظهر الرد للطرف الآخر أثناء كتابته. يعمل الوكيل بتسجيل دخولك أنت إلى Claude أو ChatGPT، وأي رد يبدو أنه يحتوي على سر ينتظر موافقتك.

استخدامات شائعة

  • مساعدك الخاص على خادم. تكتب إلى خادمك من حاسوبك المحمول، فيرد Claude Code هناك ويبني المشروع ويشغّل الاختبارات فيه.
  • مكتب استقبال لجهة اتصال. تحصل أسئلة زميلك عن مشروعك على إجابة فورية، من وكيل لا يرى إلا مجلد تلك المحادثة.
  • سكربت يرسل لك النتائج. يمكن إرسال مخرجات أي برنامج كبث مباشر: my-program | antenna send --stream <contact>.

الإعداد من النافذة

  1. على الحاسوب الذي يجب أن يعمل عليه الوكيل، افتح Agents → Set up for a contact… (أو، داخل محادثة، Agent replies → Set up… في بطاقة جهة الاتصال).
  2. اختر جهة الاتصال والبرنامج: Claude Code أو Codex أو أمرك الخاص.
  3. يمكنك اختياريًا لصق رمز تسجيل دخول طويل الأمد (من claude setup-token) في Value (optional). يُرسل إلى عقدتك مرة واحدة ويُحفظ في قاعدة بياناتها المشفرة. وعلى Mac هذه هي الطريقة الموثوقة، لأن البيئة المعزولة لا تستطيع فتح سلسلة المفاتيح (Keychain).
  4. أكّد بكلمة مرور المالك. تظهر القاعدة وآخر تشغيل لها وRun log (سجل التشغيل) في Agents.

ومن الطرفية يكفي سطر واحد: antenna wake set <contact> --cmd "claude -p --output-format stream-json". ويعرض antenna wake list القواعد وآخر عمليات التشغيل، ويوقفها antenna wake off <contact>.

ما يستطيعه الوكيل وما لا يستطيعه

  • موجّهه (prompt) ثابت: «لديك رسالة جديدة، اقرأها ورد عليها». الرسالة نفسها لا تصبح الموجّه أبدًا؛ يقرؤها الوكيل كبيانات، بصلاحيات لا تتجاوز مستوى ثقة جهة الاتصال.
  • يعمل في بيئة معزولة (bubblewrap أو Landlock على Linux، وSeatbelt على macOS): يرى مجلده المؤقت ومجلد تلك المحادثة فقط، ولا يصل إلا إلى مزوّد نموذجه. مشاريعك وملفاتك الأخرى ومفاتيح العقدة بعيدة عن متناوله. وبلا بيئة معزولة، لا يشغّله Antenna.
  • كل تشغيل يبدأ من الصفر ما لم تجعل الوكيل مقيمًا (انظر أدناه)، فلا تستطيع رسالة سابقة أن تترك تعليمات لتشغيل لاحق.
  • الحدود: مهلة زمنية لكل تشغيل، وعدد محدد من مرات التشغيل في الساعة، فلا تستطيع جهة اتصال كثيرة الكلام استنزاف استخدامك.

دعه يعمل في أحد مشاريعك

لحواسيبك أنت فقط (∞)، يمكن للوكيل أيضًا العمل في مجلد مشروع واحد بأدواتك: --project ~/code/payments، مع مجلدات للقراءة فقط عبر --tool-path، وسجلات الحزم التي يحق له الوصول إليها عبر --allow-host. يرفض Antenna ذلك لأي جهة اتصال أخرى، ولا يفتح أبدًا مجلد المنزل، ولا بياناته هو، ولا المجلدات التي تحوي أسرارًا مثل ~/.ssh.

أسئلة

هل يرى الطرف الآخر الرد أثناء كتابته؟

نعم، لجهات الاتصال من المستوى 3 فما فوق: فقاعة حية تكبر بينما يكتب الوكيل، وتتحول في النهاية إلى رسالة عادية. أما المستويان 1 و2 فيحصلان على الرد مكتملًا.

ماذا لو كتب الوكيل كلمة مرور أو مفتاحًا في رده؟

يتوقف البث عند الطرف الآخر، وتنتظر الرسالة موافقتك. ولا يستمر إلا إلى حواسيبك أنت.

هل يتذكر المحادثات السابقة؟

افتراضيًا، لا: كل رسالة تبدأ تشغيلًا جديدًا. وللعمل الذي يستمر ساعات، أضف --resident: عندها تبقى جلسة Claude Code نفسها مع المحادثة، وتحتفظ بما قيل وما تقرر، وتصبح كل رسالة جديدة دورها التالي. ومع ذلك تبقى الرسائل تصلها كبيانات من طرف آخر.

Antenna مجاني ومفتوح المصدر، لنظامي macOS وLinux. بلا حساب وبلا رقم هاتف.
