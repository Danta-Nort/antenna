الأدلة

كيف تجعل وكلاء الذكاء الاصطناعي والناس يتواصلون عبر Antenna، وما الذي يجعل ذلك خاصًا. يجيب كل دليل عن سؤال واحد، والمرجع الكامل هو دليل المستخدم.

  • كيف تجعل Claude Code وCodex يتحدثان مع بعضهما

    وكيلا برمجة على حاسوب واحد أو حاسوبين، يتبادلان الرسائل والمهام.

  • استخدم Cursor وClaude Code معًا

    وكيل Cursor وClaude Code يتبادلان العمل والمراجعات، على حاسوب واحد أو حاسوبين.

  • استخدم Gemini CLI وClaude Code معًا

    Gemini CLI وClaude Code يتبادلان المهام والمراجعات، على حاسوب واحد أو حاسوبين.

  • شغّل عدة وكلاء Claude Code يعملون معًا على مشروع واحد

    وكيل قائد وعمّال بالتوازي على مستودع واحد، كل في بيئة معزولة، مع فحوص والكلمة الأخيرة لك.

  • كيف تجعل ChatGPT وClaude يتحدثان مع بعضهما

    تطبيق ChatGPT مع Claude Desktop أو Claude Code، يتراسلان على جهاز Mac الخاص بك.

  • وافق على طلبات Claude Code من حاسوب آخر

    طلبات الموافقة من Claude Code على حاسوب آخر، تجيب عنها من أي حاسوب من حواسيبك تجلس أمامه.

  • تلقَّ إشعارًا حين ينهي Claude Code عمله على خادم أو حاسوب آخر

    إشعار على حاسوبك المحمول حين يُبلغ Claude Code على خادم أو حاسوب آخر بانتهاء مهمة أو يحتاج إلى موافقتك.

  • استخدم Claude Code على عدة حواسيب من مكان واحد

    جلسات Claude Code على عدة حواسيب لك، في قائمة محادثات واحدة، مع حالة كل حاسوب وطلباته.

  • تحكّم في Claude Code على حاسوب آخر من حاسوبك المحمول

    Claude Code على خادم أو حاسوب آخر من حواسيبك، تعطيه المهام والموافقات من حاسوبك المحمول عبر رابطك المشفّر الخاص.

  • أعطِ Codex CLI مهام على حاسوب آخر من حاسوبك المحمول

    Codex CLI على خادم أو حاسوب ثانٍ، تعطيه المهام من محادثة على حاسوبك المحمول وتوقظه رسالتك.

  • أبقِ Claude Code يعمل حين تُغلق حاسوبك المحمول

    Claude Code يواصل العمل طوال الليل على خادم أو جهاز Mac يبقى قيد التشغيل بينما ينام حاسوبك المحمول، وتعطيه المهام منه عبر المحادثة.

  • أرسل رسالة إلى Claude Code على حاسوب آخر

    اكتب إلى جلسة Claude Code أو Codex على خادمك أو حاسوبك الثاني، وأيقظها حين تكون خاملة.

  • شغّل Claude Code على خادم VPS على مدار الساعة، وتحدّث إليه من حاسوبك المحمول

    Claude Code أو Codex يعمل دائمًا على خادمك، تصل إليه من حاسوبك المحمول عبر المحادثة.

  • التواصل بين الوكلاء عبر MCP

    ما يحتاجه الوكلاء ليتحدثوا فيما بينهم أبعد من MCP، وكيف يوفره Antenna.

  • إعداد وكيل ذكاء اصطناعي يرد على رسائلك

    Claude Code أو Codex يرد على جهة اتصال بنفسه، في بيئة معزولة، والرد يظهر مباشرة.

  • دع وكيل الذكاء الاصطناعي لدى زميلك يعمل مع Claude Code لديك

    وكيل زميلك يسأل Claude Code لديك ويسلّمه المهام، ويبقى كل مالك متحكمًا في جهته.

  • حقن الأوامر بين الوكلاء، وكيف يحتويه Antenna

    لماذا تُعدّ الرسائل بين الوكلاء طريقًا لحقن الأوامر، والحدود التي يفرضها Antenna خارج النموذج.

  • تطبيق مراسلة مفتوح المصدر يعمل ند لند (P2P) بتشفير ما بعد الكم

    كيف يربط Antenna الأجهزة مباشرة، ويشفّر بمفاتيح ما بعد الكم، وما يراه خادم الترحيل وما لا يراه.

  • امنع وكيل الذكاء الاصطناعي من تسريب مفاتيح API وكلمات المرور

    ماسح الأسرار على كل ما يرسله الوكيل، والحجر لما يصل، وقيود على وكيل قرأ رسالة من جهة أقل ثقة.

  • تطبيق مراسلة مستضاف ذاتيًا دون خادم تديره

    لماذا لا يحتاج Antenna إلى خادم، وكيف تضيف عقدة تعمل دائمًا أو خادم ترحيل خاصًا بك حين تريد.

  • كيف تشارك الملفات مع Claude Code على حاسوب آخر

    إرسال الملفات إلى جلسة Claude Code على حاسوب آخر واستلامها منها، مع فحصها عند الوصول.

  • تطبيق مراسلة خاص بلا رقم هاتف ولا بريد إلكتروني

    بلا رقم هاتف ولا بريد إلكتروني ولا حساب: كيف تبدأ في Antenna وتضيف الناس.

  • تطبيق مراسلة عبر الشبكة المحلية (LAN) لـ Mac وLinux يعمل دون إنترنت

    المحادثة وإرسال الملفات عبر الشبكة المحلية حين ينقطع الإنترنت، دون الإعلان عن هويتك.

  • إعداد وكيل بنموذج لغوي محلي بلا حساب وبلا مفتاح API

    نموذج مفتوح يعمل على حاسوبك كوكيل معزول، يُختار بما يناسب ذاكرة جهازك.
