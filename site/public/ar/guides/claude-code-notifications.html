آخر تحديث 15 نوفمبر 2026

تلقَّ إشعارًا حين ينهي Claude Code عمله على خادم أو حاسوب آخر

أعطِ Claude Code مهمته في محادثة Antenna من حاسوبك المحمول، فيرسل النتيجة إلى تلك المحادثة حين ينتهي: إذ تطلب تعليمات Antenna من الوكيل المتصل أن يرسل نتائجه إلى جهة الاتصال التي كلّفته بالمهمة. وما دامت نافذة Antenna ليست في المقدمة، يعرض حاسوبك المحمول إشعارًا «New message in server · api-dev». وطلبات الموافقة تُشعرك أيضًا، فلا يبقى عمل توقف في منتصفه منتظرًا دون أن يلاحظه أحد. لا يراقب Antenna أدوار Claude Code بنفسه: فالتقرير رسالة يرسلها Claude Code نفسه.

ما الذي يُشعرك

  • رسالة من Claude Code إليك. يذكر الإشعار اسم المحادثة، لا نصها أبدًا، ومرة واحدة على الأكثر لكل محادثة كل 10 ثوانٍ.
  • طلب موافقة. تظهر الخطوة التي تحتاج إلى كلمتك على أنها «Antenna: approval needed on server»، مع اسم الوكيل وما يريد فعله والوقت المتبقي («expires in 9 min»)، لكن دون نص الطلب أبدًا. ويصل إشعار ثانٍ قبل إغلاق الطلب بنحو دقيقتين؛ إذ يُغلق الطلب بعد 10 دقائق. أما الطلبات القادمة من حاسوب آخر فتصلك عبر My devices (أجهزتي؛ تجريبي).
  • سؤال. تجريبي. يصل إشعار سؤال الوكيل على الحاسوب الذي يعمل عليه: «A question from your agent». وإذا كان الوكيل على خادم، فشغّل antenna agent escalate api-dev --to mac هناك، فتصل أسئلته بدلًا من ذلك إلى محادثة الوكيل على حاسوبك المحمول.

تعمل الإشعارات على macOS وعلى أسطح مكتب Linux التي تعرض الإشعارات. ويجب أن يكون Antenna مفتوحًا على الحاسوب المحمول؛ وحين تكون نافذته في المقدمة، تكفي أعداد الرسائل غير المقروءة في قائمة المحادثات.

الإعداد

  1. ثبّت Antenna على الحاسوبين واقرنهما مرة واحدة مع تحديد This is my own computer (∞). ويشرح دليل Claude Code على VPS جانب الخادم خطوة بخطوة.
  2. شغّل Claude Code عبر Antenna. على خادم: 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    وعلى حاسوب مكتبي ثانٍ: Agents → AI apps → Start in Code mode.
  3. لا شيء تضبطه على الحاسوب المحمول. فالمحادثة مع وكيل تُشعرك منذ البداية بالرسائل الموجّهة إليك شخصيًا وبطلبات الموافقة.

اطلب التقرير

اكتب المهمة في محادثة api-dev وقل ما تريد أن يصلك: «شغّل اختبارات الترحيل وأصلح ما يفشل منها. وحين تنتهي، ردّ هنا بما تغيّر». وإذا كان Claude Code خاملًا عند موجّهه، يكتب Antenna سطرًا واحدًا ليقرأ رسالتك (تجريبي)؛ فيعمل، ثم يرد في المحادثة نفسها، ويعرض حاسوبك المحمول الإشعار.

وللعمل الذي تبدؤه في طرفيته (antenna session attach api-dev)، اختم طلبك بعبارة «أرسل لي ملخصًا على Antenna حين تنتهي». ولتجعل ذلك عادة، أضف سطرًا إلى ملف CLAUDE.md في المشروع: «حين تنهي مهمة، أرسل ملخصًا قصيرًا إلى mac عبر send_message في Antenna».

يصل التقرير حين يقرر Claude Code أنه انتهى، كما هو الحال مع أي تعليمات يتبعها. وإذا توقف عند نافذة الأذونات الخاصة به في الطرفية («Do you want to proceed?»)، فلا يرى Antenna ذلك، ولا يصلك أي إشعار: اسمح بالأدوات التي تستخدمها عادةً في إعدادات Claude Code.

اختر المحادثات التي تُشعرك

افتح ⋮ في صف المحادثة، أو انقر عليه بالزر الأيمن، ثم اختر Notifications (الإشعارات):

  • All messages (كل الرسائل): كل رسالة جديدة في هذه المحادثة (الإعداد الافتراضي لمحادثة مع شخص).
  • Only when it asks for me (فقط حين يطلبني): الرسائل الموجّهة إليك شخصيًا وطلبات الموافقة (الإعداد الافتراضي لمحادثة مع وكيل).
  • Off (إيقاف): تبقى طلبات الموافقة تُشعرك.

وحين يرسل Claude Code تقريره إلى أحد وكلائك الآخرين بدلًا منك، تصل تلك الرسائل بلا إشعار ما لم تفعّل Notify about messages between agents (الإشعار بالرسائل بين الوكلاء) في القائمة نفسها. وفي الطرفية: antenna chats notify server --agent api-dev all.

على الحاسوب الذي تجلس أمامه

حين يعمل Claude Code في وضع Code على حاسوبك المحمول نفسه، يُشعرك Antenna بطلبات الموافقة والأسئلة منه ما دامت النافذة في الخلفية، لكنه لا يُشعرك بنهاية الدور: فالوكيل لا يستطيع مراسلتك على الحاسوب الذي يعمل عليه هو. ولهذا الغرض، يمكن لخطافات Claude Code نفسه (hooks) أن تشغّل أمرًا تختاره حين يتوقف.

أسئلة

هل يعرض الإشعار ما كتبه Claude Code؟

لا. يقول فقط «New message in» واسم المحادثة، لأن الإشعار قد يظهر على شاشة مقفلة. افتح المحادثة لتقرأ التقرير.

وماذا لو كان حاسوبي المحمول في وضع السكون؟

تنتظر الرسالة على الخادم، ويوصلها Antenna مع إشعارها حين يعود الحاسوب المحمول إلى الاتصال.

هل يمكن أن يصلني الإشعار على هاتفي؟

ليس بعد. يعمل Antenna اليوم على macOS وLinux.

Antenna مجاني ومفتوح المصدر، لنظامي macOS وLinux. بلا حساب وبلا رقم هاتف.
