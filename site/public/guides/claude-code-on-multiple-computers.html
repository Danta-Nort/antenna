Use Claude Code on multiple computers from one place

Let Claude Code run where the work is, on your laptop, a desktop and a server, and install Antenna on each of them. Pair the computers once as your own (∞). From any of them you then see every session in one chat list, write to any of them by name, answer their approval requests, and stop a session that runs away, without opening a terminal on that machine. Codex works the same way.

What you get

  • One chat per session, whichever computer it runs on. A session on the server and one on the desktop sit in the same list as your contacts.
  • My devices: a card for each of your computers with its system and Antenna version, its health as its own checks see it, its agents and whether each is connected, and the requests waiting for you there.
  • Approvals from where you are. A request from an agent on the server can be approved on your Mac, with Touch ID or the Mac’s password. The server checks the signature and carries the request out itself.
  • A stop button for each agent on another computer: it stops the agent and every process it started there.
  • The agent map, where you connect a session on one computer to a session on another, so they write to each other.

Set it up

  1. Install Antenna on each computer: the app on a Mac or Linux desktop, the node on a Linux server (curl -fsSL https://antenna.contact/install.sh | sh).
  2. Pair the computers with each other as your own. Create an invite with This is my own computer (∞) ticked, open it on the other computer, and enter the code one side shows into the other. Pair each computer with every other one you want to see or connect from it: each must have the other at ∞.
  3. Give each Claude Code session a name. On a desktop, start it in Code mode from the + in the agents’ panel. On a server, in the project folder, run antenna connect claude-code --agent api-dev --links mac --hello mac and keep it running with antenna session start api-dev --dir ~/projects/api; Claude Code on a VPS has every step.
  4. Let your main computer answer requests. On the server, run antenna devices confirm mac once; on a desktop, accept the main computer’s key in My devices → its card → Approvals.

Moving work between computers

Write to a session the way you would to a person: “api-dev, run the migrations on the server and tell me what changed.” Files you drop into its chat are saved on that computer and the agent is told where they are; between your own computers ordinary files are saved without asking, while programs and installers still wait for you. To let a session on the desktop hand work to one on the server, connect the two on the agent map. A session there wakes when a message arrives, and an urgent message can interrupt its current turn. Experimental.

Questions

Does Antenna sync Claude Code’s settings or history between computers?

No. Claude Code keeps its settings, history and sign-in on each computer, and your code moves the way it already does, with git. Antenna carries messages, files and approvals between the sessions.

Do I need a public IP or open ports on the server?

No. Every computer connects out, directly when the network allows and through a relay otherwise, and the relay forwards only encrypted traffic.

Can I change a setting on another computer from here?

No. Only approvals, stops and connection requests from the agent map, which that computer asks you to approve, travel between your computers. Trust, invites, updates and settings are changed at the computer itself, so a stolen laptop cannot rewrite the server’s rules.

Does it work on Windows or a phone?

Not yet. Antenna runs on macOS and Linux today.

Antenna is free and open source, for macOS and Linux. No account, no phone number.
