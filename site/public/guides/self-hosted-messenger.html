A self-hosted messenger with no server to run

People self-host a messenger to keep their messages off someone else’s server. Antenna gets there without a server at all: each person runs Antenna on their own computer, messages go between those computers end to end encrypted, and history is stored only there, in an encrypted database. If you want more control, you can add an always-on Linux node or run your own relay, both open source.

What a self-hosted server usually means

A classic self-hosted messenger is a server you install, update, back up and keep online, holding every account and every message of everyone who uses it. It moves trust from a company to you, and with it the work and the risk: if the server is breached, so is everyone’s history.

What Antenna does instead

  • No accounts to host. Your identity is a key on your computer, protected by your password. You add people with a one-time invite link and a code you compare by voice.
  • No message store in the middle. Your history lives on your computer, in a SQLCipher-encrypted database, and on the other person’s.
  • No server to keep online. Two computers connect directly when the network allows, and otherwise through a relay that forwards encrypted traffic and keeps nothing.

Add an always-on node

A laptop sleeps; a server does not. To keep your AI agents reachable around the clock, install the Antenna node on a Linux server (x86_64): unpack the release and run ./install.sh, which sets up a systemd user service without root, or install the .deb or .rpm package. Then pair it with your computer like a contact, at ∞ · My computer. Step by step: Add a server.

After a reboot the node’s keys stay locked until you log in and run antenna unlock: a stolen disk image gives nobody your keys.

Run your own relay

The relay is the one shared piece, and it sees only encrypted packets and which endpoints talk through it. If you would rather that be your own machine, run the open-source iroh-relay and start your node with antennad --relay <your relay URL>. Contacts you trust at levels 1 and 2 always connect through a relay, so they never learn your IP address.

Questions

Can my family use it?

On computers, yes: Antenna 0.1 runs on macOS (Apple Silicon) and Linux. There is no phone app yet.

Does the relay store messages for offline contacts?

No. A message for a contact who is offline waits on your own computer and goes by itself once they are back.

Is there anything I must host?

No. Antenna works with the default relay and no server of yours. The node and the relay are for when you want them.

How do updates work on a server?

A node installed with install.sh updates with antenna update, which checks the release signature first; a package install updates through your package manager.

Antenna is free and open source, for macOS and Linux. No account, no phone number.
