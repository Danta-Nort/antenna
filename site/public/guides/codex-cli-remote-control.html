Give Codex CLI tasks on another computer from your laptop

Install Antenna on both computers and pair them once as your own. On the computer where Codex runs, give the Codex session a name with antenna connect codex and start it with antenna session start … --cli codex. A chat with that name appears on your laptop: write a task there, and Antenna wakes Codex when it sits idle. Codex reads your message, works on the other computer, and answers in the chat. No SSH session stays open and there is no inbound port to open.

What you need

  • Codex CLI installed and signed in on the computer that does the work: a Linux server on x86_64, or a Mac or Linux desktop. Codex keeps using your own subscription; Antenna needs no API key.
  • tmux on that computer. On a server, also run sudo loginctl enable-linger $USER once, so Antenna and the session keep running after you log out.
  • Antenna on both computers: the app on a desktop, the node on a server (curl -fsSL https://antenna.contact/install.sh | sh).

1. Pair the two computers

On your laptop: New contact → Invite, tick This is my own computer (∞), create the link, and open it on the other computer (on a server, antenna join '<link>' --trust 5 --label mac). Enter the code one side shows into the other. Both sides now treat each other as your own computers. The step-by-step version with screenshots is in Claude Code on a VPS; it is the same for Codex.

2. Give the Codex session a name

On the computer where Codex runs, in the project folder:

cd ~/projects/api
    antenna connect codex --agent api-codex --links mac --hello mac

This creates the agent api-codex with its own token file, links it to your laptop (mac is the name this computer gave your laptop when you paired), and says hello, so a chat named api-codex appears on the laptop at once. Your own Codex settings are not changed: Antenna is added for this agent’s sessions only.

3. Start Codex through Antenna

antenna session start api-codex --dir ~/projects/api --cli codex
    antenna session attach api-codex

Codex starts in Antenna’s own tmux server; your tmux is not touched. Attach once to answer Codex’s first questions. The first time, Codex asks you to trust Antenna’s hooks (“Hooks need review”): choose “Trust all and continue”. Then leave with Ctrl-b d, and Codex keeps running. --resume continues the agent’s last session after a restart.

4. Write to it from your laptop

Open the api-codex chat and write: “Run the tests, fix what fails, and tell me what you changed.” When Codex sits idle at its prompt, Antenna types one built-in line telling it to read its inbox. It never types your text into the terminal and never types into a question Codex is asking. Codex reads the message through Antenna, works, and replies in the chat. Experimental.

Need it to stop what it is doing? Turn on Urgent: interrupt now before you send. Antenna presses Esc once to end the running turn and then wakes Codex for your message. To stop the agent and everything it started, open the other computer’s card in My devices on your laptop and press Stop agent and its processes… next to api-codex.

On a desktop: Code mode

If Codex runs on a Mac or Linux desktop with the Antenna app, you can skip the terminal steps. In Code mode, press + in the agents’ panel, pick Codex and the working folder, and Codex runs in a tab inside the window, woken the same way. Its chat is reachable from your other computers like any other agent’s.

Questions

Does this show me Codex’s terminal on the laptop?

No. You give Codex tasks and read its answers in a chat; the terminal stays on the other computer. To watch it, antenna session attach there, over SSH if you like.

Which Codex versions work?

Codex 0.160 and later report what they do through hooks, which is how Antenna knows when Codex is idle. With an older Codex, or without trusting the hooks, Antenna waits until Codex shows its empty input line after a turn, and never types while a turn runs.

Can Codex talk to Claude Code too?

Yes. Connect the two agents on the agent map, and each one’s messages go to the other without naming it: see Claude Code and Codex talking to each other.

Can I control it from my phone?

Not yet. Antenna runs on macOS and Linux today.

Antenna is free and open source, for macOS and Linux. No account, no phone number.
