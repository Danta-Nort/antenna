Powiadomienie, gdy Claude Code skończy pracę na serwerze albo innym komputerze

Daj Claude Code zadanie w czacie Antenny ze swojego laptopa, a gdy skończy, odeśle wynik do tego samego czatu: instrukcje Antenny każą podłączonemu agentowi odsyłać wyniki kontaktowi, który zlecił zadanie. Laptop pokaże wtedy powiadomienie „Nowa wiadomość w: server · api-dev”, o ile okno Antenny nie jest na wierzchu. Prośby o zgodę też przychodzą z powiadomieniem, więc praca zatrzymana w połowie nie czeka niezauważona. Sama Antenna nie śledzi tur Claude Code: raport to własna wiadomość Claude Code.

O czym dostajesz powiadomienia

  • Wiadomość od Claude Code do ciebie. Powiadomienie podaje nazwę czatu, nigdy treść, najwyżej raz na 10 sekund dla jednego czatu.
  • Prośba o zgodę. Krok, który wymaga twojej decyzji, pojawia się jako „Antenna: potrzebna zgoda na server”, z nazwą agenta, tym, co chce zrobić, i pozostałym czasem („wygasa za 9 min”), ale nigdy z treścią prośby. Drugie powiadomienie przychodzi około dwóch minut przed zamknięciem prośby; prośba zamyka się po 10 minutach. Prośby z innego komputera docierają do ciebie przez sekcję Moje urządzenia (funkcja eksperymentalna).
  • Pytanie. Funkcja eksperymentalna. Pytanie agenta pojawia się jako powiadomienie na komputerze, na którym agent działa: „Pytanie od twojego agenta”. W przypadku serwera uruchom na nim antenna agent escalate api-dev --to mac, a jego pytania będą zamiast tego trafiać do czatu agenta na twoim laptopie.

Powiadomienia działają na macOS i na tych pulpitach Linuksa, które pokazują powiadomienia. Antenna musi być otwarta na laptopie; gdy jej okno jest na wierzchu, wystarczą liczniki nieprzeczytanych na liście czatów.

Konfiguracja

  1. Zainstaluj Antennę na obu komputerach i połącz je raz z zaznaczonym polem To mój własny komputer (∞). Stronę serwera opisuje poradnik Claude Code na VPS.
  2. Uruchom Claude Code przez Antennę. Na serwerze: 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    Na drugim desktopie: Agenci → Aplikacje AI → Uruchom w trybie Code mode.
  3. Na laptopie nie trzeba niczego ustawiać. Czat z agentem od początku powiadamia o wiadomościach skierowanych do ciebie i o prośbach o zgodę.

Poproś o raport

Napisz zadanie w czacie api-dev i powiedz, czego oczekujesz w odpowiedzi: „Uruchom testy migracji i popraw to, co nie przechodzi. Kiedy skończysz, odpisz tutaj, co się zmieniło”. Jeśli Claude Code czeka bezczynnie w wierszu poleceń, Antenna wpisuje jedną linię, żeby przeczytał twoją wiadomość (funkcja eksperymentalna); Claude Code wykonuje pracę i odpowiada w tym samym czacie, a laptop pokazuje powiadomienie.

Gdy zaczynasz pracę w jego terminalu (antenna session attach api-dev), zakończ polecenie słowami „kiedy skończysz, wyślij mi podsumowanie przez Antennę”. Żeby weszło to w nawyk, dodaj linię do CLAUDE.md projektu: „Gdy skończysz zadanie, wyślij krótkie podsumowanie do mac narzędziem send_message Antenny”.

Raport przychodzi wtedy, gdy Claude Code uzna, że skończył, jak przy każdej instrukcji, którą wykonuje. Jeśli zatrzyma się na własnym pytaniu o zgodę w terminalu („Do you want to proceed?”), Antenna tego nie widzi i żadne powiadomienie nie przyjdzie: zezwól w ustawieniach Claude Code na narzędzia, których używasz na co dzień.

Wybierz, które czaty powiadamiają

Otwórz ⋮ w wierszu czatu albo kliknij go prawym przyciskiem, potem Powiadomienia:

  • Wszystkie wiadomości: każda nowa wiadomość w tym czacie (domyślnie dla osoby).
  • Tylko gdy zwraca się do mnie: wiadomości skierowane do ciebie i prośby o zgodę (domyślnie dla agenta).
  • Wyłączone: o prośbach o zgodę i tak dostaniesz powiadomienie.

Gdy Claude Code raportuje nie tobie, tylko innemu z twoich agentów, te wiadomości przychodzą bez powiadomień, chyba że w tym samym menu włączysz Powiadamiaj o wiadomościach między agentami. W terminalu: antenna chats notify server --agent api-dev all.

Na komputerze, przy którym siedzisz

Gdy Claude Code działa w trybie Code mode na twoim własnym laptopie, Antenna powiadamia o jego prośbach o zgodę i pytaniach, kiedy okno jest w tle, ale nie o końcu tury: agent nie może napisać do ciebie na własnym komputerze. Do tego służą własne hooki Claude Code, które mogą uruchomić twoje polecenie, gdy Claude Code się zatrzyma.

Pytania

Czy powiadomienie pokazuje, co napisał Claude Code?

Nie. Zawiera tylko „Nowa wiadomość w:” i nazwę czatu, bo powiadomienie może się pojawić na zablokowanym ekranie. Żeby przeczytać raport, otwórz czat.

A jeśli laptop śpi?

Wiadomość czeka na serwerze, a Antenna dostarczy ją razem z powiadomieniem, gdy laptop wróci do sieci.

Czy mogę dostawać powiadomienia na telefon?

Jeszcze nie. Antenna działa dziś na macOS i Linuksie.

Antenna jest darmowa i open source, na macOS i Linuksa. Bez konta i bez numeru telefonu.
