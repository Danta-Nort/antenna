Jak uruchomić kilku agentów Claude Code, którzy razem pracują nad jednym projektem

W Antennie zespół to agent prowadzący i pomocnicy pracujący nad jednym projektem w gicie. Raz ustalasz budżet (na przykład „najwyżej 2 programistów Claude Code”), a agent prowadzący dzieli pracę na zadania, uruchamia pomocników w ramach tego budżetu, przegląda każdy wynik i odsyła go do poprawki albo przyjmuje. Każdy pomocnik koduje równolegle we własnej piaskownicy (sandbox), na własnej kopii projektu, a praca zespołu trafia do twojej gałęzi dopiero wtedy, gdy ją zatwierdzisz. Funkcja eksperymentalna.

Problem z kilkoma agentami w jednym folderze

Uruchomienie obok siebie dwóch czy trzech sesji Claude Code jest proste; trudniej sprawić, żeby sobie nie przeszkadzały. Edytują te same pliki, uruchamiają polecenia w tym samym folderze i każda może przeczytać wszystko, co pozostałe. Ktoś musi rozdzielać zadania, sprawdzać, co wraca, i to scalać — i zwykle robisz to ty, skacząc między terminalami.

Jak działa zespół

  1. Tworzysz zespół w sekcji Zespoły → Nowy zespół: folder projektu, agent prowadzący (jeden z twoich agentów, lokalny model albo ty), budżet pomocników i zasady: czy pomocnicy mogą uruchamiać polecenia, jakie Polecenia sprawdzające może wskazać zadanie (cargo test, npm test) i do jakich rejestrów pakietów te sprawdzenia mogą sięgać.
  2. Dajesz agentowi prowadzącemu cel, w jego własnym terminalu: „Podziel funkcję logowania na małe zadania dla dwóch programistów”.
  3. Agent prowadzący planuje i kompletuje zespół. Pisze zadania, w ramach budżetu uruchamia pomocników, na przykład web.coder-1, i przydziela im pracę.
  4. Pomocnicy kodują równolegle. Każdy dostaje świeżą kopię projektu z gałęzi zespołu, czyta tylko swoje zadanie, pracuje i oddaje wynik albo, gdy utknie, zadaje pytanie agentowi prowadzącemu.
  5. Antenna sprawdza każdy wynik, uruchamiając polecenie sprawdzające zadania w osobnej piaskownicy, bez tokenów i bez sieci poza wskazanymi przez ciebie rejestrami. Wynik, który nie przejdzie sprawdzenia, sam wraca do pomocnika, do określonego limitu, zanim zdecyduje agent prowadzący.
  6. Agent prowadzący przegląda wynik: przyjmuje go albo odsyła z uwagami. Przyjęta praca zbiera się w gałęzi zespołu, antenna/web.
  7. Ty ją wprowadzasz. Przejrzyj i wprowadź pokazuje, co zostanie scalone z twoją gałęzią; po podaniu hasła zmiany są scalane jako fast-forward. Bez hasła nic się nie rusza.

Co widzisz

Tablica zespołu pokazuje każde zadanie według stanu, od „Otwarte” i „W toku”, przez „Do przeglądu” i „Zablokowane”, po „Przyjęte” i „Wprowadzone”, razem z wyjściem każdego pomocnika na żywo, zmianami, które wprowadza jego wynik, wynikiem sprawdzenia i zużytymi tokenami. Możesz zrobić wszystko, co agent prowadzący: odpowiedzieć na pytanie pomocnika, poprosić o zmiany, anulować zadanie albo zatrzymać pomocnika. Gdy agent prowadzący działa w trybie Code mode Antenny, budzi się za każdym razem, gdy pomocnik odda wynik albo o coś zapyta, więc zespół pracuje dalej, kiedy ciebie nie ma.

Co chroni projekt

  • Pomocnicy nigdy nie widzą twojego folderu, twoich pozostałych plików ani kopii innych pomocników, a z sieci docierają tylko do dostawcy swojego modelu.
  • Agent prowadzący nie może podnieść sobie budżetu, niczego za ciebie zatwierdzić ani zobaczyć tokenu pomocnika: o każdym wywołaniu decyduje Antenna, nie model.
  • Niezaufane dane nie wychodzą poza swoje granice. Zadanie napisane po przeczytaniu wiadomości od kontaktu z poziomu 2 nie uruchamia żadnych poleceń ani sprawdzeń, więc instrukcja przemycona w tej wiadomości nie dosięgnie twojego komputera.
  • Jeśli chcesz, tylko lokalnie. Zespół można ograniczyć do modeli działających na twoim komputerze, bez żadnego modelu w chmurze.

Pytania

Którzy agenci mogą być pomocnikami?

Claude Code z twoim własnym logowaniem, inny program, który obsługuje format stream-json Claude Code, albo lokalny model do lżejszych ról, takich jak wstępna selekcja, podsumowania i dokumentacja.

Czy agentem prowadzącym może być Codex albo inna aplikacja?

Agentem prowadzącym może być każdy z twoich agentów podłączonych do Antenny: dostaje narzędzia zespołu przez MCP przy następnym uruchomieniu swojej aplikacji. Zespół możesz też prowadzić osobiście, z tablicy.

Jak ograniczyć koszty?

Budżet określa, ilu pomocników każdego rodzaju może istnieć, a zasady ograniczają czas jednej tury i jednego sprawdzenia oraz liczbę tokenów, jaką może zużyć zadanie.

Czy to działa na moim Macu?

Tak, na macOS i Linuksie. Pomocnicy działają na komputerze, na którym jest zespół; pomocnicy na twoich pozostałych komputerach pojawią się później.

Antenna jest darmowa i open source, na macOS i Linuksa. Bez konta i bez numeru telefonu.
