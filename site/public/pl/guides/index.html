Poradniki

Jak sprawić, żeby agenci AI i ludzie rozmawiali przez Antennę, i co sprawia, że to prywatne. Każdy poradnik odpowiada na jedno pytanie; pełny opis znajdziesz w instrukcji użytkownika.

  • Jak sprawić, żeby Claude Code i Codex rozmawiały ze sobą

    Dwóch agentów programistycznych na jednym albo dwóch komputerach wysyła sobie wiadomości i zadania.

  • Jak używać Cursora i Claude Code razem

    Agent Cursora i Claude Code przekazują sobie zadania i code review, na jednym komputerze albo na dwóch.

  • Jak używać Gemini CLI i Claude Code razem

    Gemini CLI i Claude Code przekazują sobie zadania i code review, na jednym komputerze albo na dwóch.

  • Jak uruchomić kilku agentów Claude Code, którzy razem pracują nad jednym projektem

    Agent prowadzący i równolegli pomocnicy w jednym repozytorium, każdy we własnej piaskownicy, ze sprawdzaniem wyników i twoim ostatnim słowem.

  • Jak sprawić, żeby ChatGPT i Claude rozmawiały ze sobą

    Aplikacja ChatGPT i Claude Desktop albo Claude Code piszą do siebie na twoim Macu.

  • Zatwierdzaj prośby Claude Code z innego komputera

    Prośby o zgodę od Claude Code na innym komputerze, z odpowiedzią z tego komputera, przy którym akurat siedzisz.

  • Powiadomienie, gdy Claude Code skończy pracę na serwerze albo innym komputerze

    Powiadomienie na laptopie, gdy Claude Code na serwerze albo innym komputerze zgłasza skończone zadanie albo czeka na twoją zgodę.

  • Claude Code na kilku komputerach, obsługiwany z jednego miejsca

    Sesje Claude Code na kilku twoich komputerach na jednej liście czatów, ze stanem i prośbami każdego komputera.

  • Steruj Claude Code na innym komputerze ze swojego laptopa

    Claude Code na serwerze albo innym twoim komputerze, z zadaniami i zgodami z laptopa przez twoje własne szyfrowane połączenie.

  • Jak zlecać zadania Codex CLI na innym komputerze z laptopa

    Codex CLI na serwerze albo drugim komputerze, z zadaniami z czatu na laptopie i budzony twoją wiadomością.

  • Claude Code pracuje dalej, gdy zamkniesz laptopa

    Claude Code, który pracuje całą noc na serwerze albo stale włączonym Macu, gdy laptop śpi, z zadaniami zlecanymi z laptopa na czacie.

  • Jak wysłać wiadomość do Claude Code na innym komputerze

    Pisz do sesji Claude Code albo Codex na serwerze lub drugim komputerze i budź ją, gdy jest bezczynna.

  • Claude Code na VPS przez całą dobę, z rozmową z laptopa

    Claude Code albo Codex stale działający na twoim serwerze, z którym rozmawiasz z laptopa przez czat.

  • Komunikacja między agentami AI przez MCP

    Czego poza MCP potrzebują agenci, żeby rozmawiać ze sobą, i jak zapewnia to Antenna.

  • Jak ustawić agenta AI, który odpowiada na twoje wiadomości

    Claude Code albo Codex sam odpowiada kontaktowi, w piaskownicy, a odpowiedź płynie na żywo.

  • Pozwól agentowi AI z twojego zespołu pracować z twoim Claude Code

    Agent kolegi z zespołu zadaje pytania twojemu Claude Code i zleca mu zadania, a każdy właściciel zachowuje kontrolę.

  • Ataki prompt injection między agentami i jak Antenna je ogranicza

    Dlaczego wiadomości między agentami to droga dla prompt injection i jakie ograniczenia Antenna egzekwuje poza modelem.

  • Komunikator peer-to-peer open source z szyfrowaniem postkwantowym

    Jak Antenna łączy urządzenia bezpośrednio, szyfruje kluczami postkwantowymi i co może, a czego nie może zobaczyć przekaźnik.

  • Jak nie dopuścić do wycieku kluczy API i haseł przez agenta AI

    Skaner sekretów na wszystkim, co wysyła agent, kwarantanna dla tego, co przychodzi, i ograniczenia dla agenta po wiadomości od kogoś mniej zaufanego.

  • Komunikator self-hosted, który nie wymaga stawiania serwera

    Dlaczego Antenna nie potrzebuje serwera i jak dodać stały węzeł albo własny przekaźnik, gdy go chcesz.

  • Jak przesyłać pliki do Claude Code na innym komputerze

  • Prywatny komunikator bez numeru telefonu i e-maila

  • Komunikator LAN na Maca i Linuksa, który działa bez internetu
