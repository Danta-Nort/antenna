Claude Code na VPS przez całą dobę, z rozmową z laptopa

Zainstaluj Claude Code i węzeł Antenny na swoim VPS z Linuksem, raz połącz serwer z laptopem i uruchom Claude Code przez Antennę w folderze projektu. Od tej chwili działa we własnej sesji tmux także po wylogowaniu, budzi się, gdy przyjdzie do niego wiadomość, i odpowiada na czacie na twoim laptopie. Nie trzeba otwierać portu przychodzącego ani podtrzymywać sesji SSH, a Codex działa tak samo.

Czego potrzebujesz

  • Serwera z Linuksem na x86_64, z zainstalowanym i zalogowanym Claude Code (albo Codex) oraz tmuxem.
  • Antenny na laptopie: macOS albo Linux.

1. Zainstaluj węzeł Antenny na serwerze

curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER

Instalator odczytuje najnowsze wydanie z podpisanego manifestu, sprawdza archiwum, instaluje antennad i antenna do ~/.local/bin jako usługę użytkownika systemd (root nie jest potrzebny) i tworzy twój węzeł z hasłem. Druga linia sprawia, że usługa działa dalej po wylogowaniu. Na Ubuntu albo Fedorze możesz zamiast tego zainstalować pakiet .deb albo .rpm.

2. Połącz serwer z laptopem

Na laptopie: New contact → Invite, nadaj nazwę, zaznacz This is my own computer (∞), kliknij Create link i skopiuj link. Na serwerze:

antenna join '<link>' --trust 5 --label mac

Zostaw pojedyncze cudzysłowy: link zawiera znak #. Wpisz w terminalu serwera kod pokazany na laptopie, a potem na laptopie kliknij The contact confirmed — codes match. Poziom 5 to ∞ po obu stronach, więc serwer liczy się jako twój własny komputer.

3. Uruchom Claude Code przez Antennę

cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev

Linia z connect daje sesji własnego agenta i token oraz wysyła powitanie, więc na laptopie pojawia się czat api-dev. Linia ze start uruchamia Claude Code na własnym serwerze tmux Antenny (twojego tmuxa nic nie dotyka). Podłącz się raz, żeby odpowiedzieć na pierwsze pytania Claude Code, na przykład czy ufa temu folderowi, a potem odłącz się skrótem Ctrl-b d: Claude Code działa dalej. W przypadku Codexa użyj antenna connect codex i --cli codex.

4. Rozmawiaj z nim

Napisz na czacie api-dev na laptopie: „Uruchom testy migracji i napraw to, co nie przechodzi”. Gdy Claude Code czeka bezczynnie przy swoim prompcie, Antenna wpisuje jedną krótką linię, żeby przeczytał twoją wiadomość; nigdy nie wpisuje tekstu od kontaktu i nigdy nie odpowiada za niego na pytania. Karta serwera w My devices pokazuje jego stan i agentów, a jego prośby możesz zatwierdzać z laptopa.

Po restarcie

Po restarcie serwera klucze węzła są zablokowane: usługa działa, ale połączenia milczą, dopóki się nie zalogujesz i nie uruchomisz antenna unlock. Dzięki temu kopia dysku serwera nikomu nie da twoich kluczy. antenna status pokazuje, czy węzeł jest zablokowany.

Pytania

Czemu nie po prostu SSH i tmux?

To działa, dopóki siedzisz przy terminalu. Antenna dodaje czat, do którego możesz napisać z laptopa w każdej chwili, budzi sesję, gdy to zrobisz, i pozwala innym agentom zlecać jej pracę, z uprawnieniami, które sama sprawdza.

Czy serwer potrzebuje publicznego IP albo otwartych portów?

Nie. Obie strony łączą się na zewnątrz, bezpośrednio, gdy pozwala na to sieć, a w przeciwnym razie przez przekaźnik (relay). Przekaźnik przekazuje wyłącznie zaszyfrowany ruch.

Czy mogę uruchomić kilka sesji na jednym serwerze?

Tak: jeden agent na folder projektu, każdy z własną nazwą i własnym czatem na laptopie.

Czy jest wersja na ARM?

Jeszcze nie. Węzeł serwerowy jest budowany na Linuksa x86_64.

Antenna jest darmowa i open source, na macOS i Linuksa. Bez konta i bez numeru telefonu.
