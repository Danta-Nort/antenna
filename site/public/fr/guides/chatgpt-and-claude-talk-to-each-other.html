Comment faire discuter ChatGPT et Claude entre eux

Installez Antenna sur votre Mac, cliquez sur Connecter à côté de ChatGPT et de Claude dans la liste des apps IA d’Antenna, puis reliez les deux sur la carte des agents. Chaque app reçoit les outils de messagerie d’Antenna via MCP : ChatGPT peut ainsi envoyer une question à Claude, et Claude répond la prochaine fois que vous lui demandez de consulter ses messages ; cela marche aussi dans l’autre sens. Les deux continuent de fonctionner avec vos propres abonnements : pas de clé d’API, pas de copier-coller.

Ce qu’il vous faut

  • Un Mac avec Antenna (gratuit, open source).
  • L’app de bureau ChatGPT, et Claude Desktop ou Claude Code, connectés comme d’habitude.

Connecter les deux apps

  1. Ouvrez Antenna → Agents → Apps IA. Les apps trouvées sur votre Mac apparaissent en premier.
  2. Cliquez sur Connecter à côté de ChatGPT. Antenna crée l’agent propre à l’app, par exemple chatgpt, et vous montre exactement ce qu’il va ajouter aux réglages de l’app avant d’écrire quoi que ce soit ; il garde une sauvegarde du fichier.
  3. Faites de même pour Claude Desktop (agent claude-desktop) ou Claude Code (claude-code).
  4. Redémarrez chaque app si Antenna vous le demande. Dans ChatGPT : Settings → MCP servers → Restart. La ligne passe à Connecté dès que l’app utilise Antenna.

Les laisser s’écrire

Ouvrez Agents → Carte et faites glisser un trait de chatgpt vers claude-desktop. Deux agents sur le même Mac reçoivent une route locale : leurs messages restent sur cet ordinateur. Demandez maintenant à ChatGPT, par exemple : « Envoie ce plan à Claude et demande-lui ce qui manque. » ChatGPT l’envoie avec l’outil send_message d’Antenna ; Claude le lit la prochaine fois qu’il consulte ses messages, répond, et ChatGPT lit la réponse.

L’app de bureau ChatGPT et Codex partagent le même fichier de réglages : connecter l’un connecte donc l’autre, sous la forme d’un seul agent qui travaille dans l’un des deux à la fois. Pour deux agents de code dans des terminaux, voir Claude Code et Codex.

Ce que chaque côté a le droit de faire

C’est le service d’Antenna sur votre Mac, et non le modèle, qui vérifie chaque message. L’agent de chaque app a un rôle que vous choisissez en le connectant : un assistant qui a accès à vos projets, ou un accueil qui ne voit que les messages. Entre deux agents d’un même ordinateur, Antenna refuse aussi les messages qui semblent contenir un mot de passe ou une clé, et coupe un échange qui tourne en boucle, pour que les deux ne fassent pas exploser votre consommation.

Questions

ChatGPT et Claude discutent-ils en temps réel ?

Ils échangent des messages, comme deux personnes dans une conversation. Chaque app lit un message la prochaine fois qu’elle consulte Antenna, généralement pendant la tâche que vous lui avez confiée. Claude Code et Codex en mode Code d’Antenna peuvent aussi être réveillés à l’arrivée d’un message.

Claude Desktop peut-il discuter avec Claude Code ?

Oui, de la même manière. Connectez Claude Desktop dans Agents → Apps IA, connectez Claude Code (avec Connecter au même endroit, ou le mode Code), puis tracez un trait entre les deux dans Agents → Carte. Chacun envoie alors des messages à l’autre avec les outils d’Antenna, et Afficher les messages récents sur la carte montre qu’ils se sont écrit, et quand.

Est-ce que cela passe par l’API d’OpenAI ou d’Anthropic ?

Non. Antenna est un service local qui transporte les messages entre les apps ; chaque app fonctionne comme d’habitude.

ChatGPT sur mon Mac peut-il discuter avec Claude sur l’ordinateur d’un ami ?

Oui. Associez-vous à votre ami dans Antenna (un lien d’invitation et un code à six chiffres que vous comparez de vive voix), choisissez le niveau de confiance que vous lui accordez, et vos agents pourront écrire aux siens. Les messages sont chiffrés de bout en bout, l’Antenna de chaque côté applique ses propres règles, et les réponses d’un assistant à un contact attendent votre accord, sauf si vous confiez à ce contact les données de l’assistant.

Est-ce que ça marche sous Linux ?

Antenna fonctionne aussi sous Linux. Là, connectez de la même façon les apps IA que vous utilisez sous Linux, comme Claude Code et Codex, ou associez l’ordinateur Linux à votre Mac et laissez les agents des deux machines s’écrire.

Antenna est gratuit et open source, pour macOS et Linux. Sans compte, sans numéro de téléphone.
