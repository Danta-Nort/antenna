Recevoir une notification quand Claude Code a terminé, sur un serveur ou un autre ordinateur

Confiez sa tâche à Claude Code dans une conversation Antenna depuis votre portable : une fois le travail fini, il renvoie le résultat dans cette même conversation, car les instructions d’Antenna demandent à un agent connecté de rendre ses résultats au contact qui lui a confié la tâche. Votre portable affiche alors une notification, « New message in server · api-dev », tant que la fenêtre d’Antenna n’est pas au premier plan. Les demandes d’approbation déclenchent aussi une notification : un travail qui s’arrête en cours de route ne reste pas en attente sans que vous le sachiez. Antenna ne surveille pas lui-même les tours de Claude Code : le compte rendu est un message de Claude Code lui-même.

Ce qui vous notifie

  • Un message de Claude Code pour vous. La notification indique le nom de la conversation, jamais le texte, au plus une fois toutes les 10 secondes par conversation.
  • Une demande d’approbation. Une étape qui a besoin de votre accord s’affiche sous la forme « Antenna: approval needed on server », avec l’agent, ce qu’il veut faire et le temps restant (« expires in 9 min »), mais jamais le texte de la demande. Une deuxième notification arrive environ deux minutes avant la fermeture de la demande ; elle se ferme au bout de 10 minutes. Les demandes venues d’un autre ordinateur vous parviennent via My devices (mes appareils, expérimental).
  • Une question. Expérimental. La question d’un agent s’affiche en notification sur l’ordinateur où il tourne : « A question from your agent ». Pour un serveur, lancez-y antenna agent escalate api-dev --to mac : ses questions arrivent alors dans la conversation de l’agent, sur votre portable.

Les notifications fonctionnent sous macOS et sur les bureaux Linux qui affichent des notifications. Antenna doit être ouvert sur le portable ; quand sa fenêtre est au premier plan, les compteurs de non-lus de la liste des conversations font le même travail.

Mise en place

  1. Installez Antenna sur les deux ordinateurs et associez-les une fois en cochant This is my own computer (∞) (c’est mon propre ordinateur). Claude Code sur un VPS détaille le côté serveur.
  2. Lancez Claude Code via Antenna. Sur un serveur : 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    Sur un second poste de bureau : Agents → AI apps → Start in Code mode.
  3. Rien à régler sur le portable. D’emblée, une conversation avec un agent vous notifie des messages qui vous sont adressés personnellement et des demandes d’approbation.

Demander le compte rendu

Écrivez la tâche dans la conversation api-dev en précisant ce que vous attendez en retour : « Lance les tests de migration et corrige ce qui échoue. Quand tu as fini, réponds ici avec ce qui a changé. » Si Claude Code attend, inactif, à son invite, Antenna tape une ligne pour qu’il lise votre message (expérimental) ; il travaille, puis répond dans la même conversation, et votre portable affiche la notification.

Pour un travail lancé dans son terminal (antenna session attach api-dev), terminez le prompt par « envoie-moi un résumé sur Antenna quand tu as fini ». Pour en faire une habitude, ajoutez une ligne au CLAUDE.md du projet : « Quand tu termines une tâche, envoie un court résumé à mac avec le send_message d’Antenna. »

Le compte rendu arrive quand Claude Code estime avoir fini, comme pour toute instruction qu’il suit. S’il s’arrête sur sa propre invite de permission dans le terminal (« Do you want to proceed? »), Antenna ne le voit pas, et aucune notification ne vous parvient : autorisez dans les réglages de Claude Code les outils dont vous vous servez couramment.

Choisir les conversations qui notifient

Ouvrez ⋮ sur la ligne d’une conversation, ou faites un clic droit dessus, puis Notifications :

  • All messages (tous les messages) : chaque nouveau message de cette conversation (le réglage par défaut pour une personne).
  • Only when it asks for me (seulement quand on me sollicite) : les messages qui vous sont adressés personnellement et les demandes d’approbation (le réglage par défaut pour un agent).
  • Off (désactivé) : les demandes d’approbation continuent de vous notifier.

Quand Claude Code rend compte à l’un de vos autres agents plutôt qu’à vous, ces messages restent silencieux, sauf si vous activez Notify about messages between agents (notifier les messages entre agents) dans le même menu. Dans un terminal : antenna chats notify server --agent api-dev all.

Sur l’ordinateur devant lequel vous êtes

Avec Claude Code en mode Code sur votre propre portable, Antenna vous notifie de ses demandes d’approbation et de ses questions tant que la fenêtre est en arrière-plan, mais pas de la fin d’un tour : un agent ne peut pas vous écrire sur son propre ordinateur. Pour cela, les hooks de Claude Code lui-même peuvent lancer une commande de votre choix quand il s’arrête.

Questions

La notification montre-t-elle ce que Claude Code a écrit ?

Non. Elle indique seulement « New message in » et le nom de la conversation, car une notification peut s’afficher sur un écran verrouillé. Ouvrez la conversation pour lire le compte rendu.

Et si mon portable est en veille ?

Le message attend sur le serveur, et Antenna le remet, avec sa notification, quand le portable est de nouveau en ligne.

Puis-je recevoir la notification sur mon téléphone ?

Pas encore. Antenna fonctionne aujourd’hui sous macOS et Linux.

Antenna est gratuit et open source, pour macOS et Linux. Sans compte, sans numéro de téléphone.
