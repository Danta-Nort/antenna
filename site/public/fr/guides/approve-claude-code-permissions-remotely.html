Approuver les demandes de Claude Code depuis un autre ordinateur

Lancez Claude Code via Antenna, en mode Code dans la fenêtre ou avec antenna session sur un serveur, et le daemon d’Antenna vérifie chaque outil qu’il utilise et chaque message qu’il envoie. Quand une étape a besoin de vous, elle devient une demande d’approbation qui s’affiche, avec une notification, sur chacun des ordinateurs que vous avez associés comme étant les vôtres, dans My devices (mes appareils). Approuvez-la là avec le mot de passe de cet ordinateur ou avec Touch ID : l’ordinateur où tourne Claude Code vérifie votre réponse, exécute l’étape, et Claude Code poursuit.

Ce qui vous parvient

  • Les actions après la lecture du message d’un contact. Dès que Claude Code a lu un message d’un collègue, le niveau de confiance de ce collègue fixe ce qu’il peut faire : au niveau 4, chaque commande attend votre accord ; aux niveaux 2 et 3, c’est chaque modification qui l’attend, et les commandes sont refusées.
  • Les changements de sa propre configuration. Après avoir lu le message de n’importe quel contact, même celui de votre propre portable, les modifications de CLAUDE.md, de .claude/, des profils du shell, des clés et des fichiers de build comme package.json attendent votre accord.
  • Les messages qui feraient sortir vos données. Dès qu’il a lu des fichiers de votre projet, chaque message vers un contact en dessous de ∞ attend, de même que tout message vers un tel contact qui semble contenir une clé, un mot de passe ou un jeton. Dès qu’il a lu une conversation, un message vers une autre attend aussi.
  • Les questions. Expérimental. Les questions d’un agent s’affichent sur l’ordinateur où il tourne, sous Questions from your agents (questions de vos agents). Pour les recevoir plutôt sur votre portable, lancez antenna agent escalate api-dev --to mac sur cet ordinateur : chaque question arrive alors dans la conversation de l’agent, et vous y répondez dans la conversation.

L’invite de permission de Claude Code lui-même (« Do you want to proceed? ») reste dans son terminal : Antenna n’y tape jamais rien. Autorisez dans les réglages de Claude Code les outils dont vous vous servez couramment, ou répondez-y avec antenna session attach.

Mise en place

  1. Installez Antenna sur les deux ordinateurs et associez-les une fois en cochant This is my own computer (∞) (c’est mon propre ordinateur), comme dans Claude Code sur un VPS.
  2. Lancez Claude Code via Antenna. Sur un poste de bureau : Agents → AI apps → Start in Code mode. Sur un serveur : 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
  3. Sur l’ordinateur où tourne Claude Code, acceptez les réponses de celui depuis lequel vous approuverez : My devices → la fiche de cet ordinateur → Approvals → Accept approvals signed with …, avec votre mot de passe. Sur un serveur : antenna devices confirm mac.

Répondre depuis n’importe quel ordinateur

La demande s’affiche sur la fiche de l’ordinateur qui la pose, dans My devices (expérimental), avec une notification comme « Antenna: approval needed on Mac mini ». La fiche indique quel agent demande, quoi et pourquoi, et cite son texte, sauf si ce texte contient un secret : celui-ci ne quitte jamais l’ordinateur qui a posé la demande. Cliquez sur Approve with Touch ID sur un Mac (expérimental), sur Approve with password avec le mot de passe de l’ordinateur devant lequel vous êtes, ou sur Deny (refuser).

L’ordinateur qui a posé la demande vérifie la signature au regard des clés que vous y avez acceptées, de son propre défi à usage unique et de cette demande précise, puis l’exécute lui-même, une seule fois. Sur cet ordinateur lui-même, la demande se trouve dans Approval requests, ou dans un terminal avec antenna approvals et antenna approve <id>.

Claude Code attend jusqu’à 50 secondes, et une étape approuvée dans ce délai s’exécute aussitôt. Au-delà, il passe à autre chose ; quand vous approuvez, Antenna tape « Approved — continue. » dans son invite et il relance l’étape.

Si personne ne répond

Une demande se ferme au bout de 10 minutes : rien ne s’exécute, rien n’est envoyé, et Claude Code apprend que personne ne l’a approuvée. Une notification vous prévient peu avant. Après Deny, qui ne demande pas de mot de passe, Claude Code apprend que vous avez dit non.

Un agent qui approuve à votre place

Expérimental. Can approve for… (peut approuver pour…) dans Agents permet à un agent de confiance de répondre aux demandes de vos autres agents concernant des messages et des fichiers, et sa réponse ne compte que si tout ce que touche la demande est au niveau ∞. Les commandes et les modifications vous reviennent toujours.

Questions

Est-ce que ça marche avec Codex ?

En partie. Ce que Codex envoie via Antenna est vérifié de la même façon, et ces demandes arrivent sur tous vos ordinateurs ; les commandes de Codex lui-même restent soumises aux approbations de Codex, dans son terminal.

N’importe quel ordinateur peut-il approuver ?

Non. Seulement un ordinateur que vous avez associé comme le vôtre et dont vous avez accepté les clés, avec le mot de passe, sur l’ordinateur qui pose la demande. Si vous en perdez un, utilisez Revoke this computer (révoquer cet ordinateur) sur chacun des autres.

Puis-je approuver depuis mon téléphone ?

Pas encore. Antenna fonctionne aujourd’hui sous macOS et Linux.

Antenna est gratuit et open source, pour macOS et Linux. Sans compte, sans numéro de téléphone.
