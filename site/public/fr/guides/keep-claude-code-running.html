Laisser Claude Code travailler quand votre portable est fermé

Sur le portable lui-même, c’est impossible : fermer l’écran met le portable en veille, un ordinateur en veille n’exécute rien, et Claude Code se met en pause avec lui. La solution consiste à faire tourner Claude Code sur un ordinateur qui reste allumé, par exemple un serveur Linux ou un Mac mini réglé pour ne pas se mettre en veille, à l’y lancer via Antenna et à lui confier des tâches depuis la conversation Antenna de votre portable. Fermez le portable : Claude Code continue de travailler sur l’autre ordinateur, et ses réponses attendent le portable pour arriver dès qu’il est de nouveau en ligne.

Pourquoi il s’arrête

Claude Code tourne sur l’ordinateur où vous le lancez. Quand cet ordinateur se met en veille, tous ses programmes s’arrêtent, Claude Code compris, jusqu’à son réveil. Fermer le terminal ou la fenêtre SSH dans laquelle il tourne y met fin aussi. On peut garder un portable éveillé écran fermé, mais il doit alors rester branché et allumé : c’est devenu un serveur. Le travail passe donc sur un ordinateur toujours allumé, et le portable se contente de lui parler.

Ce qu’il vous faut

  • Un ordinateur qui reste allumé : un serveur Linux en x86_64 (un VPS ou une machine chez vous), ou un Mac ou un poste Linux réglé pour ne pas se mettre en veille.
  • Claude Code installé et connecté sur cet ordinateur.
  • Antenna sur les deux ordinateurs : l’app sur votre portable (macOS ou Linux), le nœud ou l’app sur l’autre.

Sur un serveur

  1. Installez le nœud Antenna et laissez-le tourner après votre déconnexion : 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
    L’installeur configure Antenna comme service utilisateur systemd et crée votre nœud avec un mot de passe. Il n’active pas le lingering, il vous le rappelle seulement : sans la deuxième ligne, le service s’arrête quand vous vous déconnectez.
  2. Associez une fois le serveur à votre portable. Sur le portable : Nouveau contact → Inviter, cochez C’est mon propre ordinateur (∞), cliquez sur Créer le lien et copiez-le. Sur le serveur : antenna join '<link>' --trust 5 --label mac, saisissez le code affiché par le portable, puis cliquez sur Le contact a confirmé — les codes correspondent sur le portable.
  3. Lancez Claude Code via Antenna dans le dossier du projet (le serveur a besoin de tmux) : 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    Répondez aux premières questions de Claude Code, par exemple s’il fait confiance au dossier, puis détachez-vous avec Ctrl-b d. Une conversation nommée api-dev se trouve désormais sur votre portable.
  4. Autorisez le portable à répondre aux demandes d’approbation du serveur : antenna devices confirm mac.

Fermez maintenant votre session SSH. Le service continue de tourner, et Claude Code aussi, dans le serveur tmux propre à Antenna ; votre tmux n’est pas touché. Claude Code sur un VPS détaille chaque étape.

Sur un Mac ou un poste de bureau toujours allumé

  1. Dans les réglages système de l’ordinateur, empêchez-le de se mettre en veille tout seul. Antenna ne garde pas un ordinateur éveillé.
  2. Associez-le à votre portable comme ci-dessus, en cochant C’est mon propre ordinateur (∞).
  3. Sur cet ordinateur, ouvrez Agents → Apps IA et cliquez sur Lancer en mode Code à côté de Claude Code. Choisissez Nouvel agent… et donnez-lui un nom, choisissez le Dossier de travail, saisissez votre mot de passe et cliquez sur Lancer. La fenêtre passe en mode Code, et Claude Code tourne dans un onglet à l’intérieur.
  4. Demandez une fois à Claude Code, dans son onglet, de dire bonjour à votre portable via Antenna. Sa conversation apparaît alors sur le portable.
  5. Autorisez le portable à répondre à ses demandes d’approbation : Mes appareils → la fiche du portable → Approbations → Accepter les approbations signées avec …, avec votre mot de passe.

Laissez la fenêtre d’Antenna ouverte : la fermer arrête les agents qui y tournent, et la fenêtre vous le demande d’abord.

Le laisser travailler

Écrivez la tâche dans la conversation de l’agent sur votre portable : « Lance les tests de migration, corrige ce qui échoue et réponds ici avec ce qui a changé. » Quand Claude Code attend, inactif, devant son invite, Antenna tape une ligne prédéfinie pour qu’il lise votre message ; s’il est au milieu d’un tour, il reçoit le message à la fin de ce tour. Antenna ne tape jamais votre texte dans le terminal. Expérimental. Ensuite, fermez le portable.

Avant une longue exécution, vérifiez ce qui pourrait l’arrêter pendant que personne n’est là :

  • L’invite de permission de Claude Code lui-même (« Do you want to proceed? ») attend dans son terminal que quelqu’un réponde, et Antenna n’y répond jamais. Autorisez dans les réglages de Claude Code les outils dont la tâche a besoin.
  • Les demandes d’approbation d’Antenna attendent 10 minutes. Ensuite, rien ne s’exécute, et Claude Code apprend que personne n’a approuvé. Une tâche confiée depuis votre propre ordinateur, au niveau ∞, exécute ses commandes et ses modifications sans rien demander ; les changements de la configuration de Claude Code lui-même, comme CLAUDE.md ou .claude/, demandent toujours votre accord.

Quand le portable se réveille

Pendant que le portable dort, les réponses de Claude Code attendent dans la file de l’autre ordinateur, et Antenna continue d’essayer de les remettre. Dès que le portable est de nouveau en ligne, elles arrivent dans la conversation, avec une notification si la fenêtre d’Antenna n’est pas au premier plan. Un message que vous avez écrit hors ligne affiche une horloge et part tout seul. Les demandes qui attendent encore votre approbation s’affichent sur la fiche de l’autre ordinateur dans Mes appareils (expérimental).

Après un redémarrage de l’autre ordinateur

Les clés sont verrouillées après un redémarrage : ses liaisons restent donc muettes jusqu’à ce que vous saisissiez le mot de passe. Sur un serveur, connectez-vous et lancez antenna unlock, puis relancez la session ; --resume reprend la dernière session de Claude Code :

antenna session start api-dev --dir ~/projects/api --resume

Sur un Mac, saisissez le mot de passe dans la fenêtre d’Antenna et relancez l’agent.

Questions

Claude Code continue-t-il de tourner si je ferme mon portable ?

Non, si fermer l’écran met le portable en veille, ce qui est le réglage habituel : Claude Code se met en pause jusqu’à ce que vous le rouvriez. Faites-le tourner sur un ordinateur qui reste allumé, et il continue de travailler.

Claude Code peut-il tourner en arrière-plan sur mon portable ?

Tant que le portable est éveillé, oui : en mode Code, il tourne dans un onglet de la fenêtre d’Antenna que vous n’avez pas besoin de regarder, et Antenna le réveille quand un message arrive. Il s’arrête quand même quand le portable se met en veille.

Dois-je garder une session SSH ouverte ?

Non. Claude Code tourne dans le tmux d’Antenna sur le serveur, et vous le joignez par la conversation. Les deux ordinateurs établissent des connexions sortantes : aucun port entrant n’est ouvert non plus.

Antenna empêche-t-il mon Mac de se mettre en veille ?

Non. Réglez le Mac pour qu’il ne se mette pas en veille dans ses réglages système. La fenêtre d’Antenna doit rester ouverte pour le mode Code.

Puis-je le surveiller depuis mon téléphone ?

Pas encore. Antenna fonctionne aujourd’hui sous macOS et Linux.

Antenna est gratuit et open source, pour macOS et Linux. Sans compte, sans numéro de téléphone.
