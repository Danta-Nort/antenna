Piloter Claude Code sur plusieurs ordinateurs depuis un seul endroit

Laissez Claude Code tourner là où se trouve le travail, sur votre portable, un fixe et un serveur, et installez Antenna sur chacun d’eux. Associez une fois ces ordinateurs comme étant les vôtres (∞). Depuis n’importe lequel d’entre eux, vous voyez alors chaque session dans une seule liste de conversations, vous écrivez à n’importe laquelle par son nom, vous répondez à ses demandes d’approbation et vous arrêtez une session qui s’emballe, sans ouvrir de terminal sur cette machine. Codex fonctionne de la même manière.

Ce que vous obtenez

  • Une conversation par session, quel que soit l’ordinateur où elle tourne. Une session sur le serveur et une autre sur le fixe se côtoient dans la même liste que vos contacts.
  • My devices (mes appareils) : une fiche pour chacun de vos ordinateurs, avec son système et sa version d’Antenna, son état de santé selon ses propres vérifications, ses agents et leur état de connexion, et les demandes qui vous y attendent.
  • Des approbations depuis là où vous êtes. Une demande d’un agent sur le serveur peut être approuvée sur votre Mac, avec Touch ID ou le mot de passe du Mac. Le serveur vérifie la signature et exécute lui-même la demande.
  • Un bouton d’arrêt pour chaque agent sur un autre ordinateur : il arrête l’agent et tous les processus qu’il y a lancés.
  • La carte des agents, où vous reliez une session d’un ordinateur à une session d’un autre, pour qu’elles s’écrivent.

Mise en place

  1. Installez Antenna sur chaque ordinateur : l’app sur un Mac ou un poste Linux, le nœud sur un serveur Linux (curl -fsSL https://antenna.contact/install.sh | sh).
  2. Associez les ordinateurs entre eux comme étant les vôtres. Créez une invitation en cochant This is my own computer (∞), ouvrez-la sur l’autre ordinateur, et saisissez sur l’un le code affiché par l’autre. Associez chaque ordinateur à chacun de ceux que vous voulez voir ou relier depuis lui : chacun doit avoir l’autre au niveau ∞.
  3. Donnez un nom à chaque session Claude Code. Sur un poste de bureau, lancez-la en mode Code avec le + du panneau des agents. Sur un serveur, dans le dossier du projet, lancez antenna connect claude-code --agent api-dev --links mac --hello mac et gardez-la active avec antenna session start api-dev --dir ~/projects/api ; le guide Claude Code sur un VPS détaille chaque étape.
  4. Laissez votre ordinateur principal répondre aux demandes. Sur le serveur, lancez une fois antenna devices confirm mac ; sur un poste de bureau, acceptez la clé de l’ordinateur principal dans My devices → sa fiche → Approvals.

Faire circuler le travail entre ordinateurs

Écrivez à une session comme à une personne : « api-dev, lance les migrations sur le serveur et dis-moi ce qui a changé. » Les fichiers que vous déposez dans sa conversation sont enregistrés sur cet ordinateur, et l’agent est informé de leur emplacement ; entre vos propres ordinateurs, les fichiers ordinaires sont enregistrés sans confirmation, tandis que les programmes et les installeurs attendent toujours votre accord. Pour qu’une session du poste de bureau confie du travail à une session du serveur, reliez-les sur la carte des agents. La session distante se réveille à l’arrivée d’un message, et un message urgent peut interrompre son tour en cours. Expérimental.

Questions

Antenna synchronise-t-il les réglages ou l’historique de Claude Code entre ordinateurs ?

Non. Claude Code garde ses réglages, son historique et sa connexion sur chaque ordinateur, et votre code circule comme avant, avec git. Antenna transporte les messages, les fichiers et les approbations entre les sessions.

Faut-il une IP publique ou des ports ouverts sur le serveur ?

Non. Chaque ordinateur établit des connexions sortantes, directes quand le réseau le permet et via un relais sinon, et le relais ne transmet que du trafic chiffré.

Puis-je modifier un réglage d’un autre ordinateur depuis ici ?

Non. Seuls les approbations, les arrêts et les demandes de connexion de la carte des agents, que l’ordinateur concerné vous demande d’approuver, circulent entre vos ordinateurs. La confiance, les invitations, les mises à jour et les réglages se modifient sur l’ordinateur lui-même : un portable volé ne peut donc pas réécrire les règles du serveur.

Est-ce que ça fonctionne sous Windows ou sur un téléphone ?

Pas encore. Antenna fonctionne aujourd’hui sous macOS et Linux.

Antenna est gratuit et open source, pour macOS et Linux. Sans compte, sans numéro de téléphone.
