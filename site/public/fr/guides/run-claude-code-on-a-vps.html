Faire tourner Claude Code sur un VPS jour et nuit, et lui parler depuis votre portable

Installez Claude Code et le nœud Antenna sur votre VPS Linux, associez une fois le serveur à votre portable, puis lancez Claude Code via Antenna dans le dossier de votre projet. Il tourne alors dans sa propre session tmux après votre déconnexion, se réveille quand un message lui est destiné et répond dans une conversation sur votre portable. Aucun port entrant à ouvrir, aucune session SSH à maintenir, et Codex fonctionne de la même manière.

Ce qu’il vous faut

  • Un serveur Linux en x86_64, avec Claude Code (ou Codex) installé et connecté, et tmux.
  • Antenna sur votre portable : macOS ou Linux.

1. Installer le nœud Antenna sur le serveur

curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER

L’installeur lit la dernière version dans le manifeste signé, vérifie l’archive, installe antennad et antenna dans ~/.local/bin en tant que service utilisateur systemd (sans root) et crée votre nœud avec un mot de passe. La deuxième ligne maintient le service actif après votre déconnexion. Sous Ubuntu ou Fedora, vous pouvez installer à la place le paquet .deb ou .rpm.

2. L’associer à votre portable

Sur votre portable : New contact → Invite, donnez-lui un nom, cochez This is my own computer (∞), cliquez sur Create link et copiez le lien. Sur le serveur :

antenna join '<link>' --trust 5 --label mac

Gardez les guillemets simples : le lien contient un #. Saisissez dans le terminal du serveur le code affiché par votre portable, puis cliquez sur The contact confirmed — codes match sur le portable. Le niveau 5 correspond à ∞ des deux côtés : le serveur compte donc comme votre propre ordinateur.

3. Lancer Claude Code via Antenna

cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev

La commande connect donne à la session son propre agent et son propre jeton, et envoie un bonjour pour qu’une conversation nommée api-dev apparaisse sur votre portable. La commande start lance Claude Code dans le serveur tmux propre à Antenna (votre tmux n’est pas touché). Attachez-vous une fois pour répondre aux premières questions de Claude Code, par exemple s’il fait confiance au dossier, puis détachez-vous avec Ctrl-b d : il continue de tourner. Pour Codex, utilisez antenna connect codex et --cli codex.

4. Lui parler

Écrivez dans la conversation api-dev sur votre portable : « Lance les tests de migration et corrige ce qui échoue. » Quand Claude Code attend, inactif, devant son invite, Antenna tape une courte ligne pour qu’il lise votre message ; il ne tape jamais le texte d’un contact et ne répond jamais à une question à sa place. La fiche du serveur dans My devices affiche son état de santé et ses agents, et vous pouvez approuver ses demandes depuis le portable.

Après un redémarrage

Les clés du nœud sont verrouillées après un redémarrage du serveur : le service tourne, mais ses liaisons restent muettes jusqu’à ce que vous vous connectiez et lanciez antenna unlock. Ainsi, une copie du disque du serveur ne livre vos clés à personne. antenna status indique s’il est verrouillé.

Questions

Pourquoi ne pas simplement utiliser SSH et tmux ?

Cela fonctionne tant que vous êtes devant un terminal. Antenna ajoute une conversation à laquelle vous pouvez écrire à tout moment depuis votre portable, réveille la session quand vous le faites, et permet à d’autres agents de lui confier du travail, avec des permissions qu’il vérifie lui-même.

Le serveur a-t-il besoin d’une IP publique ou de ports ouverts ?

Non. Les deux côtés établissent des connexions sortantes, directes quand le réseau le permet et via un relais sinon. Le relais ne transmet que du trafic chiffré.

Puis-je faire tourner plusieurs sessions sur un même serveur ?

Oui : un agent par dossier de projet, chacun avec son propre nom et sa propre conversation sur votre portable.

Existe-t-il une version ARM ?

Pas encore. Le nœud serveur est compilé pour Linux x86_64.

Antenna est gratuit et open source, pour macOS et Linux. Sans compte, sans numéro de téléphone.
