Benachrichtigt werden, wenn Claude Code auf einem Server oder anderen Computer fertig ist

Geben Sie Claude Code seine Aufgabe in einem Antenna-Chat von Ihrem Laptop aus, und wenn es fertig ist, schickt es das Ergebnis in diesen Chat zurück: Antennas Anweisungen sagen einem verbundenen Agenten, seine Ergebnisse an den Kontakt zurückzuschicken, der ihm die Aufgabe gegeben hat. Ihr Laptop zeigt dann eine Benachrichtigung, „Neue Nachricht in server · api-dev“, solange das Antenna-Fenster nicht im Vordergrund ist. Auch Freigabeanfragen lösen eine Benachrichtigung aus, damit ein Lauf, der auf halbem Weg stehen bleibt, nicht unbemerkt wartet. Antenna beobachtet die Durchgänge von Claude Code nicht selbst: Der Bericht ist eine Nachricht von Claude Code.

Wann Sie benachrichtigt werden

  • Eine Nachricht von Claude Code an Sie. Die Benachrichtigung nennt den Chat, nie den Text, höchstens einmal alle 10 Sekunden pro Chat.
  • Eine Freigabeanfrage. Ein Schritt, der Ihr Okay braucht, erscheint als „Antenna: Freigabe auf server nötig“, mit dem Agenten, dem, was er tun will, und der verbleibenden Zeit („läuft ab in 9 Min.“), aber nie mit dem Text der Anfrage. Eine zweite Benachrichtigung kommt etwa zwei Minuten, bevor die Anfrage sich schließt; sie schließt sich nach 10 Minuten. Anfragen von einem anderen Computer erreichen Sie über Meine Geräte (experimentell).
  • Eine Frage. Experimentell. Die Frage eines Agenten meldet sich auf dem Computer, auf dem er läuft: „Eine Frage Ihres Agenten“. Führen Sie auf einem Server dort antenna agent escalate api-dev --to mac aus, dann kommen seine Fragen stattdessen im Chat des Agenten auf Ihrem Laptop an.

Benachrichtigungen funktionieren unter macOS und auf Linux-Desktops, die Benachrichtigungen anzeigen. Antenna muss auf dem Laptop geöffnet sein; ist sein Fenster im Vordergrund, übernehmen die Ungelesen-Zähler in der Chatliste diese Aufgabe.

Einrichten

  1. Installieren Sie Antenna auf beiden Computern und koppeln Sie sie einmal mit gesetztem Häkchen bei Das ist mein eigener Computer (∞). Claude Code auf einem VPS beschreibt die Serverseite Schritt für Schritt.
  2. Starten Sie Claude Code über Antenna. Auf einem Server: 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    Auf einem zweiten Desktop: Agenten → KI-Apps → Im Code-Modus starten.
  3. Auf dem Laptop ist nichts einzustellen. Ein Chat mit einem Agenten meldet von Anfang an Nachrichten, die sich direkt an Sie richten, und Freigabeanfragen.

Den Bericht anfordern

Schreiben Sie die Aufgabe in den Chat api-dev und sagen Sie, was Sie zurückhaben wollen: „Führe die Migrationstests aus und behebe, was fehlschlägt. Wenn du fertig bist, antworte hier mit dem, was sich geändert hat.“ Wartet Claude Code untätig an seiner Eingabezeile, tippt Antenna eine Zeile, damit es Ihre Nachricht liest (experimentell); es arbeitet, antwortet dann im selben Chat, und Ihr Laptop zeigt die Benachrichtigung.

Bei Arbeit, die Sie in seinem Terminal starten (antenna session attach api-dev), beenden Sie den Prompt mit „schick mir eine Zusammenfassung über Antenna, wenn du fertig bist“. Damit es zur Gewohnheit wird, ergänzen Sie in der CLAUDE.md des Projekts eine Zeile: „Wenn du eine Aufgabe abgeschlossen hast, schick eine kurze Zusammenfassung an mac mit Antennas send_message.“

Der Bericht kommt, wenn Claude Code entscheidet, dass es fertig ist, wie bei jeder Anweisung, die es befolgt. Bleibt es an seiner eigenen Berechtigungsabfrage im Terminal stehen („Do you want to proceed?“), sieht Antenna das nicht, und keine Benachrichtigung erreicht Sie: Erlauben Sie die Tools, die Sie regelmäßig nutzen, in den Einstellungen von Claude Code.

Festlegen, welche Chats benachrichtigen

Öffnen Sie ⋮ in der Zeile eines Chats oder klicken Sie sie mit der rechten Maustaste an, dann Benachrichtigungen:

  • Alle Nachrichten: jede neue Nachricht in diesem Chat (Standard bei einer Person).
  • Nur wenn ich gefragt bin: Nachrichten direkt an Sie und Freigabeanfragen (Standard bei einem Agenten).
  • Aus: Freigabeanfragen melden sich trotzdem.

Berichtet Claude Code an einen Ihrer anderen Agenten statt an Sie, bleiben diese Nachrichten stumm, es sei denn, Sie schalten im selben Menü Bei Nachrichten zwischen Agenten benachrichtigen ein. Im Terminal: antenna chats notify server --agent api-dev all.

Auf dem Computer, an dem Sie sitzen

Läuft Claude Code im Code-Modus auf Ihrem eigenen Laptop, meldet Antenna seine Freigabeanfragen und Fragen, solange das Fenster im Hintergrund ist, aber nicht das Ende eines Durchgangs: Ein Agent kann Ihnen auf seinem eigenen Computer keine Nachricht schicken. Dafür können die Hooks von Claude Code selbst einen Befehl Ihrer Wahl ausführen, wenn es anhält.

Fragen

Zeigt die Benachrichtigung, was Claude Code geschrieben hat?

Nein. Sie zeigt nur „Neue Nachricht in“ und den Namen des Chats, weil eine Benachrichtigung auch auf einem gesperrten Bildschirm erscheinen kann. Öffnen Sie den Chat, um den Bericht zu lesen.

Was, wenn mein Laptop im Ruhezustand ist?

Die Nachricht wartet auf dem Server, und Antenna stellt sie samt Benachrichtigung zu, sobald der Laptop wieder online ist.

Bekomme ich die Benachrichtigung auch aufs Handy?

Noch nicht. Antenna läuft derzeit unter macOS und Linux.

Antenna ist kostenlos und Open Source, für macOS und Linux. Ohne Konto, ohne Telefonnummer.
