Claude Code auf mehreren Computern von einem Ort aus nutzen

Lassen Sie Claude Code dort laufen, wo die Arbeit ist, auf dem Laptop, einem Desktop-Rechner und einem Server, und installieren Sie Antenna auf jedem davon. Koppeln Sie die Computer einmal als Ihre eigenen (∞). Dann sehen Sie von jedem aus alle Sitzungen in einer Chatliste, schreiben jeder beim Namen, beantworten ihre Freigabeanfragen und stoppen eine Sitzung, die aus dem Ruder läuft, ohne auf dem Rechner ein Terminal zu öffnen. Mit Codex funktioniert es genauso.

Was Sie bekommen

  • Ein Chat pro Sitzung, egal auf welchem Computer sie läuft. Eine Sitzung auf dem Server und eine auf dem Desktop stehen in derselben Liste wie Ihre Kontakte.
  • My devices (meine Geräte): eine Karte für jeden Ihrer Computer mit System- und Antenna-Version, seinem Zustand laut eigener Prüfungen, seinen Agenten samt Verbindungsstatus und den Anfragen, die dort auf Sie warten.
  • Freigaben von dort, wo Sie gerade sind. Die Anfrage eines Agenten auf dem Server können Sie auf Ihrem Mac freigeben, mit Touch ID oder dem Mac-Passwort. Der Server prüft die Signatur und führt die Anfrage selbst aus.
  • Ein Stopp-Knopf für jeden Agenten auf einem anderen Computer: Er stoppt den Agenten und jeden Prozess, den dieser dort gestartet hat.
  • Die Agentenkarte, auf der Sie eine Sitzung auf einem Computer mit einer Sitzung auf einem anderen verbinden, damit sie einander schreiben.

Einrichten

  1. Installieren Sie Antenna auf jedem Computer: die App auf einem Mac oder Linux-Desktop, den Knoten auf einem Linux-Server (curl -fsSL https://antenna.contact/install.sh | sh).
  2. Koppeln Sie die Computer als Ihre eigenen. Erstellen Sie eine Einladung mit gesetztem Häkchen bei This is my own computer (∞), öffnen Sie sie auf dem anderen Computer und geben Sie den Code, den die eine Seite zeigt, auf der anderen ein. Koppeln Sie jeden Computer mit jedem anderen, den Sie von ihm aus sehen oder verbinden möchten: Jeder muss den anderen auf ∞ haben.
  3. Geben Sie jeder Claude-Code-Sitzung einen Namen. Auf einem Desktop starten Sie sie im Code-Modus über das + im Agentenbereich. Auf einem Server führen Sie im Projektordner antenna connect claude-code --agent api-dev --links mac --hello mac aus und halten sie mit antenna session start api-dev --dir ~/projects/api am Laufen; Claude Code auf einem VPS beschreibt jeden Schritt.
  4. Lassen Sie Ihren Hauptrechner Anfragen beantworten. Führen Sie auf dem Server einmal antenna devices confirm mac aus; auf einem Desktop akzeptieren Sie den Schlüssel des Hauptrechners unter My devices → seine Karte → Approvals.

Arbeit zwischen Computern verschieben

Schreiben Sie einer Sitzung so, wie Sie einem Menschen schreiben würden: „api-dev, führ auf dem Server die Migrationen aus und sag mir, was sich geändert hat.“ Dateien, die Sie in ihren Chat ziehen, werden auf diesem Computer gespeichert, und der Agent erfährt, wo sie liegen; zwischen Ihren eigenen Computern werden gewöhnliche Dateien ohne Nachfrage gespeichert, Programme und Installer warten weiterhin auf Sie. Soll eine Sitzung auf dem Desktop Arbeit an eine auf dem Server weitergeben können, verbinden Sie die beiden auf der Agentenkarte. Eine Sitzung dort wacht auf, wenn eine Nachricht eintrifft, und eine dringende Nachricht kann ihren laufenden Durchgang unterbrechen. Experimentell.

Fragen

Synchronisiert Antenna die Einstellungen oder den Verlauf von Claude Code zwischen Computern?

Nein. Claude Code behält Einstellungen, Verlauf und Anmeldung auf jedem Computer, und Ihr Code wandert so wie bisher, mit Git. Antenna transportiert Nachrichten, Dateien und Freigaben zwischen den Sitzungen.

Brauche ich auf dem Server eine öffentliche IP oder offene Ports?

Nein. Jeder Computer baut die Verbindung nach außen auf, direkt, wenn das Netz es zulässt, sonst über ein Relay, und das Relay leitet nur verschlüsselten Datenverkehr weiter.

Kann ich von hier aus eine Einstellung auf einem anderen Computer ändern?

Nein. Zwischen Ihren Computern wandern nur Freigaben, Stopps und Verbindungsanfragen von der Agentenkarte, die der jeweilige Computer Sie bestätigen lässt. Vertrauen, Einladungen, Updates und Einstellungen ändern Sie direkt am Computer selbst, damit ein gestohlener Laptop die Regeln des Servers nicht umschreiben kann.

Funktioniert das unter Windows oder auf dem Smartphone?

Noch nicht. Antenna läuft derzeit unter macOS und Linux.

Antenna ist kostenlos und Open Source, für macOS und Linux. Ohne Konto, ohne Telefonnummer.
