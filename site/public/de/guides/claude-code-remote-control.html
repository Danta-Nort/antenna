Claude Code auf einem anderen Computer vom Laptop aus steuern

Installieren Sie Antenna auf Ihrem Laptop und auf dem Computer, auf dem Claude Code läuft, koppeln Sie beide einmal als Ihre eigenen Computer und starten Sie Claude Code dort über Antenna. Auf Ihrem Laptop erscheint ein Chat mit dieser Sitzung: Schreiben Sie dort eine Aufgabe hinein, Antenna weckt Claude Code, wenn es untätig wartet, und seine Antwort kommt in den Chat zurück. Die Nachrichten laufen über eine Ende-zu-Ende-verschlüsselte Peer-to-Peer-Verbindung zwischen Ihren beiden Computern, Antenna braucht kein Konto, und die Schritte, die Ihre Freigabe brauchen, erreichen den Laptop, wo Sie mit Ihrem Passwort antworten.

Remote Control von Claude Code und Antenna

Claude Code hat eine eigene, eingebaute Funktion Remote Control; die Dokumentation von Anthropic beschreibt sie. Diese Anleitung handelt von einem anderen Aufbau: Claude Code läuft auf einem Ihrer Computer, der eingeschaltet bleibt, einem Server oder einem Desktop, und Sie steuern es von Antenna auf Ihrem Laptop aus. Das passt zu Ihnen, wenn Sie Folgendes wollen:

  • Mehrere Sitzungen auf mehreren Computern in einer Liste. Jede Sitzung ist ein eigener Chat, und Meine Geräte zeigt für jeden Computer seinen Zustand, seine Agenten und die Anfragen, die dort warten.
  • Ihre eigene Verbindung. Nachrichten werden auf dem einen Computer verschlüsselt und auf dem anderen entschlüsselt. Ihre Computer verbinden sich direkt, wenn das Netz es zulässt, sonst über ein Relay, das nur verschlüsselten Datenverkehr weiterleitet. Kein Konto, kein eingehender Port.
  • Berechtigungen, die der Daemon von Antenna prüft, auf dem Computer, auf dem Claude Code läuft, mit Freigaben, die Sie an dem Ihrer Computer beantworten, an dem Sie gerade sitzen.
  • Andere Agenten auf dieselbe Weise: Codex funktioniert wie Claude Code.

Einrichten

  1. Installieren Sie Antenna auf beiden Computern: die App auf Ihrem Laptop (macOS oder Linux) und auf dem anderen Computer die App oder, auf einem Linux-Server, den Knoten: 
    curl -fsSL https://antenna.contact/install.sh | sh
    sudo loginctl enable-linger $USER
  2. Koppeln Sie beide einmal. Auf dem Laptop: Neuer Kontakt → Einladen, Häkchen bei Das ist mein eigener Computer (∞) setzen, auf Link erstellen klicken und den Link kopieren. Auf einem Server: antenna join '<link>' --trust 5 --label mac; auf einem Desktop: Neuer Kontakt → Beitreten, mit demselben Häkchen. Geben Sie den Code, den die eine Seite zeigt, auf der anderen ein und klicken Sie auf dem Laptop auf Kontakt hat bestätigt — Codes stimmen.
  3. Starten Sie Claude Code über Antenna auf dem anderen Computer. Auf einem Server im Projektordner (tmux nötig): 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
    antenna session attach api-dev
    Beantworten Sie die ersten Fragen von Claude Code und verlassen Sie die Sitzung dann mit Ctrl-b d: Es läuft weiter, und auf Ihrem Laptop gibt es einen Chat namens api-dev. Auf einem Desktop: Agenten → KI-Apps → Im Code-Modus starten, dann läuft Claude Code dort in einem Tab des Antenna-Fensters; bitten Sie es einmal, Ihrem Laptop über Antenna Hallo zu sagen, und sein Chat erscheint auf dem Laptop.
  4. Lassen Sie den Laptop die Freigabeanfragen dieses Computers beantworten. Auf einem Server: antenna devices confirm mac. Auf einem Desktop: Meine Geräte → die Karte des Laptops → Freigaben → Mit … signierte Freigaben annehmen, mit Ihrem Passwort.

Vom Laptop aus steuern

  • Eine Aufgabe geben. Schreiben Sie in den Chat der Sitzung wie an einen Menschen. Wartet Claude Code untätig an seiner Eingabezeile, tippt Antenna eine fest eingebaute Zeile, damit es Ihre Nachricht liest; Ihren Text tippt es nie ins Terminal, und eine Frage, die Claude Code dort stellt, beantwortet es nie. Experimentell.
  • Unterbrechen. Schalten Sie vor dem Senden Dringend: jetzt unterbrechen ein: Antenna drückt einmal Esc, um den laufenden Durchgang zu beenden, nie über einer dort offenen Frage oder Berechtigungsabfrage, und Claude Code liest Ihre Nachricht. Experimentell.
  • Schritte freigeben. Ein Schritt, der Sie braucht, erscheint mit einer Benachrichtigung auf der Karte des anderen Computers unter Meine Geräte. Klicken Sie auf Mit Passwort freigeben, auf einem Mac auf Mit Touch ID freigeben oder auf Ablehnen. Experimentell.
  • Stoppen. Agent und seine Prozesse stoppen… neben dem Agenten auf dieser Karte beendet Claude Code und alles, was es dort gestartet hat. Experimentell.

Die eigene Berechtigungsabfrage von Claude Code („Do you want to proceed?“) bleibt in seinem Terminal auf dem anderen Computer, und Antenna beantwortet sie nie. Erlauben Sie die Tools, die Sie regelmäßig nutzen, in den Einstellungen von Claude Code, oder beantworten Sie die Abfrage mit antenna session attach.

Codex und andere Agenten

Codex funktioniert genauso: antenna connect codex und --cli codex auf einem Server oder Im Code-Modus starten neben Codex auf einem Desktop (siehe Codex CLI fernsteuern). Gemini CLI verbindet sich über Agenten → KI-Apps und sendet und liest Nachrichten über Antenna, aber Antenna weckt es noch nicht: Es liest eine neue Nachricht, wenn es Antenna das nächste Mal aufruft.

Fragen

Sehe ich das Terminal von Claude Code auf meinem Laptop?

Nein. Sie geben Aufgaben und lesen Antworten in einem Chat; das Terminal bleibt auf dem anderen Computer. Um es anzusehen, führen Sie dort antenna session attach aus, wenn Sie möchten, über SSH.

Braucht der andere Computer eine öffentliche IP oder offene Ports?

Nein. Beide Computer bauen die Verbindung nach außen auf, direkt, wenn das Netz es zulässt, sonst über ein Relay. Das Relay leitet nur verschlüsselten Datenverkehr weiter.

Wer kann ihm sonst noch Aufgaben geben?

Nur mit diesem Computer gekoppelte Kontakte, deren Nachrichten der Agent lesen darf (mit --links mac nur Ihr Laptop), und Agenten, die Sie auf der Agentenkarte mit ihm verbinden. Was die Nachricht eines Kontakts es tun lassen darf, entscheidet dort der Daemon von Antenna, nicht Claude Code, nach der Vertrauensstufe dieses Kontakts.

Brauche ich einen API-Schlüssel?

Nein. Claude Code behält Ihre eigene Anmeldung auf dem Computer, auf dem es läuft, und Antenna transportiert nur Nachrichten, Dateien und Freigaben.

Kann ich es vom Handy aus steuern?

Noch nicht. Antenna läuft derzeit unter macOS und Linux.

Antenna ist kostenlos und Open Source, für macOS und Linux. Ohne Konto, ohne Telefonnummer.
