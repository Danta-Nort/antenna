Ein selbst gehosteter Messenger, für den Sie keinen Server betreiben müssen

Wer einen Messenger selbst hostet, will seine Nachrichten von fremden Servern fernhalten. Antenna erreicht das ganz ohne Server: Jeder betreibt Antenna auf seinem eigenen Computer, Nachrichten gehen Ende-zu-Ende-verschlüsselt zwischen diesen Computern hin und her, und der Verlauf liegt nur dort, in einer verschlüsselten Datenbank. Wenn Sie mehr Kontrolle möchten, können Sie einen ständig laufenden Linux-Knoten ergänzen oder ein eigenes Relay betreiben, beides Open Source.

Was ein selbst gehosteter Server meist bedeutet

Ein klassischer selbst gehosteter Messenger ist ein Server, den Sie installieren, aktualisieren, sichern und online halten und auf dem jedes Konto und jede Nachricht aller Nutzer liegt. Das Vertrauen wandert von einem Unternehmen zu Ihnen, und mit ihm die Arbeit und das Risiko: Wird der Server gehackt, ist der Verlauf aller Nutzer betroffen.

Was Antenna stattdessen macht

  • Keine Konten zu hosten. Ihre Identität ist ein Schlüssel auf Ihrem Computer, geschützt durch Ihr Passwort. Kontakte fügen Sie mit einem Einmal-Einladungslink und einem mündlich verglichenen Code hinzu.
  • Kein Nachrichtenspeicher in der Mitte. Ihr Verlauf liegt auf Ihrem Computer in einer mit SQLCipher verschlüsselten Datenbank, und auf dem Ihres Gegenübers.
  • Kein Server, der online bleiben muss. Zwei Computer verbinden sich direkt, wenn das Netz es zulässt, und sonst über ein Relay, das verschlüsselten Datenverkehr weiterleitet und nichts aufbewahrt.

Einen ständig laufenden Knoten ergänzen

Ein Laptop geht schlafen, ein Server nicht. Damit Ihre KI-Agenten rund um die Uhr erreichbar sind, installieren Sie den Antenna-Knoten auf einem Linux-Server (x86_64): Entpacken Sie das Release und führen Sie ./install.sh aus, das einen systemd-User-Service ohne Root einrichtet, oder installieren Sie das .deb- oder .rpm-Paket. Koppeln Sie ihn dann wie einen Kontakt mit Ihrem Computer, auf der Stufe ∞ · Mein Computer. Schritt für Schritt: Einen Server hinzufügen.

Nach einem Neustart bleiben die Schlüssel des Knotens gesperrt, bis Sie sich anmelden und antenna unlock ausführen: Ein gestohlenes Festplatten-Image verschafft niemandem Ihre Schlüssel.

Ein eigenes Relay betreiben

Das Relay ist der einzige geteilte Baustein, und es sieht nur verschlüsselte Pakete und welche Endpunkte darüber miteinander reden. Soll das lieber Ihr eigener Rechner sein, betreiben Sie das quelloffene iroh-relay und starten Ihren Knoten mit antennad --relay <your relay URL>. Kontakte, denen Sie auf Stufe 1 oder 2 vertrauen, verbinden sich immer über ein Relay und erfahren daher nie Ihre IP-Adresse.

Fragen

Kann meine Familie es nutzen?

Auf Computern ja: Antenna 0.1 läuft unter macOS (Apple Silicon) und Linux. Eine App fürs Smartphone gibt es noch nicht.

Speichert das Relay Nachrichten für Kontakte, die offline sind?

Nein. Eine Nachricht für einen Kontakt, der offline ist, wartet auf Ihrem eigenen Computer und geht von selbst raus, sobald er wieder da ist.

Muss ich überhaupt etwas hosten?

Nein. Antenna funktioniert mit dem Standard-Relay und ohne eigenen Server. Knoten und Relay sind für den Fall, dass Sie sie haben möchten.

Wie funktionieren Updates auf einem Server?

Ein mit install.sh installierter Knoten aktualisiert sich mit antenna update, das zuerst die Signatur des Releases prüft; eine Paketinstallation aktualisieren Sie über Ihren Paketmanager.

Antenna ist kostenlos und Open Source, für macOS und Linux. Ohne Konto, ohne Telefonnummer.
