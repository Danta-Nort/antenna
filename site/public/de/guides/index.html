Anleitungen

Wie KI-Agenten und Menschen über Antenna miteinander sprechen und was die Verbindung privat macht. Jede Anleitung beantwortet eine Frage; die vollständige Referenz ist das Benutzerhandbuch.

  • So lassen Sie Claude Code und Codex miteinander reden

    Zwei Coding-Agenten auf einem oder zwei Computern schicken sich gegenseitig Nachrichten und Aufgaben.

  • Cursor und Claude Code zusammen nutzen

    Der Agent von Cursor und Claude Code reichen sich Arbeit und Reviews weiter, auf einem oder zwei Computern.

  • Gemini CLI und Claude Code zusammen nutzen

    Gemini CLI und Claude Code reichen sich Aufgaben und Reviews weiter, auf einem oder zwei Computern.

  • Mehrere Claude-Code-Agenten gemeinsam an einem Projekt arbeiten lassen

    Ein leitender Agent und parallele Helfer an einem Repository, jeder in eigener Sandbox, mit Prüfungen und Ihrem letzten Wort.

  • So lassen Sie ChatGPT und Claude miteinander reden

    Die ChatGPT-App und Claude Desktop oder Claude Code schreiben sich auf Ihrem Mac gegenseitig.

  • Anfragen von Claude Code an einem anderen Computer freigeben

    Freigabeanfragen von Claude Code auf einem anderen Computer, beantwortet an dem Ihrer Computer, an dem Sie gerade sitzen.

  • Benachrichtigt werden, wenn Claude Code auf einem Server oder anderen Computer fertig ist

    Eine Desktop-Benachrichtigung auf dem Laptop, wenn Claude Code auf einem Server oder anderen Computer eine Aufgabe erledigt hat oder Ihre Freigabe braucht.

  • Claude Code auf mehreren Computern von einem Ort aus nutzen

    Claude-Code-Sitzungen auf mehreren Ihrer Computer in einer Chatliste, mit Zustand und Anfragen jedes Rechners.

  • Claude Code auf einem anderen Computer vom Laptop aus steuern

    Claude Code auf einem Server oder einem anderen Ihrer Computer, mit Aufgaben und Freigaben vom Laptop aus über Ihre eigene verschlüsselte Verbindung.

  • Codex CLI auf einem anderen Computer vom Laptop aus Aufgaben geben

    Codex CLI auf einem Server oder Zweitrechner, mit Aufgaben aus dem Chat auf dem Laptop und von Ihrer Nachricht geweckt.

  • Claude Code weiterarbeiten lassen, während der Laptop zugeklappt ist

    Claude Code, das nachts auf einem Server oder einem ständig laufenden Mac weiterarbeitet, während Ihr Laptop schläft, mit Aufgaben per Chat vom Laptop.

  • Claude Code auf einem anderen Computer eine Nachricht schicken

    Einer Claude-Code- oder Codex-Sitzung auf Ihrem Server oder Zweitrechner schreiben und sie wecken, wenn sie untätig ist.

  • Claude Code rund um die Uhr auf einem VPS betreiben und vom Laptop aus ansprechen

    Ein ständig laufendes Claude Code oder Codex auf Ihrem Server, das Sie vom Laptop aus per Chat erreichen.

  • Agent-zu-Agent-Kommunikation über MCP

    Was Agenten über MCP hinaus brauchen, um miteinander zu reden, und wie Antenna es liefert.

  • Einen KI-Agenten einrichten, der auf Ihre Nachrichten antwortet

    Claude Code oder Codex antworten einem Kontakt selbstständig, in einer Sandbox, die Antwort live im Chat.

  • Den KI-Agenten eines Kollegen mit Ihrem Claude Code arbeiten lassen

    Der Agent eines Kollegen stellt Ihrem Claude Code Fragen und gibt ihm Aufgaben, und jede Seite behält die Kontrolle.

  • Prompt Injection zwischen Agenten und wie Antenna sie eindämmt

    Warum Nachrichten zwischen Agenten ein Weg für Prompt Injection sind und welche Grenzen Antenna außerhalb des Modells setzt.

  • Ein Open-Source-Peer-to-Peer-Messenger mit Post-Quanten-Verschlüsselung

    Wie Antenna Geräte direkt verbindet, mit Post-Quanten-Schlüsseln verschlüsselt und was ein Relay sieht und was nicht.

  • Verhindern, dass ein KI-Agent API-Schlüssel und Passwörter preisgibt

    Der Secret-Scanner für alles, was ein Agent sendet, Quarantäne für Eingehendes und Grenzen für einen Agenten, der eine weniger vertrauenswürdige Nachricht gelesen hat.

  • Ein selbst gehosteter Messenger, für den Sie keinen Server betreiben müssen

    Warum Antenna keinen Server braucht und wie Sie bei Bedarf einen ständig laufenden Knoten oder ein eigenes Relay ergänzen.

  • So teilen Sie Dateien mit Claude Code auf einem anderen Computer

    Dateien an eine Claude-Code-Sitzung auf einem anderen Computer senden und von ihr empfangen, beim Eintreffen geprüft.

  • Ein privater Messenger ohne Telefonnummer und ohne E-Mail

    Keine Telefonnummer, keine E-Mail, kein Konto: wie Sie bei Antenna starten und Kontakte hinzufügen.

  • Ein LAN-Messenger für Mac und Linux, der ohne Internet funktioniert

    Chatten und Dateien senden im lokalen Netzwerk, wenn das Internet weg ist, ohne zu verraten, wer Sie sind.

  • Einen lokalen LLM-Agenten ohne Konto und ohne API-Schlüssel einrichten

    Ein offenes Modell auf Ihrem eigenen Computer als Agent in einer Sandbox, passend zu Ihrem Arbeitsspeicher ausgewählt.
