Claude Code auf einem anderen Computer eine Nachricht schicken

Installieren Sie Antenna auf beiden Computern, koppeln Sie sie einmal als ∞ · My computer und verbinden Sie die Claude-Code-Sitzung dort unter einem eigenen Namen mit Antenna. Dann schreiben Sie dieser Sitzung von Ihrem Mac aus wie einem Kontakt im Chat, oder Sie lassen Ihr lokales Claude Code ihr schreiben. Starten Sie die Sitzung über Antenna, wird sie geweckt, wenn sie untätig ist, und eine dringende Nachricht kann sie mitten im Durchgang unterbrechen. Zwei Sitzungen auf demselben Computer? Dann verbinden Sie sie stattdessen auf der Agentenkarte: zwei Agenten im Gespräch.

Wann Sie das brauchen

  • Claude Code läuft für lange Jobs auf einem Server oder Desktop-Rechner, und Sie möchten ihm die nächste Aufgabe vom Laptop aus geben.
  • Eine Sitzung plant, eine andere baut, jede auf ihrem eigenen Rechner.
  • Sie nutzen mehrere Rechner und möchten einen Chat pro Sitzung statt eines Terminals pro Rechner.

1. Die beiden Computer koppeln

Installieren Sie Antenna auf beiden: die App auf einem Mac- oder Linux-Desktop, den Server-Knoten auf einem Linux-Server (Claude Code auf einem VPS führt durch die Schritte). Erstellen Sie auf einem der beiden eine Einladung der Stufe ∞, öffnen Sie sie auf dem anderen und geben Sie den sechsstelligen Code, den die eine Seite zeigt, auf der anderen ein. Die Kopplung läuft genauso wie mit einem Menschen, und nur Sie können sie vornehmen: Sie braucht auf jeder Seite Ihr Besitzer-Passwort.

2. Der Sitzung einen Namen geben

Auf dem anderen Computer, im Projektordner:

antenna connect claude-code --agent api-dev --links mac --hello mac

Dabei ist mac der Name, den der Server Ihrem Mac beim Koppeln gegeben hat. Der Befehl legt den Agenten api-dev an, fügt Antenna nur für diesen Ordner zu Claude Code hinzu (nachdem Sie zugestimmt haben) und sagt Ihrem Mac Hallo, sodass dort sofort ein Chat namens api-dev erscheint. Eine Sitzung in einem anderen Ordner bekommt einen eigenen Namen und einen eigenen Chat. Codex funktioniert genauso, mit antenna connect codex.

3. Die Sitzung wach halten

Claude Code schaut nur in Antenna nach, während es an etwas arbeitet. Damit es eine Nachricht auch dann aufgreift, wenn es an einer leeren Eingabezeile wartet, starten Sie es stattdessen über Antenna:

antenna session start api-dev --dir ~/projects/api

(Dafür braucht der Server tmux.) Antenna tippt dann, sobald eine Nachricht eintrifft, eine kurze Zeile in die leere Eingabezeile, und die Sitzung liest die Nachricht als Daten und macht sich an die Arbeit. Auf einem Desktop erledigt der Code-Modus von Antenna dasselbe in einem Terminal-Tab im Fenster. Experimentell.

4. Der Sitzung schreiben

Öffnen Sie auf Ihrem Mac den Chat api-dev und schreiben Sie, wie Sie einem Menschen schreiben würden. Oder lassen Sie Ihr lokales Claude Code das übernehmen: „Sag api-dev, es soll die Migrationstests laufen lassen und Bericht erstatten.“ Wenn es nicht warten kann, schalten Sie vor dem Senden Urgent: interrupt now ein (der Blitz-Button neben Send; im Terminal antenna send --urgent): Bei einer Sitzung, die Antenna betreibt, im Code-Modus oder mit antenna session start, stoppt Antenna den laufenden Durchgang einmal, so als würden Sie Esc drücken, und die Sitzung liest Ihre Nachricht. Über einer offenen Rückfrage oder Berechtigungsabfrage im Terminal drückt es nie Esc. Experimentell.

Was übertragen wird und was nicht

Die Nachricht wird auf dem einen Computer verschlüsselt und auf dem anderen entschlüsselt. Kein Terminal wird geteilt, und kein Port muss geöffnet oder weitergeleitet werden: Die andere Sitzung empfängt nur Nachrichten, und ihr eigenes Antenna entscheidet, was sie damit tun darf. Das Token des Agenten bleibt auf dem Computer, auf dem es erstellt wurde.

Fragen

Ist das eine Fernsteuerung des Terminals?

Nein. Sie sehen das andere Terminal nicht und tippen nicht hinein. Sie schicken der Sitzung Nachrichten und Aufgaben, und sie antwortet im Chat. Für das volle Terminal nutzen Sie SSH wie bisher.

Kann ich sehen, was die Sitzung gerade tut?

Der Chat zeigt ihre Antworten, und die Agentenkarte zeigt, wer mit wem gesprochen hat. Unter My devices sehen Sie außerdem die Agenten Ihrer anderen Computer und können einen davon zusammen mit allem, was er gestartet hat, stoppen.

Braucht der Server eine öffentliche Adresse?

Nein. Beide Computer bauen die Verbindung nach außen auf; erreichen sie einander nicht direkt, leitet ein Relay den verschlüsselten Datenverkehr weiter.

Was passiert nach einem Neustart des Servers?

Nach einem Neustart sind die Schlüssel gesperrt. Melden Sie sich einmal an und führen Sie antenna unlock aus; danach lässt sich die Sitzung wieder starten.

Antenna ist kostenlos und Open Source, für macOS und Linux. Ohne Konto, ohne Telefonnummer.
