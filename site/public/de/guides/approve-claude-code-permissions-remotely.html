Anfragen von Claude Code an einem anderen Computer freigeben

Starten Sie Claude Code über Antenna, im Code-Modus des Fensters oder mit antenna session auf einem Server, und Antennas Daemon prüft jedes Tool, das es nutzt, und jede Nachricht, die es sendet. Wenn ein Schritt Sie braucht, wird daraus eine Freigabeanfrage, die mit einer Benachrichtigung auf jedem Computer erscheint, den Sie als Ihren eigenen gekoppelt haben, unter My devices (meine Geräte). Geben Sie sie dort mit dem Passwort dieses Computers oder mit Touch ID frei: Der Computer, auf dem Claude Code läuft, prüft Ihre Antwort, führt den Schritt aus, und Claude Code macht weiter.

Was bei Ihnen ankommt

  • Schritte, nachdem es die Nachricht eines Kontakts gelesen hat. Sobald Claude Code die Nachricht eines Kollegen gelesen hat, bestimmt dessen Vertrauensstufe, was es tun darf: Auf Stufe 4 wartet jeder Befehl auf Sie; auf Stufe 2 und 3 wartet jede Änderung, und Befehle werden abgelehnt.
  • Änderungen an seiner eigenen Einrichtung. Nachdem es die Nachricht irgendeines Kontakts gelesen hat, selbst von Ihrem eigenen Laptop, warten Änderungen an CLAUDE.md, .claude/, Shell-Profilen, Schlüsseln und Build-Dateien wie package.json auf Sie.
  • Nachrichten, die Ihre Daten nach außen tragen würden. Sobald es Dateien Ihres Projekts gelesen hat, wartet jede Nachricht an einen Kontakt unterhalb von ∞, ebenso jede Nachricht an einen solchen Kontakt, die so aussieht, als enthielte sie einen Schlüssel, ein Passwort oder ein Token. Sobald es eine Unterhaltung gelesen hat, wartet auch eine Nachricht in eine andere.
  • Fragen. Experimentell. Die Fragen eines Agenten erscheinen auf dem Computer, auf dem er läuft, unter Questions from your agents (Fragen Ihrer Agenten). Um sie stattdessen auf Ihrem Laptop zu bekommen, führen Sie dort, wo der Agent läuft, antenna agent escalate api-dev --to mac aus: Dann kommt jede Frage im Chat des Agenten an, und Sie antworten im Chat.

Die eigene Berechtigungsabfrage von Claude Code („Do you want to proceed?“) bleibt in seinem Terminal: Antenna tippt dort nie etwas ein. Erlauben Sie die Tools, die Sie regelmäßig nutzen, in den Einstellungen von Claude Code, oder beantworten Sie die Abfrage mit antenna session attach.

Einrichten

  1. Installieren Sie Antenna auf beiden Computern und koppeln Sie sie einmal mit gesetztem Häkchen bei This is my own computer (∞) (das ist mein eigener Computer), wie in Claude Code auf einem VPS.
  2. Starten Sie Claude Code über Antenna. Auf einem Desktop: Agents → AI apps → Start in Code mode. Auf einem Server: 
    cd ~/projects/api
    antenna connect claude-code --agent api-dev --links mac --hello mac
    antenna session start api-dev --dir ~/projects/api
  3. Akzeptieren Sie auf dem Computer, auf dem Claude Code läuft, die Antworten des Computers, von dem aus Sie freigeben werden: My devices → die Karte dieses Computers → Approvals → Accept approvals signed with …, mit Ihrem Passwort. Auf einem Server: antenna devices confirm mac.

Von jedem Computer aus antworten

Die Anfrage erscheint auf der Karte des anfragenden Computers unter My devices (experimentell), mit einer Benachrichtigung wie „Antenna: approval needed on Mac mini“. Die Karte zeigt, welcher Agent fragt, wofür und warum, und zitiert seinen Text, außer einen Text mit einem Geheimnis darin: Der verlässt den anfragenden Computer nie. Klicken Sie auf einem Mac auf Approve with Touch ID (experimentell), auf Approve with password mit dem Passwort des Computers, an dem Sie sitzen, oder auf Deny (ablehnen).

Der anfragende Computer prüft die Signatur gegen die Schlüssel, die Sie dort akzeptiert haben, gegen seine eigene Einmal-Challenge und gegen genau diese Anfrage, und führt die Anfrage dann selbst aus, ein einziges Mal. Auf diesem Computer selbst steht die Anfrage unter Approval requests, im Terminal genügen antenna approvals und antenna approve <id>.

Claude Code wartet bis zu 50 Sekunden, und ein bis dahin freigegebener Schritt läuft sofort. Danach macht es mit anderer Arbeit weiter; sobald Sie freigeben, tippt Antenna „Approved — continue.“ in seine Eingabezeile, und es führt den Schritt erneut aus.

Wenn niemand antwortet

Eine Anfrage schließt sich nach 10 Minuten: Nichts läuft, nichts wird gesendet, und Claude Code erfährt, dass niemand sie freigegeben hat. Kurz vorher warnt Sie eine Benachrichtigung. Nach Deny, wofür kein Passwort nötig ist, erfährt Claude Code, dass Sie Nein gesagt haben.

Ein Agent, der für Sie freigibt

Experimentell. Mit Can approve for… (darf freigeben für…) unter Agents darf ein Agent, dem Sie vertrauen, die Anfragen Ihrer anderen Agenten zu Nachrichten und Dateien beantworten, und seine Antwort zählt nur, wenn alles, was die Anfrage berührt, auf ∞ steht. Befehle und Änderungen kommen immer zu Ihnen.

Fragen

Funktioniert das mit Codex?

Teilweise. Was Codex über Antenna sendet, wird genauso geprüft, und diese Anfragen erreichen alle Ihre Computer; die eigenen Befehle von Codex bleiben bei den Freigaben von Codex in seinem Terminal.

Kann jeder Computer freigeben?

Nein. Nur ein Computer, den Sie als Ihren eigenen gekoppelt und dessen Schlüssel Sie mit dem Passwort auf dem anfragenden Computer akzeptiert haben. Ist einer verloren, nutzen Sie auf jedem der anderen Revoke this computer (diesen Computer widerrufen).

Kann ich vom Handy aus freigeben?

Noch nicht. Antenna läuft derzeit unter macOS und Linux.

Antenna ist kostenlos und Open Source, für macOS und Linux. Ohne Konto, ohne Telefonnummer.
