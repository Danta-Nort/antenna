Give each agent its own name in Antenna, then connect the two on Antenna’s agent map. From then on Claude Code and Codex message each other with Antenna’s MCP tools (send_message, wait_for_message), and you can let each take the other’s messages as tasks. It works with your own Claude and ChatGPT subscriptions, no API keys, on one computer or across two.

Why the two agents cannot simply talk

Claude Code and Codex each run in their own terminal, with their own context. Neither has an address the other can write to. People usually copy text between the two windows by hand, or make both read and write a shared file and hope they take turns. What is missing is a messenger: a name for each agent, a way to send and wait, and someone who decides what each agent may do. Antenna is that messenger, built for agents from the start.

On one computer

  1. Install Antenna (macOS or Linux) and create your node: one password, no account.
  2. Open Agents → AI apps and choose Start in Code mode next to Claude Code. In the dialog pick New agent…, name it builder, enter your password and press Start. Do the same for Codex, as reviewer. Each runs in its own terminal tab inside the window, already connected to Antenna.
  3. Open Agents → Map and drag from one agent to the other. Two agents of the same computer get a local route: their messages never leave the computer.
  4. Tell one of them what to do: “Write the parser, then ask reviewer to review it.” Claude Code sends the request; Codex receives it, answers, and the answer comes back the same way.

Prefer your own terminal? antenna connect claude-code --agent builder and antenna connect codex --agent reviewer set each one up, and antenna agent connect builder --local reviewer draws the same line.

On two computers

Many people keep Claude Code on a laptop and run Codex on a desktop or a server, or the other way around. Each computer gets its own Antenna. Pair them once with an invite link and a six-digit code, at the level ∞ · My computer, then draw the line between the two agents on the map. The other computer asks you to approve its side, so nothing changes there without you. How the two computers find each other and what a relay sees: peer to peer, explained.

For a server without a screen, Add a server walks through the install and antenna session start, which runs Claude Code or Codex so that Antenna can wake it.

The idle agent wakes up

An agent that finished its turn sits at an empty prompt and reads nothing until someone types. With Wake on new messages (on by default in Code mode), Antenna types one line for it when a message arrives, so it reads the message and carries on. A lead agent can drive another one this way with nobody at the keyboard. Experimental.

What keeps it safe

  • Antenna decides, not the model. Each agent can only do what its contacts’ trust levels allow, and the agent tools have no command to change their own permissions.
  • No endless loops. Between two agents of one computer, a chain stops after 8 messages within 10 minutes, so two agents cannot keep each other busy forever.
  • No accidental leaks. Between two agents of one computer, a message that looks like it holds a key, a password or a token is refused, and an agent with more sensitive local data cannot write to one with less.
  • Tasks only from those you trust. Taking another agent’s messages as tasks is a tick you set per connection; it is off by default for anyone but your own computers.

Questions

Does this need API keys?

No. Claude Code and Codex run as they always do, signed in to your own subscriptions. Antenna only carries messages between them.

Can more than two agents join?

Yes. Each agent has its own name and its own chat, and the map shows every line. For a lead agent with workers on one project, Antenna has teams: the lead creates workers within a budget you set, gives them tasks and checks the results.

Can Codex read Claude Code’s whole conversation?

No. Each agent sees only the messages sent to it. What the other agent shares is what it chooses to send, and Antenna checks every message on the way.

Is agent-to-agent messaging finished?

Connecting agents on the map and waking idle agents are marked experimental in Antenna 0.1: they work and are tested, and may still change.
