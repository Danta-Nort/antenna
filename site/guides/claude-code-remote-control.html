Install Antenna on your laptop and on the computer where Claude Code runs, pair the two once as your own computers, and start Claude Code there through Antenna. A chat with that session appears on your laptop: write a task in it, Antenna wakes Claude Code when it sits idle, and its reply comes back to the chat. Messages go over an end-to-end encrypted, peer-to-peer link between your two computers, Antenna needs no account, and the steps that need your approval reach the laptop, where you answer with your password.

Claude Code’s own Remote Control, and Antenna

Claude Code has a Remote Control feature of its own, built in; Anthropic’s documentation describes it. This guide is about a different setup: Claude Code runs on a computer of yours that stays on, a server or a desktop, and you drive it from Antenna on your laptop. It suits you if you want:

  • Several sessions on several computers in one list. Each session is its own chat, and My devices shows each computer’s health, its agents and the requests waiting there.
  • Your own link. Messages are encrypted on one computer and decrypted on the other. Your computers connect directly when the network allows, otherwise through a relay that forwards encrypted traffic only. No account, no inbound port.
  • Permissions checked by Antenna’s daemon on the computer where Claude Code runs, with approvals answered from whichever of your computers you are at.
  • Other agents the same way: Codex works like Claude Code.

Set it up

  1. Install Antenna on both computers: the app on your laptop (macOS or Linux), and on the other computer the app, or on a Linux server the node: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
  2. Pair them once. On the laptop: New contact → Invite, tick This is my own computer (∞), press Create link and copy it. On a server: antenna join '<link>' --trust 5 --label mac; on a desktop: New contact → Join, with the same box ticked. Enter the code one side shows into the other, and press The contact confirmed — codes match on the laptop.
  3. Start Claude Code through Antenna on the other computer. On a server, in the project folder (tmux needed): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Answer Claude Code’s first questions, then leave with Ctrl-b d: it keeps running, and a chat named api-dev is on your laptop. On a desktop: Agents → AI apps → Start in Code mode, and Claude Code runs in a tab of Antenna’s window there; ask it once to say hello to your laptop over Antenna, and its chat appears on the laptop.
  4. Let the laptop answer that computer’s approval requests. On a server: antenna devices confirm mac. On a desktop: My devices → the laptop’s card → Approvals → Accept approvals signed with …, with your password.

Drive it from your laptop

  • Give it a task. Write in the session’s chat as you would to a person. When Claude Code sits idle at its prompt, Antenna types one built-in line so it reads your message; it never types your text into the terminal and never answers a question Claude Code asks there. Experimental.
  • Interrupt it. Turn on Urgent: interrupt now before you send: Antenna presses Esc once to end the running turn, never over a question or a permission prompt open there, and Claude Code reads your message. Experimental.
  • Approve its steps. A step that needs you shows on the other computer’s card in My devices, with a notification. Press Approve with password, Approve with Touch ID on a Mac, or Deny. Experimental.
  • Stop it. Stop agent and its processes… next to the agent on that card ends Claude Code and everything it started there. Experimental.

Claude Code’s own permission prompt (“Do you want to proceed?”) stays in its terminal on the other computer, and Antenna never answers it. Allow the tools you use routinely in Claude Code’s settings, or answer it with antenna session attach.

Codex and other agents

Codex works the same way: antenna connect codex and --cli codex on a server, or Start in Code mode next to Codex on a desktop (see Codex CLI remote control). Gemini CLI connects from Agents → AI apps and sends and reads messages through Antenna, but Antenna does not wake it yet: it reads a new message when it next calls Antenna.

Questions

Do I see Claude Code’s terminal on my laptop?

No. You give tasks and read replies in a chat; the terminal stays on the other computer. To look at it, run antenna session attach there, over SSH if you like.

Does the other computer need a public IP or open ports?

No. Both computers connect out, directly when the network allows and through a relay otherwise. The relay forwards encrypted traffic only.

Who else can send it tasks?

Only contacts paired with that computer whose messages the agent may read (with --links mac, only your laptop), and agents you connect to it on the agent map. Antenna’s daemon there, not Claude Code, decides what a contact’s message may make it do, by that contact’s trust level.

Does it need an API key?

No. Claude Code keeps your own sign-in on the computer where it runs, and Antenna only carries messages, files and approvals.

Can I control it from my phone?

Not yet. Antenna runs on macOS and Linux today.
