Give Claude Code its task in an Antenna chat from your laptop, and it sends the result back to that chat when it is done: Antenna’s instructions tell a connected agent to send its results back to the contact that gave the task. Your laptop then shows a notification, “New message in server · api-dev”, while Antenna’s window is not in front. Approval requests notify too, so a run that stops halfway does not wait unnoticed. Antenna does not watch Claude Code’s turns itself: the report is Claude Code’s own message.

What notifies you

  • A message from Claude Code to you. The notification names the chat, never the text, at most once per chat every 10 seconds.
  • An approval request. A step that needs your word shows as “Antenna: approval needed on server”, with the agent, what it wants to do and the time left (“expires in 9 min”), but never the request’s text. A second notification comes about two minutes before the request closes; it closes after 10 minutes. Requests from another computer reach you through My devices (experimental).
  • A question. Experimental. An agent’s question notifies on the computer where it runs: “A question from your agent”. For a server, run antenna agent escalate api-dev --to mac there, and its questions arrive in the agent’s chat on your laptop instead.

Notifications work on macOS and on Linux desktops that show notifications. Antenna must be open on the laptop; with its window in front, the chat list’s unread counts do the job.

Set it up

  1. Install Antenna on both computers and pair them once with This is my own computer (∞) ticked. Claude Code on a VPS walks through the server side.
  2. Start Claude Code through Antenna. On a server: 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
    On a second desktop: Agents → AI apps → Start in Code mode.
  3. Nothing to set on the laptop. A chat with an agent notifies about messages to you in person and about approval requests from the start.

Ask for the report

Write the task in the api-dev chat and say what you want back: “Run the migration tests and fix what fails. When you are done, reply here with what changed.” If Claude Code sits idle at its prompt, Antenna types one line so it reads your message (experimental); it works, then replies in the same chat, and your laptop shows the notification.

For work you start in its terminal (antenna session attach api-dev), end the prompt with “send me a summary on Antenna when you finish”. To make it a habit, add a line to the project’s CLAUDE.md: “When you finish a task, send a short summary to mac with Antenna’s send_message.”

The report comes when Claude Code decides it is done, as with any instruction it follows. If it stops at its own permission prompt in the terminal (“Do you want to proceed?”), Antenna does not see that, and nothing notifies you: allow the tools you use routinely in Claude Code’s settings.

Choose which chats notify

Open ⋮ on a chat’s row, or right-click it, then Notifications:

  • All messages: every new message in this chat (the default for a person).
  • Only when it asks for me: messages to you in person and approval requests (the default for an agent).
  • Off: approval requests still notify.

When Claude Code reports to one of your other agents instead of to you, those messages stay quiet unless you turn on Notify about messages between agents in the same menu. In a terminal: antenna chats notify server --agent api-dev all.

On the computer you are at

With Claude Code in Code mode on your own laptop, Antenna notifies you of its approval requests and questions while the window is in the background, but not of the end of a turn: an agent cannot message you on its own computer. For that, Claude Code’s own hooks can run a command of yours when it stops.

Questions

Does the notification show what Claude Code wrote?

No. It says only “New message in” and the chat’s name, because a notification can show on a locked screen. Open the chat to read the report.

What if my laptop is asleep?

The message waits on the server, and Antenna delivers it, with its notification, when the laptop is back online.

Can I get the notification on my phone?

Not yet. Antenna runs on macOS and Linux today.
