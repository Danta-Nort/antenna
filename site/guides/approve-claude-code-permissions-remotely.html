Start Claude Code through Antenna, in Code mode in the window or with antenna session on a server, and Antenna’s daemon checks every tool it uses and every message it sends. When a step needs you, it becomes an approval request that shows on each computer you paired as your own, in My devices, with a notification. Approve it there with that computer’s password or Touch ID: the computer where Claude Code runs checks your answer, carries the step out, and Claude Code continues.

What reaches you

  • Steps after reading a contact’s message. Once Claude Code has read a teammate’s message, their trust level sets what it may do: at level 4 each command waits for you; at levels 2 and 3 each edit does, and commands are refused.
  • Changes to its own setup. After reading any contact’s message, even from your own laptop, edits to CLAUDE.md, .claude/, shell profiles, keys and build files such as package.json wait for you.
  • Messages that would carry your data out. Once it has read files of your project, each message to a contact below ∞ waits, and so does any message to such a contact that looks like it holds a key, a password or a token. Once it has read one conversation, a message into another waits too.
  • Questions. Experimental. An agent’s questions show on the computer where it runs, under Questions from your agents. To get them on your laptop instead, run antenna agent escalate api-dev --to mac on the computer where it runs: each question then arrives in the agent’s chat, and you answer in the chat.

Claude Code’s own permission prompt (“Do you want to proceed?”) stays in its terminal: Antenna never types into it. Allow the tools you use routinely in Claude Code’s settings, or answer it with antenna session attach.

Set it up

  1. Install Antenna on both computers and pair them once with This is my own computer (∞) ticked, as in Claude Code on a VPS.
  2. Start Claude Code through Antenna. On a desktop: Agents → AI apps → Start in Code mode. On a server: 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
  3. On the computer where Claude Code runs, accept answers from the one you will approve from: My devices → that computer’s card → Approvals → Accept approvals signed with …, with your password. On a server: antenna devices confirm mac.

Answer from any computer

The request shows on the asking computer’s card in My devices (experimental), with a notification such as “Antenna: approval needed on Mac mini”. The card says which agent asks, what for, why, and quotes its text, except a text with a secret in it, which never leaves the computer that asked. Press Approve with Touch ID on a Mac (experimental), Approve with password with the password of the computer you are at, or Deny.

The computer that asked checks the signature against the keys you accepted there, its own one-time challenge and this exact request, then carries the request out itself, once. On that computer itself, the request is in Approval requests, or antenna approvals and antenna approve <id> in a terminal.

Claude Code waits up to 50 seconds, and a step approved by then runs at once. Later, it goes on with other work; when you approve, Antenna types “Approved — continue.” into its prompt and it runs the step again.

If nobody answers

A request closes after 10 minutes: nothing runs and nothing is sent, and Claude Code learns that nobody approved it. A notification warns you shortly before. After Deny, which needs no password, Claude Code learns that you said no.

An agent that approves for you

Experimental. Can approve for… in Agents lets an agent you trust answer your other agents’ requests about messages and files, and its answer counts only when everything the request touches is at ∞. Commands and edits always come to you.

Questions

Does this work with Codex?

Partly. What Codex sends through Antenna is checked the same way, and those requests reach all your computers; Codex’s own commands stay with Codex’s approvals in its terminal.

Can any computer approve?

No. Only a computer you paired as your own and whose keys you accepted, with the password, on the computer that asks. For a lost one, Revoke this computer on each of the others.

Can I approve from my phone?

Not yet. Antenna runs on macOS and Linux today.
