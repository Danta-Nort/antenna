Install Claude Code and the Antenna node on your Linux VPS, pair the server with your laptop once, and start Claude Code through Antenna in your project folder. It then runs in its own tmux session after you log out, wakes when a message for it arrives, and answers in a chat on your laptop. No inbound port to open, no SSH session to keep alive, and Codex works the same way.

What you need

  • A Linux server on x86_64, with Claude Code (or Codex) installed and signed in, and tmux.
  • Antenna on your laptop: macOS or Linux.

1. Install the Antenna node on the server

curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER

The installer reads the newest release from the signed manifest, checks the archive, installs antennad and antenna into ~/.local/bin as a systemd user service (no root needed) and creates your node with a password. The second line keeps the service running after you log out. On Ubuntu or Fedora you can install the .deb or .rpm instead.

2. Pair it with your laptop

On your laptop: New contact → Invite, name it, tick This is my own computer (∞), press Create link and copy it. On the server:

antenna join '<link>' --trust 5 --label mac

Keep the single quotes: the link contains a #. Type the code your laptop shows into the server’s terminal, then press The contact confirmed — codes match on the laptop. Level 5 is ∞ on both sides, so the server counts as your own computer.

3. Start Claude Code through Antenna

cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev

The connect line gives the session its own agent and token, and says hello so a chat named api-dev appears on your laptop. The start line runs Claude Code in Antenna’s own tmux server (your tmux is not touched). Attach once to answer Claude Code’s first questions, such as whether it trusts the folder, then leave with Ctrl-b d: it keeps running. For Codex, use antenna connect codex and --cli codex.

4. Talk to it

Write in the api-dev chat on your laptop: “Run the migration tests and fix what fails.” When Claude Code is idle at its prompt, Antenna types one short line so it reads your message; it never types a contact’s text and never answers a question for it. The server’s card in My devices shows its health and its agents, and you can approve its requests from the laptop.

After a reboot

The node’s keys are locked after the server restarts: the service runs, but its links stay silent until you log in and run antenna unlock. That way a copy of the server’s disk gives nobody your keys. antenna status says whether it is locked.

Questions

Why not just SSH and tmux?

That works while you sit at a terminal. Antenna adds a chat you can write to from your laptop at any time, wakes the session when you do, and lets other agents give it work, with permissions it checks itself.

Does the server need a public IP or open ports?

No. Both sides connect out, directly when the network allows and through a relay otherwise. The relay forwards encrypted traffic only.

Can I run several sessions on one server?

Yes: one agent per project folder, each with its own name and its own chat on your laptop.

Is there an ARM build?

Not yet. The server node is built for x86_64 Linux.
