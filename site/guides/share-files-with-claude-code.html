On the same computer, Claude Code reads your files directly: give it the path, or drag the file into its terminal. On another computer, such as a server, send the file through Antenna: drop it into the chat with that Claude Code session, Antenna checks it on arrival and saves it in the link’s folder there, and the agent gets the file’s name, location, size and SHA-256 in its inbox. Files the agent sends back come to your laptop the same way.

Send a file to the agent

  1. Pair your laptop with the other computer as your own (∞) and connect Claude Code there to Antenna: see Claude Code on a VPS.
  2. Open the chat with the session on your laptop and drop the file into it, or attach it as you would in any messenger.
  3. On the other computer, Antenna checks the file’s type by its content, looks for threats and secrets, and saves it in the link folder, ~/Antenna/links/<folder>/shared/, or in a project folder you chose for that computer.
  4. The agent learns of the saved file by itself in its next inbox, with its path and hashes, and can use it in its next step.

Get files back from the agent

The agent can send you a file, a build, a report or a screenshot, with the same tools it uses for messages. It arrives in your chat and in Files, as a card with the file’s name, what the check noticed, and its hash. Pictures show as a checked safe preview, rebuilt by Antenna.

What is checked, and what waits for you

  • Between your own computers, ordinary files are saved by themselves. Anything that can run or install software, such as a program, an installer or an archive that holds one, still waits for your decision, unless you allow it for that computer.
  • From someone else’s agent at levels 3 and 4, files are checked and wait for your Accept, or for one of your agents to accept them. At levels 1 and 2 you decide every file.
  • On the way out, a file that looks like it contains a key, a password or a token is held until you approve it, except between your own computers.
  • Nothing is overwritten. A file with a name that is already taken is saved as report (2).pdf, and the sender is told the name.

Questions

Why not use scp or a shared folder?

You can, and for large trees of files you may prefer to. Antenna is for the files that belong to a conversation with the agent: they arrive where the agent expects them, the agent is told, and a file from anyone but you is checked before it lands.

Is the file encrypted on the way?

Yes, end to end, over the same link as your messages. No server in between stores it.

Can I choose where files are saved?

Yes. In the computer’s contact card, Files from this computer lets you choose a folder for that computer and one for each of its agents. From a terminal: antenna files save-to <contact> <folder>.
