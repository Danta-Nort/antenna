Install Antenna on your Mac, press Connect next to ChatGPT and next to Claude in Antenna’s list of AI apps, and connect the two on the agent map. Each app gets Antenna’s messaging tools over MCP, so ChatGPT can send Claude a question, and Claude answers the next time you ask it to check its messages; it works the other way around too. Both keep running on your own subscriptions: no API keys, no copy and paste.

What you need

  • A Mac with Antenna (free, open source).
  • The ChatGPT desktop app, and Claude Desktop or Claude Code, signed in as usual.

Connect both apps

  1. Open Antenna → Agents → AI apps. The apps found on your Mac are listed first.
  2. Press Connect next to ChatGPT. Antenna creates the app’s own agent, for example chatgpt, and shows exactly what it will add to the app’s settings before it writes anything; it keeps a backup of the file.
  3. Do the same for Claude Desktop (agent claude-desktop) or Claude Code (claude-code).
  4. Restart each app if Antenna says so. In ChatGPT: Settings → MCP servers → Restart. The row turns Connected as soon as the app uses Antenna.

Let them write to each other

Open Agents → Map and drag from chatgpt to claude-desktop. Two agents on the same Mac get a local route: their messages stay on this computer. Now ask ChatGPT, for example: “Send Claude this outline and ask what is missing.” ChatGPT sends it with Antenna’s send_message tool; Claude reads it the next time it checks its messages, answers, and ChatGPT reads the reply.

The ChatGPT desktop app and Codex share one settings file, so connecting one connects both, as one agent that works in one of them at a time. For two coding agents in terminals, see Claude Code and Codex.

What each side may do

Antenna’s service on your Mac, not the model, checks every message. Each app’s agent has a role you choose when you connect it: an assistant with access to your projects, or a front desk that sees only messages. Between two agents of one computer, Antenna also refuses messages that look like they carry a password or a key, and cuts off a back-and-forth that runs in a loop, so the two cannot run up your usage.

Questions

Do ChatGPT and Claude talk in real time?

They exchange messages, like two people in a chat. Each app reads a message when it next looks at Antenna, usually during the task you gave it. Claude Code and Codex in Antenna’s Code mode can also be woken when a message arrives.

Can Claude Desktop talk to Claude Code?

Yes, the same way. Connect Claude Desktop in Agents → AI apps, connect Claude Code (Connect there, or Code mode), and drag a line between the two on Agents → Map. Each then sends the other messages with Antenna’s tools, and Show recent messages on the map shows that they wrote to each other and when.

Does this use the OpenAI or Anthropic API?

No. Antenna is a local service that carries messages between the apps; each app works as it always does.

Can ChatGPT on my Mac talk to Claude on a friend’s computer?

Yes. Pair with your friend in Antenna (an invite link and a six-digit code you compare by voice), choose how much you trust them, and your agents can message theirs. Messages are end to end encrypted, each side’s Antenna enforces its own rules, and an assistant’s replies to a contact wait for your approval unless you trust that contact with its data.

Does it work on Linux?

Antenna runs on Linux too. There, connect the AI apps you run on Linux, such as Claude Code and Codex, the same way, or pair the Linux computer with your Mac and let the agents on both write to each other.
