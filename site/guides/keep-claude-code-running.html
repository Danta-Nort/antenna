You cannot, on the laptop itself: closing the lid puts a laptop to sleep, a sleeping computer runs nothing, and Claude Code pauses with it. The way out is to run Claude Code on a computer that stays on, such as a Linux server or a Mac mini set not to sleep, start it there through Antenna, and give it tasks from your laptop’s Antenna chat. Close the laptop: Claude Code keeps working on the other computer, and its replies wait for the laptop and arrive when it is back online.

Why it stops

Claude Code runs on the computer you start it on. When that computer sleeps, every program on it stops, Claude Code included, until it wakes up. Closing the terminal or the SSH window it runs in ends it too. A laptop can be kept awake with the lid shut, but then it has to stay plugged in and switched on, and it has become a server. So the work moves to a computer that is always on, and the laptop only talks to it.

What you need

  • A computer that stays on: a Linux server on x86_64 (a VPS or one at home), or a Mac or Linux desktop set not to sleep.
  • Claude Code installed and signed in there.
  • Antenna on both computers: the app on your laptop (macOS or Linux), the node or the app on the other one.

On a server

  1. Install the Antenna node and let it run after you log out: 
    curl -fsSL https://antenna.contact/install.sh | sh
sudo loginctl enable-linger $USER
    The installer sets Antenna up as a systemd user service and creates your node with a password. It does not turn on lingering, it only reminds you: without the second line the service stops when you log out.
  2. Pair the server with your laptop once. On the laptop: New contact → Invite, tick This is my own computer (∞), press Create link and copy it. On the server: antenna join '<link>' --trust 5 --label mac, type the code the laptop shows, then press The contact confirmed — codes match on the laptop.
  3. Start Claude Code through Antenna in the project folder (the server needs tmux): 
    cd ~/projects/api
antenna connect claude-code --agent api-dev --links mac --hello mac
antenna session start api-dev --dir ~/projects/api
antenna session attach api-dev
    Answer Claude Code’s first questions, such as whether it trusts the folder, then leave with Ctrl-b d. A chat named api-dev is now on your laptop.
  4. Let the laptop answer the server’s approval requests: antenna devices confirm mac.

Now log out of SSH. The service keeps running, and Claude Code keeps running in Antenna’s own tmux server; your own tmux is not touched. Claude Code on a VPS has each step in more detail.

On a Mac or desktop that stays on

  1. Set the computer not to sleep on its own, in its system settings. Antenna does not keep a computer awake.
  2. Pair it with your laptop as above, with This is my own computer (∞) ticked.
  3. On it, open Agents → AI apps and press Start in Code mode next to Claude Code. Pick New agent… and give it a name, choose the Working folder, enter your password and press Start. The window switches to Code mode, and Claude Code runs in a tab inside it.
  4. Ask Claude Code once, in its tab, to say hello to your laptop over Antenna. Its chat then appears on the laptop.
  5. Let the laptop answer its approval requests: My devices → the laptop’s card → Approvals → Accept approvals signed with …, with your password.

Leave Antenna’s window open: closing it stops the agents running in it, and the window asks first.

Leave it working

Write the task in the agent’s chat on your laptop: “Run the migration tests, fix what fails, and reply here with what changed.” When Claude Code sits idle at its prompt, Antenna types one built-in line so it reads your message; if it is in the middle of a turn, it gets the message when the turn ends. Antenna never types your text into the terminal. Experimental. Then close the laptop.

Before a long run, check what could stop it while nobody is there:

  • Claude Code’s own permission prompt (“Do you want to proceed?”) waits in its terminal until someone answers, and Antenna never answers it. Allow the tools the task needs in Claude Code’s settings.
  • Antenna’s approval requests wait 10 minutes. Then nothing runs, and Claude Code learns that nobody approved. A task you give from your own computer at ∞ runs its commands and edits without asking; changes to Claude Code’s own setup, such as CLAUDE.md or .claude/, still ask.

When the laptop wakes up

While the laptop sleeps, Claude Code’s replies wait in the other computer’s queue, and Antenna keeps trying to deliver them. Once the laptop is back online they arrive in the chat, with a notification while Antenna’s window is not in front. A message you wrote while offline shows a clock and goes out by itself. Requests still waiting for your approval show on the other computer’s card in My devices (experimental).

After the other computer restarts

The keys are locked after a restart, so its links stay silent until you enter the password. On a server, log in and run antenna unlock, then start the session again; --resume continues Claude Code’s last session:

antenna session start api-dev --dir ~/projects/api --resume

On a Mac, enter the password in Antenna’s window and start the agent again.

Questions

Does Claude Code keep running if I close my laptop?

Not if closing the lid puts the laptop to sleep, which is the usual setting: Claude Code pauses until you open it. Run it on a computer that stays on and it keeps working.

Can Claude Code run in the background on my laptop?

While the laptop is awake, yes: in Code mode it runs in a tab of Antenna’s window that you need not look at, and Antenna wakes it when a message arrives. It still stops when the laptop sleeps.

Do I need to keep an SSH session open?

No. Claude Code runs in Antenna’s tmux on the server, and you reach it through the chat. Both computers connect out, so no inbound port is opened either.

Does Antenna keep my Mac awake?

No. Set the Mac not to sleep in its system settings. Antenna’s window has to stay open for Code mode.

Can I check on it from my phone?

Not yet. Antenna runs on macOS and Linux today.
