Antenna: first launch on a Mac

1. Drag Antenna to Applications, then open it from Applications (not from this window: macOS would run a copy
   from a temporary folder, and agent settings would point to the wrong place).

2. Antenna asks you to create your node: choose a password. It protects your keys on this Mac and cannot be
   recovered, so keep it somewhere safe.

3. Invite your other computer or a person (New contact → Invite), or open an invite link you received.

4. Connect an AI agent: Agents → AI apps → Connect next to Claude Code, Codex or another app you use.

5. To use the antenna command in Terminal: Settings → "antenna command in the terminal…".

Guide: https://github.com/Danta-Nort/antenna/blob/main/docs/guide/getting-started.md
